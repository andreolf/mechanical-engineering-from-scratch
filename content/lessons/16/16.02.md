title: Direct stiffness method for trusses
minutes: 45

A truss is a set of bars joined by pins, like a footbridge or the frame of a crane. Each bar is just a spring along its own axis, with $k = EA/L$. The only new ingredient compared with the spring chain is **direction**: a bar at an angle pushes its end nodes both horizontally and vertically. With that one change, the same assembly solves any 2D truss.

## A bar in global axes

Let a bar run from node $i$ to node $j$ at angle $\theta$, with $c = \cos\theta$, $s = \sin\theta$. Its stretch is the relative displacement projected on its axis, $\delta = c(u_j - u_i) + s(v_j - v_i)$. Its force $N = (EA/L)\delta$ acts along the axis on both nodes. Written for the four displacements $[u_i, v_i, u_j, v_j]$:

$$
k_e = \frac{EA}{L}\begin{bmatrix} c^2 & cs & -c^2 & -cs \\ cs & s^2 & -cs & -s^2 \\ -c^2 & -cs & c^2 & cs \\ -cs & -s^2 & cs & s^2 \end{bmatrix} = \frac{EA}{L}\,\mathbf t\,\mathbf t^{\mathsf T}, \quad \mathbf t = [c, s, -c, -s]^{\mathsf T} .
$$

This is the spring matrix rotated into global axes. Assembly puts each $k_e$ into the rows and columns of its four degrees of freedom; supports remove fixed degrees of freedom; solve; and each bar's force follows from its end displacements: $N = (EA/L)\,[c(u_j - u_i) + s(v_j - v_i)]$, tension positive.

## The check: statics

If a truss has exactly as many unknowns (bar forces plus reactions) as joint equilibrium equations, $m + r = 2n$, it is **statically determinate**: the forces follow from equilibrium alone, whatever the stiffness. The **method of joints** writes $\sum F_x = 0$ and $\sum F_y = 0$ at every joint and solves them as one linear system. For a determinate truss, the stiffness method must give exactly the same bar forces. For an indeterminate truss (extra bars), only the stiffness method works, because the force split then depends on the stiffnesses.

:::example A Pratt footbridge truss
Four panels of 3 m, 2.5 m deep. Steel bars with $EA = 210\ \text{GPa}\cdot1200\ \text{mm}^2$. Pin at the left, roller at the right; deck loads of 20, 30 and 20 kN at the three inner bottom joints. Eight joints, 13 bars and 3 reactions: $13 + 3 = 16 = 2\cdot8$, so it is determinate.

1. Reactions 35 kN at each support (by symmetry).
2. End diagonals: length $\sqrt{3^2 + 2.5^2} = 3.905$ m, so the force is $35\cdot3.905/2.5 = 54.67$ kN in compression. The bottom chord carries its horizontal component, $35\cdot3/2.5 = 42.0$ kN in tension.
3. Top chord at mid-span: moment $35\cdot6 - 20\cdot3 = 150$ kN·m over a depth of 2.5 m gives 60.0 kN compression.
4. The FEM solver and the method of joints agree on all 13 bar forces and the 3 reactions to within $10^{-6}$ N. The middle vertical carries nothing; the inner diagonals carry 23.43 kN in tension.
5. Mid-span deflection 4.805 mm, about span/2500. Only the stiffness method gives this.
:::

```python file=truss.py
"""2D truss by the direct stiffness method: bar stiffness rotated to global axes, assembly, supports, member forces; checked against the method of joints for a statically determinate footbridge truss."""
import math
import numpy as np


def bar_stiffness(xy1, xy2, EA):
    dx, dy = np.subtract(xy2, xy1)
    L = math.hypot(dx, dy)
    c, s = dx / L, dy / L
    t = np.array([c, s, -c, -s])
    return EA / L * np.outer(t, t), L, c, s


def solve_truss(nodes, bars, EA, supports, loads):
    """nodes: (n, 2) array; bars: list of (i, j); supports: list of fixed dof indices; loads: {dof: force}."""
    n = len(nodes)
    K = np.zeros((2 * n, 2 * n))
    for i, j in bars:
        k, *_ = bar_stiffness(nodes[i], nodes[j], EA)
        d = [2 * i, 2 * i + 1, 2 * j, 2 * j + 1]
        K[np.ix_(d, d)] += k
    F = np.zeros(2 * n)
    for dof, f in loads.items():
        F[dof] += f
    free = [d for d in range(2 * n) if d not in supports]
    u = np.zeros(2 * n)
    u[free] = np.linalg.solve(K[np.ix_(free, free)], F[free])
    N = []
    for i, j in bars:
        _, L, c, s = bar_stiffness(nodes[i], nodes[j], EA)
        N.append(EA / L * (c * (u[2 * j] - u[2 * i]) + s * (u[2 * j + 1] - u[2 * i + 1])))
    return u, np.array(N), K @ u - F


def method_of_joints(nodes, bars, supports, loads):
    """Equilibrium at every joint: unknowns are the bar forces (tension +) and the support reactions."""
    n = len(nodes)
    m = len(bars) + len(supports)
    A = np.zeros((2 * n, m)); b = np.zeros(2 * n)
    for e, (i, j) in enumerate(bars):
        dx, dy = np.subtract(nodes[j], nodes[i]); L = math.hypot(dx, dy)
        c, s = dx / L, dy / L
        A[2 * i, e] += c; A[2 * i + 1, e] += s      # tension pulls joint i towards j
        A[2 * j, e] -= c; A[2 * j + 1, e] -= s
    for r, dof in enumerate(supports):
        A[dof, len(bars) + r] = 1.0
    for dof, f in loads.items():
        b[dof] -= f
    assert A.shape[0] == A.shape[1], "not statically determinate"
    x = np.linalg.solve(A, b)
    return x[:len(bars)], x[len(bars):]


if __name__ == "__main__":
    # Pratt footbridge truss: 4 panels of 3 m, 2.5 m deep, steel bars EA = 210 GPa x 1200 mm^2
    P, H = 3.0, 2.5
    bottom = [(k * P, 0.0) for k in range(5)]
    top = [(k * P, H) for k in range(1, 4)]
    nodes = np.array(bottom + top)                       # 0-4 bottom, 5-7 top
    bars = [(0, 1), (1, 2), (2, 3), (3, 4), (5, 6), (6, 7), (0, 5), (4, 7),
            (1, 5), (2, 6), (3, 7), (5, 2), (7, 2)]
    EA = 210e9 * 1200e-6
    supports = [0, 1, 9]                                 # pin at node 0, roller (vertical) at node 4
    loads = {3: -20e3, 5: -30e3, 7: -20e3}               # deck loads at the bottom joints 1, 2, 3 (N)
    u, N, R = solve_truss(nodes, bars, EA, supports, loads)
    Nj, Rj = method_of_joints(nodes, bars, supports, loads)
    for e, (i, j) in enumerate(bars):
        print(f"bar {i}-{j}: FEM {N[e]/1000:8.3f} kN, joints {Nj[e]/1000:8.3f} kN")
    assert np.allclose(N, Nj, atol=1e-6)                 # determinate: stiffness method = statics
    assert np.allclose(R[supports], Rj, atol=1e-6)
    print(f"reactions {Rj/1000} kN; mid-span deflection {-u[5]*1000:.3f} mm")
    assert abs(Rj[1] + Rj[2] - 70e3) < 1e-6
```
