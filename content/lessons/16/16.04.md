The hat functions of the last lesson are the simplest **shape functions**. Every finite element is defined by its shape functions: how the unknown field is interpolated from the nodal values inside one element. Higher-order shape functions follow curves better and converge faster. This lesson builds 1D elements of order 1 and 2 on a **reference element** and measures the difference.

## The reference element

Every element is mapped from the reference interval $\xi \in [-1, 1]$ by $x = x_a + (\xi + 1)\,h/2$, so $dx = J\,d\xi$ with Jacobian $J = h/2$. Derivatives transform as $d/dx = (1/J)\,d/d\xi$.

**Linear** (2 nodes, at $\xi = \mp1$):

$$
N_1 = \tfrac12(1 - \xi), \qquad N_2 = \tfrac12(1 + \xi) .
$$

**Quadratic** (3 nodes, at $\xi = -1, 0, 1$):

$$
N_1 = \tfrac12\xi(\xi - 1), \qquad N_2 = 1 - \xi^2, \qquad N_3 = \tfrac12\xi(\xi + 1) .
$$

Each $N_a$ is 1 at its own node and 0 at the others, and they always sum to 1 (**partition of unity**), so a constant field is reproduced exactly. With $\mathbf B = d\mathbf N/dx$, the element matrices are

$$
k_e = \int_{-1}^{1} EA\,\mathbf B\,\mathbf B^{\mathsf T}\,J\,d\xi, \qquad f_e = \int_{-1}^{1} \mathbf N\,f\,J\,d\xi ,
$$

evaluated with **Gauss quadrature**: $n$ points integrate polynomials up to degree $2n - 1$ exactly.

## Convergence

For a smooth solution, the error in the displacement (measured as an $L^2$ norm) falls as $h^{p+1}$ for elements of order $p$: halving the elements cuts the linear error by 4 and the quadratic error by 8. Per unknown, the higher-order element usually wins clearly. The catch is smoothness: near a crack tip or a point load, the solution is not smooth, and refinement there matters more than order.

:::example Linear against quadratic

1. Linear elements with 4, 8, 16, 32 elements: $L^2$ errors $3.928\times10^{-2}$, $9.921\times10^{-3}$, $2.487\times10^{-3}$, $6.220\times10^{-4}$. Fitted rate 1.994.
2. Quadratic elements, same element counts: $1.952\times10^{-3}$, $2.457\times10^{-4}$, $3.076\times10^{-5}$, $3.847\times10^{-6}$. Rate 2.996.
3. Same 17 nodes: 16 linear elements give $2.487\times10^{-3}$, 8 quadratic elements $2.457\times10^{-4}$, 10.1 times smaller.
:::

```python file=shape1d.py
"""1D finite elements with linear and quadratic Lagrange shape functions on the reference element; convergence study shows quadratic elements converge faster."""
import math
import numpy as np


def gauss(n):
    x, w = np.polynomial.legendre.leggauss(n)
    return x, w


def shape(order, xi):
    """Lagrange shape functions and their derivatives on xi in [-1, 1]."""
    if order == 1:
        N = np.array([(1 - xi) / 2, (1 + xi) / 2])
        dN = np.array([-0.5 + 0 * xi, 0.5 + 0 * xi])
    else:  # nodes at -1, 0, 1
        N = np.array([xi * (xi - 1) / 2, 1 - xi**2, xi * (xi + 1) / 2])
        dN = np.array([xi - 0.5, -2 * xi, xi + 0.5])
    return N, dN


def solve(order, ne, f, EA=1.0, L=1.0):
    """-(EA u')' = f on [0, L], u(0) = u(L) = 0."""
    nn = order * ne + 1
    x_nodes = np.linspace(0, L, nn)
    K = np.zeros((nn, nn)); F = np.zeros(nn)
    xg, wg = gauss(order + 2)
    for e in range(ne):
        dofs = np.arange(order * e, order * e + order + 1)
        a, b = x_nodes[dofs[0]], x_nodes[dofs[-1]]
        J = (b - a) / 2
        N, dN = shape(order, xg)
        x = a + (xg + 1) * J
        B = dN / J
        K[np.ix_(dofs, dofs)] += EA * (B * wg) @ B.T * J
        F[dofs] += (N * wg) @ f(x) * J
    u = np.zeros(nn)
    u[1:-1] = np.linalg.solve(K[1:-1, 1:-1], F[1:-1])
    return x_nodes, u


def l2_error(order, ne, x_nodes, u, exact, L=1.0):
    xg, wg = gauss(8)
    err = 0.0
    for e in range(ne):
        dofs = np.arange(order * e, order * e + order + 1)
        a, b = x_nodes[dofs[0]], x_nodes[dofs[-1]]
        J = (b - a) / 2
        N, _ = shape(order, xg)
        x = a + (xg + 1) * J
        err += np.sum(wg * (u[dofs] @ N - exact(x)) ** 2) * J
    return math.sqrt(err)


if __name__ == "__main__":
    f = lambda x: math.pi**2 * np.sin(math.pi * x)
    exact = lambda x: np.sin(math.pi * x)
    # partition of unity on the reference element
    for order in (1, 2):
        N, dN = shape(order, np.linspace(-1, 1, 7))
        assert np.allclose(N.sum(0), 1) and np.allclose(dN.sum(0), 0)
    rates = {}
    for order in (1, 2):
        errs, hs = [], []
        for ne in (4, 8, 16, 32):
            x, u = solve(order, ne, f)
            errs.append(l2_error(order, ne, x, u, exact)); hs.append(1 / ne)
        slope = np.polyfit(np.log(hs), np.log(errs), 1)[0]
        rates[order] = slope
        print(f"order {order}: L2 errors {['%.3e' % e for e in errs]}, convergence rate {slope:.3f}")
    assert abs(rates[1] - 2) < 0.1 and abs(rates[2] - 3) < 0.15 and rates[2] > rates[1]
    # same number of unknowns (17 nodes): quadratic is far more accurate
    x1, u1 = solve(1, 16, f); x2, u2 = solve(2, 8, f)
    e1, e2 = l2_error(1, 16, x1, u1, exact), l2_error(2, 8, x2, u2, exact)
    print(f"17 nodes each: linear error {e1:.3e}, quadratic error {e2:.3e} ({e1/e2:.1f} times smaller)")
    assert e2 < e1
```

:::exercise Evaluating shape functions
Evaluate the three quadratic shape functions at $\xi = 0.5$ and check that they sum to 1. If the nodal values are 0, 2 and 3, what is the interpolated value there?
---solution---
1. $N_1 = \tfrac12\cdot0.5\cdot(-0.5) = -0.125$, $N_2 = 1 - 0.25 = 0.75$, $N_3 = \tfrac12\cdot0.5\cdot1.5 = 0.375$.
2. Sum: $-0.125 + 0.75 + 0.375 = 1$.
3. $u = 0\cdot(-0.125) + 2\cdot0.75 + 3\cdot0.375 = 2.625$.
:::
