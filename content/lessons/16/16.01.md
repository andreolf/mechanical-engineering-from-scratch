The finite element method (FEM) analyses everything from bike frames to dams. Its core idea fits in a chain of springs: break a structure into simple pieces (**elements**), write the force-displacement law of one piece as a small matrix, and add all the pieces into one big system. Phase 16 builds that machinery from scratch, one step at a time, until it handles 2D and 3D solids, vibration and nonlinearity.

## One spring, one matrix

A spring of stiffness $k$ connects node $i$ to node $j$. The force it exerts depends only on the stretch $u_j - u_i$. The forces on its two ends are

$$
\begin{bmatrix} f_i \\ f_j \end{bmatrix} = k\begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}\begin{bmatrix} u_i \\ u_j \end{bmatrix} .
$$

That 2 × 2 matrix is the **element stiffness matrix**. It is symmetric, and it is singular: moving both ends together ($u_i = u_j$) produces no force. That is a **rigid-body mode**.

## Assembly

At each node, the external force must balance the sum of the spring forces from every element attached to it. So the global system $K\mathbf u = \mathbf F$ is built by adding each element matrix into the rows and columns of its two nodes. This **assembly** step is the same for every element type in this phase; only the element matrix changes.

The assembled $K$ is still singular, because the whole chain can slide. **Supports** fix that: a node with prescribed zero displacement has its row and column removed, the reduced system is solved, and the removed rows then give the **reaction forces**, $\mathbf R = K\mathbf u - \mathbf F$.

For springs in a chain, the result must match the series formula $1/k_{\text{eq}} = \sum 1/k_e$, and every spring carries the same force.

:::example A four-spring chain
Springs of 200, 100, 400 and 250 N/mm in a chain, fixed at node 0, pulled with 1 kN at node 4.

1. Assembly gives a 5 × 5 tridiagonal matrix. Row 2, for example, is $[0, -100, 500, -400, 0]$: node 2 touches the 100 and the 400 N/mm springs.
2. Remove node 0 and solve: displacements 0, 5, 15, 17.5 and 21.5 mm.
3. Tip stiffness $1000/21.5 = 46.512$ N/mm. The series formula gives $1/(1/200 + 1/100 + 1/400 + 1/250) = 46.512$ N/mm.
4. Reaction at node 0: −1000 N. Each spring carries exactly 1000 N, for example $100\cdot(15 - 5) = 1000$ N.
5. With both ends fixed and loads of +300 N at node 1 and −200 N at node 3, the reactions are −193.02 N and +93.02 N; they sum to −100 N, balancing the net applied +100 N.
:::

```python file=springs.py
"""Finite elements as springs: element stiffness k[[1,-1],[-1,1]], assembly into a global matrix, supports, and a check against the series-spring formula."""
import numpy as np


def assemble(ks):
    """Chain of springs between nodes 0-1, 1-2, ...; returns the (n+1) x (n+1) global stiffness matrix."""
    n = len(ks)
    K = np.zeros((n + 1, n + 1))
    for e, k in enumerate(ks):
        ke = k * np.array([[1.0, -1.0], [-1.0, 1.0]])
        dofs = [e, e + 1]
        K[np.ix_(dofs, dofs)] += ke
    return K


def solve(K, F, fixed):
    """Remove fixed degrees of freedom (zero displacement), solve the rest, recover reactions."""
    n = len(F)
    free = [i for i in range(n) if i not in fixed]
    u = np.zeros(n)
    u[free] = np.linalg.solve(K[np.ix_(free, free)], F[free])
    R = K @ u - F
    return u, R


if __name__ == "__main__":
    ks = [200.0, 100.0, 400.0, 250.0]           # N/mm, a chain fixed at node 0
    K = assemble(ks)
    print("global stiffness matrix (N/mm):")
    print(K)
    assert np.allclose(K, K.T) and abs(np.linalg.det(K)) < 1e-6 * np.abs(K).max() ** len(K)  # symmetric and singular until supported
    F = np.zeros(5); F[-1] = 1000.0               # 1 kN pull at the free end
    u, R = solve(K, F, fixed=[0])
    series = 1 / sum(1 / k for k in ks)
    print(f"node displacements (mm): {np.round(u, 4)}")
    print(f"tip stiffness {F[-1]/u[-1]:.4f} N/mm, series formula {series:.4f} N/mm, reaction {R[0]:.1f} N")
    assert abs(F[-1] / u[-1] - series) < 1e-9 and abs(R[0] + 1000) < 1e-9
    # every spring carries the same force in a chain: k (u_j+1 - u_j)
    forces = [k * (u[e + 1] - u[e]) for e, k in enumerate(ks)]
    assert np.allclose(forces, 1000.0)
    # loads at interior nodes too, fixed at both ends
    F2 = np.array([0, 300.0, 0, -200.0, 0])
    u2, R2 = solve(K, F2, fixed=[0, 4])
    print(f"both ends fixed: displacements {np.round(u2, 4)} mm, reactions {R2[0]:.2f} and {R2[4]:.2f} N")
    assert abs(R2.sum() - (-F2.sum())) < 1e-9
```

:::exercise Two springs by hand
Springs $k_1 = 100$ and $k_2 = 300$ N/mm in series, fixed at the left, with 600 N at the right end. Assemble $K$, solve, and check the series formula.
---solution---
1. $K = \begin{bmatrix} 100 & -100 & 0 \\ -100 & 400 & -300 \\ 0 & -300 & 300 \end{bmatrix}$.
2. Remove node 0: $\begin{bmatrix} 400 & -300 \\ -300 & 300 \end{bmatrix}\begin{bmatrix} u_1 \\ u_2 \end{bmatrix} = \begin{bmatrix} 0 \\ 600 \end{bmatrix}$, so $u_1 = 6$ mm and $u_2 = 8$ mm.
3. Tip stiffness $600/8 = 75$ N/mm $= 1/(1/100 + 1/300)$. Reaction $-100\cdot6 = -600$ N.
:::
