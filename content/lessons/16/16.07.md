Real meshes are not made of perfect squares. The **isoparametric** idea handles any four-sided shape: write everything on the reference square $(\xi, \eta) \in [-1, 1]^2$, and use the *same* shape functions to map the geometry as to interpolate the displacement.

## The Q4 map

The bilinear shape functions of the four-node quadrilateral are

$$
N_a(\xi, \eta) = \tfrac14(1 + \xi_a\xi)(1 + \eta_a\eta), \qquad (\xi_a, \eta_a) \in \{(-1,-1), (1,-1), (1,1), (-1,1)\},
$$

and a point of the element is $x = \sum N_a x_a$, $y = \sum N_a y_a$. The **Jacobian** collects the derivatives of the map:

$$
J = \begin{bmatrix} \partial x/\partial\xi & \partial y/\partial\xi \\ \partial x/\partial\eta & \partial y/\partial\eta \end{bmatrix}, \qquad dA = \det J\; d\xi\, d\eta, \qquad \begin{bmatrix}\partial N/\partial x\\ \partial N/\partial y\end{bmatrix} = J^{-1}\begin{bmatrix}\partial N/\partial \xi\\ \partial N/\partial \eta\end{bmatrix} .
$$

Integrals over the real element become integrals over the square, evaluated by **Gauss quadrature**: 2×2 points at $\pm1/\sqrt3$, all weights 1. They integrate every term of degree up to 3 in each variable exactly.

## When the map breaks

$\det J$ must be positive everywhere. For a Q4 it is linear in $\xi$ and $\eta$, so it is enough to check the four corners, where $\det J$ is a quarter of the cross product of the two edges meeting there. A **non-convex** quad (one interior angle above 180°) gives a negative corner value: the map folds over, and the element must be rejected or remeshed. Very distorted but still valid elements are also bad news, because accuracy degrades as the shape departs from a square.

:::example Integrating on a distorted quad
Corners (counter-clockwise) $(0, 0)$, $(4, 0.5)$, $(3.2, 3.0)$, $(0.6, 2.2)$.

1. Shoelace area: $\tfrac12\sum(x_i y_{i+1} - x_{i+1}y_i) = 7.8200$. 2×2 Gauss on $\det J$: $7.8200000000$, exact to round-off.
2. $\int x\,dA$: Gauss $15.7986667$, polygon formula $15.7986667$; centroid $x = 2.0203$.
3. $\int x^2\,dA$: Gauss $39.3017333$, polygon formula $39.3017333$. Still exact, since $x^2 \det J$ is at most cubic in each variable.
4. At the centre, $\det J = 1.955 = 7.82/4$.
5. Pull corner 3 to $(1.2, 0.9)$: the corner value of $\det J$ there becomes $-0.85$, and the element is inverted.
:::

```python file=isoparam.py
"""Isoparametric Q4 mapping: shape functions, the Jacobian, 2x2 Gauss quadrature on a distorted quad, checked against the polygon (shoelace) formulas; detects an inverted element."""
import numpy as np

GP = np.array([-1, 1]) / np.sqrt(3.0)


def q4_shape(xi, eta):
    N = 0.25 * np.array([(1 - xi) * (1 - eta), (1 + xi) * (1 - eta), (1 + xi) * (1 + eta), (1 - xi) * (1 + eta)])
    dN = 0.25 * np.array([[-(1 - eta), (1 - eta), (1 + eta), -(1 + eta)],
                          [-(1 - xi), -(1 + xi), (1 + xi), (1 - xi)]])
    return N, dN


def jacobian(X, xi, eta):
    _, dN = q4_shape(xi, eta)
    return dN @ X            # rows: d/dxi, d/deta; cols: x, y


def integrate(X, f, gp=GP, w=None):
    w = np.ones(len(gp)) if w is None else w
    total = 0.0
    for a, wa in zip(gp, w):
        for b, wb in zip(gp, w):
            N, _ = q4_shape(a, b)
            x, y = N @ X
            total += f(x, y) * np.linalg.det(jacobian(X, a, b)) * wa * wb
    return total


def shoelace(X):
    x, y = X[:, 0], X[:, 1]
    xn, yn = np.roll(x, -1), np.roll(y, -1)
    cr = x * yn - xn * y
    A = cr.sum() / 2
    Sx = ((x + xn) * cr).sum() / 6          # integral of x dA
    Ixx = ((x**2 + x * xn + xn**2) * cr).sum() / 12   # integral of x^2 dA
    return A, Sx, Ixx


def min_detJ(X, n=21):
    s = np.linspace(-1, 1, n)
    return min(np.linalg.det(jacobian(X, a, b)) for a in s for b in s)


if __name__ == "__main__":
    X = np.array([[0.0, 0.0], [4.0, 0.5], [3.2, 3.0], [0.6, 2.2]])   # a distorted quad, corners counter-clockwise
    A, Sx, Ixx = shoelace(X)
    Ai = integrate(X, lambda x, y: 1.0)
    Si = integrate(X, lambda x, y: x)
    Ii = integrate(X, lambda x, y: x * x)
    print(f"area: Gauss {Ai:.10f}, shoelace {A:.10f}")
    print(f"integral of x: Gauss {Si:.10f}, polygon {Sx:.10f}; centroid x = {Si/Ai:.6f}")
    print(f"integral of x^2: Gauss {Ii:.10f}, polygon {Ixx:.10f}")
    assert abs(Ai - A) < 1e-12 and abs(Si - Sx) < 1e-12 and abs(Ii - Ixx) < 1e-11
    J0 = jacobian(X, 0, 0)
    print("J at the centre:", J0.round(4).tolist(), "det", round(np.linalg.det(J0), 6), "(= area/4: det J is linear in xi and eta for a Q4)")
    assert abs(np.linalg.det(J0) - A / 4) < 1e-12
    print(f"min det J over the element: {min_detJ(X):.4f}")
    assert min_detJ(X) > 0
    # pull corner 3 past the diagonal: the quad becomes non-convex and det J goes negative near that corner
    Xbad = X.copy(); Xbad[2] = [1.2, 0.9]
    m = min_detJ(Xbad)
    print(f"non-convex quad: min det J = {m:.4f} (negative: inverted region, the element is unusable)")
    assert m < 0
```

:::exercise A corner Jacobian
For the same quad, find $\det J$ at corner 1, $(0, 0)$, from the two edges leaving it.
---solution---
1. Edge to corner 2: $(4, 0.5)$. Edge to corner 4: $(0.6, 2.2)$.
2. Cross product: $4 \times 2.2 - 0.5 \times 0.6 = 8.5$.
3. $\det J = 8.5/4 = 2.125$. The quarter is because the reference square has side 2, so each reference edge vector has length 2 and the area ratio carries $2 \times 2 = 4$.
:::
