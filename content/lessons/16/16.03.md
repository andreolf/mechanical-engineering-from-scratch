Springs and trusses are naturally discrete. Most structures are not: a beam, a plate or a dam wall is a continuum governed by a differential equation. The **weak form** is the bridge. It turns a differential equation into exactly the kind of matrix system we have been assembling, and it is the reason the finite element method works for heat, fluids and electromagnetism as well as for solids.

## From the strong form to the weak form

An elastic bar with axial stiffness $EA(x)$ under a distributed load $f(x)$ satisfies the **strong form**

$$
-\frac{d}{dx}\left(EA\,\frac{du}{dx}\right) = f, \qquad u(0) = 0, \qquad EA\,u'(L) = P .
$$

Multiply by any **test function** $w(x)$ that vanishes where $u$ is prescribed ($w(0) = 0$), integrate over the bar, and integrate by parts:

$$
\int_0^L EA\,u'\,w'\,dx = \int_0^L f\,w\,dx + P\,w(L) \qquad \text{for all admissible } w .
$$

This is the **weak form**. Three things happened. It asks for only one derivative of $u$ instead of two, so piecewise-linear functions are allowed. The end-force condition appeared by itself in the boundary term (it is a **natural** boundary condition), while $u(0) = 0$ must be imposed (an **essential** one). And if it holds for every $w$, the strong form follows back.

## Galerkin's method

Approximate $u \approx \sum_j u_j\,\phi_j(x)$ with **hat functions** $\phi_j$ (1 at node $j$, 0 at the others, linear in between) and use the same functions as test functions, $w = \phi_i$. Each choice of $i$ gives one equation:

$$
\sum_j \underbrace{\int_0^L EA\,\phi_i'\,\phi_j'\,dx}_{K_{ij}}\; u_j = \underbrace{\int_0^L f\,\phi_i\,dx + P\,\phi_i(L)}_{F_i} .
$$

On one element of length $h$ with constant $EA$, the derivatives of the two hats are $\mp1/h$, so the element integral is $\frac{EA}{h}\begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}$: **exactly the bar spring matrix**. The load vector gives each node its share of the distributed load, half an element's worth from each side for uniform $f$ (a **consistent** load vector).

In 1D, with linear elements and constant $EA$, the Galerkin solution is exact at the nodes, whatever $f$ is. Between the nodes it is only the linear interpolant. (The lesson plan suggested SymPy for this derivation; the code here evaluates the same integrals numerically with Gauss quadrature, which needs only NumPy.)

:::example A rod hanging under its own weight
A 100 m steel rod (E = 210 GPa, A = 2 cm², ρ = 7850 kg/m³) hangs from the top with a 2 kN weight at the bottom. Its weight per metre is $w = \rho g A = 15.40$ N/m. Five elements of 20 m.

1. The Galerkin matrix, integrated with 3 Gauss points per element, equals the assembled bar matrices to machine precision.
2. Load vector: $wh = 308.0$ N at each interior node, and $wh/2 + P = 2154.0$ N at the bottom node.
3. Exact solution $u = [w(Lx - x^2/2) + Px]/EA$. FEM and exact values agree at every node: 1.61245, 3.07822, 4.39731, 5.56972 and 6.59544 mm.
4. Halfway between the first two nodes, FEM gives 0.80623 mm against the exact 0.82456 mm: the true curve is a parabola, the element is straight.
:::

```python file=weakform.py
"""Weak form of -(EA u')' = f: Galerkin with hat test functions, integrals by Gauss quadrature, compared with the bar stiffness method; a rod hanging under its own weight is reproduced exactly at the nodes."""
import math
import numpy as np

GP = np.array([-math.sqrt(3 / 5), 0.0, math.sqrt(3 / 5)])
GW = np.array([5 / 9, 8 / 9, 5 / 9])


def hat(i, x, nodes):
    """Piecewise-linear test function: 1 at node i, 0 at all other nodes."""
    phi = np.zeros_like(x); dphi = np.zeros_like(x)
    if i > 0:
        a, b = nodes[i - 1], nodes[i]
        m = (x >= a) & (x <= b)
        phi[m] = (x[m] - a) / (b - a); dphi[m] = 1 / (b - a)
    if i < len(nodes) - 1:
        a, b = nodes[i], nodes[i + 1]
        m = (x > a) & (x <= b) if i > 0 else (x >= a) & (x <= b)
        phi[m] = (b - x[m]) / (b - a); dphi[m] = -1 / (b - a)
    return phi, dphi


def galerkin(nodes, EA, f, P_end):
    """K_ij = int EA phi_i' phi_j' dx, F_i = int f phi_i dx + P phi_i(L). Integrated element by element with Gauss points."""
    n = len(nodes)
    K = np.zeros((n, n)); F = np.zeros(n)
    for e in range(n - 1):
        a, b = nodes[e], nodes[e + 1]
        x = 0.5 * (a + b) + 0.5 * (b - a) * GP
        w = 0.5 * (b - a) * GW
        for i in (e, e + 1):
            phi_i, dphi_i = hat(i, x, nodes)
            F[i] += np.sum(w * f(x) * phi_i)
            for j in (e, e + 1):
                _, dphi_j = hat(j, x, nodes)
                K[i, j] += np.sum(w * EA(x) * dphi_i * dphi_j)
    F[-1] += P_end
    return K, F


def bar_stiffness_assembly(nodes, EA):
    n = len(nodes); K = np.zeros((n, n))
    for e in range(n - 1):
        k = EA / (nodes[e + 1] - nodes[e])
        K[e:e + 2, e:e + 2] += k * np.array([[1, -1], [-1, 1]])
    return K


if __name__ == "__main__":
    # a 100 m steel rod hanging from the top (x = 0) under its own weight, plus a 2 kN weight at the bottom
    L, E, A, rho, g, P = 100.0, 210e9, 2e-4, 7850.0, 9.81, 2000.0
    nodes = np.linspace(0, L, 6)
    K, F = galerkin(nodes, lambda x: E * A + 0 * x, lambda x: rho * g * A + 0 * x, P)
    Kb = bar_stiffness_assembly(nodes, E * A)
    print("Galerkin K equals the assembled bar matrices:", np.allclose(K, Kb))
    assert np.allclose(K, Kb, rtol=1e-12)
    w = rho * g * A
    h = nodes[1] - nodes[0]
    assert np.allclose(F[1:-1], w * h) and abs(F[-1] - (w * h / 2 + P)) < 1e-9  # consistent load: half an element to the end nodes
    u = np.zeros(len(nodes))
    u[1:] = np.linalg.solve(K[1:, 1:], F[1:])
    exact = lambda x: (w * (L * x - x**2 / 2) + P * x) / (E * A)
    print("node  FEM (mm)    exact (mm)")
    for x, ui in zip(nodes, u):
        print(f"{x:5.0f} {1000*ui:10.5f} {1000*exact(x):10.5f}")
    assert np.allclose(u, exact(nodes), rtol=1e-12, atol=1e-15)   # linear elements are exact at the nodes in 1D
    mid = 0.5 * (nodes[0] + nodes[1])
    print(f"between nodes (x = {mid}): FEM {1000*0.5*(u[0]+u[1]):.5f} mm, exact {1000*exact(mid):.5f} mm")
```

:::exercise Consistent loads
A bar of length 3 m is split into three equal elements and carries a uniform load of 600 N/m. What is the consistent load vector? What if the load were a point load of 900 N at x = 1.5 m?
---solution---
1. Each element carries $600\cdot1 = 600$ N, half to each of its nodes: $\mathbf F = [300, 600, 600, 300]$ N.
2. A point load at $x = 1.5$ m: $F_i = 900\,\phi_i(1.5)$. The point lies mid-way in element 2, so $\phi_1 = \phi_2 = 0.5$ there: $\mathbf F = [0, 450, 450, 0]$ N.
:::
