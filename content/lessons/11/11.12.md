Before a Swiss dam gets a new spillway, engineers build it at 1:30 or 1:50 in a laboratory hall, such as the VAW at ETH Zurich, and run water over it. A model is only useful if it behaves like the real thing, and that requires the right dimensionless groups to match. For open-water flows that's the Froude number. It's also why you can't make every group match at once.

## Similarity

A model is **geometrically similar** if every length scales by the same ratio $\lambda = L_p/L_m$. It's **dynamically similar** if the ratios of all forces match, which means the relevant dimensionless groups are equal in model and prototype.

## Froude scaling

Spillways, waves, ships and river works are dominated by gravity and inertia. Matching $Fr = V/\sqrt{gL}$ with the same $g$:

$$
\frac{V_p}{V_m} = \lambda^{1/2} .
$$

Everything else follows from the dimensions:

| Quantity | Prototype/model ratio |
|---|---|
| Length | $\lambda$ |
| Velocity, time | $\lambda^{1/2}$ |
| Discharge | $\lambda^{5/2}$ |
| Force (same fluid) | $\lambda^3$ |
| Pressure | $\lambda$ |
| Power | $\lambda^{7/2}$ |

## The Reynolds problem

With water in both, the Reynolds number is $\lambda^{3/2}$ times smaller in the model. Matching both Fr and Re would need a model fluid with viscosity $\lambda^{3/2}$ times lower than water, which doesn't exist. So modellers keep the model Reynolds number high enough (fully turbulent) that friction behaves similarly, and correct for the remaining **scale effects**.

:::widget froudemodel
Froude scale factors as a function of the model scale.
:::

:::example A 1:50 spillway model
1. Scale factors: velocity and time 7.07, discharge 17 677.67, force 125 000, power 883 883.
2. A prototype discharge of 1500 m³/s becomes 84.85 L/s in the model; 8 m/s becomes 1.1314 m/s; a 30 s surge lasts 4.243 s.
3. The Froude number is 0.8077 in both, while the Reynolds number drops from $8.0\times10^7$ to $2.26\times10^5$, a ratio of 353.6 $= 50^{1.5}$.
4. Matching Re too would need $\nu = 2.83\times10^{-9}$ m²/s.
:::

```python file=froude.py
"""Froude similarity: scale factors for a 1:50 spillway model, and why the Reynolds number can't match at the same time."""
import math

EXPONENTS = {"length": 1.0, "velocity": 0.5, "time": 0.5, "discharge": 2.5, "force": 3.0, "pressure": 1.0, "power": 3.5}


def scale(quantity, lam):
    """Prototype/model ratio for Froude similarity with the same fluid and gravity; lam = prototype/model length ratio."""
    return lam ** EXPONENTS[quantity]


if __name__ == "__main__":
    lam = 50.0
    for q in EXPONENTS:
        print(f"{q:9s}: prototype = model x {scale(q, lam):,.2f}")
    # a prototype spillway passing 1500 m^3/s, water 8 m/s, a 30 s surge
    Qp, Vp, tp = 1500.0, 8.0, 30.0
    Qm, Vm, tm = Qp / scale("discharge", lam), Vp / scale("velocity", lam), tp / scale("time", lam)
    print(f"model: {Qm*1000:.2f} L/s, {Vm:.4f} m/s, surge lasts {tm:.3f} s")
    g = 9.81; Lp = 10.0; Lm = Lp / lam
    Fr_p, Fr_m = Vp / math.sqrt(g * Lp), Vm / math.sqrt(g * Lm)
    assert abs(Fr_p - Fr_m) < 1e-12                                     # Froude matched
    assert abs(Vp / Vm - math.sqrt(lam)) < 1e-12                        # velocity scales with sqrt(length scale)
    nu = 1.0e-6
    Re_p, Re_m = Vp * Lp / nu, Vm * Lm / nu
    print(f"Froude number {Fr_p:.4f} in both; Reynolds {Re_p:.2e} prototype vs {Re_m:.2e} model (ratio {Re_p/Re_m:.1f} = lambda^1.5)")
    print(f"matching Re too would need a model fluid with nu = {nu/lam**1.5:.2e} m^2/s, which doesn't exist")
```

:::exercise Wave forces
In a 1:50 model of a harbour wall, waves with a 1.2 s period push on a wall section with a peak force of 12 N. What are the prototype wave period and force?
---solution---
1. Time scales with $\lambda^{1/2} = 7.071$: the prototype period is $1.2\cdot7.071 = 8.49$ s.
2. Force scales with $\lambda^3 = 125\,000$: $12\cdot125\,000 = 1.5$ MN. Seawater is about 2.5 % denser than the lab's fresh water, so the real force is about 1.54 MN.
:::
