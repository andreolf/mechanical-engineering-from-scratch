A pencil balanced on its tip is in equilibrium: forces and moments balance. So is a pencil lying on the table. Only one of them stays that way when someone breathes on it. Statics so far asked whether a position *is* in equilibrium; this last lesson asks whether it *stays* there. The answer comes from potential energy, and it's the doorway to buckling in Phase 06.

## Energy and equilibrium

For a conservative system (weights and springs), the total potential energy $V(\theta)$ depends on the position coordinate $\theta$. The virtual work principle (05.19) says equilibrium is where a small displacement does no work, which is where the energy is stationary:

$$
\frac{dV}{d\theta} = 0 .
$$

Its **stability** depends on the second derivative:

$$
\frac{d^2V}{d\theta^2} > 0 \;\text{stable (a valley)}, \qquad < 0 \;\text{unstable (a hilltop)}, \qquad = 0 \;\text{neutral (test higher derivatives)}.
$$

A small push into a valley raises the energy, so the system has to be pushed back. A ball on a landscape is the picture to keep in mind.

## An inverted bar with a spring

A rigid bar of length $L$ stands upright on a hinge with a rotational spring of stiffness $k$, carrying a load $P$ on top. Leaning it by $\theta$ stores spring energy and lowers the load:

$$
V(\theta) = \tfrac12 k\theta^2 + PL\cos\theta, \qquad V'(\theta) = k\theta - PL\sin\theta, \qquad V''(\theta) = k - PL\cos\theta .
$$

$\theta = 0$ is always an equilibrium, and it is stable if $V''(0) = k - PL > 0$, i.e. for

$$
P < P_{cr} = \frac{k}{L} .
$$

Above the **critical load**, upright is unstable and the bar leans over to a new stable equilibrium where $k\theta = PL\sin\theta$. That is buckling in its simplest form: a structure that was fine under a smaller load suddenly finds a lower-energy position sideways.

:::

:::example Below and above the critical load
$k = 20$ kN m/rad, $L = 2$ m, so $P_{cr} = 10$ kN.

1. $P = 8$ kN: $V''(0) = 20 - 16 = 4 > 0$. Upright is stable.
2. $P = 12$ kN: $V''(0) = 20 - 24 = -4 < 0$. Upright is unstable.
3. Solving $20\theta = 24\sin\theta$ by bisection gives $\theta = \pm58.83°$, where $V'' = 20 - 24\cos58.83° = 7.58 > 0$: stable leaning positions.
4. The code checks each second derivative against finite differences, and checks that a small push raises the energy exactly when $V'' > 0$.
:::

```python file=stability.py
"""Stability of equilibrium from potential energy: an inverted bar on a hinge with a rotational spring."""
import math
import numpy as np


def V(theta, k, P, L):
    """Spring energy k theta^2 / 2 plus the load's potential P L cos(theta) (it drops as the bar leans)."""
    return 0.5 * k * theta**2 + P * L * math.cos(theta)


def dV(theta, k, P, L):
    return k * theta - P * L * math.sin(theta)


def d2V(theta, k, P, L):
    return k - P * L * math.cos(theta)


def equilibria(k, P, L):
    """theta = 0 always; a leaning pair where k theta = P L sin(theta) when P L > k (bisection on (0, pi))."""
    eq = [0.0]
    if P * L > k:
        lo, hi = 1e-9, math.pi - 1e-9
        for _ in range(200):
            mid = 0.5 * (lo + hi)
            if dV(mid, k, P, L) < 0: lo = mid
            else: hi = mid
        eq += [lo, -lo]
    return eq


if __name__ == "__main__":
    k, L = 20.0, 2.0              # kN m/rad, m: critical load k / L = 10 kN
    print(f"critical load P_cr = k / L = {k / L:.1f} kN")
    for P in (8.0, 12.0):
        for th in equilibria(k, P, L):
            c = d2V(th, k, P, L)
            # second derivative by finite differences agrees with the formula
            h = 1e-4; c_num = (V(th + h, k, P, L) - 2 * V(th, k, P, L) + V(th - h, k, P, L)) / h**2
            assert abs(c - c_num) < 1e-4 and abs(dV(th, k, P, L)) < 1e-9
            # stable iff d2V > 0: a small push makes the energy rise
            pushed = V(th + 0.01, k, P, L) - V(th, k, P, L)
            assert (c > 0) == (pushed > 0)
            print(f"P = {P:4.1f} kN, theta = {math.degrees(th):8.4f} deg: V'' = {c:8.4f} -> {'stable' if c > 0 else 'unstable'}")
    # above P_cr the upright position is unstable and the bar settles at the leaning angle
    assert d2V(0, k, 12, L) < 0 and d2V(equilibria(k, 12, L)[1], k, 12, L) > 0
```

:::exercise A horizontal spring instead
Replace the rotational spring by a horizontal spring of stiffness $k = 5$ kN/m at the top of the 2 m bar, which stays horizontal as the bar leans. Then $V = \tfrac12k(L\sin\theta)^2 + PL\cos\theta$. Find $P_{cr}$, and classify the leaning equilibria for $P = 8$ kN.
---solution---
1. $V' = L\sin\theta\,(kL\cos\theta - P)$ and $V''(0) = kL^2 - PL$, so $P_{cr} = kL = 10$ kN.
2. For $P = 8$ kN, besides $\theta = 0$ (stable), there are equilibria where $\cos\theta = P/(kL) = 0.8$, i.e. $\theta = \pm36.87°$.
3. There $V'' = -kL^2\sin^2\theta = -5\cdot4\cdot0.36 = -7.2 < 0$: unstable. These hilltops are the edges of the valley. Push the bar past 36.87° and it falls over, even though the load is below the critical value. Structures like this are sensitive to imperfections, a theme Phase 06 picks up with real columns.
:::
