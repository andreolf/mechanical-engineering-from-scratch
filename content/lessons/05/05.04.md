Statics deals with bodies at rest, but you need to describe how a rigid body *can* move before you can stop it moving. Supports remove possible motions, mechanisms keep some of them, and the virtual work method in lesson 05.19 is built entirely on small rigid motions. This lesson gives the one formula that describes every planar rigid motion.

## Rigid motion

A body is **rigid** if the distance between any two of its points never changes. In the plane, its position has three numbers: two for a reference point and one for an angle. Those are its three **degrees of freedom**. Its velocity is also three numbers: the velocity $\mathbf v_A$ of one point $A$ and an angular velocity $\omega$ (counter-clockwise positive). Every other point follows from

$$
\mathbf v_B = \mathbf v_A + \boldsymbol\omega\times\mathbf r_{AB}, \qquad \boldsymbol\omega\times\mathbf r = \omega\,(-r_y,\; r_x).
$$

The relative velocity of $B$ with respect to $A$ is perpendicular to $AB$, with magnitude $\omega\,|AB|$. A rigid body can't stretch, so no relative velocity along $AB$ is possible.

## The instantaneous centre

If $\omega\neq0$, there is exactly one point (perhaps off the body) whose velocity is zero right now:

$$
\mathbf r_I = \mathbf r_A + \frac{\hat{\mathbf k}\times\mathbf v_A}{\omega}.
$$

At that instant the body is purely rotating about $I$: every point moves perpendicular to its line to $I$ with speed $|\omega|\,d_I$. To find $I$ by drawing, draw perpendiculars to the known velocity directions of two points; they cross at $I$. For a wheel rolling without slip, $I$ is the contact point, so the top of the wheel moves at twice the hub speed.

:::widget crank
A slider-crank (engine, pump, compressor). Turn the crank. The amber dashed lines are perpendicular to the two known velocities: the crank line OA extended and the vertical through the piston. Where they meet (often above the plot) is the rod's instantaneous centre, and the panel gives its coordinates.
:::

:::example Bicycle wheel and engine slider-crank
1. Wheel, $r = 0.35$ m, hub at 8 m/s: $\omega = -8/0.35 = -22.86$ rad/s. The top point moves at $8 + 22.86\cdot0.35 = 16$ m/s, the front point at $(8, -8)$ m/s, the contact point at zero.
2. Slider-crank, $r = 50$ mm, $l = 200$ mm, crank at 60° turning at 100 rad/s: crank pin $A = (0.025, 0.0433)$ m, $\mathbf v_A = (-4.330, 2.5)$ m/s. Piston $B = (0.2203, 0)$.
3. $B$ moves only horizontally, so $v_{B,y} = 0 = 2.5 + \omega_{rod}\,(0.2203 - 0.025)$, giving $\omega_{rod} = -12.80$ rad/s.
4. $v_B = -4.330 - (-12.80)(-0.0433) = -4.885$ m/s. The rod's instantaneous centre is at $(0.2203, 0.3815)$ m, and $|v_B| = 12.80\cdot0.3815$. The code also checks $v_B$ by differentiating the piston position numerically.
:::

```python file=rigid_kinematics.py
"""Planar rigid-body kinematics: v_B = v_A + omega x r_AB, and the instantaneous centre of zero velocity."""
import math
import numpy as np


def cross_z(w, r):
    """omega (about z) x r for a planar vector r."""
    return np.array([-w * r[1], w * r[0]])


def velocity(vA, w, A, P):
    return vA + cross_z(w, np.asarray(P) - np.asarray(A))


def instant_centre(vA, w, A):
    """Point with zero velocity: I = A + (k x vA) / w."""
    return np.asarray(A) + np.array([-vA[1], vA[0]]) / w


def slider_crank(r, l, theta, w_crank):
    """Crank OA (radius r) turning at w_crank, rod AB (length l), piston B sliding on the x axis."""
    A = r * np.array([math.cos(theta), math.sin(theta)])
    B = np.array([A[0] + math.sqrt(l**2 - A[1] ** 2), 0.0])
    vA = cross_z(w_crank, A)
    rAB = B - A
    w_rod = -vA[1] / rAB[0]                    # B moves horizontally, so its y-velocity is zero
    vB = velocity(vA, w_rod, A, B)
    return A, B, vA, w_rod, vB


if __name__ == "__main__":
    # a bicycle wheel rolling without slip: r = 0.35 m at 8 m/s; the contact point is the instantaneous centre
    R, V = 0.35, 8.0
    w = -V / R                                   # clockwise when rolling to the right
    C = np.array([0.0, R])
    for name, P in (("contact", (0, 0)), ("top", (0, 2 * R)), ("front", (R, R))):
        print(f"wheel {name:7s}: v = {np.round(velocity(np.array([V, 0]), w, C, P), 4)} m/s")
    assert np.allclose(velocity(np.array([V, 0]), w, C, (0, 0)), 0) and np.allclose(instant_centre(np.array([V, 0.0]), w, C), (0, 0))
    # slider-crank of a small engine: r = 50 mm, l = 200 mm, 100 rad/s, crank at 60 deg
    A, B, vA, w_rod, vB = slider_crank(0.05, 0.2, math.radians(60), 100.0)
    I = instant_centre(vA, w_rod, A)
    print(f"crank pin A = {np.round(A, 5)}, piston B = {np.round(B, 5)} m")
    print(f"rod angular velocity {w_rod:.4f} rad/s, piston velocity {vB[0]:.4f} m/s")
    print(f"rod instantaneous centre I = {np.round(I, 5)} m")
    assert np.allclose(velocity(vA, w_rod, A, I), 0, atol=1e-12)          # the instantaneous centre has zero velocity
    assert abs(abs(vB[0]) - abs(w_rod) * np.linalg.norm(B - I)) < 1e-12    # |v| = |omega| * distance from I
    # cross-check the piston speed by differentiating the position numerically
    h = 1e-7
    xB = lambda th: slider_crank(0.05, 0.2, th, 100.0)[1][0]
    assert abs((xB(math.radians(60) + h) - xB(math.radians(60) - h)) / (2 * h) * 100.0 - vB[0]) < 1e-5
```

:::exercise Crank at 90°
Same slider-crank, crank at 90°. Find the rod's angular velocity and the piston velocity. Where is the instantaneous centre?
---solution---
1. $A = (0, 0.05)$, $\mathbf v_A = 100\cdot(-0.05, 0) = (-5, 0)$ m/s, horizontal.
2. $B$ also moves horizontally, so both velocities are parallel. Their perpendiculars are parallel too and never meet: the instantaneous centre is at infinity.
3. The rod is translating at this instant: $\omega_{rod} = 0$ and $v_B = -5$ m/s, the same as the crank pin. That's close to the piston's peak speed.
:::
