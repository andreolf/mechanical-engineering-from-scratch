Almost every statics mistake happens before the first equation: a forgotten force, a reaction in the wrong direction, an internal force counted twice. The free-body diagram (FBD) is the tool that prevents this. It is the most important drawing in mechanical engineering, and the habit carries straight into dynamics, machine design and finite elements.

## The cut principle

**Cut** the body free from everything that touches it, then replace each contact with the force (or couple) it can transmit. What remains is the body alone, with

- **applied loads**: weights, people, wind, pressure;
- **reactions** at every cut support, with as many components as the support can carry (lesson 05.05);
- **nothing else**. Forces *inside* the body cancel in pairs (Newton's third law) and don't appear.

If you cut through a body instead of around it, the cut exposes internal forces, equal and opposite on the two sides. That's how you'll find forces in truss members (05.09) and bending moments in beams (05.13).

## Rules that prevent mistakes

1. Draw the body alone, then draw every force at its true point of application.
2. For unknown reactions, *assume* a direction and label it. A negative answer just means the arrow points the other way; never redraw it mid-solution.
3. Friction acts along the contact surface and opposes the motion that *would* happen. A smooth surface has a normal force only.
4. Use consistent units and a sign convention (counter-clockwise positive here).

In the plane, the FBD gives exactly three independent equations:

$$
\sum F_x = 0, \qquad \sum F_y = 0, \qquad \sum M_O = 0 .
$$

Once the forces balance, the moment sum is the same about every point, so you may pick $O$ wherever it kills the most unknowns.

:::example The ladder FBD
Ladder 5 m long at 65°, ladder weight 200 N at mid-length, person 800 N at 3.75 m up. The wall is smooth.

1. Unknowns: wall push $N_w$ (horizontal), floor normal $N_f$, floor friction $F_f$.
2. $\sum F_y = 0$: $N_f = 200 + 800 = 1000$ N.
3. $\sum M$ about the foot (kills $N_f$ and $F_f$): $N_w\cdot5\sin65° = 200\cdot2.5\cos65° + 800\cdot3.75\cos65°$, so $N_w = 326.42$ N.
4. $\sum F_x = 0$: $F_f = N_w = 326.42$ N, towards the wall. The floor needs $\mu \ge 326.42/1000 = 0.3264$.
5. The code checks the residual is zero about three different points, and shows the check catching an FBD with the friction left out.
:::

```python file=fbd.py
"""A free-body diagram as data: forces with points of application, plus couples, and an equilibrium check."""
import math
import numpy as np


class FBD:
    def __init__(self, name):
        self.name, self.forces, self.couples = name, [], []

    def force(self, label, at, F):
        self.forces.append((label, np.array(at, float), np.array(F, float)))

    def couple(self, label, M):
        self.couples.append((label, float(M)))

    def residual(self, about=(0.0, 0.0)):
        """(sum Fx, sum Fy, sum M about a point). All three are zero for a body in equilibrium."""
        o = np.array(about, float)
        Fx = sum(F[0] for _, _, F in self.forces)
        Fy = sum(F[1] for _, _, F in self.forces)
        M = sum((p - o)[0] * F[1] - (p - o)[1] * F[0] for _, p, F in self.forces) + sum(m for _, m in self.couples)
        return np.array([Fx, Fy, M])


def ladder(L, theta, W, P, s):
    """Ladder of length L at angle theta to the floor, smooth wall, rough floor.
    Ladder weight W at mid-length, person P at distance s up the ladder. Returns (wall N, floor N, floor friction)."""
    c, sn = math.cos(theta), math.sin(theta)
    Nf = W + P                                         # sum Fy = 0
    Nw = (W * L / 2 * c + P * s * c) / (L * sn)        # moments about the foot
    Ff = Nw                                            # sum Fx = 0: friction pushes towards the wall
    return Nw, Nf, Ff


if __name__ == "__main__":
    L, th, W, P, s = 5.0, math.radians(65), 200.0, 800.0, 3.75
    Nw, Nf, Ff = ladder(L, th, W, P, s)
    print(f"wall reaction {Nw:.2f} N, floor normal {Nf:.1f} N, floor friction {Ff:.2f} N, needs mu >= {Ff / Nf:.4f}")
    top = (L * math.cos(th), L * math.sin(th))
    b = FBD("ladder")
    b.force("weight", (top[0] / 2, top[1] / 2), (0, -W))
    b.force("person", (s / L * top[0], s / L * top[1]), (0, -P))
    b.force("wall", top, (-Nw, 0))
    b.force("floor normal", (0, 0), (0, Nf))
    b.force("floor friction", (0, 0), (Ff, 0))
    for about in ((0, 0), top, (10, -3)):                  # moments balance about ANY point once forces balance
        r = b.residual(about)
        print(f"residual about {np.round(about, 3)}: {np.round(r, 10)}")
        assert np.allclose(r, 0, atol=1e-9)
    # how high can the person climb before the ladder slips with mu = 0.25?
    mu = 0.25
    s_max = (mu * (W + P) * L * math.sin(th) - W * L / 2 * math.cos(th)) / (P * math.cos(th))
    print(f"with mu = {mu}: safe up to s = {s_max:.3f} m of {L} m")
    assert abs(ladder(L, th, W, P, s_max)[2] - mu * (W + P)) < 1e-9
    # a wrong FBD: forget the friction and the check catches it
    bad = FBD("ladder, no friction")
    for lab, p, F in b.forces[:-1]:
        bad.force(lab, p, F)
    assert not np.allclose(bad.residual(), 0)
    print("forgotten friction: residual", np.round(bad.residual(), 3))
```

:::exercise How high is safe?
Same ladder and person, but the floor only offers $\mu = 0.25$. How far up the ladder can the person go before it slips?
---solution---
1. Limit: $F_f = \mu N_f = 0.25\cdot1000 = 250$ N, so $N_w = 250$ N.
2. Moments about the foot: $250\cdot5\sin65° = 200\cdot2.5\cos65° + 800\,s\cos65°$.
3. $1132.9 = 211.3 + 338.1\,s$, so $s = 2.726$ m: a bit over halfway. Above that, the ladder slides out. Steeper ladders or a rubber foot help.
:::
