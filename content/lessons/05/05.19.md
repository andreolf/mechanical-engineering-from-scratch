A scissor lift has nine unknown pin forces. You could draw three free-body diagrams and solve nine equations, or you could use one equation that never mentions a pin force at all. The principle of virtual work replaces force balance with a work balance, and for mechanisms with one degree of freedom it is often the fastest route to the answer.

## The principle

Imagine giving a body in equilibrium a tiny, imaginary displacement that its supports allow: a **virtual displacement** $\delta\mathbf r$. Since the resultant force and moment are zero, the total work they do is zero too:

$$
\delta W = \sum_i \mathbf F_i\cdot\delta\mathbf r_i = 0 \quad\text{for every admissible virtual displacement.}
$$

The useful part: ideal constraints (smooth pins, rollers, rigid links) do no work in such a displacement. Their reactions drop out. For a mechanism with one degree of freedom $\theta$, write every loaded point's position as a function of $\theta$, differentiate, and the equilibrium condition becomes one scalar equation.

## The recipe

1. Choose one coordinate $\theta$ that describes the mechanism's position.
2. Write the position of each point where an active force acts: $y_W(\theta)$, $x_P(\theta)$, and so on.
3. Differentiate: $\delta y_W = y_W'(\theta)\,\delta\theta$.
4. Set $\sum F\,\delta(\text{position}) = 0$ and solve for the unknown force.

It's the same idea as mechanical advantage (05.12): output force times output motion equals input force times input motion.

:::widget scissor
A scissor lift with 1.2 m links and an actuator pushing the base ends together. Change the angle, the number of stages and the load. Virtual work gives the actuator force in one line: low and folded is the hard case.
:::

:::example A scissor lift
One stage, links of length $L$ at angle $\theta$, load $W = 4$ kN on the platform. The actuator spans the base ends, $x = L\cos\theta$; the platform is at $y = L\sin\theta$.

1. Virtual displacement: $\delta y = L\cos\theta\,\delta\theta$, $\delta x = -L\sin\theta\,\delta\theta$.
2. The load does work $-W\,\delta y$; the actuator, pushing the ends together, does $-P\,\delta x$.
3. $-WL\cos\theta\,\delta\theta + PL\sin\theta\,\delta\theta = 0$, so $P = W\cot\theta$. With $n$ stages, $y = nL\sin\theta$ and $P = nW\cot\theta$.
4. At 35°: $P = 4\cot35° = 5.713$ kN. At 20°: 10.99 kN. At 60°: 2.309 kN.
5. The code solves the full nine-unknown FBD system (two links, platform, every pin) and gets the same numbers.
:::

```python file=virtual_work.py
"""Virtual work on a scissor lift: P = n W cot(theta), checked against a full multi-body FBD solve."""
import math
import numpy as np


def actuator_force_vw(W, theta, n=1):
    """Platform height y = n L sin(theta); the actuator spans the base ends, x = L cos(theta).
    delta W = -W dy + P (-dx) = 0 with dy = n L cos dtheta and dx = -L sin dtheta  ->  P = n W cot(theta)."""
    return n * W / math.tan(theta)


def actuator_force_numeric(W, theta, L=1.0, n=1, h=1e-6):
    y = lambda t: n * L * math.sin(t)
    x = lambda t: L * math.cos(t)
    dy = (y(theta + h) - y(theta - h)) / (2 * h); dx = (x(theta + h) - x(theta - h)) / (2 * h)
    return -W * dy / dx                                      # work balance: P |dx| = W dy


def actuator_force_fbd(W, theta, L=1.0):
    """One-stage scissor: link A from base pin O(0,0) to top roller at (c, s); link B from base roller at (c, 0)
    to top pin (0, s); the links cross at the middle pin. Platform from (0, s) to (c, s) carries W at its middle.
    The actuator pushes the base roller end towards the pin with force P. Unknowns: Ox, Oy, By, P, Mx, My, Tx, Ty, Ry."""
    c, s = L * math.cos(theta), L * math.sin(theta)
    m = (c / 2, s / 2)
    cols, rhs = [], np.zeros(9)                              # 3 equations per body: A (0..2), B (3..5), platform (6..8)
    def col(*contribs):
        v = np.zeros(9)
        for body, (x, y), (fx, fy) in contribs:
            v[3 * body:3 * body + 3] += [fx, fy, x * fy - y * fx]
        cols.append(v)
    col((0, (0, 0), (1, 0))); col((0, (0, 0), (0, 1)))                       # base pin on link A
    col((1, (c, 0), (0, 1)))                                                 # base roller on link B
    col((1, (c, 0), (-1, 0)))                                                # actuator P on link B, pointing inward
    col((0, m, (1, 0)), (1, m, (-1, 0))); col((0, m, (0, 1)), (1, m, (0, -1)))   # middle pin
    col((1, (0, s), (1, 0)), (2, (0, s), (-1, 0))); col((1, (0, s), (0, 1)), (2, (0, s), (0, -1)))  # top pin
    col((0, (c, s), (0, 1)), (2, (c, s), (0, -1)))                           # top roller (vertical contact)
    rhs[6:9] = -np.array([0, -W, (c / 2) * (-W)])                            # the load on the platform
    x = np.linalg.solve(np.array(cols).T, rhs)
    return x[3]


if __name__ == "__main__":
    W = 4.0                       # kN on the platform
    for deg in (20, 35, 60):
        th = math.radians(deg)
        Pv, Pn, Pf = actuator_force_vw(W, th), actuator_force_numeric(W, th), actuator_force_fbd(W, th)
        print(f"theta = {deg} deg: virtual work {Pv:.4f} kN, numerical derivative {Pn:.4f}, nine-unknown FBD {Pf:.4f}")
        assert abs(Pv - Pf) < 1e-9 and abs(Pv - Pn) < 1e-6
    print(f"a 3-stage lift at 20 deg needs {actuator_force_vw(W, math.radians(20), 3):.3f} kN: low and folded is the hard case")
```

:::exercise A three-stage lift
A three-stage scissor lift carries 4 kN. What actuator force does it need at 20°, and at what angle does the force drop to 4 kN?
---solution---
1. $P = 3\cdot4\cot20° = 12\cdot2.747 = 32.97$ kN.
2. $P = 4$ kN when $\cot\theta = 4/12 = 1/3$, so $\theta = \arctan3 = 71.57°$.
3. This is why real lifts mount the actuator diagonally rather than horizontally: it improves the leverage when folded.
:::
