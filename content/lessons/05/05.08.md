Some structures can be solved with statics alone; others need you to know how they deform. Telling them apart before you start saves hours, and it matters in design too. A determinate bridge doesn't care if a support settles or the sun heats it. An indeterminate one builds up internal force when that happens, but it also has a spare load path if a member fails.

## Equations against unknowns

Split a structure into $b$ rigid bodies joined by internal hinges. Each body gives 3 equations, so there are $3b$ equations. The unknowns are the $r$ support reactions plus 2 forces at every internal hinge. Write all the equations as a matrix system $A\mathbf x = \mathbf f$, where each column of $A$ is one unknown's contribution to the forces and moments on each body. Then

$$
\text{free motions} = 3b - \operatorname{rank} A, \qquad \text{degree of indeterminacy} = n_{\text{unknowns}} - \operatorname{rank} A .
$$

- Both zero: **statically determinate**. One unique solution for any load.
- Free motions $> 0$: a **mechanism**. Some loads can't be balanced at all.
- Indeterminacy $> 0$: **statically indeterminate**. Equilibrium allows infinitely many solutions; the deformation picks one.

A structure can be both a mechanism and indeterminate at once: rigid in one direction with spare supports, free in another. Counting alone ($n$ against $3b$) can't see that. The rank can.

## Classic cases

| Structure | Bodies | Unknowns | Verdict |
|---|---|---|---|
| Pin + roller | 1 | 3 | determinate |
| Clamp + roller (propped cantilever) | 1 | 4 | 1× indeterminate |
| Clamp + clamp | 1 | 6 | 3× indeterminate |
| Clamp, hinge, roller (Gerber beam) | 2 | 6 | determinate |
| Three-hinged arch | 2 | 6 | determinate |
| Pin, hinge, roller | 2 | 5 | mechanism |

Adding a hinge to a beam releases one internal moment, so it takes away one degree of indeterminacy. Heinrich Gerber used exactly that in the 1860s to make long continuous bridges determinate: a hinge per extra support. Many Swiss road bridges are continuous girders made the other way, indeterminate on purpose for stiffness and redundancy.

:::example Classifying by rank
1. Propped cantilever: unknowns 4, equations 3, rank 3. Indeterminacy $4 - 3 = 1$.
2. Gerber beam: clamp (3) + hinge (2) + roller (1) = 6 unknowns, two bodies give 6 equations, rank 6: determinate.
3. Pin at the left, roller at the right but rolling horizontally, in line with the pin: rank 2. One free motion (rotation about the pin) and one redundant reaction (two horizontal reactions on one line).
:::

```python file=determinacy.py
"""Static determinacy by the rank of the equilibrium matrix, for one or several pinned rigid bodies."""
import numpy as np


def classify(n_bodies, unknowns):
    """unknowns: list of unit reactions; each is a list of (body, (x, y), (Fx, Fy), Mz) contributions.
    An internal hinge force appears on two bodies with opposite signs. Returns (rank, degree, verdict)."""
    A = np.zeros((3 * n_bodies, len(unknowns)))
    for j, contribs in enumerate(unknowns):
        for body, (x, y), (fx, fy), mz in contribs:
            A[3 * body:3 * body + 3, j] += [fx, fy, x * fy - y * fx + mz]
    rank = np.linalg.matrix_rank(A)
    mech, indet = 3 * n_bodies - rank, len(unknowns) - rank
    if mech > 0:
        verdict = f"mechanism ({mech} free motion{'s' if mech > 1 else ''})" + (f", also {indet}x indeterminate" if indet else "")
    elif indet > 0:
        verdict = f"{indet}x statically indeterminate"
    else:
        verdict = "statically determinate"
    return rank, indet, mech, verdict


def pin(body, at):          # two force components at a ground pin
    return [[(body, at, (1, 0), 0)], [(body, at, (0, 1), 0)]]


def roller(body, at, d=(0, 1)):
    return [[(body, at, d, 0)]]


def clamp(body, at):
    return pin(body, at) + [[(body, at, (0, 0), 1)]]


def hinge(b1, b2, at):      # internal pin: equal and opposite forces on the two bodies
    return [[(b1, at, (1, 0), 0), (b2, at, (-1, 0), 0)], [(b1, at, (0, 1), 0), (b2, at, (0, -1), 0)]]


if __name__ == "__main__":
    cases = {
        "simply supported": (1, pin(0, (0, 0)) + roller(0, (6, 0))),
        "propped cantilever": (1, clamp(0, (0, 0)) + roller(0, (6, 0))),
        "fixed-fixed": (1, clamp(0, (0, 0)) + clamp(0, (6, 0))),
        "two rollers": (1, roller(0, (0, 0)) + roller(0, (6, 0))),
        "pin + horizontal roller in line": (1, pin(0, (0, 0)) + roller(0, (6, 0), (1, 0))),
        "Gerber beam (clamp, hinge, roller)": (2, clamp(0, (0, 0)) + hinge(0, 1, (4, 0)) + roller(1, (10, 0))),
        "three-hinged arch": (2, pin(0, (0, 0)) + hinge(0, 1, (5, 4)) + pin(1, (10, 0))),
        "pin, hinge, roller (two bodies)": (2, pin(0, (0, 0)) + hinge(0, 1, (4, 0)) + roller(1, (10, 0))),
    }
    expect = {"simply supported": (0, 0), "propped cantilever": (1, 0), "fixed-fixed": (3, 0), "two rollers": (0, 1),
              "pin + horizontal roller in line": (1, 1), "Gerber beam (clamp, hinge, roller)": (0, 0),
              "three-hinged arch": (0, 0), "pin, hinge, roller (two bodies)": (0, 1)}
    for name, (nb, unk) in cases.items():
        rank, indet, mech, verdict = classify(nb, unk)
        print(f"{name:36s} unknowns {len(unk):2d}, equations {3 * nb}, rank {rank}: {verdict}")
        assert (indet, mech) == expect[name], name
```

:::exercise A three-span bridge
A continuous girder has a pin at the left end and rollers at three more piers (4 supports in total, no hinges). How indeterminate is it? How many hinges, and where, would make it determinate without making it a mechanism?
---solution---
1. Unknowns $2 + 1 + 1 + 1 = 5$, equations 3, rank 3: 2× indeterminate.
2. Each hinge adds a body (3 equations) and 2 unknowns, so it removes one degree. Two hinges make it determinate.
3. Put them in different spans, never two in one span. A sensible choice is one hinge in each outer span, near the inner piers, so the middle span becomes a beam with two cantilevers that carry suspended end pieces. Two hinges in one span would leave that piece with no support of its own: a mechanism even though the count is right.
:::
