Cable cars, power lines, suspension bridges and washing lines all hang in a curve set by their own weight. Cables can only pull, so they find the one shape in which pure tension balances the load. For self-weight that shape is the catenary, and finding it is a nice combination of statics, calculus and root finding.

## The equation of a hanging cable

Take a cable with weight $w$ per unit length. Cut out a piece from the lowest point to $x$. The horizontal tension $H$ is the same everywhere (no horizontal loads), and the vertical component at $x$ must carry the weight of the piece, $w\,s$:

$$
\frac{dy}{dx} = \frac{w\,s}{H}.
$$

Differentiating, with $ds = \sqrt{1 + y'^2}\,dx$, and solving gives the **catenary**

$$
y = a\cosh\frac{x}{a}, \qquad a = \frac{H}{w}.
$$

The tension at any point is $T = w\,y$: it grows by $w$ times the height you climb.

## Span, length, sag

For supports at equal height a span $S$ apart, the cable length is $L = 2a\sinh(S/2a)$. Given $S$ and $L$, that equation has no closed-form solution for $a$, but the left side falls steadily as $a$ grows, so bisection finds it reliably. Then the sag is $d = a(\cosh(S/2a) - 1)$.

When the sag is small, the catenary is very close to a **parabola** (the exact shape for a load spread evenly along the span, as on a suspension bridge deck):

$$
H \approx \frac{wS^2}{8d}, \qquad L \approx S + \frac{8d^2}{3S}.
$$

Note how tension grows as sag falls. A perfectly straight cable would need infinite tension, which is why power lines always sag.

:::example A cable-car track rope
Span 400 m, rope 404 m, 30 kg/m ($w = 0.2943$ kN/m).

1. Bisection on $2a\sinh(200/a) = 404$: $a = 817.7$ m.
2. Sag $d = 817.7(\cosh(200/817.7) - 1) = 24.58$ m.
3. $H = wa = 240.65$ kN; at the towers $T = H + wd = 247.89$ kN.
4. The parabola gives a sag of 24.50 m and $H = 240.29$ kN, within 0.4 %.
5. A slack 14 m chain on a 10 m span sags 4.38 m, but the parabola says 3.87 m. The code also checks that the arc-length integral returns the specified length.
:::

```python file=catenary.py
"""Catenary y = a cosh(x/a): find a for a given span and cable length, then sag and tensions."""
import math
import numpy as np


def catenary_a(S, L, tol=1e-12):
    """Solve 2 a sinh(S / (2 a)) = L for a by bisection (the left side falls monotonically from inf to S)."""
    if L <= S:
        raise ValueError("cable must be longer than the span")
    f = lambda a: 2 * a * math.sinh(S / (2 * a)) - L
    lo, hi = S / 1000, S * 1000.0
    while f(lo) > 1e300 or math.isinf(f(lo)):
        lo *= 2
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        if f(mid) > 0: lo = mid
        else: hi = mid
        if hi - lo < tol * hi: break
    return 0.5 * (lo + hi)


def arc_length(a, S, n=20001):
    """Integrate sqrt(1 + y'^2) with y' = sinh(x / a) by Simpson's rule."""
    x = np.linspace(-S / 2, S / 2, n); g = np.sqrt(1 + np.sinh(x / a) ** 2); h = S / (n - 1)
    w = np.ones(n); w[1:-1:2] = 4; w[2:-1:2] = 2
    return h / 3 * (w @ g)


if __name__ == "__main__":
    # an alpine cable-car track rope between two towers at the same height: span 400 m, rope 404 m, 30 kg/m
    S, L, w = 400.0, 404.0, 30 * 9.81 / 1000        # w in kN/m
    a = catenary_a(S, L)
    sag = a * (math.cosh(S / (2 * a)) - 1)
    H = w * a; Tmax = w * a * math.cosh(S / (2 * a))
    print(f"a = {a:.3f} m, sag = {sag:.3f} m, horizontal tension H = {H:.2f} kN, tension at the towers {Tmax:.2f} kN")
    assert abs(arc_length(a, S) - L) < 1e-6                     # the length integral returns the specified length
    assert abs(Tmax - (H + w * sag)) < 1e-9                     # T = w y: tension grows by w times the height climbed
    # parabolic approximation: L ~ S + 8 d^2 / (3 S)  ->  d = sqrt(3 S (L - S) / 8)
    d_par = math.sqrt(3 * S * (L - S) / 8); H_par = w * S**2 / (8 * d_par)
    print(f"parabola: sag {d_par:.3f} m ({(d_par / sag - 1) * 100:.2f} % off), H = {H_par:.2f} kN")
    assert abs(d_par / sag - 1) < 0.01
    # a slack chain: span 10 m, length 14 m: the parabola is now poor
    a2 = catenary_a(10, 14); sag2 = a2 * (math.cosh(5 / a2) - 1); d2 = math.sqrt(3 * 10 * 4 / 8)
    print(f"slack chain: catenary sag {sag2:.3f} m, parabola {d2:.3f} m")
    assert abs(arc_length(a2, 10) - 14) < 1e-6 and abs(d2 / sag2 - 1) > 0.05
```

:::exercise A power line
A power line weighs 15 N/m and spans 250 m between towers of equal height. The design limit for horizontal tension is 20 kN. Using the parabolic approximation, what is the minimum sag, and how much longer than the span is the conductor?
---solution---
1. $d = wS^2/(8H) = 15\cdot250^2/(8\cdot20000) = 5.86$ m.
2. $L - S \approx 8d^2/(3S) = 8\cdot5.86^2/750 = 0.366$ m. Only 37 cm of extra conductor makes almost 6 m of sag.
3. On a hot day the conductor expands, $L$ grows, and the sag increases noticeably. That's why clearance is checked at maximum temperature.
:::
