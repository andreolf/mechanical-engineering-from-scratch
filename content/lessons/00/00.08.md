Real data arrives late, irregular and noisy. A river gauge logs every ten minutes, except when the modem drops out; a thermocouple reports volts, not degrees. This lesson turns raw readings into a clean, evenly spaced series you can trust: convert units, interpolate onto a regular grid, and avoid the sampling mistake that makes fast signals look slow.

## From signal to physical value

Industrial sensors usually send a 4 to 20 mA current loop. Zero current means a broken wire, which is why the scale starts at 4. A linear sensor maps current $I$ to a quantity $y$ with

$$
y = y_\text{min} + \frac{I - 4\ \mathrm{mA}}{16\ \mathrm{mA}}\,(y_\text{max} - y_\text{min}) .
$$

Calibrating a sensor means finding that straight line from two or more known points, then checking the residuals.

## Sampling and aliasing

Sampling at rate $f_s$ can only represent frequencies up to the **Nyquist frequency** $f_s/2$. A sinusoid at frequency $f$ above that doesn't disappear; it shows up at the alias

$$
f_\text{alias} = \left| f - k f_s \right|, \quad k = \operatorname{round}(f / f_s) .
$$

A 0.9 Hz vibration sampled once per second looks like a slow 0.1 Hz drift. No amount of processing afterwards can tell the two apart, which is why data loggers put an analogue low-pass filter before the converter.

## Resampling with linear interpolation

To put irregular samples $(t_i, y_i)$ onto an hourly grid, find for each grid time $t$ the two neighbours $t_i \le t \le t_{i+1}$ and interpolate:

$$
y(t) = y_i + \frac{t - t_i}{t_{i+1} - t_i}\,(y_{i+1} - y_i) .
$$

Linear interpolation never overshoots the data and preserves the mean of a smooth signal well. It can't recover anything faster than the original sampling, and it quietly bridges gaps, so the code also reports the longest gap it bridged.

:::example A level gauge on the Limmat
A pressure-based level sensor on the Limmat in Zurich spans 0 to 5 m over 4 to 20 mA and samples every 10 minutes.

1. A reading of $11.2\ \mathrm{mA}$ means $y = 0 + \dfrac{11.2 - 4}{16} \times 5 = 2.25\ \mathrm{m}$.
2. Nyquist limit: $f_s = 1/600\ \mathrm{Hz}$, so $f_s/2 = 1/1200\ \mathrm{Hz}$: anything faster than one cycle per 20 minutes is unresolved. Surface waves are, river level changes from rain and lake regulation are not.
3. Two neighbouring samples at 10:00 ($2.20\ \mathrm{m}$) and 10:10 ($2.26\ \mathrm{m}$) give $2.236\ \mathrm{m}$ at 10:06, by $2.20 + 0.6 \times 0.06$.
:::

```python file=resample.py
"""Parse irregular sensor CSV, convert 4-20 mA to metres, resample to hourly by linear interpolation."""
import csv
import io
import math
import random
from bisect import bisect_right


def ma_to_level(ma, lo=0.0, hi=5.0):
    if not 3.8 <= ma <= 20.5:
        raise ValueError(f"{ma} mA is outside the loop range: broken wire or sensor fault")
    return lo + (ma - 4.0) / 16.0 * (hi - lo)


def make_sample_csv(seed=3):
    """Three days of 10-minute samples with jitter and a 2-hour modem dropout."""
    rng = random.Random(seed)
    out = io.StringIO()
    w = csv.writer(out)
    w.writerow(["t_seconds", "current_mA"])
    t = 0.0
    while t < 3 * 86400:
        if not (30 * 3600 <= t < 32 * 3600):     # dropout
            level = 2.2 + 0.3 * math.sin(2 * math.pi * t / 86400) + rng.gauss(0, 0.005)
            w.writerow([f"{t:.0f}", f"{4 + 16 * level / 5:.4f}"])
        t += 600 + rng.uniform(-30, 30)
    return out.getvalue()


def read_series(text):
    rows = list(csv.DictReader(io.StringIO(text)))
    t = [float(r["t_seconds"]) for r in rows]
    y = [ma_to_level(float(r["current_mA"])) for r in rows]
    return t, y


def interp(t, ts, ys):
    i = bisect_right(ts, t) - 1
    i = max(0, min(i, len(ts) - 2))
    f = (t - ts[i]) / (ts[i + 1] - ts[i])
    return ys[i] + f * (ys[i + 1] - ys[i])


def resample(ts, ys, step=3600):
    grid = [ts[0] + k * step for k in range(int((ts[-1] - ts[0]) // step) + 1)]
    gap = max(b - a for a, b in zip(ts, ts[1:]))
    return grid, [interp(t, ts, ys) for t in grid], gap


if __name__ == "__main__":
    assert abs(ma_to_level(11.2) - 2.25) < 1e-12
    ts, ys = read_series(make_sample_csv())
    grid, hourly, gap = resample(ts, ys)
    assert all(math.isfinite(v) for v in hourly)                 # no NaNs
    raw_mean = sum((y0 + y1) / 2 * (t1 - t0) for t0, t1, y0, y1 in zip(ts, ts[1:], ys, ys[1:])) / (ts[-1] - ts[0])
    new_mean = sum(hourly) / len(hourly)
    print(f"{len(ts)} raw samples -> {len(hourly)} hourly, longest gap {gap / 3600:.1f} h")
    print(f"mean raw {raw_mean:.4f} m, hourly {new_mean:.4f} m")
    assert abs(new_mean / raw_mean - 1) < 0.01                   # mean kept within 1%
    assert gap > 7000                                            # the dropout is reported
    f, fs = 0.9, 1.0
    assert abs(abs(f - round(f / fs) * fs) - 0.1) < 1e-12        # alias of 0.9 Hz at 1 Hz
```

Notice that the raw mean is computed as a time-weighted average (trapezoids between samples), not a plain average of readings. With irregular sampling a plain average over-weights the periods when the logger happened to sample more often.

:::exercise Choose a sample rate
A pump's shaft runs at $2950\ \mathrm{rpm}$ and you want to see vibration up to the third harmonic of shaft speed. What is the minimum sampling rate, and what rate would you actually choose?
---solution---
1. Shaft frequency: $2950/60 = 49.2\ \mathrm{Hz}$.
2. Third harmonic: $3 \times 49.2 = 147.5\ \mathrm{Hz}$.
3. Nyquist requires $f_s > 2 \times 147.5 = 295\ \mathrm{Hz}$.
4. Real anti-alias filters roll off gradually, so choose 2.5 to 4 times the highest frequency: a standard $1\ \mathrm{kHz}$ rate is a sensible choice.
:::
