Every mechanics problem in this course starts the same way: cut the object you care about free from everything it touches, replace each contact with the force it transmits, and only then write equations. Skip the drawing and you will forget a force, double-count one, or get a sign wrong. This lesson makes that habit concrete and checkable in code.

## Newton's laws as balance statements

For a body at rest, or moving at constant velocity, Newton's first law says the forces and moments on it balance. In the plane that's three scalar equations:

$$
\sum F_x = 0, \qquad \sum F_y = 0, \qquad \sum M_O = 0 .
$$

The moment about a point $O$ of a force $\mathbf{F}$ applied at $\mathbf{r}$ (measured from $O$) is the 2D cross product

$$
M_O = r_x F_y - r_y F_x .
$$

Three equations means you can find at most three unknown forces on one rigid body in the plane. If a diagram has more unknowns, the body is statically indeterminate and you'll need deformation (Phase 06) to solve it.

## The four-step recipe

1. **Isolate**: draw only the body, with its outline cut free.
2. **Replace**: at every cut, draw the force the removed part exerted. A smooth surface pushes perpendicular to itself; a rough one adds a friction force along it; a pin can push in any direction (two unknowns); a fixed clamp adds a moment too.
3. **Load**: add gravity at the centre of mass and any applied loads.
4. **Balance**: write the three equations, choosing the moment point where unknowns meet so they drop out.

:::example Will the ladder slip?
A uniform ladder of length $L = 4\ \mathrm{m}$ and mass $15\ \mathrm{kg}$ leans against a smooth wall at $\theta = 60^\circ$ to the floor. What wall reaction and floor friction keep it in place, and what friction coefficient is needed?

1. Weight: $W = 15 \times 9.81 = 147.15\ \mathrm{N}$, acting at $L/2$.
2. Vertical balance: $N_f = W = 147.15\ \mathrm{N}$.
3. Moments about the foot, where $N_f$ and $F$ act, so they drop out: $N_w L\sin\theta - W\frac{L}{2}\cos\theta = 0$, so $N_w = \dfrac{W}{2\tan\theta} = \dfrac{147.15}{2\times1.732} = 42.5\ \mathrm{N}$.
4. Horizontal balance: $F = N_w = 42.5\ \mathrm{N}$.
5. Friction needed: $\mu \ge F/N_f = \dfrac{1}{2\tan\theta} = 0.289$.

The ladder's length and mass cancel out of the friction requirement. Only the angle matters, which is why ladder labels specify an angle and not a weight limit for slipping.
:::

## Checking a diagram in code

A free-body diagram is just a list of forces with application points. The code below stores it that way, solves for the unknown magnitudes with a $3\times3$ linear system, and then checks that every equation balances to $10^{-9}$. If you forget a force, the check fails.

```python file=fbd.py
"""Free-body diagrams as data: solve for unknown reactions and check equilibrium."""
import math


def solve3(A, b):
    """Gaussian elimination with partial pivoting for a 3x3 system."""
    M = [row[:] + [bi] for row, bi in zip(A, b)]
    n = 3
    for c in range(n):
        p = max(range(c, n), key=lambda r: abs(M[r][c]))
        if abs(M[p][c]) < 1e-14:
            raise ValueError("singular: the diagram is a mechanism or indeterminate")
        M[c], M[p] = M[p], M[c]
        for r in range(c + 1, n):
            f = M[r][c] / M[c][c]
            M[r] = [a - f * b for a, b in zip(M[r], M[c])]
    x = [0.0] * n
    for r in reversed(range(n)):
        x[r] = (M[r][n] - sum(M[r][k] * x[k] for k in range(r + 1, n))) / M[r][r]
    return x


def resultant(forces):
    """forces: list of (point (x, y), force (Fx, Fy)). Returns (sum Fx, sum Fy, moment about origin)."""
    fx = sum(f[0] for _, f in forces)
    fy = sum(f[1] for _, f in forces)
    m = sum(p[0] * f[1] - p[1] * f[0] for p, f in forces)
    return fx, fy, m


def ladder(L=4.0, mass=15.0, theta_deg=60.0, person=None):
    th = math.radians(theta_deg)
    foot, top = (0.0, 0.0), (L * math.cos(th), L * math.sin(th))
    known = [((L / 2 * math.cos(th), L / 2 * math.sin(th)), (0.0, -mass * 9.81))]
    if person:
        m, d = person
        known.append(((d * math.cos(th), d * math.sin(th)), (0.0, -m * 9.81)))
    # unknown unit forces: N_w at top pointing -x, N_f at foot +y, F at foot +x
    unknown = [(top, (-1.0, 0.0)), (foot, (0.0, 1.0)), (foot, (1.0, 0.0))]
    A = [[0.0] * 3 for _ in range(3)]
    for j, (p, f) in enumerate(unknown):
        A[0][j], A[1][j], A[2][j] = resultant([(p, f)])
    rhs = [-v for v in resultant(known)]
    Nw, Nf, F = solve3(A, rhs)
    all_forces = known + [(p, (f[0] * s, f[1] * s)) for (p, f), s in zip(unknown, (Nw, Nf, F))]
    assert all(abs(v) < 1e-9 for v in resultant(all_forces)), "diagram does not balance"
    return Nw, Nf, F


if __name__ == "__main__":
    Nw, Nf, F = ladder()
    print(f"N_w = {Nw:.2f} N, N_f = {Nf:.2f} N, F = {F:.2f} N, mu_min = {F / Nf:.4f}")
    assert abs(Nw - 42.4785) < 1e-3 and abs(F / Nf - 1 / (2 * math.sqrt(3))) < 1e-12
    Nw2, Nf2, F2 = ladder(person=(80.0, 3.0))
    assert abs(F2 / Nf2 - 0.41022) < 1e-4
    print(f"with an 80 kg person 3 m up: mu_min = {F2 / Nf2:.3f}")
```

:::exercise Someone climbs the ladder
An $80\ \mathrm{kg}$ person stands $3\ \mathrm{m}$ along the same ladder (measured from the foot). What friction coefficient is now needed?
---solution---
1. Weights: ladder $W_l = 147.15\ \mathrm{N}$ at $2\ \mathrm{m}$, person $W_p = 80 \times 9.81 = 784.8\ \mathrm{N}$ at $3\ \mathrm{m}$.
2. Moments about the foot: $N_w L\sin\theta = (W_l \cdot 2 + W_p \cdot 3)\cos\theta$.
3. $N_w = \dfrac{(294.3 + 2354.4) \times 0.5}{4 \times 0.866} = 382.3\ \mathrm{N}$.
4. Vertical: $N_f = 147.15 + 784.8 = 931.95\ \mathrm{N}$; horizontal: $F = N_w = 382.3\ \mathrm{N}$.
5. $\mu \ge 382.3 / 931.95 = 0.410$. The higher the climber, the more friction is needed, which is why ladders slip when someone is near the top.
:::
