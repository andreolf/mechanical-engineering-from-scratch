Forces, velocities and displacements are vectors, and an engineering model is usually thousands of them at once. In this lesson you treat a vector as a list of numbers in $\mathbb{R}^n$, learn which operations are element-wise and which aren't, and replace slow Python loops with NumPy array operations that give the same answer much faster.

## Vectors as arrays

A force in the plane is a pair $\mathbf{F} = (F_x, F_y)$. Adding forces adds components; scaling a force scales each component:

$$
\mathbf{F}_1 + \mathbf{F}_2 = (F_{1x} + F_{2x},\ F_{1y} + F_{2y}), \qquad c\,\mathbf{F} = (cF_x,\ cF_y).
$$

Those two operations, with the usual rules, are what make $\mathbb{R}^n$ a **vector space**. Two more operations matter constantly:

$$
\mathbf{a}\cdot\mathbf{b} = \sum_i a_i b_i, \qquad \lVert \mathbf{a} \rVert = \sqrt{\mathbf{a}\cdot\mathbf{a}} .
$$

The dot product of force and displacement is work. The norm is a magnitude.

## Element-wise is not matrix multiplication

In NumPy, `a * b` multiplies element by element. Matrix multiplication is `a @ b`. For two vectors, `(a * b).sum()` equals `a @ b`, but for matrices the two differ completely. Mixing them up is the most common array bug in engineering code, and it's silent: both run, one is wrong.

## Broadcasting

When two arrays have different shapes, NumPy stretches dimensions of length 1 to match. Shapes are compared from the right; each pair must be equal or contain a 1.

$$
(3, 1) \text{ with } (1, 4) \;\longrightarrow\; (3, 4)
$$

Broadcasting is how you compute all pairwise differences between $N$ points without a loop: `d = p[:, None, :] - p[None, :, :]` has shape $(N, N, 2)$.

:::example Resultant of three forces on a bracket
A bracket carries $F_1 = 400\ \mathrm{N}$ at $30^\circ$, $F_2 = 250\ \mathrm{N}$ at $120^\circ$ and $F_3 = 300\ \mathrm{N}$ at $250^\circ$, angles measured from the $x$ axis. Find the resultant.

1. Components, $F(\cos\theta, \sin\theta)$: $\mathbf{F}_1 = (346.4,\ 200.0)$, $\mathbf{F}_2 = (-125.0,\ 216.5)$, $\mathbf{F}_3 = (-102.6,\ -281.9)$ newtons.
2. Sum: $\mathbf{R} = (118.8,\ 134.6)\ \mathrm{N}$.
3. Magnitude: $\lVert\mathbf{R}\rVert = \sqrt{118.8^2 + 134.6^2} = 179.5\ \mathrm{N}$.
4. Direction: $\operatorname{atan2}(134.6, 118.8) = 48.6^\circ$.

In NumPy that's three lines: build an array of shape $(3, 2)$, sum along axis 0, take the norm.
:::

## Loops versus arrays

The code computes a spring force pulling each of $10^5$ particles toward the origin, plus gravity, once with a Python loop and once with arrays. It asserts that both agree to $10^{-12}$ and measures the speed-up.

```python file=vectorise.py
"""Loop versus vectorised force evaluation, plus broadcasting for pairwise distances."""
import time
import numpy as np

K = 50.0                      # spring stiffness, N/m
G = np.array([0.0, -9.81])    # gravity, m/s^2


def forces_loop(pos, mass):
    out = []
    for (x, y), m in zip(pos.tolist(), mass.tolist()):
        out.append((-K * x + m * G[0], -K * y + m * G[1]))
    return np.array(out)


def forces_vec(pos, mass):
    return -K * pos + mass[:, None] * G      # (N,2) + (N,1)*(2,) -> (N,2)


def pairwise_distances(p):
    d = p[:, None, :] - p[None, :, :]        # (N,1,2) - (1,N,2) -> (N,N,2)
    return np.sqrt((d ** 2).sum(axis=-1))


if __name__ == "__main__":
    rng = np.random.default_rng(0)
    pos = rng.normal(size=(100_000, 2))
    mass = rng.uniform(0.1, 2.0, size=100_000)

    t0 = time.perf_counter(); a = forces_loop(pos, mass); t1 = time.perf_counter()
    b = forces_vec(pos, mass); t2 = time.perf_counter()
    assert np.max(np.abs(a - b)) < 1e-12
    speedup = (t1 - t0) / max(t2 - t1, 1e-9)
    print(f"loop {t1 - t0:.3f} s, vectorised {t2 - t1:.4f} s, {speedup:.0f}x faster")
    assert speedup > 5   # usually 20x or more; kept loose so slow machines still pass

    # resultant of the worked example
    ang = np.radians([30, 120, 250])
    F = np.array([400, 250, 300])[:, None] * np.c_[np.cos(ang), np.sin(ang)]
    R = F.sum(axis=0)
    assert abs(np.linalg.norm(R) - 179.53) < 0.01
    assert abs(np.degrees(np.arctan2(R[1], R[0])) - 48.57) < 0.01

    # broadcasting: distances between the corners of a 3-4-5 triangle
    D = pairwise_distances(np.array([[0.0, 0.0], [3.0, 0.0], [3.0, 4.0]]))
    assert np.allclose(D, D.T) and abs(D[0, 2] - 5.0) < 1e-12
    print("resultant", R.round(1), "distances ok")
```

On a laptop the vectorised version is typically 20 to 100 times faster (26 times on the machine that built this page). The physics didn't change; the work just moved from the Python interpreter into compiled loops over contiguous memory.

:::exercise Work done by a cable
A cable pulls a cart with force $\mathbf{F} = (120,\ 50,\ 0)\ \mathrm{N}$ while it moves by $\mathbf{d} = (3,\ -2,\ 0.5)\ \mathrm{m}$. How much work does the cable do? Write it as a single NumPy expression.
---solution---
1. Work is the dot product: $W = \mathbf{F}\cdot\mathbf{d} = 120\times3 + 50\times(-2) + 0\times0.5$.
2. $W = 360 - 100 + 0 = 260\ \mathrm{J}$.
3. In NumPy: `np.array([120, 50, 0]) @ np.array([3, -2, 0.5])` returns `260.0`.
4. Note `F * d` would return the array `[360, -100, 0]`, which is not work until you sum it.
:::
