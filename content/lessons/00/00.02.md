Most wrong answers in engineering are not bad math; they are numbers in the wrong unit. In this lesson you treat a unit as part of the number, write a `Quantity` class that refuses to add metres to seconds, and see how one missing conversion destroyed a spacecraft.

## A unit is a vector of exponents

Every SI quantity can be written as a number times a product of the seven base units: metre, kilogram, second, ampere, kelvin, mole and candela. A newton is $\mathrm{kg\,m\,s^{-2}}$; a pascal is $\mathrm{kg\,m^{-1}\,s^{-2}}$. If you store only the exponents, a unit becomes a vector of seven integers:

$$
[\mathrm{N}] = (1, 1, -2, 0, 0, 0, 0) \quad \text{over } (\mathrm{m}, \mathrm{kg}, \mathrm{s}, \mathrm{A}, \mathrm{K}, \mathrm{mol}, \mathrm{cd})
$$

Unit algebra then reduces to vector algebra:

- Multiplying quantities adds their exponent vectors
- Dividing subtracts them
- Raising to a power $p$ multiplies the vector by $p$
- Adding or subtracting is allowed only when the vectors are equal

That last rule is the whole point. A sum of a length and a time is not small or large; it is meaningless, and your code should say so.

## The Mars Climate Orbiter

In September 1999 NASA lost the Mars Climate Orbiter. The mishap investigation board found that ground software produced thruster impulse data in pound-force seconds, while the navigation software expected newton seconds. One pound-force second is 4.448 newton seconds, so every small trajectory correction was under-counted by that factor. The accumulated error put the spacecraft far lower at Mars than planned, and it was lost on arrival.

No equation was wrong. The bug was a number travelling between two programs without its unit.

:::example Converting impulse correctly
A thruster burn delivers an impulse of $J = 12.0\ \mathrm{lbf\,s}$. With $1\ \mathrm{lbf} = 4.448222\ \mathrm{N}$:

$$
J = 12.0 \times 4.448222\ \mathrm{N\,s} = 53.38\ \mathrm{N\,s}
$$

If software reads the raw number 12.0 as newton seconds, the recorded impulse is 12.0 N s, low by a factor of 4.448. For a 338 kg spacecraft the velocity change $\Delta v = J/m$ is $53.38/338 = 0.158\ \mathrm{m/s}$, but the software books $12.0/338 = 0.0355\ \mathrm{m/s}$.
:::

## Writing the Quantity class

The class stores a float and an exponent tuple. Arithmetic operators combine exponents; addition checks them first. Keeping the exponents as a tuple of integers (or fractions, for square roots) makes equality checks exact.

```python file=quantity.py
DIMS = ("m", "kg", "s", "A", "K", "mol", "cd")


class UnitError(TypeError):
    pass


class Quantity:
    def __init__(self, value, dims):
        self.value = float(value)
        self.dims = tuple(dims)

    def _check(self, other):
        if self.dims != other.dims:
            raise UnitError(f"cannot combine {self.unit()} and {other.unit()}")

    def __add__(self, other):
        self._check(other)
        return Quantity(self.value + other.value, self.dims)

    def __sub__(self, other):
        self._check(other)
        return Quantity(self.value - other.value, self.dims)

    def __mul__(self, other):
        if not isinstance(other, Quantity):
            return Quantity(self.value * other, self.dims)
        d = tuple(a + b for a, b in zip(self.dims, other.dims))
        return Quantity(self.value * other.value, d)

    __rmul__ = __mul__

    def __truediv__(self, other):
        if not isinstance(other, Quantity):
            return Quantity(self.value / other, self.dims)
        d = tuple(a - b for a, b in zip(self.dims, other.dims))
        return Quantity(self.value / other.value, d)

    def __pow__(self, p):
        return Quantity(self.value ** p, tuple(a * p for a in self.dims))

    def unit(self):
        parts = [f"{n}^{e}" if e != 1 else n
                 for n, e in zip(DIMS, self.dims) if e]
        return " ".join(parts) or "1"


def q(value, m=0, kg=0, s=0, A=0, K=0, mol=0, cd=0):
    return Quantity(value, (m, kg, s, A, K, mol, cd))


N = q(1, m=1, kg=1, s=-2)
LBF = 4.448222 * N
SEC = q(1, s=1)

if __name__ == "__main__":
    J = 12.0 * LBF * SEC
    m = q(338, kg=1)
    dv = J / m
    assert dv.dims == q(1, m=1, s=-1).dims
    assert abs(J.value - 53.378664) < 1e-6
    assert abs(dv.value - 0.15792) < 1e-5
    try:
        q(1, m=1) + q(1, s=1)
    except UnitError as e:
        print("refused:", e)
    else:
        raise AssertionError("adding m and s must fail")
    print(f"impulse {J.value:.2f} {J.unit()}, dv {dv.value:.4f} {dv.unit()}")
```

:::note Torque versus energy
A newton-metre of torque and a joule of energy have identical exponent vectors. Dimensional checks catch "metres plus seconds" but cannot catch "torque plus energy". Engineers keep the unit names different (N m versus J) as a reminder; your code can add a tag if you need that distinction.
:::

:::exercise Pressure in a Swiss dam
Water at the base of a 250 m deep reservoir is under hydrostatic pressure $p = \rho g h$. Using your `Quantity` class with $\rho = 1000\ \mathrm{kg/m^3}$ and $g = 9.81\ \mathrm{m/s^2}$, compute $p$ and confirm the result has the exponents of a pascal. Express it in bar ($1\ \mathrm{bar} = 10^5\ \mathrm{Pa}$).
---solution---
1. Build the inputs: `rho = q(1000, kg=1, m=-3)`, `g = q(9.81, m=1, s=-2)`, `h = q(250, m=1)`.
2. Multiply: exponents add to $(-3+1+1,\ 1,\ -2) = (-1, 1, -2)$ over (m, kg, s), which is $\mathrm{kg\,m^{-1}\,s^{-2}}$, a pascal.
3. Value: $1000 \times 9.81 \times 250 = 2.4525 \times 10^{6}\ \mathrm{Pa}$.
4. In bar: $2.4525\times10^6 / 10^5 = 24.5\ \mathrm{bar}$, about 24 times atmospheric pressure.
:::
