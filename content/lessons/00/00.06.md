A plot is an argument. An engineering plot has units on both axes, a scale chosen so the physics is visible, and a fit you can read off by eye. This lesson is about one trick that pays off for the rest of the course: log-log axes turn power laws into straight lines.

## Power laws become lines

Many engineering relations are power laws, $y = a\,x^{b}$: drag grows with $v^2$, fan power with speed cubed, beam deflection with length cubed, numerical error with step size to some order. Take logs of both sides:

$$
\log y = \log a + b \log x .
$$

On log-log axes this is a straight line with slope $b$ and intercept $\log a$. The exponent, which is usually the physics you care about, becomes a slope you can measure with a ruler. From any two points,

$$
b = \frac{\log y_2 - \log y_1}{\log x_2 - \log x_1} .
$$

:::widget loglog
The same curve $y = 3x^b$ on linear and log-log axes. On linear axes every exponent looks like "a curve going up"; on log-log axes the exponent is the slope.
:::

## Rules for a plot someone else can use

1. Label every axis with quantity and unit: "pressure drop, kPa", never just "dp".
2. Use log axes when the data spans more than about one decade, or when you expect a power law.
3. Show measured data as markers and models as lines, so the reader can tell what's real.
4. Start a linear axis at zero only when zero means something for the comparison.
5. Put the plot's conclusion in the caption: "error falls with $h^2$", not "error vs h".

:::example The fan laws from two measurements
A cooling fan draws $12\ \mathrm{W}$ at $1000\ \mathrm{rpm}$ and $96\ \mathrm{W}$ at $2000\ \mathrm{rpm}$. Find the exponent and predict the power at $1500\ \mathrm{rpm}$.

1. Slope on log-log axes: $b = \dfrac{\ln 96 - \ln 12}{\ln 2000 - \ln 1000} = \dfrac{\ln 8}{\ln 2} = 3.0$.
2. That's the fan affinity law $P \propto n^3$: flow scales with speed, pressure with speed squared, and power is their product.
3. Prediction: $P = 12 \times (1500/1000)^3 = 12 \times 3.375 = 40.5\ \mathrm{W}$.

Halving the speed of a fan cuts its power by a factor of 8. That's why variable-speed drives save so much energy.
:::

## Fitting a power law in code

With many noisy points, fit the line by least squares in log space. For points $(X_i, Y_i) = (\ln x_i, \ln y_i)$ the slope is

$$
b = \frac{\sum (X_i - \bar X)(Y_i - \bar Y)}{\sum (X_i - \bar X)^2}, \qquad \ln a = \bar Y - b \bar X .
$$

```python file=plot_eng.py
"""Log-log power-law fitting and a small plotting helper with units in the labels."""
import math
import random


def fit_power_law(xs, ys):
    """Least-squares fit of y = a * x**b on log-log axes. Returns (a, b)."""
    X = [math.log(x) for x in xs]
    Y = [math.log(y) for y in ys]
    mx, my = sum(X) / len(X), sum(Y) / len(Y)
    b = sum((x - mx) * (y - my) for x, y in zip(X, Y)) / sum((x - mx) ** 2 for x in X)
    return math.exp(my - b * mx), b


def plot_eng(xs, ys, xlabel, ylabel, path, fit=None, loglog=True):
    """Save a plot with markers for data and a line for the fit. Needs matplotlib."""
    import matplotlib
    matplotlib.use("Agg")
    import matplotlib.pyplot as plt
    fig, ax = plt.subplots(figsize=(5, 3.5), dpi=150)
    ax.plot(xs, ys, "o", ms=3, label="data")
    if fit:
        a, b = fit
        ax.plot(xs, [a * x ** b for x in xs], "-", label=f"fit: {a:.3g} x^{b:.3f}")
    if loglog:
        ax.set_xscale("log"); ax.set_yscale("log")
    ax.set_xlabel(xlabel); ax.set_ylabel(ylabel)
    ax.grid(True, which="both", alpha=0.3); ax.legend()
    fig.tight_layout(); fig.savefig(path); plt.close(fig)


if __name__ == "__main__":
    rng = random.Random(1)
    xs = [10 ** (i / 20) for i in range(-20, 41)]               # 0.1 to 100
    ys = [3 * x ** 1.5 * math.exp(rng.gauss(0, 0.05)) for x in xs]  # 5% scatter
    a, b = fit_power_law(xs, ys)
    print(f"fitted a = {a:.3f}, b = {b:.4f}")
    assert abs(b - 1.5) < 0.01 and abs(a / 3 - 1) < 0.05

    a2, b2 = fit_power_law([1000, 2000], [12, 96])               # fan example
    assert abs(b2 - 3) < 1e-12 and abs(a2 * 1500 ** b2 - 40.5) < 1e-9
    try:
        plot_eng(xs, ys, "x, m", "y, N", "power_law.png", fit=(a, b))
        print("saved power_law.png")
    except ImportError:
        print("matplotlib not installed; skipped the figure")
```

Fitting the line in log space treats the scatter as a percentage, which matches how most measurement errors behave. A straight fit on linear axes would let the largest values dominate.

:::exercise Read the order of a method
A numerical method has error $2.0\times10^{-3}$ with step $h = 0.1$ and $2.0\times10^{-7}$ with $h = 0.001$. What is its order, the exponent $p$ in error $\propto h^p$? What error do you expect at $h = 0.01$?
---solution---
1. Slope on log-log axes: $p = \dfrac{\log_{10}(2\times10^{-3}) - \log_{10}(2\times10^{-7})}{\log_{10}0.1 - \log_{10}0.001} = \dfrac{4}{2} = 2$.
2. Second order: dividing $h$ by 10 divides the error by 100.
3. At $h = 0.01$: $2.0\times10^{-3}/100 = 2.0\times10^{-5}$.
:::
