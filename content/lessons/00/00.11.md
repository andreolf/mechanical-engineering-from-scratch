Deriving by hand is how you understand a result. It's also where sign errors and dropped factors hide. A computer algebra system such as SymPy can't tell you what to derive, but it can tell you in a second whether your derivation is right. In this course the rule is: derive on paper first, then let the machine check you.

## Equal means "the difference simplifies to zero"

Two expressions $a(x)$ and $b(x)$ are the same function when $a - b = 0$ for every $x$. SymPy's `simplify(a - b) == 0` tries algebraic rewrites until the difference vanishes. If it returns `0`, your result is proven. If it returns something else, either you made a mistake or SymPy couldn't find the simplification, so you follow up with a numeric spot check at random points.

## A derivative you can't look up quickly

Differentiate $y = x^x$ for $x > 0$. Neither the power rule (which needs a constant exponent) nor the exponential rule (which needs a constant base) applies. Take logs first:

$$
\ln y = x \ln x .
$$

Differentiate both sides with the chain rule on the left and the product rule on the right:

$$
\frac{y'}{y} = \ln x + 1 \quad\Longrightarrow\quad y' = x^x(\ln x + 1) .
$$

At $x = 2$: $y' = 4(\ln 2 + 1) = 6.773$. This technique, logarithmic differentiation, appears again whenever a variable sits in an exponent, for example in the Arrhenius law for creep.

:::example A cantilever's deflection, derived then checked
A cantilever of length $L$ is clamped at $x = 0$ and loaded by $P$ at the tip. Euler–Bernoulli beam theory gives the bending moment $M(x) = -P(L - x)$ and $EI\,w''(x) = M(x)$, with $w(0) = w'(0) = 0$.

1. Integrate once: $EI\,w' = -P\left(Lx - \tfrac{x^2}{2}\right) + C_1$, and $w'(0) = 0$ gives $C_1 = 0$.
2. Integrate again: $EI\,w = -P\left(\tfrac{Lx^2}{2} - \tfrac{x^3}{6}\right) + C_2$, and $w(0) = 0$ gives $C_2 = 0$.
3. So $w(x) = -\dfrac{P x^2 (3L - x)}{6EI}$ and the tip deflection is $w(L) = -\dfrac{PL^3}{3EI}$.
4. Numbers: $P = 1\ \mathrm{kN}$, $L = 2\ \mathrm{m}$, steel $E = 210\ \mathrm{GPa}$, rectangular section $50 \times 100\ \mathrm{mm}$ so $I = bh^3/12 = 4.167\times10^{-6}\ \mathrm{m^4}$. Tip deflection: $\dfrac{1000 \times 8}{3 \times 210\times10^9 \times 4.167\times10^{-6}} = 3.05\ \mathrm{mm}$.

The code checks steps 1 to 3 symbolically: it substitutes the hand result back into the differential equation and both boundary conditions.
:::

```python file=sym_check.py
"""Check hand derivations with SymPy, with a numeric fallback when SymPy is missing."""
import math
import random


def numeric_equal(f, g, lo=0.2, hi=3.0, n=50, rtol=1e-6):
    rng = random.Random(0)
    for _ in range(n):
        x = rng.uniform(lo, hi)
        a, b = f(x), g(x)
        if abs(a - b) > rtol * max(1.0, abs(b)):
            return False
    return True


def central_diff(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)


if __name__ == "__main__":
    hand = lambda x: x**x * (math.log(x) + 1)          # my derivative of x^x
    assert numeric_equal(lambda x: central_diff(lambda t: t**t, x), hand)
    assert abs(hand(2) - 6.7725887) < 1e-6

    try:
        import sympy as sp
    except ImportError:
        print("SymPy not installed: numeric check passed, symbolic check skipped")
    else:
        x = sp.symbols("x", positive=True)
        assert sp.simplify(sp.diff(x**x, x) - x**x * (sp.log(x) + 1)) == 0

        P, L, E, I, s = sp.symbols("P L E I s", positive=True)
        w = -P * s**2 * (3 * L - s) / (6 * E * I)       # my hand result
        assert sp.simplify(E * I * sp.diff(w, s, 2) - (-P * (L - s))) == 0   # ODE
        assert w.subs(s, 0) == 0 and sp.diff(w, s).subs(s, 0) == 0          # BCs
        tip = sp.simplify(w.subs(s, L))
        assert sp.simplify(tip + P * L**3 / (3 * E * I)) == 0
        print("symbolic checks passed; tip =", tip)

    I_val = 0.05 * 0.1**3 / 12
    tip_mm = 1000 * 2**3 / (3 * 210e9 * I_val) * 1000
    assert abs(tip_mm - 3.0476) < 1e-3
    print(f"tip deflection {tip_mm:.2f} mm")
```

## What a checker can and can't do

- It **can** confirm algebra, derivatives, integrals and that a function satisfies a differential equation and its boundary conditions.
- It **can't** tell you that you picked the wrong model. If the beam is short and thick, Euler–Bernoulli theory itself is off (shear deformation matters), and SymPy will happily confirm a correct derivation of the wrong equation.
- Don't use it to skip the derivation. The check only means something when you had a result to check.

:::exercise Twice the length
The same cantilever is made $4\ \mathrm{m}$ long, everything else unchanged. Predict the new tip deflection using the formula's structure, then confirm with numbers.
---solution---
1. Tip deflection is $PL^3/(3EI)$, so it scales with $L^3$.
2. Doubling $L$ multiplies it by $2^3 = 8$.
3. $8 \times 3.05 = 24.4\ \mathrm{mm}$.
4. Direct: $\dfrac{1000 \times 64}{3 \times 210\times10^9 \times 4.167\times10^{-6}} = 24.4\ \mathrm{mm}$. Same answer, and a reminder that long cantilevers get floppy fast.
:::
