Swiss trains run on a clock-face timetable: the same departures every hour, with trains meeting at hub stations just before the full or half hour so passengers can change in a few minutes. That only works if every run between two stations takes a predictable time. This lesson models one run with nothing but constant-acceleration kinematics and closes Phase 00 by putting the whole loop together: derive, code, test.

## Three phases of a run

A train leaves a station at rest, accelerates at $a$ up to the line speed $v_\text{max}$, cruises, then brakes at $b$ to stop at the next platform a distance $D$ away. For constant acceleration the distance covered while reaching speed $v$ from rest is

$$
s = \frac{v^2}{2a} .
$$

So accelerating to $v_\text{max}$ takes $s_1 = v_\text{max}^2/(2a)$ and braking from it takes $s_3 = v_\text{max}^2/(2b)$. If $s_1 + s_3 \le D$, the train cruises over the rest and the run time is

$$
T = \frac{v_\text{max}}{a} + \frac{D - s_1 - s_3}{v_\text{max}} + \frac{v_\text{max}}{b} = \frac{D}{v_\text{max}} + \frac{v_\text{max}}{2}\left(\frac{1}{a} + \frac{1}{b}\right).
$$

The first term is the time at full speed over the whole distance. The second is the penalty for starting and stopping. If the stations are too close to reach line speed ($s_1 + s_3 > D$), the profile is a triangle with peak

$$
v_p = \sqrt{\frac{2Dab}{a + b}}, \qquad T = v_p\left(\frac{1}{a} + \frac{1}{b}\right).
$$

:::example A regional run between two stations
Two stations are $8\ \mathrm{km}$ apart. A regional train has line speed $125\ \mathrm{km/h}$, accelerates at $0.7\ \mathrm{m/s^2}$ and brakes at $0.9\ \mathrm{m/s^2}$.

1. Line speed in SI: $v_\text{max} = 125/3.6 = 34.72\ \mathrm{m/s}$.
2. Distances: $s_1 = 34.72^2/1.4 = 861\ \mathrm{m}$, $s_3 = 34.72^2/1.8 = 670\ \mathrm{m}$. Their sum, $1531\ \mathrm{m}$, is less than $8000\ \mathrm{m}$, so the train reaches line speed.
3. Time: $T = \dfrac{8000}{34.72} + \dfrac{34.72}{2}\left(\dfrac{1}{0.7} + \dfrac{1}{0.9}\right) = 230.4 + 44.1 = 274.5\ \mathrm{s}$, or 4 min 34 s.
4. Add a 30 s dwell time at the station and a few percent recovery margin, and the timetable slot is about 5 min 20 s.

Raising line speed to $160\ \mathrm{km/h}$ gives $T = 236.4\ \mathrm{s}$: 28% more speed buys only 14% less time on this short hop. Better acceleration is often the cheaper upgrade, which is why modern multiple units have powered axles along the whole train.
:::

## Simulate it and test against the formula

The formula is short, but the simulation is what you'd extend later with gradients, curves and traction limits. The test is that the two agree to $10^{-6}\ \mathrm{s}$. To get that accuracy the simulator doesn't rely on a tiny time step: within each step it solves exactly for the moment a phase ends.

```python file=train_run.py
"""Train run between two stations: closed-form time versus an event-driven simulation."""
import math


def run_time(D, vmax, a, b):
    s1, s3 = vmax**2 / (2 * a), vmax**2 / (2 * b)
    if s1 + s3 <= D:
        return D / vmax + vmax / 2 * (1 / a + 1 / b), vmax
    vp = math.sqrt(2 * D * a * b / (a + b))
    return vp * (1 / a + 1 / b), vp


def simulate(D, vmax, a, b, dt=0.5):
    t = x = v = 0.0
    while True:
        brake_dist = v * v / (2 * b)
        if D - x <= brake_dist + 1e-12:           # braking phase: finish analytically
            return t + v / b
        if v < vmax:                              # accelerating
            # time until line speed, or until the braking curve is hit, whichever first
            t_v = (vmax - v) / a
            # solve x + v*tau + a*tau^2/2 + (v + a*tau)^2/(2b) = D for tau
            A = a / 2 + a * a / (2 * b)
            B = v + a * v / b
            C = x + v * v / (2 * b) - D
            t_b = (-B + math.sqrt(B * B - 4 * A * C)) / (2 * A)
            tau = min(dt, t_v, t_b)
            x += v * tau + a * tau * tau / 2
            v = min(vmax, v + a * tau)
        else:                                     # cruising until the braking point
            tau = min(dt, (D - brake_dist - x) / v)
            x += v * tau
        t += tau


if __name__ == "__main__":
    v = 125 / 3.6
    T, vp = run_time(8000, v, 0.7, 0.9)
    Ts = simulate(8000, v, 0.7, 0.9)
    print(f"8 km at 125 km/h: formula {T:.6f} s, simulation {Ts:.6f} s")
    assert abs(T - Ts) < 1e-6 and abs(T - 274.4917) < 1e-3
    T2, vp2 = run_time(1000, v, 0.7, 0.9)                 # too short to reach line speed
    assert vp2 < v and abs(T2 - simulate(1000, v, 0.7, 0.9)) < 1e-6
    T3, _ = run_time(8000, 160 / 3.6, 0.7, 0.9)
    print(f"160 km/h saves {T - T3:.1f} s")
    assert abs((T - T3) - 38.054) < 1e-2
```

:::exercise Stations close together
An S-Bahn stops every $1\ \mathrm{km}$ in the city, with the same train ($v_\text{max} = 125\ \mathrm{km/h}$, $a = 0.7$, $b = 0.9\ \mathrm{m/s^2}$). Does it reach line speed? What peak speed and run time do you get?
---solution---
1. Reaching $125\ \mathrm{km/h}$ needs $s_1 + s_3 = 1531\ \mathrm{m} > 1000\ \mathrm{m}$, so no: the profile is a triangle.
2. Peak speed: $v_p = \sqrt{\dfrac{2 \times 1000 \times 0.7 \times 0.9}{0.7 + 0.9}} = \sqrt{787.5} = 28.06\ \mathrm{m/s} = 101\ \mathrm{km/h}$.
3. Run time: $T = 28.06 \left(\dfrac{1}{0.7} + \dfrac{1}{0.9}\right) = 28.06 \times 2.540 = 71.3\ \mathrm{s}$.
4. Line speed doesn't matter at all on this stretch; only acceleration and braking do.
:::
