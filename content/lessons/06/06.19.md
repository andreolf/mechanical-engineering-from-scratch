Push on the ends of a plastic ruler. It stays straight, then suddenly bows out sideways, at a load far below what would crush the material. That is buckling: a loss of stability, not of strength. Slender struts, scaffold tubes, truss members in compression and thin bike frame tubes are all sized against it.

## Euler's derivation

Take a pinned-pinned column of length $L$ under axial load $P$, and ask whether a slightly bent shape $w(x)$ can be in equilibrium. The load has a lever arm $w$, so the bending moment is $M = -Pw$, and with $EIw'' = M$:

$$
EI\,w'' + P\,w = 0, \qquad w(0) = w(L) = 0 .
$$

Writing $k^2 = P/EI$, the solution is $w = A\sin kx$. The end condition $w(L) = 0$ allows a non-zero $A$ only when $kL = n\pi$. The lowest load where a bent shape is possible is the **Euler load**:

$$
P_{cr} = \frac{\pi^2 EI}{(KL)^2} .
$$

$K$ is the **effective length factor** for other end conditions: 1 for pinned-pinned, 2 for fixed-free (a flagpole), 0.5 for fixed-fixed, and 0.699 for fixed-pinned.

## Slenderness

Dividing by the area gives the critical stress $\sigma_{cr} = \pi^2 E/(KL/r)^2$, with the radius of gyration $r = \sqrt{I/A}$. The slenderness $KL/r$ decides everything. Long, slender members buckle elastically far below yield. Short, stocky ones crush first. Between the two, imperfections and yield interact (next lesson).

## As an eigenvalue problem

Discretise the column into beam elements (Phase 04 ideas) and the condition becomes $\mathbf K\boldsymbol\phi = P\,\mathbf K_g\boldsymbol\phi$: a generalised eigenvalue problem. The smallest eigenvalue is the critical load, and its eigenvector the buckled shape. This is exactly what finite-element software does for buckling.

:::widget buckle
A 3 m steel scaffold tube, 48.3 × 3.2 mm. Choose the end conditions and raise the load. Below $P_{cr}$ the column stays straight; at $P_{cr}$ it snaps into its buckled shape.
:::

:::example A scaffold tube
$D = 48.3$ mm, $t = 3.2$ mm: $I = 115{,}857$ mm⁴, $A = 453.4$ mm², $r = 15.99$ mm. $L = 3$ m, $E = 210$ GPa.

1. Pinned-pinned: $P_{cr} = \pi^2\cdot210000\cdot115857/3000^2 = 26.68$ kN.
2. The squash load at 235 MPa is 106.5 kN, four times higher: this tube fails by buckling. Slenderness $L/r = 187.7$.
3. Beam elements: 2 elements give 26.88 kN (0.75 % high), 4 give 0.05 %, 16 give 0.0002 %. The discrete answer converges to Euler from above.
4. Same tube, other ends: fixed-free 6.67 kN, fixed-pinned 54.58 kN, fixed-fixed 106.72 kN. The code recovers $K$ = 2, 0.6992 and 0.5.
:::

```python file=buckling.py
"""Euler buckling from a discretised column: beam finite elements give K phi = P Kg phi."""
import math
import numpy as np


def column_matrices(L, EI, n):
    """Assemble bending stiffness K and geometric stiffness Kg (per unit axial load) for n Hermite beam elements."""
    l = L / n
    k = EI / l**3 * np.array([[12, 6*l, -12, 6*l], [6*l, 4*l*l, -6*l, 2*l*l], [-12, -6*l, 12, -6*l], [6*l, 2*l*l, -6*l, 4*l*l]])
    g = 1 / (30 * l) * np.array([[36, 3*l, -36, 3*l], [3*l, 4*l*l, -3*l, -l*l], [-36, -3*l, 36, -3*l], [3*l, -l*l, -3*l, 4*l*l]])
    N = 2 * (n + 1)
    K, Kg = np.zeros((N, N)), np.zeros((N, N))
    for e in range(n):
        idx = slice(2 * e, 2 * e + 4)
        K[idx, idx] += k; Kg[idx, idx] += g
    return K, Kg


def critical_load(L, EI, n, ends):
    """ends: 'pinned-pinned', 'fixed-free', 'fixed-fixed' or 'fixed-pinned'. DOFs per node: (w, slope)."""
    K, Kg = column_matrices(L, EI, n)
    last = 2 * n
    fixed = {"pinned-pinned": [0, last], "fixed-free": [0, 1], "fixed-fixed": [0, 1, last, last + 1], "fixed-pinned": [0, 1, last]}[ends]
    free = [i for i in range(K.shape[0]) if i not in fixed]
    Kr, Gr = K[np.ix_(free, free)], Kg[np.ix_(free, free)]
    lam = np.linalg.eigvals(np.linalg.solve(Gr, Kr))
    return float(np.min(lam.real[lam.real > 0]))


if __name__ == "__main__":
    E = 210e3
    # a scaffold tube 48.3 x 3.2 mm, 3 m between joints
    D, t, L = 48.3, 3.2, 3000.0
    I = math.pi * (D**4 - (D - 2 * t) ** 4) / 64; A = math.pi * (D**2 - (D - 2 * t) ** 2) / 4
    EI = E * I
    euler = math.pi**2 * EI / L**2
    print(f"scaffold tube: I = {I:.0f} mm^4, A = {A:.1f} mm^2, Euler load (pinned) {euler/1e3:.3f} kN")
    for n in (2, 4, 8, 16):
        Pn = critical_load(L, EI, n, "pinned-pinned")
        print(f"  {n:2d} elements: {Pn/1e3:.4f} kN (error {(Pn/euler - 1)*100:.4f} %)")
    assert abs(critical_load(L, EI, 16, "pinned-pinned") / euler - 1) < 1e-5
    for ends, K in (("fixed-free", 2.0), ("fixed-fixed", 0.5), ("fixed-pinned", 0.6992)):
        Pn = critical_load(L, EI, 32, ends)
        Keff = math.pi * math.sqrt(EI / Pn) / L
        print(f"  {ends}: {Pn/1e3:.3f} kN, effective length factor K = {Keff:.4f} (textbook {K})")
        assert abs(Keff - K) < 1e-3
    print(f"squash load at 235 MPa: {235 * A / 1e3:.1f} kN; slenderness L/r = {L / math.sqrt(I / A):.1f}")
```

:::exercise A push rod
A solid steel push rod, 20 mm in diameter and 1.5 m long, is pinned at both ends. What load buckles it? What if one end were clamped and the other free?
---solution---
1. $I = \pi\cdot20^4/64 = 7854$ mm⁴.
2. Pinned-pinned: $P_{cr} = \pi^2\cdot210000\cdot7854/1500^2 = 7.235$ kN.
3. Fixed-free, $K = 2$: four times less, 1.809 kN.
4. Compare the squash load at 235 MPa: $235\cdot314.2 = 73.8$ kN. Buckling governs by a factor of 10.
:::
