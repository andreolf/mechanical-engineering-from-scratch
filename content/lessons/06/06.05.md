Lesson 05.08 flagged structures where statics alone can't find the forces. Now you have the missing ingredient: deformation. A bar clamped between two walls, a steel bolt inside an aluminium sleeve, a concrete column with steel bars inside it. All are solved with the same three-step recipe, and the answers say something important: stiffness attracts load.

## The three ingredients

1. **Equilibrium**: the force equations you'd write anyway. They have more unknowns than equations.
2. **Compatibility**: a geometric condition on the deformations. For a bar between rigid walls, the total stretch must be zero. For parts bolted together, they must stretch by the same amount.
3. **Constitutive law**: Hooke's law, $\delta = NL/(EA)$, links forces to deformations.

Put the force–deformation law into the compatibility condition and you get the extra equations you need.

## A bar between two walls

A bar between rigid walls carries a load $P$ at the point where part 1 (length $a$, stiffness $E_1A_1$, at wall A) meets part 2 (length $b$, stiffness $E_2A_2$, at wall B). Part 1 is in tension $R_A$ and part 2 in compression $R_B$.

$$
R_A + R_B = P, \qquad \frac{R_A\,a}{E_1A_1} = \frac{R_B\,b}{E_2A_2} .
$$

For a uniform bar, $R_A = Pb/L$ and $R_B = Pa/L$: the wall **closer** to the load takes more. In general each part takes load in proportion to its spring stiffness $EA/L$. That is the principle behind every indeterminate structure: load goes where the stiffness is.

## Stiffness matrices

The same answer comes from treating each part as a spring with stiffness $k = EA/L$, assembling a stiffness matrix and solving $\mathbf K\mathbf u = \mathbf f$ for the free nodal displacements. That is the 1D finite element method, which the code uses as a cross-check, and it scales to any number of parts and loads.

:::example Two walls, two materials
1. Uniform steel bar, $L = 1000$ mm, 60 kN at $a = 300$ mm: $R_A = 60\cdot700/1000 = 42$ kN, $R_B = 18$ kN. The load point moves $42000\cdot300/(210000\cdot400) = 0.15$ mm.
2. Steel 300 mm ($A = 400$ mm²) next to wall A and aluminium 700 mm ($A = 600$ mm²) next to wall B. Flexibilities $a/(E_1A_1) = 3.571\times10^{-6}$ and $b/(E_2A_2) = 1.667\times10^{-5}$ mm/N.
3. $R_A = 60\cdot16.667/(3.571 + 16.667) = 49.41$ kN and $R_B = 10.59$ kN. The short steel part carries 123.5 MPa, the long aluminium part only 17.6 MPa.
4. With 25 kN and 8 kN at two points on a three-part bar, the stiffness model gives reactions 24.23 and 8.77 kN, summing to the 33 kN applied.
:::

```python file=indeterminate_bar.py
"""A bar fixed at both ends: equilibrium + compatibility + Hooke's law, checked with a small stiffness-matrix model."""
import numpy as np


def fixed_fixed(P, a, L1_EA, L2_EA):
    """Load P at the step between part 1 (wall A side) and part 2 (wall B side). L_EA = L / (E A) of each part.
    Equilibrium: RA + RB = P. Compatibility: total stretch zero -> RA * f1 = RB * f2 (part 1 stretches, part 2 shortens)."""
    RA = P * L2_EA / (L1_EA + L2_EA)
    return RA, P - RA


def fe_bar(lengths, EAs, loads):
    """1D finite elements: nodes at the ends of each part; both end nodes fixed. loads: force at each interior node."""
    n = len(lengths) + 1
    K = np.zeros((n, n))
    for e, (L, EA) in enumerate(zip(lengths, EAs)):
        k = EA / L
        K[e:e + 2, e:e + 2] += k * np.array([[1, -1], [-1, 1]])
    f = np.zeros(n); f[1:-1] = loads
    u = np.zeros(n); u[1:-1] = np.linalg.solve(K[1:-1, 1:-1], f[1:-1])
    R = K @ u - f
    return u, R


if __name__ == "__main__":
    # uniform bar: P at distance a from wall A: RA = P b / L, RB = P a / L
    P, a, b, EA = 60e3, 300.0, 700.0, 210e3 * 400
    RA, RB = fixed_fixed(P, a, a / EA, b / EA)
    print(f"uniform bar: RA = {RA / 1e3:.3f} kN, RB = {RB / 1e3:.3f} kN (P b/L = {P * b / 1000 / 1e3:.3f})")
    assert abs(RA + RB - P) < 1e-9 and abs(RA - P * b / (a + b)) < 1e-9
    u, R = fe_bar([a, b], [EA, EA], [P])
    print(f"  stiffness model: load-point displacement {u[1]:.5f} mm, wall reactions {np.round(-R[[0, -1]] / 1e3, 3)} kN")
    assert np.allclose(-R[[0, -1]], [RA, RB]) and abs(u[1] - RA * a / EA) < 1e-12
    # steel part 300 mm (A = 400 mm^2) and aluminium part 700 mm (A = 600 mm^2): the stiffer side takes more
    f1, f2 = 300 / (210e3 * 400), 700 / (70e3 * 600)
    RA, RB = fixed_fixed(P, 300, f1, f2)
    u, R = fe_bar([300, 700], [210e3 * 400, 70e3 * 600], [P])
    print(f"steel/aluminium bar: RA = {RA / 1e3:.3f} kN (steel side), RB = {RB / 1e3:.3f} kN; stresses {RA / 400:.2f} and {-RB / 600:.2f} MPa")
    assert np.allclose(-R[[0, -1]], [RA, RB]) and abs(RA + RB - P) < 1e-9
    # several loads: reactions still sum to the total applied load
    u, R = fe_bar([200, 300, 500], [EA, EA / 2, EA], [25e3, 8e3])
    print(f"two loads (25 kN and 8 kN): reactions {np.round(-R[[0, -1]] / 1e3, 4)} kN, sum {-R[[0, -1]].sum() / 1e3:.4f} kN")
    assert abs(-R[[0, -1]].sum() - 33e3) < 1e-6
```

:::exercise A bolt and a sleeve
A steel bolt ($A = 80$ mm²) passes through an aluminium sleeve ($A = 240$ mm²) of the same length. A 30 kN compressive load is applied to both through rigid end plates. How is the load shared?
---solution---
1. Equilibrium: $N_s + N_a = 30$ kN.
2. Compatibility: same length, same shortening, so $N_s/(E_sA_s) = N_a/(E_aA_a)$.
3. Stiffnesses: $E_sA_s = 210000\cdot80 = 16.8$ MN and $E_aA_a = 70000\cdot240 = 16.8$ MN. Equal, so each carries 15 kN. Stresses: 187.5 MPa in the bolt and 62.5 MPa in the sleeve. Equal force, very different stress.
:::
