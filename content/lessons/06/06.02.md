Stress is what the material feels; **strain** is what you can measure. A strain gauge glued to a bridge girder or a bike crank reads how much the material stretches and distorts, and from that, via Hooke's law, engineers infer the stress. This lesson defines strain from the displacement field and shows its one subtle point: rotations must not count as strain.

## Displacement and its gradient

Every material point moves by a displacement $\mathbf u(\mathbf x)$. A uniform $\mathbf u$ is a rigid translation: no deformation. What matters is how $\mathbf u$ changes from point to point, the displacement gradient $\nabla\mathbf u$ with entries $\partial u_i/\partial x_j$. Split it into a symmetric and an antisymmetric part:

$$
\nabla\mathbf u = \underbrace{\tfrac12(\nabla\mathbf u + \nabla\mathbf u^T)}_{\boldsymbol\varepsilon\ \text{(strain)}} + \underbrace{\tfrac12(\nabla\mathbf u - \nabla\mathbf u^T)}_{\boldsymbol\omega\ \text{(rotation)}} .
$$

- $\varepsilon_{xx} = \partial u_x/\partial x$ is the stretch of a fibre along $x$ (0.001 = 0.1 % = 1000 microstrain).
- $\varepsilon_{xy} = \tfrac12(\partial u_x/\partial y + \partial u_y/\partial x)$ is half the change of a right angle. Engineers often use $\gamma_{xy} = 2\varepsilon_{xy}$.
- $\boldsymbol\omega$ is a small rigid rotation and causes no stress.

## Small strain and its limit

This **small-strain** tensor is linear in $\mathbf u$, which makes everything downstream (beams, finite elements) linear. The price: a rigid rotation by $\theta$ shows up as a false strain of about $-\theta^2/2$. For rotations of a degree or less, that's negligible. For a fishing rod or a rubber seal, you need large-deformation measures (such as the Green–Lagrange strain, which is exactly zero for any rigid rotation).

:::example Strains from a displacement field
The code samples displacement fields on a 101 × 101 grid and differentiates them numerically.

1. $u_x = 0.002x + 0.0005y$, $u_y = 0.0005x - 0.0006y$: $\varepsilon_{xx} = 0.002$, $\varepsilon_{yy} = -0.0006$, $\varepsilon_{xy} = \tfrac12(0.0005 + 0.0005) = 0.0005$, rotation zero.
2. A rigid rotation by 0.01 rad gives $|\varepsilon_{xx}| = 1 - \cos0.01 = 5.0\times10^{-5}$, matching $\theta^2/2$. At 0.001 rad it falls 100 times, to $5\times10^{-7}$: second order.
3. A bending-like field $u_x = -kxy$, $u_y = kx^2/2$ gives $\varepsilon_{xx} = -ky$, varying linearly through the depth, with zero shear strain. That's the beam theory of 06.09 in miniature.
:::

```python file=strain.py
"""Small strain from a displacement field on a grid: eps = (grad u + grad u^T) / 2, by central differences."""
import numpy as np


def strain_field(ux, uy, h):
    """ux, uy sampled on a grid with spacing h (axis 0 = y, axis 1 = x). Returns eps_xx, eps_yy, eps_xy, rotation."""
    dux_dy, dux_dx = np.gradient(ux, h, edge_order=2)
    duy_dy, duy_dx = np.gradient(uy, h, edge_order=2)
    return dux_dx, duy_dy, 0.5 * (dux_dy + duy_dx), 0.5 * (duy_dx - dux_dy)


if __name__ == "__main__":
    h = 0.01
    y, x = np.mgrid[0:1 + h / 2:h, 0:1 + h / 2:h]
    # stretch 0.2 % in x, contract 0.06 % in y, shear: a 1 m square patch of aluminium skin
    ux = 0.002 * x + 0.0005 * y
    uy = -0.0006 * y + 0.0005 * x
    exx, eyy, exy, w = strain_field(ux, uy, h)
    print(f"homogeneous field: eps_xx {exx.mean():.6f}, eps_yy {eyy.mean():.6f}, eps_xy {exy.mean():.6f}, rotation {w.mean():.2e}")
    assert np.allclose(exx, 0.002) and np.allclose(eyy, -0.0006) and np.allclose(exy, 0.0005) and np.allclose(w, 0)
    # a rigid rotation by theta: small strain is only second order, -theta^2/2 on the diagonal
    for th in (1e-2, 1e-3):
        c, s = np.cos(th), np.sin(th)
        ux, uy = c * x - s * y - x, s * x + c * y - y
        exx, eyy, exy, w = strain_field(ux, uy, h)
        print(f"rigid rotation {th:.0e} rad: max |eps| = {max(abs(exx).max(), abs(exy).max()):.3e} (theta^2/2 = {th**2 / 2:.3e}), rotation {w.mean():.6e}")
        assert abs(abs(exx).max() - (1 - c)) < 1e-12 and abs((1 - c) / (th**2 / 2) - 1) < 1e-4 and abs(exy).max() < 1e-12 and abs(w.mean() - s) < 1e-12
    # a bending-like field u_x = -k x y, u_y = k x^2 / 2: eps_xx = -k y varies across the depth, shear strain zero
    k = 0.01
    ux, uy = -k * x * y, k * x**2 / 2
    exx, eyy, exy, w = strain_field(ux, uy, h)
    assert np.allclose(exx, -k * y) and np.allclose(exy, 0, atol=1e-12)
    print(f"bending field: eps_xx from {exx.max():.4f} (y = 0) to {exx.min():.4f} (y = 1), no shear strain")
```

:::exercise A strain gauge rosette
Three gauges on a bike crank read $\varepsilon_0 = 600\times10^{-6}$ along $x$, $\varepsilon_{90} = -180\times10^{-6}$ along $y$, and $\varepsilon_{45} = 410\times10^{-6}$ at 45°. Find $\gamma_{xy}$. (The strain along a direction at angle $\varphi$ is $\varepsilon_{xx}\cos^2\varphi + \varepsilon_{yy}\sin^2\varphi + \gamma_{xy}\sin\varphi\cos\varphi$.)
---solution---
1. At 45°: $\varepsilon_{45} = \tfrac12(\varepsilon_{xx} + \varepsilon_{yy}) + \tfrac12\gamma_{xy}$.
2. $410 = \tfrac12(600 - 180) + \tfrac12\gamma_{xy} = 210 + \tfrac12\gamma_{xy}$, so $\gamma_{xy} = 400\times10^{-6}$.
3. That's how every 45° rosette on a test rig works: three readings give the full 2D strain state.
:::
