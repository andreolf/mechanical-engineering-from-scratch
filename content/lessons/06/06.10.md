Steel beams are I-shaped, bike frames are tubes and bamboo grows hollow, all for the same reason. Bending stiffness and strength depend on the second moment of area $I$, which weights each bit of material by the square of its distance from the neutral axis. Put material far from the axis and you get much more stiffness for the same weight. This lesson builds a section calculator and compares shapes at equal area.

## Definition and basic shapes

$$
I = \int_A y^2\,dA \qquad [\text{mm}^4] .
$$

- Rectangle $b\times h$ about its centroid: $bh^3/12$.
- Solid circle of diameter $D$: $\pi D^4/64$.
- Tube: $\pi(D^4 - d^4)/64$.

## The parallel-axis theorem

A part with area $A_i$ and its own centroidal $I_i$, whose centroid sits a distance $d_i$ from the section's neutral axis, contributes

$$
I = \sum_i \big(I_i + A_i\,d_i^2\big) .
$$

The $A d^2$ term is why flanges are so effective: for an I-beam almost all of $I$ comes from the flanges' distance from the axis, while the thin web mainly carries shear and holds the flanges apart.

For any polygon, Green's theorem gives the second moment directly from the vertices, $I_{x0} = \tfrac{1}{12}\sum (y_i^2 + y_iy_{i+1} + y_{i+1}^2)(x_iy_{i+1} - x_{i+1}y_i)$, which makes a good independent check.

## Efficiency

Stiffness is $EI$ and strength is $W = I/c$. At equal area (equal mass per metre), an I-section or a thin tube beats a solid square or round bar many times over. The limit is local buckling: a too-thin flange or tube wall crumples (lessons 06.19 and 06.20).

:::example An I-beam and friends
1. I-section like an IPE 200 (without root fillets): $h = 200$, $b = 100$, $t_f = 8.5$, $t_w = 5.6$ mm. $A = 2724.8$ mm².
2. Flanges: $2\,[100\cdot8.5^3/12 + 850\cdot95.75^2] = 1.5596\times10^7$ mm⁴. Web: $5.6\cdot183^3/12 = 2.860\times10^6$ mm⁴. Total $I = 1.8456\times10^7$ mm⁴. The polygon formula agrees.
3. At the same area: square $6.19\times10^5$, round bar $5.91\times10^5$, tube 100 mm × 9.59 mm $2.82\times10^6$ mm⁴. The I-section is 29.8 times the square.
4. The T-section from 05.17 (centroid 139.05 mm up) has $I = 4.03\times10^7$ mm⁴.
:::

```python file=sections.py
"""Second moments of area: composite sections with the parallel-axis theorem, checked by a polygon formula."""
import math
import numpy as np


def rects(parts):
    """parts: (b, h, yc) rectangles centred on the y axis. Returns A, centroid y, I about the centroidal x axis."""
    A = sum(b * h for b, h, _ in parts)
    yb = sum(b * h * yc for b, h, yc in parts) / A
    I = sum(b * h**3 / 12 + b * h * (yc - yb) ** 2 for b, h, yc in parts)     # parallel-axis theorem
    return A, yb, I


def polygon_props(pts):
    """Area, centroid y and I about the centroidal x axis of a simple polygon (Green's theorem)."""
    p = np.asarray(pts, float); x, y = p[:, 0], p[:, 1]; xn, yn = np.roll(x, -1), np.roll(y, -1)
    cr = x * yn - xn * y
    A = cr.sum() / 2; yb = ((y + yn) * cr).sum() / (6 * A)
    Ix0 = ((y**2 + y * yn + yn**2) * cr).sum() / 12
    return A, yb, Ix0 - A * yb**2


def tube(D, d):
    return math.pi * (D**2 - d**2) / 4, math.pi * (D**4 - d**4) / 64


if __name__ == "__main__":
    # I-section like an IPE 200 without root fillets: h 200, b 100, flanges 8.5, web 5.6
    h, b, tf, tw = 200.0, 100.0, 8.5, 5.6
    A, yb, I = rects([(b, tf, h - tf / 2), (tw, h - 2 * tf, h / 2), (b, tf, tf / 2)])
    pts = [(-b / 2, 0), (b / 2, 0), (b / 2, tf), (tw / 2, tf), (tw / 2, h - tf), (b / 2, h - tf), (b / 2, h), (-b / 2, h),
           (-b / 2, h - tf), (-tw / 2, h - tf), (-tw / 2, tf), (-b / 2, tf)]
    Ap, ybp, Ip = polygon_props(pts)
    print(f"I-section: A = {A:.1f} mm^2, I = {I:.4e} mm^4 (polygon {Ip:.4e})")
    assert abs(A - Ap) < 1e-9 and abs(I - Ip) < 1e-6 * I
    # T-section from lesson 05.17: flange 200 x 30 over a 30 x 170 web
    At, ybt, It = rects([(200, 30, 185), (30, 170, 85)])
    print(f"T-section: centroid {ybt:.4f} mm, I = {It:.4e} mm^4")
    # equal area comparison: square, round bar, tube, I-section
    s = math.sqrt(A); Isq = s**4 / 12
    Dr = math.sqrt(4 * A / math.pi); Ir = math.pi * Dr**4 / 64
    # a tube of the same area with 100 mm outside diameter
    d_in = math.sqrt(100**2 - 4 * A / math.pi); At_, It_ = tube(100, d_in)
    for name, val in (("square", Isq), ("round bar", Ir), (f"tube 100 x {(100 - d_in) / 2:.2f}", It_), ("I-section", I)):
        print(f"  same area {A:.0f} mm^2, {name:16s}: I = {val:.4e} mm^4 ({val / Isq:5.1f} x the square)")
    assert I > It_ > Ir and I > 20 * Isq and abs(At_ - A) < 1e-9
```

:::exercise A box section
A steel box section is 150 mm wide, 200 mm deep, with 10 mm walls all round. Find $I$ about the horizontal axis.
---solution---
1. Outer rectangle minus inner: $I = (150\cdot200^3 - 130\cdot180^3)/12$.
2. $= (1.2\times10^9 - 7.582\times10^8)/12 = 3.682\times10^7$ mm⁴.
3. Its area is $150\cdot200 - 130\cdot180 = 6600$ mm². A solid square of that area would have $I = 6600^2/12 = 3.63\times10^6$ mm⁴, about ten times less.
:::
