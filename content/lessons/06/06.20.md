Euler's column is perfectly straight, perfectly loaded through its axis and made of material that never yields. Real columns are none of these. They have a slight initial bow, the load is a little off centre, and they yield. Tests show real columns failing below the Euler load, sometimes far below. This lesson shows why, and how designers allow for it.

## A column with an initial bow

Give the pinned column an initial shape $w_0 = e_0\sin(\pi x/L)$, with $e_0$ the bow at mid-span. Under load $P$ the extra deflection $w$ satisfies

$$
EI\,w'' + P\,w = -P\,w_0 .
$$

Try $w = B\sin(\pi x/L)$. It works with $B = e_0\,\dfrac{P/P_{cr}}{1 - P/P_{cr}}$, so the total bow is

$$
w_0 + w = \frac{e_0}{1 - P/P_{cr}} .
$$

That is the **amplification factor** $1/(1 - P/P_{cr})$. At half the Euler load the bow doubles; at 90 % it is ten times the initial bow; as $P \to P_{cr}$ it grows without bound. There is no sudden snap: the column bends more and more.

## Failure by first yield

The bow adds bending to the axial stress. The extreme fibre carries

$$
\sigma_{max} = \frac{P}{A} + \frac{P\,c}{I}\cdot\frac{e_0}{1 - P/P_{cr}} .
$$

Setting $\sigma_{max} = f_y$ and solving for $P$ gives the **Perry–Robertson** failure load. Steel design codes are built on exactly this idea, with $e_0$ calibrated from tests (around $L/1000$ plus residual stress effects) and expressed as buckling curves.

:::example The scaffold tube, slightly bent
Same tube: $P_{cr} = 26.68$ kN, $A = 453.4$ mm², $I = 115{,}857$ mm⁴, $c = 24.15$ mm. Initial bow $e_0 = L/1000 = 3$ mm.

1. The code solves the bowed-column equation by finite differences. At $P/P_{cr}$ = 0.25, 0.5, 0.8, 0.9 and 0.95 the total bow is 4, 6, 15, 30 and 60 mm, matching $e_0/(1 - P/P_{cr})$.
2. First yield (235 MPa) by bisection: $P = 24.43$ kN $= 0.916\,P_{cr}$. There, $P/A = 53.9$ MPa and the bow is 35.6 mm, adding 181.1 MPa of bending.
3. Shorter tubes, with $e_0 = L/1000$ each time: at 1 m, failure is 92.4 kN against Euler's 240 kN and a squash load of 106.5 kN. Stocky columns are limited by yield, slender ones by buckling, and imperfections pull both below their ideal values.
:::

```python file=imperfect.py
"""Imperfect columns: amplification 1/(1 - P/Pcr) and the Perry-Robertson failure load."""
import math
import numpy as np


def bow_fd(P, L, EI, e0, n=200):
    """Solve EI w'' + P w = -P w0 with w0 = e0 sin(pi x / L), pinned ends, by finite differences.
    Returns the extra mid-span deflection w (not counting the initial bow)."""
    x = np.linspace(0, L, n + 1); h = L / n
    m = n - 1
    A = (np.diag(-2 * np.ones(m)) + np.diag(np.ones(m - 1), 1) + np.diag(np.ones(m - 1), -1)) * EI / h**2 + P * np.eye(m)
    w = np.zeros(n + 1)
    w[1:-1] = np.linalg.solve(A, -P * e0 * np.sin(np.pi * x[1:-1] / L))
    return x, w


def perry_load(A, I, c, L, E, fy, e0):
    """Axial load at which the extreme fibre first yields: P/A + P e0 c / (I (1 - P/Pcr)) = fy (bisection)."""
    Pcr = math.pi**2 * E * I / L**2
    f = lambda P: P / A + P * e0 * c / (I * (1 - P / Pcr)) - fy
    lo, hi = 0.0, min(Pcr, fy * A) * (1 - 1e-12)
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        lo, hi = (mid, hi) if f(mid) < 0 else (lo, mid)
    return 0.5 * (lo + hi), Pcr


if __name__ == "__main__":
    E, fy = 210e3, 235.0
    D, t, L = 48.3, 3.2, 3000.0                         # the scaffold tube from 06.19
    I = math.pi * (D**4 - (D - 2 * t) ** 4) / 64; A = math.pi * (D**2 - (D - 2 * t) ** 2) / 4; c = D / 2
    EI = E * I; Pcr = math.pi**2 * EI / L**2
    e0 = L / 1000                                       # a typical out-of-straightness, 3 mm
    for ratio in (0.25, 0.5, 0.8, 0.9, 0.95, 0.99):
        P = ratio * Pcr
        x, w = bow_fd(P, L, EI, e0)
        total = e0 + w[len(w) // 2]
        print(f"P/Pcr = {ratio:.2f}: total mid-span bow {total:7.3f} mm, amplification {total / e0:6.2f} (1/(1-P/Pcr) = {1/(1-ratio):6.2f})")
        # the discrete column's Pcr is 0.002 % low, an error the amplification magnifies by (1/(1-P/Pcr))^2
        assert abs(total / e0 - 1 / (1 - ratio)) < 5e-5 / (1 - ratio) ** 2
    # the bow grows without bound as P approaches Pcr
    ws = [e0 / (1 - r) for r in (0.99, 0.999, 0.9999)]
    assert ws[0] < ws[1] < ws[2] and ws[2] > 1000 * e0 * 0.99
    Pf, _ = perry_load(A, I, c, L, E, fy, e0)
    print(f"first yield of the bowed tube at {Pf/1e3:.2f} kN = {Pf/Pcr:.3f} Pcr (Euler {Pcr/1e3:.2f} kN, squash {fy*A/1e3:.1f} kN)")
    for L2 in (1000.0, 2000.0, 3000.0, 4000.0):
        Pf2, Pc2 = perry_load(A, I, c, L2, E, fy, L2 / 1000)
        print(f"  L = {L2/1e3:.0f} m: failure {Pf2/1e3:6.2f} kN, Euler {Pc2/1e3:7.2f} kN, squash {fy*A/1e3:.1f} kN")
```

:::exercise A working load
The scaffold tube (3 m, $e_0 = 3$ mm) carries 15 kN. Find the total bow and the peak stress.
---solution---
1. $P/P_{cr} = 15/26.68 = 0.562$: amplification $1/(1 - 0.562) = 2.284$, total bow $6.85$ mm.
2. Axial stress $15000/453.4 = 33.1$ MPa. Bending $15000\cdot6.85\cdot24.15/115857 = 21.4$ MPa.
3. Peak $54.5$ MPa, well below yield. But a 15 kN load already costs 65 % extra stress from the bow, and the margin shrinks quickly as the load grows.
:::
