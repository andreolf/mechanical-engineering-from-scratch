A floor that is strong enough can still feel bouncy, a machine bed that bends ruins accuracy, and a footbridge that sags looks unsafe even when it isn't. Stiffness is often the real design limit, not strength. This lesson computes how far a beam bends, by integrating the curvature from 06.09 and by solving the fourth-order beam equation directly.

## The beam equation

With $w(x)$ the deflection (upward positive) and small slopes, curvature is $w''$, and 06.09 gave $\kappa = M/EI$:

$$
EI\,w'' = M(x) .
$$

Combine with $dM/dx = V$ and $dV/dx = -q$ from 05.13, and for constant $EI$:

$$
EI\,w'''' = -q(x) \qquad (q \text{ downward positive}).
$$

Four integrations need four boundary conditions, two at each end:

| End | Conditions |
|---|---|
| Clamped | $w = 0$, $w' = 0$ |
| Pinned or roller | $w = 0$, $M = 0$ (so $w'' = 0$) |
| Free | $M = 0$, $V = 0$ ($w'' = 0$, $w''' = 0$) |

## Standard results

Integrating by hand (or in code) gives the cases every engineer knows:

- Cantilever, tip load: $\delta = \dfrac{PL^3}{3EI}$.
- Simply supported, central load: $\delta = \dfrac{PL^3}{48EI}$.
- Simply supported, uniform load: $\delta = \dfrac{5qL^4}{384EI}$.

Note the powers: doubling the span multiplies the deflection by 8 or 16. Doubling the depth of a rectangular beam divides it by 8. A typical serviceability limit is span/300 for floors and footbridges.

:::example A balcony and a footbridge
$E = 210$ GPa, $I = 1.8456\times10^7$ mm⁴, so $EI = 3.876\times10^{12}$ N mm².

1. Cantilever balcony beam, 1.8 m, 5 kN at the tip: $\delta = 5000\cdot1800^3/(3\cdot3.876\times10^{12}) = 2.51$ mm.
2. Footbridge, simply supported over 6 m, 5 kN/m: $\delta = 5\cdot5\cdot6000^4/(384\cdot3.876\times10^{12}) = 21.77$ mm, span/276. Slightly over the span/300 target: a deeper section is needed.
3. The code gets both by integrating $M/EI$ twice, and the footbridge again by solving $EI\,w'''' = q$ with finite differences (21.770 mm).
4. 20 kN at mid-span: $PL^3/48EI = 23.22$ mm.
:::

```python file=deflection.py
"""Beam deflection: integrate EI w'' = M twice, and solve EI w'''' = q by finite differences."""
import numpy as np


def cumtrapz(f, x):
    return np.concatenate([[0.0], np.cumsum((f[1:] + f[:-1]) / 2 * np.diff(x))])


def deflect_from_moment(x, M, EI, bc):
    """w is measured upward and sagging M is positive, so w'' = M / EI.
    bc = 'cantilever' (w = w' = 0 at x = 0) or 'simple' (w = 0 at both ends)."""
    th = cumtrapz(M / EI, x)
    w = cumtrapz(th, x)
    if bc == "simple":
        w = w - x / x[-1] * w[-1]            # add a rigid rotation so that w(L) = 0 too
    return w


def fd_simply_supported(q, L, EI, n=400):
    """EI w'''' = -q (q downward) with w = w'' = 0 at both ends, central differences on n intervals."""
    h = L / n; m = n - 1
    A = np.zeros((m, m))
    for i in range(m):
        for j, c in zip(range(i - 2, i + 3), (1, -4, 6, -4, 1)):
            if 0 <= j < m: A[i, j] += c
    A[0, 0] -= 1; A[-1, -1] -= 1            # ghost points: w_{-1} = -w_1 (w'' = 0 at a pinned end)
    w = np.linalg.solve(A / h**4, -q / EI * np.ones(m))
    return np.concatenate([[0], w, [0]])


if __name__ == "__main__":
    E, I = 210e3, 1.8456e7                  # MPa, mm^4 (the I-section from 06.10)
    EI = E * I
    # cantilever balcony beam, 1.8 m, 5 kN at the tip
    L, P = 1800.0, 5000.0
    x = np.linspace(0, L, 3601)
    w = deflect_from_moment(x, -P * (L - x), EI, "cantilever")
    print(f"cantilever tip deflection {-w[-1]:.4f} mm (P L^3 / 3EI = {P * L**3 / (3 * EI):.4f})")
    assert abs(-w[-1] - P * L**3 / (3 * EI)) < 1e-5
    # footbridge, simply supported 6 m, 5 kN/m = 5 N/mm
    L, q = 6000.0, 5.0
    x = np.linspace(0, L, 6001)
    w = deflect_from_moment(x, q * x * (L - x) / 2, EI, "simple")
    exact = 5 * q * L**4 / (384 * EI)
    print(f"footbridge mid-span deflection {-w.min():.4f} mm (5 q L^4 / 384 EI = {exact:.4f}), span / deflection = {L / exact:.0f}")
    assert abs(-w.min() - exact) < 1e-4
    wf = fd_simply_supported(q, L, EI)
    print(f"finite differences on EI w'''' = q: {-wf.min():.4f} mm")
    assert abs(-wf.min() - exact) < 1e-3 * exact
    # mid-span point load: P L^3 / 48 EI
    P = 20000.0
    w = deflect_from_moment(x, np.where(x < L / 2, P / 2 * x, P / 2 * (L - x)), EI, "simple")
    print(f"20 kN at mid-span: {-w.min():.4f} mm (P L^3 / 48 EI = {P * L**3 / (48 * EI):.4f})")
    assert abs(-w.min() - P * L**3 / (48 * EI)) < 1e-4
```

:::exercise A diving board
A diving board is a cantilever 3 m long, 500 mm wide and 50 mm thick, made of a glass-fibre composite with $E = 25$ GPa. A 750 N diver stands at the tip. How far does it bend?
---solution---
1. $I = 500\cdot50^3/12 = 5.208\times10^6$ mm⁴, $EI = 1.302\times10^{11}$ N mm².
2. $\delta = 750\cdot3000^3/(3\cdot1.302\times10^{11}) = 51.8$ mm.
3. Bouncing adds dynamic effects (Phase 07), but the static deflection sets the board's spring stiffness: $k = 3EI/L^3 = 14.5$ N/mm.
:::
