Lesson 06.01 showed that the normal and shear stress depend on which plane you look at. A designer wants to know the worst plane: the largest tension (where a brittle part cracks) and the largest shear (where a ductile part yields). For plane stress, a 19th-century graphical trick by Otto Mohr shows all planes at once as points on a circle, and it's still the clearest way to think about it.

## Rotating the element

For plane stress $(\sigma_x, \sigma_y, \tau_{xy})$, the stresses on a face whose normal is rotated by $\theta$ are

$$
\sigma_{x'} = \frac{\sigma_x + \sigma_y}{2} + \frac{\sigma_x - \sigma_y}{2}\cos2\theta + \tau_{xy}\sin2\theta, \qquad
\tau_{x'y'} = -\frac{\sigma_x - \sigma_y}{2}\sin2\theta + \tau_{xy}\cos2\theta .
$$

The double angle is the key. Square and add the two equations and $\theta$ disappears:

$$
\Big(\sigma_{x'} - C\Big)^2 + \tau_{x'y'}^2 = R^2, \qquad C = \frac{\sigma_x + \sigma_y}{2}, \quad R = \sqrt{\Big(\frac{\sigma_x - \sigma_y}{2}\Big)^2 + \tau_{xy}^2} .
$$

Every orientation lies on one circle in the $(\sigma, \tau)$ plane: **Mohr's circle**.

## Reading the circle

- **Principal stresses**: $\sigma_{1,2} = C \pm R$, where the circle crosses the $\sigma$ axis. On those planes the shear is zero.
- **Principal angle**: $\tan2\theta_p = 2\tau_{xy}/(\sigma_x - \sigma_y)$.
- **Maximum in-plane shear**: $\tau_{max} = R$, on planes at 45° to the principal ones.
- Rotating the element by $\theta$ moves its point by $2\theta$ round the circle.
- $\sigma_x + \sigma_y = \sigma_1 + \sigma_2$ doesn't change with orientation (an invariant).

Mathematically the principal stresses are the **eigenvalues** of $\boldsymbol\sigma$ and the principal directions its eigenvectors. In 3D there are three, and three circles.

:::widget mohr
Set a plane stress state, then rotate the element. The lime point is the rotated $x'$ face, the amber point the $y'$ face, always diametrically opposite. They reach the $\sigma$ axis at the principal stresses.
:::

:::example A frame lug in plane stress
$\sigma_x = 80$, $\sigma_y = -20$, $\tau_{xy} = 30$ MPa.

1. $C = 30$ MPa, $R = \sqrt{50^2 + 30^2} = 58.31$ MPa.
2. $\sigma_1 = 88.31$ MPa, $\sigma_2 = -28.31$ MPa, matching the eigenvalues of $\boldsymbol\sigma$.
3. $\theta_p = \tfrac12\arctan(60/100) = 15.48°$. Rotating the element by that angle makes the shear vanish.
4. $\tau_{max} = 58.31$ MPa. The code also checks that 12 rotated states all lie on the circle and keep $\sigma_x + \sigma_y = 60$ MPa.
5. The bike tube (60 MPa axial, 25 MPa shear) has $\sigma_1 = 69.05$ MPa at 19.90°.
:::

```python file=mohr.py
"""2D stress transformation and Mohr's circle; principal stresses equal the eigenvalues of sigma."""
import math
import numpy as np


def rotate(sx, sy, txy, theta):
    """Stresses on an element rotated by theta (counter-clockwise)."""
    c, s = math.cos(2 * theta), math.sin(2 * theta)
    m, d = (sx + sy) / 2, (sx - sy) / 2
    return m + d * c + txy * s, m - d * c - txy * s, -d * s + txy * c


def mohr(sx, sy, txy):
    """Centre, radius, principal stresses and the angle of the first principal direction."""
    C = (sx + sy) / 2; R = math.hypot((sx - sy) / 2, txy)
    return C, R, C + R, C - R, 0.5 * math.atan2(2 * txy, sx - sy)


if __name__ == "__main__":
    sx, sy, txy = 80.0, -20.0, 30.0
    C, R, s1, s2, tp = mohr(sx, sy, txy)
    print(f"Mohr's circle: centre {C:.1f} MPa, radius {R:.4f} MPa -> sigma1 {s1:.4f}, sigma2 {s2:.4f} MPa, at {math.degrees(tp):.4f} deg; max in-plane shear {R:.4f} MPa")
    ev = np.linalg.eigvalsh(np.array([[sx, txy], [txy, sy]]))
    assert np.allclose(sorted([s1, s2]), ev)
    # rotating the element to the principal angle kills the shear stress
    a, b, t = rotate(sx, sy, txy, tp)
    assert abs(t) < 1e-12 and abs(a - s1) < 1e-12
    # every rotated state lies on the circle, and the sum sx + sy is invariant
    for deg in range(0, 180, 15):
        a, b, t = rotate(sx, sy, txy, math.radians(deg))
        assert abs(math.hypot(a - C, t) - R) < 1e-12 and abs(a + b - (sx + sy)) < 1e-12
    print("all rotated states lie on the circle; sigma_x + sigma_y is invariant")
    # the bike tube from 06.01: 60 MPa axial, 25 MPa shear
    C, R, s1, s2, tp = mohr(60, 0, 25)
    print(f"bike tube: sigma1 {s1:.4f}, sigma2 {s2:.4f} MPa at {math.degrees(tp):.4f} deg")
    # pure shear: principal stresses +tau and -tau at 45 deg
    C, R, s1, s2, tp = mohr(0, 0, 50)
    assert abs(s1 - 50) < 1e-12 and abs(s2 + 50) < 1e-12 and abs(math.degrees(tp) - 45) < 1e-12
```

:::exercise A twisted shaft
A shaft in pure torsion has $\tau_{xy} = 50$ MPa and no normal stress. Find the principal stresses and their directions. Why do chalk sticks twisted to failure break along a helix?
---solution---
1. $C = 0$, $R = 50$ MPa, so $\sigma_1 = 50$ MPa and $\sigma_2 = -50$ MPa.
2. $\tan2\theta_p = 100/0 \to \infty$, so $\theta_p = 45°$.
3. Chalk is brittle and fails in tension, across the direction of $\sigma_1$. That direction runs at 45° round the stick, so the crack follows a 45° helix. A ductile steel shaft fails instead on the plane of maximum shear, straight across.
:::
