Finding the deflection of a curved hook, a bent bracket or a frame by integrating curvature step by step works, but it's fiddly. Castigliano's theorem turns the problem into one integral and one derivative. It works for any shape, and with a trick it gives the deflection anywhere, in any direction.

## The theorem

For a linear elastic structure with strain energy $U$ written in terms of the applied loads, the deflection at load $P_i$, in its direction, is

$$
\delta_i = \frac{\partial U}{\partial P_i} .
$$

Why: add a little extra $dP_i$. The extra energy stored is $dU$, and it must equal the extra work done, $\delta_i\,dP_i$ (the other loads do work too, but by Maxwell's reciprocity those terms balance out). For a single load, $U = P\delta/2$ with $\delta \propto P$, so $dU/dP = \delta$. That's a quick check.

## The working formula

For a member dominated by bending, $U = \int M^2/(2EI)\,ds$ along its centreline, so

$$
\delta_i = \int \frac{M}{EI}\,\frac{\partial M}{\partial P_i}\,ds .
$$

Differentiate before integrating: $\partial M/\partial P_i$ is just the moment from a unit load at point $i$.

## The dummy load trick

To find a deflection where there's no load, or in a different direction, add a **dummy load** $Q$ there, differentiate, then set $Q = 0$. That's how the next example finds how far a hook swings sideways under a vertical load.

:::

:::example A bike on a ceiling hook
$EI = 210000\cdot\pi\cdot8^4/64 = 4.222\times10^7$ N mm². A 15 kg bike puts $P = 147.15$ N on the bottom of the J, at horizontal distance $R = 40$ mm from the shank.

1. Shank (length $a$): $M = PR$, $\partial M/\partial P = R$. Arc, angle $\phi$ from the shank: $M = PR\cos\phi$, $\partial M/\partial P = R\cos\phi$.
2. Shank term: $\int_0^a PR\cdot R\,ds/EI = PR^2a/EI = 0.558$ mm. Arc term: $\int_0^{\pi/2} PR^3\cos^2\phi\,d\phi/EI = \pi PR^3/(4EI) = 0.175$ mm. Total $\delta_v = 0.733$ mm.
3. Sideways: a dummy horizontal $Q$ at the load point. Working through gives $\delta_h = PR(a + R)^2/(2EI) = 1.366$ mm, towards the shank. The hook swings almost twice as far sideways as it drops.
4. The code differentiates the numerically integrated energy, and separately integrates curvature segment by segment. Both match the formulas to 4 decimals.
5. Rod stress at the ceiling: $PR\cdot4/(\pi d^4/64) = 117$ MPa.
:::

```python file=castigliano.py
"""Castigliano's theorem on a ceiling bike hook: a straight shank plus a semicircular J."""
import math
import numpy as np


def hook_geometry(a, R, n_shank=2001, n_arc=4001):
    """Centreline from the ceiling (0, 0) down the shank to (0, -a), then round a semicircle of radius R.
    Returns points, arc length steps, and the index of the lowest point of the J (where the rim sits)."""
    ys = np.linspace(0, -a, n_shank)
    shank = np.column_stack([np.zeros_like(ys), ys])
    ph = np.linspace(0, np.pi, n_arc)[1:]
    arc = np.column_stack([R - R * np.cos(ph), -a - R * np.sin(ph)])
    pts = np.vstack([shank, arc])
    ds = np.r_[0, np.hypot(*np.diff(pts, axis=0).T)]
    i_low = n_shank - 1 + (n_arc - 1) // 2
    return pts, ds, i_low


def moment(pts, i_load, P, Q):
    """Bending moment (N mm) from a downward load P and a sideways load Q (+x) at point i_load."""
    xL, yL = pts[i_load]
    M = np.zeros(len(pts))
    r = pts[: i_load + 1]
    # moment about each section of the loads beyond it (only sections between the ceiling and the load are loaded)
    M[: i_load + 1] = -P * (xL - r[:, 0]) - Q * (yL - r[:, 1])
    return M


def energy(pts, ds, i_load, P, Q, EI):
    M = moment(pts, i_load, P, Q)
    f = M**2 / (2 * EI)
    return np.sum(0.5 * (f[1:] + f[:-1]) * ds[1:])


def direct_displacement(pts, ds, i_load, P, Q, EI):
    """Integrate curvature: each little segment rotates by M ds / EI, swinging the load point about it."""
    M = moment(pts, i_load, P, Q)
    k = 0.5 * (M[1:] + M[:-1]) / EI * ds[1:]          # rotation of each segment (counter-clockwise positive)
    mid = 0.5 * (pts[1:] + pts[:-1])
    rel = pts[i_load] - mid
    m = np.arange(len(k)) < i_load
    ux = np.sum(-k[m] * rel[m, 1]); uy = np.sum(k[m] * rel[m, 0])
    return ux, uy


if __name__ == "__main__":
    E, d, a, R = 210e3, 8.0, 100.0, 40.0
    EI = E * math.pi * d**4 / 64
    P = 15 * 9.81                                          # a 15 kg bike
    pts, ds, iL = hook_geometry(a, R)
    print(f"load point {pts[iL].round(3)} (bottom of the J), EI = {EI:.4e} N mm^2")
    # Castigliano: delta = dU/dP, sideways movement = dU/dQ at Q = 0 (a dummy load)
    h = 1e-3
    dv = (energy(pts, ds, iL, P + h, 0, EI) - energy(pts, ds, iL, P - h, 0, EI)) / (2 * h)
    dh = (energy(pts, ds, iL, P, h, EI) - energy(pts, ds, iL, P, -h, EI)) / (2 * h)
    hand_v = P * R**2 * a / EI + math.pi * P * R**3 / (4 * EI)
    hand_h = P * R * (a + R) ** 2 / (2 * EI)
    print(f"Castigliano: down {dv:.4f} mm (hand {hand_v:.4f}), sideways {dh:.4f} mm (hand {hand_h:.4f})")
    ux, uy = direct_displacement(pts, ds, iL, P, 0, EI)
    print(f"direct integration of curvature: ux = {ux:+.4f} mm, uy = {uy:+.4f} mm")
    assert abs(dv - hand_v) < 1e-3 * hand_v and abs(abs(dh) - hand_h) < 1e-3 * hand_h
    assert abs(-uy - dv) < 1e-3 * dv and abs(abs(ux) - abs(dh)) < 1e-3 * abs(dh)
    s = P * R * (d / 2) / (math.pi * d**4 / 64)
    print(f"bending stress in the shank {s:.1f} MPa; the load point swings back towards the shank {abs(ux)/abs(uy):.2f} times as far as it drops")
```

:::exercise A quarter-circle bracket
A thin bar is bent into a quarter circle of radius $R$, clamped at one end with its tangent vertical, so its free end lies at the top with its tangent horizontal. A vertical load $P$ hangs from the free end. Using Castigliano, find the vertical deflection.
---solution---
1. Measure $\theta$ from the free end. A point at angle $\theta$ is $R\sin\theta$ horizontally from the load, so $M = PR\sin\theta$ and $\partial M/\partial P = R\sin\theta$.
2. $\delta = \dfrac{1}{EI}\int_0^{\pi/2} PR^2\sin^2\theta\,R\,d\theta = \dfrac{\pi PR^3}{4EI}$.
3. Compare a straight horizontal cantilever of length $R$: $PR^3/(3EI)$. The curved bar is $3\pi/4 = 2.36$ times as flexible.
:::
