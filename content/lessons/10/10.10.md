A bicycle pump gets hot when you use it hard. Part of that is the ideal temperature rise of compressing air, and part is friction and turbulence that a perfect machine wouldn't have. Turbomachinery engineers separate the two with one number per machine, the **isentropic efficiency**. It compares the real compressor or turbine with an ideal reversible, adiabatic one working between the same pressures.

## The ideal reference

An adiabatic reversible process has constant entropy. For an ideal gas with constant specific heats,

$$
\Delta s = c_p\ln\frac{T_2}{T_1} - R\ln\frac{p_2}{p_1} = 0 \quad\Rightarrow\quad \frac{T_{2s}}{T_1} = \left(\frac{p_2}{p_1}\right)^{(k-1)/k} ,
$$

with $k = c_p/c_v \approx 1.4$ for air.

## Definitions

A real compressor needs more work than the ideal one; a real turbine delivers less:

$$
\eta_c = \frac{h_{2s} - h_1}{h_2 - h_1}, \qquad \eta_t = \frac{h_3 - h_4}{h_3 - h_{4s}} .
$$

Both put the ideal work in the "better" place, so both are below 1. With constant $c_p$, $h$ differences are $c_p$ times temperature differences, so the actual compressor exit temperature is

$$
T_2 = T_1 + \frac{T_{2s} - T_1}{\eta_c} .
$$

On an h-s diagram the ideal process is a vertical line; the real one leans to the right, because friction generates entropy. Modern large compressors and turbines reach 85–92 %.

:::

:::example A gas-turbine compressor
Air enters at 20 °C and 1 bar; pressure ratio 8; $\eta_c = 0.85$; $c_p = 1.005$, $R = 0.287$ kJ/(kg K), so $k = 1.3997$.

1. $T_{2s} = 293.15\cdot8^{0.2857} = 530.87$ K.
2. $T_2 = 293.15 + (530.87 - 293.15)/0.85 = 572.82$ K $= 299.7$ °C.
3. Work: $1.005\cdot(572.82 - 293.15) = 281.07$ kJ/kg against 238.91 ideal.
4. Entropy generated: $1.005\ln(572.82/293.15) - 0.287\ln 8 = 0.07644$ kJ/(kg K). The code checks that it's positive for every efficiency below 1 and that $\eta = 1$ recovers the isentropic state.
5. Turbine from 1400 K over the same ratio at 90 %: $T_{4s} = 773.09$ K, $T_4 = 835.78$ K, work 567.04 kJ/kg.
:::

```python file=isentropic.py
"""Isentropic efficiency of a compressor and a turbine with air as an ideal gas (constant cp)."""
import math

CP, R = 1.005, 0.287      # kJ/(kg K)
K = CP / (CP - R)


def s_change(T1, p1, T2, p2):
    """Entropy change (kJ/(kg K)) of an ideal gas."""
    return CP * math.log(T2 / T1) - R * math.log(p2 / p1)


def compressor(T1, rp, eta):
    T2s = T1 * rp ** ((K - 1) / K)
    T2 = T1 + (T2s - T1) / eta
    return T2s, T2, CP * (T2 - T1)


def turbine(T3, rp, eta):
    T4s = T3 / rp ** ((K - 1) / K)
    T4 = T3 - eta * (T3 - T4s)
    return T4s, T4, CP * (T3 - T4)


if __name__ == "__main__":
    print(f"k = {K:.4f}")
    T1, rp = 293.15, 8.0
    T2s, T2, w = compressor(T1, rp, 0.85)
    print(f"compressor 20 C, rp 8, eta 0.85: T2s = {T2s:.2f} K, T2 = {T2:.2f} K ({T2-273.15:.1f} C), work {w:.2f} kJ/kg")
    print(f"  ideal work {CP*(T2s-T1):.2f} kJ/kg; entropy generated {s_change(T1, 100, T2, 800):.5f} kJ/(kg K)")
    assert abs(s_change(T1, 100, T2s, 800)) < 1e-12              # the isentropic state really is isentropic
    assert abs(compressor(T1, rp, 1.0)[1] - T2s) < 1e-12         # eta = 1 recovers it
    for eta in (0.6, 0.7, 0.8, 0.9, 0.99):
        assert s_change(T1, 100, compressor(T1, rp, eta)[1], 800) > 0
    T4s, T4, wt = turbine(1400.0, rp, 0.90)
    print(f"turbine 1400 K, rp 8, eta 0.90: T4s = {T4s:.2f} K, T4 = {T4:.2f} K, work {wt:.2f} kJ/kg")
    assert s_change(1400, 800, T4, 100) > 0
```

:::exercise From measurements back to efficiency
A test rig measures that the compressor above (20 °C in, ratio 8) actually delivers air at 320 °C. What's its isentropic efficiency, and how much extra work per kg goes into friction compared with the ideal?
---solution---
1. $T_2 = 593.15$ K; $T_{2s} = 530.87$ K as before.
2. $\eta_c = (530.87 - 293.15)/(593.15 - 293.15) = 237.72/300.00 = 0.7924$.
3. Extra work: $1.005\cdot(593.15 - 530.87) = 62.59$ kJ/kg, which ends up as a hotter exit gas.
:::
