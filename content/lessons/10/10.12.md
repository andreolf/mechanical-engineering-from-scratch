A petrol engine sparks its mixture at the top of the stroke and burns it almost instantly; a diesel squeezes air so hard it gets hot enough to ignite fuel sprayed in as the piston moves down. Both are messy in reality: friction, heat losses, real combustion. The **air-standard** cycles strip that away, treating the working fluid as air in a closed cycle with heat added and removed, and they explain the main design trends.

## The Otto cycle

1. 1→2: isentropic compression by the **compression ratio** $r = v_1/v_2$.
2. 2→3: heat added at constant volume (the spark).
3. 3→4: isentropic expansion.
4. 4→1: heat rejected at constant volume.

With constant specific heats the efficiency depends only on $r$:

$$
\eta_\text{Otto} = 1 - \frac{1}{r^{k-1}} .
$$

Higher compression means higher efficiency, but petrol engines are limited to about 10–13 by **knock**, auto-ignition of the end gas.

## The Diesel cycle

Heat is added at constant pressure while the piston moves out, until the **cutoff ratio** $r_c = v_3/v_2$:

$$
\eta_\text{Diesel} = 1 - \frac{1}{r^{k-1}}\,\frac{r_c^k - 1}{k(r_c - 1)} .
$$

The bracket is always above 1, so at the same $r$ the Diesel is less efficient. But diesels compress only air, so knock isn't a problem and they run at $r$ = 15–22, which wins overall.

:::example Integrating the loop
Air, $c_v = 0.718$, $R = 0.287$ kJ/(kg K), $k = 1.3997$, starting at 300 K and 100 kPa. The code integrates $\oint p\,dv$ numerically and compares with the formulas.

1. Otto with 1200 kJ/kg added: $r = 8$, 0.5645 (peak 2360 K, 6.29 MPa); $r = 10$, 0.6016; $r = 12$, 0.6296. Integration agrees to five digits.
2. Diesel, $r = 18$, $r_c = 2$: 0.6313, peak 1905 K at 5.72 MPa.
3. Same $r = 10$: Otto 0.6016, Diesel 0.5337.
:::

```python file=otto.py
"""Air-standard Otto and Diesel cycles: state points, net work by integrating p dV, and the closed-form efficiencies."""
import numpy as np

CV, R = 0.718, 0.287
K = (CV + R) / CV


def otto_eff(r):
    return 1 - r ** (1 - K)


def diesel_eff(r, rc):
    return 1 - r ** (1 - K) * (rc ** K - 1) / (K * (rc - 1))


def trap(y, x):
    return float(np.sum((y[1:] + y[:-1]) / 2 * np.diff(x)))


def cycle(r, q_in=None, rc=None, T1=300.0, p1=100.0, n=4000):
    """Integrate p dV around an Otto (q_in given, kJ/kg) or Diesel (cutoff rc given) cycle per kg of air."""
    v1 = R * T1 / p1; v2 = v1 / r
    v = np.linspace(v1, v2, n); p_c = p1 * (v1 / v) ** K                     # 1-2 isentropic compression
    T2 = T1 * r ** (K - 1); p2 = p_c[-1]
    if rc is None:                                                            # Otto: heat at constant volume
        T3 = T2 + q_in / CV; p3 = p2 * T3 / T2; v3 = v2; w_heat = 0.0; q = q_in
    else:                                                                     # Diesel: heat at constant pressure
        v3 = rc * v2; T3 = T2 * rc; p3 = p2; w_heat = p2 * (v3 - v2); q = (CV + R) * (T3 - T2)
    ve = np.linspace(v3, v1, n); p_e = p3 * (v3 / ve) ** K                    # 3-4 isentropic expansion
    w = trap(p_c, v) + w_heat + trap(p_e, ve)
    return w, q, T3, p3


if __name__ == "__main__":
    print(f"k = {K:.4f}")
    for r in (8, 10, 12):
        w, q, T3, p3 = cycle(r, q_in=1200.0)
        print(f"Otto r = {r}: efficiency {otto_eff(r):.4f} (integrated {w/q:.4f}), peak {T3:.0f} K, {p3/1000:.2f} MPa")
        assert abs(w / q - otto_eff(r)) < 1e-5
    w, q, T3, p3 = cycle(18, rc=2.0)
    print(f"Diesel r = 18, rc = 2: efficiency {diesel_eff(18, 2):.4f} (integrated {w/q:.4f}), peak {T3:.0f} K, {p3/1000:.2f} MPa")
    assert abs(w / q - diesel_eff(18, 2)) < 1e-5
    assert diesel_eff(10, 2) < otto_eff(10)          # same r: Otto wins; Diesel wins by running higher r
    print(f"same r = 10: Otto {otto_eff(10):.4f}, Diesel (rc 2) {diesel_eff(10, 2):.4f}")
```

:::exercise Matching a diesel
What compression ratio would an Otto cycle need to match the Diesel's 0.6313? Why can't a petrol engine simply use it?
---solution---
1. $1 - r^{1-k} = 0.6313 \Rightarrow r = (1 - 0.6313)^{1/(1-k)} = 0.3687^{-2.502} = 12.14$.
2. That's at the edge of what petrol engines tolerate. Premium fuels and direct injection allow about 13, but in a premixed charge the unburnt end gas would auto-ignite (knock) at higher ratios, so real petrol engines run lower.
3. Real engine efficiencies are well below air-standard values: about 35–40 % for petrol and 45–50 % for large diesels.
:::
