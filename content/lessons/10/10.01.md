Thermodynamics is the science of energy and its conversions: fuel into motion in a scooter engine, electricity into heat in a heat pump, falling water into electricity in an Alpine power station. Its first rule of method is to say exactly **what** you're analysing. Draw a boundary around it, decide what can cross that boundary, and describe what's inside by a few numbers. Get this step wrong and every equation afterwards will be wrong too.

## Systems

- A **closed system** contains a fixed mass. Energy can cross its boundary as heat or work, but matter can't. Gas in a piston-cylinder is the classic example; the boundary may move.
- An **open system** or **control volume** has mass flowing in and out: a turbine, a pump, a nozzle, a heat exchanger.
- An **isolated system** exchanges nothing at all with its surroundings.

## Properties and states

A **property** is any measurable characteristic: pressure $p$, temperature $T$, specific volume $v = V/m$, internal energy $u$, enthalpy $h$, entropy $s$. **Intensive** properties don't depend on size ($p$, $T$, $v$); **extensive** ones do ($V$, $U$, $m$). Dividing an extensive property by mass gives a **specific** property.

The **state** is the condition described by the full set of properties. A **process** takes a system from one state to another.

## The state postulate

For a simple compressible substance (no electric, magnetic or surface effects), **two independent intensive properties fix the state**. Everything else follows from the equation of state and property relations. For an ideal gas,

$$
pv = RT ,
$$

so $p$ and $T$ give $v$. Specifying a third property over-determines the state: it must agree with the first two or the data are inconsistent. (Inside the two-phase region $p$ and $T$ are not independent, 10.06.)

Thermodynamic properties depend only on the state, not on how you got there. Heat and work are **not** properties: they depend on the path (10.03).

:::example Air as a state object
Air as an ideal gas: $R = 287$ J/(kg K), $c_p = 1005$ J/(kg K).

1. $p = 101.325$ kPa, $T = 288.15$ K: $v = 287\cdot288.15/101325 = 0.81618$ m³/kg, so $\rho = 1.2252$ kg/m³, the standard sea-level air density.
2. Specifying $T$ and $v$ instead gives back the same pressure.
3. Specifying $p$, $T$ and $v = 0.9$ m³/kg is rejected: $pv = 91\,192$ J/kg but $RT = 82\,699$ J/kg.
4. Specifying only $T$ is rejected: one property doesn't fix a state.
5. At 2 MPa and 700 K, with reference 298.15 K: $h = 1005\,(700 - 298.15) = 403.86$ kJ/kg, and $h - u = R\,\Delta T$, consistent with $h = u + pv$.
:::

```python file=state.py
"""A thermodynamic state as an object: give exactly two independent properties of an ideal gas and it works out the rest, refusing inconsistent or over-specified input."""
import math

R_AIR, CP_AIR = 287.0, 1005.0           # J/(kg K)
CV_AIR = CP_AIR - R_AIR
T_REF, P_REF = 298.15, 101325.0         # reference state for entropy (s = 0)


class StateError(ValueError):
    pass


class State:
    """Simple compressible ideal gas. Accepts any two of p (Pa), T (K), v (m^3/kg); a third must agree."""

    def __init__(self, p=None, T=None, v=None, R=R_AIR, cp=CP_AIR, rtol=1e-9):
        given = {k: x for k, x in (("p", p), ("T", T), ("v", v)) if x is not None}
        if len(given) < 2:
            raise StateError("state postulate: need two independent intensive properties")
        if any(x <= 0 for x in given.values()):
            raise StateError("p, T and v must be positive")
        self.R, self.cp, self.cv = R, cp, cp - R
        if p is None: p = R * T / v
        if T is None: T = p * v / R
        if v is None: v = R * T / p
        if abs(p * v - R * T) > rtol * R * T:
            raise StateError(f"over-specified and inconsistent: pv = {p*v:.6g} but RT = {R*T:.6g}")
        self.p, self.T, self.v = p, T, v

    @property
    def rho(self): return 1 / self.v
    @property
    def u(self): return self.cv * (self.T - T_REF)
    @property
    def h(self): return self.cp * (self.T - T_REF)
    @property
    def s(self): return self.cp * math.log(self.T / T_REF) - self.R * math.log(self.p / P_REF)

    def __repr__(self):
        return f"State(p={self.p/1e3:.2f} kPa, T={self.T:.2f} K, v={self.v:.5f} m3/kg)"


if __name__ == "__main__":
    a = State(p=101325, T=288.15)
    print(a, f"rho = {a.rho:.4f} kg/m^3")
    assert abs(a.rho - 1.2252) < 1e-3
    b = State(T=288.15, v=a.v)            # any two give the same state
    assert abs(b.p - a.p) < 1e-6
    c = State(p=2e6, T=700.0)
    print(c, f"h = {c.h/1e3:.2f} kJ/kg, s = {c.s:.2f} J/(kg K)")
    assert abs(c.h - c.u - c.R * (c.T - T_REF)) < 1e-9     # h = u + pv up to the reference constant
    try:
        State(p=101325, T=288.15, v=0.9)
    except StateError as e:
        print("rejected:", e)
    else:
        raise AssertionError("inconsistent state accepted")
    try:
        State(T=300.0)
    except StateError as e:
        print("rejected:", e)
    State(p=101325, T=288.15, v=a.v)       # consistent over-specification is accepted
```

:::exercise Helium in a balloon
A party balloon holds helium ($R = 2077$ J/(kg K)) at 103 kPa and 25 °C, volume 15 L. Find its specific volume, density and mass.
---solution---
1. $v = RT/p = 2077\cdot298.15/103000 = 6.012$ m³/kg.
2. $\rho = 1/v = 0.1663$ kg/m³.
3. $m = \rho V = 0.1663\cdot0.015 = 2.49$ g.
:::
