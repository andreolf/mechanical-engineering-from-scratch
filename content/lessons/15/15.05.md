A gear on a shaft has to pass torque without slipping. There are three classic ways: a **key** in a slot, a **spline** (many keys machined into the shaft), or a **press fit**, where the hub bore is made slightly smaller than the shaft and friction does the work. The press fit has no slot to weaken the shaft, but its capacity depends entirely on the contact pressure, and that comes from thick-cylinder elasticity.

## Keys and splines

A parallel key of width $w$, height $h$ and length $L$ on a shaft of diameter $d$ carries the force $F = 2T/d$ at the shaft surface. Two checks:

$$
\tau = \frac{2T}{d\,w\,L} \ \ \text{(shear across the key)}, \qquad \sigma_c = \frac{4T}{d\,h\,L} \ \ \text{(crushing on half the key height)} .
$$

For a square key ($w = h$) the crushing stress is twice the shear stress. The key is meant to be the weak link: it is cheap to replace, and it protects the shaft and hub. A spline spreads the same torque over many teeth, so it is shorter for the same torque and lets a hub slide axially, as on a gearbox selector or a bike's freehub body.

## Press fits from Lamé

A hub (bore $R$, outer radius $r_o$) is forced onto a solid shaft of radius $R + \delta$, where $\delta$ is the **radial interference**. Both parts are thick cylinders. Lamé's solution gives the radial displacement of each under the interface pressure $p$; the hub bore must grow and the shaft shrink by a total of $\delta$:

$$
\delta = pR\left[\frac{1}{E_o}\left(\frac{r_o^2 + R^2}{r_o^2 - R^2} + \nu_o\right) + \frac{1}{E_i}\left(1 - \nu_i\right)\right] .
$$

For the same material on both sides this simplifies to

$$
p = \frac{E\,\delta\,(r_o^2 - R^2)}{2R\,r_o^2} .
$$

Friction then gives the torque and axial capacity, and the hub bore carries the largest hoop stress:

$$
T = 2\pi R^2 L\,\mu\,p, \qquad F_{\text{axial}} = 2\pi R L\,\mu\,p, \qquad \sigma_{t,\text{bore}} = p\,\frac{r_o^2 + R^2}{r_o^2 - R^2} .
$$

Assumptions: plane stress, both parts elastic, hub length equal to the fit length, and a friction coefficient around 0.1 to 0.2 for dry steel (it varies a lot, so press fits are rated conservatively). The code checks Lamé against an independent finite-difference solution of the radial displacement equation $u'' + u'/r - u/r^2 = 0$.

:::widget pressfit
Radial stress (cyan) and hoop stress (lime) through the shaft and hub. More interference means more grip and more hoop stress.
:::

:::example A scooter gear pressed on a 20 mm shaft
Steel hub, outer diameter 60 mm, length 25 mm, on a 20 mm steel shaft; diametral interference 20 μm (radial $\delta = 0.010$ mm); $E = 207$ GPa, $\mu = 0.15$.

1. $p = 207\,000\cdot0.010\cdot(900 - 100)/(2\cdot10\cdot900) = 92.0$ MPa. The finite-difference solution agrees to better than 0.01%.
2. Torque capacity $T = 2\pi\cdot10^2\cdot25\cdot0.15\cdot92.0 = 216.8$ N·m; push-out force 21.68 kN.
3. Hoop stress at the hub bore: $92.0\cdot1000/800 = 115.0$ MPa, comfortably elastic for steel.
4. A 6 × 6 mm key, 25 mm long, carrying 100 N·m instead: shear $2\cdot100\,000/(20\cdot6\cdot25) = 66.7$ MPa, crushing 133.3 MPa.
:::

```python file=pressfit.py
"""Press fit of a hub on a solid shaft: contact pressure from Lame's thick-cylinder solution, checked against a finite-difference solution of the radial displacement equation, then torque capacity and a key for comparison."""
import math
import numpy as np


def lame_pressure(delta_r, R, ro, Eo, nuo, Ei, nui, ri=0.0):
    """Interface pressure (MPa) for radial interference delta_r (mm) between a hub (outer radius ro) and a shaft (bore ri)."""
    hub = ((ro**2 + R**2) / (ro**2 - R**2) + nuo) / Eo
    shaft = ((R**2 + ri**2) / (R**2 - ri**2) - nui) / Ei
    return delta_r / (R * (hub + shaft))


def fd_radial_displacement(a, b, E, nu, pa, pb, n=4001):
    """Plane stress annulus a <= r <= b (a may be 0) with pressures pa inside and pb outside.
    Solves u'' + u'/r - u/r^2 = 0 by central differences; returns u at r = a and r = b."""
    if a == 0:
        a_eff = b * 1e-6  # tiny hole replaced by the symmetry condition u(0) = 0
    else:
        a_eff = a
    r = np.linspace(a_eff, b, n)
    h = r[1] - r[0]
    A = np.zeros((n, n)); rhs = np.zeros(n)
    for k in range(1, n - 1):
        A[k, k - 1] = 1 / h**2 - 1 / (2 * h * r[k])
        A[k, k] = -2 / h**2 - 1 / r[k] ** 2
        A[k, k + 1] = 1 / h**2 + 1 / (2 * h * r[k])
    c = E / (1 - nu**2)
    # sigma_r = c (u' + nu u / r), second-order one-sided differences at the ends
    def bc(row, k, sign, p):
        if sign > 0:
            A[row, k], A[row, k + 1], A[row, k + 2] = -1.5 / h, 2 / h, -0.5 / h
        else:
            A[row, k], A[row, k - 1], A[row, k - 2] = 1.5 / h, -2 / h, 0.5 / h
        A[row, k] += nu / r[k]
        rhs[row] = -p / c
    if a == 0:
        A[0, 0] = 1.0; rhs[0] = 0.0
    else:
        bc(0, 0, +1, pa)
    bc(n - 1, n - 1, -1, pb)
    u = np.linalg.solve(A, rhs)
    return u[0], u[-1]


def fd_pressure(delta_r, R, ro, E, nu):
    """Unit pressure gives the hub bore growth and shaft shrinkage; the response is linear, so scale to close the gap."""
    hub_in, _ = fd_radial_displacement(R, ro, E, nu, 1.0, 0.0)
    _, shaft_out = fd_radial_displacement(0.0, R, E, nu, 0.0, 1.0)
    return delta_r / (hub_in - shaft_out)


if __name__ == "__main__":
    # scooter gear hub: steel, 20 mm shaft, 60 mm hub, 25 mm long, 20 um diametral interference
    E, nu, R, ro, L, mu = 207e3, 0.29, 10.0, 30.0, 25.0, 0.15
    delta_r = 0.010
    p = lame_pressure(delta_r, R, ro, E, nu, E, nu)
    closed = E * delta_r * (ro**2 - R**2) / (2 * R * ro**2)  # same material, solid shaft
    pf = fd_pressure(delta_r, R, ro, E, nu)
    print(f"contact pressure: Lame {p:.3f} MPa, same-material formula {closed:.3f}, finite differences {pf:.3f}")
    assert abs(p - closed) < 1e-9 and abs(pf / p - 1) < 1e-4
    T = 2 * math.pi * R**2 * L * mu * p
    F = 2 * math.pi * R * L * mu * p
    hoop = p * (ro**2 + R**2) / (ro**2 - R**2)
    print(f"torque capacity {T/1000:.1f} N m, push-out force {F/1000:.2f} kN, hub bore hoop stress {hoop:.1f} MPa")
    assert abs(T / 1000 - 216.8) < 0.1
    # a 6 x 6 mm parallel key, 25 mm long, for 100 N m
    Tk, w, hk = 100e3, 6.0, 6.0
    tau = 2 * Tk / (2 * R * w * L)
    crush = 4 * Tk / (2 * R * hk * L)
    print(f"key: shear {tau:.1f} MPa, bearing (crushing) {crush:.1f} MPa")
    assert abs(crush - 2 * tau) < 1e-9
```

:::exercise Using a standard fit
The same hub uses a 20 H7/s6 fit. From the ISO tables, the hole is 0 to +21 μm and the s6 shaft is +35 to +48 μm. Find the range of contact pressure and torque capacity, and the largest hub hoop stress.
---solution---
1. Diametral interference from $35 - 21 = 14$ μm to $48 - 0 = 48$ μm, so radial 7 to 24 μm.
2. $p = 207\,000\cdot800/18\,000 \cdot \delta = 9200\,\delta$: from 64.4 to 220.8 MPa.
3. Torque from 151.7 N·m (loosest) to 520.2 N·m (tightest). Design on the loosest: 151.7 N·m.
4. Largest hoop stress $220.8\cdot1.25 = 276.0$ MPa, still below the yield strength of a medium-carbon steel hub, but worth checking.
:::
