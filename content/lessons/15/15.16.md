Analysis asks: given a linkage, how does it move? **Synthesis** asks the reverse: given the motion I want, what linkage produces it? For the four-bar linkage there is a remarkably neat answer when the goal is a **function generator**, where the output rocker angle $\psi$ must follow the input crank angle $\phi$ at chosen points.

## The Freudenstein equation

Put the ground pivots at the origin and at $(d, 0)$. The crank of length $a$ ends at $A = a(\cos\phi, \sin\phi)$; the rocker of length $c$ ends at $B = (d, 0) + c(\cos\psi, \sin\psi)$. The coupler is rigid, $|B - A| = b$. Expanding the square and dividing by $2ac$ gives the **Freudenstein equation**:

$$
K_1\cos\psi - K_2\cos\phi + K_3 = \cos(\phi - \psi), \qquad K_1 = \frac{d}{a},\ \ K_2 = \frac{d}{c},\ \ K_3 = \frac{a^2 - b^2 + c^2 + d^2}{2ac} .
$$

It is **linear in the three unknowns** $K_1, K_2, K_3$. So three desired pairs $(\phi_j, \psi_j)$, the **precision points**, give a 3 × 3 linear system. Solve it, and the link lengths follow: $a = d/K_1$, $c = d/K_2$, $b^2 = a^2 + c^2 + d^2 - 2acK_3$. The ground length $d$ just sets the scale.

Three warnings, all checked in the code:

1. A negative $a$ or $c$ means that link points the other way; a negative $b^2$ means no linkage exists. Choose different precision points.
2. A four-bar has **two assembly branches** (open and crossed). The synthesized linkage passes the precision points on one of them only, and it cannot jump between branches without being taken apart.
3. Between the precision points the function is only approximated. Spacing the points well (Chebyshev spacing) minimises the error.

The **Grashof condition** $s + l \le p + q$ (shortest plus longest at most the sum of the other two) tells you whether some link can rotate fully. With the shortest link as the crank, the result is a **crank-rocker**, like a windscreen-wiper drive.

:::widget linkdesign
Move the three target rocker angles. The linkage is re-synthesized and drawn at the middle precision point.
:::

:::example A wiper-style drive
Targets: crank at 40°, 70°, 100° should put the rocker at 70°, 80°, 95°. Ground $d = 100$ mm.

1. The linear system gives $K_1 = 2.3744$, $K_2 = 1.2230$, $K_3 = 0.9908$.
2. So $a = 100/2.3744 = 42.115$ mm, $c = 100/1.2230 = 81.768$ mm, and $b = 107.870$ mm.
3. Solving the assembled linkage by circle intersection gives exactly 70.000000°, 80.000000° and 95.000000° at the three crank angles on one branch; the other branch misses by more than 2 rad.
4. Grashof: $42.1 + 107.9 = 150.0 \le 81.8 + 100 = 181.8$, and the crank is the shortest link, so it can turn fully. Over a full turn the rocker swings between 69.19° and 139.11°.
:::

```python file=linkage.py
"""Four-bar linkage synthesis with the Freudenstein equation: three input-output angle pairs give the link lengths; the assembled linkage is then solved by circle intersection and checked against the targets."""
import math
import numpy as np


def synthesize(pairs, d=1.0):
    """pairs: [(phi, psi)] in radians. K1 cos(psi) - K2 cos(phi) + K3 = cos(phi - psi)."""
    A = np.array([[math.cos(ps), -math.cos(ph), 1.0] for ph, ps in pairs])
    rhs = np.array([math.cos(ph - ps) for ph, ps in pairs])
    K1, K2, K3 = np.linalg.solve(A, rhs)
    a, c = d / K1, d / K2
    b2 = a * a + c * c + d * d - 2 * a * c * K3
    if b2 <= 0:
        raise ValueError("no real coupler length")
    return a, math.sqrt(b2), c, d


def output_angle(a, b, c, d, phi, branch):
    """Rocker angle for crank angle phi: intersect the circle of radius b about the crank pin with radius c about (d, 0)."""
    A = np.array([a * math.cos(phi), a * math.sin(phi)])
    O = np.array([d, 0.0])
    D = np.linalg.norm(O - A)
    if D > b + abs(c) or D < abs(b - abs(c)):
        return None
    x = (b * b - c * c + D * D) / (2 * D)
    h = math.sqrt(max(b * b - x * x, 0.0))
    u = (O - A) / D
    n = np.array([-u[1], u[0]])
    B = A + x * u + branch * h * n
    return math.atan2(B[1] - O[1], B[0] - O[0]) if c > 0 else math.atan2(O[1] - B[1], O[0] - B[0])


def grashof(lengths):
    s, *mid, l = sorted(map(abs, lengths))
    return s + l <= sum(mid)


if __name__ == "__main__":
    deg = math.pi / 180
    # a wiper-style drive: crank at 40, 70, 100 degrees should put the rocker at 70, 80, 95 degrees
    targets = [(40 * deg, 70 * deg), (70 * deg, 80 * deg), (100 * deg, 95 * deg)]
    a, b, c, d = synthesize(targets, d=100.0)
    print(f"crank a = {a:.3f} mm, coupler b = {b:.3f} mm, rocker c = {c:.3f} mm, ground d = {d:.1f} mm; Grashof: {grashof([a, b, c, d])}")
    for branch in (+1, -1):
        errs = []
        for ph, ps in targets:
            out = output_angle(a, b, c, d, ph, branch)
            errs.append(None if out is None else abs((out - ps + math.pi) % (2 * math.pi) - math.pi))
        print(f"branch {branch:+d}: errors {['%.2e' % e if e is not None else 'none' for e in errs]}")
        if all(e is not None and e < 1e-9 for e in errs):
            good = branch
    for ph, ps in targets:
        print(f"phi {ph/deg:.0f} deg -> psi {output_angle(a, b, c, d, ph, good)/deg:.6f} deg (target {ps/deg:.0f})")
        assert abs(output_angle(a, b, c, d, ph, good) - ps) < 1e-9
    assert min(a, b, c, d) == a and grashof([a, b, c, d])  # shortest link is the crank: it can turn fully
    sweep = [output_angle(a, b, c, d, ph, good) for ph in np.linspace(0, 2 * math.pi, 3601)]
    assert all(x is not None for x in sweep)
    print(f"full crank turn: rocker swings between {min(sweep)/deg:.2f} and {max(sweep)/deg:.2f} deg")
```

:::exercise Check a design by hand
With $a = 42.115$, $b = 107.870$, $c = 81.768$ and $d = 100$ mm, verify the Freudenstein equation at $\phi = 70°$, $\psi = 80°$.
---solution---
1. $K_1 = 2.3744$, $K_2 = 1.2230$, $K_3 = (42.115^2 - 107.870^2 + 81.768^2 + 100^2)/(2\cdot42.115\cdot81.768) = 0.9908$.
2. Left side: $2.3744\cos80° - 1.2230\cos70° + 0.9908 = 0.4123 - 0.4183 + 0.9908 = 0.9848$.
3. Right side: $\cos(70° - 80°) = \cos10° = 0.9848$. They agree.
:::
