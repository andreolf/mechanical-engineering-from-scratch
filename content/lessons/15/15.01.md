Machine design is not one calculation. It is a loop: **define** the need, **generate** several concepts, **select** one, **analyse** it in detail, **test**, and go round again when something fails. Phase 15 is about the analysis tools for the machine elements every product is built from: shafts, bearings, gears, bolts, springs. Before any of that, though, someone has to pick the concept, and that choice is usually made with a **weighted decision matrix**.

## The weighted decision matrix

List the criteria that matter, give each an importance weight $w_j$, and score every concept $i$ against every criterion on the same scale (here 1 = poor to 5 = excellent). Normalise the weights so they sum to one, then

$$
T_i = \sum_j \hat w_j\, s_{ij}, \qquad \hat w_j = \frac{w_j}{\sum_k w_k} .
$$

The concept with the highest total wins. Two properties make this useful and also show its limits:

1. **Only the ratios of the weights matter.** Multiplying every weight by 7 changes nothing, because of the normalisation.
2. **Totals are linear in the weights.** If you raise one weight $\hat w_j$ from 0 to 1 while scaling the others down in proportion, each total moves along a straight line, so the point where two concepts swap is a single linear equation. That is a **sensitivity check**: if a small change in a weight flips the winner, the matrix has not really decided anything.

The scores are judgements, not measurements. The matrix makes those judgements explicit and easy to argue about, which is its real value.

:::example Choosing a drivetrain for a commuter bike
Four concepts are scored on cost, mass, efficiency, maintenance and gear range:

| Concept | Cost | Mass | Efficiency | Maintenance | Gear range |
|---|---|---|---|---|---|
| 1x derailleur | 4 | 5 | 5 | 2 | 4 |
| 8-speed hub | 3 | 2 | 3 | 4 | 3 |
| belt + hub | 1 | 2 | 3 | 5 | 3 |
| single speed | 5 | 5 | 5 | 4 | 1 |

A commuter in a wet, flat city gives importance points 25, 20, 15, 30, 10 (out of 100), so the weights are 0.25, 0.20, 0.15, 0.30, 0.10.

1. Single speed: $0.25\cdot5 + 0.20\cdot5 + 0.15\cdot5 + 0.30\cdot4 + 0.10\cdot1 = 4.30$.
2. 1x derailleur 3.75, 8-speed hub 3.10, belt + hub 2.90. Single speed wins.
3. Sensitivity: move to a hilly town and raise the gear-range weight $\lambda$, scaling the other four in proportion. With $\lambda = 0$ the totals are 4.667 (single speed) and 3.722 (derailleur); with $\lambda = 1$ they are 1 and 4. They cross where $0.944 = 3.944\,\lambda$, so $\lambda = 17/71 = 0.2394$. Above about 24% weight on gear range, the derailleur wins.
:::

```python file=decision.py
"""Weighted decision matrix for choosing a bike drivetrain: normalise the weights, score, rank, and find how far a weight can move before the winner changes."""
import numpy as np

CRITERIA = ["cost", "mass", "efficiency", "maintenance", "gear range"]
CONCEPTS = ["1x derailleur", "8-speed hub", "belt + hub", "single speed"]
# scores 1 (poor) to 5 (excellent); rows are concepts, columns are criteria
SCORES = np.array([
    [4, 5, 5, 2, 4],
    [3, 2, 3, 4, 3],
    [1, 2, 3, 5, 3],
    [5, 5, 5, 4, 1],
], float)


def normalise(raw):
    raw = np.asarray(raw, float)
    assert np.all(raw >= 0) and raw.sum() > 0
    return raw / raw.sum()


def totals(weights, scores=SCORES):
    return scores @ normalise(weights)


def ranking(weights, scores=SCORES):
    return list(np.argsort(-totals(weights, scores), kind="stable"))


def with_weight(weights, i, wi):
    """Set criterion i to weight wi (0..1) and scale the others so the total stays 1."""
    w = normalise(weights)
    rest = np.delete(np.arange(len(w)), i)
    out = w.copy()
    out[rest] = w[rest] * (1 - wi) / w[rest].sum()
    out[i] = wi
    return out


def switch_point(weights, i, n=20001):
    """Smallest weight on criterion i at which the winner changes (None if it never does)."""
    w0 = normalise(weights)
    first = ranking(w0)[0]
    for wi in np.linspace(0, 1, n):
        if wi <= w0[i]:
            continue
        if ranking(with_weight(w0, i, wi))[0] != first:
            return wi
    return None


if __name__ == "__main__":
    raw = [25, 20, 15, 30, 10]  # importance points out of 100: a commuter in a wet city
    w = normalise(raw)
    t = totals(raw)
    for k in ranking(raw):
        print(f"{CONCEPTS[k]:14s} {t[k]:.2f}")
    # the ranking is reproducible from the weights: a hand sum for the winner
    hand = sum(SCORES[3, j] * w[j] for j in range(5))
    assert abs(hand - t[3]) < 1e-12
    assert ranking(raw) == ranking(np.array(raw) * 7)  # only the ratios of the weights matter
    assert [CONCEPTS[k] for k in ranking(raw)] == ["single speed", "1x derailleur", "8-speed hub", "belt + hub"]
    # a hilly route: raise the weight on gear range until single speed loses
    ws = switch_point(raw, 4)
    print(f"single speed stops winning when gear range carries {ws:.4f} of the weight")
    # check the crossover by hand: totals are linear in the weight, so solve for equality
    a = with_weight(raw, 4, 0.0); b = with_weight(raw, 4, 1.0)
    ta, tb = SCORES @ a, SCORES @ b
    lam = [(ta[3] - ta[k]) / ((ta[3] - ta[k]) - (tb[3] - tb[k])) for k in range(3) if (tb[3] - tb[k]) < 0]
    exact = min(x for x in lam if x > w[4])
    print(f"exact crossover {exact:.4f}")
    assert abs(ws - exact) < 1e-4
```

:::exercise Doubling the cost weight
Keep the bike scores. Give cost 50 points and mass, efficiency, maintenance and gear range 20, 10, 10 and 10. What are the new totals for the single speed and the belt + hub, and does the winner change?
---solution---
1. Weights: 50, 20, 10, 10, 10 out of 100, so 0.5, 0.2, 0.1, 0.1, 0.1.
2. Single speed: $0.5\cdot5 + 0.2\cdot5 + 0.1\cdot5 + 0.1\cdot4 + 0.1\cdot1 = 4.50$.
3. Belt + hub: $0.5\cdot1 + 0.2\cdot2 + 0.1\cdot3 + 0.1\cdot5 + 0.1\cdot3 = 2.00$.
4. The 1x derailleur gets $2 + 1 + 0.5 + 0.2 + 0.4 = 4.10$. Single speed still wins, by a wider margin.
:::
