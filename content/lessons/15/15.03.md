No part is made exactly to size. A drawing that says "25 mm" really means "25 mm give or take something", and the designer chooses that something. Choose it too tight and the part is expensive; too loose and the bearing rattles or the gear will not press on. This lesson covers the two everyday tools: **ISO fits** for a shaft in a hole, and **stack-up analysis** for a chain of parts.

## ISO 286 fits

The **tolerance grade** IT sets the width of the band. ISO 286 builds it from a tolerance unit that grows slowly with size $D$ (the geometric mean of a size step, in mm):

$$
i = 0.45\,D^{1/3} + 0.001\,D \ \ \mu\text{m}, \qquad \text{IT6} = 10i,\ \ \text{IT7} = 16i,\ \ \text{IT8} = 25i .
$$

A **letter** sets the position of the band. In the common basic-hole system the hole is always H (lower deviation zero) and the shaft letter does the work: g sits below zero (clearance), h touches zero, k and n sit above zero (transition), p and s higher still (interference). The fundamental deviations also come from formulas, for example $e_s = -2.5\,D^{0.34}$ for g, $e_i = 0.6\,D^{1/3}$ for k and $e_i = 5\,D^{0.34}$ for n (μm), rounded to whole micrometres.

A fit is then described by its extreme clearances:

$$
c_{\max} = \text{hole}_{\max} - \text{shaft}_{\min}, \qquad c_{\min} = \text{hole}_{\min} - \text{shaft}_{\max} .
$$

Both positive: a **clearance** fit. Both negative: an **interference** fit. One of each: a **transition** fit, which may go together loose or tight.

## Stack-ups: worst case and root-sum-square

When parts sit end to end, their tolerances add. If a gap is $g = \sum_k s_k L_k$ with signs $s_k = \pm1$ and part tolerances $\pm t_k$:

$$
t_{\text{WC}} = \sum_k t_k, \qquad t_{\text{RSS}} = \sqrt{\textstyle\sum_k t_k^2} \le t_{\text{WC}} .
$$

**Worst case** guarantees assembly even if every part is at its limit in the bad direction. **Root-sum-square** assumes the errors are independent and each tolerance is $3\sigma$ of a normal distribution; then the gap's standard deviation is $t_{\text{RSS}}/3$ and 99.73% of assemblies land inside $\pm t_{\text{RSS}}$. With many parts, RSS is much narrower, because it is unlikely that all parts are off in the same direction at once.

:::example A 25 mm bearing seat and a bike hub stack
1. For 25 mm the size step is 18 to 30 mm, so $D = \sqrt{18\cdot30} = 23.24$ and $i = 1.308$ μm. IT6 = 13 μm and IT7 = 21 μm, the table values.
2. **25 H7/g6**: hole 0 to +21 μm; shaft $e_s = -2.5\cdot23.24^{0.34} = -7$, so −7 to −20 μm. Clearance from +7 to +41 μm: a sliding fit.
3. **25 H7/k6**: shaft +2 to +15 μm, so from 15 μm interference to 19 μm clearance: a transition fit, typical for a bearing inner ring that must be located but still removable.
4. A hub stack: housing 50.30 ± 0.10 mm minus two bearings 15.00 ± 0.05 and a spacer 20.00 ± 0.08. Nominal play 0.30 mm. Worst case ± 0.280 mm; RSS $\sqrt{0.1^2 + 0.05^2 + 0.08^2 + 0.05^2} = \pm0.146$ mm.
5. A million Monte Carlo assemblies (each tolerance = 3σ) give a play standard deviation of 0.0487 mm, equal to RSS/3, and 0.27% outside the RSS band, as predicted.
:::

```python file=fits.py
"""ISO 286 fits from the standard tolerance formulas, and a tolerance stack-up: worst case against root-sum-square against Monte Carlo."""
import math
import numpy as np

# ISO 286 size steps up to 120 mm; the formulas use the geometric mean of each step
STEPS = [3, 6, 10, 18, 30, 50, 80, 120]


def mean_size(d):
    lo = 0
    for hi in STEPS:
        if d <= hi:
            return math.sqrt(max(lo, 1) * hi)
        lo = hi
    raise ValueError("size above 120 mm not covered")


def tol_unit(d):
    D = mean_size(d)
    return 0.45 * D ** (1 / 3) + 0.001 * D  # micrometres


def IT(grade, d):
    k = {5: 7, 6: 10, 7: 16, 8: 25, 9: 40}[grade]
    return round(k * tol_unit(d))


def shaft_limits(letter, grade, d):
    """Upper and lower deviations of a shaft (micrometres) from the ISO fundamental-deviation formulas."""
    D, t = mean_size(d), IT(grade, d)
    if letter == "g":
        es = -round(2.5 * D ** 0.34); return es, es - t
    if letter == "f":
        es = -round(5.5 * D ** 0.41); return es, es - t
    if letter == "h":
        return 0, -t
    if letter == "k":
        ei = round(0.6 * D ** (1 / 3)); return ei + t, ei
    if letter == "n":
        ei = round(5 * D ** 0.34); return ei + t, ei
    raise ValueError(letter)


def fit(hole_grade, letter, shaft_grade, d):
    """Basic-hole fit: hole H (lower deviation 0). Returns (max clearance, min clearance) in micrometres; negative = interference."""
    H = IT(hole_grade, d)
    es, ei = shaft_limits(letter, shaft_grade, d)
    return H - ei, 0 - es


def stack(nominals, tols, signs):
    nom = sum(s * n for s, n in zip(signs, nominals))
    wc = sum(tols)
    rss = math.sqrt(sum(t * t for t in tols))
    return nom, wc, rss


if __name__ == "__main__":
    d = 25
    print(f"IT6 = {IT(6, d)} um, IT7 = {IT(7, d)} um for a {d} mm diameter")
    assert (IT(6, d), IT(7, d), IT(8, d)) == (13, 21, 33)  # the ISO 286 table values for 18-30 mm
    for letter in "gkn":
        cmax, cmin = fit(7, letter, 6, d)
        kind = "clearance" if cmin >= 0 else ("interference" if cmax <= 0 else "transition")
        print(f"25 H7/{letter}6: clearance from {cmin:+d} to {cmax:+d} um -> {kind}")
    assert shaft_limits("g", 6, d) == (-7, -20) and shaft_limits("k", 6, d) == (15, 2) and shaft_limits("n", 6, d) == (28, 15)
    assert fit(7, "g", 6, d) == (41, 7)
    # bike hub: housing between locknuts minus bearing, spacer, bearing gives the axial play
    nominals, tols, signs = [50.30, 15.00, 20.00, 15.00], [0.10, 0.05, 0.08, 0.05], [1, -1, -1, -1]
    nom, wc, rss = stack(nominals, tols, signs)
    print(f"gap {nom:.2f} mm, worst case +-{wc:.3f}, RSS +-{rss:.4f}")
    assert rss <= wc
    rng = np.random.default_rng(3)
    N = 1_000_000
    parts = [rng.normal(n, t / 3, N) for n, t in zip(nominals, tols)]  # each tolerance is 3 sigma
    gap = sum(s * x for s, x in zip(signs, parts))
    out = np.mean(np.abs(gap - nom) > rss)
    print(f"Monte Carlo: gap sigma {gap.std():.5f} (RSS/3 = {rss/3:.5f}), outside RSS band {100*out:.3f}%, outside worst case {100*np.mean(np.abs(gap-nom) > wc):.5f}%")
    assert abs(gap.std() - rss / 3) < 1e-3 and abs(out - 0.0027) < 0.0005
```

:::exercise A 50 mm shaft
For a 50 mm diameter (size step 30 to 50 mm), compute IT7 and the g6 shaft limits, and the clearance range of 50 H7/g6.
---solution---
1. $D = \sqrt{30\cdot50} = 38.73$, $i = 0.45\cdot38.73^{1/3} + 0.0387 = 1.561$ μm.
2. IT7 = $16i = 25$ μm; IT6 = $10i = 16$ μm.
3. g: $e_s = -2.5\cdot38.73^{0.34} = -8.66 \to -9$ μm, so the shaft is −9 to −25 μm.
4. Clearance from $0 - (-9) = 9$ μm to $25 - (-25) = 50$ μm.
:::
