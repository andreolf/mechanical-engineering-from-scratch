A planetary (epicyclic) gear set packs a large reduction into a small, coaxial package: a **sun** gear in the middle, several **planets** around it held by a **carrier**, and an internal **ring** gear outside. It is inside automatic car gearboxes, bicycle hub gears, e-bike hub motors and electric screwdrivers. Its trick is that it has two degrees of freedom: fix any one member (or drive two) and the third is determined.

## The Willis equation

Watch the set from the carrier. In that rotating frame the carrier is still, so the gears form an ordinary train: sun to planet to ring, with an internal mesh that keeps the direction. The ratio is $-z_s/z_r$. Converting the relative speeds back to absolute ones gives the **Willis equation**:

$$
\frac{\omega_r - \omega_c}{\omega_s - \omega_c} = -\frac{z_s}{z_r} .
$$

Three common cases:

| Fixed | Input | Output | Ratio $\omega_{\text{out}}/\omega_{\text{in}}$ |
|---|---|---|---|
| ring | sun | carrier | $z_s/(z_s + z_r)$ |
| sun | carrier | ring | $1 + z_s/z_r$ |
| sun | ring | carrier | $z_r/(z_s + z_r)$ |

Locking any two members together locks the whole set: ratio 1.

**Geometry and assembly.** With one module, the ring must satisfy $z_r = z_s + 2z_p$. Equally spaced planets fit only if $(z_s + z_r)/N$ is a whole number, where $N$ is the number of planets.

The code checks Willis independently: it solves the two rolling conditions (sun surface and ring surface move with the planet's pitch points) for the planet spin and the unknown member.

:::example A three-speed hub and an e-bike motor
1. A bike hub gear with $z_s = 18$, $z_p = 18$, $z_r = 54$ (54 = 18 + 2·18; (18 + 54)/3 = 24, so 3 or 4 planets fit, 5 do not).
2. Sun locked to the axle. **High gear**: the sprocket drives the carrier, the ring drives the hub: $1 + 18/54 = 4/3$, so the wheel turns 33.3% faster.
3. **Low gear**: the sprocket drives the ring, the carrier drives the hub: $54/72 = 3/4$, 25% slower. **Direct**: sprocket straight to the hub. These are the classic −25%, 0, +33% steps of a Sturmey-Archer AW-type hub, a total spread of $(4/3)/(3/4) = 1.778$.
4. The rolling-condition solver confirms, for example: with the sun still and the carrier at 1, the planets spin at 2 and the ring at 1.3333; with sun 2.5 and ring −1, the carrier turns at −0.125. Each case satisfies Willis to machine precision.
5. An e-bike hub motor: motor on the sun ($z_s = 14$), ring fixed ($z_r = 82$, planets 34): the carrier turns $14/96$ as fast, a reduction of $1 + 82/14 = 6.857 : 1$.
:::

```python file=planetary.py
"""Planetary gear set: the Willis equation, checked by solving the rolling-without-slip conditions at the two meshes, plus assembly conditions and the ratios of a three-speed bicycle hub."""
import numpy as np
from fractions import Fraction


def willis(zs, zr, ws=None, wr=None, wc=None):
    """(wr - wc)/(ws - wc) = -zs/zr. Give two speeds, get the third."""
    k = Fraction(zs, zr)
    if wc is None:
        return (wr + k * ws) / (1 + k)
    if wr is None:
        return wc - k * (ws - wc)
    return wc - (wr - wc) / k


def kinematics(zs, zp, zr, given, m=1.0):
    """Unknowns ws, wp (planet spin, absolute), wr, wc. Pitch-point velocities must match at sun-planet and planet-ring.
    given: dict with two of 'ws', 'wr', 'wc'. Returns all four speeds."""
    rs, rp, rr = m * zs / 2, m * zp / 2, m * zr / 2
    assert abs(rr - (rs + 2 * rp)) < 1e-12
    names = ["ws", "wp", "wr", "wc"]
    A, b = [], []
    # planet centre at radius rs + rp moves at wc (rs + rp); its contact with the sun is rp nearer the centre
    A.append([rs, rp, 0, -(rs + rp)]); b.append(0.0)    # sun surface speed = planet-centre speed - wp rp
    A.append([0, -rp, rr, -(rs + rp)]); b.append(0.0)   # ring surface speed = planet-centre speed + wp rp
    for k, v in given.items():
        row = [0.0] * 4; row[names.index(k)] = 1.0; A.append(row); b.append(float(v))
    sol = np.linalg.solve(np.array(A, float), np.array(b))
    return dict(zip(names, sol))


def can_assemble(zs, zp, zr, n_planets):
    return zr == zs + 2 * zp and (zs + zr) % n_planets == 0


if __name__ == "__main__":
    zs, zp, zr = 18, 18, 54
    assert can_assemble(zs, zp, zr, 3) and can_assemble(zs, zp, zr, 4) and not can_assemble(zs, zp, zr, 5)
    for given in ({"ws": 0, "wc": 1}, {"wr": 1, "ws": 0}, {"ws": 1, "wr": 0}, {"ws": 2.5, "wr": -1.0}):
        k = kinematics(zs, zp, zr, given)
        lhs = (k["wr"] - k["wc"]) / (k["ws"] - k["wc"])
        print(", ".join(f"{n} {v:+.4f}" for n, v in k.items()), f"-> Willis ratio {lhs:.6f}")
        assert abs(lhs + zs / zr) < 1e-12
    # three-speed hub: sun locked to the axle. High: carrier in, ring out. Low: ring in, carrier out.
    high = willis(zs, zr, ws=0, wc=1)
    low = willis(zs, zr, ws=0, wr=1)
    print(f"hub gears: low {float(low):.4f}, direct 1, high {float(high):.4f}; spread {float(high/low):.4f}")
    assert high == Fraction(4, 3) and low == Fraction(3, 4)
    # e-bike hub motor stage: motor on the sun, ring fixed, carrier drives the wheel
    zs2, zp2, zr2 = 14, 34, 82
    red = 1 / willis(zs2, zr2, ws=1, wr=0)
    print(f"hub motor reduction {float(red):.4f} : 1 = 1 + zr/zs")
    assert red == 1 + Fraction(zr2, zs2)
```

:::exercise A two-input case
In the 18-18-54 set, the sun turns at 300 rpm and the ring at 120 rpm in the same direction. How fast is the carrier, and how fast must the ring turn for the carrier to stand still?
---solution---
1. Solve Willis for the carrier: $\omega_c = (\omega_r + k\omega_s)/(1 + k)$ with $k = 18/54 = 1/3$.
2. $\omega_c = (120 + 100)/(4/3) = 165$ rpm.
3. Carrier still: $\omega_r/\omega_s = -1/3$, so the ring turns at −100 rpm, opposite to the sun. The set is then an ordinary train.
:::
