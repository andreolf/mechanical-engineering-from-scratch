Most steel structures, from bicycle frames to trailer hitches, are held together by welds. The commonest is the **fillet weld**: a triangular bead laid in the corner between two plates. It is analysed with a simple and deliberately conservative idea: whatever the actual load direction, treat the stress on the weld's narrowest section, the **throat**, as shear.

## The throat and the weld as a line

A fillet weld with equal legs $h$ has a throat $t = h\cos45° = 0.707h$. A weld of length $L$ carrying a force $F$ along it has an average throat shear stress

$$
\tau = \frac{F}{0.707\,h\,L} .
$$

For a **group** of welds loaded eccentrically, treat each weld as a line and use the same steps as a bolt group:

1. Find the centroid of the weld lines.
2. **Direct shear**: $\tau' = F/A$ with $A = 0.707h\sum L_i$, in the direction of the load.
3. **Torsional shear**: the moment $M = F e$ about the centroid gives $\tau'' = M r/J$, perpendicular to the radius $r$, with $J = 0.707\,h\,J_u$ and $J_u$ the **unit polar moment** of the lines. For two parallel lines of length $b$ a distance $d$ apart, $J_u = b(3d^2 + b^2)/6$.
4. Add the two vectorially and find the largest magnitude, usually at the point farthest from the centroid.

Every stress scales as $1/h$, so the leg size follows directly from an allowable stress. A common static allowable is $\tau_{\text{all}} = 0.3\,S_{ut}$ of the electrode (AISC), for example $0.3\cdot482 = 145$ MPa for an E70 electrode.

Assumptions: the base metal is stronger than the weld, stresses spread uniformly along each line, and residual stresses and fatigue are ignored. Fatigue is where welds really fail: the toe of a weld is a severe notch, and fatigue design uses separate detail categories.

:::example A trailer hitch bracket
A plate is welded to a post with two horizontal fillet welds, each 50 mm long and 80 mm apart. A load of 10 kN acts downwards 150 mm from the centroid of the welds.

1. $J_u = 50(3\cdot80^2 + 50^2)/6 = 180\,833$ mm³. With $h = 6$ mm: $t = 4.242$ mm, $A = 4.242\cdot100 = 424.2$ mm², $J = 767\,095$ mm⁴.
2. Direct shear $10\,000/424.2 = 23.57$ MPa, downwards.
3. $M = 10\,000\cdot150 = 1.5\times10^6$ N·mm. At the far corner $(25, 40)$ mm from the centroid: horizontal torsional component $1.5\times10^6\cdot40/767\,095 = 78.22$ MPa, vertical $1.5\times10^6\cdot25/767\,095 = 48.89$ MPa.
4. Resultant $\sqrt{78.22^2 + (23.57 + 48.89)^2} = 106.6$ MPa. Summing 8000 small weld elements gives the same value and the same location.
5. With $h$ = 4, 6 and 8 mm the stress is 159.9, 106.6 and 80.0 MPa: exactly $1/h$. For 145 MPa the leg must be at least $4\cdot159.9/145 = 4.41$ mm, so specify 5 mm.
:::

```python file=weld.py
"""Fillet weld group under eccentric load: welds treated as lines, direct and torsional shear on the throat, checked by summing small weld elements."""
import math
import numpy as np


def weld_elements(segments, n=4000):
    """segments: list of ((x0, y0), (x1, y1)) weld lines. Returns element midpoints and lengths."""
    pts, lens = [], []
    for (x0, y0), (x1, y1) in segments:
        t = (np.arange(n) + 0.5) / n
        pts.append(np.column_stack([x0 + (x1 - x0) * t, y0 + (y1 - y0) * t]))
        lens.append(np.full(n, math.hypot(x1 - x0, y1 - y0) / n))
    return np.vstack(pts), np.concatenate(lens)


def weld_group_stress(segments, h, F, load_point):
    """Vertical downward load F at load_point. Returns the max shear stress on the throat and where it occurs."""
    P, dl = weld_elements(segments)
    t = 0.707 * h
    A = t * dl.sum()
    c = (P * dl[:, None]).sum(0) / dl.sum()                       # weld group centroid
    r = P - c
    J = t * (dl * (r**2).sum(1)).sum()                             # polar moment of the throat area
    M = F * (load_point[0] - c[0])                                 # moment of the downward force about the centroid
    direct = np.array([0.0, -F / A])
    # torsional shear is perpendicular to r, magnitude M r / J; clockwise for a load to the right
    tors = (M / J) * np.column_stack([r[:, 1], -r[:, 0]])
    tau = np.linalg.norm(direct + tors, axis=1)
    k = int(np.argmax(tau))
    return tau[k], P[k], A, J, c


if __name__ == "__main__":
    # trailer hitch bracket: two horizontal 50 mm fillet welds, 80 mm apart, load 10 kN at 150 mm from the weld centroid
    b, d, F = 50.0, 80.0, 10000.0
    segs = [((0, d / 2), (b, d / 2)), ((0, -d / 2), (b, -d / 2))]
    load = (b / 2 + 150.0, 0.0)
    for h in (4.0, 6.0, 8.0):
        tau, where, A, J, c = weld_group_stress(segs, h, F, load)
        # textbook line formulas: A = 0.707 h (2b), Ju = b (3 d^2 + b^2)/6, J = 0.707 h Ju
        t = 0.707 * h
        Ju = b * (3 * d**2 + b**2) / 6
        rmax = math.hypot(b / 2, d / 2)
        M = F * 150.0
        tx = M * (d / 2) / (t * Ju)                      # horizontal component at the far corner
        ty = F / (t * 2 * b) + M * (b / 2) / (t * Ju)    # vertical: direct plus torsion
        hand = math.hypot(tx, ty)
        print(f"h = {h} mm: throat {t:.3f} mm, J = {J:.0f} mm^4 (line formula {t*Ju:.0f}), max shear {tau:.1f} MPa at ({where[0]:.1f}, {where[1]:.1f}); hand {hand:.1f} MPa")
        assert abs(J / (t * Ju) - 1) < 1e-6 and abs(tau / hand - 1) < 1e-3
        if h == 4.0:
            tau4 = tau
        else:
            assert abs(tau * h - tau4 * 4.0) < 1e-3 * tau4 * 4  # stress is inversely proportional to the throat
    # size for an allowable shear of 145 MPa (0.3 x 482 MPa, E70 electrode)
    h_req = 4.0 * tau4 / 145.0
    print(f"required leg size for 145 MPa: {h_req:.2f} mm -> next standard size up")
```

:::exercise A single weld in tension
A 10 mm thick bar is joined to a plate by two side fillet welds, 6 mm leg, each 80 mm long, carrying 120 kN along the welds. What is the throat shear stress? What length of each weld would bring it to 145 MPa?
---solution---
1. $A = 0.707\cdot6\cdot160 = 678.7$ mm².
2. $\tau = 120\,000/678.7 = 176.8$ MPa, too high.
3. Required total length $120\,000/(0.707\cdot6\cdot145) = 195.1$ mm, so about 98 mm per weld; round up to 100 mm.
:::
