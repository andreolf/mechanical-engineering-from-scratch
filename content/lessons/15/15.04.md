A rotating shaft carrying a gear sees its bending stress go from tension to compression once per revolution, millions of times. So a shaft is almost always designed for **fatigue**, not for a single static load. The standard recipe combines the bending moment diagram, stress concentration, the Marin endurance limit and the Goodman line into one diameter formula.

## Loads on a rotating shaft

For a shaft supported in two bearings with point loads, statics gives the reactions and the bending moment $M(x)$, which peaks under a load. Because the shaft rotates while the load direction stays fixed in space, a fibre on the surface sees **fully reversed** bending: alternating moment $M_a = M$, mean $M_m = 0$. The torque from the gear is usually steady: $T_m = T$, $T_a = 0$.

## The DE-Goodman diameter

Combine bending and torsion with the distortion-energy (von Mises) equivalent stress, apply the fatigue stress concentration factors $K_f$ (bending) and $K_{fs}$ (torsion) at the shoulder, and put the alternating and mean parts on the Goodman line $\sigma_a'/S_e + \sigma_m'/S_{ut} = 1/n$. Solving for $d$:

$$
d = \left[\frac{16n}{\pi}\left(\frac{\sqrt{4(K_f M_a)^2 + 3(K_{fs}T_a)^2}}{S_e} + \frac{\sqrt{4(K_f M_m)^2 + 3(K_{fs}T_m)^2}}{S_{ut}}\right)\right]^{1/3} .
$$

The endurance limit itself depends on the diameter through the size factor $k_b = 1.24\,d^{-0.107}$ (for 2.8 to 51 mm), with $S_e = k_a k_b\, 0.5\,S_{ut}$ and the machined-surface factor $k_a = 4.51\,S_{ut}^{-0.265}$. So the formula is solved by **fixed-point iteration**: guess $d$, compute $S_e$, compute a new $d$, repeat. It converges in a handful of steps because $k_b$ varies slowly.

Assumptions: steady torque, fully reversed bending, a single critical section, Goodman (slightly conservative compared with test data), and $K_f$ values taken as given. In a real design you check every shoulder and keyway, and the deflection and critical speed too.

:::widget shaftload
Move the gear along the shaft. The curve is the bending moment; the output is the DE-Goodman diameter at the peak.
:::

:::example A gearbox countershaft
Bearings 300 mm apart; a gear force of 2000 N at 100 mm and a pulley pull of 1200 N at 220 mm, both in the same plane. Steady torque 150 N·m. 1045 cold-drawn steel, $S_{ut} = 630$ MPa; shoulder $K_f = 1.7$, $K_{fs} = 1.5$; target $n = 2$.

1. Reactions: $R_2 = (2000\cdot100 + 1200\cdot220)/300 = 1546.7$ N, $R_1 = 1653.3$ N.
2. Peak moment under the gear: $M = 1653.3\cdot0.1 = 165.33$ N·m (at the pulley it is $1546.7\cdot0.08 = 123.7$ N·m).
3. $k_a = 4.51\cdot630^{-0.265} = 0.817$. After iterating, $d = 31.84$ mm, $k_b = 0.856$, $S_e = 220.4$ MPa.
4. Bending term $2\cdot1.7\cdot165\,333/220.4 = 2550.2$; torsion term $\sqrt3\cdot1.5\cdot150\,000/630 = 618.6$. Then $d = [10.186\cdot3168.8]^{1/3} = 31.84$ mm.
5. Back-check: $\sigma_a' = 88.70$ MPa, $\sigma_m' = 61.49$ MPa, and $1/(88.70/220.4 + 61.49/630) = 2.000$.
6. For $n$ = 1.5, 2, 2.5, 3 the diameter is 28.85, 31.84, 34.37, 36.59 mm: a larger safety factor always needs a larger shaft, roughly as $n^{1/3}$. A designer would pick the next standard size, 32 or 35 mm.
:::

```python file=shaft.py
"""Shaft diameter from combined bending and torsion with the DE-Goodman fatigue criterion, including the Marin factors and the size factor iteration."""
import math
import numpy as np


def moment_diagram(L, loads, n=3001):
    """Simply supported shaft of length L with point loads [(x, F)]: reactions and bending moment along x."""
    R2 = sum(F * a for a, F in loads) / L
    R1 = sum(F for _, F in loads) - R2
    x = np.linspace(0, L, n)
    M = R1 * x - sum(F * np.clip(x - a, 0, None) for a, F in loads)
    return R1, R2, x, M


def endurance_limit(Sut, d, ka_a=4.51, ka_b=-0.265, kc=1.0, kd=1.0, ke=1.0):
    """Marin: machined surface, rotating bending size factor kb, MPa and mm."""
    Se_prime = 0.5 * Sut if Sut <= 1400 else 700.0
    ka = ka_a * Sut ** ka_b
    kb = 1.24 * d ** -0.107 if d <= 51 else 1.51 * d ** -0.157
    return ka * kb * kc * kd * ke * Se_prime


def de_goodman_d(n, Sut, Ma, Tm, Kf, Kfs, Mm=0.0, Ta=0.0):
    """Diameter (mm) for safety factor n; moments in N mm, stresses in MPa. Iterates the size factor."""
    d = 25.0
    for _ in range(100):
        Se = endurance_limit(Sut, d)
        A = math.sqrt(4 * (Kf * Ma) ** 2 + 3 * (Kfs * Ta) ** 2)
        B = math.sqrt(4 * (Kf * Mm) ** 2 + 3 * (Kfs * Tm) ** 2)
        d_new = (16 * n / math.pi * (A / Se + B / Sut)) ** (1 / 3)
        if abs(d_new - d) < 1e-10:
            break
        d = d_new
    return d


def goodman_n(d, Sut, Ma, Tm, Kf, Kfs):
    """Back-check: von Mises alternating and mean stresses, then 1/n = sa/Se + sm/Sut."""
    sa = 32 * Kf * Ma / (math.pi * d ** 3)
    tm = 16 * Kfs * Tm / (math.pi * d ** 3)
    sm = math.sqrt(3) * tm
    return 1 / (sa / endurance_limit(Sut, d) + sm / Sut)


if __name__ == "__main__":
    # gearbox countershaft: bearings 300 mm apart, gear force 2000 N at 100 mm, pulley pull 1200 N at 220 mm
    L, loads = 300.0, [(100.0, 2000.0), (220.0, 1200.0)]
    R1, R2, x, M = moment_diagram(L, loads)
    i = int(np.argmax(np.abs(M)))
    Mmax = M[i]
    print(f"reactions {R1:.1f} N and {R2:.1f} N; maximum moment {Mmax/1000:.2f} N m at x = {x[i]:.0f} mm")
    assert abs(R1 + R2 - 3200) < 1e-9 and abs(Mmax - R1 * 100) < 1e-6
    Sut, T, Kf, Kfs = 630.0, 150e3, 1.7, 1.5  # 1045 cold-drawn steel, 150 N m steady torque, shoulder fillet
    ds = []
    for n in (1.5, 2.0, 2.5, 3.0):
        d = de_goodman_d(n, Sut, Mmax, T, Kf, Kfs)
        ds.append(d)
        print(f"n = {n}: d = {d:.2f} mm (Se = {endurance_limit(Sut, d):.1f} MPa), back-check n = {goodman_n(d, Sut, Mmax, T, Kf, Kfs):.4f}")
        assert abs(goodman_n(d, Sut, Mmax, T, Kf, Kfs) - n) < 1e-6
    assert all(b > a for a, b in zip(ds, ds[1:]))  # a larger safety factor needs a larger diameter
```

:::exercise Without the torque
If the same shaft carried the bending loads but no torque, what diameter would $n = 2$ need? And with 50% more bending moment and the torque back?
---solution---
1. With $T = 0$ only the bending term remains; iterating gives $d = 29.54$ mm.
2. With $M = 248.0$ N·m and $T = 150$ N·m, $d = 35.77$ mm.
3. The bending term dominates: dropping all the torque saves only 2.3 mm, while 50% more bending adds 3.9 mm.
:::
