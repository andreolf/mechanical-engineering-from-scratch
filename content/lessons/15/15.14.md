A helical compression spring looks like a bending problem, but it is really a **torsion bar** wound into a helix. Push on the ends and every section of the wire twists by the same torque, $T = FD/2$. That one observation gives the spring rate and the stress.

## Rate and stress

A spring with wire diameter $d$, mean coil diameter $D$ and $n$ active coils has a wire length of about $\pi D n$. Twisting it by $T = FD/2$ rotates one end of the wire relative to the other by $\theta = TL/(GJ)$, and that rotation moves the load point by $\theta D/2$. With $J = \pi d^4/32$:

$$
k = \frac{F}{\delta} = \frac{G\,d^4}{8\,D^3\,n} .
$$

The rate goes as $d^4$ and $1/D^3$, so small changes in wire or coil size matter a lot, and it is inversely proportional to the number of coils: twice the coils, half the rate.

The maximum shear stress is the torsion stress $8FD/(\pi d^3)$, increased by the curvature of the wire (the inside of the coil is shorter, so it is more strained) and by the direct shear of $F$. The **Wahl factor** combines both, with spring index $C = D/d$:

$$
\tau = K_W\,\frac{8FD}{\pi d^3}, \qquad K_W = \frac{4C - 1}{4C - 4} + \frac{0.615}{C} .
$$

Practical springs have $C$ between 4 and 12. Spring wire is very strong and gets stronger as it gets thinner, roughly $S_{ut} = A/d^m$; for oil-tempered wire $A = 1855$ MPa·mm$^m$ and $m = 0.187$, and the torsional yield strength is about $0.50\,S_{ut}$.

The code checks the rate formula independently: it builds the actual helix, computes the moment of the load at each wire section, splits it into torsion and bending, and integrates the strain energy. For a pitch of 1.6 wire diameters, the helix angle adds a tiny bending share and the result is 0.11% softer than the formula.

:::widget springcoils
Change the coils and the wire. The force-deflection line gets steeper with thicker wire and fewer coils.
:::

:::example A scooter suspension spring
Oil-tempered wire $d = 5$ mm, mean diameter $D = 40$ mm, 8 active coils, $G = 79.3$ GPa.

1. $k = 79\,300\cdot5^4/(8\cdot40^3\cdot8) = 12.100$ N/mm. The helix strain-energy integral gives 12.087 N/mm (−0.11%).
2. With 6, 10 or 12 coils: 16.134, 9.680 and 8.067 N/mm.
3. Under 600 N (rider weight share plus a bump): deflection $600/12.10 = 49.6$ mm.
4. $C = 8$, $K_W = 31/28 + 0.615/8 = 1.1840$, so $\tau = 1.1840\cdot8\cdot600\cdot40/(\pi\cdot125) = 578.9$ MPa.
5. $S_{ut} = 1855/5^{0.187} = 1373$ MPa, $S_{sy} = 686$ MPa: a static factor of 1.19. Thin for a part that is hammered by potholes; a fatigue check would push towards thicker wire or a larger diameter.
:::

```python file=spring.py
"""Helical compression spring: rate k = G d^4/(8 D^3 n) checked against the strain energy of a real helix (torsion plus bending of the wire), Wahl-corrected stress and a coil-count study."""
import math
import numpy as np


def rate(G, d, D, n):
    return G * d**4 / (8 * D**3 * n)


def wahl(C):
    return (4 * C - 1) / (4 * C - 4) + 0.615 / C


def shear_stress(F, D, d):
    return wahl(D / d) * 8 * F * D / (math.pi * d**3)


def helix_rate(G, E, d, D, n, pitch, m=20000):
    """Axial load F on the helix axis. At each wire section the moment of F has a torsion part (about the wire
    tangent) and a bending part. Strain energy U = int(Mt^2/(2GJ) + Mb^2/(2EI)) ds, deflection = 2U/F."""
    R = D / 2
    J = math.pi * d**4 / 32; I = J / 2
    th = np.linspace(0, 2 * math.pi * n, m + 1)
    pos = np.column_stack([R * np.cos(th), R * np.sin(th), pitch * th / (2 * math.pi)])
    tang = np.column_stack([-R * np.sin(th), R * np.cos(th), np.full_like(th, pitch / (2 * math.pi))])
    ds_dth = np.linalg.norm(tang[0])
    tang /= ds_dth
    F = 1.0
    force = np.array([0.0, 0.0, F])
    # moment at the section from the load applied on the axis (0, 0, z_end): M = (r_axis - r) x F
    r = np.column_stack([-pos[:, 0], -pos[:, 1], np.zeros(len(th))])
    M = np.cross(r, force)
    Mt = (M * tang).sum(1)
    Mb2 = (M**2).sum(1) - Mt**2
    e = Mt**2 / (2 * G * J) + Mb2 / (2 * E * I)
    U = float(np.sum(0.5 * (e[1:] + e[:-1])) * (th[1] - th[0]) * ds_dth)
    return F / (2 * U / F)


if __name__ == "__main__":
    # scooter front suspension spring: oil-tempered wire d = 5 mm, mean diameter 40 mm, 8 active coils
    G, E, d, D = 79.3e3, 203.4e3, 5.0, 40.0
    for n in (6, 8, 10, 12):
        pitch = d + 0.6 * d  # open coils
        k = rate(G, d, D, n)
        kh = helix_rate(G, E, d, D, n, pitch)
        print(f"n = {n:2d}: k = {k:.4f} N/mm, helix strain energy {kh:.4f} N/mm ({100*(kh/k-1):+.3f}%)")
        assert abs(kh / k - 1) < 0.005
    k8 = rate(G, d, D, 8)
    assert abs(rate(G, d, D, 16) - k8 / 2) < 1e-12   # doubling the coils halves the rate
    F = 600.0
    C = D / d
    tau = shear_stress(F, D, d)
    Sut = 1855 / d**0.187     # oil-tempered wire, MPa
    Ssy = 0.50 * Sut
    print(f"C = {C:.1f}, Wahl factor {wahl(C):.4f}, deflection {F/k8:.1f} mm, shear stress {tau:.1f} MPa; Sut {Sut:.0f} MPa, Ssy {Ssy:.0f} MPa, factor {Ssy/tau:.2f}")
    assert tau < Ssy
```

:::exercise A small spring
A spring has $d = 3$ mm, $D = 30$ mm and 10 active coils, $G = 79.3$ GPa. Find its rate, its Wahl factor and the stress at 200 N.
---solution---
1. $k = 79\,300\cdot81/(8\cdot27\,000\cdot10) = 2.974$ N/mm.
2. $C = 30/3 = 10$, so $K_W = 39/36 + 0.0615 = 1.1448$.
3. $\tau = 1.1448\cdot8\cdot200\cdot30/(\pi\cdot27) = 647.8$ MPa.
:::
