A gear tooth can fail in two ways. It can **break** at the root, like a cantilever overloaded in bending fatigue. Or its working surface can **pit**: the repeated Hertz contact stress starts tiny subsurface cracks, as in a rolling bearing, and flakes come out of the flank. Each failure has its own classic formula, and both say the same thing about size: bigger teeth are stronger.

## Bending: the Lewis equation

Wilfred Lewis (1892) treated the tooth as a cantilever loaded at its tip by the tangential force $W_t = 2T/d$. Fitting the largest parabola of uniform strength inside the tooth outline gives the critical section near the root and a dimensionless **Lewis form factor** $Y$ that depends only on the tooth count and the profile:

$$
\sigma_b = \frac{K_v\,W_t}{F\,m\,Y}, \qquad K_v = \frac{6.1 + V}{6.1} \ \text{(cut teeth, } V \text{ in m/s)} .
$$

$F$ is the face width and $m$ the module. $K_v$, the **Barth velocity factor**, accounts for dynamic loads from small spacing errors, which grow with pitch-line speed $V$. $Y$ rises from 0.245 at 12 teeth to 0.485 for a rack (more teeth means a wider root). Modern AGMA and ISO methods refine this with a computed geometry factor, overload and size factors, but the structure is the same.

## Contact: Hertz on the flanks

Near the pitch point, two involute flanks act like two cylinders of radii $\rho_i = (d_i/2)\sin\phi$ pressed together by the normal load $W_t/\cos\phi$. Hertz line contact then gives the peak pressure. AGMA packages the geometry into a factor $I$:

$$
\sigma_c = C_p\sqrt{\frac{K_v W_t}{F\,d_1\,I}}, \qquad I = \frac{\cos\phi\sin\phi}{2}\,\frac{m_G}{m_G + 1}, \qquad C_p = \sqrt{\frac{1}{\pi\left(\frac{1-\nu_1^2}{E_1} + \frac{1-\nu_2^2}{E_2}\right)}} ,
$$

with gear ratio $m_G = z_2/z_1$. For steel on steel $C_p \approx 190\ \sqrt{\text{MPa}}$. The code checks that this formula is exactly the Hertz result for the two equivalent cylinders.

At fixed torque, a bigger module means a bigger pitch diameter, so a smaller $W_t$; bending also gains the factor $m$ in the denominator, so $\sigma_b \propto 1/m^2$ roughly, and $\sigma_c \propto 1/m$. (The velocity factor grows a little with $m$, which slightly offsets the gain.)

1. Torque $3000/(2\pi\cdot25) = 19.099$ N·m.
2. With $m = 2$: $d_1 = 36$ mm, $V = 2.827$ m/s, $W_t = 2\cdot19\,099/36 = 1061.0$ N, $K_v = 1.4635$.
3. Bending: $Y(18) = 0.309$, so $\sigma_b = 1.4635\cdot1061.0/(20\cdot2\cdot0.309) = 125.6$ MPa.
4. Contact: $I = (\cos20°\sin20°/2)(2.5/3.5) = 0.1148$. The term under the root is $1.4635\cdot1061.0/(20\cdot36\cdot0.1148) = 18.79$ MPa, so $\sigma_c = 190.3\sqrt{18.79} = 824.8$ MPa.
5. Over modules 1.5, 2, 2.5, 3 and 4 mm, the bending stress is 205.7, 125.6, 86.8, 64.7 and 41.4 MPa and the contact stress 1055, 825, 685, 592 and 473 MPa. Both fall steadily.

Contact usually governs for hardened steel gears: 825 MPa needs a through-hardened or case-hardened steel, while 125.6 MPa in bending is modest.

```python file=gearstress.py
"""Gear tooth strength: Lewis bending stress with the Barth velocity factor, and Hertz contact stress from the AGMA geometry factor checked against two contacting cylinders."""
import math
import numpy as np

# Lewis form factor Y for 20 degree full-depth teeth (tooth count: Y), as tabulated in Shigley
LEWIS = [(12, .245), (13, .261), (14, .277), (15, .290), (16, .296), (17, .303), (18, .309), (19, .314), (20, .322),
         (21, .328), (22, .331), (24, .337), (26, .346), (28, .353), (30, .359), (34, .371), (38, .384), (43, .397),
         (50, .409), (60, .422), (75, .435), (100, .447), (150, .460), (300, .472), (400, .480)]


def lewis_Y(z):
    zs, ys = zip(*LEWIS)
    return float(np.interp(z, zs, ys))


def barth_Kv(V):
    """Velocity factor for cut or milled teeth, V pitch-line speed in m/s."""
    return (6.1 + V) / 6.1


def lewis_stress(Wt, F, m, z, V):
    return barth_Kv(V) * Wt / (F * m * lewis_Y(z))


def elastic_coefficient(E1, nu1, E2, nu2):
    return math.sqrt(1 / (math.pi * ((1 - nu1**2) / E1 + (1 - nu2**2) / E2)))


def contact_stress(Wt, F, d1, z1, z2, phi, Cp, Kv=1.0):
    """AGMA form: sigma_c = Cp sqrt(Kv Wt / (F d1 I)), I = cos(phi) sin(phi)/2 * mG/(mG + 1)."""
    mG = z2 / z1
    I = math.cos(phi) * math.sin(phi) / 2 * mG / (mG + 1)
    return Cp * math.sqrt(Kv * Wt / (F * d1 * I))


def hertz_cylinders(Wt, F, d1, d2, phi, E, nu, Kv=1.0):
    """Two cylinders of radii equal to the involute curvatures at the pitch point, pressed by the normal tooth load."""
    rho1, rho2 = d1 / 2 * math.sin(phi), d2 / 2 * math.sin(phi)
    Rstar = 1 / (1 / rho1 + 1 / rho2)
    Estar = E / (2 * (1 - nu**2))
    w = Kv * Wt / math.cos(phi) / F
    return math.sqrt(w * Estar / (math.pi * Rstar))


if __name__ == "__main__":
    z1, z2, phi, F, E, nu = 18, 45, math.radians(20), 20.0, 207e3, 0.30
    P, n1 = 3000.0, 1500.0  # 3 kW at 1500 rpm on the pinion
    T = P / (2 * math.pi * n1 / 60) * 1000  # N mm
    Cp = elastic_coefficient(E, nu, E, nu)
    print(f"pinion torque {T/1000:.3f} N m, elastic coefficient {Cp:.1f} sqrt(MPa)")
    prev = None
    for m in (1.5, 2.0, 2.5, 3.0, 4.0):
        d1, d2 = m * z1, m * z2
        V = math.pi * d1 / 1000 * n1 / 60
        Wt = 2 * T / d1
        sb = lewis_stress(Wt, F, m, z1, V)
        sc = contact_stress(Wt, F, d1, z1, z2, phi, Cp, barth_Kv(V))
        sh = hertz_cylinders(Wt, F, d1, d2, phi, E, nu, barth_Kv(V))
        print(f"m = {m}: V = {V:.3f} m/s, Wt = {Wt:.1f} N, Kv = {barth_Kv(V):.4f}, bending {sb:.1f} MPa, contact {sc:.1f} MPa")
        assert abs(sc / sh - 1) < 1e-12  # the AGMA geometry factor is Hertz for cylinders at the pitch point
        if prev:
            assert sb < prev[0] and sc < prev[1]  # stresses fall as the module grows
        prev = (sb, sc)
```

:::exercise Face width for a bending limit
Keep $m = 2$. What face width brings the bending stress down to 100 MPa? What is the contact stress then?
---solution---
1. $F = K_v W_t/(\sigma_b m Y) = 1.4635\cdot1061.0/(100\cdot2\cdot0.309) = 25.13$ mm.
2. $\sigma_c \propto 1/\sqrt F$: $824.8\sqrt{20/25.13} = 735.8$ MPa.
3. Face widths are usually kept between about 8 and 16 modules (16 to 32 mm here), so 25 mm is reasonable.
:::
