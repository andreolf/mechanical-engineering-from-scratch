A design is not finished when the numbers work out on your screen. Someone else has to check it: a colleague, a customer, a certification body. A **design review** walks through every requirement, the calculation behind it and its margin. The best way to make that review trustworthy is to generate the calculation report **directly from the code** that does the calculations, so the report can never drift away from the analysis.

## What a calculation report contains

1. **Inputs**: loads, speeds, materials, geometry, with sources.
2. **Checks**: each failure mode with its value, its limit and a pass or fail status.
3. **Assumptions**: what the models leave out (Phase 15 has listed them in every lesson).
4. **Result**: a single line saying whether everything passes, and which checks govern.

When an input changes (a heavier load, a cheaper bearing), you rerun the script and the whole report updates. Version control then records which report belongs to which design.

## Report from code, and a test that it is right

The code below gathers checks from this phase for the countershaft of lesson 15.04: peak bending moment, endurance limit, DE-Goodman safety factor, bearing L10 lives at both supports (lesson 15.06), and key shear and crushing (lesson 15.05). It writes a Markdown table, which renders on GitHub or converts to PDF. Then it **parses the report back** and checks that every printed number matches the computed value to the printed precision, and that every status is right. A second run with a thinner shaft must show a failure.

This is the same idea as an automated test in software: the report is an output that can be checked by a machine, not only read by a person.

:::widget designreport
A live report: change the shaft and the load and watch the statuses change.
:::

:::example The countershaft report
Inputs as in lesson 15.04: 150 N·m at 600 rpm; gear 2000 N at 100 mm and pulley 1200 N at 220 mm on a 300 mm span; 1045 steel; bearings with $C = 19.5$ kN (about a 6206); a 10 × 8 × 40 mm key in 1018 steel ($S_y = 370$ MPa) with a design factor of 2.

| Check | Value | Limit | Status |
|---|---|---|---|
| Peak bending moment | 165.33 N·m | | info |
| Endurance limit $S_e$ | 220.31 MPa | | info |
| Fatigue factor (DE-Goodman), $d = 32$ mm | 2.03 | ≥ 2.00 | pass |
| Bearing L10, left | 45 574 h | ≥ 20 000 h | pass |
| Bearing L10, right | 55 669 h | ≥ 20 000 h | pass |
| Key shear | 23.44 MPa | ≤ 106.74 MPa | pass |
| Key crushing | 58.59 MPa | ≤ 185.00 MPa | pass |

1. The left bearing carries $R_1 = 1653.3$ N: $L_{10} = (19\,500/1653.3)^3 = 1640.7$ million revolutions, or 45 574 h at 600 rpm.
2. Key shear $2\cdot150\,000/(32\cdot10\cdot40) = 23.44$ MPa.
3. The parser reads all seven rows back and every value and status agrees.
4. With a 28 mm shaft the fatigue factor falls to 1.375 and the report says "1 check(s) fail". The governing check is shaft fatigue; the bearings and key have large margins.
:::

```python file=report.py
"""Design review: one script computes every check for a gearbox countershaft and writes a calculation report in Markdown; the report is then parsed back to prove it reproduces the numbers."""
import math
import re
import numpy as np


def design(T=150e3, n_rpm=600.0, F_gear=2000.0, F_pulley=1200.0, d=32.0, life_h=20000.0, C_bearing=19.5e3):
    """All the checks from Phase 15 for one shaft. Units: N, mm, MPa."""
    L, a1, a2 = 300.0, 100.0, 220.0
    R2 = (F_gear * a1 + F_pulley * a2) / L
    R1 = F_gear + F_pulley - R2
    M = max(R1 * a1, R2 * (L - a2))
    Sut, Kf, Kfs = 630.0, 1.7, 1.5
    Se = 4.51 * Sut ** -0.265 * 1.24 * d ** -0.107 * 0.5 * Sut
    sa = 32 * Kf * M / (math.pi * d**3)
    sm = math.sqrt(3) * 16 * Kfs * T / (math.pi * d**3)
    n_fatigue = 1 / (sa / Se + sm / Sut)
    # deep groove ball bearings at each end (C = 19.5 kN, about a 6206), life in hours at the shaft speed
    L10 = [(C_bearing / R) ** 3 * 1e6 / (n_rpm * 60) for R in (R1, R2)]
    # key 10 x 8 x 40 for the gear, 1018 cold-drawn steel (S_y = 370 MPa), design factor 2
    w, h, lk, Sy_key = 10.0, 8.0, 40.0, 370.0
    tau_key = 2 * T / (d * w * lk)
    crush = 4 * T / (d * h * lk)
    checks = [
        ("Peak bending moment", M / 1000, "N m", None, None),
        ("Endurance limit S_e", Se, "MPa", None, None),
        ("Fatigue safety factor (DE-Goodman)", n_fatigue, "-", 2.0, ">="),
        ("Bearing L10 life, left", L10[0], "h", life_h, ">="),
        ("Bearing L10 life, right", L10[1], "h", life_h, ">="),
        ("Key shear stress", tau_key, "MPa", 0.577 * Sy_key / 2, "<="),
        ("Key crushing stress", crush, "MPa", Sy_key / 2, "<="),
    ]
    return checks


def status(value, limit, sense):
    if limit is None:
        return "info"
    ok = value >= limit if sense == ">=" else value <= limit
    return "pass" if ok else "FAIL"


def report(checks, title="Countershaft design review"):
    lines = [f"# {title}", "", "| Check | Value | Unit | Limit | Status |", "|---|---|---|---|---|"]
    for name, val, unit, lim, sense in checks:
        lim_s = "" if lim is None else f"{sense} {lim:.2f}"
        lines.append(f"| {name} | {val:.2f} | {unit} | {lim_s} | {status(val, lim, sense)} |")
    fails = sum(status(v, l, s) == "FAIL" for _, v, _, l, s in checks)
    lines += ["", f"Result: {'all checks pass' if fails == 0 else f'{fails} check(s) fail'}."]
    return "\n".join(lines)


def parse(md):
    rows = re.findall(r"^\| ([^|]+?) \| ([-\d.]+) \| [^|]* \| [^|]* \| (\w+) \|$", md, re.M)
    return {name: (float(val), st) for name, val, st in rows}


if __name__ == "__main__":
    checks = design()
    md = report(checks)
    print(md)
    back = parse(md)
    assert len(back) == len(checks)
    for name, val, unit, lim, sense in checks:
        v, st = back[name]
        assert abs(v - val) <= 0.005 + 1e-9, name          # every number in the report matches the calculation
        assert st == status(val, lim, sense)
    # a weaker design must be flagged: a 28 mm shaft
    md2 = report(design(d=28.0), "28 mm variant")
    assert "FAIL" in md2 and "check(s) fail" in md2
    print("\n" + md2.splitlines()[-1].replace("Result", "28 mm variant"))
```

:::exercise Adding a check
Add a static yield check for the shaft: the peak von Mises stress $\sqrt{(32K_fM/\pi d^3)^2 + 3(16K_{fs}T/\pi d^3)^2}$ must be at most $S_y/1.5$ with $S_y = 530$ MPa. Compute it for $d = 32$ mm.
---solution---
1. Bending $32\cdot1.7\cdot165\,333/(\pi\cdot32^3) = 87.37$ MPa.
2. Torsion $16\cdot1.5\cdot150\,000/(\pi\cdot32^3) = 34.97$ MPa, so $\sqrt3\cdot34.97 = 60.57$ MPa.
3. von Mises $\sqrt{87.37^2 + 60.57^2} = 106.3$ MPa against a limit of $530/1.5 = 353.3$ MPa: pass, with a big margin. Fatigue governs, as usual for rotating shafts.
4. In code: one more tuple in the `checks` list, and the parser test covers it automatically.
:::
