The LMTD method is ideal when you know all four temperatures and want the area. Often it is the other way round: you have an exchanger (you know $UA$) and want to know what it will do with given inlet temperatures. With LMTD that means guessing an outlet temperature and iterating. The **effectiveness-NTU** method answers directly.

## Effectiveness

The most heat any exchanger could transfer is limited by the stream with the smaller capacity rate $C_{\min}$, which could at best change temperature by the full inlet difference:

$$
Q_{\max} = C_{\min}\,(T_{h,\text{in}} - T_{c,\text{in}}), \qquad \varepsilon = \frac{Q}{Q_{\max}} .
$$

## NTU and capacity ratio

Two dimensionless groups determine $\varepsilon$ for a given flow arrangement: the **number of transfer units** and the **capacity ratio**,

$$
\text{NTU} = \frac{UA}{C_{\min}}, \qquad C_r = \frac{C_{\min}}{C_{\max}} .
$$

Solving the same stream equations as for LMTD gives closed forms:

$$
\varepsilon_{\text{parallel}} = \frac{1 - e^{-\text{NTU}(1 + C_r)}}{1 + C_r}, \qquad
\varepsilon_{\text{counter}} = \frac{1 - e^{-\text{NTU}(1 - C_r)}}{1 - C_r\,e^{-\text{NTU}(1 - C_r)}},
$$

with $\varepsilon_{\text{counter}} = \text{NTU}/(1 + \text{NTU})$ when $C_r = 1$. When one stream condenses or boils, its temperature stays constant ($C_r = 0$) and every arrangement gives $\varepsilon = 1 - e^{-\text{NTU}}$.

Two lessons hide in these formulas. Parallel flow can never beat $1/(1 + C_r)$, only 50% for balanced streams. And past NTU of about 3, extra area buys very little.

:::example The oil cooler again
1. For four exchangers with different $C_h$, $C_c$ and $UA$, marching the streams with RK4 reproduces both closed-form effectivenesses to a worst relative error of $4.4\times10^{-14}$.
2. The 13.12 oil cooler: $C_{\min} = 418$ W/K (water), so $\text{NTU} = 300/418 = 0.7177$ and $C_r = 418/420 = 0.9952$. Parallel: $\varepsilon = 0.38149$, $Q = 13554.397$ W. Counter: $\varepsilon = 0.41824$, $Q = 14860.179$ W. Both match $UA\,\Delta T_{\text{lm}}$ exactly, with no iteration.
3. Balanced counterflow: $\varepsilon = 0.3333$, 0.5000, 0.6667, 0.8000, 0.8889 at NTU 0.5, 1, 2, 4, 8. Parallel flow: 0.3161, 0.4323, 0.4908, 0.4998, 0.5000, stuck at one half.
:::

```python file=entu.py
"""Effectiveness-NTU: closed-form effectiveness for parallel and counterflow, checked against marching the two streams numerically, and against LMTD."""
import math


def eff_parallel(ntu, cr):
    return (1 - math.exp(-ntu * (1 + cr))) / (1 + cr)


def eff_counter(ntu, cr):
    if abs(1 - cr) < 1e-12:
        return ntu / (1 + ntu)
    e = math.exp(-ntu * (1 - cr))
    return (1 - e) / (1 - cr * e)


def march(Ch, Cc, UA, counter, n=4000):
    """Q from marching both streams with RK4, inlets 1 (hot) and 0 (cold). Counterflow shoots on the cold outlet."""
    def run(tc0, sign):
        f = lambda th, tc: (-(th - tc) / Ch, sign * (th - tc) / Cc)
        th, tc, dA = 1.0, tc0, UA / n
        for _ in range(n):
            a1, b1 = f(th, tc); a2, b2 = f(th + dA / 2 * a1, tc + dA / 2 * b1); a3, b3 = f(th + dA / 2 * a2, tc + dA / 2 * b2); a4, b4 = f(th + dA * a3, tc + dA * b3)
            th += dA / 6 * (a1 + 2 * a2 + 2 * a3 + a4); tc += dA / 6 * (b1 + 2 * b2 + 2 * b3 + b4)
        return th, tc
    if not counter:
        th, _ = run(0.0, +1)
    else:
        lo, hi = 0.0, 1.0
        for _ in range(55):
            mid = 0.5 * (lo + hi)
            lo, hi = (mid, hi) if run(mid, -1)[1] < 0 else (lo, mid)
        th, _ = run(0.5 * (lo + hi), -1)
    return Ch * (1 - th)


if __name__ == "__main__":
    worst = 0.0
    for Ch, Cc, UA in ((420, 418, 300), (1000, 250, 400), (200, 900, 1500), (500, 500, 800)):
        Cmin, Cmax = min(Ch, Cc), max(Ch, Cc)
        ntu, cr = UA / Cmin, Cmin / Cmax
        for counter, eff in ((False, eff_parallel), (True, eff_counter)):
            q_num, q_ntu = march(Ch, Cc, UA, counter), eff(ntu, cr) * Cmin
            worst = max(worst, abs(q_num - q_ntu) / q_ntu)
    print(f"closed-form effectiveness vs RK4 marching, 8 cases: worst relative error {worst:.1e}")
    assert worst < 1e-7
    # the oil cooler from 13.12: oil 110 C (C_h = 420 W/K), water 25 C (C_c = 418 W/K), UA = 300 W/K
    Ch, Cc, UA, Thi, Tci = 420.0, 418.0, 300.0, 110.0, 25.0
    ntu, cr = UA / Cc, Cc / Ch
    for name, eff in (("parallel", eff_parallel), ("counter", eff_counter)):
        e = eff(ntu, cr); Q = e * Cc * (Thi - Tci)
        tho, tco = Thi - Q / Ch, Tci + Q / Cc
        dT1, dT2 = (Thi - Tci, tho - tco) if name == "parallel" else (Thi - tco, tho - Tci)
        lm = (dT1 - dT2) / math.log(dT1 / dT2)
        print(f"{name}: NTU = {ntu:.4f}, Cr = {cr:.4f}, effectiveness {e:.5f}, Q = {Q:.3f} W; UA LMTD = {UA*lm:.3f} W")
        assert abs(Q - UA * lm) < 1e-6 * Q
    # diminishing returns: counterflow, Cr = 1
    for n_ in (0.5, 1, 2, 4, 8):
        print(f"  NTU {n_}: counterflow effectiveness (Cr = 1) {eff_counter(n_, 1.0):.4f}, parallel {eff_parallel(n_, 1.0):.4f}")
    assert eff_parallel(50, 1.0) < 0.5 + 1e-12 and eff_counter(50, 1.0) > 0.98
    # a condenser (Cr = 0): every arrangement gives 1 - exp(-NTU)
    assert abs(eff_counter(2, 0) - eff_parallel(2, 0)) < 1e-15 and abs(eff_counter(2, 0) - (1 - math.exp(-2))) < 1e-15
```

:::exercise A shower heat recovery pipe
Waste shower water at 38 °C runs down a counterflow drain heat exchanger, warming incoming mains water at 15 °C. Both flows are 0.12 kg/s (c = 4180) and $UA = 600$ W/K. Find NTU, the effectiveness, the heat recovered and the preheated water temperature.
---solution---
1. $C = 0.12\cdot4180 = 501.6$ W/K for both streams, so $C_r = 1$ and $\text{NTU} = 600/501.6 = 1.1962$.
2. $\varepsilon = 1.1962/2.1962 = 0.5447$.
3. $Q = 0.5447\cdot501.6\cdot23 = 6284$ W.
4. The mains water leaves at $15 + 0.5447\cdot23 = 27.53$ °C.
:::
