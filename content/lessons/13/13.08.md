Coolant in an engine, water in a solar collector, refrigerant in an air conditioner: most heat exchange happens inside tubes. For these flows we rarely solve the equations. We use **correlations**, curve fits to experiments. Each one comes with a validity range, and using it outside that range is one of the most common mistakes in thermal design.

## Laminar flow: exact limits

Below $\text{Re} = UD/\nu \approx 2300$ the flow is laminar. Far enough downstream, the shape of the temperature profile stops changing (thermally fully developed), and the Nusselt number $\text{Nu} = hD/k$ becomes a constant:

$$
\text{Nu} = 3.66 \ \ \text{(constant wall temperature)}, \qquad \text{Nu} = \tfrac{48}{11} = 4.36 \ \ \text{(constant heat flux)} .
$$

Both follow from the energy equation with the parabolic velocity profile $u = 2U(1 - r^2/r_w^2)$. The 3.66 is an eigenvalue: $\text{Nu} = \lambda^2/2$, where $\lambda$ makes $\phi'' + \phi'/r + \lambda^2(1 - r^2)\phi = 0$ vanish at the wall.

## Turbulent flow: correlations

**Dittus-Boelter**, simple and widely quoted:

$$
\text{Nu} = 0.023\,\text{Re}^{0.8}\,\text{Pr}^{n}, \qquad n = 0.4 \text{ heating}, \ 0.3 \text{ cooling}
$$

valid for $\text{Re} > 10^4$, $0.6 < \text{Pr} < 160$, $L/D > 10$, and modest temperature differences.

**Gnielinski**, more accurate (about 10%) and valid down into the transition range:

$$
\text{Nu} = \frac{(f/8)(\text{Re} - 1000)\,\text{Pr}}{1 + 12.7\sqrt{f/8}\,(\text{Pr}^{2/3} - 1)}, \qquad f = (0.790\ln\text{Re} - 1.64)^{-2}
$$

for $3000 < \text{Re} < 5\times10^6$ and $0.5 < \text{Pr} < 2000$. Between 2300 and 3000, no correlation is trustworthy.

:::example Laminar limits and a coolant loop
1. Shooting on the eigenvalue problem gives $\text{Nu} = 3.6568$; integrating the constant-flux temperature profile numerically gives 4.3636 $= 48/11$.
2. Water at 40 °C ($\nu = 0.658\times10^{-6}$, $k = 0.631$, Pr = 4.32) in a 10 mm tube at 1 m/s, being heated: $\text{Re} = 15198$, inside both ranges. Dittus-Boelter gives Nu = 91.48 ($h = 5773$ W/(m² K)); Gnielinski 95.98 ($h = 6056$). They agree within 5%.
3. At Re = 4000, Dittus-Boelter (outside its range) gives 31.45 against Gnielinski's 26.74: 18% too high.
:::

```python file=pipe.py
"""Forced convection in pipes: the laminar limits (3.66 and 4.36) derived numerically, then Dittus-Boelter and Gnielinski with their validity ranges."""
import math


def rk4(f, y, x0, x1, n):
    h = (x1 - x0) / n; x = x0
    for _ in range(n):
        k1 = f(x, y); k2 = f(x + h / 2, [a + h / 2 * b for a, b in zip(y, k1)]); k3 = f(x + h / 2, [a + h / 2 * b for a, b in zip(y, k2)]); k4 = f(x + h, [a + h * b for a, b in zip(y, k3)])
        y = [a + h / 6 * (b + 2 * c + 2 * d + e) for a, b, c, d, e in zip(y, k1, k2, k3, k4)]; x += h
    return y


def nu_constant_wall_temperature(n=4000):
    """Fully developed Graetz mode: (1/r)(r phi')' + lam^2 (1 - r^2) phi = 0, phi'(0) = 0, phi(1) = 0. Nu = lam^2 / 2 (based on diameter)."""
    def phi_at_wall(lam2):
        r0 = 1e-6
        f = lambda r, y: [y[1], -y[1] / r - lam2 * (1 - r * r) * y[0]]
        return rk4(f, [1.0, -lam2 * r0 / 2], r0, 1.0, n)[0]
    a, b = 5.0, 9.0
    while b - a > 1e-12:
        c = 0.5 * (a + b)
        a, b = (c, b) if (phi_at_wall(a) > 0) == (phi_at_wall(c) > 0) else (a, c)
    return 0.5 * (a + b) / 2


def nu_constant_heat_flux(n=200000):
    """Constant flux, fully developed: (1/r)(r T')' = C u(r) with u = 2(1 - r^2) and r the radius over r_w.
    Take C = 1: then r T' = 2 (r^2/2 - r^4/4), so T'(1) = 1/2. Integrate T(r) and its bulk (velocity-weighted) mean numerically.
    Nu = h D / k = 2 T'(1) / (Tw - Tm)."""
    dr = 1.0 / n
    rs = [(i + 0.5) * dr for i in range(n)]
    dT = [2 * (r * r / 2 - r ** 4 / 4) / r for r in rs]
    T, acc = [], 0.0
    for r, g in zip(rs, dT):
        T.append(acc + g * dr / 2); acc += g * dr                     # T at the cell centre, from T(0) = 0
    Tw = acc
    Tm = sum(2 * (1 - r * r) * t * r for r, t in zip(rs, T)) / sum(2 * (1 - r * r) * r for r in rs)
    return 2 * 0.5 / (Tw - Tm)


def dittus_boelter(Re, Pr, heating=True):
    ok = Re >= 1e4 and 0.6 <= Pr <= 160
    return 0.023 * Re ** 0.8 * Pr ** (0.4 if heating else 0.3), ok


def gnielinski(Re, Pr):
    f = (0.790 * math.log(Re) - 1.64) ** -2
    ok = 3000 <= Re <= 5e6 and 0.5 <= Pr <= 2000
    return (f / 8) * (Re - 1000) * Pr / (1 + 12.7 * math.sqrt(f / 8) * (Pr ** (2 / 3) - 1)), ok


if __name__ == "__main__":
    a = nu_constant_wall_temperature()
    b = nu_constant_heat_flux()
    print(f"laminar fully developed: Nu = {a:.4f} (constant wall temperature), {b:.4f} (constant flux; exact 48/11 = {48/11:.4f})")
    assert abs(a - 3.6568) < 1e-3 and abs(b - 48 / 11) < 1e-3
    # water at 40 C heated in a 10 mm tube at 1 m/s (an e-bike motor coolant loop)
    nu, k, Pr, D, U = 0.658e-6, 0.631, 4.32, 0.010, 1.0
    Re = U * D / nu
    Nd, okd = dittus_boelter(Re, Pr)
    Ng, okg = gnielinski(Re, Pr)
    print(f"water: Re = {Re:.0f}; Dittus-Boelter Nu = {Nd:.2f} (valid: {okd}), h = {Nd*k/D:.0f}; Gnielinski Nu = {Ng:.2f} (valid: {okg}), h = {Ng*k/D:.0f}")
    assert okd and okg and abs(Nd - Ng) < 0.1 * Ng
    # in the transition range Dittus-Boelter is outside its range and overshoots Gnielinski
    Re2 = 4000
    Nd2, okd2 = dittus_boelter(Re2, Pr); Ng2, okg2 = gnielinski(Re2, Pr)
    print(f"Re = 4000: Dittus-Boelter {Nd2:.2f} (valid: {okd2}), Gnielinski {Ng2:.2f} (valid: {okg2}); DB is {100*(Nd2/Ng2-1):.0f}% high")
    assert not okd2 and okg2 and Nd2 > 1.15 * Ng2
```

:::exercise Air in a duct
Air at 40 °C ($\nu = 1.70\times10^{-5}$, $k = 0.0271$, Pr = 0.71) flows at 5 m/s through a 50 mm duct and is heated. Find Re and h from Dittus-Boelter. Is it in range?
---solution---
1. $\text{Re} = 5\cdot0.05/1.70\times10^{-5} = 14706$. In range ($> 10^4$, Pr in 0.6 to 160).
2. $\text{Nu} = 0.023\cdot14706^{0.8}\cdot0.71^{0.4} = 43.27$.
3. $h = 43.27\cdot0.0271/0.05 = 23.45$ W/(m² K).
:::
