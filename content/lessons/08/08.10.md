Hit the end of a steel bar with a hammer and it rings with a high, pure tone. An oil-well drill string, kilometres of steel pipe twisting in the ground, can lock and release at less than one cycle per second, wrecking bits. Both are the same physics: waves running along a rod and reflecting from its ends.

## The wave equation in a rod

For **axial** motion $u(x,t)$ of a uniform rod, a slice $dx$ carries stress $E\,\partial u/\partial x$. The difference in force across the slice accelerates its mass $\rho A\,dx$:

$$
\rho\frac{\partial^2 u}{\partial t^2} = E\frac{\partial^2 u}{\partial x^2}, \qquad c = \sqrt{\frac{E}{\rho}} .
$$

For **torsion** the twist angle $\theta(x,t)$ obeys the same equation with $c_t = \sqrt{G/\rho}$ (for a circular section, where $GJ$ and $\rho J$ share the same $J$). It's the string equation of 08.09 with different physics behind $c$. In steel, $c \approx 5170$ m/s and $c_t \approx 3210$ m/s.

## Boundary conditions and modes

A **fixed** end has $u = 0$. A **free** end carries no force, so $\partial u/\partial x = 0$. With $u = \sin(kx)\cos(\omega t)$:

- **Fixed-fixed**: $\sin kL = 0$, so $f_n = \dfrac{nc}{2L}$, all whole multiples, like a string.
- **Fixed-free**: $\cos kL = 0$, so $f_n = \dfrac{(2n-1)c}{4L}$: only the odd multiples 1, 3, 5, …, of $c/(4L)$.

The fixed-free fundamental's wavelength is four times the length: a wave runs to the free end, reflects, returns, reflects again (inverted at the fixed end) and needs a second round trip to repeat.

:::example A steel bar and a drill string
1. Steel: $c = \sqrt{210\times10^9/7850} = 5172.2$ m/s; $c_t = \sqrt{81\times10^9/7850} = 3212.2$ m/s.
2. A 2 m fixed-free bar: exact $f_1, f_2, f_3$ = 646.52, 1939.57, 3232.62 Hz. Linear finite elements give 649.19, 2011.91, 3564.48 Hz with 5 elements; 646.69, 1944.06, 3253.43 with 20; 646.53, 1939.85, 3233.92 with 80. The error falls as the square of the element size, slowest for high modes.
3. Fixed-fixed: $f_1 = 1293.05$ Hz $= c/2L$, and $f_2/f_1 = 2.0000$.
4. A 3000 m drill string, clamped by the rig's top drive and free at the bit, twisting: $f_1 = c_t/(4L) = 0.2677$ Hz, a period of 3.74 s. Finite elements on the real pipe section give 0.2677 Hz too. The heavy assembly near the bit lowers it further in practice. Torsional stick-slip in real wells has periods of a few seconds.
:::

```python file=rod.py
"""Axial and torsional vibration of rods: a lumped-mass model of a fixed-free rod converging to f_n = (2n - 1) c / (4 L)."""
import math
import numpy as np
from scipy.linalg import eigh


def rod_modes(L, EA, rhoA, ne, fixed_free=True):
    """Linear finite elements (consistent mass) for a uniform rod; returns natural frequencies in Hz."""
    h = L / ne
    ke = EA / h * np.array([[1, -1], [-1, 1]]); me = rhoA * h / 6 * np.array([[2, 1], [1, 2]])
    K = np.zeros((ne + 1, ne + 1)); M = np.zeros_like(K)
    for e in range(ne):
        K[e:e+2, e:e+2] += ke; M[e:e+2, e:e+2] += me
    keep = slice(1, None) if fixed_free else slice(1, -1)
    w2 = eigh(K[keep, keep], M[keep, keep], eigvals_only=True)
    return np.sqrt(w2) / (2 * math.pi)


if __name__ == "__main__":
    E, G, rho = 210e9, 81e9, 7850.0
    c, ct = math.sqrt(E / rho), math.sqrt(G / rho)
    print(f"steel: axial wave speed {c:.1f} m/s, torsional {ct:.1f} m/s")
    L, A = 2.0, 1e-4
    for ne in (5, 20, 80):
        f = rod_modes(L, E * A, rho * A, ne)
        print(f"{ne:3d} elements: f1..f3 = {', '.join(f'{x:.2f}' for x in f[:3])} Hz")
    exact = [(2 * n - 1) * c / (4 * L) for n in (1, 2, 3)]
    print(f"exact (2n - 1) c / (4L): {', '.join(f'{x:.2f}' for x in exact)} Hz")
    f = rod_modes(L, E * A, rho * A, 400)
    assert abs(f[0] / exact[0] - 1) < 1e-5 and abs(f[2] / exact[2] - 1) < 1e-4
    ff = rod_modes(L, E * A, rho * A, 400, fixed_free=False)
    print(f"fixed-fixed: f1 = {ff[0]:.2f} Hz (c / 2L = {c/(2*L):.2f}), f2 / f1 = {ff[1]/ff[0]:.4f}")
    # torsion uses the same equation with GJ and rho J: a 3000 m drill string, fixed at the rig, free at the bit
    Ld = 3000.0
    print(f"drill string {Ld:.0f} m, torsional f1 = c_t / (4 L) = {ct/(4*Ld):.4f} Hz (period {4*Ld/ct:.2f} s)")
    J = math.pi / 32 * (0.127**4 - 0.108**4)
    fd = rod_modes(Ld, G * J, rho * J, 300)
    print(f"finite elements for the drill pipe: {fd[0]:.4f} Hz")
    assert abs(fd[0] / (ct / (4 * Ld)) - 1) < 1e-4
```

:::exercise A singing rod
An aluminium rod ($E = 70$ GPa, $\rho = 2700$ kg/m³) held at its midpoint and struck on the end rings at its lowest free-free axial mode, $f_1 = c/(2L)$ (it behaves like two fixed-free halves). What length rings at 2000 Hz?
---solution---
1. $c = \sqrt{70\times10^9/2700} = 5092$ m/s.
2. $L = c/(2f_1) = 5092/4000 = 1.273$ m.
3. Holding it at the midpoint, which is a node of this mode, barely damps it, so these rods ring for many seconds. Physics demonstrations use them.
:::
