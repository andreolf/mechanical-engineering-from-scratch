A building in an earthquake, a car body on its suspension, an aircraft wing: their models have hundreds to millions of coupled coordinates. Solving them directly is possible but costly and hard to interpret. Modal analysis turns one big coupled problem into many independent single oscillators, of which usually only a handful matter.

## Modal coordinates

For $\mathbf M\ddot{\mathbf x} + \mathbf C\dot{\mathbf x} + \mathbf K\mathbf x = \mathbf F(t)$ with $n$ coordinates, solve the eigenproblem $(\mathbf K - \omega^2\mathbf M)\boldsymbol\phi = \mathbf 0$ for $n$ frequencies and mass-normalised mode shapes, collected as columns of $\boldsymbol\Phi$. Write the motion as a mix of modes:

$$
\mathbf x(t) = \boldsymbol\Phi\,\mathbf q(t) = \sum_i \boldsymbol\phi_i\,q_i(t) .
$$

Substitute and multiply by $\boldsymbol\Phi^T$. Orthogonality (08.06) makes the mass and stiffness matrices diagonal. If the damping is also diagonal in modal coordinates (assumed by giving each mode a damping ratio $\zeta_i$), every mode decouples:

$$
\ddot q_i + 2\zeta_i\omega_i\dot q_i + \omega_i^2 q_i = \boldsymbol\phi_i^T\mathbf F(t) .
$$

Each is the single oscillator of 08.02 and 08.03. Solve them separately and add them back up: **modal superposition**.

## Ground shaking

For a building whose base accelerates at $a_g(t)$, the effective force is $\mathbf F = -\mathbf M\mathbf 1\,a_g$. Mode $i$ is driven by $L_i = \boldsymbol\phi_i^T\mathbf M\mathbf 1$, its **participation factor**. The **effective modal mass** $L_i^2$ tells how much of the building's mass the mode moves. Building codes require enough modes to reach 90 % of the total. For regular buildings the first mode alone often carries 80 % or more, which is why simple hand methods work.

:::example A five-storey frame in an earthquake pulse
Floors of 20 t, storey stiffness 40 MN/m, 2 % damping in every mode. Ground acceleration $2\sin(2\pi\cdot1.5t)$ m/s² for 4 s.

1. `scipy.linalg.eigh(K, M)` gives 2.0259, 5.9135, 9.3221, 11.9755 and 13.6586 Hz. Mode 1 shape, roof = 1: 0.2846, 0.5462, 0.7635, 0.9190, 1.
2. Effective modal masses: 87.95, 8.72, 2.42, 0.75 and 0.16 % of the total. Two modes pass 90 %.
3. Integrating all ten coupled first-order equations directly with RK4 ($\Delta t = 2$ ms, 10 s) and integrating five separate modal oscillators give the same displacements to a relative difference of $1.1\times10^{-14}$.
4. Peak roof displacement 53.261 mm. Mode 1 alone gives 53.709 mm, within 1 %. Peak base shear 635.8 kN.
:::

```python file=shearbuilding.py
"""Modal analysis of a 5-storey shear building: modes with scipy.linalg.eigh, then modal superposition
checked against direct integration of all five coupled equations."""
import math
import numpy as np
from scipy.linalg import eigh

n, m, k, zeta = 5, 20e3, 40e6, 0.02          # storeys, floor mass (kg), storey stiffness (N/m), modal damping
M = np.eye(n) * m
K = np.zeros((n, n))
for i in range(n):
    K[i, i] += k
    if i + 1 < n: K[i, i] += k; K[i, i + 1] = K[i + 1, i] = -k
w2, Phi = eigh(K, M)                       # mass-normalised: Phi^T M Phi = I
w = np.sqrt(w2)
ag = lambda t: 2.0 * math.sin(2 * math.pi * 1.5 * t) * (t < 4.0)   # ground acceleration pulse, m/s^2


def rk4(f, s, dt, steps):
    out = [s.copy()]
    for i in range(steps):
        t = i * dt
        k1 = f(t, s); k2 = f(t + dt/2, s + dt/2*k1); k3 = f(t + dt/2, s + dt/2*k2); k4 = f(t + dt, s + dt*k3)
        s = s + dt/6*(k1 + 2*k2 + 2*k3 + k4); out.append(s.copy())
    return np.array(out)


if __name__ == "__main__":
    print("natural frequencies (Hz):", np.round(w / (2 * math.pi), 4))
    print("mode 1 shape (top = 1):", np.round(Phi[:, 0] / Phi[-1, 0], 4))
    assert np.allclose(Phi.T @ M @ Phi, np.eye(n), atol=1e-12)
    # effective modal mass: how much of the total mass each mode moves in a ground shake
    L = Phi.T @ M @ np.ones(n); meff = L**2
    print("effective modal mass (% of total):", np.round(meff / (n * m) * 100, 2))
    dt, T = 0.002, 10.0; steps = int(T / dt)
    # direct: M x'' + C x' + K x = -M 1 ag, with C built to give 2 % in every mode
    C = M @ Phi @ np.diag(2 * zeta * w) @ Phi.T @ M
    Mi = np.linalg.inv(M)
    f = lambda t, s: np.r_[s[n:], Mi @ (-M @ np.ones(n) * ag(t) - C @ s[n:] - K @ s[:n])]
    X = rk4(f, np.zeros(2 * n), dt, steps)[:, :n]
    # modal: five independent oscillators q'' + 2 zeta w q' + w^2 q = -L ag
    def g(t, s):
        q, qd = s[:n], s[n:]
        return np.r_[qd, -L * ag(t) - 2 * zeta * w * qd - w2 * q]
    Q = rk4(g, np.zeros(2 * n), dt, steps)[:, :n]
    Xm = Q @ Phi.T
    err = np.max(np.abs(Xm - X)) / np.max(np.abs(X))
    print(f"peak roof displacement {np.max(np.abs(X[:, -1]))*1000:.3f} mm; modal vs direct max difference {err:.1e} (relative)")
    assert err < 1e-9
    X1 = np.outer(Q[:, 0], Phi[:, 0])
    print(f"mode 1 alone gives a roof peak of {np.max(np.abs(X1[:, -1]))*1000:.3f} mm")
    base_shear = np.max(np.abs(k * X[:, 0]))
    print(f"peak base shear {base_shear/1e3:.1f} kN")
```

:::exercise A two-storey check
A two-storey shear building has floor masses $m$ and storey stiffnesses $k$, so $\mathbf M = m\mathbf I$ and $\mathbf K = k\begin{bmatrix}2 & -1\\-1 & 1\end{bmatrix}$. Find both frequencies in terms of $\sqrt{k/m}$, and the first mode's effective modal mass as a fraction of the total.
---solution---
1. $\det(\mathbf K - \lambda\mathbf M) = 0$: $(2k - \lambda m)(k - \lambda m) - k^2 = 0$, so $\lambda = \tfrac{3 \mp \sqrt5}{2}\,k/m$.
2. $\omega_1 = 0.618\sqrt{k/m}$, $\omega_2 = 1.618\sqrt{k/m}$ (the golden ratio appears).
3. Mode 1 from row 2: $-k\phi_1 + (k - 0.382k)\phi_2 = 0$, so $\phi = (0.618, 1)$.
4. $L = m(0.618 + 1) = 1.618m$; $\boldsymbol\phi^T\mathbf M\boldsymbol\phi = m(0.382 + 1) = 1.382m$. Effective mass $L^2/(\boldsymbol\phi^T\mathbf M\boldsymbol\phi) = 1.894m$, which is 94.7 % of $2m$.
:::
