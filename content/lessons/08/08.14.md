Linear theory is powerful because it lets us add solutions and work frequency by frequency. But push a spring far enough and it stiffens; hang a cable and its sag changes with load; let a structure rattle in its joints. Then strange things happen. Responses depend on history, amplitudes jump suddenly, and new frequencies appear.

## The Duffing oscillator

The simplest nonlinear oscillator adds a cubic term to the spring:

$$
\ddot x + 2\zeta\omega_n\dot x + \omega_n^2 x + \beta x^3 = F\cos\omega t .
$$

With $\beta > 0$ the spring hardens (a stretched cable, a rubber mount near its limit); with $\beta < 0$ it softens (a buckling-prone panel, a pendulum at large angles).

## Frequency depends on amplitude

Assume $x \approx A\cos(\omega t - \varphi)$ and keep only the first harmonic (**harmonic balance**). Using $\cos^3\theta = \tfrac34\cos\theta + \tfrac14\cos3\theta$ and dropping the $3\omega$ term gives, with $\omega_n = 1$,

$$
\left[(1 - \omega^2)A + \tfrac34\beta A^3\right]^2 + (2\zeta\omega A)^2 = F^2 .
$$

The free vibration frequency rises with amplitude, $\omega \approx \sqrt{1 + \tfrac34\beta A^2}$ (the **backbone curve**), so the resonance peak bends to the right.

## Jumps and hysteresis

Bent far enough, the response curve folds over. For some frequencies there are three amplitudes. The middle one is unstable. Which of the other two you get depends on history:

- **Sweeping up**, the oscillator rides the upper branch to its tip, then **jumps down**.
- **Sweeping down**, it stays on the lower branch until that ends, then **jumps up**.

Between the jumps, up and down sweeps give different answers: hysteresis. A linear system never does this.

:::example Sweeping a Duffing oscillator
$\zeta = 0.02$, $\beta = 1$, $F = 0.1$, $\omega_n = 1$. The frequency is stepped from 0.8 to 2.0 in steps of 0.02. At each step 150 forcing cycles are integrated with RK4, starting from the previous step's end state, and the amplitude is measured over the last 20.

| $\omega$ | sweep up | sweep down | harmonic balance |
|---|---|---|---|
| 1.04 | 0.5808 | 0.5808 | 0.5771 |
| 1.28 | 0.9937 | 0.1611 | 0.1610, 0.8416, 0.9840 |
| 1.64 | 1.5261 | 0.0592 | 0.0592, 1.4951, 1.5055 |
| 1.76 | 0.0477 | 0.0477 | 0.0477 |

1. The upward sweep jumps down between $\omega$ = 1.64 and 1.66. The downward sweep jumps up between 1.16 and 1.18. The largest difference between them is 1.467, at $\omega = 1.64$.
2. Where harmonic balance has one solution, the simulation agrees with it within 3 % (the third harmonic it ignores accounts for the rest).
3. Repeat with $\beta = 0$: the up and down sweeps agree to $4\times10^{-10}$.
:::

```python file=duffing.py
"""The Duffing oscillator: frequency sweeps up and down show the jump phenomenon and hysteresis."""
import math
import numpy as np

zeta, beta, F = 0.02, 1.0, 0.1          # x'' + 2 zeta x' + x + beta x^3 = F cos(w t)


def rk4_cycles(s, w, cycles, per=80):
    dt = 2 * math.pi / w / per; t = 0.0; xs = []
    f = lambda t, s: np.array([s[1], F * math.cos(w * t) - 2 * zeta * s[1] - s[0] - beta * s[0]**3])
    for i in range(cycles * per):
        k1 = f(t, s); k2 = f(t + dt/2, s + dt/2*k1); k3 = f(t + dt/2, s + dt/2*k2); k4 = f(t + dt, s + dt*k3)
        s = s + dt/6*(k1 + 2*k2 + 2*k3 + k4); t += dt; xs.append(s[0])
    return s, np.array(xs)


def sweep(ws, cycles=150, keep=20):
    """Step the forcing frequency, starting each step from the previous end state (t restarts at a whole cycle)."""
    s = np.zeros(2); amp = []
    for w in ws:
        s, xs = rk4_cycles(s, w, cycles)
        amp.append((xs[-80 * keep:].max() - xs[-80 * keep:].min()) / 2)
    return np.array(amp)


def harmonic_balance(w):
    """Amplitudes A > 0 solving [(1 - w^2) A + 3/4 beta A^3]^2 + (2 zeta w A)^2 = F^2 (a cubic in A^2)."""
    a = 9 / 16 * beta**2; b = 1.5 * beta * (1 - w * w); c = (1 - w * w)**2 + (2 * zeta * w)**2
    r = np.roots([a, b, c, -F * F])
    return sorted(math.sqrt(z.real) for z in r if abs(z.imag) < 1e-9 and z.real > 0)


if __name__ == "__main__":
    ws = np.linspace(0.8, 2.0, 61)
    up = sweep(ws); down = sweep(ws[::-1])[::-1]
    for w, a, b in zip(ws[::6], up[::6], down[::6]):
        print(f"w = {w:.2f}: sweep up {a:.4f}, sweep down {b:.4f}, harmonic balance {', '.join(f'{x:.4f}' for x in harmonic_balance(w))}")
    gap = np.abs(up - down)
    print(f"largest up/down difference {gap.max():.3f} at w = {ws[np.argmax(gap)]:.2f}")
    assert gap.max() > 0.5
    # where both agree with harmonic balance (single-valued region) the sweep is accurate
    for w, a in zip(ws, up):
        hb = harmonic_balance(w)
        if len(hb) == 1: assert abs(a / hb[0] - 1) < 0.03, (w, a, hb)
    i_up = np.argmax(np.diff(up) < -0.3); i_dn = np.argmax(np.diff(down) < -0.3)
    assert np.any(np.diff(up) < -0.3) and np.any(np.diff(down) < -0.3) and ws[i_dn] < ws[i_up]
    print(f"jump down during the upward sweep between w = {ws[i_up]:.2f} and {ws[i_up+1]:.2f}; jump up during the downward sweep between {ws[i_dn]:.2f} and {ws[i_dn+1]:.2f}")
    # the linear oscillator (beta = 0) has no hysteresis
    beta = 0.0
    lu = sweep(ws[::4], 300); ld = sweep(ws[::4][::-1], 300)[::-1]
    print(f"linear: largest up/down difference {np.abs(lu - ld).max():.1e}")
    assert np.abs(lu - ld).max() < 1e-3
```

:::exercise Backbone estimate
A cable-stayed footbridge mode behaves like a Duffing oscillator with $f_n = 1.2$ Hz and $\beta = 0.05\ \text{cm}^{-2}$ in units where $\omega_n = 1$ and $x$ is in centimetres. At what frequency does it oscillate freely with an amplitude of 4 cm?
---solution---
1. $\omega/\omega_n \approx \sqrt{1 + \tfrac34\cdot0.05\cdot4^2} = \sqrt{1.6} = 1.265$.
2. $f \approx 1.2\cdot1.265 = 1.518$ Hz.
3. A frequency shift of 26 % with amplitude means a TMD tuned at small amplitude (08.07) would be badly mistuned in a large event.
:::
