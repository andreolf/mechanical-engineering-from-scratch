A string has infinitely many degrees of freedom: every point along it can move. Yet a guitar string still has distinct modes, and their frequencies come out as exact whole-number multiples of the lowest. That's why a string sounds like a clear musical note, while a drum or a bell sounds more clangorous.

## The wave equation

Take a string of tension $T$ and mass per length $\mu$. A small element $dx$ that is curved feels a net vertical force from the tension at its two ends, $T\,\partial^2 y/\partial x^2\,dx$. Newton's law for the element gives

$$
\mu\frac{\partial^2 y}{\partial t^2} = T\frac{\partial^2 y}{\partial x^2}, \qquad c = \sqrt{\frac{T}{\mu}} .
$$

Here $c$ is the speed at which waves travel along the string.

## Standing waves

With both ends fixed, look for solutions $y = \sin(n\pi x/L)\cos(\omega_n t)$. Each satisfies the end conditions, and the wave equation then requires $\omega_n = n\pi c/L$:

$$
f_n = \frac{nc}{2L} = \frac{n}{2L}\sqrt{\frac{T}{\mu}}, \qquad n = 1, 2, 3, \dots
$$

The modes are **harmonics**: $f, 2f, 3f, \dots$. Mode $n$ has $n - 1$ nodes, points that never move. Musicians use this: lightly touching a string at its midpoint kills every odd mode and leaves the octave.

## Plucking

The pluck shape sets how much of each mode is present. A string pulled aside by $h$ at position $x_p$ and released is a triangle. Its sine-series coefficients are

$$
b_n = \frac{2hL^2}{n^2\pi^2 x_p(L - x_p)}\sin\frac{n\pi x_p}{L} .
$$

They fall as $1/n^2$. Any mode with a node at the pluck point is missing: pluck at $L/5$ and harmonics 5, 10, 15 are silent. Plucking near the bridge excites more high harmonics and sounds brighter.

:::example A guitar's high E string
Scale length $L = 0.65$ m, tension 70 N, tuned to $f_1 = 329.63$ Hz.

1. $c = 2Lf_1 = 428.5$ m/s, so $\mu = T/c^2 = 0.3812$ g/m. The whole string weighs 0.248 g.
2. Plucked 3 mm at $L/5$: modal amplitudes 2.2333, 0.9034, 0.4015, 0.1396, 0 mm, then −0.0620, … with harmonic 10 also exactly 0.
3. Checking against a finite-difference simulation of the wave equation (500 cells, leapfrog at Courant number 1): at 0.1 m from the end over 0.05 s, the two agree to within 3.5 µm on a 3 mm pluck.
4. One second of synthesised sound at 44.1 kHz with a little decay: spectral peaks at 329.62, 659.27, 988.88, 1318.52, then 1977.77 Hz. The ratios are 1, 2.0001, 3.0001, 4.0002, 6.0002: whole numbers, with 5 missing.
:::

```python file=string_modes.py
"""Vibrating string: modal synthesis of a plucked guitar string, checked against a finite-difference wave simulation."""
import math
import numpy as np


def pluck_modes(L, xp, h, N):
    """Fourier sine coefficients of a triangle of height h plucked at xp."""
    n = np.arange(1, N + 1)
    return n, 2 * h * L**2 / (n**2 * math.pi**2 * xp * (L - xp)) * np.sin(n * math.pi * xp / L)


def synth(L, c, xp, h, x_obs, t, N=40, decay=0.0):
    n, b = pluck_modes(L, xp, h, N)
    wn = n * math.pi * c / L
    return (b * np.sin(n * math.pi * x_obs / L))[None, :] @ (np.cos(np.outer(wn, t)) * np.exp(-decay * n[:, None] * t[None, :]))


def fd_string(L, c, xp, h, x_obs, T, nx=400):
    """Leapfrog on y_tt = c^2 y_xx with Courant number 1 (exact for the 1D wave equation on the grid)."""
    dx = L / nx; dt = dx / c; x = np.linspace(0, L, nx + 1)
    y = np.where(x < xp, h * x / xp, h * (L - x) / (L - xp))
    yp = y.copy(); yp[1:-1] = y[1:-1] + 0.5 * (y[2:] - 2 * y[1:-1] + y[:-2])   # first step from rest
    io = int(round(x_obs / dx)); rec = [y[io], yp[io]]
    for _ in range(int(T / dt) - 1):
        yn = np.zeros_like(y); yn[1:-1] = 2 * yp[1:-1] - y[1:-1] + (yp[2:] - 2 * yp[1:-1] + yp[:-2])
        y, yp = yp, yn; rec.append(yp[io])
    return np.arange(len(rec)) * dt, np.array(rec)


if __name__ == "__main__":
    L, T, f1 = 0.65, 70.0, 329.63          # high E string on a guitar: scale length, tension, pitch
    c = 2 * L * f1; mu = T / c**2
    print(f"wave speed {c:.1f} m/s, string mass {mu*1e3:.4f} g/m ({mu*L*1e3:.4f} g)")
    xp, h = L / 5, 0.003                    # plucked a fifth of the way along, 3 mm
    n, b = pluck_modes(L, xp, h, 12)
    print("modal amplitudes (mm):", np.round(b * 1000, 4))
    assert abs(b[4]) < 1e-15 and abs(b[9]) < 1e-15        # every 5th harmonic is missing
    tt, yfd = fd_string(L, c, xp, h, 0.1, 0.05, nx=500)
    ys = synth(L, c, xp, h, 0.1, tt, N=500)[0]
    print(f"finite differences vs modal sum at x = 0.1 m over 0.05 s: max difference {np.max(np.abs(yfd - ys))*1e6:.3f} um")
    assert np.max(np.abs(yfd - ys)) < 2e-5
    # spectrum of one second of synthesised sound (with a little decay) at the bridge pickup position
    fs = 44100; t = np.arange(fs) / fs
    y = synth(L, c, xp, h, 0.05, t, N=40, decay=0.5)[0]
    Y = np.abs(np.fft.rfft(y * np.hanning(len(y)))); fr = np.fft.rfftfreq(len(y), 1 / fs)
    # peak frequencies refined with a parabola through the log-magnitude of three bins
    lY = np.log(Y + 1e-30); pk = []
    for i in range(1, len(Y) - 1):
        if Y[i] > Y[i-1] and Y[i] >= Y[i+1] and Y[i] > 1e-3 * Y.max():
            d = 0.5 * (lY[i-1] - lY[i+1]) / (lY[i-1] - 2 * lY[i] + lY[i+1]); pk.append(fr[i] + d * (fr[1] - fr[0]))
    print("spectral peaks (Hz):", [round(float(p), 2) for p in pk[:10]])
    ratios = np.array(pk[:8]) / pk[0]
    print("ratios to the fundamental:", np.round(ratios, 4))
    assert np.allclose(ratios, np.round(ratios), atol=0.002) and abs(pk[0] - f1) < 0.05
    assert 5 not in np.round(ratios)                        # the 5th harmonic is silent
```

:::exercise Restringing
A bass guitar's open E string ($f_1 = 41.2$ Hz) has a scale length of 0.864 m and a mass of 18 g/m. What tension does it need? If you tune it down a whole tone to D (36.7 Hz), by how much does the tension fall?
---solution---
1. $c = 2Lf_1 = 2\cdot0.864\cdot41.2 = 71.19$ m/s.
2. $T = \mu c^2 = 0.018\cdot71.19^2 = 91.2$ N.
3. Tension scales with $f^2$: $(36.7/41.2)^2 = 0.7935$, so $T = 72.4$ N, about 21 % less.
:::
