In 1787 Ernst Chladni scattered sand on a metal plate and drew a violin bow along its edge. The sand jumped off the moving regions and collected along lines that stayed still, drawing intricate figures that changed with every note. Those lines are the **nodal lines** of the plate's modes: vibration in two dimensions.

## The membrane

A drum skin under tension $T$ per unit length, with mass $\rho_s$ per unit area, obeys the 2D wave equation:

$$
\frac{\partial^2 w}{\partial t^2} = c^2\left(\frac{\partial^2 w}{\partial x^2} + \frac{\partial^2 w}{\partial y^2}\right), \qquad c = \sqrt{\frac{T}{\rho_s}} .
$$

For a square of side $a$ fixed at the edges, the modes are products of string modes:

$$
w_{mn} = \sin\frac{m\pi x}{a}\sin\frac{n\pi y}{a}, \qquad \omega_{mn} = \frac{c\pi}{a}\sqrt{m^2 + n^2} .
$$

The overtones are $\sqrt{5/2} = 1.581$, $2$, $\sqrt{10/2} = 2.236$, … times the fundamental. They're not harmonic, so a square drum has no clear pitch.

## Degenerate modes

$(m, n) = (1, 2)$ and $(2, 1)$ have the same frequency. When two modes share a frequency, any combination of them is also a mode. So the pattern you see depends on exactly how the plate is excited. That's where many of Chladni's figures come from. A plate (bending stiffness, fourth-order equation) has different frequencies from a membrane, but square plates show the same effect, and the classic approximation $\cos m\pi x\cos n\pi y \pm \cos n\pi x\cos m\pi y$ reproduces many of the figures.

## Finding modes numerically

Discretise the Laplacian on a grid with the 5-point stencil from 04, giving a large sparse matrix. You only want its few lowest eigenvalues, so use a sparse eigensolver with shift-invert around zero (`scipy.sparse.linalg.eigsh` with `sigma=0`). The same approach works for drums of any shape, where no formula exists.

:::example The square membrane by finite differences
Unit square, 99 × 99 interior points, 9801 unknowns.

1. The ten smallest eigenvalues divided by $\pi^2$: 1.9998, 4.9986, 4.9986, 7.9974, 9.9933, 9.9933, 12.992, 12.992, 16.9789, 16.9789. The pattern of $m^2 + n^2$ is 2, 5, 5, 8, 10, 10, 13, 13, 17, 17, within 0.2 %.
2. They match the exact eigenvalues of the discrete operator, $\tfrac{4}{h^2}\left(\sin^2\tfrac{m\pi h}{2} + \sin^2\tfrac{n\pi h}{2}\right)$, to $10^{-9}$. The small difference from $m^2 + n^2$ is the discretisation error, not solver error.
3. Modes 2 and 3 have equal eigenvalues, 49.3342: the degenerate pair.
4. A 0.4 m square membrane with $T = 2000$ N/m and $\rho_s = 0.25$ kg/m²: $c = 89.44$ m/s, $f_{11} = 158.11$ Hz, overtones 1.581, 1.581, 2.000, 2.236, 2.236 times that.
:::

```python file=membrane.py
"""Modes of a square membrane by finite differences and scipy.sparse.linalg.eigsh."""
import math
import numpy as np
import scipy.sparse as sp
from scipy.sparse.linalg import eigsh


def laplacian_2d(N, h):
    """5-point Laplacian on the N x N interior points of a square with fixed edges (negative definite)."""
    d = sp.diags([1.0, -2.0, 1.0], [-1, 0, 1], shape=(N, N)) / h**2
    I = sp.identity(N)
    return (sp.kron(I, d) + sp.kron(d, I)).tocsc()


if __name__ == "__main__":
    a, N = 1.0, 99                       # unit square, 99 x 99 interior points
    h = a / (N + 1)
    A = -laplacian_2d(N, h)
    lam, V = eigsh(A, k=10, sigma=0, which="LM")
    order = np.argsort(lam); lam, V = lam[order], V[:, order]
    exact = sorted(math.pi**2 * (m * m + n * n) / a**2 for m in range(1, 6) for n in range(1, 6))[:10]
    # exact eigenvalues of the discrete operator, for a sharper test
    disc = sorted((4 / h**2) * (math.sin(m * math.pi * h / (2 * a))**2 + math.sin(n * math.pi * h / (2 * a))**2) for m in range(1, 6) for n in range(1, 6))[:10]
    print("lambda / pi^2:", np.round(lam / math.pi**2, 4))
    print("m^2 + n^2    :", [round(e / math.pi**2) for e in exact])
    assert np.allclose(lam, disc, rtol=1e-9)
    assert np.allclose(lam / math.pi**2, np.round(np.array(exact) / math.pi**2), rtol=2e-3)
    # frequencies of a drum-like membrane: f = c sqrt(lambda) / (2 pi), c = sqrt(T / rho_s)
    T, rho_s, side = 2000.0, 0.25, 0.4      # tension per length N/m, areal density kg/m^2, side m
    c = math.sqrt(T / rho_s)
    f11 = c / (2 * side) * math.sqrt(2)
    print(f"0.4 m square membrane: c = {c:.2f} m/s, f11 = {f11:.2f} Hz; overtone ratios", [round(math.sqrt(e / exact[0]), 3) for e in exact[:6]])
    # degenerate pair (1,2) and (2,1): equal frequencies, so any mix is also a mode (Chladni-like patterns)
    print(f"modes 2 and 3: lambda {lam[1]:.4f} and {lam[2]:.4f} (equal)")
    assert abs(lam[1] - lam[2]) < 1e-8 * lam[1]
```

:::exercise A rectangular drum
A membrane 0.6 m by 0.3 m has $c = 100$ m/s. The modes are $\omega_{mn} = c\pi\sqrt{(m/a)^2 + (n/b)^2}$. Find the three lowest frequencies in Hz. Are any degenerate?
---solution---
1. $f_{mn} = \tfrac{c}{2}\sqrt{(m/0.6)^2 + (n/0.3)^2}$.
2. $f_{11} = 50\sqrt{2.778 + 11.11} = 186.3$ Hz, $f_{21} = 50\sqrt{11.11 + 11.11} = 235.7$ Hz and $f_{31} = 50\sqrt{25 + 11.11} = 300.5$ Hz. The next ones are $f_{12} = 343.6$ Hz and then $f_{41} = 372.7$ Hz.
3. The three lowest are not degenerate. But unequal sides don't rule degeneracy out: $f_{41} = f_{22} = 372.7$ Hz, because $16/0.36 + 1/0.09 = 4/0.36 + 4/0.09 = 55.6$.
:::
