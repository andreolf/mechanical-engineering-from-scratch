Push a child on a swing at the right moment and small pushes build a big swing. Machines do the same to whatever they sit on: an unbalanced pump on a floor, an engine in a car body, a crowd on a grandstand. When the forcing frequency nears a natural frequency, the response can be many times larger than the static deflection. That's resonance.

## Steady-state response

Drive the damped oscillator with a harmonic force $F_0\cos\omega t$:

$$
m\ddot x + c\dot x + kx = F_0\cos\omega t .
$$

After the start-up transient decays, the mass moves at the forcing frequency with amplitude $X$ and a phase lag $\varphi$. Using complex notation, $F = F_0e^{i\omega t}$ and $x = Xe^{i(\omega t - \varphi)}$, the **frequency response** (receptance) is

$$
H(\omega) = \frac{X e^{-i\varphi}}{F_0} = \frac{1}{k - m\omega^2 + ic\omega} .
$$

With the frequency ratio $r = \omega/\omega_n$:

$$
\frac{X}{F_0/k} = \frac{1}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}}, \qquad \tan\varphi = \frac{2\zeta r}{1 - r^2} .
$$

## Three regions

- **Well below resonance** ($r \ll 1$): the spring dominates. $X \approx F_0/k$, in phase with the force.
- **At resonance** ($r = 1$): spring and inertia cancel and only damping limits the motion. $X = (F_0/k)/(2\zeta)$, lagging the force by 90°. That 90° lag is the cleanest way to spot a resonance in a test.
- **Well above resonance** ($r \gg 1$): inertia dominates. $X \approx F_0/(m\omega^2)$, falling fast, and 180° out of phase.

The amplitude peaks slightly below $\omega_n$, at $\omega_n\sqrt{1-2\zeta^2}$, with height $1/(2\zeta\sqrt{1-\zeta^2})$. For $\zeta > 0.707$ there is no peak at all.

:::example A machine on rubber mounts
$m = 200$ kg, $k = 2\times10^5$ N/m, $\zeta = 0.05$, driven by $F_0 = 500$ N.

1. $\omega_n = 31.623$ rad/s (5.033 Hz); $c = 2\zeta\sqrt{km} = 632.5$ N s/m; static deflection $F_0/k = 2.50$ mm.
2. Searching $|H|$ on a fine grid puts the peak at 31.544 rad/s, matching $\omega_n\sqrt{1-2\zeta^2} = 31.544$.
3. Peak amplitude 25.031 mm, an amplification of 10.0125, matching $1/(2\zeta\sqrt{1-\zeta^2})$.
4. Integrating the forced equation for 60 cycles with RK4 and measuring the last 5:

| $r$ | $\lvert H\rvert F_0$ (mm) | simulated (mm) | phase lag |
|---|---|---|---|
| 0.5 | 3.3260 | 3.3259 | 3.81° |
| 1.0 | 25.0000 | 25.0000 | 90.00° |
| 2.0 | 0.8315 | 0.8315 | 176.19° |
:::

```python file=forced.py
"""Forced vibration: frequency response H(omega) of a damped oscillator, checked against time simulation."""
import math
import numpy as np


def H(w, m, c, k):
    """Complex receptance X/F for F e^{i w t}."""
    return 1.0 / (k - m * w**2 + 1j * c * w)


def steady_amplitude_by_simulation(m, c, k, F0, w, cycles=60, per=200):
    dt = 2 * math.pi / w / per
    f = lambda t, s: np.array([s[1], (F0 * math.cos(w * t) - c * s[1] - k * s[0]) / m])
    s = np.zeros(2); t = 0.0; xs = []
    for i in range(cycles * per):
        k1 = f(t, s); k2 = f(t + dt/2, s + dt/2*k1); k3 = f(t + dt/2, s + dt/2*k2); k4 = f(t + dt, s + dt*k3)
        s = s + dt/6*(k1 + 2*k2 + 2*k3 + k4); t += dt
        if i >= (cycles - 5) * per: xs.append(s[0])
    return (max(xs) - min(xs)) / 2


if __name__ == "__main__":
    m, k, zeta, F0 = 200.0, 2e5, 0.05, 500.0     # a machine on rubber mounts, shaken by 500 N
    wn = math.sqrt(k / m); c = 2 * zeta * math.sqrt(k * m)
    print(f"omega_n = {wn:.3f} rad/s ({wn/(2*math.pi):.3f} Hz), c = {c:.1f} N s/m, static deflection {F0/k*1000:.2f} mm")
    w = np.linspace(0.01, 3 * wn, 300001)
    A = np.abs(H(w, m, c, k)) * F0
    i = np.argmax(A)
    print(f"peak at {w[i]:.3f} rad/s, theory omega_n sqrt(1 - 2 zeta^2) = {wn*math.sqrt(1-2*zeta**2):.3f}")
    assert abs(w[i] - wn * math.sqrt(1 - 2 * zeta**2)) < 1e-3
    print(f"peak amplitude {A[i]*1000:.3f} mm, dynamic amplification {A[i]/(F0/k):.4f} (theory 1/(2 zeta sqrt(1 - zeta^2)) = {1/(2*zeta*math.sqrt(1-zeta**2)):.4f})")
    for r in (0.5, 1.0, 2.0):
        h = H(r * wn, m, c, k) * F0
        xs = steady_amplitude_by_simulation(m, c, k, F0, r * wn)
        print(f"r = {r}: amplitude {abs(h)*1000:.4f} mm (simulated {xs*1000:.4f}), phase lag {-math.degrees(np.angle(h)):.2f} deg")
        assert abs(xs / abs(h) - 1) < 2e-3
```

:::exercise Staying clear of resonance
A 50 kg fan unit on springs with $\zeta = 0.03$ runs at 1450 rpm. Its rotor produces a 40 N force at running speed. The springs give a natural frequency of 20 Hz. Find the amplitude at running speed, and what it would be if the springs were swapped for ones giving 24 Hz.
---solution---
1. $\omega = 1450\cdot2\pi/60 = 151.8$ rad/s, which is 24.17 Hz.
2. With $f_n = 20$ Hz: $k = 50(2\pi\cdot20)^2 = 7.896\times10^5$ N/m, $r = 1.208$, amplification $1/\sqrt{(1-1.460)^2 + (0.0725)^2} = 2.147$. $X = 2.147\cdot40/7.896\times10^5 = 0.109$ mm.
3. With $f_n = 24$ Hz: $r = 1.007$, amplification 16.1, and $X = 0.57$ mm, five times worse. Stiffer is not always better; here softer springs (lower $f_n$) would help most.
:::
