Open a bottle of compressed air and the hiss reaches a limit: past a certain pressure ratio, lowering the outside pressure doesn't push any more air through. The flow at the narrowest point has reached the speed of sound, and no signal about the outside pressure can travel upstream against it. That's **choking**, and the shape that gets past it, a converging-diverging nozzle, powers every rocket and supersonic wind tunnel.

## The area-Mach relation

For steady isentropic flow in a duct of slowly varying area $A$, mass, momentum and energy combine into

$$
\frac{dA}{A} = (M^2 - 1)\frac{dV}{V} .
$$

Subsonic flow ($M < 1$) speeds up in a converging duct, as in a garden hose. Supersonic flow ($M > 1$) speeds up in a **diverging** duct, because density falls faster than velocity rises. So to accelerate from rest to supersonic speed, the duct must converge to a throat where $M = 1$ exactly, then diverge. Integrating gives the area ratio relative to the sonic throat area $A^*$:

$$
\frac{A}{A^*} = \frac1M\left[\frac{2}{k+1}\left(1 + \frac{k-1}{2}M^2\right)\right]^{\frac{k+1}{2(k-1)}} .
$$

Each area ratio has two solutions, one subsonic and one supersonic.

## Choked mass flow

With $M = 1$ at the throat, the mass flow depends only on the supply conditions:

$$
\dot m_{\max} = A^*\,\frac{p_0}{\sqrt{T_0}}\sqrt{\frac kR}\left(\frac{2}{k+1}\right)^{\frac{k+1}{2(k-1)}} = 0.040415\,\frac{A^* p_0}{\sqrt{T_0}}\ \text{for air (SI)} .
$$

## Back pressure

Lower the back pressure $p_b$ from $p_0$:

1. The flow is subsonic throughout, fastest at the throat.
2. At the first critical pressure the throat reaches $M = 1$: the nozzle chokes.
3. Below that, the diverging section goes supersonic and ends in a **normal shock** (next lesson), which moves downstream as $p_b$ falls.
4. When the shock reaches the exit, the whole nozzle flows supersonic. Below this, the exit pressure is fixed, and any mismatch with $p_b$ is sorted out by oblique shocks or expansion fans outside.

From step 2 on, the mass flow never changes.

Pressure along a converging-diverging nozzle (exit area twice the throat). Lower the back pressure and watch it choke, then push the shock out.
:::

:::example A 7 bar air nozzle
Supply $p_0 = 700$ kPa, $T_0 = 300$ K, throat 1 cm², exit 2 cm².

1. $A/A^* = 2$ has two solutions: M = 0.30590 and M = 2.19720.
2. Critical back pressures: choking at 6.5601 bar, a shock standing at the exit at 3.5938 bar, design exit pressure 0.6575 bar.
3. Mass flow: 80.021 g/s at 6.9 bar and 156.267 g/s at 6.6 bar (not choked); 163.33487 g/s at every back pressure from 6.5 bar down to vacuum. That equals $0.040415\,A^*p_0/\sqrt{T_0}$.
4. The shock sits at $A/A_t$ = 1.0329 for 6.5 bar, 1.3261 for 5.5 bar and 1.8331 for 4.0 bar, moving out as the back pressure falls.
:::

```python file=nozzle.py
"""Converging-diverging nozzle: the area-Mach relation, choked mass flow, and where a normal shock sits for a given back pressure."""
import math

K, R = 1.4, 287.05


def area_ratio(M, k=K):
    """A/A* for isentropic flow at Mach M."""
    return (1 / M) * ((2 / (k + 1)) * (1 + (k - 1) / 2 * M * M)) ** ((k + 1) / (2 * (k - 1)))


def mach_from_area(Ar, supersonic, k=K):
    lo, hi = (1.0, 50.0) if supersonic else (1e-9, 1.0)
    for _ in range(200):
        m = (lo + hi) / 2
        too_big = area_ratio(m, k) > Ar
        if supersonic: lo, hi = (lo, m) if too_big else (m, hi)
        else: lo, hi = (m, hi) if too_big else (lo, m)
    return (lo + hi) / 2


def p_ratio(M, k=K):
    return (1 + (k - 1) / 2 * M * M) ** (-k / (k - 1))


def shock(M1, k=K):
    M2 = math.sqrt((1 + (k - 1) / 2 * M1 ** 2) / (k * M1 ** 2 - (k - 1) / 2))
    p21 = 1 + 2 * k / (k + 1) * (M1 ** 2 - 1)
    p0r = p21 * p_ratio(M1, k) / p_ratio(M2, k)          # p02/p01 = (p2/p1) (p1/p01) / (p2/p02)
    return M2, p21, p0r


def nozzle(p0, T0, At, Ae, pb, k=K):
    """Mass flow and exit state for back pressure pb. Returns (mdot, regime, shock area or None, exit pressure)."""
    Are = Ae / At
    Me_sub, Me_sup = mach_from_area(Are, False), mach_from_area(Are, True)
    p_crit1 = p0 * p_ratio(Me_sub)                       # subsonic everywhere, just sonic at the throat
    M2s, p21, _ = shock(Me_sup); p_crit2 = p0 * p_ratio(Me_sup) * p21   # normal shock standing at the exit
    mdot_choked = At * p0 / math.sqrt(T0) * math.sqrt(k / R) * (2 / (k + 1)) ** ((k + 1) / (2 * (k - 1)))
    if pb >= p0: return 0.0, "no flow", None, pb
    if pb >= p_crit1:                                     # unchoked: subsonic throughout, exit pressure = pb
        Me = math.sqrt(2 / (k - 1) * ((p0 / pb) ** ((k - 1) / k) - 1))
        Astar = Ae / area_ratio(Me)
        return Astar / At * mdot_choked, "subsonic, not choked", None, pb
    if pb >= p_crit2:                                     # shock in the diverging part: find its area by bisection
        lo, hi = At * 1.0000001, Ae
        def exit_p(As):
            M1 = mach_from_area(As / At, True); _, _, p0r = shock(M1)
            Astar2 = At / p0r                             # throat area that the post-shock flow would need
            Me = mach_from_area(Ae / Astar2, False)
            return p0 * p0r * p_ratio(Me)
        for _ in range(100):
            m = (lo + hi) / 2
            lo, hi = (m, hi) if exit_p(m) > pb else (lo, m)
        return mdot_choked, "normal shock inside the nozzle", (lo + hi) / 2, pb
    return mdot_choked, "supersonic exit (over- or under-expanded outside)", None, p0 * p_ratio(Me_sup)


if __name__ == "__main__":
    p0, T0, At, Ae = 700e3, 300.0, 1.0e-4, 2.0e-4          # a 7 bar air supply, 1 cm^2 throat, exit twice as big
    Me_sub, Me_sup = mach_from_area(2.0, False), mach_from_area(2.0, True)
    print(f"A/A* = 2: subsonic M = {Me_sub:.5f}, supersonic M = {Me_sup:.5f}")
    assert abs(area_ratio(Me_sub) - 2) < 1e-9 and abs(area_ratio(Me_sup) - 2) < 1e-9
    flows = []
    for pb_bar in (6.9, 6.6, 6.5, 5.5, 4.0, 2.0, 0.6, 0.0):
        md, regime, As, pe = nozzle(p0, T0, At, Ae, pb_bar * 1e5)
        flows.append((pb_bar, md))
        print(f"pb = {pb_bar:4.1f} bar: mdot = {md*1000:.5f} g/s, {regime}" + (f", shock at A/At = {As/At:.4f}" if As else ""))
    choked = [md for pb, md in flows if pb <= 6.5]
    assert max(choked) - min(choked) < 1e-15                # choked flow doesn't depend on back pressure
    c = math.sqrt(K / R) * (2 / (K + 1)) ** ((K + 1) / (2 * (K - 1)))
    print(f"choked mass flow = {c:.6f} A* p0 / sqrt(T0) = {c*At*p0/math.sqrt(T0)*1000:.5f} g/s")
    print(f"critical back pressures: choking at {p0*p_ratio(Me_sub)/1e5:.4f} bar, shock at the exit at {p0*p_ratio(Me_sup)*shock(Me_sup)[1]/1e5:.4f} bar, design exit {p0*p_ratio(Me_sup)/1e5:.4f} bar")
```

:::exercise A tyre valve
Air leaks from a tyre at 3.5 bar absolute and 20 °C through a hole of 0.5 mm² to the atmosphere (1.013 bar). Is the flow choked? What's the mass flow, ignoring friction?
---solution---
1. Choking needs $p_b/p_0 < (2/(k+1))^{k/(k-1)} = 0.5283$. Here $1.013/3.5 = 0.289$: choked.
2. $\dot m = 0.040415\cdot0.5\times10^{-6}\cdot350\,000/\sqrt{293.15} = 4.131\times10^{-4}$ kg/s, about 0.41 g/s.
3. The flow stays the same until the tyre pressure drops below $1.013/0.5283 = 1.92$ bar.
:::
