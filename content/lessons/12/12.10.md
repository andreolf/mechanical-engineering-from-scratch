Zürich's water mains carry around 300 000 m³ a day. Almost all of that flow is turbulent, so the neat Hagen-Poiseuille law from lesson 11.14 doesn't apply. Engineers instead use an empirical friction factor, found from experiments on rough pipes in the 1930s and summarised in the **Moody chart**.

## Darcy-Weisbach

Dimensional analysis says the pressure drop in a long straight pipe depends on $\mathrm{Re}$ and the relative roughness $\varepsilon/D$. Writing it as

$$
h_f = \frac{\Delta p}{\rho g} = f\,\frac{L}{D}\,\frac{V^2}{2g}
$$

defines the **Darcy friction factor** $f(\mathrm{Re}, \varepsilon/D)$. For laminar flow, Hagen-Poiseuille gives exactly $f = 64/\mathrm{Re}$, independent of roughness.

## The Colebrook equation

For turbulent flow, Colebrook (1939) blended the smooth-pipe law of Prandtl and von Kármán with the fully rough law of Nikuradse:

$$
\frac{1}{\sqrt f} = -2\log_{10}\!\left(\frac{\varepsilon/D}{3.7} + \frac{2.51}{\mathrm{Re}\sqrt f}\right) .
$$

$f$ appears on both sides, so solve it iteratively. Writing $x = 1/\sqrt f$, the fixed-point iteration $x \leftarrow -2\log_{10}(\varepsilon/3.7D + 2.51x/\mathrm{Re})$ converges in a few steps. The explicit Haaland formula, $1/\sqrt f = -1.8\log_{10}[(\varepsilon/3.7D)^{1.11} + 6.9/\mathrm{Re}]$, is within about 2% and makes a good starting guess.

Three regimes show on the Moody chart:

- **Laminar**, $\mathrm{Re} < 2300$: $f = 64/\mathrm{Re}$.
- **Transitional**, $2300 < \mathrm{Re} < 4000$: unpredictable; avoid designing here.
- **Turbulent**: $f$ falls with Re for smooth pipes, then levels off at a constant set by roughness once the roughness pokes through the viscous sublayer (**fully rough**).

:::example A cast-iron water main
1. Laminar check: for Re = 500, 1000 and 2000 the solver returns exactly 0.128, 0.064 and 0.032 = 64/Re.
2. Turbulent values (every one satisfies Colebrook to $10^{-12}$):

| Re | Smooth | $\varepsilon/D = 10^{-4}$ | $\varepsilon/D = 0.01$ | Haaland, 0.01 |
|---|---|---|---|---|
| $10^4$ | 0.03088 | 0.03104 | 0.04313 | 0.04304 |
| $10^5$ | 0.01799 | 0.01851 | 0.03850 | 0.03854 |
| $10^6$ | 0.01165 | 0.01344 | 0.03796 | 0.03804 |
| $10^8$ | 0.00594 | 0.01200 | 0.03790 | 0.03798 |

3. A 1 km cast-iron main, D = 200 mm, $\varepsilon = 0.26$ mm, carrying 50 L/s: V = 1.592 m/s, Re = $3.183\times10^5$, f = 0.02172, head loss 14.020 m (1.375 bar).
4. Fully rough, $\varepsilon/D = 0.0013$: f = 0.02095, matching von Kármán's $(2\log_{10}(3.7D/\varepsilon))^{-2}$.
:::

```python file=colebrook.py
"""Turbulent pipe friction: solve the Colebrook equation, compare with Haaland, and use Darcy-Weisbach for head loss."""
import math

G = 9.81


def colebrook(Re, rel_rough, tol=1e-14):
    """Darcy friction factor. Laminar below Re = 2300; otherwise fixed-point iteration on x = 1/sqrt(f)."""
    if Re < 2300:
        return 64 / Re
    x = 1 / math.sqrt(haaland(Re, rel_rough))
    for _ in range(100):
        x_new = -2 * math.log10(rel_rough / 3.7 + 2.51 * x / Re)
        if abs(x_new - x) < tol: break
        x = x_new
    return 1 / x_new ** 2


def haaland(Re, rel_rough):
    return (-1.8 * math.log10((rel_rough / 3.7) ** 1.11 + 6.9 / Re)) ** -2


def head_loss(Q, D, L, rough, nu=1.0e-6):
    V = Q / (math.pi * D * D / 4); Re = V * D / nu
    f = colebrook(Re, rough / D)
    return f * L / D * V * V / (2 * G), f, Re, V


if __name__ == "__main__":
    for Re in (500, 1000, 2000):
        assert colebrook(Re, 1e-3) == 64 / Re                     # laminar limit, roughness doesn't matter
    print("laminar: f = 64/Re for Re = 500, 1000, 2000 ->", [round(colebrook(R, 1e-3), 4) for R in (500, 1000, 2000)])
    for Re in (1e4, 1e5, 1e6, 1e8):
        for e in (0.0, 1e-4, 1e-2):
            f = colebrook(Re, e)
            x = 1 / math.sqrt(f)
            assert abs(x + 2 * math.log10(e / 3.7 + 2.51 * x / Re)) < 1e-12
        print(f"Re = {Re:.0e}: smooth {colebrook(Re, 0):.5f}, e/D = 1e-4 {colebrook(Re, 1e-4):.5f}, e/D = 0.01 {colebrook(Re, 1e-2):.5f} (Haaland {haaland(Re, 1e-2):.5f})")
    # a 1 km cast-iron main (D = 200 mm, roughness 0.26 mm) carrying 50 L/s
    hf, f, Re, V = head_loss(0.05, 0.2, 1000, 0.26e-3)
    print(f"water main: V = {V:.3f} m/s, Re = {Re:.3e}, f = {f:.5f}, head loss {hf:.3f} m ({1000*G*hf/1e5:.3f} bar)")
    # fully rough limit: f independent of Re
    print(f"fully rough e/D = 0.0013: f = {colebrook(1e9, 0.0013):.5f}, von Karman (2 log10(3.7 D/e))^-2 = {(2*math.log10(3.7/0.0013))**-2:.5f}")
```

:::exercise A farm irrigation pipe
A 500 m PVC pipe (smooth), 100 mm across, carries 12 L/s of water ($\nu = 10^{-6}$ m²/s). Find V, Re and the head loss, using Colebrook for the friction factor. How much power does the pump spend on friction?
---solution---
1. $V = 0.012/(\pi\cdot0.1^2/4) = 1.528$ m/s; $\mathrm{Re} = 1.528\cdot0.1/10^{-6} = 1.53\times10^5$.
2. Colebrook with $\varepsilon = 0$ gives $f = 0.01649$.
3. $h_f = 0.01649\cdot(500/0.1)\cdot1.528^2/(2\cdot9.81) = 9.81$ m.
4. Power: $\rho g Q h_f = 1000\cdot9.81\cdot0.012\cdot9.81 = 1155$ W.
:::
