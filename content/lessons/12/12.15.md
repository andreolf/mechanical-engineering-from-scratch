When supersonic flow has to slow down abruptly, at the nose of a blunt body, in an engine inlet or in an over-pressured nozzle, it does so through a **shock wave**: a layer a few molecular free paths thick across which pressure, density and temperature jump almost instantly. Inside the shock, viscosity and heat conduction are intense, so it's irreversible. Outside it, we can treat the jumps as discontinuities and find them from conservation laws alone.

## Rankine-Hugoniot relations

In a frame moving with a normal shock, gas enters at $M_1 > 1$ and leaves at $M_2$. Mass, momentum and energy are conserved across it:

$$
\rho_1u_1 = \rho_2u_2, \qquad p_1 + \rho_1u_1^2 = p_2 + \rho_2u_2^2, \qquad h_1 + \tfrac12u_1^2 = h_2 + \tfrac12u_2^2 .
$$

For an ideal gas these give closed-form jumps:

$$
M_2^2 = \frac{1 + \frac{k-1}{2}M_1^2}{kM_1^2 - \frac{k-1}{2}}, \qquad \frac{p_2}{p_1} = 1 + \frac{2k}{k+1}(M_1^2 - 1), \qquad \frac{\rho_2}{\rho_1} = \frac{(k+1)M_1^2}{(k-1)M_1^2 + 2} .
$$

The flow behind a normal shock is always subsonic. Stagnation temperature is unchanged (energy is conserved), but stagnation pressure drops.

## Why shocks only compress

The same algebra also allows $M_1 < 1$: an "expansion shock". The second law rules it out. The entropy change

$$
s_2 - s_1 = c_p\ln\frac{T_2}{T_1} - R\ln\frac{p_2}{p_1}
$$

is positive only for $M_1 > 1$. For $M_1 < 1$ it would be negative, so expansions happen smoothly through fans instead. The lost stagnation pressure, $p_{02}/p_{01} = e^{-\Delta s/R}$, is why supersonic inlets use a series of weak oblique shocks rather than one strong normal shock.

## The shock tube

A tube with high-pressure gas on one side of a diaphragm and low-pressure gas on the other is the classic test. When the diaphragm bursts, a shock runs into the low-pressure gas, an expansion fan runs back into the high-pressure gas, and a contact surface separates the two gases. Sod's version (pressures 1 and 0.1, densities 1 and 0.125) is the standard benchmark for CFD codes.

2. Plugging these back in, the mass and momentum residuals are 0 and the energy residual $9\times10^{-16}$; $u_2/a_2$ reproduces $M_2$.
3. Entropy rise and stagnation pressure kept:

| $M_1$ | 1.0 | 1.2 | 1.5 | 2.0 | 3.0 | 5.0 |
|---|---|---|---|---|---|---|
| $\Delta s$, J/(kg K) | 0 | 2.0747 | 20.8973 | 93.9489 | 319.6858 | 799.4936 |
| $p_{02}/p_{01}$ | 100% | 99.28% | 92.98% | 72.09% | 32.83% | 6.17% |

4. An expansion shock at $M_1 = 0.8$ would need $\Delta s = -4.7010$ J/(kg K): impossible.
5. Sod's tube, solved exactly: $p^* = 0.30313$, $u^* = 0.92745$, shock speed 1.75216, shock Mach 1.65563. The pressure ratio across it, 3.03130, matches the normal-shock formula to $10^{-9}$.

```python file=shock.py
"""Normal shocks: the Rankine-Hugoniot jump relations, a conservation and entropy check, and the exact Sod shock tube."""
import math

K, R = 1.4, 287.05
CP = K * R / (K - 1)


def normal_shock(M1, k=K):
    M2 = math.sqrt((1 + (k - 1) / 2 * M1 ** 2) / (k * M1 ** 2 - (k - 1) / 2))
    p21 = 1 + 2 * k / (k + 1) * (M1 ** 2 - 1)
    r21 = (k + 1) * M1 ** 2 / ((k - 1) * M1 ** 2 + 2)
    T21 = p21 / r21
    return M2, p21, r21, T21


def entropy_jump(M1, k=K):
    _, p21, _, T21 = normal_shock(M1, k)
    return CP * math.log(T21) - R * math.log(p21)


def sod_exact(rhoL=1.0, pL=1.0, rhoR=0.125, pR=0.1, k=K):
    """Star-region pressure and velocity for a shock tube with gas at rest (Toro's exact Riemann solver, two-shock-or-rarefaction functions)."""
    aL, aR = math.sqrt(k * pL / rhoL), math.sqrt(k * pR / rhoR)
    def f(p, rho, pk, a):
        if p > pk:
            A, B = 2 / ((k + 1) * rho), (k - 1) / (k + 1) * pk
            return (p - pk) * math.sqrt(A / (p + B))
        return 2 * a / (k - 1) * ((p / pk) ** ((k - 1) / (2 * k)) - 1)
    lo, hi = 1e-8, 10 * max(pL, pR)
    for _ in range(200):
        m = (lo + hi) / 2
        lo, hi = (m, hi) if f(m, rhoL, pL, aL) + f(m, rhoR, pR, aR) < 0 else (lo, m)
    p = (lo + hi) / 2
    u = 0.5 * (f(p, rhoR, pR, aR) - f(p, rhoL, pL, aL))
    g = (k - 1) / (k + 1)
    rho2 = rhoR * (p / pR + g) / (g * p / pR + 1)          # density behind the right-moving shock
    S = u * rho2 / (rho2 - rhoR)                             # shock speed from mass conservation
    return p, u, S, aR


if __name__ == "__main__":
    M1 = 2.0
    M2, p21, r21, T21 = normal_shock(M1)
    print(f"M1 = {M1}: M2 = {M2:.5f}, p2/p1 = {p21:.4f}, rho2/rho1 = {r21:.4f}, T2/T1 = {T21:.4f}")
    # conservation across the shock, per unit p1 and rho1 (shock frame)
    a1 = math.sqrt(K); u1 = M1 * a1; u2 = u1 / r21; a2 = math.sqrt(K * p21 / r21)
    mass = 1 * u1 - r21 * u2
    mom = (1 + u1 ** 2) - (p21 + r21 * u2 ** 2)
    h = lambda p, rho: K / (K - 1) * p / rho
    energy = (h(1, 1) + u1 ** 2 / 2) - (h(p21, r21) + u2 ** 2 / 2)
    print(f"residuals: mass {mass:.1e}, momentum {mom:.1e}, energy {energy:.1e}; M2 from u2/a2 = {u2/a2:.5f}")
    assert max(abs(mass), abs(mom), abs(energy)) < 1e-12 and abs(u2 / a2 - M2) < 1e-12
    for M in (1.0, 1.2, 1.5, 2.0, 3.0, 5.0):
        ds = entropy_jump(M)
        print(f"M1 = {M}: entropy rise {ds:9.4f} J/(kg K), stagnation pressure kept {math.exp(-ds/R)*100:6.2f} %")
        assert ds >= -1e-12                                       # entropy never falls across a shock
    print(f"an 'expansion shock' at M1 = 0.8 would need ds = {entropy_jump(0.8):.4f} J/(kg K) < 0: impossible")
    assert entropy_jump(0.8) < 0
    # Sod's shock tube: the shock it launches obeys the same relations
    p, u, S, aR = sod_exact()
    Ms = S / aR
    print(f"Sod: p* = {p:.5f}, u* = {u:.5f}, shock speed {S:.5f}, shock Mach {Ms:.5f}; p*/pR = {p/0.1:.5f} vs normal-shock {normal_shock(Ms)[1]:.5f}")
    assert abs(p / 0.1 - normal_shock(Ms)[1]) < 1e-9
```

:::exercise A supersonic inlet
Air at Mach 2.5, 220 K and 25 kPa passes through a normal shock in an engine inlet. Find $M_2$, $p_2$, $T_2$ and the fraction of stagnation pressure lost.
---solution---
1. $M_2^2 = (1 + 0.2\cdot6.25)/(1.4\cdot6.25 - 0.2) = 2.25/8.55 = 0.26316$, so $M_2 = 0.5130$.
2. $p_2/p_1 = 1 + (2.8/2.4)(6.25 - 1) = 7.125$, so $p_2 = 178.1$ kPa.
3. $\rho_2/\rho_1 = 2.4\cdot6.25/(0.4\cdot6.25 + 2) = 3.3333$; $T_2/T_1 = 7.125/3.3333 = 2.1375$, so $T_2 = 470.3$ K.
4. $p_{02}/p_{01} = 7.125\cdot(1 + 0.2\cdot6.25)^{-3.5}/(1 + 0.2\cdot0.26316)^{-3.5} = 0.4990$: half the stagnation pressure is lost.
:::
