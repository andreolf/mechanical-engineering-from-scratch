A pump on its own doesn't have "a flow rate". It has a curve of head against flow, and the pipeline it feeds has another. Where they cross is where the system runs. Getting that crossing near the pump's best efficiency is what separates a quiet, cheap installation from a noisy one that burns power and wears out its bearings.

## Pump curve and system curve

A centrifugal pump adds most head at shut-off (zero flow) and less as flow rises, roughly

$$
H_{\text{pump}} = H_0 - aQ^2 .
$$

The **system** needs a static lift $H_s$ (raising water to a tank) plus friction losses that grow as $Q^2$ in turbulent flow (lesson 12.10):

$$
H_{\text{sys}} = H_s + kQ^2 .
$$

The **operating point** is where $H_{\text{pump}} = H_{\text{sys}}$. The shaft power is $P = \rho g Q H/\eta$, with the efficiency $\eta$ peaking at the **best efficiency point** (BEP).

## Affinity laws

Changing speed is the efficient way to change flow (much better than throttling a valve). Dimensional analysis with the flow coefficient $Q/(ND^3)$ and head coefficient $gH/(N^2D^2)$ held constant gives, for one pump at a new speed:

$$
\frac{Q_2}{Q_1} = \frac{N_2}{N_1}, \qquad \frac{H_2}{H_1} = \left(\frac{N_2}{N_1}\right)^2, \qquad \frac{P_2}{P_1} = \left(\frac{N_2}{N_1}\right)^3 .
$$

Each point of the pump curve moves to a "similar" point with the same efficiency. A word of care: the *operating* flow scales with speed only if the system curve is a parabola through the origin (no static lift). With static lift, slowing down cuts the flow faster, and below a certain speed the pump can't lift the water at all.

:::example A pump lifting to a village tank
Pump: $H = 40(N/1450)^2 - 4000Q^2$, BEP at 60 L/s at 1450 rpm, peak efficiency 78%. System: $H = 15 + 3000Q^2$.

| Speed | Q, L/s | H, m | Efficiency | Shaft power, kW |
|---|---|---|---|---|
| 1450 rpm | 59.761 | 25.714 | 0.780 | 19.328 |
| 1200 rpm | 42.081 | 20.313 | 0.762 | 11.007 |
| 1000 rpm | 23.979 | 16.725 | 0.642 | 6.127 |

1. Affinity check at $r = 1200/1450 = 0.8276$: every pump-curve point $(Q, H)$ maps exactly to $(rQ, r^2H)$ on the slower curve, with the same efficiency. Power scales by $r^3 = 0.5668$.
2. With 15 m of static lift, cutting speed by 17% cuts the operating flow by 30%.
3. With no static lift, the operating flow ratio is 0.827586, exactly the speed ratio.
:::

```python file=pumps.py
"""Pump and system curves: the operating point, and the affinity laws for a change of speed."""
import math

RHO, G = 1000.0, 9.81


def pump_head(Q, N, H0=40.0, a=4000.0, N0=1450.0):
    """A typical centrifugal pump curve at speed N (rpm): H = H0 (N/N0)^2 - a Q^2."""
    return H0 * (N / N0) ** 2 - a * Q * Q


def pump_eff(Q, N, Qbep=0.06, N0=1450.0, eta_max=0.78):
    """Efficiency peaks at the best-efficiency flow, which moves with speed (affinity)."""
    q = Q / (Qbep * N / N0)
    return max(0.0, eta_max * (2 * q - q * q))


def system_head(Q, Hs=15.0, k=3000.0):
    """Static lift plus friction losses that grow as Q^2."""
    return Hs + k * Q * Q


def operating_point(N, **sys):
    lo, hi = 0.0, 1.0
    for _ in range(200):
        m = (lo + hi) / 2
        lo, hi = (m, hi) if pump_head(m, N) > system_head(m, **sys) else (lo, m)
    return (lo + hi) / 2


if __name__ == "__main__":
    for N in (1450, 1200, 1000):
        Q = operating_point(N); H = system_head(Q); eta = pump_eff(Q, N)
        P = RHO * G * Q * H / eta
        print(f"N = {N} rpm: Q = {Q*1000:.3f} L/s, H = {H:.3f} m, efficiency {eta:.3f}, shaft power {P/1000:.3f} kW")
    # affinity laws: a point (Q, H) on the curve at N maps to (Q r, H r^2) at r N, with power r^3
    r = 1200 / 1450
    for Q in (0.02, 0.05, 0.08):
        H = pump_head(Q, 1450)
        assert abs(pump_head(Q * r, 1200) - H * r * r) < 1e-12           # flow linear in speed, head quadratic
        assert abs(pump_eff(Q * r, 1200) - pump_eff(Q, 1450)) < 1e-12     # same efficiency at the similar point
    print(f"affinity check passed for r = {r:.4f}: flow x {r:.4f}, head x {r*r:.4f}, power x {r**3:.4f}")
    # with no static lift the system curve is itself a parabola through the origin, so the operating flow scales exactly
    Q1, Q2 = operating_point(1450, Hs=0.0), operating_point(1200, Hs=0.0)
    print(f"no static lift: Q ratio {Q2/Q1:.6f} = speed ratio {r:.6f}")
    assert abs(Q2 / Q1 - r) < 1e-9
```

:::exercise Slowing a fan
A ventilation fan delivers 2.0 m³/s at 900 rpm against 400 Pa, using 1.1 kW. The duct has no static pressure, only friction. What flow, pressure and power at 720 rpm?
---solution---
1. $r = 720/900 = 0.8$.
2. Flow: $2.0\cdot0.8 = 1.6$ m³/s (no static head, so the operating point scales).
3. Pressure: $400\cdot0.8^2 = 256$ Pa.
4. Power: $1.1\cdot0.8^3 = 0.5632$ kW, about half, for 80% of the airflow.
:::
