A Balinese village gets its water from a spring tank on the hill, through a grid of pipes that loops around the banjar's lanes. Loops make a network reliable: if one pipe breaks, water reaches every house another way. But loops also make it hard to say which way and how much water flows in each pipe. In 1936 Hardy Cross found a method simple enough to do by hand.

## Two laws

A network of pipes and nodes obeys:

1. **Continuity at every node:** flow in equals flow out plus the demand drawn off there, $\sum Q_{\text{in}} - \sum Q_{\text{out}} = q_{\text{node}}$.
2. **Energy around every loop:** going round a closed loop you come back to the same head, so the signed head losses sum to zero, $\sum_{\text{loop}} \pm h_f = 0$.

Each pipe's loss is $h = K\,Q|Q|$, with $K = 8fL/(g\pi^2D^5)$ from Darcy-Weisbach. The loss is nonlinear in $Q$, so the equations need iteration.

## Hardy Cross

1. Guess flows that satisfy continuity at every node (any guess will do).
2. For each loop, the head imbalance is $\sum s\,K Q|Q|$, with $s = \pm1$ for pipes running with or against the loop direction. A first-order Taylor expansion gives the correction that balances it:

$$
\Delta Q = -\frac{\sum s\,K\,Q|Q|}{\sum 2K|Q|} .
$$

3. Add $s\,\Delta Q$ to every pipe in the loop. The same amount enters and leaves each node of the loop, so continuity stays exact.
4. Repeat for all loops until the corrections are negligible.

It's Newton's method applied loop by loop. Modern tools such as EPANET solve all the nodes together with a global Newton method, but the physics is the same.

:::example A village grid
Six nodes, seven pipes (300–400 m long, 100–200 mm across, f = 0.02), 60 L/s entering at node 0 and drawn off at the others (10, 10, 10, 15, 15 L/s).

1. The starting guess satisfies continuity exactly. Hardy Cross converges in 7 sweeps, with corrections falling 4.7e-3, 1.0e-3, 3.8e-5, 3.8e-7, 3.3e-9 m³/s: Newton-like convergence.
2. Final flows (L/s): 0-1 34.939, 1-2 16.859, 0-3 25.061, 1-4 8.079, 2-5 6.859, 3-4 15.061, 4-5 8.141.
3. The largest continuity error at any node is $1.6\times10^{-17}$ m³/s: mass is conserved at every node.
4. An independent solution, with node heads as the unknowns and SciPy's fsolve, gives the same flows to $2\times10^{-12}$ L/s. With 50 m of head at the tank, the lowest head is 42.672 m at node 5, the far corner.
:::

```python file=hardycross.py
"""Hardy Cross on a looped village water network, checked against an independent node-head solution."""
import math
import numpy as np
from scipy.optimize import fsolve

G = 9.81
# nodes: 0 1 2 on top, 3 4 5 below; water enters at 0
pipes = [(0, 1, 400, 0.20), (1, 2, 400, 0.15), (0, 3, 300, 0.20), (1, 4, 300, 0.15),
         (2, 5, 300, 0.10), (3, 4, 400, 0.15), (4, 5, 400, 0.10)]          # (from, to, length m, diameter m)
demand = np.array([-0.060, 0.010, 0.010, 0.010, 0.015, 0.015])           # m^3/s; negative = supply
loops = [[(0, +1), (3, +1), (5, -1), (2, -1)],                           # 0-1-4-3-0
         [(1, +1), (4, +1), (6, -1), (3, -1)]]                           # 1-2-5-4-1
F = 0.02
K = np.array([8 * F * L / (G * math.pi ** 2 * D ** 5) for _, _, L, D in pipes])


def hardy_cross(Q, tol=1e-12, max_iter=200):
    Q = Q.copy(); history = []
    for it in range(max_iter):
        biggest = 0.0
        for loop in loops:
            num = sum(s * K[p] * Q[p] * abs(Q[p]) for p, s in loop)
            den = sum(2 * K[p] * abs(Q[p]) for p, s in loop)
            dQ = -num / den
            for p, s in loop: Q[p] += s * dQ
            biggest = max(biggest, abs(dQ))
        history.append(biggest)
        if biggest < tol: break
    return Q, history


def node_residual(Q):
    r = demand.copy()
    for k, (a, b, _, _) in enumerate(pipes):
        r[a] += Q[k]; r[b] -= Q[k]
    return r


if __name__ == "__main__":
    Q0 = np.array([0.030, 0.012, 0.030, 0.008, 0.002, 0.020, 0.013])     # any guess that satisfies continuity
    assert np.max(np.abs(node_residual(Q0))) < 1e-15
    Q, hist = hardy_cross(Q0)
    print(f"converged in {len(hist)} sweeps; corrections {', '.join(f'{h:.1e}' for h in hist[:5])} ...")
    for k, (a, b, L, D) in enumerate(pipes):
        print(f"pipe {a}-{b}: {Q[k]*1000:8.3f} L/s, head loss {K[k]*Q[k]*abs(Q[k]):7.3f} m")
    res = node_residual(Q)
    print(f"largest continuity error at a node: {np.max(np.abs(res)):.1e} m^3/s")
    assert np.max(np.abs(res)) < 1e-15                                     # mass conserved at every node
    for loop in loops:
        assert abs(sum(s * K[p] * Q[p] * abs(Q[p]) for p, s in loop)) < 1e-9
    # independent check: unknown node heads (node 0 fixed at 50 m), flows from h = K Q|Q|
    def eqs(H):
        Hall = np.concatenate([[50.0], H]); Qn = np.array([np.sign(Hall[a] - Hall[b]) * math.sqrt(abs(Hall[a] - Hall[b]) / K[k]) for k, (a, b, _, _) in enumerate(pipes)])
        return node_residual(Qn)[1:]
    H = fsolve(eqs, np.full(5, 40.0), xtol=1e-12)
    Hall = np.concatenate([[50.0], H])
    Qn = np.array([np.sign(Hall[a] - Hall[b]) * math.sqrt(abs(Hall[a] - Hall[b]) / K[k]) for k, (a, b, _, _) in enumerate(pipes)])
    print(f"node-head solution differs by at most {np.max(np.abs(Qn - Q))*1000:.1e} L/s; lowest head {Hall.min():.3f} m at node {Hall.argmin()}")
    assert np.max(np.abs(Qn - Q)) < 1e-8
```

:::exercise One correction by hand
A single loop has three pipes. Going round it, the flows are +30, +10 and −20 L/s, with $K$ = 1000, 4000 and 2000 s²/m⁵. Find the head imbalance and the first Hardy Cross correction.
---solution---
1. Imbalance: $1000\cdot0.03^2 + 4000\cdot0.01^2 - 2000\cdot0.02^2 = 0.9 + 0.4 - 0.8 = 0.5$ m.
2. Denominator: $2(1000\cdot0.03 + 4000\cdot0.01 + 2000\cdot0.02) = 2(30 + 40 + 40) = 220$ s/m².
3. $\Delta Q = -0.5/220 = -2.273\times10^{-3}$ m³/s, so subtract 2.273 L/s round the loop: new flows +27.73, +7.73 and −22.27 L/s.
:::
