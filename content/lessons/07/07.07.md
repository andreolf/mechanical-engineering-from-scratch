A figure skater pulls in her arms and spins faster. A satellite moves fastest when closest to Earth. A ball on a string wound around a pole speeds up as the string shortens. All three follow from one law: the rate of change of angular momentum equals the applied moment, and if the moment is zero, angular momentum is conserved.

## Angular momentum

For a particle of mass $m$ at position $\mathbf r$ (from a fixed point O) with velocity $\mathbf v$:

$$
\mathbf L_O = \mathbf r \times m\mathbf v .
$$

In the plane, with polar coordinates, $L = mr^2\dot\theta$: only the transverse velocity $r\dot\theta$ counts.

## The law

Differentiate: $\dot{\mathbf L}_O = \dot{\mathbf r}\times m\mathbf v + \mathbf r\times m\dot{\mathbf v}$. The first term is zero (a vector crossed with itself), and $m\dot{\mathbf v} = \mathbf F$, so

$$
\dot{\mathbf L}_O = \mathbf r\times\mathbf F = \mathbf M_O .
$$

A **central force**, always pointing towards or away from O (string tension, gravity from a planet), has no moment about O. Then $mr^2\dot\theta$ is constant.

## The shrinking string

A mass whirls on a string pulled in through a hole. The string pulls radially, so $L$ is conserved and

$$
\omega = \omega_0\left(\frac{r_0}{r}\right)^2 .
$$

Halve the radius and the spin rate quadruples. Kinetic energy is not conserved: it grows as $1/r^2$, and the extra energy comes from the work done pulling the string against the growing tension $mr\omega^2$.

A 200 g mass on a string, spinning once per second at 0.8 m. Pull the string in and watch the spin rate, speed and tension rise.
:::

:::example Pulling in the string
$m = 0.2$ kg, $r_0 = 0.8$ m, $\omega_0 = 2\pi$ rad/s. The string is pulled in at 0.15 m/s for 4 s, to 0.2 m.

1. RK4 on the transverse polar equation $r\ddot\theta + 2\dot r\dot\theta = 0$: $\omega$ rises to 100.531 rad/s (16 rev/s), as predicted by $\omega_0(r_0/r)^2 = 16\omega_0$.
2. $L = 0.804248$ kg m²/s before and after, a relative change of $2\times10^{-12}$.
3. Kinetic energy rises from 2.527 J to 40.426 J. The difference, 37.899 J, equals $\int m r\omega^2\,dr$, the work done on the string.
4. The tension climbs from 6.32 N to 404 N. Pulling in a fast-spinning mass gets very hard.
:::

```python file=spinstring.py
"""A mass on a string pulled through a hole: angular momentum is conserved, so it spins up."""
import math
import numpy as np


def simulate(r0, w0, rdot, t_end, dt=1e-4):
    """Polar equations with the radius pulled in at a set rate: the string force is radial, so
    the transverse equation r theta'' + 2 r' theta' = 0 is integrated with RK4."""
    def f(t, s):
        th, w = s
        r = r0 + rdot * t
        return np.array([w, -2 * rdot * w / r])
    s, t = np.array([0.0, w0]), 0.0
    n = int(round(t_end / dt))
    for _ in range(n):
        k1 = f(t, s); k2 = f(t + dt / 2, s + dt / 2 * k1); k3 = f(t + dt / 2, s + dt / 2 * k2); k4 = f(t + dt, s + dt * k3)
        s = s + dt / 6 * (k1 + 2 * k2 + 2 * k3 + k4); t += dt
    return s, r0 + rdot * t_end


if __name__ == "__main__":
    m, r0, w0 = 0.2, 0.8, 2 * math.pi            # 200 g at 0.8 m, one turn per second
    (th, w), r1 = simulate(r0, w0, -0.15, 4.0)    # pull 0.6 m of string in over 4 s
    L0, L1 = m * r0**2 * w0, m * r1**2 * w
    print(f"radius {r0} -> {r1:.2f} m: omega {w0:.4f} -> {w:.4f} rad/s ({w / (2 * math.pi):.3f} rev/s), predicted {w0 * (r0 / r1) ** 2:.4f}")
    print(f"angular momentum {L0:.6f} -> {L1:.6f} kg m^2/s (relative change {abs(L1 / L0 - 1):.1e})")
    assert abs(L1 / L0 - 1) < 1e-9
    T0, T1 = 0.5 * m * (r0 * w0) ** 2, 0.5 * m * (r1 * w) ** 2
    print(f"kinetic energy {T0:.3f} -> {T1:.3f} J: the hand pulling the string did {T1 - T0:.3f} J of work")
    # string tension needed at the end (centripetal, ignoring the slow pull): m r w^2
    print(f"string tension: start {m * r0 * w0**2:.2f} N, end {m * r1 * w**2:.2f} N")
    # and the work done equals the integral of tension times pull-in distance
    rs = np.linspace(r1, r0, 200001)
    Wq = np.trapezoid(m * rs * (w0 * r0**2 / rs**2) ** 2, rs)
    print(f"integral of m r w^2 dr = {Wq:.3f} J")
    assert abs(Wq - (T1 - T0)) < 1e-6
```

:::exercise A satellite's speed
A satellite in an elliptical orbit is 7000 km from Earth's centre at perigee, moving at 8.0 km/s perpendicular to the radius. At apogee it is 10,500 km away. How fast is it moving there?
---solution---
1. Gravity is central, so $L = mrv_\perp$ is conserved. At perigee and apogee the velocity is perpendicular to the radius.
2. $v_a = v_p r_p/r_a = 8.0\cdot7000/10500 = 5.33$ km/s.
:::
