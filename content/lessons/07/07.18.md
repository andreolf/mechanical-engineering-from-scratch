Newton's method needs every force, including the constraint forces at pins and guides that you don't care about. For a double pendulum, a robot arm or a crank mechanism this gets messy fast. Lagrange's method works with energies in a set of coordinates that already respect the constraints, and the constraint forces never appear.

## Generalised coordinates

Pick the minimum number of coordinates $q_1, \dots, q_n$ that fix the configuration. A double pendulum needs two angles, $\theta_1$ and $\theta_2$, not four Cartesian positions linked by two rod-length constraints. The number $n$ is the number of degrees of freedom.

## The Lagrangian

Write the kinetic energy $T$ and potential energy $V$ in terms of the $q_i$ and their rates $\dot q_i$, and form

$$
L = T - V .
$$

Then for each coordinate

$$
\frac{d}{dt}\left(\frac{\partial L}{\partial \dot q_i}\right) - \frac{\partial L}{\partial q_i} = Q_i ,
$$

where $Q_i$ is the generalised force from anything not in $V$ (applied torques, damping). For a conservative system $Q_i = 0$. This gives $n$ equations of motion with no reaction forces.

## A check on one pendulum

For a single pendulum, $T = \tfrac12 ml^2\dot\theta^2$ and $V = -mgl\cos\theta$. Then $\partial L/\partial\dot\theta = ml^2\dot\theta$, its time derivative is $ml^2\ddot\theta$, and $\partial L/\partial\theta = -mgl\sin\theta$. The equation is $ml^2\ddot\theta + mgl\sin\theta = 0$, the familiar result, with no rod tension needed.

## The double pendulum

With two equal masses on equal rods the differentiation is tedious by hand but trivial for a computer algebra system. The code below lets SymPy derive both equations, then integrates them. For small swings the system has two normal modes, at $\omega = \sqrt{(2\mp\sqrt2)\,g/l}$. For large swings it's chaotic: tiny differences in the start grow exponentially, though energy is still conserved.

:::

:::example Deriving and testing the double pendulum
$m_1 = m_2 = 1$ kg, $l_1 = l_2 = 1$ m, $g = 9.81$ m/s².

1. SymPy forms $L$, applies Lagrange's equation to each angle and solves for $\ddot\theta_1, \ddot\theta_2$.
2. Small swing in the in-phase mode shape ($\theta_2 = \sqrt2\,\theta_1$): simulated period 2.6211 s, theory $2\pi/\sqrt{(2-\sqrt2)\,9.81} = 2.6211$ s.
3. Large swing from 2.0 and 2.5 rad, 20 s with RK4: relative energy drift $4.2\times10^{-4}$ at $\Delta t = 0.01$ s, $9.4\times10^{-9}$ at 0.001 s. The equations are right; the step size controls the error.
4. Two starts differing by $10^{-9}$ rad differ by more than 0.1 rad in $\theta_2$ after 9.73 s. Long-term prediction is impossible in principle.
:::

```python file=lagrange.py
"""Lagrangian mechanics: derive the double pendulum's equations with SymPy, then simulate them."""
import math
import numpy as np
import sympy as sp


def derive():
    t = sp.symbols("t")
    m1, m2, l1, l2, g = sp.symbols("m1 m2 l1 l2 g", positive=True)
    th1, th2 = sp.Function("th1")(t), sp.Function("th2")(t)
    x1, y1 = l1 * sp.sin(th1), -l1 * sp.cos(th1)
    x2, y2 = x1 + l2 * sp.sin(th2), y1 - l2 * sp.cos(th2)
    T = m1 / 2 * (sp.diff(x1, t)**2 + sp.diff(y1, t)**2) + m2 / 2 * (sp.diff(x2, t)**2 + sp.diff(y2, t)**2)
    V = m1 * g * y1 + m2 * g * y2
    L = sp.simplify(T - V)
    eqs = [sp.diff(sp.diff(L, sp.diff(q, t)), t) - sp.diff(L, q) for q in (th1, th2)]
    a1, a2 = sp.symbols("a1 a2"); w1, w2, q1, q2 = sp.symbols("w1 w2 q1 q2")
    sub = {sp.diff(th1, t, 2): a1, sp.diff(th2, t, 2): a2, sp.diff(th1, t): w1, sp.diff(th2, t): w2}
    eqs = [e.subs(sub).subs({th1: q1, th2: q2}) for e in eqs]
    sol = sp.solve(eqs, [a1, a2], dict=True)[0]
    energy = (T + V).subs(sub).subs({th1: q1, th2: q2})
    args = (q1, q2, w1, w2, m1, m2, l1, l2, g)
    return sp.lambdify(args, [sol[a1], sol[a2]], "math"), sp.lambdify(args, energy, "math")


def simulate(acc, s0, p, t_end, dt):
    def f(s):
        a = acc(*s, *p); return np.array([s[2], s[3], a[0], a[1]])
    s = np.array(s0, float); out = [s.copy()]
    for _ in range(int(round(t_end / dt))):
        k1 = f(s); k2 = f(s + dt/2*k1); k3 = f(s + dt/2*k2); k4 = f(s + dt*k3)
        s = s + dt/6*(k1 + 2*k2 + 2*k3 + k4); out.append(s.copy())
    return np.array(out)


if __name__ == "__main__":
    acc, energy = derive()
    p = (1.0, 1.0, 1.0, 1.0, 9.81)                        # m1, m2, l1, l2, g
    # small swings: the linearised normal-mode frequencies for equal masses and lengths are sqrt((2 -+ sqrt 2) g / l)
    s0 = [0.01, 0.01 * math.sqrt(2), 0, 0]                  # in-phase mode shape
    tr = simulate(acc, s0, p, 10.0, 1e-3)
    zc = np.where(np.diff(np.sign(tr[:, 0])) != 0)[0]
    period = 2 * np.mean(np.diff(zc)) * 1e-3
    w_mode = math.sqrt((2 - math.sqrt(2)) * 9.81)
    print(f"in-phase mode: simulated period {period:.4f} s, theory {2 * math.pi / w_mode:.4f} s")
    assert abs(period - 2 * math.pi / w_mode) < 2e-3
    # large swings: chaos, but energy must be conserved
    for dt in (1e-2, 1e-3):
        tr = simulate(acc, [2.0, 2.5, 0, 0], p, 20.0, dt)
        E = np.array([energy(*s, *p) for s in tr])
        print(f"chaotic swing, dt = {dt}: relative energy drift {np.max(np.abs(E - E[0])) / abs(E[0]):.1e}")
    assert np.max(np.abs(E - E[0])) / abs(E[0]) < 1e-6
    # sensitivity: two starts differing by 1e-9 rad separate completely
    a = simulate(acc, [2.0, 2.5, 0, 0], p, 20.0, 1e-3); b = simulate(acc, [2.0 + 1e-9, 2.5, 0, 0], p, 20.0, 1e-3)
    sep = np.abs(a[:, 1] - b[:, 1])
    i = int(np.argmax(sep > 0.1))
    print(f"a 1e-9 rad difference grows past 0.1 rad after {i * 1e-3:.2f} s")
```

:::exercise A bead on a spinning hoop
A bead of mass $m$ slides without friction on a hoop of radius $R$ spinning about its vertical diameter at a constant $\Omega$. Using the angle $\theta$ from the bottom, $T = \tfrac12 m R^2(\dot\theta^2 + \Omega^2\sin^2\theta)$ and $V = -mgR\cos\theta$. Find the equation of motion, and the angle where the bead can sit still when $\Omega = 5$ rad/s and $R = 0.2$ m.
---solution---
1. $\partial L/\partial\dot\theta = mR^2\dot\theta$; $\partial L/\partial\theta = mR^2\Omega^2\sin\theta\cos\theta - mgR\sin\theta$.
2. Equation: $R\ddot\theta = R\Omega^2\sin\theta\cos\theta - g\sin\theta$.
3. Equilibrium off the bottom: $\cos\theta = g/(R\Omega^2) = 9.81/(0.2\cdot25) = 1.962$. That's more than 1, so at 5 rad/s the bead can only sit at the bottom.
4. The off-centre equilibrium appears only above $\Omega = \sqrt{g/R} = 7.0$ rad/s. At 10 rad/s, $\cos\theta = 0.4905$, so $\theta = 60.6°$.
:::
