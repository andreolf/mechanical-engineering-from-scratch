Drones, satellites, phones and VR headsets all need to know which way they point. Their gyroscopes measure angular velocity in body axes, many times a second, and software integrates that into an orientation. How orientation is stored matters: the obvious choice, three angles, fails at certain attitudes. Quaternions don't.

## Rotation matrices

An orientation can be stored as a 3 × 3 rotation matrix $\mathbf R$ that turns body-frame vectors into world-frame ones. It is orthogonal ($\mathbf R^T\mathbf R = \mathbf I$) with determinant +1. Nine numbers for three degrees of freedom: integrating it lets rounding errors break orthogonality.

## Euler angles

Three successive rotations, for example yaw $\psi$, pitch $\theta$ and roll $\phi$. Intuitive, and used on every aircraft display. But the angle rates relate to body rates $(p, q, r)$ through

$$
\dot\phi = p + (q\sin\phi + r\cos\phi)\tan\theta, \qquad \dot\psi = \frac{q\sin\phi + r\cos\phi}{\cos\theta} .
$$

At $\theta = 90°$, $\cos\theta = 0$: the rates become infinite. Two of the gimbal axes line up and one degree of freedom is lost. That is **gimbal lock**, which nearly caught Apollo 13's guidance platform.

## Quaternions

A unit quaternion $q = (\cos\tfrac{\alpha}{2},\ \sin\tfrac{\alpha}{2}\,\mathbf n)$ represents a rotation by $\alpha$ about the unit axis $\mathbf n$. Four numbers, one constraint ($|q| = 1$), no singularities. With body angular velocity $\boldsymbol\omega$:

$$
\dot q = \tfrac12\,q\otimes(0, \boldsymbol\omega) .
$$

This is linear in $q$ and smooth everywhere. Integrate with RK4 and renormalise $q$ after each step to keep $|q| = 1$. Convert to a rotation matrix or Euler angles only for display.

A body yawing at 1 rad/s about its own axis. As its pitch approaches 90°, the Euler-angle rates needed to follow it explode (red, log scale). The quaternion rate (lime) stays at $|\omega|/2$.
:::

:::example Integrating orientation
1. Constant spin of 1.5 rad/s about the axis (1, 2, 2)/3 for 4 s: the integrated quaternion matches the exact axis-angle rotation to $1\times10^{-14}$.
2. A tumbling body ($\omega$ varying with time) for 200 s with a coarse 0.05 s step: with renormalisation the norm error stays at $2\times10^{-16}$; without it, it drifts to $1.9\times10^{-7}$. Small, but it grows without bound in long flights.
3. The rotation matrix built from the final quaternion is orthogonal to $3\times10^{-16}$, determinant 1.
4. Euler-angle rates for a 1 rad/s body yaw (roll 0.3 rad): 0.96 rad/s of yaw rate at level pitch, 10.96 at 85°, 54.7 at 89°, 547 at 89.9°.
:::

```python file=quaternion.py
"""Integrating orientation from angular velocity: rotation matrices, Euler angles and quaternions."""
import math
import numpy as np


def qmul(a, b):
    w1, x1, y1, z1 = a; w2, x2, y2, z2 = b
    return np.array([w1*w2 - x1*x2 - y1*y2 - z1*z2, w1*x2 + x1*w2 + y1*z2 - z1*y2,
                     w1*y2 - x1*z2 + y1*w2 + z1*x2, w1*z2 + x1*y2 - y1*x2 + z1*w2])


def qrot(q):
    w, x, y, z = q
    return np.array([[1 - 2*(y*y + z*z), 2*(x*y - w*z), 2*(x*z + w*y)],
                     [2*(x*y + w*z), 1 - 2*(x*x + z*z), 2*(y*z - w*x)],
                     [2*(x*z - w*y), 2*(y*z + w*x), 1 - 2*(x*x + y*y)]])


def axis_angle(axis, ang):
    axis = np.asarray(axis, float) / np.linalg.norm(axis)
    return np.r_[math.cos(ang / 2), math.sin(ang / 2) * axis]


def integrate(omega_body, t_end, dt, renorm=True):
    """q' = q * (0, w) / 2 with w in body axes, RK4."""
    q = np.array([1.0, 0, 0, 0]); t = 0.0; norms = []
    f = lambda t, q: 0.5 * qmul(q, np.r_[0.0, omega_body(t)])
    while t < t_end - 1e-12:
        k1 = f(t, q); k2 = f(t + dt/2, q + dt/2*k1); k3 = f(t + dt/2, q + dt/2*k2); k4 = f(t + dt, q + dt*k3)
        q = q + dt/6*(k1 + 2*k2 + 2*k3 + k4); t += dt
        if renorm: q = q / np.linalg.norm(q)
        norms.append(np.linalg.norm(q))
    return q, np.array(norms)


def euler_zyx_rates(phi, theta, w):
    """Roll-pitch-yaw angle rates from body rates: singular when cos(theta) = 0 (gimbal lock)."""
    p, q, r = w
    c, s, t = math.cos(phi), math.sin(phi), math.tan(theta)
    return np.array([p + (q * s + r * c) * t, q * c - r * s, (q * s + r * c) / math.cos(theta)])


if __name__ == "__main__":
    np.set_printoptions(suppress=True)
    # 1. constant spin about a fixed axis: the integrated quaternion must equal the exact axis-angle rotation
    axis = np.array([1.0, 2.0, 2.0]) / 3.0; rate = 1.5
    q, norms = integrate(lambda t: rate * axis, 4.0, 1e-3)
    q_exact = axis_angle(axis, rate * 4.0)
    print(f"constant spin: |q - exact| = {np.linalg.norm(q - q_exact):.2e}, |q| = {np.linalg.norm(q):.15f}")
    assert np.linalg.norm(q - q_exact) < 1e-9
    # 2. a tumbling body: renormalising keeps |q| = 1; without it the norm drifts slowly
    wt = lambda t: np.array([1.0 + 0.5 * math.sin(2 * t), 0.7 * math.cos(3 * t), 0.4])
    q1, n1 = integrate(wt, 200.0, 0.05, renorm=True)
    q2, n2 = integrate(wt, 200.0, 0.05, renorm=False)
    print(f"tumbling for 200 s at dt = 0.05: norm error with renormalisation {np.max(np.abs(n1 - 1)):.1e}, without {abs(n2[-1] - 1):.1e}")
    assert np.max(np.abs(n1 - 1)) < 1e-14
    R = qrot(q1)
    print(f"rotation matrix stays orthogonal: |R^T R - I| = {np.linalg.norm(R.T @ R - np.eye(3)):.1e}, det = {np.linalg.det(R):.12f}")
    # 3. gimbal lock: Euler-angle rates blow up as pitch approaches 90 degrees, quaternions don't care
    for th in (0, 60, 85, 89, 89.9):
        rates = euler_zyx_rates(0.3, math.radians(th), np.array([0.0, 0.0, 1.0]))
        print(f"  pitch {th:5.1f} deg: Euler angle rates {np.round(rates, 2)} rad/s for a body yaw rate of 1 rad/s")
```

:::exercise A quarter turn
Write the quaternion for a 90° rotation about the z axis. Use it to rotate the vector (1, 0, 0) with $\mathbf v' = q\otimes(0, \mathbf v)\otimes q^*$, where $q^*$ flips the sign of the vector part.
---solution---
1. $q = (\cos45°, 0, 0, \sin45°) = (0.7071, 0, 0, 0.7071)$.
2. $q\otimes(0, 1, 0, 0) = (0, 0.7071, 0.7071, 0)$.
3. Multiply by $q^* = (0.7071, 0, 0, -0.7071)$: $(0, 0, 1, 0)$. So $\mathbf v' = (0, 1, 0)$, the x axis turned 90° onto the y axis, as expected.
:::
