To control a motor, a pump or a heater you need a model of it. You can derive one from physics, but the datasheet values are approximate and friction is never in the datasheet. **System identification** builds the model from measured input and output data instead, and it is the step between the measurement lessons and the control lessons that follow.

## Discrete-time models

A logger samples every $T$ seconds, so the natural model is a **difference equation**. A first-order system $\tau\dot y + y = K u$ with the input held constant between samples (a zero-order hold) is exactly

$$
y_n = a\,y_{n-1} + b\,u_{n-1}, \qquad a = e^{-T/\tau}, \qquad b = K(1 - a) .
$$

The general **ARX** model (autoregressive with exogenous input) of orders $n_a, n_b$ is

$$
y_n = \sum_{i=1}^{n_a} a_i\,y_{n-i} + \sum_{j=1}^{n_b} b_j\,u_{n-j} + e_n .
$$

## Least squares

The model is **linear in the parameters**, even though it describes dynamics. Stack one row per sample, $\varphi_n = [y_{n-1}, \dots, u_{n-1}, \dots]$, into a matrix $\Phi$ and solve

$$
\hat\theta = \arg\min_\theta \|Y - \Phi\theta\|^2 = (\Phi^\mathsf{T}\Phi)^{-1}\Phi^\mathsf{T} Y .
$$

From the parameters you get back the physics: the steady gain $K = \sum b_j/(1 - \sum a_i)$, and the continuous poles $s = \ln(z)/T$ from the roots $z$ of $z^{n_a} - a_1 z^{n_a - 1} - \dots - a_{n_a}$.

## Things that go wrong

- **The model order.** Too low, and the model lumps several lags into one. Too high, and it fits the noise.
- **Noise bias.** Measurement noise on $y$ also appears in the regressors $y_{n-1}$, which biases ARX estimates. More data does not fix it; instrumental variables or output-error methods do.
- **Validation.** Always test the model on a different data set from the one you fitted, by simulating it from the input alone. The usual score is the normalised fit $100\,(1 - \|y - \hat y\|/\|y - \bar y\|)$ %.

:::example Identify a small DC motor
The synthetic "true" motor: $R = 2$ Ω, $L = 8$ mH, $k = 0.03$ N·m/A, $J = 5.4\times10^{-5}$ kg·m², viscous friction $10^{-5}$ N·m·s. Its steady gain is $K = k/(Rb + k^2) = 32.6087$ rad/s per volt, and it has two poles, $-241.36$ s⁻¹ (electrical) and $-8.823$ s⁻¹ (mechanical, $\tau = 0.11334$ s). A 6 V step is sampled at 200 Hz for 1.5 s with 0.3 rad/s of tachometer noise.

1. **ARX(1,1):** $a = 0.959894$, $b = 1.311949$, so $K = 32.7121$ (+0.32 %) and $\tau = -T/\ln a = 0.12215$ s (+7.8 %). The gain is right, but the single time constant absorbs the 4 ms electrical lag as well.
2. **ARX(2,2):** $K = 32.6543$ (+0.14 %), continuous poles −256.6 and −8.53 s⁻¹. The dominant pole is within 3.4 % of the truth, and the model now separates the two lags.
3. **Validation** on a staircase of voltages not used in the fit: ARX(1,1) scores 97.16 %, ARX(2,2) 98.76 %.
4. With 3 rad/s of noise instead of 0.3, ARX(1,1) gives $\tau = 0.10637$ s: the equation-error bias makes the motor look faster than it is.
:::

```python file=sysid.py
"""System identification of a DC motor from step data: ARX models fitted by linear least squares.
The 'true' motor is a second-order electro-mechanical model simulated with RK4; the identified
gain, time constant and poles are compared with it, and the model is validated on fresh data. numpy only."""
import numpy as np

R, L, k, J, bv = 2.0, 8e-3, 0.03, 5.4e-5, 1e-5          # ohm, H, N m/A (= V s/rad), kg m^2, N m s/rad
A = np.array([[-R / L, -k / L], [k / J, -bv / J]])       # states: current i, speed w
Bm = np.array([1 / L, 0.0])
K_true = k / (R * bv + k * k)                            # steady speed per volt
poles_true = np.linalg.eigvals(A)
fs = 200.0; T = 1 / fs

def simulate(u, sub=40):
    """Zero-order-hold input, RK4 with 40 sub-steps per sample. Returns speed at the sample instants."""
    x = np.zeros(2); out = np.empty(len(u)); h = T / sub
    f = lambda x, v: A @ x + Bm * v
    for n, v in enumerate(u):
        out[n] = x[1]
        for _ in range(sub):
            k1 = f(x, v); k2 = f(x + h / 2 * k1, v); k3 = f(x + h / 2 * k2, v); k4 = f(x + h * k3, v)
            x = x + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
    return out

def arx(y, u, na, nb):
    """y[n] = sum_i a_i y[n-i] + sum_j b_j u[n-j] + e[n], solved by least squares."""
    n0 = max(na, nb)
    Phi = np.column_stack([y[n0 - i: len(y) - i] for i in range(1, na + 1)] + [u[n0 - j: len(u) - j] for j in range(1, nb + 1)])
    th = np.linalg.lstsq(Phi, y[n0:], rcond=None)[0]
    return th[:na], th[na:]

def sim_arx(a, b, u):
    y = np.zeros(len(u))
    for n in range(len(u)):
        y[n] = sum(a[i] * y[n - 1 - i] for i in range(len(a)) if n - 1 - i >= 0) + sum(b[j] * u[n - 1 - j] for j in range(len(b)) if n - 1 - j >= 0)
    return y

rng = np.random.default_rng(8)
t = np.arange(0, 1.5, T)
u = np.where(t >= 0.05, 6.0, 0.0)                              # 6 V step at 50 ms
w = simulate(u) + 0.3 * rng.standard_normal(len(t))           # tachometer noise 0.3 rad/s
print(f"true motor: K = {K_true:.4f} rad/s/V, poles {np.sort(poles_true.real).round(3)} 1/s, mechanical tau = {-1/max(poles_true.real):.5f} s")

a1, b1 = arx(w, u, 1, 1)
tau1 = -T / np.log(a1[0]); K1 = b1[0] / (1 - a1[0])
print(f"ARX(1,1): a = {a1[0]:.6f}, b = {b1[0]:.6f} -> K = {K1:.4f} rad/s/V ({(K1/K_true-1)*100:+.2f} %), tau = {tau1:.5f} s ({(tau1/(-1/max(poles_true.real))-1)*100:+.2f} %)")
a2, b2 = arx(w, u, 2, 2)
zp = np.roots(np.r_[1, -a2]); sp = np.log(zp.astype(complex)) / T
K2 = b2.sum() / (1 - a2.sum())
print(f"ARX(2,2): K = {K2:.4f}, continuous poles from ln(z)/T = {np.sort(sp.real).round(2)}")
assert abs(K1 / K_true - 1) < 0.02 and 0 < tau1 / (-1 / max(poles_true.real)) - 1 < 0.10   # first order soaks up the electrical lag
assert abs(K2 / K_true - 1) < 0.02 and abs(max(sp.real) / max(poles_true.real) - 1) < 0.05

# validate on different data: a staircase of voltages the model has not seen
uv = np.repeat([0, 3, 9, 4, 12, 0, 6], 60).astype(float)
wv = simulate(uv)
for name, (a, b) in (("ARX(1,1)", (a1, b1)), ("ARX(2,2)", (a2, b2))):
    ym = sim_arx(a, b, uv)
    fit = 100 * (1 - np.linalg.norm(wv - ym) / np.linalg.norm(wv - wv.mean()))
    print(f"{name} validation fit (NRMSE) = {fit:.2f} %")
    assert fit > 95

# why noise matters: with 10x more output noise the ARX estimate of a is biased low (tau too short)
wn = simulate(u) + 3.0 * rng.standard_normal(len(t))
an, bn = arx(wn, u, 1, 1)
assert -1 / max(sp.real) < tau1                       # the second-order model separates the two lags
print(f"with 3 rad/s noise: tau = {-T/np.log(an[0]):.5f} s, K = {bn[0]/(1-an[0]):.4f}: equation-error bias")
```

:::exercise From ARX to physics
A heater identified at $T = 1$ s gives $y_n = 0.9802\,y_{n-1} + 0.0396\,u_{n-1}$, with $y$ in °C above ambient and $u$ in watts. Find the time constant and the steady gain, and the final temperature rise for 50 W.
---solution---
1. $\tau = -T/\ln a = -1/\ln 0.9802 = 50.0$ s.
2. $K = b/(1 - a) = 0.0396/0.0198 = 2.00$ °C per watt.
3. At 50 W the temperature rise settles to $2.00 \times 50 = 100$ °C.
:::
