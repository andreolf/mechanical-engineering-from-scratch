A data logger does not record a signal. It records a list of numbers, one every $T_s = 1/f_s$ seconds. Between the samples it knows nothing, and that ignorance has a precise and dangerous consequence: two different signals can produce the same samples.

## Why sines can impersonate each other

Sample $x(t) = \sin(2\pi f t)$ at $t_n = n/f_s$. Replace $f$ by $f + k f_s$ for any integer $k$:

$$
\sin\!\big(2\pi (f + k f_s)\, n/f_s\big) = \sin(2\pi f n/f_s + 2\pi k n) = \sin(2\pi f n / f_s) .
$$

The samples are identical. Also $\sin(2\pi(f_s - f)n/f_s) = -\sin(2\pi f n/f_s)$, the same sine with a sign flip. So every frequency **folds** into the band $0 \le f \le f_s/2$, and a component at $f$ shows up at the **alias**

$$
f_a = \left| f - f_s\,\mathrm{round}\!\left(\frac{f}{f_s}\right) \right| .
$$

## The Nyquist-Shannon theorem

If the signal contains nothing at or above $f_s/2$ (the **Nyquist frequency**), the samples determine it completely, and sinc interpolation rebuilds it exactly. If it does contain energy above $f_s/2$, no processing after the fact can tell it from a real low-frequency component. Hence the rule of every data-acquisition system: put an analogue **anti-aliasing filter** in front of the ADC, and sample several times faster than the highest frequency you care about.

## The wagon-wheel effect

A film camera samples a moving picture. A wheel with $N$ identical spokes looks the same every $1/N$ of a turn, so the picture repeats at the spoke frequency $N f_\text{rot}$. If that is above half the frame rate it aliases. The eye follows the nearest spoke, and the wheel appears to turn at

$$
f_\text{app} = \frac{N f_\text{rot} - f_s\,\mathrm{round}(N f_\text{rot}/f_s)}{N},
$$

which can be slow, zero or negative.

:::example A vibration logger and a car on film
**Logger.** A 200 Hz logger with a 1024-point FFT and a Hann window. The code builds the FFT from scratch and checks it against `np.fft.fft`.

| True frequency, Hz | FFT peak, Hz | Alias formula, Hz |
|---|---|---|
| 30 | 29.998 | 30 |
| 110 | 89.997 | 90 |
| 180 | 20.002 | 20 |
| 230 | 29.998 | 30 |
| 397 | 3.003 | 3 |

A 180 Hz gear-mesh vibration reads as a convincing 20 Hz peak. Nothing in the data says it is fake.

**Car.** A 6-spoke rim, tyre diameter 0.63 m, at 50 km/h, filmed at 25 frames per second.

1. $f_\text{rot} = (50/3.6)/(\pi \times 0.63) = 7.0174$ rev/s. Spoke frequency $6 \times 7.0174 = 42.104$ Hz, above the 12.5 Hz Nyquist limit.
2. $42.104 - 25 \times 2 = -7.896$ Hz, divided by 6 spokes: the wheel seems to turn **backwards** at 1.3159 rev/s. Tracking the nearest spoke frame by frame in the code gives the same number.
3. It looks frozen whenever $N f_\text{rot}$ is a multiple of 25 Hz: at 29.69 km/h and 59.38 km/h.
:::

```python file=aliasing.py
"""Sampling and aliasing: a from-scratch FFT finds the frequency a sampled sine appears at, and a
spoked wheel filmed at 25 frames per second shows the wagon-wheel effect. numpy only."""
import numpy as np

def fft(x):
    """Recursive radix-2 Cooley-Tukey FFT (len(x) a power of two)."""
    x = np.asarray(x, complex); n = len(x)
    if n == 1: return x
    e, o = fft(x[0::2]), fft(x[1::2])
    w = np.exp(-2j * np.pi * np.arange(n // 2) / n) * o
    return np.concatenate([e + w, e - w])

def alias(f, fs):
    """Apparent frequency of a sine at f sampled at fs: fold into [0, fs/2]."""
    return abs(f - fs * np.round(f / fs))

x = np.random.default_rng(0).standard_normal(256)
assert np.allclose(fft(x), np.fft.fft(x))                         # check the FFT against numpy's

fs, N = 200.0, 1024                                               # 200 Hz logger, 1024 samples
t = np.arange(N) / fs
win = 0.5 - 0.5 * np.cos(2 * np.pi * np.arange(N) / N)            # Hann window against leakage
freqs = np.arange(N // 2 + 1) * fs / N
print("  true f    peak of FFT   alias formula")
for f in (30.0, 90.0, 110.0, 180.0, 230.0, 397.0):
    X = np.abs(fft(win * np.sin(2 * np.pi * f * t)))[: N // 2 + 1]
    k = np.argmax(X)
    d = 0.5 * (np.log(X[k - 1]) - np.log(X[k + 1])) / (np.log(X[k - 1]) - 2 * np.log(X[k]) + np.log(X[k + 1])) if 0 < k < N // 2 else 0
    fp = (k + d) * fs / N                                          # parabolic interpolation of the log peak
    print(f"{f:8.1f} {fp:12.3f} {alias(f, fs):12.3f}")
    assert abs(fp - alias(f, fs)) < 0.02

# the wagon-wheel effect: a 6-spoke rim at 50 km/h, filmed at 25 frames per second
v, D, spokes, fps = 50 / 3.6, 0.63, 6, 25.0
frot = v / (np.pi * D)                                             # rev/s
pitch = 2 * np.pi / spokes                                         # the picture repeats every spoke
frames = np.arange(50)
theta = 2 * np.pi * frot * frames / fps                            # true wheel angle at each frame
seen = np.unwrap(np.mod(theta, pitch) * spokes) / spokes           # the eye tracks the nearest spoke (minimal motion)
f_app = np.polyfit(frames / fps, seen, 1)[0] / (2 * np.pi)
f_pred = (frot * spokes - fps * np.round(frot * spokes / fps)) / spokes   # signed alias of the spoke frequency
print(f"wheel {frot:.4f} rev/s, spoke-passing frequency {frot*spokes:.3f} Hz; on film it turns {f_app:+.4f} rev/s (formula {f_pred:+.4f})")
assert abs(f_app - f_pred) < 1e-9 and f_app < 0                    # it appears to turn backwards
v_still = [fps * k / spokes * np.pi * D * 3.6 for k in (1, 2)]
print(f"the wheel looks frozen at {v_still[0]:.2f} and {v_still[1]:.2f} km/h")
assert abs(alias(v_still[0] / 3.6 / (np.pi * D) * spokes, fps)) < 1e-9
```

:::exercise Choose a sampling rate
A pump runs at 1450 rpm with 7 impeller vanes. You want to see the blade-pass frequency and its second harmonic without aliasing. What is the minimum sampling rate, and what would a 250 Hz logger show instead of the blade-pass tone?
---solution---
1. Shaft $1450/60 = 24.17$ Hz. Blade-pass $7 \times 24.17 = 169.2$ Hz, second harmonic 338.3 Hz.
2. Nyquist needs $f_s > 2 \times 338.3 = 676.7$ Hz. In practice use 1 kHz or more with an anti-aliasing filter at about 400 Hz.
3. At 250 Hz: $|169.2 - 250| = 80.8$ Hz. The logger shows an 80.8 Hz tone that does not exist.
:::
