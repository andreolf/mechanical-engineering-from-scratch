Transfer functions handle one input and one output. A cart balancing a pendulum has one input, the motor force, but four things to control at once: the angle, the angular rate, the cart position and its speed. **State space** handles any number of them, and the **linear-quadratic regulator** (LQR) finds the best feedback gains for all of them in one calculation.

## State-space models

Collect everything the future depends on into a state vector $\mathbf x$, and write the dynamics as

$$
\dot{\mathbf x} = A\mathbf x + B\mathbf u, \qquad \mathbf y = C\mathbf x + D\mathbf u .
$$

The eigenvalues of $A$ are the poles. The system is **controllable** when the input can steer the state anywhere, which is tested by the rank of $[B,\ AB,\ A^2B,\ \dots,\ A^{n-1}B]$: it must be $n$.

For a cart of mass $M$ carrying a point mass $m$ on a massless rod of length $l$, with $\theta$ measured from upright, Lagrange's equations are

$$
(M + m)\ddot x + ml\cos\theta\,\ddot\theta - ml\sin\theta\,\dot\theta^2 = F, \qquad \cos\theta\,\ddot x + l\ddot\theta = g\sin\theta .
$$

Linearised about $\theta = 0$, with $\mathbf x = [x, \dot x, \theta, \dot\theta]$:

$$
A = \begin{bmatrix} 0 & 1 & 0 & 0 \\ 0 & 0 & -mg/M & 0 \\ 0 & 0 & 0 & 1 \\ 0 & 0 & (M + m)g/(Ml) & 0 \end{bmatrix}, \qquad B = \begin{bmatrix} 0 \\ 1/M \\ 0 \\ -1/(Ml) \end{bmatrix} .
$$

The eigenvalue $+\sqrt{(M + m)g/(Ml)}$ is the pendulum falling over.

## The linear-quadratic regulator

With full state feedback $\mathbf u = -K\mathbf x$, choose $K$ to minimise

$$
J = \int_0^\infty \left(\mathbf x^\mathsf{T} Q\,\mathbf x + \mathbf u^\mathsf{T} R\,\mathbf u\right) dt .
$$

$Q$ says how much each state error costs and $R$ how much actuator effort costs. The answer is $K = R^{-1}B^\mathsf{T}P$, where $P$ is the symmetric positive-definite solution of the **algebraic Riccati equation**

$$
A^\mathsf{T}P + PA - PBR^{-1}B^\mathsf{T}P + Q = 0 .
$$

To solve it, build the Hamiltonian matrix

$$
H = \begin{bmatrix} A & -BR^{-1}B^\mathsf{T} \\ -Q & -A^\mathsf{T}\end{bmatrix} .
$$

Its eigenvalues come in $\pm$ pairs. Stack the $n$ eigenvectors with negative real part into an upper block $X_1$ and a lower block $X_2$; then $P = X_2 X_1^{-1}$. If $(A, B)$ is controllable and $Q > 0$, the closed loop $A - BK$ is guaranteed stable, with good margins (at least 60° of phase margin for a single input).

:::

:::example Balance a pendulum on a cart
$M = 1$ kg, $m = 0.1$ kg, $l = 0.5$ m, $Q = \mathrm{diag}(10, 1, 100, 1)$, $R = 0.1$.

1. Open-loop eigenvalues: $0, 0, \pm 4.6456$ s⁻¹. The positive one is the fall: the tilt grows by a factor $e$ every 0.215 s.
2. The controllability matrix has rank 4, so LQR can stabilise all four states with one force.
3. Riccati by the Hamiltonian: residual $3.4\times10^{-12}$, and $P$ is positive definite. It matches `scipy.linalg.solve_continuous_are`, and python-control 0.10.2 `lqr` gives the same gain.
4. The gains are $k_x = -10.000$, $k_{\dot x} = -11.6234$, $k_\theta = -72.1539$ and $k_{\dot\theta} = -14.7366$. The cart-position gain comes out as exactly $-\sqrt{q_x/r} = -\sqrt{10/0.1} = -10$.
5. Closed-loop eigenvalues: $-7.5911 \pm 3.4313j$ and $-1.3338 \pm 1.0238j$. All have negative real parts.
6. **Non-linear simulation** from a 15° tilt: after 3 s the angle is 0.33°, and the cart runs out to 0.314 m and comes back. The peak force is 18.89 N.
7. **Force limit.** Just holding a 15° tilt needs $(M + m)g\tan 15° = 2.891$ N. With the motor limited to 3 N the pendulum falls over; with 4 N it recovers.
:::

```python file=lqr_pendulum.py
"""LQR for an inverted pendulum on a cart. Linearise, check controllability, solve the continuous
algebraic Riccati equation from scratch through the stable invariant subspace of the Hamiltonian
matrix, and balance the full non-linear pendulum from a 15 degree tilt. numpy only; scipy's
solve_continuous_are is used as an optional cross-check if installed."""
import numpy as np

M, m, l, g = 1.0, 0.1, 0.5, 9.81           # cart kg, bob kg (point mass), rod length m
# state x = [cart position, cart velocity, angle from upright, angular velocity]
A = np.array([[0, 1, 0, 0],
              [0, 0, -m * g / M, 0],
              [0, 0, 0, 1],
              [0, 0, (M + m) * g / (M * l), 0]])
B = np.array([[0], [1 / M], [0], [-1 / (M * l)]])
print("open-loop eigenvalues:", np.round(np.sort(np.linalg.eigvals(A).real), 4), "(one positive: it falls)")
Cm = np.hstack([np.linalg.matrix_power(A, k) @ B for k in range(4)])
print("controllability matrix rank:", np.linalg.matrix_rank(Cm))
assert np.linalg.matrix_rank(Cm) == 4

def care(A, B, Q, R):
    """Solve A'P + PA - P B R^-1 B' P + Q = 0. The Hamiltonian H = [[A, -B R^-1 B'], [-Q, -A']] has
    eigenvalues in +- pairs; the n stable eigenvectors [X1; X2] give P = X2 X1^-1."""
    n = len(A); Ri = np.linalg.inv(R)
    H = np.block([[A, -B @ Ri @ B.T], [-Q, -A.T]])
    ev, V = np.linalg.eig(H)
    Vs = V[:, ev.real < 0]
    P = np.real(Vs[n:] @ np.linalg.inv(Vs[:n]))
    return (P + P.T) / 2

Q = np.diag([10.0, 1.0, 100.0, 1.0])       # care most about the angle, then the cart position
R = np.array([[0.1]])
P = care(A, B, Q, R)
K = np.linalg.inv(R) @ B.T @ P
res = A.T @ P + P @ A - P @ B @ np.linalg.inv(R) @ B.T @ P + Q
cl = np.linalg.eigvals(A - B @ K)
print("LQR gain K =", np.round(K.ravel(), 4))
print(f"Riccati residual {np.max(np.abs(res)):.2e}; P symmetric positive definite: {np.all(np.linalg.eigvalsh(P) > 0)}")
print("closed-loop eigenvalues:", np.round(cl, 4))
assert np.max(np.abs(res)) < 1e-8 and np.all(np.linalg.eigvalsh(P) > 0)
assert np.all(cl.real < 0)                  # every closed-loop eigenvalue has a negative real part
try:
    from scipy.linalg import solve_continuous_are
    assert np.allclose(solve_continuous_are(A, B, Q, R), P, rtol=1e-8, atol=1e-10)
    print("matches scipy.linalg.solve_continuous_are")
except ImportError:
    print("scipy not installed: skipped the optional cross-check")

def f(s, F):
    """Full non-linear cart-pendulum: theta from upright, bob at x + l sin(theta). Lagrange's equations
    (M+m) x'' + m l cos(th) th'' - m l sin(th) th'^2 = F and cos(th) x'' + l th'' = g sin(th)."""
    x, xd, th, thd = s
    st, ct = np.sin(th), np.cos(th)
    Mm = np.array([[M + m, m * l * ct], [m * l * ct, m * l * l]])
    rhs = np.array([F + m * l * thd**2 * st, m * g * l * st])
    xdd, thdd = np.linalg.solve(Mm, rhs)
    return np.array([xd, xdd, thd, thdd])

def run(K, th0, Fmax=np.inf, T=6.0, h=1e-3):
    s = np.array([0.0, 0.0, np.radians(th0), 0.0]); out = []; Fpk = 0
    for k in range(int(T / h)):
        F = float(np.clip(-K @ s, -Fmax, Fmax)); Fpk = max(Fpk, abs(F))
        k1 = f(s, F); k2 = f(s + h / 2 * k1, F); k3 = f(s + h / 2 * k2, F); k4 = f(s + h * k3, F)
        s = s + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4); out.append(s.copy())
    return np.array(out), Fpk

# the linear model must match the non-linear one for a small tilt
lin = A @ np.array([0, 0, 0.01, 0]); non = f(np.array([0, 0, 0.01, 0]), 0.0)
print(f"linear vs non-linear accelerations at a 0.01 rad tilt: {lin[[1,3]].round(5)} vs {non[[1,3]].round(5)}")
assert np.allclose(lin, non, rtol=1e-3, atol=1e-6)
tr, Fpk = run(K.ravel(), 15.0)
print(f"from 15 deg: angle after 3 s {np.degrees(tr[2999, 2]):.4f} deg, cart overshoot {tr[:, 0].min():.3f} .. {tr[:, 0].max():.3f} m, peak force {Fpk:.2f} N")
assert abs(tr[-1, 2]) < 1e-3 and abs(tr[-1, 0]) < 1e-2
# a force limit: to stop a 15 deg tilt the cart must accelerate at about g tan(15 deg)
print(f"static estimate of the force needed: (M + m) g tan 15 deg = {(M + m) * g * np.tan(np.radians(15)):.3f} N")
for Fmax in (3.0, 4.0):
    tr2, _ = run(K.ravel(), 15.0, Fmax=Fmax, T=10.0)
    ok = abs(tr2[-1, 2]) < 1e-3
    print(f"motor limited to {Fmax:.0f} N: final angle {np.degrees(tr2[-1, 2]):10.2f} deg ({'recovers' if ok else 'falls over'})")
    assert ok == (Fmax == 4.0)
```

:::exercise LQR for a single integrator
For $\dot x = u$ with cost $\int (q x^2 + r u^2)\,dt$, solve the Riccati equation by hand. What are the gain and the closed-loop pole for $q = 4$, $r = 1$?
---solution---
1. Here $A = 0$, $B = 1$: the Riccati equation is $-P^2/r + q = 0$, so $P = \sqrt{qr}$.
2. $K = P/r = \sqrt{q/r} = 2$.
3. The closed loop $\dot x = -2x$ has its pole at $-2$. A higher $q/r$ means a faster, more aggressive controller.
:::
