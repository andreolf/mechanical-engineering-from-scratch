Real sensor signals carry noise: mains hum at 50 Hz, vibration from a motor, electronic hiss. A **low-pass filter** keeps the slow part you care about and removes the fast part. In code a filter is a **difference equation**, a few multiplications per sample, and the whole design job is choosing its coefficients.

## The RC filter

A resistor in series with a capacitor, output across the capacitor:

$$
RC\,\dot y + y = x \quad\Longrightarrow\quad H(s) = \frac{1}{1 + sRC}, \qquad |H(j\omega)| = \frac{1}{\sqrt{1 + (\omega RC)^2}} .
$$

The **cutoff** $f_c = 1/(2\pi RC)$ is where $|H| = 1/\sqrt2$ (−3 dB). Above it the gain falls by 20 dB per decade. That is gentle: a tone at $5 f_c$ is only reduced to 0.196.

## Butterworth: as flat as possible

The $n$-th order **Butterworth** filter has $|H(j\omega)|^2 = 1/(1 + (\omega/\omega_c)^{2n})$, maximally flat in the passband and falling by $20n$ dB per decade. For $n = 2$:

$$
H(s) = \frac{\omega_c^2}{s^2 + \sqrt2\,\omega_c s + \omega_c^2} .
$$

## From $s$ to a difference equation: the bilinear transform

Sampling at $f_s$ with period $T$, replace $s$ by

$$
s = \frac{2}{T}\,\frac{z - 1}{z + 1} ,
$$

where $z^{-1}$ means "one sample ago". This maps the stable left half-plane exactly into the unit circle, so a stable analogue filter stays stable. It also squeezes the infinite analogue frequency axis into $0 \le f < f_s/2$: an analogue frequency $\omega_a$ lands at $\omega_a = (2/T)\tan(\omega_d T/2)$. **Pre-warping** sets $K = \tan(\pi f_c / f_s)$ so the cutoff lands where you asked. For the second-order Butterworth:

$$
y_n = b_0 x_n + b_1 x_{n-1} + b_2 x_{n-2} - a_1 y_{n-1} - a_2 y_{n-2},
$$

$$
b_0 = b_2 = \frac{K^2}{a_0'},\; b_1 = 2b_0,\; a_1 = \frac{2(K^2 - 1)}{a_0'},\; a_2 = \frac{1 - \sqrt2 K + K^2}{a_0'},\; a_0' = 1 + \sqrt2 K + K^2 .
$$

The resulting **digital** magnitude is exactly $1/\sqrt{1 + (\tan(\pi f/f_s)/K)^4}$, slightly better than the analogue prototype near Nyquist.

:::example Clean an accelerometer signal
$f_s = 500$ Hz, $f_c = 10$ Hz, second-order Butterworth.

1. $K = \tan(\pi \cdot 10/500) = 0.062915$. Coefficients: $b_0 = b_2 = 0.00362168$, $b_1 = 0.00724336$, $a_1 = -1.82269493$, $a_2 = 0.83718165$. Both poles have $|z| = 0.914976 < 1$, so the filter is stable.
2. Gains: 0.999205 at 2 Hz, 0.707107 at 10 Hz, and 0.037467 (−28.53 dB) at 50 Hz. The analogue prototype gives 0.039968 at 50 Hz: the bilinear warping helps here.
3. Running the difference equation on 10 s of the noisy signal, a least-squares fit of the output tones gives gains 0.9992 at 2 Hz and 0.0374 at 50 Hz, matching $|H|$.
4. The price is **phase lag**: 16.40° at 2 Hz, a 22.77 ms delay. For a controller that delay matters (lesson 18.13). For offline analysis, running the filter forwards and then backwards cancels the phase.
5. A first-order RC with the same cutoff only reduces the 50 Hz tone to 0.1901.
6. With SciPy installed, the coefficients match `scipy.signal.butter(2, 10, fs=500)` and the output matches `scipy.signal.lfilter` to rounding error.
:::

```python file=iirfilter.py
"""IIR low-pass filters from their difference equations: a first-order RC filter and a second-order
Butterworth biquad designed with the bilinear transform. Checked against the exact digital frequency
response, and against scipy.signal if it happens to be installed. The filter itself is numpy only."""
import numpy as np

def butter2(fc, fs):
    """2nd-order Butterworth low-pass H(s) = w^2 / (s^2 + sqrt2 w s + w^2), bilinear transform
    s = (2/T)(z-1)/(z+1) with the cutoff pre-warped so |H| = 1/sqrt2 exactly at fc."""
    K = np.tan(np.pi * fc / fs)                      # = w_analogue T / 2 after pre-warping
    a0 = 1 + np.sqrt(2) * K + K * K
    b = np.array([K * K, 2 * K * K, K * K]) / a0
    a = np.array([1.0, 2 * (K * K - 1) / a0, (1 - np.sqrt(2) * K + K * K) / a0])
    return b, a

def rc1(fc, fs):
    """1st-order RC low-pass 1/(1 + s RC) by the bilinear transform, pre-warped at fc."""
    K = np.tan(np.pi * fc / fs)
    return np.array([K, K]) / (1 + K), np.array([1.0, (K - 1) / (1 + K)])

def lfilter(b, a, x):
    """Direct form I: a0 y[n] = sum b_k x[n-k] - sum_{k>=1} a_k y[n-k]."""
    y = np.zeros(len(x))
    for n in range(len(x)):
        acc = 0.0
        for k in range(len(b)):
            if n - k >= 0: acc += b[k] * x[n - k]
        for k in range(1, len(a)):
            if n - k >= 0: acc -= a[k] * y[n - k]
        y[n] = acc / a[0]
    return y

def freqz(b, a, f, fs):
    z = np.exp(1j * 2 * np.pi * np.asarray(f) / fs)
    return np.polyval(b[::-1], 1 / z) / np.polyval(a[::-1], 1 / z)

fs, fc = 500.0, 10.0
b, a = butter2(fc, fs)
print("biquad b =", np.round(b, 8), " a =", np.round(a, 8))
poles = np.roots(a)
print(f"poles |z| = {np.abs(poles).round(6)} (inside the unit circle, so stable)")
assert np.all(np.abs(poles) < 1)

# exact digital magnitude: the bilinear map turns f into tan(pi f / fs), so |H| = 1/sqrt(1 + (tan/tan_c)^4)
for f in (2.0, 10.0, 50.0):
    H = abs(freqz(b, a, f, fs))
    ex = 1 / np.sqrt(1 + (np.tan(np.pi * f / fs) / np.tan(np.pi * fc / fs)) ** 4)
    an = 1 / np.sqrt(1 + (f / fc) ** 4)
    print(f"f = {f:5.1f} Hz: |H| = {H:.6f} ({20*np.log10(H):7.2f} dB); exact {ex:.6f}; analogue prototype {an:.6f}")
    assert abs(H - ex) < 1e-12

# a vibrating sensor: 2 Hz motion of 1 g plus 0.5 g of 50 Hz mains pick-up and white noise
t = np.arange(0, 10, 1 / fs)
rng = np.random.default_rng(3)
x = np.sin(2 * np.pi * 2 * t) + 0.5 * np.sin(2 * np.pi * 50 * t) + 0.1 * rng.standard_normal(len(t))
y = lfilter(b, a, x)
ss = t > 2                                            # drop the start-up transient
def amp(sig, f):                                      # least-squares amplitude of one tone
    M = np.column_stack([np.sin(2 * np.pi * f * t[ss]), np.cos(2 * np.pi * f * t[ss])])
    return np.hypot(*np.linalg.lstsq(M, sig[ss], rcond=None)[0])
for f, A in ((2.0, 1.0), (50.0, 0.5)):
    print(f"{f:4.0f} Hz tone: in {amp(x, f):.4f}, out {amp(y, f):.4f}, gain {amp(y, f)/amp(x, f):.4f} (|H| = {abs(freqz(b, a, f, fs)):.4f})")
    assert abs(amp(y, f) / amp(x, f) - abs(freqz(b, a, f, fs))) < 0.01
lag = -np.angle(freqz(b, a, 2.0, fs)) / (2 * np.pi * 2.0)
print(f"phase lag at 2 Hz = {np.degrees(-np.angle(freqz(b, a, 2.0, fs))):.2f} deg = {lag*1e3:.2f} ms delay")

b1, a1 = rc1(fc, fs)
assert abs(abs(freqz(b1, a1, fc, fs)) - 1 / np.sqrt(2)) < 1e-12
print(f"first-order RC at 50 Hz: |H| = {abs(freqz(b1, a1, 50, fs)):.4f}, Butterworth: {abs(freqz(b, a, 50, fs)):.4f}")

try:
    from scipy import signal                         # optional cross-check, not needed to run the lesson
    bs, as_ = signal.butter(2, fc, fs=fs)
    assert np.allclose(bs, b) and np.allclose(as_, a) and np.allclose(signal.lfilter(b, a, x), y)
    print("matches scipy.signal.butter and scipy.signal.lfilter")
except ImportError:
    print("scipy not installed: skipped the optional cross-check")
```

:::exercise An RC filter in hardware
You want a 100 Hz RC low-pass in front of an ADC with a 10 kΩ resistor. What capacitor do you need, and how much does the filter attenuate a 1 kHz component?
---solution---
1. $C = 1/(2\pi R f_c) = 1/(2\pi \times 10^4 \times 100) = 159$ nF. Use the standard 150 nF, giving $f_c = 106$ Hz.
2. At 1 kHz with $f_c = 100$ Hz: $|H| = 1/\sqrt{1 + 10^2} = 0.0995$, about −20 dB.
3. One decade above the cutoff gives only a factor of 10. If 1 kHz noise must not alias, use a higher-order filter or a faster ADC.
:::
