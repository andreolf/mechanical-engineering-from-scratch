Control engineers describe a machine by how it turns an input into an output. The **transfer function** packs a linear ODE into one ratio of polynomials. Its roots tell you, before any simulation, whether the machine oscillates, how fast it settles and whether a controller will make it unstable.

## From an ODE to a transfer function

Take the Laplace transform $Y(s) = \int_0^\infty y(t)e^{-st}dt$. With zero initial conditions, differentiation becomes multiplication by $s$: $\mathcal L\{\dot y\} = sY$. A mass-spring-damper driven by a force,

$$
m\ddot x + c\dot x + kx = F \quad\Longrightarrow\quad G(s) = \frac{X(s)}{F(s)} = \frac{1}{ms^2 + cs + k} .
$$

Written with $\omega_n = \sqrt{k/m}$ and $\zeta = c/(2\sqrt{km})$, the denominator is $m(s^2 + 2\zeta\omega_n s + \omega_n^2)$.

## Poles and zeros

The roots of the denominator are the **poles**, and the roots of the numerator the **zeros**. Each pole $p$ contributes a mode $e^{pt}$ to the response:

- Real negative pole: a decaying exponential with time constant $-1/p$.
- Complex pair $-\zeta\omega_n \pm j\omega_n\sqrt{1 - \zeta^2}$: a decaying oscillation. For a step, the overshoot is $M_p = e^{-\zeta\pi/\sqrt{1 - \zeta^2}}$.
- Any pole with positive real part: a growing mode, so the system is **unstable**.

The steady response to a unit step is the **DC gain** $G(0)$ (the final-value theorem). Zeros do not change stability, but they shape the response: a zero in the right half-plane makes the output start the wrong way.

## Block-diagram algebra

Transfer functions combine like fractions:

- **Series:** $G_1 G_2$.
- **Parallel:** $G_1 + G_2$.
- **Negative feedback** around $G$ with $H$ in the return path:

$$
T(s) = \frac{G}{1 + GH} .
$$

The closed-loop poles are the roots of $1 + GH = 0$, the **characteristic equation**. Feedback moves the poles, and that is the whole point of control.

To simulate a transfer function, turn it into state-space form $\dot{\mathbf x} = A\mathbf x + Bu$, $y = C\mathbf x + Du$ (the controllable canonical form puts the denominator coefficients in the first row of $A$). With the input held over each step $h$, $\mathbf x_{k+1} = e^{Ah}\mathbf x_k + \left(\int_0^h e^{A\tau}d\tau\right) B u_k$ is exact, and both matrices come out of one matrix exponential.

:::example A positioner with an actuator lag
**Plant.** $m = 2$ kg, $c = 4$ N·s/m, $k = 50$ N/m: $\omega_n = 5$ rad/s, $\zeta = 0.2$, poles $-1 \pm 4.899j$.

1. The step response from the transfer-function class matches the closed form to $2.3\times10^{-16}$ m. Overshoot 52.66 %, the same as $e^{-0.2\pi/\sqrt{0.96}}$.

**Closed loop.** A 50 ms actuator lag $1/(0.05s + 1)$, a proportional gain $K_p = 50$ N/m and unity feedback.

2. $T = K_p A G/(1 + K_p A G)$ has the denominator $s^3 + 22s^2 + 65s + 1000$ (after dividing by 0.1).
3. Poles: $-21.16$ and $-0.419 \pm 6.862j$. All in the left half-plane, but the complex pair is lightly damped.
4. DC gain $K_p/(k + K_p) = 0.5$: proportional control leaves a 50 % steady error against the spring. Lesson 18.12 fixes it with integral action.
5. Writing the loop as three ODEs ($e = r - x$, $0.05\dot F + F = K_p e$, $m\ddot x + c\dot x + kx = F$) and integrating with RK4 gives the same step response to $5\times10^{-11}$. The peak is 0.892 at 0.504 s.
6. At $K_p = 200$ the same code finds poles at $+0.85 \pm 10.2j$: unstable. Lesson 18.11 finds the exact limit.
:::

```python file=tfclass.py
"""A transfer-function class from scratch: polynomial algebra for series, parallel and feedback
connections, poles and zeros, and a step response through a state-space realisation and an exact
matrix-exponential discretisation. Checked against the closed-form response and a direct RK4
integration of the physical ODEs. numpy only."""
import numpy as np

class TF:
    def __init__(self, num, den):
        num, den = np.atleast_1d(np.asarray(num, float)), np.atleast_1d(np.asarray(den, float))
        num = np.trim_zeros(num, 'f') if np.any(num) else np.array([0.0])
        self.num, self.den = num / den[0], den / den[0]          # monic denominator
    def __mul__(self, o): o = o if isinstance(o, TF) else TF([o], [1]); return TF(np.polymul(self.num, o.num), np.polymul(self.den, o.den))
    __rmul__ = __mul__
    def __add__(self, o): o = o if isinstance(o, TF) else TF([o], [1]); return TF(np.polyadd(np.polymul(self.num, o.den), np.polymul(o.num, self.den)), np.polymul(self.den, o.den))
    def feedback(self, H=1.0):
        """Negative feedback G / (1 + G H)."""
        H = H if isinstance(H, TF) else TF([H], [1])
        return TF(np.polymul(self.num, H.den), np.polyadd(np.polymul(self.den, H.den), np.polymul(self.num, H.num)))
    def poles(self): return np.roots(self.den)
    def zeros(self): return np.roots(self.num) if len(self.num) > 1 else np.array([])
    def dcgain(self): return np.polyval(self.num, 0) / np.polyval(self.den, 0)
    def __call__(self, s): return np.polyval(self.num, s) / np.polyval(self.den, s)
    def ss(self):
        """Controllable canonical form (strictly proper part) plus direct feed-through D."""
        n = len(self.den) - 1
        num = np.r_[np.zeros(n + 1 - len(self.num)), self.num]
        D = num[0]; b = num[1:] - D * self.den[1:]             # remove the feed-through
        A = np.zeros((n, n)); A[0, :] = -self.den[1:]; A[1:, :-1] = np.eye(n - 1)
        B = np.zeros(n); B[0] = 1.0
        return A, B, b, D
    def step(self, t):
        A, B, Cr, D = self.ss(); n = len(B); h = t[1] - t[0]
        M = np.zeros((n + 1, n + 1)); M[:n, :n] = A * h; M[:n, n] = B * h
        E = expm(M); Ad, Bd = E[:n, :n], E[:n, n]              # exact for a step input held over each interval
        x = np.zeros(n); y = np.empty(len(t))
        for k in range(len(t)):
            y[k] = Cr @ x + D; x = Ad @ x + Bd
        return y

def expm(M):
    """Matrix exponential by scaling and squaring with a 16-term Taylor series."""
    s = max(0, int(np.ceil(np.log2(max(np.abs(M).sum(1).max(), 1e-16)))) + 1)
    X = M / 2**s; E = np.eye(len(M)); term = np.eye(len(M))
    for k in range(1, 17): term = term @ X / k; E = E + term
    for _ in range(s): E = E @ E
    return E

s = TF([1, 0], [1])                                            # the Laplace variable itself
m, c, k = 2.0, 4.0, 50.0
G = TF([1], [m, c, k])                                         # mass-spring-damper, force -> position
wn, zeta = np.sqrt(k / m), c / (2 * np.sqrt(k * m))
print(f"plant: wn = {wn:.4f} rad/s, zeta = {zeta:.4f}, poles {np.round(G.poles(), 4)}")
t = np.linspace(0, 6, 6001)
wd = wn * np.sqrt(1 - zeta**2)
exact = (1 - np.exp(-zeta * wn * t) * (np.cos(wd * t) + zeta / np.sqrt(1 - zeta**2) * np.sin(wd * t))) / k
yG = G.step(t)
print(f"open-loop step: max error vs closed form {np.max(abs(yG - exact)):.2e} m; overshoot {(yG.max()*k-1)*100:.2f} % (formula {np.exp(-zeta*np.pi/np.sqrt(1-zeta**2))*100:.2f} %)")
assert np.max(abs(yG - exact)) < 1e-12

act = TF([1], [0.05, 1])                                       # actuator lag, 50 ms
Kp = 50.0
T = (Kp * act * G).feedback(1.0)                               # unity feedback around actuator + plant
print(f"closed loop: den = {np.round(T.den, 4)}, poles {np.round(T.poles(), 4)}, DC gain {T.dcgain():.5f} (= Kp/(k+Kp) = {Kp/(k+Kp):.5f})")
assert abs(T.dcgain() - Kp / (k + Kp)) < 1e-12 and np.all(T.poles().real < 0)

# the same closed loop written as ODEs and integrated with RK4: e = r - x, 0.05 F' + F = Kp e, m x'' + c x' + k x = F
def f(z, r=1.0):
    x, v, F = z
    return np.array([v, (F - c * v - k * x) / m, (Kp * (r - x) - F) / 0.05])
z = np.zeros(3); h = t[1] - t[0]; xo = np.empty(len(t))
for i in range(len(t)):
    xo[i] = z[0]
    k1 = f(z); k2 = f(z + h / 2 * k1); k3 = f(z + h / 2 * k2); k4 = f(z + h * k3); z = z + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
yT = T.step(t)
print(f"closed-loop step from the TF vs RK4 on the ODEs: max difference {np.max(abs(yT - xo)):.2e}; peak {yT.max():.4f} at t = {t[np.argmax(yT)]:.3f} s, final {yT[-1]:.4f}")
assert np.max(abs(yT - xo)) < 1e-8
P = TF([1, 2], [1, 3]) + TF([1], [1, 1])                       # parallel connection check at s = 1j
assert abs(P(1j) - ((1j + 2) / (1j + 3) + 1 / (1j + 1))) < 1e-14
```

:::exercise Close a loop by hand
A motor speed loop has $G(s) = 10/(s + 2)$ and a proportional controller $K$. Find the closed-loop transfer function, its pole and its DC gain for $K = 1.8$.
---solution---
1. $T = KG/(1 + KG) = 10K/(s + 2 + 10K)$.
2. For $K = 1.8$: $T = 18/(s + 20)$, a pole at $s = -20$. The loop is 10 times faster than the motor's own pole at $-2$.
3. DC gain $18/20 = 0.9$: a 10 % steady error remains.
:::
