Feedback compares what you want with what you have and acts on the difference. It makes a machine follow commands, ignore disturbances and tolerate a plant that is not what the datasheet says. It can also make a perfectly stable machine oscillate itself to pieces. This lesson is about the line between the two.

## Why feedback works

Wrap a controller $K$ around a plant $G$ with unity feedback. The output is $Y = T R + S D$, with

$$
T = \frac{KG}{1 + KG}, \qquad S = \frac{1}{1 + KG} .
$$

Where the loop gain $|KG|$ is large, $T \approx 1$ and $S \approx 0$: the output follows the reference, and a disturbance $D$ at the output is divided by $1 + KG$. The same factor protects you from the plant: a relative change $dG/G$ changes the closed loop by only $dT/T = S\,dG/G$. A 20 % drop in a motor's gain, with a loop gain of 200, moves the closed loop by about 0.1 %.

## Closed-loop poles and the root locus

The closed-loop poles are the roots of the **characteristic equation** $1 + K\,N(s)/D(s) = 0$, or

$$
D(s) + K\,N(s) = 0 .
$$

At $K = 0$ they sit at the open-loop poles; as $K \to \infty$ they go to the open-loop zeros or off to infinity along asymptotes. The path they trace as $K$ grows is the **root locus**. Two real branches that meet leave the axis at a **breakaway point**, where $dK/ds = 0$. When a branch crosses the imaginary axis, the loop starts to oscillate at that frequency and beyond it the loop is unstable.

## The Routh-Hurwitz test

You can count right-half-plane roots without computing any. Write the coefficients of $a_0 s^n + a_1 s^{n-1} + \dots$ into two rows and build each next row from the two above:

$$
b_j = \frac{r_{1}\,q_{j+1} - q_{1}\,r_{j+1}}{r_1} ,
$$

where $q$ is the row two above and $r$ the row directly above. **The number of sign changes in the first column equals the number of roots with positive real part.** For a cubic $s^3 + a_1 s^2 + a_2 s + a_3$ this reduces to: all coefficients positive and $a_1 a_2 > a_3$. At the limit the auxiliary polynomial $a_1 s^2 + a_3 = 0$ gives the oscillation frequency $\omega = \sqrt{a_3/a_1}$.

:::example Where does it go unstable?
**Case 1.** $KG = K/(s(s + 1)(s + 5))$, characteristic equation $s^3 + 6s^2 + 5s + K = 0$.

1. Routh array, first column: $1,\ 6,\ (30 - K)/6,\ K$. At $K = 10$: $1, 6, 3.333, 10$, no sign change, stable. At $K = 50$: $1, 6, -3.333, 50$, two sign changes, two right-half-plane roots. `np.roots` agrees at every gain tested.
2. The limit is $6 \times 5 = K$, so $K = 30$, and $6s^2 + 30 = 0$ gives $\omega = \sqrt5 = 2.236068$ rad/s. Bisection on the root locus gives $K = 30.000000$ and $\omega = 2.236068$.
3. The two poles starting at 0 and −1 meet at the breakaway point $s = -0.4725$ ($3s^2 + 12s + 5 = 0$), at $K = 1.1285$. The sweep finds $K = 1.129$.

**Case 2.** The positioner of lesson 18.10: $0.1s^3 + 2.2s^2 + 6.5s + 50 + K_p = 0$.

4. Dividing by 0.1, the Routh condition is $22 \times 65 > 500 + 10K_p$, so $K_p < 93$. The bisection gives 93.0000, oscillating at $\sqrt{65} = 8.0623$ rad/s.

**Why feedback.** A plant $10/(s + 1)$ under $K = 20$: the closed-loop DC gain is 0.9950. Drop the plant gain to 8 and it becomes 0.9938, a change of only 0.124 % for a 20 % change in the plant.
:::

```python file=rootlocus.py
"""Feedback and stability: the Routh-Hurwitz test from scratch, a root locus traced by sweeping
the gain, and the gain at which the closed-loop poles cross into the right half-plane, found both
ways. Also why feedback works: a 20 % change in the plant barely moves the closed loop. numpy only."""
import numpy as np

def routh(c, eps=1e-9):
    """Routh array of the polynomial c[0] s^n + ... + c[n]. Returns the array and the number of
    sign changes in its first column (= number of right-half-plane roots)."""
    c = np.asarray(c, float); n = len(c)
    cols = (n + 1) // 2
    R = np.zeros((n, cols))
    R[0, :len(c[0::2])] = c[0::2]; R[1, :len(c[1::2])] = c[1::2]
    for i in range(2, n):
        if abs(R[i - 1, 0]) < eps: R[i - 1, 0] = eps            # epsilon trick for a zero pivot
        for j in range(cols - 1):
            R[i, j] = (R[i - 1, 0] * R[i - 2, j + 1] - R[i - 2, 0] * R[i - 1, j + 1]) / R[i - 1, 0]
    first = R[:, 0]
    return R, int(np.sum(np.sign(first[:-1]) != np.sign(first[1:])))

def char_poly(num, den, K):
    return np.polyadd(den, K * np.asarray(num, float))       # 1 + K N/D = 0  ->  D + K N = 0

def crossing_gain(num, den, lo=1e-6, hi=1e6):
    """Bisection on 'is any closed-loop pole in the RHP', in log K."""
    unstable = lambda K: np.max(np.roots(char_poly(num, den, K)).real) > 0
    assert not unstable(lo) and unstable(hi)
    for _ in range(200):
        mid = np.sqrt(lo * hi)
        lo, hi = (lo, mid) if unstable(mid) else (mid, hi)
    return np.sqrt(lo * hi)

# case 1: G = 1 / (s (s + 1)(s + 5)): characteristic s^3 + 6 s^2 + 5 s + K
num, den = [1.0], np.polymul([1, 0], np.polymul([1, 1], [1, 5]))
for K in (10, 30 - 1e-6, 30 + 1e-6, 50):
    R, nrhp = routh(char_poly(num, den, K))
    print(f"K = {K:9.6f}: Routh first column {np.round(R[:, 0], 4)}, RHP roots {nrhp}, from np.roots: {int(np.sum(np.roots(char_poly(num, den, K)).real > 0))}")
    assert nrhp == int(np.sum(np.roots(char_poly(num, den, K)).real > 0))
Kc = crossing_gain(num, den)
wc = np.max(np.abs(np.roots(char_poly(num, den, Kc)).imag))
print(f"root locus crosses the imaginary axis at K = {Kc:.6f}, omega = {wc:.6f} rad/s (Routh: K = 30, omega = sqrt 5 = {np.sqrt(5):.6f})")
assert abs(Kc - 30) < 1e-6 and abs(wc - np.sqrt(5)) < 1e-4

# the locus itself: closed-loop poles over a sweep of K
Ks = np.geomspace(0.01, 200, 20000)
locus = np.array([np.sort_complex(np.roots(char_poly(num, den, K))) for K in Ks])
brk = Ks[np.argmax(np.abs(locus[:, 1].imag) > 1e-6)]
print(f"two real poles meet and split off the axis at K = {brk:.3f} (breakaway point s = {np.real(locus[np.argmax(np.abs(locus[:, 1].imag) > 1e-6) - 1, 1]):.3f})")
sb = (-12 + np.sqrt(144 - 60)) / 6                           # dK/ds = 0: 3 s^2 + 12 s + 5 = 0
print(f"breakaway from dK/ds = 0: s = {sb:.4f}, K = {-np.polyval(den, sb):.4f}")
assert abs(brk + np.polyval(den, sb)) < 0.005

# case 2: the positioner from lesson 18.10: 0.1 s^3 + 2.2 s^2 + 6.5 s + 50 + Kp
num2, den2 = [1.0], np.polymul([0.05, 1], [2, 4, 50])
Kc2 = crossing_gain(num2, np.polyadd(den2, [0]))
print(f"positioner: unstable above Kp = {Kc2:.4f} (Routh: (22*65 - 500)/10 = {(22*65-500)/10:.1f}), oscillating at {np.max(np.abs(np.roots(char_poly(num2, den2, Kc2)).imag)):.4f} rad/s (sqrt 65 = {np.sqrt(65):.4f})")
assert abs(Kc2 - 93) < 1e-5

# why feedback works: plant gain drops 20 %, closed loop with K = 20 on G0 = 10 / (s + 1)
for g in (10.0, 8.0):
    print(f"plant DC gain {g:4.1f}: open-loop output {g:5.2f}, closed loop K = 20 -> {20*g/(1+20*g):.4f}")
dT = (20 * 8 / 161) / (20 * 10 / 201) - 1
print(f"a 20 % plant change moves the closed loop by {dT*100:.3f} % (sensitivity 1/(1 + KG) = {1/201:.4f})")
assert abs(dT) < 0.0015
```

:::exercise Routh by hand
For $s^3 + 4s^2 + 8s + K$, find the range of $K$ for stability and the frequency of oscillation at the limit.
---solution---
1. Routh array: rows $[1, 8]$, $[4, K]$, then $(4 \times 8 - K)/4$, then $K$.
2. Stable if $K > 0$ and $32 - K > 0$: $0 < K < 32$.
3. At $K = 32$ the auxiliary equation is $4s^2 + 32 = 0$, so $\omega = \sqrt8 = 2.83$ rad/s.
:::
