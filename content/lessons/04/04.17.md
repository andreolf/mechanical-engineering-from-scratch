Steady temperature in a plate, the stress function in a twisted shaft, pressure in incompressible flow, electrostatic potential: all are Poisson problems $-\nabla^2u = f$. Lesson 03.16 solved one with SOR without saying much about why it works or how to choose its parameter. This lesson builds the three classic iterations, explains their speed through eigenvalues, and shows that the right relaxation factor turns thousands of iterations into about a hundred.

## The 5-point system

On an $n\times n$ grid with spacing $h$,

$$
\frac{4u_{i,j} - u_{i+1,j} - u_{i-1,j} - u_{i,j+1} - u_{i,j-1}}{h^2} = f_{i,j}.
$$

That's $(n - 1)^2$ unknowns with a sparse, symmetric positive definite matrix. Direct sparse solvers work well in 2D; iterative methods matter for very large or 3D problems, and they're the stepping stone to multigrid.

## Three iterations

- **Jacobi:** replace every value by the average of its four neighbours plus $h^2f/4$, using only old values.
- **Gauss-Seidel:** the same, but use new values as soon as they are computed. About twice as fast as Jacobi.
- **SOR:** compute the Gauss-Seidel value and overshoot it: $u \leftarrow (1 - \omega)u + \omega u_{\text{GS}}$ with $1 < \omega < 2$.

## Why they're slow, and how fast SOR can be

The error shrinks each iteration by the **spectral radius** $\rho$ of the iteration matrix. For the model problem:

$$
\rho_{\text{J}} = \cos\pi h, \qquad \rho_{\text{GS}} = \cos^2\pi h, \qquad \omega_{\text{opt}} = \frac{2}{1 + \sin\pi h}, \qquad \rho_{\text{SOR}} = \omega_{\text{opt}} - 1 .
$$

For small $h$, Jacobi has $\rho \approx 1 - \pi^2h^2/2$: the number of iterations grows like $1/h^2$, so like $n^2$. With $\omega_{\text{opt}}$, SOR has $\rho \approx 1 - 2\pi h$, so iterations grow only like $n$. The slow components are always the smooth, long-wavelength errors, which local averaging barely touches. That observation leads straight to multigrid in the next lesson.

:::example A 32 × 32 plate
$-\nabla^2u = 2\pi^2\sin\pi x\sin\pi y$ on the unit square with $u = 0$ on the edges (exact $u = \sin\pi x\sin\pi y$), $n = 32$, iterating until the residual falls by $10^8$.

1. $\omega_{\text{opt}} = 2/(1 + \sin(\pi/32)) = 1.8215$.
2. Iterations: Jacobi 3817, Gauss-Seidel 1945, SOR 126. SOR is 15 times faster than Gauss-Seidel and 30 times faster than Jacobi.
3. Prediction for Jacobi: $\ln10^{-8}/\ln\cos(\pi/32) = 3816$ iterations. The right-hand side is a single eigenmode, so the prediction is essentially exact.
4. All three reach the same discretisation error, $8.04\times10^{-4}$: iterating further can't beat the grid.
:::

```python file=poisson_sor.py
"""2D Poisson on a square: Jacobi, Gauss-Seidel and SOR with the optimal relaxation factor."""
import math
import numpy as np


def residual(u, f, h):
    r = np.zeros_like(u)
    r[1:-1, 1:-1] = f[1:-1, 1:-1] + (u[2:, 1:-1] + u[:-2, 1:-1] + u[1:-1, 2:] + u[1:-1, :-2] - 4 * u[1:-1, 1:-1]) / h**2
    return r


def solve(method, n, f, tol=1e-8, omega=1.0, maxit=100_000):
    """-lap u = f on the unit square, u = 0 on the boundary; returns the iteration count to reach a relative residual tol."""
    h = 1.0 / n; u = np.zeros((n + 1, n + 1)); r0 = np.linalg.norm(f[1:-1, 1:-1])
    for it in range(1, maxit + 1):
        if method == "jacobi":
            u[1:-1, 1:-1] = 0.25 * (u[2:, 1:-1] + u[:-2, 1:-1] + u[1:-1, 2:] + u[1:-1, :-2] + h * h * f[1:-1, 1:-1])
        else:                                      # Gauss-Seidel / SOR in red-black order, so each half-sweep vectorises
            for colour in (0, 1):
                m = np.zeros_like(u, bool); ii, jj = np.meshgrid(np.arange(n + 1), np.arange(n + 1), indexing="ij")
                m[1:-1, 1:-1] = ((ii + jj) % 2 == colour)[1:-1, 1:-1]
                gs = np.zeros_like(u)
                gs[1:-1, 1:-1] = 0.25 * (u[2:, 1:-1] + u[:-2, 1:-1] + u[1:-1, 2:] + u[1:-1, :-2] + h * h * f[1:-1, 1:-1])
                u[m] = (1 - omega) * u[m] + omega * gs[m]
        if np.linalg.norm(residual(u, f, h)[1:-1, 1:-1]) < tol * r0:
            return u, it
    raise RuntimeError("no convergence")


if __name__ == "__main__":
    n = 32
    x = np.linspace(0, 1, n + 1); X, Y = np.meshgrid(x, x, indexing="ij")
    f = 2 * math.pi**2 * np.sin(math.pi * X) * np.sin(math.pi * Y)     # exact u = sin(pi x) sin(pi y)
    omega_opt = 2 / (1 + math.sin(math.pi / n))
    print(f"n = {n}: optimal omega = 2 / (1 + sin(pi h)) = {omega_opt:.4f}")
    its = {}
    for name, meth, om in (("Jacobi", "jacobi", 1.0), ("Gauss-Seidel", "sor", 1.0), ("SOR (optimal)", "sor", omega_opt)):
        u, its[name] = solve(meth, n, f, omega=om)
        err = np.max(np.abs(u - np.sin(math.pi * X) * np.sin(math.pi * Y)))
        print(f"{name:14s}: {its[name]:5d} iterations, max error vs exact {err:.2e}")
    assert its["SOR (optimal)"] * 10 < its["Gauss-Seidel"]
    assert 1.7 < its["Jacobi"] / its["Gauss-Seidel"] < 2.3          # Gauss-Seidel is twice as fast as Jacobi
    # spectral radius of Jacobi: cos(pi h); iterations ~ ln(tol) / ln(rho)
    rho = math.cos(math.pi / n)
    print(f"Jacobi spectral radius cos(pi h) = {rho:.5f}: predicted about {math.log(1e-8) / math.log(rho):.0f} iterations")
    assert abs(its["Jacobi"] - math.log(1e-8) / math.log(rho)) < 5
```

:::exercise Doubling the grid
Estimate the iteration counts for Jacobi and optimal SOR at $n = 64$, from the $n = 32$ results.
---solution---
1. Jacobi iterations scale like $1/h^2$: $3817\cdot4 \approx 15\,300$. Check: $\ln10^{-8}/\ln\cos(\pi/64) = 15\,283$.
2. SOR scales like $1/h$: about $126\cdot2 \approx 250$.
3. Each iteration also costs four times as much on the finer grid, so Jacobi's total work grows 16 times, SOR's 8 times. Multigrid's grows only 4 times, in proportion to the unknowns.
:::
