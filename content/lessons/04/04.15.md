A plucked guitar string, a pressure pulse in a hydraulic line, a stress wave in a bar after an impact: all obey the wave equation $u_{tt} = c^2u_{xx}$. Information travels at speed $c$, and a numerical scheme must respect that. The **CFL condition** (Courant, Friedrichs and Lewy, 1928) says the numerical domain of dependence must contain the physical one. Break it and the solution explodes; meet it exactly and, for this equation, the scheme is exact.

## Leapfrog

Centred differences in both time and space:

$$
u_i^{n+1} = 2u_i^n - u_i^{n-1} + \sigma^2\left(u_{i+1}^n - 2u_i^n + u_{i-1}^n\right), \qquad \sigma = \frac{c\,\Delta t}{\Delta x}.
$$

$\sigma$ is the **Courant number**. Starting from rest, the first step uses $u_i^1 = u_i^0 + \tfrac{\sigma^2}{2}(u_{i+1}^0 - 2u_i^0 + u_{i-1}^0)$.

## The CFL condition

In one step, the scheme only lets information move one cell, a distance $\Delta x$. The physical wave moves $c\Delta t$. If $c\Delta t > \Delta x$, the true solution at a node depends on data the scheme never sees, and it cannot converge. Von Neumann analysis makes it precise:

$$
\sin\frac{\omega\Delta t}{2} = \sigma\sin\frac{k\Delta x}{2},
$$

which has real frequencies for every mode only if $\sigma \le 1$. Above 1, the grid-scale mode grows exponentially.

At $\sigma = 1$ exactly, $\omega = ck$ for every mode: no dispersion, and leapfrog reproduces d'Alembert's solution exactly at the nodes. Below 1, short waves travel slightly too slowly (numerical dispersion), so sharp kinks smear into ripples.

:::widget cfl
A plucked string (dashed: exact). At CFL = 1 the leapfrog solution sits on the exact one after any number of periods. Lower it and ripples trail the kinks; push it to 1.01 and the string explodes within a period.
:::

:::example A guitar's high E string
Scale length $L = 648$ mm, fundamental $f_1 = 329.63$ Hz, plucked 2 mm high at 20% of the length.

1. Wave speed $c = 2Lf_1 = 2\cdot0.648\cdot329.63 = 427.2$ m/s; period $1/f_1 = 3.0337$ ms.
2. With 100 cells, $\Delta x = 6.48$ mm and the CFL limit is $\Delta t \le \Delta x/c = 15.17$ µs: 200 steps per period.
3. After exactly one period the string should be back in its plucked shape. Measured maximum deviation: $2.8\times10^{-15}$ mm at CFL 1.000 (exact), $0.089$ mm at CFL 0.5 (4% of the amplitude, from dispersion), and $5\times10^{30}$ mm at CFL 1.02.
:::

```python file=wave_cfl.py
"""Leapfrog for the wave equation u_tt = c^2 u_xx on a guitar string: stable for CFL = c dt/dx <= 1, exact at CFL = 1."""
import numpy as np

L, F1 = 0.648, 329.63          # high E string: scale length (m) and fundamental (Hz)
C = 2 * L * F1                 # wave speed, m/s


def pluck(x, a=0.2 * L, height=2e-3):
    return np.where(x < a, height * x / a, height * (L - x) / (L - a))


def leapfrog(n, cfl, t_end):
    dx = L / n; steps = max(1, round(t_end * C / (cfl * dx))); dt = t_end / steps; s2 = (C * dt / dx) ** 2
    x = np.linspace(0, L, n + 1)
    u_old = pluck(x)
    u = u_old.copy()                                       # first step from rest: u1 = u0 + (s^2 / 2) * second difference
    u[1:-1] = u_old[1:-1] + 0.5 * s2 * (u_old[2:] - 2 * u_old[1:-1] + u_old[:-2])
    for _ in range(steps - 1):
        u_new = np.zeros_like(u)
        u_new[1:-1] = 2 * u[1:-1] - u_old[1:-1] + s2 * (u[2:] - 2 * u[1:-1] + u[:-2])
        u_old, u = u, u_new
    return x, u, C * dt / dx, steps


if __name__ == "__main__":
    period = 1 / F1
    print(f"wave speed c = 2 L f = {C:.1f} m/s, period {period * 1e3:.4f} ms")
    n = 100
    for cfl in (1.0, 0.5, 1.02):
        x, u, s, steps = leapfrog(n, cfl, period)
        err = np.max(np.abs(u - pluck(x)))                # after one period the string is back in its plucked shape
        print(f"CFL {s:.3f}: {steps} steps, max deviation from the plucked shape after one period {err * 1e3:.3g} mm")
    x, u, s, _ = leapfrog(n, 1.0, period); assert np.max(np.abs(u - pluck(x))) < 1e-12        # exact at CFL = 1
    x, u, s, _ = leapfrog(n, 0.5, period); assert 1e-6 < np.max(np.abs(u - pluck(x))) < 5e-4  # stable, slightly dispersive
    x, u, s, _ = leapfrog(n, 1.02, 3 * period); assert np.max(np.abs(u)) > 1                   # unstable past CFL = 1
    dx = L / n
    print(f"stability limit dt <= dx / c = {dx / C * 1e6:.3f} us for {n} cells")
```

:::exercise Water hammer time step
A pressure wave travels at $c = 1200$ m/s in a steel water pipe. You model 300 m of pipe with 600 cells. What is the largest stable time step, and how many steps cover 2 s?
---solution---
1. $\Delta x = 300/600 = 0.5$ m.
2. $\Delta t \le \Delta x/c = 0.5/1200 = 0.417$ ms.
3. $2/0.000417 = 4800$ steps. At CFL exactly 1 the scheme is also dispersion-free, so a standard choice in water hammer codes (the method of characteristics) is to run at $\sigma = 1$.
:::
