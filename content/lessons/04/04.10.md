A ball dropped on a hard floor spends almost a second in smooth free flight and under two milliseconds in contact, where the forces are thousands of times larger. A fixed step small enough for the contact wastes thousands of steps in flight; a step sized for the flight jumps straight through the floor. Adaptive integrators measure their own error every step and adjust $h$ to meet a tolerance you set. They're the default in every serious ODE library.

## Estimating the error for free

Run two methods of different order from the same point and compare. An **embedded pair** shares all its stage evaluations: the Dormand-Prince pair computes seven stages, combines them one way for a fifth-order result $y^{(5)}$ and another way for a fourth-order $y^{(4)}$. Their difference estimates the local error of the lower-order one:

$$
\mathrm{err} = \left\| \frac{y^{(5)} - y^{(4)}}{\mathrm{atol} + \mathrm{rtol}\,|y|} \right\|_{\mathrm{RMS}} .
$$

Scaling by $\mathrm{atol} + \mathrm{rtol}|y|$ makes $\mathrm{err} \le 1$ mean "within tolerance". The method then carries on with the fifth-order value (local extrapolation), and since the seventh stage equals the first stage of the next step, each accepted step costs six new evaluations.

## Choosing the next step

Local error of a fourth-order estimate scales like $h^5$, so to hit $\mathrm{err} = 1$:

$$
h_{\text{new}} = h \cdot \min\!\left(5,\ \max\!\left(0.2,\ 0.9\,\mathrm{err}^{-1/5}\right)\right).
$$

If $\mathrm{err} > 1$ the step is **rejected** and retried with the smaller $h$. The safety factor 0.9 and the limits 0.2 and 5 stop the controller from oscillating.

## Local tolerance, global error

The controller bounds the error made in each step, not the accumulated error at the end. For well-behaved problems the global error ends up close to the tolerance, which the code checks; for chaotic or unstable problems it can be much larger. Always repeat a run at a tighter tolerance and compare: if the answer changes, it wasn't converged.

Large steps also mean the solution is only known at a few points. To plot it, or to find the apex of a bounce, use **dense output**: an interpolant built from the stage values. The widget below uses a cubic Hermite curve through the position and velocity at each accepted step, which is exact for a free-flight parabola.

1. Harmonic oscillator $y'' = -y$, $y(0) = 1$, to $t = 10$ (exact $\cos10$):

| rtol | steps | global error |
|---|---|---|
| $10^{-4}$ | 23 | $1.5\times10^{-4}$ |
| $10^{-6}$ | 53 | $1.2\times10^{-6}$ |
| $10^{-8}$ | 129 | $1.1\times10^{-8}$ |

Each factor of 100 in tolerance costs about $100^{1/5} \approx 2.5$ times more steps, as a fifth-order method should.

2. Ball, $m = 0.06$ kg, contact stiffness $2\times10^5$ N/m, damping 8 N s/m, rtol $10^{-6}$: 47 steps for the first second. Largest step in flight 390 ms, smallest in contact 3.6 µs, a ratio of about $10^5$.
3. Physics check: contact time $\pi\sqrt{m/k} = 1.72$ ms; damping ratio $\zeta = 8/(2\sqrt{2\times10^5\cdot0.06}) = 0.0365$, so restitution $e = e^{-\zeta\pi/\sqrt{1 - \zeta^2}} = 0.892$ and rebound height $e^2 \times 1$ m $= 0.795$ m. The solver gives 0.795 m.

```python file=adaptive_rk45.py
"""Dormand-Prince RK5(4) with error control: steps shrink at an impact and grow in free flight."""
import math
import numpy as np

C = np.array([0, 1 / 5, 3 / 10, 4 / 5, 8 / 9, 1, 1])
A = [[], [1 / 5], [3 / 40, 9 / 40], [44 / 45, -56 / 15, 32 / 9],
     [19372 / 6561, -25360 / 2187, 64448 / 6561, -212 / 729],
     [9017 / 3168, -355 / 33, 46732 / 5247, 49 / 176, -5103 / 18656],
     [35 / 384, 0, 500 / 1113, 125 / 192, -2187 / 6784, 11 / 84]]
B5 = np.array([35 / 384, 0, 500 / 1113, 125 / 192, -2187 / 6784, 11 / 84, 0])
B4 = np.array([5179 / 57600, 0, 7571 / 16695, 393 / 640, -92097 / 339200, 187 / 2100, 1 / 40])


def dopri(f, t, y, t_end, rtol=1e-6, atol=1e-9, h=1e-3):
    ts, ys, hs = [t], [y.copy()], []
    while t < t_end:
        h = min(h, t_end - t)
        k = []
        for i in range(7):
            k.append(f(t + C[i] * h, y + h * sum(a * kj for a, kj in zip(A[i], k))))
        k = np.array(k)
        y5 = y + h * B5 @ k
        err = h * (B5 - B4) @ k                         # embedded error estimate, free of extra evaluations
        sc = atol + rtol * np.maximum(np.abs(y), np.abs(y5))
        en = math.sqrt(np.mean((err / sc) ** 2))
        if en <= 1:                                     # accept
            t, y = t + h, y5
            ts.append(t); ys.append(y.copy()); hs.append(h)
        h *= min(5.0, max(0.2, 0.9 * en ** (-1 / 5))) if en > 0 else 5.0
    return np.array(ts), np.array(ys), np.array(hs)


def ball(t, y, m=0.06, k=2e5, c=8.0, g=9.81):
    """Tennis ball on a stiff penalty contact: free fall above the floor, spring-damper below it."""
    x, v = y
    F = -m * g + ((-k * x - c * v) if x < 0 else 0.0)
    return np.array([v, F / m])


if __name__ == "__main__":
    # accuracy: harmonic oscillator, exact solution cos t
    for tol in (1e-4, 1e-6, 1e-8):
        ts, ys, hs = dopri(lambda t, y: np.array([y[1], -y[0]]), 0.0, np.array([1.0, 0.0]), 10.0, rtol=tol, atol=tol * 1e-3)
        err = abs(ys[-1, 0] - math.cos(10))
        print(f"rtol {tol:.0e}: {len(hs):4d} steps, global error at t = 10: {err:.1e}")
        assert err < 100 * tol
    # step-size history for a dropped ball
    ts, ys, hs = dopri(ball, 0.0, np.array([1.0, 0.0]), 1.0)
    contact = ys[1:, 0] < 0
    print(f"ball: {len(hs)} steps; largest step in flight {hs[~contact].max() * 1e3:.2f} ms, smallest in contact {hs[contact].min() * 1e6:.1f} us")
    # big steps in flight skip over the apex, so compute it from the first state after lift-off
    i = np.nonzero((ys[:, 0] > 0) & (ys[:, 1] > 0))[0][0]
    apex = ys[i, 0] + ys[i, 1] ** 2 / (2 * 9.81)
    print(f"contact lasts about {np.sum(hs[contact]) * 1e3:.2f} ms (pi sqrt(m/k) = {math.pi * math.sqrt(0.06 / 2e5) * 1e3:.2f} ms); rebound apex {apex:.3f} m")
    assert abs(apex - 0.7946) < 2e-3
    assert hs[contact].min() < hs[~contact].max() / 20
```

:::exercise Predict the next step
A fourth-order error estimate gives $\mathrm{err} = 3.2$ for a step of 2 ms. Is the step accepted, and what step is tried next?
---solution---
1. $\mathrm{err} > 1$: rejected.
2. Factor $0.9\cdot3.2^{-1/5} = 0.9\cdot0.792 = 0.713$, inside the limits $[0.2, 5]$.
3. Retry with $h = 0.713\cdot2 = 1.43$ ms.
:::
