A simulation that runs for a while and then shoots off to $10^{300}$ is the most common surprise in engineering computing. It is rarely a bug in the physics. It is the time step violating the **stability limit** of the integrator. You can predict that limit exactly with one line of algebra, and this lesson shows how.

## The test equation

Linearise any system around an operating point and diagonalise it: each mode behaves like

$$
y' = \lambda y, \qquad y(0) = 1, \qquad y(t) = e^{\lambda t},
$$

with $\lambda$ an eigenvalue of the Jacobian (Phase 02). Real negative $\lambda$ is a decaying mode (cooling, damping); complex $\lambda$ with negative real part is a damped oscillation.

## One step of Euler

Explicit Euler, $y_{n+1} = y_n + h f(y_n)$, applied to the test equation gives

$$
y_{n+1} = (1 + h\lambda)\,y_n \quad\Longrightarrow\quad y_n = (1 + h\lambda)^n .
$$

The numerical solution decays only if the **amplification factor** satisfies $|1 + h\lambda| \le 1$. In the complex $z = h\lambda$ plane that is a disc of radius 1 centred at $-1$: the **stability region**. For a real decay rate $\lambda = -k$:

$$
|1 - hk| \le 1 \quad\Longleftrightarrow\quad h \le \frac{2}{k}.
$$

For $1/k < h < 2/k$ the solution still decays but flips sign every step: stable, but qualitatively wrong. Purely imaginary $\lambda$ (an undamped oscillator) is *never* inside the disc: Euler always adds energy to a spring-mass system.

## Stiffness

For a system, every mode must be stable, so the **fastest** mode sets the step, even after it has decayed to nothing. Eigenvalues $-1$ and $-1000$ force $h < 0.002$ s, so 5000 steps to cover 10 s of a slow transient. That is a **stiff** system, and lesson 04.11 cures it with implicit methods.

:::example A thermocouple bead
A bead with time constant $\tau = 0.5$ s obeys $y' = -2y$ ($k = 2$ s⁻¹). Integrate with explicit Euler for 50 steps.

| $h$ (s) | $1 - hk$ | size after 50 steps |
|---|---|---|
| 0.1 | 0.8 | $1.4\times10^{-5}$ |
| 0.5 | 0 | 0 (one step lands on the answer) |
| 0.9 | $-0.8$ | $1.4\times10^{-5}$, sign flipping |
| 1.0 | $-1$ | 1, oscillating forever |
| 1.1 | $-1.2$ | $9.1\times10^{3}$, blown up |

The boundary is exactly $h = 2/k = 1$ s, and the code checks it at 59 step sizes.
:::

```python file=euler_stability.py
"""Explicit Euler on y' = -k y: amplification factor 1 - h k, stable exactly when h <= 2/k."""
import numpy as np


def euler(f, y0, h, n):
    y = np.empty(n + 1); y[0] = y0
    for i in range(n):
        y[i + 1] = y[i] + h * f(y[i])
    return y


if __name__ == "__main__":
    # a thermocouple bead: time constant tau = 0.5 s, so k = 2 1/s
    k = 2.0; f = lambda y: -k * y
    print("  h (s)   h k   amplification   |y| after 50 steps")
    for h in (0.1, 0.5, 0.9, 1.0, 1.1):
        y = euler(f, 1.0, h, 50)
        print(f"{h:6.2f} {h * k:6.2f} {1 - h * k:14.2f} {abs(y[-1]):20.3e}")
    # the stability limit is exactly h = 2 / k
    for h in np.linspace(0.05, 1.5, 59):
        grows = abs(euler(f, 1.0, h, 200)[-1]) > 1.0
        assert grows == (h > 2 / k + 1e-12), h
    print(f"diverges exactly when h > 2/k = {2 / k} s")
    # stiff pair: a fast mode (k = 1000) forces a tiny step even after it has died out
    lam = np.array([-1.0, -1000.0])
    h_max = 2 / 1000
    print(f"system with eigenvalues {lam}: explicit Euler needs h < {h_max} s, i.e. {int(10 / h_max)} steps to reach t = 10 s")
    assert np.all(np.abs(1 + 0.0019 * lam) < 1) and not np.all(np.abs(1 + 0.0021 * lam) < 1)
```

:::exercise Step limit for a damped oscillator
A suspension mode has $\lambda = -0.5 \pm 3i$ s⁻¹. What is the largest stable explicit Euler step?
---solution---
1. Need $|1 + h\lambda|^2 = (1 - 0.5h)^2 + (3h)^2 \le 1$.
2. Expand: $1 - h + 0.25h^2 + 9h^2 \le 1$, so $h(9.25h - 1) \le 0$.
3. $h \le 1/9.25 = 0.108$ s. In general $h \le -2\,\mathrm{Re}\lambda/|\lambda|^2$: lightly damped oscillators need tiny steps.
:::
