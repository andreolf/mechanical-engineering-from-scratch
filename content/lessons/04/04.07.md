Every finite-element stiffness matrix, every mass matrix and every load vector is built from integrals over elements, evaluated millions of times. Each function evaluation costs. Gaussian quadrature answers a sharp question: with $n$ evaluations, what is the most accurate rule possible? Answer: place the points at the roots of a Legendre polynomial and you integrate every polynomial up to degree $2n - 1$ exactly, twice what equally spaced points achieve.

## Counting the freedom

A rule $\int_{-1}^{1}f(x)\,dx \approx \sum_{i=1}^{n} w_i f(x_i)$ has $2n$ free numbers: $n$ nodes and $n$ weights. Demanding exactness for $1, x, x^2, \dots, x^{2n-1}$ gives $2n$ equations. For $n = 2$, symmetry gives $x_{1,2} = \pm a$, $w_1 = w_2 = 1$ (from $\int1 = 2$), and $\int x^2 = 2/3$ requires $2a^2 = 2/3$:

$$
\int_{-1}^{1}f\,dx \approx f\!\left(-\tfrac{1}{\sqrt3}\right) + f\!\left(\tfrac{1}{\sqrt3}\right),
$$

exact for cubics. The three-point rule uses $0$ and $\pm\sqrt{3/5}$ with weights $8/9$ and $5/9$.

## Why Legendre roots

Divide a polynomial $f$ of degree $\le 2n - 1$ by the Legendre polynomial $P_n$: $f = qP_n + r$ with $q$ and $r$ of degree $\le n - 1$. Legendre polynomials are orthogonal, so $\int qP_n = 0$. At the roots of $P_n$, $f(x_i) = r(x_i)$, and an $n$-point rule with the right weights is exact for the degree-$(n-1)$ remainder $r$. So the rule is exact for $f$.

## Computing nodes: Golub-Welsch

Legendre polynomials satisfy a three-term recurrence, which can be written as an eigenvalue problem. The nodes are the eigenvalues of the symmetric tridiagonal matrix with off-diagonal entries $\beta_k = k/\sqrt{4k^2 - 1}$, and the weights are $w_i = 2v_{1,i}^2$ from the first components of the normalised eigenvectors. Phase 02's eigenvalue machinery does the rest.

For an interval $[a, b]$, map $x = \frac{b - a}{2}t + \frac{a + b}{2}$ and multiply the sum by $\frac{b - a}{2}$.

Nodes (cyan) sit at the roots of $P_n$, clustering towards the ends. Bar heights are the weights. Watch the error of $\int_0^2 e^{-x^2}dx$ fall by orders of magnitude with each extra point.

:::example Two points, exact cubic
Integrate $f(x) = x^3 + x^2$ on $[0, 2]$ with the two-point rule.

1. Map: $x = t + 1$, scale factor $(b - a)/2 = 1$. Nodes $x = 1 \mp 0.57735$: $0.42265$ and $1.57735$.
2. $f(0.42265) = 0.25413$ and $f(1.57735) = 6.41253$.
3. Sum: $6.66667$. Exact: $\frac{2^4}{4} + \frac{2^3}{3} = 4 + 2.66667 = 6.66667$. Exact, as promised for a cubic.
4. For $\int_0^2 e^{-x^2}dx = 0.882081$, errors with 2 to 6 points are $3.7\times10^{-2}$, $3.2\times10^{-3}$, $1.5\times10^{-4}$, $3.4\times10^{-6}$, $3.5\times10^{-8}$. Simpson with 5 points is still at $2.7\times10^{-4}$.
:::

```python file=gauss_quadrature.py
"""Gauss-Legendre nodes and weights by Golub-Welsch, exactness check and a beam-section integral."""
import math
import numpy as np


def gauss_legendre(n):
    """Eigenvalues of the symmetric tridiagonal Jacobi matrix are the nodes; weights come from the eigenvectors."""
    k = np.arange(1, n)
    beta = k / np.sqrt(4 * k**2 - 1)
    J = np.diag(beta, 1) + np.diag(beta, -1)
    x, V = np.linalg.eigh(J)
    w = 2 * V[0] ** 2
    return x, w


def integrate(f, a, b, n):
    x, w = gauss_legendre(n)
    return 0.5 * (b - a) * np.sum(w * f(0.5 * (b - a) * x + 0.5 * (a + b)))


def simpson(f, a, b, m):
    x = np.linspace(a, b, m + 1); y = f(x); h = (b - a) / m
    return h / 3 * (y[0] + y[-1] + 4 * y[1:-1:2].sum() + 2 * y[2:-1:2].sum())


if __name__ == "__main__":
    x2, w2 = gauss_legendre(2)
    print("2-point nodes", x2, "weights", w2)
    assert np.allclose(x2, [-1 / math.sqrt(3), 1 / math.sqrt(3)]) and np.allclose(w2, [1, 1])
    for n in range(1, 9):
        x, w = gauss_legendre(n)
        for d in range(2 * n):                          # exact up to degree 2n - 1
            exact = 2 / (d + 1) if d % 2 == 0 else 0.0
            assert abs(np.sum(w * x**d) - exact) < 1e-13, (n, d)
        d = 2 * n
        assert abs(np.sum(w * x**d) - 2 / (d + 1)) > 1e-6     # and not beyond
    ref, wref = np.polynomial.legendre.leggauss(5)
    assert np.allclose(gauss_legendre(5)[0], ref) and np.allclose(gauss_legendre(5)[1], wref)
    print("n-point rule exact to degree 2n - 1 for n = 1..8; matches numpy leggauss")
    # smooth non-polynomial: integral of exp(-x^2) on [0, 2]
    f = lambda x: np.exp(-x**2)
    exact = math.sqrt(math.pi) / 2 * math.erf(2)
    for n in (2, 3, 4, 5, 6):
        print(f"Gauss {n} points: error {abs(integrate(f, 0, 2, n) - exact):.2e}")
    print(f"Simpson, 5 points: error {abs(simpson(f, 0, 2, 4) - exact):.2e}")
    assert abs(integrate(f, 0, 2, 6) - exact) < 1e-6
```

:::exercise How many points for an element?
A 2D bilinear quadrilateral element with a constant material has a stiffness integrand that, on a rectangular element, is a polynomial of degree 2 in each direction. How many Gauss points per direction integrate it exactly, and how many in total?
---solution---
1. $n$ points are exact to degree $2n - 1$. Degree 2 needs $2n - 1 \ge 2$, so $n = 2$.
2. Use a tensor product: $2 \times 2 = 4$ points per element. That is the standard "full integration" of a bilinear quad.
3. Using only 1 point ("reduced integration") is cheaper and avoids shear locking in bending, but it can admit zero-energy hourglass modes. Phase 16 (finite elements) comes back to this.
:::
