The last lesson ended with a frustration: simple iterations kill jagged errors quickly but crawl on smooth ones, so their cost explodes as the grid is refined. Multigrid turns that weakness into a strategy. A smooth error on a fine grid looks jagged on a coarser grid, where the same simple iteration kills it cheaply. Cycle between grids and the cost of a solve becomes proportional to the number of unknowns, the best possible. Modern FE and CFD codes rely on it, often hidden inside an "algebraic multigrid" preconditioner.

## Smoothers smooth

Weighted Jacobi with $\omega = 2/3$ on $-u'' = f$ multiplies the error mode $\sin(k\pi x)$ by

$$
g(k) = 1 - 2\omega\sin^2\frac{k\pi h}{2}.
$$

For the upper half of the modes ($kh \ge 1/2$), $|g| \le 1/3$: each sweep removes at least two thirds of every rough component, whatever the grid size. For the smoothest mode $g \approx 1 - \omega\pi^2h^2/2$, almost 1. So after a few sweeps the error is **smooth**, not small. That's why the method is called a smoother.

## Coarse-grid correction

A smooth error can be represented on a grid with half the points. The two-grid cycle:

1. **Pre-smooth**: a few weighted-Jacobi sweeps on the fine grid.
2. **Restrict** the residual $r = f - Au$ to the coarse grid with full weighting $(\tfrac14, \tfrac12, \tfrac14)$.
3. **Solve** the coarse error equation $A_{2h}e_{2h} = r_{2h}$.
4. **Prolong** $e_{2h}$ back by linear interpolation and correct: $u \leftarrow u + Pe_{2h}$.
5. **Post-smooth** to remove the jaggedness that the interpolation introduces.

Solve step 3 the same way, recursively, and you have a **V-cycle**. The work per cycle is about twice that of one fine-grid sweep (the grids sum to $n + n/2 + n/4 + \dots \approx 2n$), and the error reduction per cycle is independent of $n$.

```python file=multigrid.py
"""Two-grid and multigrid V-cycles for -u'' = f in 1D: weighted Jacobi smooths, the coarse grid fixes the smooth error."""
import math
import numpy as np


def apply_A(u, h):
    """-u'' on interior nodes; u includes the zero boundary values."""
    r = np.zeros_like(u)
    r[1:-1] = (2 * u[1:-1] - u[:-2] - u[2:]) / h**2
    return r


def smooth(u, f, h, sweeps, w=2 / 3):
    for _ in range(sweeps):
        u[1:-1] = (1 - w) * u[1:-1] + w * 0.5 * (u[:-2] + u[2:] + h * h * f[1:-1])
    return u


def restrict(r):
    """Full weighting: coarse value = (1/4, 1/2, 1/4) of the fine neighbours."""
    rc = np.zeros((len(r) - 1) // 2 + 1)
    rc[1:-1] = 0.25 * r[1:-2:2] + 0.5 * r[2:-1:2] + 0.25 * r[3::2]
    return rc


def prolong(ec):
    """Linear interpolation back to the fine grid."""
    e = np.zeros(2 * (len(ec) - 1) + 1)
    e[::2] = ec; e[1::2] = 0.5 * (ec[:-1] + ec[1:])
    return e


def v_cycle(u, f, h, pre=2, post=2, two_grid=False):
    n = len(u) - 1
    if n <= 2:
        u[1] = 0.5 * (u[0] + u[2] + h * h * f[1]); return u
    u = smooth(u, f, h, pre)
    rc = restrict(f - apply_A(u, h))
    if two_grid:                                       # solve the coarse problem exactly
        m = len(rc) - 2; H = 2 * h
        Ac = (2 * np.eye(m) - np.eye(m, k=1) - np.eye(m, k=-1)) / H**2
        ec = np.zeros(len(rc)); ec[1:-1] = np.linalg.solve(Ac, rc[1:-1])
    else:                                              # or recurse: a full multigrid V-cycle
        ec = v_cycle(np.zeros(len(rc)), rc, 2 * h)
    u = u + prolong(ec)
    return smooth(u, f, h, post)


def reduction_factor(n, cycles=8, two_grid=False):
    h = 1.0 / n
    rng = np.random.default_rng(0)
    f = rng.standard_normal(n + 1); f[0] = f[-1] = 0           # rough right-hand side: every frequency present
    u = np.zeros(n + 1); r = [np.linalg.norm(f - apply_A(u, h))]
    for _ in range(cycles):
        u = v_cycle(u, f, h, two_grid=two_grid); r.append(np.linalg.norm((f - apply_A(u, h))[1:-1]))
    return (r[-1] / r[2]) ** (1 / (cycles - 2)), r


if __name__ == "__main__":
    # why smoothing alone fails: weighted Jacobi damps mode k by |1 - 2w sin^2(k pi h / 2)|
    n = 64; h = 1 / n; w = 2 / 3
    g = lambda k: abs(1 - 2 * w * math.sin(k * math.pi * h / 2) ** 2)
    print(f"weighted Jacobi damping per sweep, n = {n}: smoothest mode {g(1):.4f}, high modes (k >= n/2) at most {max(g(k) for k in range(n // 2, n)):.4f}")
    assert max(g(k) for k in range(n // 2, n)) <= 1 / 3 + 1e-12
    print("   n   two-grid factor   V-cycle factor")
    facs = []
    for n in (32, 64, 128, 256, 512, 1024):
        tg, _ = reduction_factor(n, two_grid=True); vc, _ = reduction_factor(n)
        facs.append(vc)
        print(f"{n:5d} {tg:16.4f} {vc:16.4f}")
    assert max(facs) < 0.15 and max(facs) - min(facs) < 0.03      # independent of n
```

:::exercise Cost of a V-cycle in 2D
In 2D each coarser grid has a quarter of the points. If one smoothing sweep on the finest grid costs 1 unit and the V-cycle does 4 sweeps per level, what does a V-cycle cost?
---solution---
1. Levels cost $4(1 + \tfrac14 + \tfrac1{16} + \dots) = 4\cdot\frac{1}{1 - 1/4} = 5.33$ units.
2. That's only a third more than the 4 sweeps on the finest grid alone.
3. With a reduction factor near 0.1 per cycle, reaching $10^{-8}$ takes about 8 cycles, about 43 sweep-equivalents, at any grid size.
:::
