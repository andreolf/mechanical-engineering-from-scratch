Every numerical method trades effort for accuracy. The question an engineer asks is not "is it accurate?" but "how fast does the error fall when I pay more?" That rate, the **order of convergence**, is the single most useful number for comparing methods, choosing step sizes and catching bugs. A solver that should be second order but measures as first order has a mistake in it, every time.

## Two kinds of convergence

**Iterative methods** (root finders, linear solvers) produce a sequence $x_0, x_1, \dots$ with error $e_n = |x_n - x^*|$. The method has order $p$ if

$$
e_{n+1} \approx C\,e_n^{\,p}.
$$

$p = 1$ is linear (each step multiplies the error by $C < 1$), $p = 2$ is quadratic (the number of correct digits roughly doubles per step).

**Discretisation methods** (finite differences, quadrature, ODE solvers) have a step $h$ and error

$$
E(h) \approx K\,h^{p}.
$$

Halving $h$ divides the error by $2^p$: by 4 for a second-order method, by 16 for a fourth-order one.

## Measuring the order from data

Take logs and the power law becomes a straight line. For an iteration, three consecutive errors give

$$
p \approx \frac{\ln(e_{n+1}/e_n)}{\ln(e_n/e_{n-1})}.
$$

For a discretisation, two step sizes give $p \approx \ln(E_1/E_2)/\ln(h_1/h_2)$; with more points, fit a line to $\log E$ against $\log h$. When the exact answer is unknown, compare three solutions at $h$, $h/2$, $h/4$: $p \approx \log_2\big((u_h - u_{h/2})/(u_{h/2} - u_{h/4})\big)$.

## Truncation versus round-off

Shrinking $h$ reduces the truncation error $Kh^p$, but every function value carries a relative rounding error near $\varepsilon \approx 2.2\times10^{-16}$, and a difference formula divides it by $h$. The total error behaves like

$$
E(h) \approx K h^{p} + \frac{\varepsilon |f|}{h},
$$

so there is a best step. For the forward difference ($p = 1$) it's near $\sqrt{\varepsilon} \approx 10^{-8}$; for the central difference ($p = 2$) near $\varepsilon^{1/3} \approx 6\times10^{-6}$. Below that, the error grows again.

:::example Newton's order, measured
Solve Wallis's cubic $x^3 - 2x - 5 = 0$ (root $x^* = 2.0945515$) with Newton's method from $x_0 = 3$.

1. Errors: $0.91,\ 0.27,\ 3.3\times10^{-2},\ 5.8\times10^{-4},\ 1.9\times10^{-7},\ 2.1\times10^{-14}$.
2. Last triple: $p \approx \ln(2.1\times10^{-14}/1.9\times10^{-7}) / \ln(1.9\times10^{-7}/5.8\times10^{-4}) = 2.00$.
3. Theory predicts $C = |f''(x^*)/(2f'(x^*))| = 6x^*/(2(3x^{*2} - 2)) = 0.563$. Check: $2.1\times10^{-14}/(1.9\times10^{-7})^2 \approx 0.58$.
4. The secant method on the same equation measures $p \approx 1.61$, close to the golden ratio $1.618$ that theory predicts.
:::

```python file=error_order.py
"""Measure convergence order from successive errors: Newton (p = 2) and secant (p = 1.618) on x^3 - 2x - 5."""
import math
import numpy as np

f = lambda x: x**3 - 2 * x - 5
df = lambda x: 3 * x**2 - 2
ROOT = 2.0945514815423265          # Wallis's classic cubic


def newton(x, n):
    xs = [x]
    for _ in range(n):
        x = x - f(x) / df(x); xs.append(x)
    return xs


def secant(x0, x1, n):
    xs = [x0, x1]
    for _ in range(n):
        if f(x1) == f(x0):
            break                                   # converged to machine precision
        x0, x1 = x1, x1 - f(x1) * (x1 - x0) / (f(x1) - f(x0)); xs.append(x1)
    return xs


def orders(errs):
    """p_n = log(e_{n+1}/e_n) / log(e_n/e_{n-1}) for each consecutive triple."""
    return [math.log(errs[i + 1] / errs[i]) / math.log(errs[i] / errs[i - 1]) for i in range(1, len(errs) - 1)]


def fit_order(h, e):
    """Slope of log e against log h: the order of a discretisation method."""
    return np.polyfit(np.log(h), np.log(e), 1)[0]


if __name__ == "__main__":
    en = [abs(x - ROOT) for x in newton(3.0, 6)]
    en = [e for e in en if e > 1e-15]
    es = [abs(x - ROOT) for x in secant(3.0, 2.8, 9)]
    es = [e for e in es if e > 1e-15]
    pn, ps = orders(en), orders(es)
    print("Newton errors:", " ".join(f"{e:.1e}" for e in en))
    print("Newton orders:", " ".join(f"{p:.3f}" for p in pn))
    print("secant orders:", " ".join(f"{p:.3f}" for p in ps))
    assert abs(pn[-1] - 2) < 0.05
    assert abs(ps[-1] - (1 + math.sqrt(5)) / 2) < 0.08
    # discretisation order: central difference of sin at x = 1
    h = np.array([0.1, 0.05, 0.025, 0.0125])
    e = np.abs((np.sin(1 + h) - np.sin(1 - h)) / (2 * h) - math.cos(1))
    p = fit_order(h, e)
    print(f"central difference observed order {p:.4f}")
    assert abs(p - 2) < 0.01
```

:::exercise Read the order off a table
A solver for a beam deflection returns $u = 4.2860$ mm at $h = 0.1$ m, $4.2884$ mm at $h = 0.05$ m and $4.2890$ mm at $h = 0.025$ m. What order does it show, and what is the extrapolated answer?
---solution---
1. Differences: $4.2884 - 4.2860 = 0.0024$ and $4.2890 - 4.2884 = 0.0006$.
2. Ratio $0.0024/0.0006 = 4$, so $p = \log_2 4 = 2$: second order.
3. Richardson extrapolation: $u \approx u_{h/4} + (u_{h/4} - u_{h/2})/(2^p - 1) = 4.2890 + 0.0006/3 = 4.2892$ mm.
:::
