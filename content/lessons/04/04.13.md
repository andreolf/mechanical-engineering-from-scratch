So far you've integrated in time. Many engineering problems are boundary-value problems in space instead: the temperature along a heated rod, the deflection of a cable, the pressure along a pipe. Finite differences replace derivatives by differences on a grid and turn the differential equation into a linear system. It is the simplest discretisation there is, and everything about it (stencils, matrices, boundary conditions, convergence) carries over to the 2D and 3D solvers that follow.

## Stencils from Taylor series

Expand $u(x \pm h)$:

$$
u(x \pm h) = u \pm hu' + \tfrac{h^2}{2}u'' \pm \tfrac{h^3}{6}u''' + \tfrac{h^4}{24}u'''' + \dots
$$

Add the two and the odd terms cancel:

$$
u''(x) = \frac{u(x - h) - 2u(x) + u(x + h)}{h^2} - \frac{h^2}{12}u''''(\xi).
$$

Second order. The stencil is exact whenever $u'''' = 0$, so for any cubic.

## From equation to matrix

For $-u'' = f$ on $[0, L]$ with $u(0) = u_a$ and $u(L) = u_b$, put $n$ cells of width $h = L/n$ and write the stencil at each interior node $i = 1, \dots, n - 1$:

$$
\frac{1}{h^2}\begin{pmatrix} 2 & -1 & & \\ -1 & 2 & -1 & \\ & \ddots & \ddots & \ddots \\ & & -1 & 2 \end{pmatrix}\begin{pmatrix}u_1\\u_2\\\vdots\\u_{n-1}\end{pmatrix} = \begin{pmatrix} f_1 + u_a/h^2\\ f_2\\ \vdots\\ f_{n-1} + u_b/h^2 \end{pmatrix}.
$$

Known boundary values move to the right-hand side. The matrix is tridiagonal, symmetric and positive definite, with eigenvalues $\frac{4}{h^2}\sin^2\frac{k\pi h}{2L}$. The smallest approximates $(\pi/L)^2$, the continuous eigenvalue; the largest is about $4/h^2$. Their ratio, the condition number, grows like $1/h^2$, which matters for iterative solvers (lesson 04.17).

A prescribed flux $u'(0) = g$ (a Neumann condition, Phase 03) needs a ghost node $u_{-1} = u_1 - 2hg$ to stay second order.

:::example A rod heated by an electric current
A 100 mm steel rod ($k = 50$ W/(m K)) generates $q = 1$ MW/m³ and both ends are held at 20 °C. Steady conduction: $-kT'' = q$.

1. Exact solution: $T = 20 + \frac{q}{2k}x(L - x)$, with centre value $20 + \frac{qL^2}{8k} = 20 + \frac{10^6\cdot0.01}{400} = 45$ °C.
2. Finite differences with only 10 cells give 45.0000 °C at the centre, exact to rounding at every node, because the solution is quadratic and the stencil is exact for polynomials up to degree 3.
3. For a solution that isn't a polynomial, $-u'' = \pi^2\sin\pi x$: max errors $8.27\times10^{-3}$, $2.06\times10^{-3}$, $5.14\times10^{-4}$, $1.29\times10^{-4}$ for 10, 20, 40, 80 cells. Observed orders 2.005, 2.001, 2.000.
:::

```python file=fd_1d.py
"""Finite differences for -u'' = f on [0, L]: the second-difference matrix, a heated rod, and O(h^2) convergence."""
import math
import numpy as np


def second_difference(n, h):
    """(n-1)x(n-1) matrix for -u'' at the interior nodes, Dirichlet ends: tridiag(-1, 2, -1) / h^2."""
    return (2 * np.eye(n - 1) - np.eye(n - 1, k=1) - np.eye(n - 1, k=-1)) / h**2


def solve_poisson(f, L, n, ua, ub):
    x = np.linspace(0, L, n + 1); h = L / n
    A = second_difference(n, h)
    b = f(x[1:-1]).astype(float)
    b[0] += ua / h**2; b[-1] += ub / h**2         # known boundary values move to the right-hand side
    u = np.empty(n + 1); u[0], u[-1] = ua, ub
    u[1:-1] = np.linalg.solve(A, b)
    return x, u


if __name__ == "__main__":
    # a 100 mm steel rod carrying current: q = 1 MW/m^3 generated, k = 50 W/(m K), both ends held at 20 C
    q, k, L = 1e6, 50.0, 0.1
    x, T = solve_poisson(lambda x: np.full_like(x, q / k), L, 10, 20.0, 20.0)
    T_exact = 20 + q / (2 * k) * x * (L - x)
    print(f"heated rod, 10 cells: centre {T[5]:.4f} C (exact {20 + q * L**2 / (8 * k):.4f} C)")
    assert np.max(np.abs(T - T_exact)) < 1e-10      # exact: the solution is quadratic, so the stencil has no error
    # convergence on u = sin(pi x): -u'' = pi^2 sin(pi x)
    errs = []
    for n in (10, 20, 40, 80):
        x, u = solve_poisson(lambda x: math.pi**2 * np.sin(math.pi * x), 1.0, n, 0.0, 0.0)
        errs.append(np.max(np.abs(u - np.sin(math.pi * x))))
    orders = [math.log2(a / b) for a, b in zip(errs, errs[1:])]
    print("max errors:", " ".join(f"{e:.2e}" for e in errs), " orders:", " ".join(f"{p:.3f}" for p in orders))
    assert all(abs(p - 2) < 0.02 for p in orders)
    # the matrix is symmetric positive definite with known eigenvalues (4/h^2) sin^2(k pi h / 2)
    n, h = 10, 0.1
    lam = np.sort(np.linalg.eigvalsh(second_difference(n, h)))
    assert np.allclose(lam, np.sort(4 / h**2 * np.sin(np.arange(1, n) * math.pi * h / 2) ** 2))
    print(f"smallest eigenvalue {lam[0]:.4f} vs pi^2 = {math.pi**2:.4f}")
```

:::exercise Three interior nodes by hand
Solve $-u'' = 1$ on $[0, 1]$, $u(0) = u(1) = 0$, with $h = 0.25$. Compare with the exact $u = x(1 - x)/2$.
---solution---
1. With $h^2 = 1/16$: $2u_1 - u_2 = 1/16$, $-u_1 + 2u_2 - u_3 = 1/16$, $-u_2 + 2u_3 = 1/16$.
2. By symmetry $u_1 = u_3$. Then $2u_1 - u_2 = 1/16$ and $-2u_1 + 2u_2 = 1/16$. Adding: $u_2 = 2/16 = 0.125$, and $u_1 = (1/16 + 0.125)/2 = 0.09375$.
3. Exact: $u(0.25) = 0.25\cdot0.75/2 = 0.09375$ and $u(0.5) = 0.125$. Exact again, because the solution is quadratic.
:::
