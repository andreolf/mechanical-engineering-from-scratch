A rubber bushing, a contact spring, a fast chemical reaction or a stiff structural mode settles in milliseconds, while the motion you care about lasts seconds. Explicit methods must resolve the fastest mode forever, even after it has died away. **Implicit** methods evaluate the slope at the end of the step instead of the start. Each step needs an equation solve, but the step can be as large as accuracy allows, often thousands of times larger.

## Backward Euler

$$
y_{n+1} = y_n + h\,f(t_{n+1}, y_{n+1}).
$$

The unknown appears on both sides. On the test equation $y' = \lambda y$:

$$
y_{n+1} = \frac{y_n}{1 - h\lambda}, \qquad R(z) = \frac{1}{1 - z}.
$$

$|R(z)| \le 1$ for **every** $z$ with $\mathrm{Re}\,z \le 0$: the method is **A-stable**. For $y' = -ky$ at $h = 100/k$ the amplification is $1/101$, a perfectly tame decay, where explicit Euler's factor would be $-99$. As $z \to -\infty$, $R \to 0$: fast modes are damped out at once. That property, L-stability, is exactly what you want for stiff transients.

## Newton inside every step

For a nonlinear $f$, each step solves $\mathbf G(\mathbf z) = \mathbf z - \mathbf y_n - h\mathbf f(\mathbf z) = \mathbf 0$ with Newton's method (lesson 04.03):

$$
\left(I - hJ\right)\Delta\mathbf z = -\mathbf G(\mathbf z), \qquad J = \frac{\partial\mathbf f}{\partial\mathbf y}.
$$

Start from $\mathbf z = \mathbf y_n$; a few iterations suffice because the guess is close. Production codes reuse one factorisation of $I - hJ$ for several steps.

## Stable is not accurate

Backward Euler is only first order. Large steps give a stable, smooth answer that may miss the fast transient entirely, which is fine if you only care about the slow motion. For accuracy, use higher-order implicit methods: BDF formulas (SciPy `BDF`) or implicit Runge-Kutta (`Radau`). The trapezoidal rule (Crank-Nicolson, lesson 04.14) is second order and A-stable but not L-stable, so very fast modes ring instead of dying.

:::example A stiff bushing
$m\ddot x + c\dot x + kx\left(1 + (x/d)^2\right) = F$ with $m = 0.01$ kg, $c = 20$ N s/m, $k = 10^4$ N/m, $d = 1$ mm, $F = 10$ N, starting at rest.

1. Linearised at rest: $\lambda^2 + 2000\lambda + 10^6 = 0$, so $\lambda = -1000$ s⁻¹ twice (critically damped). Explicit Euler needs $h < 2/1000 = 2$ ms.
2. Static deflection: with $s = x/d$, $s + s^3 = 1$ gives $s = 0.6823$, so $x = 0.6823$ mm.
3. Backward Euler with $h = 0.1$ s ($h|\lambda| = 100$): after 2 s, $x = 0.6823$ mm, with 1 to 6 Newton iterations per step.
4. Explicit Euler with the same step: $|x| = 2\times10^3$ m after 3 steps.
5. Accuracy of the transient at $t = 2$ ms: error 14.70 µm at $h = 100$ µs and 7.47 µm at $h = 50$ µs. Halving $h$ halves the error: first order.
:::

```python file=stiff_implicit.py
"""Implicit (backward) Euler with Newton iterations: stable at steps 100 times beyond the explicit limit."""
import numpy as np

M, C, K, D, F = 0.01, 20.0, 1e4, 1e-3, 10.0     # kg, N s/m, N/m, m, N: a small mass on a stiffening rubber bushing


def f(y):
    x, v = y
    return np.array([v, (F - C * v - K * x * (1 + (x / D) ** 2)) / M])


def jac(y):
    x, v = y
    return np.array([[0.0, 1.0], [-K * (1 + 3 * (x / D) ** 2) / M, -C / M]])


def implicit_euler(y0, h, n, tol=1e-12):
    """Solve y_{n+1} - y_n - h f(y_{n+1}) = 0 for y_{n+1} by Newton at every step."""
    y = np.array(y0, float); out = [y.copy()]; newton_its = []
    for _ in range(n):
        z = y.copy()
        for it in range(1, 30):
            G = z - y - h * f(z)
            dz = np.linalg.solve(np.eye(2) - h * jac(z), -G)
            z += dz
            if np.linalg.norm(dz) < tol * (1 + np.linalg.norm(z)):
                break
        newton_its.append(it); y = z; out.append(y.copy())
    return np.array(out), newton_its


def explicit_euler(y0, h, n):
    y = np.array(y0, float); out = [y.copy()]
    for _ in range(n):
        y = y + h * f(y); out.append(y.copy())
        if not np.all(np.isfinite(y)) or abs(y[0]) > 1e3:
            break
    return np.array(out)


if __name__ == "__main__":
    lam = np.linalg.eigvals(jac([0.0, 0.0]))
    print(f"eigenvalues at rest: {lam.real.round(1)} 1/s (critically damped); explicit Euler needs h < {2 / 1000:.3f} s")
    # scalar check: amplification 1/(1 + h k) for y' = -k y, even at h = 100/k
    k = 1000.0; h = 100 / k
    assert abs(1 / (1 + h * k) - 1 / 101) < 1e-15
    # the bushing under a 10 N step: static deflection solves s + s^3 = 1 with s = x / D
    s = np.roots([1, 0, 1, -1]); s = s[np.isreal(s)].real[0]
    print(f"static deflection {s * D * 1e3:.4f} mm")
    y_imp, its = implicit_euler([0, 0], 0.1, 20)
    y_exp = explicit_euler([0, 0], 0.1, 20)
    print(f"implicit Euler, h = 0.1 s (h|lambda| = 100): x = {y_imp[-1, 0] * 1e3:.4f} mm after 2 s, Newton iterations per step {min(its)}-{max(its)}")
    print(f"explicit Euler, same step: |x| = {abs(y_exp[-1, 0]):.1e} m after {len(y_exp) - 1} steps (blown up)")
    assert abs(y_imp[-1, 0] - s * D) < 1e-9 and abs(y_exp[-1, 0]) > 1
    # accuracy needs small steps only while things change fast: compare the transient at t = 2 ms
    ref, _ = implicit_euler([0, 0], 1e-6, 2000)
    errs = []
    for hh in (1e-4, 5e-5):
        yy, _ = implicit_euler([0, 0], hh, int(round(2e-3 / hh)))
        errs.append(abs(yy[-1, 0] - ref[-1, 0]))
        print(f"h = {hh:.0e} s: x(2 ms) error {errs[-1] * 1e6:.2f} um")
    assert 1.8 < errs[0] / errs[1] < 2.2          # first order: stable is not the same as accurate
```

:::exercise Two steps by hand
Apply backward Euler to $y' = -1000y$, $y(0) = 1$, with $h = 0.01$. Give $y_1$, $y_2$ and compare with what explicit Euler does.
---solution---
1. $R = 1/(1 + 1000\cdot0.01) = 1/11$.
2. $y_1 = 0.0909$, $y_2 = 0.00826$. The exact values ($e^{-10} = 4.5\times10^{-5}$ and $e^{-20}$) are smaller still, but the numerical solution decays monotonically: qualitatively right.
3. Explicit Euler: factor $1 - 10 = -9$, so $y_1 = -9$, $y_2 = 81$. Exploding.
:::
