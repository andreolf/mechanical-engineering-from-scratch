A slug of dye released into a river, heat carried by coolant through a pipe, smoke in a ventilation duct: quantities that are **carried** by a flow obey the advection equation. It looks like the simplest PDE there is, yet it breaks naive schemes in instructive ways. The fix, upwinding (taking information from the direction the flow comes from), is the foundation of every CFD code in Phase 17.

## The advection equation

For a concentration $q(x, t)$ carried at speed $U > 0$:

$$
q_t + Uq_x = 0, \qquad q(x, t) = q_0(x - Ut).
$$

The profile slides downstream unchanged. A good scheme should move it at the right speed, keep it positive and not invent new peaks.

## Three schemes

With $c = U\Delta t/\Delta x$:

- **Central (FTCS):** $q_i^{n+1} = q_i^n - \tfrac c2(q_{i+1}^n - q_{i-1}^n)$. Von Neumann gives $|G|^2 = 1 + c^2\sin^2\theta > 1$: unstable for every $c$. Don't use it.
- **Upwind:** $q_i^{n+1} = q_i^n - c(q_i^n - q_{i-1}^n)$, using the upstream neighbour. Stable for $c \le 1$, and each new value is a convex combination $(1 - c)q_i + cq_{i-1}$ of old ones, so it is **monotone**: no new maxima, no negative concentrations.
- **Lax-Wendroff:** adds the term $\tfrac{c^2}{2}(q_{i+1} - 2q_i + q_{i-1})$ to the central scheme, making it stable and second order, but not monotone.

## The modified equation

Expand the upwind scheme in Taylor series and ask which PDE it actually solves to the next order:

$$
q_t + Uq_x = D_{\text{num}}\,q_{xx}, \qquad D_{\text{num}} = \frac{U\Delta x}{2}(1 - c).
$$

Upwind solves advection plus a **numerical diffusion**. It smears sharp fronts, more so on coarse grids and at small CFL numbers, and it's exact at $c = 1$. Godunov's theorem says no linear scheme can be both monotone and better than first order; modern codes beat it with nonlinear flux limiters that switch between upwind near fronts and second order elsewhere.

:::example Dye in a river
River speed $U = 0.5$ m/s, a 100 m slug at concentration 1 centred at $x = 300$ m, cells of $\Delta x = 5$ m, CFL $c = 0.8$, run for 2000 s (the slug travels 1000 m).

| scheme | max | min | total mass |
|---|---|---|---|
| upwind | 0.886 | 0 | 100.00 |
| Lax-Wendroff | 1.194 | $-0.192$ | 100.00 |
| central | $2.6\times10^{25}$ | $-2.6\times10^{25}$ | blown up |

Upwind's centre of mass is at exactly 1300 m. The modified equation predicts $D_{\text{num}} = 0.5\cdot5\cdot0.2/2 = 0.25$ m²/s, so the pulse variance should grow from $100^2/12 = 833$ m² to $833 + 2D_{\text{num}}t = 1833$ m². Measured: 1831 m².
:::

```python file=advection.py
"""A pollutant pulse carried down a river: first-order upwind (monotone, diffusive) versus central differencing (oscillates)."""
import numpy as np

U, LEN = 0.5, 2000.0          # river speed m/s, reach length m


def pulse(x, x0=300.0, w=100.0):
    return np.where(np.abs(x - x0) <= w / 2, 1.0, 0.0)     # a 100 m slug of dye, concentration 1


def run(scheme, n, cfl, t_end):
    dx = LEN / n; dt = cfl * dx / U; steps = round(t_end / dt); c = U * dt / dx
    x = (np.arange(n) + 0.5) * dx
    q = pulse(x)
    for _ in range(steps):
        if scheme == "upwind":
            q = q - c * (q - np.roll(q, 1))
        elif scheme == "central":      # forward Euler in time with a centred difference: unconditionally unstable
            q = q - 0.5 * c * (np.roll(q, -1) - np.roll(q, 1))
        elif scheme == "lax-wendroff":
            q = q - 0.5 * c * (np.roll(q, -1) - np.roll(q, 1)) + 0.5 * c * c * (np.roll(q, -1) - 2 * q + np.roll(q, 1))
    return x, q, steps * dt


if __name__ == "__main__":
    n, cfl, t_end = 400, 0.8, 2000.0            # 5 m cells; the pulse travels 1000 m
    for s in ("upwind", "lax-wendroff", "central"):
        x, q, t = run(s, n, cfl, t_end)
        print(f"{s:13s}: max {q.max():.4g}, min {q.min():.4g}" + (f", total mass {q.sum() * LEN / n:.2f} (initial 100.00)" if abs(q).max() < 10 else ": blown up"))
    x, q, _ = run("upwind", n, cfl, t_end)
    assert q.min() >= -1e-12 and q.max() <= 1 + 1e-12        # monotone: no new extrema
    assert abs(q.sum() * LEN / n - 100) < 1e-6                 # conservative
    centre = (q * x).sum() / q.sum()
    print(f"upwind pulse centre at {centre:.1f} m (exact 1300.0 m)")
    assert abs(centre - 1300) < 1e-6
    # modified equation: upwind behaves like advection plus diffusion with D_num = U dx (1 - c) / 2
    dx = LEN / n; Dnum = U * dx * (1 - cfl) / 2
    var = (q * (x - centre) ** 2).sum() / q.sum()
    var_pred = 100.0**2 / 12 + 2 * Dnum * t_end
    print(f"numerical diffusivity {Dnum:.3f} m^2/s: pulse variance {var:.0f} m^2, predicted {var_pred:.0f} m^2")
    assert abs(var / var_pred - 1) < 0.02
    x, qc, _ = run("central", n, cfl, 400.0)
    assert qc.min() < -0.05                                     # central oscillates (and soon blows up)
    x, ql, _ = run("lax-wendroff", n, cfl, t_end)
    assert ql.min() < -0.01 and ql.max() > 1.0                  # second order but not monotone: over- and undershoots
```

:::exercise Is the smearing physical?
The river's real turbulent dispersion coefficient is about 5 m²/s. With $\Delta x = 20$ m and $c = 0.5$, how does upwind's numerical diffusion compare?
---solution---
1. $D_{\text{num}} = \frac{U\Delta x}{2}(1 - c) = \frac{0.5\cdot20}{2}\cdot0.5 = 2.5$ m²/s.
2. That's half the physical value: the model would overstate the spreading by 50%. The numerical error is the same size as the physics.
3. Fixes: refine to $\Delta x = 2$ m ($D_{\text{num}} = 0.25$ m²/s, 5% of physical), run closer to $c = 1$, or use a second-order limited scheme.
:::
