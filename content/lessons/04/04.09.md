Euler's method looks at the slope once per step and walks in a straight line. Runge-Kutta methods sample the slope several times inside the step and combine the samples so that the errors cancel up to a high power of $h$. Classical RK4 needs four slope evaluations per step and is fourth order: halve the step and the error drops 16 times. It's been the workhorse for well-behaved ODEs for over a century.

## Deriving RK2 by matching Taylor series

Propose a two-stage method for $y' = f(t, y)$:

$$
k_1 = f(t_n, y_n), \quad k_2 = f(t_n + c_2h,\ y_n + a_{21}hk_1), \quad y_{n+1} = y_n + h(b_1k_1 + b_2k_2).
$$

Expand $k_2$ to first order: $k_2 \approx f + c_2hf_t + a_{21}hff_y$. The exact solution has $y(t + h) = y + hf + \tfrac{h^2}{2}(f_t + ff_y) + O(h^3)$. Matching terms:

$$
b_1 + b_2 = 1, \qquad b_2c_2 = \tfrac12, \qquad b_2a_{21} = \tfrac12 .
$$

One free parameter. $b_2 = \tfrac12$ gives **Heun's method** ($c_2 = 1$); $b_2 = 1$ gives the **midpoint method** ($c_2 = \tfrac12$). Both have local error $O(h^3)$ and global error $O(h^2)$.

## Butcher tableaus

Any explicit RK method is a table of coefficients: $c_i$ (stage times), $a_{ij}$ (how stages combine) and $b_i$ (final weights). Classical RK4:

$$
\begin{array}{c|cccc}
0 & & & & \\
\tfrac12 & \tfrac12 & & & \\
\tfrac12 & 0 & \tfrac12 & & \\
1 & 0 & 0 & 1 & \\ \hline
 & \tfrac16 & \tfrac13 & \tfrac13 & \tfrac16
\end{array}
$$

One engine that reads a tableau can run every method, which is how libraries are written. The code below does exactly that.

## Is more stages always better?

Cost is counted in function evaluations. To reach error $10^{-6}$ on a smooth problem, RK4 typically needs far fewer evaluations than Euler: in the example below, RK4 with 200 evaluations beats Euler with 20 000 by more than two orders of magnitude. For non-smooth problems (impacts, friction switching) the high order is wasted at the discontinuities, which is one reason adaptive methods (next lesson) exist.

```python file=runge_kutta.py
"""A Butcher-tableau Runge-Kutta engine: Euler, Heun (RK2) and classical RK4, with measured orders on a pendulum."""
import math
import numpy as np

TABLEAUS = {
    "Euler": ([[0]], [1], [0]),
    "Heun": ([[0, 0], [1, 0]], [0.5, 0.5], [0, 1]),
    "midpoint": ([[0, 0], [0.5, 0]], [0, 1], [0, 0.5]),
    "RK4": ([[0, 0, 0, 0], [0.5, 0, 0, 0], [0, 0.5, 0, 0], [0, 0, 1, 0]], [1 / 6, 1 / 3, 1 / 3, 1 / 6], [0, 0.5, 0.5, 1]),
}


def rk_step(f, t, y, h, tableau):
    A, b, c = (np.array(m, float) for m in tableau)
    k = []
    for i in range(len(b)):
        yi = y + h * sum(A[i, j] * k[j] for j in range(i)) if i else y
        k.append(f(t + c[i] * h, yi))
    return y + h * sum(bi * ki for bi, ki in zip(b, k))


def solve(f, y0, t_end, n, tableau):
    h = t_end / n; y = np.array(y0, float)
    for i in range(n):
        y = rk_step(f, i * h, y, h, tableau)
    return y


def pendulum(t, y, g=9.81, L=1.0):
    return np.array([y[1], -g / L * math.sin(y[0])])


if __name__ == "__main__":
    y0 = [math.radians(60), 0.0]; T = 2.0
    ref = solve(pendulum, y0, T, 20000, TABLEAUS["RK4"])      # converged reference
    print(f"reference angle after {T} s: {math.degrees(ref[0]):.6f} deg")
    print(" method     n=50 error    n=100 error   observed order")
    orders = {}
    for name in ("Euler", "Heun", "midpoint", "RK4"):
        e = [abs(solve(pendulum, y0, T, n, TABLEAUS[name])[0] - ref[0]) for n in (50, 100, 200)]
        orders[name] = math.log2(e[1] / e[2])
        print(f" {name:9s} {e[0]:12.3e} {e[1]:13.3e} {orders[name]:12.2f}")
    assert abs(orders["Euler"] - 1) < 0.15 and abs(orders["Heun"] - 2) < 0.1 and abs(orders["RK4"] - 4) < 0.1
    # cost: RK4 with 50 steps (200 evaluations) beats Euler with 20000 steps
    e_rk4 = abs(solve(pendulum, y0, T, 50, TABLEAUS["RK4"])[0] - ref[0])
    e_eul = abs(solve(pendulum, y0, T, 20000, TABLEAUS["Euler"])[0] - ref[0])
    print(f"RK4, 200 evaluations: {e_rk4:.1e} rad; Euler, 20000 evaluations: {e_eul:.1e} rad")
    assert e_rk4 < e_eul
```

:::exercise Ralston's method
Choose $b_2 = \tfrac34$ in the RK2 family. Find $b_1$, $c_2$ and $a_{21}$, and write the method.
---solution---
1. $b_1 = 1 - b_2 = \tfrac14$.
2. $c_2 = a_{21} = \frac{1}{2b_2} = \tfrac23$.
3. $k_1 = f(t_n, y_n)$, $k_2 = f(t_n + \tfrac23h,\ y_n + \tfrac23hk_1)$, $y_{n+1} = y_n + \tfrac h4(k_1 + 3k_2)$. This is Ralston's method, the RK2 choice with the smallest error constant.
:::
