A draughtsman bending a thin wooden strip through pins on a drawing board was solving a variational problem: the strip settles into the shape with the least bending energy. That shape, piecewise cubic with continuous slope and curvature, is the **cubic spline**. It's how CAD tools draw smooth curves, how cam profiles are designed and how you interpolate measured data without Runge's wiggles.

## Conditions on each piece

Between knots $x_i$ and $x_{i+1}$ (spacing $h_i$) the spline is a cubic $S_i(x)$. With $n$ intervals there are $4n$ coefficients. Conditions:

- $S_i(x_i) = y_i$ and $S_i(x_{i+1}) = y_{i+1}$: $2n$ conditions.
- slope continuous at the $n - 1$ interior knots.
- second derivative (curvature) continuous at the interior knots.

That is $4n - 2$. The last two come from the ends: a **natural** spline sets $S'' = 0$ at both ends (a free strip), a **clamped** spline prescribes the end slopes.

## Solve for the curvatures

Use the knot second derivatives $M_i = S''(x_i)$ as unknowns. Within an interval $S''$ is linear, so integrating twice and imposing the values gives, with $A = (x_{i+1} - x)/h_i$ and $B = 1 - A$,

$$
S(x) = A y_i + B y_{i+1} + \frac{h_i^2}{6}\left[(A^3 - A)M_i + (B^3 - B)M_{i+1}\right].
$$

Slope continuity at each interior knot then becomes one equation linking three neighbours:

$$
h_{i-1}M_{i-1} + 2(h_{i-1} + h_i)M_i + h_i M_{i+1} = 6\left(\frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}}\right).
$$

The matrix is **tridiagonal** and diagonally dominant, so the Thomas algorithm (Gaussian elimination without fill-in) solves it in $O(n)$ operations. A million-knot spline costs milliseconds.

:::example A four-knot natural spline by hand
Knots $(0, 0)$, $(1, 1)$, $(2, 0)$, $(3, 1)$, all $h = 1$, natural ends $M_0 = M_3 = 0$.

1. Knot 1: $M_0 + 4M_1 + M_2 = 6(y_0 - 2y_1 + y_2) = -12$.
2. Knot 2: $M_1 + 4M_2 + M_3 = 6(y_1 - 2y_2 + y_3) = 12$.
3. Solve $4M_1 + M_2 = -12$, $M_1 + 4M_2 = 12$: $M_1 = -4$, $M_2 = 4$.
4. At $x = 0.5$ ($A = B = 0.5$): $S = 0.5\cdot0 + 0.5\cdot1 + \tfrac16(-0.375\cdot0 - 0.375\cdot(-4)) = 0.5 + 0.25 = 0.75$.
:::

```python file=splines.py
"""Natural cubic spline from scratch: second-derivative unknowns, Thomas tridiagonal solve, C2 check."""
import numpy as np


def thomas(a, b, c, d):
    """Solve a tridiagonal system: a sub-, b main, c super-diagonal (a[0] and c[-1] unused)."""
    n = len(b); cp = np.zeros(n); dp = np.zeros(n)
    cp[0], dp[0] = c[0] / b[0], d[0] / b[0]
    for i in range(1, n):
        m = b[i] - a[i] * cp[i - 1]
        cp[i] = c[i] / m if i < n - 1 else 0.0
        dp[i] = (d[i] - a[i] * dp[i - 1]) / m
    x = np.zeros(n); x[-1] = dp[-1]
    for i in range(n - 2, -1, -1):
        x[i] = dp[i] - cp[i] * x[i + 1]
    return x


def natural_spline(x, y):
    """Return the knot second derivatives M (M_0 = M_n = 0)."""
    h = np.diff(x); n = len(x) - 1
    a = np.r_[0, h[1:-1]]; b = 2 * (h[:-1] + h[1:]); c = np.r_[h[1:-1], 0]
    d = 6 * ((y[2:] - y[1:-1]) / h[1:] - (y[1:-1] - y[:-2]) / h[:-1])
    M = np.zeros(n + 1); M[1:-1] = thomas(a, b, c, d)
    return M


def evaluate(x, y, M, t, der=0):
    i = np.clip(np.searchsorted(x, t) - 1, 0, len(x) - 2)
    h = x[i + 1] - x[i]; A = (x[i + 1] - t) / h; B = (t - x[i]) / h
    if der == 0:
        return A * y[i] + B * y[i + 1] + ((A**3 - A) * M[i] + (B**3 - B) * M[i + 1]) * h * h / 6
    if der == 1:
        return (y[i + 1] - y[i]) / h + ((1 - 3 * A**2) * M[i] + (3 * B**2 - 1) * M[i + 1]) * h / 6
    return A * M[i] + B * M[i + 1]


if __name__ == "__main__":
    # hand example: knots (0,0), (1,1), (2,0), (3,1)
    x = np.array([0.0, 1, 2, 3]); y = np.array([0.0, 1, 0, 1])
    M = natural_spline(x, y)
    print("knot second derivatives:", M, " S(0.5) =", evaluate(x, y, M, np.array([0.5]))[0])
    assert np.allclose(M, [0, -4, 4, 0]) and abs(evaluate(x, y, M, np.array([0.5]))[0] - 0.75) < 1e-12
    # a tube centreline sampled at uneven stations (mm)
    xs = np.array([0, 60, 150, 260, 400, 520, 600.0]); ys = np.array([0, 18, 40, 52, 47, 30, 22.0])
    M = natural_spline(xs, ys)
    eps = 1e-7
    for k in xs[1:-1]:
        for der in (0, 1, 2):
            left, right = evaluate(xs, ys, M, np.array([k - eps]), der)[0], evaluate(xs, ys, M, np.array([k + eps]), der)[0]
            assert abs(left - right) < 1e-4, (k, der, left, right)
    print("value, slope and curvature are continuous at every interior knot")
    from scipy.interpolate import CubicSpline
    t = np.linspace(0, 600, 1201)
    ref = CubicSpline(xs, ys, bc_type="natural")(t)
    print(f"max difference from scipy CubicSpline(natural): {np.max(np.abs(evaluate(xs, ys, M, t) - ref)):.2e} mm")
    assert np.max(np.abs(evaluate(xs, ys, M, t) - ref)) < 1e-10
```

The continuity test is worth having: an early version of the code above built the sub-diagonal from the wrong spacings. With uneven knots the curve still passed through every point and looked fine, but the slope jumped at the third station. Only the test caught it.

:::exercise Natural or clamped?
A cam profile must start from rest: lift $0$ and slope $0$ at $\theta = 0$. Which end condition do you use there, and what does a natural spline do instead?
---solution---
1. Use a clamped end with $S'(0) = 0$, so the follower velocity starts at zero.
2. A natural spline forces $S''(0) = 0$ instead and leaves the slope free; the follower would start with a nonzero velocity, a velocity jump and an infinite acceleration spike at the start.
3. For cams you often need continuous jerk too, which leads to quintic splines or B-splines of higher degree.
:::
