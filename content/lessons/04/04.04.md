Measurements and tables give you values at a few points: a thermocouple calibration, a steam table, a cam profile, a wind-tunnel sweep. Interpolation fills in between. The obvious idea, one polynomial through all the points, works beautifully for a handful of points and fails spectacularly for many equally spaced ones. Understanding why tells you where to put your sample points.

## Lagrange form

Through $n + 1$ points $(x_j, y_j)$ there is exactly one polynomial of degree at most $n$:

$$
p(x) = \sum_{j=0}^{n} y_j\,\ell_j(x), \qquad \ell_j(x) = \prod_{k\ne j}\frac{x - x_k}{x_j - x_k}.
$$

Each basis polynomial $\ell_j$ is 1 at its own node and 0 at the others. For computing, use the **barycentric form**, which is stable and costs $O(n)$ per evaluation:

$$
p(x) = \frac{\sum_j \frac{w_j}{x - x_j}\,y_j}{\sum_j \frac{w_j}{x - x_j}}, \qquad w_j = \frac{1}{\prod_{k\ne j}(x_j - x_k)} .
$$

## The error formula and Runge's phenomenon

For a smooth $f$,

$$
f(x) - p(x) = \frac{f^{(n+1)}(\xi)}{(n + 1)!}\prod_{j=0}^{n}(x - x_j).
$$

Two factors fight: the derivative term and the **node polynomial** $\prod(x - x_j)$. For equally spaced nodes the node polynomial is tiny in the middle and huge near the ends. For $f = 1/(1 + 25x^2)$ on $[-1, 1]$, the derivatives grow fast enough that the error near the ends *grows* with $n$: Runge's phenomenon.

## Chebyshev nodes

Choose nodes that cluster towards the ends:

$$
x_k = \cos\frac{(2k + 1)\pi}{2(n + 1)}, \qquad k = 0, \dots, n .
$$

They make $\max|\prod(x - x_k)| = 2^{-n}$, the smallest possible, and for any smooth function the interpolation error then falls as $n$ grows. When you can choose where to measure, measure at Chebyshev points.

:::widget runge
Interpolating $1/(1 + 25x^2)$. With equispaced nodes, raise $n$ past 10 and watch the ends blow up. Switch to Chebyshev nodes and the same degree converges.
:::

:::example Thermocouple between table values
A type K thermocouple gives 0 mV at 0 °C, 4.096 mV at 100 °C and 8.138 mV at 200 °C. Estimate the voltage at 150 °C.

1. $\ell_0(150) = \frac{(150 - 100)(150 - 200)}{(0 - 100)(0 - 200)} = -0.125$.
2. $\ell_1(150) = \frac{(150 - 0)(150 - 200)}{(100 - 0)(100 - 200)} = 0.75$, and $\ell_2(150) = \frac{150\cdot50}{200\cdot100} = 0.375$.
3. $p(150) = 0 + 0.75\cdot4.096 + 0.375\cdot8.138 = 6.124$ mV.
4. The reference table gives 6.138 mV. The 0.014 mV gap is about 0.35 °C at roughly 41 µV/°C: fine for a quick check, not for calibration, where you'd use more points or a spline.
:::

```python file=interpolation.py
"""Lagrange interpolation in barycentric form: equispaced nodes (Runge) versus Chebyshev nodes."""
import numpy as np

runge = lambda x: 1 / (1 + 25 * x**2)


def bary_weights(xn):
    w = np.ones(len(xn))
    for j in range(len(xn)):
        w[j] = 1 / np.prod(xn[j] - np.delete(xn, j))
    return w


def interp(xn, yn, x):
    """Barycentric Lagrange formula: stable, O(n) per point once the weights are known."""
    w = bary_weights(xn)
    d = x[:, None] - xn[None, :]
    exact = np.isclose(d, 0, atol=1e-14)
    d[exact] = 1
    t = w / d
    p = (t @ yn) / t.sum(axis=1)
    rows, cols = np.nonzero(exact)
    p[rows] = yn[cols]
    return p


def equi(n):
    return np.linspace(-1, 1, n + 1)


def cheb(n):
    k = np.arange(n + 1)
    return np.cos((2 * k + 1) * np.pi / (2 * (n + 1)))


if __name__ == "__main__":
    x = np.linspace(-1, 1, 4001)
    # sanity: interpolating a cubic with 4+ nodes is exact
    xn = equi(5)
    assert np.max(np.abs(interp(xn, xn**3 - xn, x) - (x**3 - x))) < 1e-12
    print(" n   equispaced max error   Chebyshev max error")
    ce = []
    for n in (5, 10, 15, 20):
        ee = np.max(np.abs(interp(equi(n), runge(equi(n)), x) - runge(x)))
        ce.append(np.max(np.abs(interp(cheb(n), runge(cheb(n)), x) - runge(x))))
        print(f"{n:2d}   {ee:20.4f}   {ce[-1]:19.4f}")
    assert all(b < a for a, b in zip(ce, ce[1:]))          # Chebyshev error falls as n grows
    e20 = np.max(np.abs(interp(equi(20), runge(equi(20)), x) - runge(x)))
    assert e20 > 50                                         # Runge: equispaced error explodes
```

The script prints, for Runge's function:

| $n$ | equispaced max error | Chebyshev max error |
|---|---|---|
| 5 | 0.433 | 0.556 |
| 10 | 1.916 | 0.109 |
| 15 | 2.108 | 0.083 |
| 20 | 59.8 | 0.015 |

At very low degree Chebyshev is not automatically better, but only Chebyshev keeps improving.

:::exercise Why not just use more points?
A colleague fits a degree-20 polynomial through 21 equally spaced points of a measured cam lift curve and finds wild oscillations near the ends. Give two fixes.
---solution---
1. Measure at Chebyshev-spaced angles instead, if the rig allows it. The node polynomial is then evenly small across the interval.
2. Use piecewise interpolation: a cubic spline (next lesson) through the same 21 points. Each piece only sees its neighbours, so the error is controlled locally and doesn't grow with the number of points.
3. If the data are noisy, don't interpolate at all: fit a low-degree least-squares model (Phase 02) or a smoothing spline.
:::
