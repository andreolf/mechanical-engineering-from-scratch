Lesson 03.14 solved the cooling of a rod with a Fourier series. Real parts have awkward shapes, varying properties and time-dependent boundaries, so you need a time-stepping solver. Discretise space with the stencil from the last lesson and time with Euler or the trapezoidal rule, and you get the two classic schemes: FTCS, simple but bound by a strict time-step limit, and Crank-Nicolson, implicit and stable at any step.

## FTCS: forward time, centred space

For $u_t = \alpha u_{xx}$ on a grid $x_i = i\Delta x$, $t_n = n\Delta t$:

$$
u_i^{n+1} = u_i^n + r\left(u_{i+1}^n - 2u_i^n + u_{i-1}^n\right), \qquad r = \frac{\alpha\Delta t}{\Delta x^2}.
$$

Each new value is a weighted average of three old ones, with weights $r$, $1 - 2r$, $r$. If $r > 1/2$ the centre weight goes negative and the scheme overshoots.

## Von Neumann stability analysis

Insert a single Fourier mode $u_i^n = G^n e^{\mathrm i k i\Delta x}$:

$$
G = 1 - 4r\sin^2\frac{k\Delta x}{2}.
$$

The worst mode is the grid-scale zig-zag ($k\Delta x = \pi$), with $G = 1 - 4r$. Requiring $|G| \le 1$ gives

$$
r \le \tfrac12 \quad\Longleftrightarrow\quad \Delta t \le \frac{\Delta x^2}{2\alpha}.
$$

Halving $\Delta x$ forces a quarter of the time step: four times the steps on twice the nodes, eight times the work. That is why explicit heat solvers get expensive on fine grids.

## Crank-Nicolson

Average the spatial operator between the old and new time levels (the trapezoidal rule in time):

$$
\left(I + \tfrac r2 A\right)\mathbf u^{n+1} = \left(I - \tfrac r2 A\right)\mathbf u^{n}, \qquad A = \mathrm{tridiag}(-1, 2, -1).
$$

One tridiagonal solve per step, $O(n)$. The amplification factor is

$$
G = \frac{1 - 2r\sin^2(k\Delta x/2)}{1 + 2r\sin^2(k\Delta x/2)},
$$

always between $-1$ and $1$: unconditionally stable and second order in both time and space. At large $r$, $G \to -1$ for the zig-zag mode, so sharp initial corners ring for a few steps before decaying. Starting with a couple of backward Euler steps removes that.

An aluminium rod, 0.5 m long, starts at 100 °C with both ends at 0 °C. Push FTCS past $r = 0.5$ and a zig-zag explodes from the grid scale. Switch to Crank-Nicolson and $r = 5$ still gives a smooth, accurate profile with ten times fewer steps.
:::

|---|---|---|---|
| FTCS | 0.250 | 2328 | 12.7864 |

:::

```python file=heat_schemes.py
"""Heat equation u_t = alpha u_xx: FTCS (explicit, needs r <= 1/2) and Crank-Nicolson (implicit, unconditionally stable)."""
import math
import numpy as np
from scipy.linalg import solve_banded

ALPHA, L, T0 = 9.7e-5, 0.5, 100.0      # aluminium rod, 0.5 m, initially 100 C, ends plunged into 0 C


def exact(x, t, terms=401):
    return sum(4 * T0 / (k * math.pi) * np.sin(k * math.pi * x / L) * math.exp(-ALPHA * (k * math.pi / L) ** 2 * t)
               for k in range(1, terms, 2))


def ftcs(n, r, t_end):
    dx = L / n; steps = max(1, round(t_end * ALPHA / (r * dx * dx))); r = ALPHA * (t_end / steps) / dx**2   # land exactly on t_end
    u = np.full(n + 1, T0); u[0] = u[-1] = 0.0
    for _ in range(steps):
        u[1:-1] = u[1:-1] + r * (u[2:] - 2 * u[1:-1] + u[:-2])
    return u, r, steps


def crank_nicolson(n, r, t_end):
    dx = L / n; steps = max(1, round(t_end * ALPHA / (r * dx * dx))); r = ALPHA * (t_end / steps) / dx**2; m = n - 1
    ab = np.zeros((3, m)); ab[0, 1:] = -r / 2; ab[1, :] = 1 + r; ab[2, :-1] = -r / 2     # (I + r/2 A) on the left
    u = np.full(n + 1, T0); u[0] = u[-1] = 0.0
    for _ in range(steps):
        rhs = (1 - r) * u[1:-1] + r / 2 * (u[2:] + u[:-2])                                  # (I - r/2 A) on the right
        u[1:-1] = solve_banded((1, 1), ab, rhs)
    return u, r, steps


if __name__ == "__main__":
    n, t_end = 50, 600.0
    ex = exact(L / 2, t_end)
    print(f"exact centre temperature after {t_end:.0f} s: {ex:.4f} C")
    for r in (0.25, 0.5, 0.52):
        u, ra, steps = ftcs(n, r, t_end)
        c = u[n // 2]
        print(f"FTCS r = {ra:.3f}: centre {c:.4f} C after {steps} steps" if abs(c) < 1e4 else f"FTCS r = {ra:.3f}: centre {c:.2e} C after {steps} steps: blown up")
    u, ra, _ = ftcs(n, 0.4, t_end); assert abs(u[n // 2] - ex) < 0.1
    u, ra, _ = ftcs(n, 0.52, 3 * t_end); assert ra > 0.5 and np.max(np.abs(u)) > 1e3     # blows up just past r = 1/2
    for r in (0.5, 5, 50):
        u, ra, steps = crank_nicolson(n, r, t_end)
        print(f"Crank-Nicolson r = {ra:.2f}: centre {u[n // 2]:.4f} C after {steps} steps, error {abs(u[n // 2] - ex):.4f} C")
        assert abs(u[n // 2] - ex) < 0.3
```

:::exercise Time-step budget
A copper bus bar ($\alpha = 1.11\times10^{-4}$ m²/s) is modelled with $\Delta x = 2$ mm. What is the FTCS time-step limit, and how many steps does a 10-minute simulation take? How many with Crank-Nicolson at $r = 10$?
---solution---
1. $\Delta t \le \Delta x^2/(2\alpha) = (0.002)^2/(2.22\times10^{-4}) = 0.0180$ s.
2. 600 s / 0.0180 s = 33 300 steps.
3. Crank-Nicolson at $r = 10$: $\Delta t = 10\cdot4\times10^{-6}/1.11\times10^{-4} = 0.360$ s, so about 1670 steps, each a cheap tridiagonal solve.
:::
