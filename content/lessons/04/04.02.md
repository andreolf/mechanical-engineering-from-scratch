Engineering is full of equations you cannot rearrange: the Colebrook friction factor in a pipe, the natural frequencies of a beam, the operating point of a pump on a system curve. You met bisection and Newton in Phase 01. This lesson builds the toolbox a professional uses: know which method is safe, which is fast, and how to combine them so you get both.

## The trade-off

| Method | Needs | Order | Can fail? |
|---|---|---|---|
| Bisection | a bracket $[a, b]$ with a sign change | 1 (halves the bracket) | no |
| Newton | $f'$ and a good start | 2 | yes: diverges, cycles, $f' = 0$ |
| Secant | two starting points | 1.618 | yes |
| Brent | a bracket | superlinear | no |

Bisection is guaranteed but slow: to shrink a bracket of width $L$ to $\delta$ takes $\lceil\log_2(L/\delta)\rceil$ steps, independent of the function. Newton is fast but needs a derivative and can be thrown far away by a flat region.

## Secant: Newton without the derivative

Replace $f'(x_n)$ by the slope through the last two points:

$$
x_{n+1} = x_n - f(x_n)\,\frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}.
$$

One new function evaluation per step and order $\varphi = 1.618$. Per evaluation that beats Newton (which needs $f$ and $f'$) whenever the derivative costs more than about 44% of a function call.

## Brent: fast when it can be, safe when it must be

Brent's method keeps a bracket at all times. Each step it tries a fast interpolation step: **inverse quadratic interpolation** through the last three points (fit $x$ as a quadratic in $y$ and set $y = 0$), or a secant step. It accepts that step only if it lands inside the bracket and shrinks the interval well enough; otherwise it bisects. So it is never slower than bisection by more than a constant factor and usually converges superlinearly. It's what `scipy.optimize.brentq` runs.

:::

:::example Friction factor in a water main
Find the Darcy friction factor $f$ for $Re = 10^5$ and relative roughness $\varepsilon/D = 10^{-4}$ from Colebrook:

$$
\frac{1}{\sqrt f} = -2\log_{10}\!\left(\frac{\varepsilon/D}{3.7} + \frac{2.51}{Re\sqrt f}\right).
$$

1. Solve for $x = 1/\sqrt f$: $g(x) = x + 2\log_{10}(\varepsilon/D/3.7 + 2.51x/Re) = 0$.
2. Bracket: $g(1) = -7.57$ and $g(20) = +13.45$, so a root lies in $[1, 20]$.
3. Brent converges in 6 iterations to $x = 7.3494$, so $f = 1/x^2 = 0.01851$. Bisection needs 45 iterations for the same $10^{-12}$ tolerance.
4. Sanity check against the explicit Swamee-Jain approximation: $0.01845$, within 0.4%.
:::

```python file=root_finding.py
"""Bisection, secant and a simplified Brent method, raced on the Colebrook friction-factor equation."""
import math


def bisection(f, a, b, tol=1e-12):
    fa = f(a); n = 0
    while b - a > tol:
        m = 0.5 * (a + b); fm = f(m); n += 1
        if fa * fm <= 0:
            b = m
        else:
            a, fa = m, fm
    return 0.5 * (a + b), n


def secant(f, x0, x1, tol=1e-12, maxit=100):
    f0, f1 = f(x0), f(x1)
    for n in range(1, maxit + 1):
        x2 = x1 - f1 * (x1 - x0) / (f1 - f0)
        x0, f0, x1, f1 = x1, f1, x2, f(x2)
        if abs(x1 - x0) < tol:
            return x1, n
    raise RuntimeError("secant did not converge")


def brent(f, a, b, tol=1e-12, maxit=200):
    """Keep a bracket; try inverse quadratic / secant steps, fall back to bisection when they misbehave."""
    fa, fb = f(a), f(b)
    if fa * fb > 0:
        raise ValueError("root not bracketed")
    if abs(fa) < abs(fb):
        a, b, fa, fb = b, a, fb, fa
    c, fc, n = a, fa, 0
    while abs(b - a) > tol and fb != 0 and n < maxit:
        n += 1
        if fa != fc and fb != fc:          # inverse quadratic interpolation through (a, b, c)
            s = (a * fb * fc / ((fa - fb) * (fa - fc)) + b * fa * fc / ((fb - fa) * (fb - fc))
                 + c * fa * fb / ((fc - fa) * (fc - fb)))
        else:                              # secant
            s = b - fb * (b - a) / (fb - fa)
        lo, hi = sorted(((3 * a + b) / 4, b))
        if not (lo < s < hi) or abs(s - b) >= abs(b - c) / 2:
            s = 0.5 * (a + b)              # bisection: guaranteed progress
        fs = f(s)
        c, fc = b, fb
        if fa * fs < 0:
            b, fb = s, fs
        else:
            a, fa = s, fs
        if abs(fa) < abs(fb):
            a, b, fa, fb = b, a, fb, fa
    return b, n


def colebrook(Re, rel):
    """Residual in x = 1/sqrt(f): x + 2 log10(rel/3.7 + 2.51 x / Re) = 0."""
    return lambda x: x + 2 * math.log10(rel / 3.7 + 2.51 * x / Re)


if __name__ == "__main__":
    g = colebrook(1e5, 1e-4)
    xb, nb = bisection(g, 1, 20)
    xs, ns = secant(g, 1, 20)
    xr, nr = brent(g, 1, 20)
    fric = 1 / xr**2
    print(f"Colebrook Re = 1e5, eps/D = 1e-4: f = {fric:.5f}")
    print(f"iterations: bisection {nb}, secant {ns}, Brent {nr}")
    assert abs(xb - xr) < 1e-10 and abs(xs - xr) < 1e-10
    assert nr < nb
    # a suite of awkward bracketed functions: Brent must never fail
    suite = [(lambda x: x**3 - 2 * x - 5, 2, 3), (lambda x: math.atan(x - 1) * 100, -5, 30),
             (lambda x: (x - 1) ** 3, 0, 3.3), (lambda x: math.exp(x) - 1e6, 0, 30),
             (lambda x: x - math.cos(x), 0, 1), (lambda x: 1 / (x - 0.3) + 1 if x != 0.3 else 1e300, -2, 0.29)]
    for h, a, b in suite:
        r, n = brent(h, a, b)
        assert abs(h(r)) < 1e-6 or abs(r - 1) < 1e-4, (r, h(r))
    print("Brent solved all", len(suite), "bracketed test functions")
```

:::exercise Choose the method
You need the first natural frequency of a clamped beam from $\cos\beta\cosh\beta = -1$, inside a design loop that calls it 10 000 times. The derivative is easy. Which method do you use and how do you start it?
---solution---
1. The root near $\beta = 1.875$ lies in the bracket $[1, 3]$: $\cos1\cosh1 + 1 = 1.83 > 0$ and $\cos3\cosh3 + 1 = -8.97 < 0$.
2. Brent with that bracket is safe and fast. Newton is faster per step, but $\cosh\beta$ grows quickly, so a bad start can throw it to another root.
3. A good compromise for the loop: Newton started from the previous design's root, falling back to Brent if a step leaves the bracket. That is the same idea Brent uses internally.
:::
