Real structures rarely give you one equation in one unknown. A cable net, a linkage, a pipe network or a large-deflection frame gives you $n$ coupled nonlinear equations $\mathbf F(\mathbf x) = \mathbf 0$. Newton's method carries over almost unchanged: replace the derivative by the **Jacobian matrix** and the division by a linear solve. It is the engine inside every nonlinear finite-element code.

## Newton in $n$ dimensions

Linearise around the current guess:

$$
\mathbf F(\mathbf x + \Delta\mathbf x) \approx \mathbf F(\mathbf x) + J(\mathbf x)\,\Delta\mathbf x, \qquad J_{ij} = \frac{\partial F_i}{\partial x_j}.
$$

Set the linear model to zero and solve for the step:

$$
J(\mathbf x_k)\,\Delta\mathbf x = -\mathbf F(\mathbf x_k), \qquad \mathbf x_{k+1} = \mathbf x_k + \Delta\mathbf x.
$$

Never invert $J$; solve the system (LU from Phase 02). Near the solution the convergence is quadratic: the residual norm squares each step.

## Where the Jacobian comes from

- **By hand**, when the equations are simple. Best accuracy and speed.
- **By finite differences**, column by column: $J_{:,j} \approx (\mathbf F(\mathbf x + h\mathbf e_j) - \mathbf F(\mathbf x - h\mathbf e_j))/(2h)$. Costs $2n$ residual evaluations. Always use it to *check* a hand-derived Jacobian.
- **By automatic differentiation**, in modern frameworks.

## A node held by two cables

A node at $\mathbf p$ hangs from elastic cables anchored at $\mathbf a_i$ with unstretched length $L_{0,i}$ and axial stiffness $EA$. With $\mathbf d_i = \mathbf a_i - \mathbf p$, $L_i = |\mathbf d_i|$ and $\mathbf u_i = \mathbf d_i/L_i$, each cable pulls with tension $T_i = \frac{EA}{L_{0,i}}(L_i - L_{0,i})$ (zero if slack). Equilibrium is

$$
\mathbf F(\mathbf p) = \sum_i T_i\,\mathbf u_i + \begin{pmatrix}0\\-W\end{pmatrix} = \mathbf 0 .
$$

Differentiating gives the **tangent stiffness**, two physical parts per cable:

$$
J = -\sum_i \left[ k_i\,\mathbf u_i\mathbf u_i^{\mathsf T} + \frac{T_i}{L_i}\left(I - \mathbf u_i\mathbf u_i^{\mathsf T}\right)\right], \qquad k_i = \frac{EA}{L_{0,i}}.
$$

The first term is the cable's axial stiffness. The second is the **geometric stiffness**: a taut cable resists sideways motion in proportion to its tension, which is why a guitar string gets stiffer as you tune it up.

3. Solution $\mathbf p = (2.2991, -1.1971)$ m. Cable lengths $2.5921$ m and $2.0799$ m.
4. Tensions $T_1 = 50\,000\cdot0.0921/2.5 = 1842$ N and $T_2 = 50\,000\cdot0.0799/2.0 = 1997$ N. Their vertical components add up to $W$.
:::

```python file=nonlinear_systems.py
"""Newton's method for a node hanging from two elastic cables: residual, analytic Jacobian, quadratic convergence."""
import numpy as np

ANCHORS = np.array([[0.0, 0.0], [4.0, 0.0]])     # m
L0 = np.array([2.5, 2.0])                        # unstretched lengths, m
EA = 50e3                                        # axial stiffness of each cable, N
W = 2000.0                                       # hanging load, N


def residual(p):
    r = np.array([0.0, -W])
    for a, l0 in zip(ANCHORS, L0):
        d = a - p; L = np.linalg.norm(d)
        T = EA * (L - l0) / l0 if L > l0 else 0.0   # cables cannot push
        r += T * d / L
    return r


def jacobian(p):
    J = np.zeros((2, 2))
    for a, l0 in zip(ANCHORS, L0):
        d = a - p; L = np.linalg.norm(d); u = d / L
        if L <= l0:
            continue
        k = EA / l0; T = k * (L - l0)
        # d/dp of T u: stiffness along the cable plus geometric stiffness T/L across it
        J -= k * np.outer(u, u) + (T / L) * (np.eye(2) - np.outer(u, u))
    return J


def newton(F, J, p, tol=1e-10, maxit=20):
    hist = []
    for k in range(maxit):
        r = F(p); hist.append(np.linalg.norm(r))
        if hist[-1] < tol:
            return p, hist
        p = p - np.linalg.solve(J(p), r)
    raise RuntimeError("no convergence")


if __name__ == "__main__":
    p0 = np.array([2.0, -2.0])
    # check the analytic Jacobian against finite differences
    h = 1e-6
    Jfd = np.column_stack([(residual(p0 + h * e) - residual(p0 - h * e)) / (2 * h) for e in np.eye(2)])
    assert np.allclose(Jfd, jacobian(p0), rtol=1e-6, atol=1e-2)
    p, hist = newton(residual, jacobian, p0)
    T = [EA * (np.linalg.norm(a - p) - l0) / l0 for a, l0 in zip(ANCHORS, L0)]
    print(f"node at ({p[0]:.4f}, {p[1]:.4f}) m after {len(hist) - 1} Newton steps")
    print("residual history:", " ".join(f"{r:.1e}" for r in hist))
    print(f"tensions: left {T[0]:.1f} N, right {T[1]:.1f} N")
    assert len(hist) - 1 <= 10 and hist[-1] < 1e-10
    # vertical equilibrium check by hand: sum of vertical tension components equals W
    assert abs(sum(t * (a - p)[1] / np.linalg.norm(a - p) for t, a in zip(T, ANCHORS)) - W) < 1e-6
```

:::exercise One Newton step by hand
Solve $x^2 + y^2 = 4$, $xy = 1$ starting from $(x, y) = (2, 0.5)$. Take one Newton step and compare with the exact root in that quadrant.
---solution---
1. $\mathbf F = (x^2 + y^2 - 4,\ xy - 1) = (0.25,\ 0)$ and $J = \begin{pmatrix}2x & 2y\\ y & x\end{pmatrix} = \begin{pmatrix}4 & 1\\ 0.5 & 2\end{pmatrix}$, $\det J = 7.5$.
2. $\Delta = -J^{-1}\mathbf F = -\frac{1}{7.5}\begin{pmatrix}2 & -1\\ -0.5 & 4\end{pmatrix}\begin{pmatrix}0.25\\0\end{pmatrix} = (-0.0667,\ 0.0167)$.
3. New point $(1.9333,\ 0.5167)$.
4. Exact: $x^2 + 1/x^2 = 4$ gives $x^2 = 2 + \sqrt3$, so $x = 1.9319$, $y = 0.5176$. One step already has three correct digits.
:::
