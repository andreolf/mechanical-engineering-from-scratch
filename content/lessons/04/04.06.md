A displacement sensor on a test rig gives you position every millisecond. You want velocity and acceleration. Differentiating the samples directly, with the finite differences from Phase 01, produces garbage: each difference divides a small noise by a small step. This lesson quantifies the problem and fixes it the way instrumentation engineers do, by fitting before differentiating.

## Why noise explodes

Write each sample as $x_i = x(t_i) + \eta_i$ with independent noise of standard deviation $\sigma$. The central difference gives

$$
\frac{x_{i+1} - x_{i-1}}{2h} = x'(t_i) + \underbrace{\frac{h^2}{6}x'''}_{\text{truncation}} + \underbrace{\frac{\eta_{i+1} - \eta_{i-1}}{2h}}_{\text{noise}} .
$$

The noise term has standard deviation $\sqrt2\,\sigma/(2h) = \sigma/(\sqrt2\,h)$. Sampling *faster* makes it *worse*. A second derivative is worse again, scaling like $\sigma/h^2$. At 1 kHz with 0.1 mm noise the velocity noise is about 0.07 m/s, and a raw second difference has about 245 m/s² of noise, 25 g.

## Fit first: Savitzky-Golay

Around each sample take a window of $2m + 1$ points, fit a low-degree polynomial by least squares (Phase 02), and differentiate the polynomial at the centre. Because the fit is linear in the data, the whole operation is a fixed set of weights $c_k$, a convolution:

$$
\hat x'(t_i) = \sum_{k=-m}^{m} c_k\,x_{i+k}.
$$

For a quadratic (or linear) fit the first-derivative weights are simply $c_k = k/(h\sum k^2)$, the least-squares slope. Their noise gain is $\sigma/(h\sqrt{\sum k^2})$, which falls like $m^{-3/2}$. The price is bias: a wide window flattens fast features. Choose the window to span a small fraction of the shortest period you care about.

:::example Velocity from a shaker test
Position $x = 0.05\sin(2\pi\cdot1.5\,t)$ m, sampled at $h = 1$ ms with $\sigma = 0.1$ mm noise. True peak speed $0.05\cdot2\pi\cdot1.5 = 0.471$ m/s.

1. Raw central difference: predicted noise $\sigma/(\sqrt2 h) = 10^{-4}/(1.414\times10^{-3}) = 0.0707$ m/s; measured RMS error 0.0718 m/s, 15% of the peak.
2. Savitzky-Golay, 51-point window, quadratic: noise gain $\sigma/(h\sqrt{2\sum_1^{25}k^2}) = 10^{-4}/(10^{-3}\cdot105.1) = 0.00095$ m/s.
3. Measured RMS error 0.00213 m/s, which includes the small bias of fitting a parabola over 51 ms of a 667 ms period. Better than raw by a factor of 34.
:::

```python file=noisy_diff.py
"""Differentiating noisy measurements: raw differences amplify noise like sigma/h; Savitzky-Golay fits a local polynomial first."""
import numpy as np


def savgol_coeffs(half, order, deriv, h):
    """Least-squares polynomial of given order on 2*half+1 points; return the weights for the deriv-th derivative at the centre."""
    k = np.arange(-half, half + 1)
    A = np.vander(k, order + 1, increasing=True)          # columns 1, k, k^2, ...
    pinv = np.linalg.pinv(A)                               # (order+1) x (2 half + 1)
    fact = np.prod(np.arange(1, deriv + 1)) if deriv else 1
    return fact * pinv[deriv] / h**deriv


def savgol(y, half, order, deriv, h):
    c = savgol_coeffs(half, order, deriv, h)
    out = np.convolve(y, c[::-1], mode="same")
    out[:half] = np.nan; out[-half:] = np.nan              # no full window at the ends
    return out


if __name__ == "__main__":
    rng = np.random.default_rng(1)
    # a test-rig position sensor: x(t) = 0.05 sin(2 pi 1.5 t) m, sampled at 1 kHz with 0.1 mm noise
    h = 1e-3; t = np.arange(0, 2, h)
    x_true = 0.05 * np.sin(2 * np.pi * 1.5 * t); v_true = 0.05 * 2 * np.pi * 1.5 * np.cos(2 * np.pi * 1.5 * t)
    x = x_true + rng.normal(0, 1e-4, t.size)
    v_raw = np.full_like(x, np.nan); v_raw[1:-1] = (x[2:] - x[:-2]) / (2 * h)
    v_sg = savgol(x, 25, 2, 1, h)
    m = slice(30, -30)
    e_raw = np.sqrt(np.nanmean((v_raw[m] - v_true[m]) ** 2)); e_sg = np.sqrt(np.nanmean((v_sg[m] - v_true[m]) ** 2))
    print(f"peak true speed {v_true.max():.4f} m/s")
    print(f"RMS velocity error: raw central difference {e_raw:.4f} m/s, Savitzky-Golay (51 points, quadratic) {e_sg:.5f} m/s")
    print(f"predicted raw noise sigma/(sqrt(2) h) = {1e-4 / (np.sqrt(2) * h):.4f} m/s")
    assert e_sg < e_raw / 10
    assert abs(e_raw - 1e-4 / (np.sqrt(2) * h)) < 0.01
    # SG weights reproduce derivatives of polynomials up to the fitted order exactly
    c = savgol_coeffs(3, 2, 1, 1.0)
    k = np.arange(-3, 4)
    assert abs(c @ (2 + 3 * k + 0.5 * k**2) - 3) < 1e-12
    from scipy.signal import savgol_filter
    ref = savgol_filter(x, 51, 2, deriv=1, delta=h)
    assert np.allclose(ref[m], v_sg[m], atol=1e-10)
    print("matches scipy.signal.savgol_filter")
```

:::exercise Acceleration from the same data
Estimate the noise in a raw second difference $(x_{i+1} - 2x_i + x_{i-1})/h^2$ for $\sigma = 0.1$ mm and $h = 1$ ms, and compare with the true peak acceleration.
---solution---
1. The noise is $(\eta_{i+1} - 2\eta_i + \eta_{i-1})/h^2$, with variance $(1 + 4 + 1)\sigma^2/h^4$, so standard deviation $\sqrt6\,\sigma/h^2 = 2.449\cdot10^{-4}/10^{-6} = 245$ m/s².
2. True peak acceleration $0.05\,(2\pi\cdot1.5)^2 = 4.44$ m/s².
3. The noise is 55 times the signal. You must smooth (a Savitzky-Golay second-derivative filter or a low-pass filter) or measure acceleration directly with an accelerometer.
:::
