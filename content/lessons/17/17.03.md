The finite-volume update is only as good as its face flux. First-order upwind is robust but smears everything; second-order schemes are sharper but wiggle near jumps. **TVD limiters** combine the two.

## Upwind and Lax-Wendroff

For advection with speed $a > 0$ and Courant number $c = a\Delta t/\Delta x$, write the face flux as upwind plus a correction:

$$
F_{i+1/2} = a\left[Q_i + \tfrac12(1 - c)\,\phi(r_i)\,(Q_{i+1} - Q_i)\right], \qquad r_i = \frac{Q_i - Q_{i-1}}{Q_{i+1} - Q_i} .
$$

- $\phi = 0$: **upwind**, first order, adds numerical diffusion $\tfrac12 a\Delta x(1 - c)$.
- $\phi = 1$: **Lax-Wendroff**, second order, but dispersive: it creates over- and undershoots at jumps.

Godunov's theorem says no *linear* scheme can be both better than first order and free of new extrema. The way out is a nonlinear $\phi(r)$ that depends on the local smoothness ratio $r$.

## TVD limiters

The **total variation** $TV = \sum_i |Q_{i+1} - Q_i|$ measures how wiggly the solution is. A scheme is **TVD** (total variation diminishing) if $TV$ never grows; then no new extrema can appear. Harten and Sweby showed that the scheme above is TVD when $0 \le \phi(r) \le \min(2r, 2)$, and second order in smooth regions when $\phi(1) = 1$.

| Limiter | $\phi(r)$ |
|---|---|
| minmod | $\max(0, \min(1, r))$ |
| van Leer | $(r + |r|)/(1 + |r|)$ |
| superbee | $\max(0, \min(2r, 1), \min(r, 2))$ |

Minmod is the most diffusive of the three, superbee the most compressive (it sharpens fronts, and can square off smooth peaks).

|---|---|---|---|---|
| upwind | 0.00000 | 0.99731 | 1.9946 | 0.0797 |
| Lax-Wendroff | −0.23210 | 1.23206 | 3.9352 | 0.0523 |

| van Leer | 0.00000 | 1.00000 | 2.0000 | 0.0204 |
| superbee | 0.00000 | 1.00000 | 2.0000 | 0.0088 |

1. The four TVD schemes never leave $[0, 1]$, and their total variation never grows at any step.
2. Lax-Wendroff overshoots by 23 % and almost doubles the total variation.
3. Superbee is nine times more accurate than upwind on this discontinuous profile.
:::

```python file=limiters.py
"""Flux schemes for linear advection on a periodic domain: first-order upwind, Lax-Wendroff, and TVD schemes with the minmod and superbee limiters. A square pulse is advected once around; TVD schemes create no new extrema and never increase the total variation."""
import numpy as np


def minmod(r):
    return np.maximum(0, np.minimum(1, r))


def superbee(r):
    return np.maximum(0, np.maximum(np.minimum(2 * r, 1), np.minimum(r, 2)))


def vanleer(r):
    return (r + np.abs(r)) / (1 + np.abs(r))


LIMITERS = {"upwind": lambda r: 0 * r, "Lax-Wendroff": lambda r: 1 + 0 * r, "minmod": minmod, "superbee": superbee, "van Leer": vanleer}


def step(q, c, phi):
    """Flux-limited scheme for a > 0, Courant number c: F = a q_i + a/2 (1 - c) phi(r) (q_{i+1} - q_i)."""
    dq = np.roll(q, -1) - q                          # q_{i+1} - q_i  at face i+1/2
    dqm = q - np.roll(q, 1)                          # q_i - q_{i-1}
    with np.errstate(divide="ignore", invalid="ignore"):
        r = np.where(np.abs(dq) > 1e-14, dqm / dq, 0.0)
    F = q + 0.5 * (1 - c) * phi(r) * dq              # flux / a
    return q - c * (F - np.roll(F, 1))


def tv(q):
    return np.abs(np.roll(q, -1) - q).sum()


def run(name, N=200, c=0.5, periods=1):
    x = (np.arange(N) + 0.5) / N; q = ((x > 0.2) & (x < 0.5)).astype(float)
    n = int(round(periods * N / c)); tvs = [tv(q)]; ext = [0.0, 1.0]
    for _ in range(n):
        q = step(q, c, LIMITERS[name]); tvs.append(tv(q))
    return x, q, np.array(tvs)


if __name__ == "__main__":
    exact = None
    for name in LIMITERS:
        x, q, tvs = run(name)
        if exact is None: exact = ((x > 0.2) & (x < 0.5)).astype(float)
        err = np.abs(q - exact).mean()
        print(f"{name:13s}: min {q.min():+.5f}, max {q.max():.5f}, TV {tvs[0]:.3f} -> {tvs[-1]:.4f}, L1 error {err:.4f}")
        if name in ("upwind", "minmod", "superbee", "van Leer"):
            assert q.min() >= -1e-12 and q.max() <= 1 + 1e-12          # no new extrema
            assert np.all(np.diff(tvs) <= 1e-12)                       # total variation never grows
    x, q, tvs = run("Lax-Wendroff")
    assert q.min() < -0.05 and q.max() > 1.05 and tvs[-1] > tvs[0]     # second order but oscillates
    e = {n: np.abs(run(n)[1] - exact).mean() for n in ("upwind", "minmod", "superbee")}
    assert e["superbee"] < e["minmod"] < e["upwind"]
```

:::exercise Evaluating limiters
At a cell where $Q_{i-1} = 0.2$, $Q_i = 0.5$, $Q_{i+1} = 0.6$, find $r$ and the minmod, van Leer and superbee values of $\phi$.
---solution---
1. $r = (0.5 - 0.2)/(0.6 - 0.5) = 3$.
2. Minmod: $\max(0, \min(1, 3)) = 1$.
3. Van Leer: $(3 + 3)/(1 + 3) = 1.5$.
4. Superbee: $\max(0, \min(6, 1), \min(3, 2)) = 2$.
:::
