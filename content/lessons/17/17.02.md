Mass, momentum and energy are conserved: what leaves one region enters the next. The **finite-volume method** builds this into the discretisation, which is why nearly every industrial CFD code (OpenFOAM, Fluent, STAR-CCM+) uses it.

## Integral form and cell averages

A conservation law $\partial_t q + \partial_x f(q) = 0$, integrated over a cell $[x_{i-1/2}, x_{i+1/2}]$, becomes exact bookkeeping:

$$
\frac{d}{dt}\int_{x_{i-1/2}}^{x_{i+1/2}} q\,dx = f(x_{i-1/2}) - f(x_{i+1/2}) .
$$

Store the **cell average** $Q_i$. With a numerical flux $F_{i+1/2}$ at each face and forward Euler in time:

$$
Q_i^{n+1} = Q_i^n - \frac{\Delta t}{\Delta x}\left(F_{i+1/2} - F_{i-1/2}\right) .
$$

Summed over all cells, the face fluxes cancel in pairs (telescoping), so on a periodic domain $\sum_i Q_i\Delta x$ never changes, apart from round-off. That holds for **any** flux formula; accuracy and stability depend on the choice.

## The upwind flux

For advection $f = aq$ with $a > 0$, information comes from the left, so take $F_{i+1/2} = aQ_i$. The scheme is stable for **Courant number** $c = a\Delta t/\Delta x \le 1$: the fluid must not travel more than one cell per step (the CFL condition).

**Conservative against advective form.** With a variable speed $a(x)$, the conservation law is $q_t + (aq)_x = 0$. The **advective** equation $q_t + aq_x = 0$ is a different equation: it transports values along the flow but does not conserve the total. Discretising the wrong form is a classic bug.

:::example Dye in a periodic channel
200 cells on $[0, 1]$, $a = 1$, a Gaussian bump plus a block of dye, Courant number 0.8.

1. Once around the domain (250 steps): the total $\sum Q_i\Delta x = 0.325331413609785$ drifts by at most $5.6\times10^{-17}$.
2. The values stay between 0 and 1: upwind with $c \le 1$ makes each new value a weighted average of old ones, $Q_i^{n+1} = (1 - c)Q_i + cQ_{i-1}$.
3. At $c = 1.2$ the weights are no longer positive, and after half a period the solution has grown to $1.5\times10^{11}$.
4. Variable speed $a = 1 + 0.5\sin 2\pi x$, 400 steps: the conservative form keeps the total at 0.125331413610; the advective form drifts to 0.048193.
:::

```python file=fvadvect.py
"""1D finite-volume advection in conservation form: cell averages updated by face fluxes. Periodic domain; the total amount is conserved to round-off because every face flux leaves one cell and enters its neighbour. Also a non-conservative update for contrast."""
import numpy as np


def upwind_flux(q, a):
    """Flux through the right face of each cell, i+1/2, for speed a > 0."""
    return a * q


def step_fv(q, a, dx, dt):
    F = upwind_flux(q, a)                    # F[i] = flux at face i+1/2
    return q - dt / dx * (F - np.roll(F, 1))  # F[i-1/2] = F[i-1]


def run(N=200, a=1.0, cfl=0.8, T=1.0):
    dx = 1.0 / N; x = (np.arange(N) + 0.5) * dx
    q = np.exp(-200 * (x - 0.3) ** 2) + (np.abs(x - 0.7) < 0.1)       # a bump and a block of dye
    dt = cfl * dx / a; n = int(round(T / dt)); dt = T / n
    m0 = q.sum() * dx; drift = 0.0
    for _ in range(n):
        q = step_fv(q, a, dx, dt); drift = max(drift, abs(q.sum() * dx - m0))
    return x, q, m0, drift, n


if __name__ == "__main__":
    x, q, m0, drift, n = run()
    print(f"{n} steps once around the periodic domain: total {m0:.15f}, largest drift {drift:.2e}")
    assert drift < 1e-13
    assert q.min() >= -1e-15 and q.max() <= 1 + 1e-12       # upwind with CFL <= 1: no new extremes
    # stability: CFL above 1 blows up
    x, q2, _, _, _ = run(cfl=1.2, T=0.5)
    print(f"CFL 1.2: max |q| after half a period {np.abs(q2).max():.2e} (unstable)")
    assert np.abs(q2).max() > 1e3
    # a non-conservative form for a variable speed a(x) q_x: amount is not conserved
    N = 200; dx = 1 / N; xc = (np.arange(N) + 0.5) * dx; ax = 1 + 0.5 * np.sin(2 * np.pi * xc)
    qa = np.exp(-200 * (xc - 0.3) ** 2); qb = qa.copy(); dt = 0.5 * dx / ax.max()
    af = 1 + 0.5 * np.sin(2 * np.pi * (xc + dx / 2))          # speed at the right faces
    for _ in range(400):
        Fa = af * qa; qa = qa - dt / dx * (Fa - np.roll(Fa, 1))                 # conservative: (a q)_x
        qb = qb - dt / dx * ax * (qb - np.roll(qb, 1))                           # non-conservative: a q_x
    m = np.exp(-200 * (xc - 0.3) ** 2).sum() * dx
    print(f"variable speed, 400 steps: conservative total {qa.sum()*dx:.12f}, non-conservative {qb.sum()*dx:.6f}, start {m:.12f}")
    assert abs(qa.sum() * dx - m) < 1e-13 and abs(qb.sum() * dx - m) > 1e-3
```

:::exercise One step by hand
Cells hold $Q = [0, 1, 1, 0]$ (periodic), $a = 1$, $c = 0.5$. Do one upwind step and check the total.
---solution---
1. Fluxes through the right faces: $F/a = Q = [0, 1, 1, 0]$.
2. $Q_i^{\text{new}} = Q_i - 0.5(Q_i - Q_{i-1})$: $[0 - 0.5(0 - 0),\; 1 - 0.5(1 - 0),\; 1 - 0.5(1 - 1),\; 0 - 0.5(0 - 1)] = [0, 0.5, 1, 0.5]$.
3. Total: $2$ before and $0 + 0.5 + 1 + 0.5 = 2$ after.
:::
