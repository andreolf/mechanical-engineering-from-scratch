Computational fluid dynamics turns the Navier-Stokes equations into numbers on a grid. It shows what no wind tunnel can (pressure everywhere, flow inside a pump), and it is cheap to vary a design. It also produces beautiful, wrong pictures with great confidence. This phase builds solvers from scratch so you know where the errors come from.

## Three kinds of error

Every CFD result differs from reality by a sum of contributions:

$$
\phi_{\text{computed}} - \phi_{\text{real}} = \underbrace{(\phi_{\text{model}} - \phi_{\text{real}})}_{\text{modelling}} + \underbrace{(\phi_{h} - \phi_{\text{model}})}_{\text{discretisation}} + \underbrace{(\phi_{\text{computed}} - \phi_h)}_{\text{round-off and iteration}} .
$$

- **Modelling error**: the equations you solve are not the real ones. Turbulence models, a neglected heat source, an assumed inlet profile, rigid walls.
- **Discretisation error**: the grid and time step are finite. It falls with refinement at the scheme's order, $\varepsilon \approx Ch^p$, so it can be estimated from two or three grids (Richardson extrapolation).
- **Round-off and iteration error**: floating-point arithmetic and stopping an iterative solver early. Round-off grows as the grid gets finer, so refinement eventually stops helping.

Refining the grid only attacks the second term. No amount of mesh fixes a wrong model, which is why **validation** against experiments (17.17) is separate from **verification** of the numerics.

## Stability is not accuracy

Some schemes produce nonsense outright. Central differences for advection-diffusion oscillate when the **cell Peclet number** $Pe_h = U h/\Gamma$ exceeds 2. Explicit schemes blow up above a Courant limit (17.02). These failures are obvious; the dangerous errors are the smooth, plausible ones.

:::example An error budget that adds up
The real problem is $u\phi' - \Gamma\phi'' = s$ on $[0, 1]$ with $\phi(0) = 0$, $\phi(1) = 1$, $u = 1$, $\Gamma = 0.05$ (Pe = 20) and a small source $s = 0.05$. The model leaves the source out and uses central differences. The quantity of interest is $\phi(0.9)$.

Each contribution is estimated without knowing the true answer: modelling by a sensitivity run with the source switched on, discretisation by Richardson extrapolation from $N$ and $2N$ intervals, round-off by repeating the solve in float64.

| Grid, precision | Modelling | Discretisation | Round-off | Budget | Observed |
|---|---|---|---|---|---|
| 20, float64 | −0.038304 | −0.024652 | 0 | −0.062956 | −0.062457 |
| 40, float64 | −0.038251 | −0.005760 | 0 | −0.044010 | −0.043969 |
| 40, float32 | −0.038251 | −0.005760 | $+1.9\times10^{-8}$ | −0.044010 | −0.043968 |
| 2000, float32 | −0.038233 | −0.000002 | $-1.8\times10^{-4}$ | −0.038417 | −0.038417 |

1. The budget matches the observed error to within 1 % in every case.
2. From 20 to 40 intervals, the discretisation error falls by 4.3 times (order 2), but the modelling error does not move.
3. At 2000 intervals in float32, round-off has grown to 100 times the discretisation error.
4. With 8 intervals the cell Peclet number is 2.5, and the solution dips to −0.111: an unphysical wiggle.
:::

```python file=errbudget.py
"""An error budget for a toy CFD problem: steady 1D advection-diffusion. The 'truth' has a small heat source the model leaves out (modelling error); the model is discretised with central differences (discretisation error) and solved in float32 or float64 (round-off). Each part is estimated separately, and the budget is compared with the observed error."""
import math
import numpy as np

U, GAMMA, S0 = 1.0, 0.05, 0.05          # velocity, diffusivity, neglected source strength
XP = 0.9                                 # quantity of interest: phi at x = 0.9


def exact(x, s):
    """u phi' - Gamma phi'' = s on [0, 1], phi(0) = 0, phi(1) = 1."""
    Pe = U / GAMMA
    hom = (np.exp(Pe * x) - 1) / (math.exp(Pe) - 1)
    # particular solution s x / U, corrected so that phi(1) = 1
    return hom + s / U * (x - hom)


def solve_fd(N, s, dtype=np.float64):
    """Central differences on N intervals, Thomas algorithm carried out in the given precision."""
    h = 1.0 / N; x = np.linspace(0, 1, N + 1)
    a = dtype(-U / (2 * h) - GAMMA / h**2); b = dtype(2 * GAMMA / h**2); c = dtype(U / (2 * h) - GAMMA / h**2)
    n = N - 1; d = np.full(n, s, dtype=dtype); d[-1] -= c * dtype(1.0)
    cp = np.zeros(n, dtype); dp = np.zeros(n, dtype)
    cp[0] = c / b; dp[0] = d[0] / b
    for i in range(1, n):
        m = b - a * cp[i - 1]; cp[i] = c / m; dp[i] = (d[i] - a * dp[i - 1]) / m
    phi = np.zeros(n, dtype); phi[-1] = dp[-1]
    for i in range(n - 2, -1, -1): phi[i] = dp[i] - cp[i] * phi[i + 1]
    return x, np.concatenate([[0.0], phi.astype(np.float64), [1.0]])


def at(x, phi, xp=XP):
    return float(np.interp(xp, x, phi))


def budget(N, dtype):
    truth = float(exact(np.array(XP), S0))
    x, ph = solve_fd(N, 0.0, dtype)
    observed = at(x, ph) - truth
    # estimates, each computed without knowing the truth:
    xa, pa = solve_fd(4 * N, 0.0); xb, pb = solve_fd(4 * N, S0)
    model = at(xa, pa) - at(xb, pb)                                           # sensitivity run: switch the source on
    x2, ph2 = solve_fd(2 * N, 0.0, np.float64); x1, ph1 = solve_fd(N, 0.0, np.float64)
    disc = (at(x1, ph1) - at(x2, ph2)) * 4 / 3                               # Richardson, order 2
    roundoff = at(x, ph) - at(x1, ph1)                                        # same grid, float64 reference
    return observed, model, disc, roundoff


if __name__ == "__main__":
    print(f"Peclet number {U/GAMMA:.0f}; quantity of interest phi({XP})")
    for N, dt in ((20, np.float64), (40, np.float64), (40, np.float32), (2000, np.float32)):
        obs, m, d, r = budget(N, dt)
        total = m + d + r
        print(f"N = {N:5d}, {np.dtype(dt).name}: model {m:+.6f}, discretisation {d:+.6f}, round-off {r:+.2e}; budget {total:+.6f}, observed {obs:+.6f}")
        assert abs(total - obs) < 0.02 * abs(obs)
    # the cell Peclet number h U / Gamma must stay below 2 for central differences to avoid wiggles
    x, ph = solve_fd(8, 0.0)
    print(f"N = 8 (cell Peclet {U/GAMMA/8:.1f}): min phi {ph.min():.4f} (negative: unphysical oscillation)")
    assert ph.min() < 0
```

:::exercise When to stop refining
A second-order scheme has a discretisation error of $4\times10^{-3}$ at $N = 50$. The modelling error is about $2\times10^{-2}$. How many intervals bring the discretisation error below one tenth of the modelling error?
---solution---
1. Target: $2\times10^{-3}$, half the current value.
2. Error $\propto N^{-2}$, so $N = 50\sqrt{2} = 70.7$; use $N = 71$.
3. Refining further buys almost nothing: the answer is dominated by the model.
:::
