A CFD run produces millions of velocity vectors. To see the flow's structure you need to find its **vortices**, and that is harder than it sounds: vorticity is large in every boundary layer and shear layer, where nothing is swirling.

## The Q-criterion

Split the velocity gradient into its symmetric strain-rate part $\mathbf S$ and antisymmetric rotation part $\boldsymbol\Omega$:

$$
\nabla\mathbf u = \mathbf S + \boldsymbol\Omega, \qquad S_{ij} = \tfrac12\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\right), \qquad \Omega_{ij} = \tfrac12\left(\frac{\partial u_i}{\partial x_j} - \frac{\partial u_j}{\partial x_i}\right) .
$$

Hunt, Wray and Moin (1988) defined a vortex as a region where rotation beats strain:

$$
Q = \tfrac12\left(\|\boldsymbol\Omega\|^2 - \|\mathbf S\|^2\right) > 0 .
$$

- Solid-body rotation has $Q > 0$; pure strain $Q < 0$; **simple shear has $Q = 0$**, although its vorticity is as large as the solid-body rotation's.
- For incompressible flow, the divergence of the momentum equation gives $\nabla^2 p/\rho = 2Q$: vortex cores, $Q > 0$, are pressure minima. That is why tornado cores and tip vortices condense water vapour.
- In practice one draws an **isosurface** $Q = Q_0 > 0$ coloured by speed or vorticity. It is the standard picture of turbulent structures, wakes and tip vortices.

For an axisymmetric swirl $u_\theta(r)$, $Q = (u_\theta/r)\,du_\theta/dr$: positive exactly where the swirl still increases with radius. For the **Lamb-Oseen vortex** $u_\theta = \frac{\Gamma}{2\pi r}\left(1 - e^{-r^2/r_c^2}\right)$, that is inside the radius of peak swirl, $1.1209\,r_c$.

:::example Q on known flows
1. **Elementary flows**: solid-body rotation $Q = +1$, pure strain $Q = -1$, simple shear $Q = 0$.
2. **Lamb-Oseen**, finite differences on a 401 × 401 grid: $Q > 0$ for $r < 1.1211\,r_c$ against the analytic 1.1209 (one grid spacing is 0.02). Outside the core $Q < 0$, although the vorticity there is still up to 10.5 % of its peak: vorticity marks the core too broadly; Q does not.
3. **Taylor-Green vortex** on a periodic $48^3$ box with spectral derivatives: $Q > 0$ in 47.5 % of the box, largest (1.0000) at $(\tfrac12, \tfrac12, 0)\pi$, the centre of a vortex column. The pressure identity holds to round-off: $\max|\nabla^2 p - 2Q| = 1.4\times10^{-13}$.
4. **Deviation from the curriculum:** it suggested a three.js viewer. This course has no WebGL dependency, so the widget is a hand-rolled rotating point projection of the cells above the threshold. A real isosurface would come from marching cubes in ParaView, or from OpenFOAM's `postProcess -func Q` followed by a contour filter.
:::

```python file=qcrit.py
"""Finding vortices with the Q-criterion, Q = (|Omega|^2 - |S|^2)/2: positive where rotation
beats strain. Checked on analytic flows: solid-body rotation, pure strain, simple shear, the
Lamb-Oseen vortex (Q > 0 exactly inside the radius of peak swirl), and the 3D Taylor-Green
vortex, where the pressure Poisson identity lap(p)/rho = 2Q is verified. numpy only."""
import numpy as np

def Q_from_grad(G):
    """G[..., i, j] = du_i/dx_j. Returns Q."""
    S = 0.5 * (G + np.swapaxes(G, -1, -2)); W = 0.5 * (G - np.swapaxes(G, -1, -2))
    return 0.5 * (np.sum(W**2, axis=(-1, -2)) - np.sum(S**2, axis=(-1, -2)))

# 1) elementary 2D flows (uniform gradients)
cases = {"solid-body rotation": [[0, -1], [1, 0]], "pure strain": [[1, 0], [0, -1]], "simple shear": [[0, 1], [0, 0]]}
for name, G in cases.items():
    print(f"{name}: Q = {Q_from_grad(np.array(G, float)):+.3f}")
assert Q_from_grad(np.array(cases["solid-body rotation"], float)) == 1.0
assert Q_from_grad(np.array(cases["pure strain"], float)) == -1.0
assert Q_from_grad(np.array(cases["simple shear"], float)) == 0.0     # vorticity alone does not make a vortex

# 2) Lamb-Oseen vortex, by finite differences on a grid
G0, rc = 1.0, 1.0
n = 401; L = 4.0
x = np.linspace(-L, L, n); h = x[1] - x[0]
X, Y = np.meshgrid(x, x, indexing="ij")
R2 = X**2 + Y**2 + 1e-300
ut = G0 / (2 * np.pi) * (1 - np.exp(-R2 / rc**2)) / R2          # u_theta / r
u, v = -ut * Y, ut * X
G = np.empty((n, n, 2, 2))
G[..., 0, 0], G[..., 0, 1] = np.gradient(u, h, h)
G[..., 1, 0], G[..., 1, 1] = np.gradient(v, h, h)
Q = Q_from_grad(G)
r = np.sqrt(R2)
# along the x axis, where Q changes sign
row = Q[n // 2 + 1:, n // 2]; rr = x[n // 2 + 1:]
k = np.where(row < 0)[0][0]
r0 = rr[k - 1] - row[k - 1] * (rr[k] - rr[k - 1]) / (row[k] - row[k - 1])
# radius of peak swirl: d/dr [(1 - e^{-r^2}) / r] = 0, by Newton
rm = 1.1
for _ in range(50):
    f = 2 * rm**2 * np.exp(-rm**2) - (1 - np.exp(-rm**2))
    df = 4 * rm * np.exp(-rm**2) - 4 * rm**3 * np.exp(-rm**2) - 2 * rm * np.exp(-rm**2)
    rm -= f / df
vort = np.gradient(v, h, axis=0) - np.gradient(u, h, axis=1)
w_out = abs(vort[(r > 1.5) & (r < 3.5)]).max() / abs(vort).max()
print(f"Lamb-Oseen: Q > 0 for r < {r0:.4f} r_c; peak swirl at r = {rm:.4f} r_c; analytic Q = (u/r) du/dr changes sign there")
print(f"  outside the core, Q < 0 although the vorticity is not zero (up to {w_out*100:.1f} % of its peak at 1.5 < r < 3.5)")
assert abs(r0 - rm) < 2 * h
assert np.all(Q[(r > 0.2) & (r < 1.0)] > 0) and np.all(Q[(r > 1.25) & (r < 3.5)] < 0)

# 3) Taylor-Green vortex in 3D: u = (sin x cos y cos z, -cos x sin y cos z, 0), p = (cos 2x + cos 2y)(cos 2z + 2)/16
N = 48
s = np.arange(N) * 2 * np.pi / N
X, Y, Z = np.meshgrid(s, s, s, indexing="ij")
U = [np.sin(X) * np.cos(Y) * np.cos(Z), -np.cos(X) * np.sin(Y) * np.cos(Z), 0 * X]
P = (np.cos(2 * X) + np.cos(2 * Y)) * (np.cos(2 * Z) + 2) / 16
k = np.fft.fftfreq(N, 1 / N)
def d(f, ax):                                     # spectral derivative on the periodic box
    K = [k[:, None, None], k[None, :, None], k[None, None, :]][ax]
    return np.real(np.fft.ifftn(1j * K * np.fft.fftn(f)))
G = np.empty((N, N, N, 3, 3))
for i in range(3):
    for j in range(3):
        G[..., i, j] = d(U[i], j)
Q = Q_from_grad(G)
lapP = sum(d(d(P, a), a) for a in range(3))
err = np.max(abs(lapP - 2 * Q))
print(f"Taylor-Green: Q > 0 in {np.mean(Q > 0)*100:.1f} % of the box; max Q {Q.max():.4f}, min {Q.min():.4f}; max |lap p - 2Q| = {err:.1e}")
assert err < 1e-12
# the strongest cores lie on the lines x, y = pi/2 + n pi in the planes z = 0, pi, where the swirl is largest
i = np.unravel_index(np.argmax(Q), Q.shape)
print(f"  Q is largest at (x, y, z) = ({s[i[0]]/np.pi:.3f}, {s[i[1]]/np.pi:.3f}, {s[i[2]]/np.pi:.3f}) pi")
assert abs(np.cos(s[i[2]])) > 0.99 and abs(np.sin(s[i[0]])) > 0.99 and abs(np.sin(s[i[1]])) > 0.99
```

:::exercise Shear or vortex?
A flow has $\nabla\mathbf u = \begin{bmatrix} 0 & 2 \\ -1 & 0\end{bmatrix}$. Is it a vortex? What if the $-1$ is replaced by $+1$?
---solution---
1. $\mathbf S$ has off-diagonal $\tfrac12(2 - 1) = 0.5$, $\boldsymbol\Omega$ has $\pm\tfrac12(2 + 1) = \pm1.5$. $\|\mathbf S\|^2 = 2 \times 0.25 = 0.5$, $\|\boldsymbol\Omega\|^2 = 2 \times 2.25 = 4.5$, so $Q = \tfrac12(4.5 - 0.5) = 2 > 0$: a vortex, with elliptical streamlines.
2. With $+1$: $\mathbf S$ off-diagonal 1.5, $\boldsymbol\Omega$ off-diagonal 0.5, so $Q = \tfrac12(0.5 - 4.5) = -2$: strain-dominated, hyperbolic streamlines, no vortex.
:::
