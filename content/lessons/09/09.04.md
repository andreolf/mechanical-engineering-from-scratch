Almost every strength number you'll use, from yield strength in a datasheet to the allowable stress in a code, starts with one test: pull a standard bar until it breaks and record the load and the stretch. Reading that curve properly is a core skill.

## Engineering and true stress

A round bar of original area $A_0$ and gauge length $L_0$ carries load $P$ and stretches by $\Delta L$.

- **Engineering** stress and strain use the original dimensions: $s = P/A_0$ and $e = \Delta L/L_0$.
- **True** stress and strain use the current ones: $\sigma = P/A$ and $\varepsilon = \ln(L/L_0)$.

Plastic deformation keeps the volume constant, $A L = A_0L_0$, so before necking

$$
\sigma = s(1 + e), \qquad \varepsilon = \ln(1 + e) .
$$

## Reading the curve

1. **Young's modulus** $E$: the slope of the straight initial part. Fit a line well inside the elastic region, and use its zero crossing to correct for slack in the grips.
2. **0.2 % offset yield** $R_{p0.2}$: most metals have no sharp yield point. Draw a line of slope $E$ starting at 0.2 % strain; where it cuts the curve is the yield strength.
3. **Ultimate tensile strength** (UTS): the maximum engineering stress.
4. **Elongation**: the strain at fracture (ductility).

## Necking: the Considère criterion

The load is $P = \sigma A$. As the bar stretches, $\sigma$ rises (work hardening) but $A$ falls. The load peaks when $dP = 0$:

$$
\frac{d\sigma}{d\varepsilon} = \sigma .
$$

Past that point any thinner spot carries more stress than its hardening can resist, and a neck forms. For a material with $\sigma = K\varepsilon^n$ (Hollomon), necking starts at a true strain of exactly $\varepsilon = n$, with

$$
\text{UTS} = K\,n^n e^{-n} .
$$

So the hardening exponent $n$ tells you how far a sheet can stretch evenly, which matters for forming car panels (09.22).

:::example Processing a raw test
A round aluminium-alloy bar, $d_0 = 6$ mm ($A_0 = 28.274$ mm²), extensometer gauge 30 mm. The data are synthetic so the answer is known: $E = 69$ GPa, $\sigma = 380\,\varepsilon_p^{0.06}$ MPa, with 5 N of load-cell noise and 0.5 µm of extensometer noise, 4000 points up to necking.

1. Linear fit between 10 % and 40 % of the maximum load: $E = 68.69$ GPa.
2. 0.2 % offset line, with linear interpolation at the crossing: yield 259.90 MPa. The exact value is $380\cdot0.002^{0.06} = 261.73$ MPa, so the error is 0.7 %, inside the 1 % target.
3. UTS 301.16 MPa against Considère's $Kn^ne^{-n} = 302.28$ MPa. Uniform elongation 6.55 % against 6.68 % predicted (the top of the curve is very flat, so noise blurs where the maximum is).
4. At necking the true stress, 320.98 MPa, equals the hardening slope $nK\varepsilon^{n-1}$ = 320.98 MPa.
:::

```python file=tensile.py
"""The tensile test: process raw load-extension data into E, 0.2 % offset yield, UTS and elongation."""
import math
import numpy as np


def synthetic_test(E=69e3, K=380.0, n=0.06, d0=6.0, L0=30.0, seed=3):
    """Load (N) and extension (mm) for a round bar, from sigma_true = K eps_p^n with an elastic part,
    up to necking at true strain n (Considere). Units: MPa, mm, N."""
    s_true = np.linspace(1.0, K * n**n * 1.0, 4000)            # true stress up to the necking point
    eps_true = s_true / E + (s_true / K)**(1 / n)
    keep = eps_true <= n + s_true / E
    s_true, eps_true = s_true[keep], eps_true[keep]
    e_eng = np.exp(eps_true) - 1; s_eng = s_true / (1 + e_eng)
    A0 = math.pi * d0**2 / 4
    rng = np.random.default_rng(seed)
    load = s_eng * A0 + rng.normal(0, 5.0, s_eng.size)            # 5 N load-cell noise
    ext = e_eng * L0 + rng.normal(0, 0.0005, s_eng.size)          # 0.5 um extensometer noise
    return load, ext, A0, L0


def process(load, ext, A0, L0):
    s = load / A0; e = ext / L0
    smax = s.max()
    sel = (s > 0.1 * smax) & (s < 0.4 * smax)                     # clearly elastic window
    E, b = np.polyfit(e[sel], s[sel], 1)
    e0 = -b / E                                                   # toe correction: where the fitted line crosses zero
    offset = s - E * (e - e0 - 0.002)                             # positive left of the 0.2 % offset line
    i = np.argmax(offset < 0)
    t = offset[i - 1] / (offset[i - 1] - offset[i])
    sy = s[i - 1] + t * (s[i] - s[i - 1])
    return E, sy, smax, e[np.argmax(s)] - e0


if __name__ == "__main__":
    E_true, K, n = 69e3, 380.0, 0.06                               # an aluminium alloy
    load, ext, A0, L0 = synthetic_test(E_true, K, n)
    E, sy, uts, eu = process(load, ext, A0, L0)
    sy_true = K * 0.002**n
    uts_true = K * n**n * math.exp(-n)
    print(f"specimen d0 = 6 mm, A0 = {A0:.3f} mm^2, gauge 30 mm; {len(load)} data points")
    print(f"E = {E/1e3:.2f} GPa (input {E_true/1e3:.0f})")
    print(f"0.2 % offset yield {sy:.2f} MPa (exact K 0.002^n = {sy_true:.2f})")
    print(f"UTS {uts:.2f} MPa (Considere prediction K n^n e^-n = {uts_true:.2f}), uniform elongation {eu*100:.2f} % (Considere, elastic part included: {(math.exp(n + K*n**n/E_true)-1)*100:.2f} %)")
    assert abs(E / E_true - 1) < 0.02 and abs(sy / sy_true - 1) < 0.01 and abs(uts / uts_true - 1) < 0.005
    # true stress at the UTS point equals the hardening slope there (Considere)
    eps = n; s_t = K * eps**n; slope = n * K * eps**(n - 1)
    print(f"at necking: true stress {s_t:.2f} MPa = d sigma / d eps {slope:.2f} MPa")
    assert abs(s_t - slope) < 1e-9
```

:::exercise A steel test
A steel bar of 10 mm diameter yields (0.2 % offset) at a load of 27.5 kN and reaches a maximum of 36.1 kN at an extension of 9.0 mm over a 50 mm gauge. Find the yield strength, the UTS, and the true stress and true strain at the UTS.
---solution---
1. $A_0 = \pi\cdot10^2/4 = 78.54$ mm². Yield $= 27500/78.54 = 350.1$ MPa.
2. UTS $= 36100/78.54 = 459.6$ MPa.
3. $e = 9/50 = 0.18$. True stress $= 459.6\cdot1.18 = 542.3$ MPa; true strain $= \ln1.18 = 0.1655$.
4. By Considère that true strain is about the hardening exponent: $n \approx 0.17$, typical for mild steel.
:::
