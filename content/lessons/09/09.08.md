A gear has to be hard on the surface to resist wear, but tough in the core so its teeth don't snap. One way to get both is to pack a low-carbon steel gear in a carbon-rich atmosphere at about 900 °C for a few hours. Carbon atoms wander in from the surface, giving a hard **case** once the gear is quenched. How deep they get is a diffusion problem.

## Fick's laws

Atoms jump randomly between lattice sites. Where there are more atoms on one side than the other, more jump down the gradient than up. **Fick's first law** gives the flux:

$$
J = -D\frac{\partial C}{\partial x} .
$$

Conservation of atoms then gives **Fick's second law**, which is the same equation as heat conduction (Phase 07):

$$
\frac{\partial C}{\partial t} = D\frac{\partial^2 C}{\partial x^2} .
$$

## Diffusivity and temperature

Each jump needs an activation energy $Q$, so $D$ follows an Arrhenius law:

$$
D = D_0\, e^{-Q/RT} .
$$

For carbon in austenite, $D_0 = 2.3\times10^{-5}$ m²/s and $Q = 148$ kJ/mol. A 100 °C rise roughly triples $D$.

## The carburising solution

A thick part, initially at carbon content $C_0$, whose surface is held at $C_s$ from time zero, has the profile

$$
C(x,t) = C_s - (C_s - C_0)\,\operatorname{erf}\!\left(\frac{x}{2\sqrt{Dt}}\right) .
$$

The error function rises from 0 to almost 1 as its argument goes from 0 to 2. Any particular concentration sits at a fixed value of $x/\sqrt{Dt}$, so

$$
x \propto \sqrt{Dt} .
$$

Doubling the case depth takes four times as long. The quantity $\sqrt{Dt}$ is the diffusion length. It's the quick estimate for how far atoms get in a given time, in welding, semiconductor doping and corrosion alike.

:::example Carburising a gear
Surface 1.0 % C, steel 0.2 % C, case defined at 0.4 % C.

1. At 927 °C (1200.15 K): $D = 2.3\times10^{-5}\,e^{-148000/(8.314\cdot1200.15)} = 8.32\times10^{-12}$ m²/s.
2. We need $\operatorname{erf}(z) = (1.0 - 0.4)/(1.0 - 0.2) = 0.75$, so $z = 0.8134$.
3. After 4 h: $x = 2\cdot0.8134\sqrt{8.32\times10^{-12}\cdot14400} = 0.563$ mm.
4. At 1027 °C, $D = 2.60\times10^{-11}$ m²/s, and the same depth takes only 1.28 h.
5. An explicit finite-difference solution of Fick's second law matches the erf profile to $3.4\times10^{-5}$ % C everywhere.
:::

```python file=diffusion.py
"""Diffusion: Arrhenius diffusivity, the erf solution for carburising, checked against a finite-difference solution of Fick's second law."""
import math
import numpy as np

R = 8.314
D0, Q = 2.3e-5, 148e3        # carbon in austenite (FCC iron): m^2/s, J/mol


def D(T):
    return D0 * math.exp(-Q / (R * T))


def erfinv(y):
    """Inverse error function by Newton's method on math.erf."""
    x = 0.0
    for _ in range(50):
        x -= (math.erf(x) - y) / (2 / math.sqrt(math.pi) * math.exp(-x * x))
    return x


def profile(x, t, T, Cs, C0):
    """Carbon content at depth x (m) after time t (s), surface held at Cs, initial C0."""
    return Cs - (Cs - C0) * math.erf(x / (2 * math.sqrt(D(T) * t)))


def case_depth(t, T, Cs, C0, Cx):
    """Depth where the carbon content has fallen to Cx."""
    z = erfinv((Cs - Cx) / (Cs - C0))
    return 2 * z * math.sqrt(D(T) * t)


def fdm(t, T, Cs, C0, L=3e-3, n=301):
    """Explicit finite differences for dC/dt = D d2C/dx2 on [0, L]; returns grid and profile."""
    x = np.linspace(0, L, n); dx = x[1] - x[0]; d = D(T)
    dt = 0.4 * dx * dx / d; steps = int(math.ceil(t / dt)); dt = t / steps
    c = np.full(n, C0); c[0] = Cs
    for _ in range(steps):
        c[1:-1] += d * dt / dx**2 * (c[2:] - 2 * c[1:-1] + c[:-2])
    return x, c


if __name__ == "__main__":
    T = 927 + 273.15
    print(f"D at 927 C: {D(T):.3e} m^2/s; at 1027 C: {D(1300.15):.3e} m^2/s")
    t = 4 * 3600
    xc = case_depth(t, T, 1.0, 0.2, 0.4)
    print(f"case depth to 0.4 %C after 4 h at 927 C: {xc*1e3:.3f} mm")
    assert abs(profile(xc, t, T, 1.0, 0.2) - 0.4) < 1e-9
    # depth grows with sqrt(time): 4x the time, 2x the depth
    assert abs(case_depth(4 * t, T, 1.0, 0.2, 0.4) / xc - 2) < 1e-12
    hours_hot = (xc / (2 * erfinv(0.75))) ** 2 / D(1300.15) / 3600
    print(f"same depth at 1027 C takes {hours_hot:.2f} h")
    x, c = fdm(t, T, 1.0, 0.2)
    exact = np.array([profile(xi, t, T, 1.0, 0.2) for xi in x])
    err = np.max(np.abs(c - exact))
    print(f"finite differences vs erf: max difference {err:.2e} wt% C")
    assert err < 2e-3
    for xm in (0.25, 0.5, 1.0, 1.5):
        print(f"  {xm} mm: {profile(xm*1e-3, t, T, 1.0, 0.2):.3f} %C")
```

:::exercise A deeper case
How long at 927 °C does the gear need for a case depth of 1.0 mm?
---solution---
1. Depth goes as $\sqrt t$, so $t = 4\text{ h}\times(1.0/0.563)^2$.
2. $(1.0/0.563)^2 = 3.155$, giving 12.6 h.
3. That's why deep cases are expensive, and why carburising is pushed to higher temperatures when the furnace and grain growth allow.
:::
