Test thirty bamboo culms in compression and you might get anything from 40 to 75 MPa. Same species, same plantation, same age. Natural materials vary far more than steel. So what strength do you design with? Not the average: half the culms would be weaker. Structural codes for timber and bamboo (Eurocode 5, ISO 22156) use a **characteristic value**, a low percentile estimated from tests, then reduce it further for load duration, moisture and safety.

## The 5th percentile

The characteristic strength $f_k$ is the value that only 5 % of the material falls below. If strengths are normally distributed with mean $\mu$ and standard deviation $\sigma$,

$$
f_{0.05} = \mu - 1.645\,\sigma .
$$

Strength data are often skewed (they can't go below zero), so a **lognormal** distribution often fits better: take logs, apply the same formula, transform back. You can also rank the data and read off the 5th percentile directly, which needs plenty of tests.

## Small samples

With $n$ tests you only have estimates $m$ and $s$. The estimated 5th percentile is itself uncertain, and about half the time it would come out above the true value, which is unsafe. Codes therefore reduce it. ISO 12122 and ISO 22157 use a factor of this form:

$$
f_k = (m - 1.645\,s)\left(1 - \frac{2.7\,s/m}{\sqrt n}\right) .
$$

Larger scatter and fewer tests reduce $f_k$ more, which rewards testing.

## From characteristic to design value

$$
f_d = \frac{k_\text{mod}\,f_k}{\gamma_M} ,
$$

with $k_\text{mod}$ for load duration and moisture (natural fibres creep and lose strength under long-term load, 09.09) and the partial factor $\gamma_M$ (about 1.3 for timber) for model and material uncertainty. The design check is then $\sigma_\text{design} \le f_d$, with the loads themselves increased by their own partial factors.

:::example Thirty bamboo culms
Simulated lognormal strengths, true mean 55 MPa, CoV 15 %; true 5th percentile 42.6 MPa.

1. Sample: mean 56.7 MPa, $s = 9.1$ MPa, CoV 16.0 %.
2. 5th-percentile estimates: normal 41.8 MPa, ranked 42.0, lognormal 42.9.
3. With the sample-size factor: $f_k = 41.8\,(1 - 2.7\cdot0.160/\sqrt{30}) = 38.5$ MPa.
4. Design strength with $k_\text{mod} = 0.8$ and $\gamma_M = 1.3$: $0.8\cdot38.5/1.3 = 23.7$ MPa, less than half the mean.
5. Repeating the 30-culm test 20 000 times: the plain $m - 1.645s$ lands at or below the true 5th percentile only 68 % of the time. With the factor, 96 % of the time.
:::

```python file=charvalue.py
"""Design values for a natural material: the 5th-percentile characteristic strength of bamboo from test data, a confidence adjustment for small samples, and a check by simulation."""
import math
import numpy as np

MEAN, COV = 55.0, 0.15                         # true compressive strength of the culms, MPa
SIG_LN = math.sqrt(math.log(1 + COV**2)); MU_LN = math.log(MEAN) - SIG_LN**2 / 2
TRUE_P5 = math.exp(MU_LN - 1.6449 * SIG_LN)


def char_value(x):
    """ISO 12122-style: normal 5th percentile reduced for sample size, f_k = (m - 1.645 s)(1 - 2.7 (s/m)/sqrt(n))."""
    m, s, n = x.mean(), x.std(ddof=1), len(x)
    return (m - 1.645 * s) * (1 - 2.7 * (s / m) / math.sqrt(n)), m - 1.645 * s


def nonparam_p5(x):
    xs = np.sort(x); pos = 0.05 * (len(xs) + 1) - 1
    i = int(math.floor(pos)); f = pos - i
    return xs[max(i, 0)] if i < 0 else xs[i] + f * (xs[i + 1] - xs[i])


if __name__ == "__main__":
    rng = np.random.default_rng(21)
    x = rng.lognormal(MU_LN, SIG_LN, 30)
    fk, p5 = char_value(x)
    print(f"30 culms: mean {x.mean():.1f} MPa, s {x.std(ddof=1):.1f}, CoV {x.std(ddof=1)/x.mean()*100:.1f} %")
    print(f"5th percentile: normal {p5:.1f}, ranked {nonparam_p5(x):.1f}, lognormal {math.exp(np.log(x).mean()-1.645*np.log(x).std(ddof=1)):.1f}; true {TRUE_P5:.1f} MPa")
    print(f"characteristic value with the sample-size factor: {fk:.1f} MPa")
    kmod, gm = 0.8, 1.3
    print(f"design strength k_mod f_k / gamma_M = {kmod*fk/gm:.1f} MPa")
    # how often does each estimate land at or below the true 5th percentile (i.e. is safe)?
    sims = rng.lognormal(MU_LN, SIG_LN, (20000, 30))
    m, s = sims.mean(axis=1), sims.std(axis=1, ddof=1)
    plain = m - 1.645 * s; adj = plain * (1 - 2.7 * (s / m) / math.sqrt(30))
    c_plain, c_adj = np.mean(plain <= TRUE_P5), np.mean(adj <= TRUE_P5)
    print(f"confidence of being safe: plain {c_plain*100:.0f} %, adjusted {c_adj*100:.0f} %")
    assert c_adj > 0.75 and c_adj > c_plain
    # z for 5 %
    assert abs(0.5 * (1 + math.erf(-1.6449 / math.sqrt(2))) - 0.05) < 1e-4
```

:::exercise Ten culms only
A builder tests 10 culms: mean 60 MPa, $s = 12$ MPa. Find $f_k$ and the design strength ($k_\text{mod} = 0.8$, $\gamma_M = 1.3$).
---solution---
1. $m - 1.645s = 60 - 19.74 = 40.26$ MPa.
2. Factor: $1 - 2.7\cdot0.2/\sqrt{10} = 1 - 0.1708 = 0.8292$.
3. $f_k = 40.26\cdot0.8292 = 33.4$ MPa; $f_d = 0.8\cdot33.4/1.3 = 20.5$ MPa.
4. Testing 30 culms with the same mean and scatter would give $f_k = 40.26\,(1 - 0.0986) = 36.3$ MPa: more tests buy a higher design value.
:::
