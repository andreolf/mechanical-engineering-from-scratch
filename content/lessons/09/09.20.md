A CNC mill doesn't know what a pocket is. It follows a list of straight lines and arcs, one per line of a text file, in a language called **G-code** that dates back to the 1950s. CAM software turns your CAD model into that list. Writing a simple one by hand teaches you what the software is doing, and how to spot a toolpath that would break a tool or leave material behind.

## G-code basics

Each line is a command with coordinates:

| Code | Meaning |
|---|---|
| `G21` / `G90` | millimetres / absolute coordinates |
| `G0 X.. Y.. Z..` | rapid move (not cutting) |
| `G1 X.. Y.. Z.. F..` | straight cut at feed F (mm/min) |
| `G2` / `G3` | clockwise / anticlockwise arc |
| `M3 S..` / `M5` | spindle on at S rev/min / off |
| `M30` | end of program |

The coordinates are those of the **tool centre** (with no cutter compensation), so a toolpath must stay one tool radius away from every wall.

## Pocketing

To clear a rectangular pocket:

1. **Step down** in layers of depth $a_p$, limited by the tool and machine rigidity.
2. In each layer, **zigzag** at a **stepover** $a_e$, usually 40 to 60 % of the diameter for roughing. If $a_e > D$, ridges are left between passes.
3. Finish with a **contour pass** along the walls, one radius in.

A round tool can't cut a sharp inside corner: each corner keeps a radius equal to the tool radius. The uncut area in the four corners is

$$
4\left(r^2 - \frac{\pi r^2}{4}\right) .
$$

If the drawing needs sharp corners, you'll need EDM or a redesign. Better to give every inside corner a radius slightly larger than the tool's.

Machining time is roughly path length divided by feed, times the number of layers, plus plunges and rapids.

:::example A 40 × 25 × 6 mm pocket
8 mm end mill, stepover 4 mm (50 %), step-down 2 mm, feed 600 mm/min, plunge 150 mm/min.

1. Each layer: zigzag rows at y = 4, 8, 12, 16, 20 and 21 mm between x = 4 and 36 mm, then the contour. 307.0 mm of cutting.
2. Simulated on a 0.1 mm grid: the path clears 98.624 % of the pocket, and the tool centre never comes closer than 4 mm to a wall (zero intrusion).
3. The uncut 1.376 % matches the four corners, $4(16 - 4\pi)/1000 = 1.373$ %, within the grid resolution.
4. Three layers: 61 lines of G-code and about 1.58 min of feed motion.
:::

```python file=pocket.py
"""CNC pocketing: generate a zigzag-plus-contour toolpath and G-code for a rectangular pocket, then check by simulation that it clears every point without gouging the walls."""
import math
import numpy as np

W, H, DEPTH = 40.0, 25.0, 6.0      # pocket size and depth, mm (corner at the origin)
D_TOOL = 8.0                        # flat end mill diameter
STEPOVER, STEPDOWN = 0.5 * D_TOOL, 2.0
FEED, PLUNGE = 600.0, 150.0         # mm/min


def layer_path():
    """Tool-centre path for one depth: zigzag inside the finishing contour, then the contour itself."""
    r = D_TOOL / 2
    x0, x1, y0, y1 = r, W - r, r, H - r
    pts, y, k = [], y0, 0
    while y < y1 - 1e-9:
        pts += [(x0, y), (x1, y)] if k % 2 == 0 else [(x1, y), (x0, y)]
        y = min(y + STEPOVER, y1); k += 1
    pts += [(x0, y1), (x1, y1)] if k % 2 == 0 else [(x1, y1), (x0, y1)]
    pts += [(x0, y1), (x0, y0), (x1, y0), (x1, y1), (x0, y1)]    # finishing contour
    return pts


def gcode():
    lines = ["G21 G90 G17", "G0 Z5", f"G0 X{D_TOOL/2:.3f} Y{D_TOOL/2:.3f}", "M3 S8000"]
    nlayers = math.ceil(DEPTH / STEPDOWN)
    for i in range(1, nlayers + 1):
        z = -min(i * STEPDOWN, DEPTH)
        path = layer_path()
        lines.append(f"G0 X{path[0][0]:.3f} Y{path[0][1]:.3f}")
        lines.append(f"G1 Z{z:.3f} F{PLUNGE:.0f}")
        lines += [f"G1 X{x:.3f} Y{y:.3f} F{FEED:.0f}" for x, y in path[1:]]
    lines += ["G0 Z5", "M5", "M30"]
    return lines


def simulate(path, res=0.1):
    """Mark every grid point within the tool radius of the path; return the fraction of the pocket cleared and the deepest wall intrusion."""
    xs = np.arange(res / 2, W, res); ys = np.arange(res / 2, H, res); X, Y = np.meshgrid(xs, ys)
    cut = np.zeros_like(X, dtype=bool); r = D_TOOL / 2
    for (ax, ay), (bx, by) in zip(path[:-1], path[1:]):
        dx, dy = bx - ax, by - ay; L2 = dx * dx + dy * dy
        t = np.clip(((X - ax) * dx + (Y - ay) * dy) / L2, 0, 1) if L2 > 0 else 0
        cut |= (X - ax - t * dx) ** 2 + (Y - ay - t * dy) ** 2 <= r * r + 1e-9
    gouge = max(max(r - min(x, W - x, y, H - y) for x, y in path), 0.0)
    return cut.mean(), gouge


if __name__ == "__main__":
    path = layer_path()
    L = sum(math.dist(a, b) for a, b in zip(path[:-1], path[1:]))
    frac, gouge = simulate(path)
    print(f"one layer: {len(path)} points, {L:.1f} mm of cutting; cleared {frac*100:.3f} % of the pocket area, wall intrusion {gouge:.3f} mm")
    assert gouge < 1e-9
    # corners of a rectangular pocket cut with a round tool keep a radius = tool radius: uncut area is 4 (r^2 - pi r^2 / 4)
    r = D_TOOL / 2; corner = 4 * (r * r - math.pi * r * r / 4) / (W * H)
    print(f"expected uncut corner fraction {corner*100:.3f} %")
    assert abs((1 - frac) - corner) < 0.002
    g = gcode()
    nlay = math.ceil(DEPTH / STEPDOWN)
    t_min = nlay * (L / FEED + STEPDOWN / PLUNGE)
    print(f"{len(g)} G-code lines, {nlay} layers, about {t_min:.2f} min of feed motion")
    print("\n".join(g[:9]))
```

:::exercise Time for a deeper pocket
The same pocket is now 15 mm deep, cut at 2.5 mm per layer. How many layers, and roughly how many minutes of feed motion?
---solution---
1. Layers: $15/2.5 = 6$.
2. Each layer: $307/600 = 0.512$ min of cutting plus $2.5/150 = 0.017$ min of plunge, so 0.528 min.
3. Total: $6\cdot0.528 = 3.17$ min, plus rapids.
:::
