A carbon-fibre bike frame weighs under a kilogram and is stiffer than steel, but drop it on a sharp edge and it can crack where the fibres weren't pointing. A composite is two materials combined: strong, stiff fibres (carbon, glass, aramid, flax) held in place by a softer matrix (epoxy, polyester). The fibres carry the load; the matrix transfers it between fibres and protects them. The catch is that the result is only stiff in the directions the fibres point.

## Rule of mixtures

With fibre volume fraction $V_f$, loading **along** the fibres strains both constituents equally (springs in parallel):

$$
E_1 = V_f E_f + (1 - V_f) E_m \quad\text{(Voigt)} .
$$

Loading **across** the fibres puts them in series, so the stresses are equal and the soft matrix dominates:

$$
\frac{1}{E_2} = \frac{V_f}{E_f} + \frac{1 - V_f}{E_m} \quad\text{(Reuss)} .
$$

These two are upper and lower bounds on the stiffness of any mixture with these volume fractions.

## Off-axis loading

Load a unidirectional ply at angle $\theta$ to its fibres and the modulus falls off fast:

$$
\frac{1}{E_x} = \frac{\cos^4\theta}{E_1} + \left(\frac{1}{G_{12}} - \frac{2\nu_{12}}{E_1}\right)\sin^2\theta\cos^2\theta + \frac{\sin^4\theta}{E_2} .
$$

## Laminates

Real parts stack plies at different angles. **Classical lamination theory** rotates each ply's stiffness matrix to the laminate axes and adds them, weighted by thickness. A symmetric stack such as $[0/{+45}/{-45}/90]_s$ is **quasi-isotropic**: the same in-plane stiffness in every direction, at roughly a third of the unidirectional value. Designers choose layups so fibres follow the loads, for example ±45° plies in a tube to carry torsion.

:::example A carbon/epoxy ply and laminate
Fibre: $E_f = 230$ GPa, $G_f = 15$ GPa, $\nu_f = 0.2$. Epoxy: $E_m = 3.5$ GPa, $G_m = 1.3$ GPa, $\nu_m = 0.35$. $V_f = 0.6$.

1. $E_1 = 0.6\cdot230 + 0.4\cdot3.5 = 139.4$ GPa. $E_2 = 1/(0.6/230 + 0.4/3.5) = 8.55$ GPa. $G_{12} = 2.88$ GPa (Reuss), $\nu_{12} = 0.26$.
2. Off-axis: 103.5 GPa at 5°, 35.4 at 15°, 13.2 at 30°, 8.5 at 45°. Just 15° of misalignment costs three quarters of the stiffness.
3. Rotating the stiffness matrix numerically gives the same $E_x$ as the closed form to $10^{-6}$.
4. Quasi-isotropic $[0/45/{-45}/90]_s$: 51.58 GPa at 0°, 22.5°, 45° and 70°, identical to $10^{-6}$.
5. With density $0.6\cdot1800 + 0.4\cdot1200 = 1560$ kg/m³, its specific stiffness is 33.1 MJ/kg against 25.9 for aluminium. Even the quasi-isotropic layup wins, and tailored layups win by far more.
:::

```python file=composites.py
"""Composites: rule of mixtures bounds, off-axis stiffness of a unidirectional ply, and a quasi-isotropic laminate from classical lamination theory."""
import math
import numpy as np


def voigt(Ef, Em, Vf):
    return Vf * Ef + (1 - Vf) * Em          # loading along the fibres: equal strain


def reuss(Ef, Em, Vf):
    return 1 / (Vf / Ef + (1 - Vf) / Em)    # loading across the fibres: equal stress


def ply(Ef=230e9, Em=3.5e9, Gf=15e9, Gm=1.3e9, nuf=0.2, num=0.35, Vf=0.6):
    E1 = voigt(Ef, Em, Vf); E2 = reuss(Ef, Em, Vf); G12 = reuss(Gf, Gm, Vf); nu12 = Vf * nuf + (1 - Vf) * num
    return E1, E2, G12, nu12


def Q(E1, E2, G12, nu12):
    """Reduced stiffness of a ply in its own axes (plane stress)."""
    nu21 = nu12 * E2 / E1; d = 1 - nu12 * nu21
    return np.array([[E1 / d, nu12 * E2 / d, 0], [nu12 * E2 / d, E2 / d, 0], [0, 0, G12]])


def Qbar(Qm, th):
    """Rotate the ply stiffness by angle th (rad) with the strain transformation (engineering shear)."""
    c, s = math.cos(th), math.sin(th)
    T = np.array([[c * c, s * s, 2 * c * s], [s * s, c * c, -2 * c * s], [-c * s, c * s, c * c - s * s]])
    R = np.diag([1, 1, 2.0])
    return np.linalg.inv(T) @ Qm @ R @ T @ np.linalg.inv(R)


def Ex_offaxis(E1, E2, G12, nu12, th):
    c, s = math.cos(th), math.sin(th)
    return 1 / (c**4 / E1 + (1 / G12 - 2 * nu12 / E1) * s * s * c * c + s**4 / E2)


def laminate_Ex(angles_deg, props, t_ply=0.125e-3, load_deg=0.0):
    """Effective in-plane modulus of a symmetric laminate along direction load_deg."""
    Qm = Q(*props); A = sum(Qbar(Qm, math.radians(a)) * t_ply for a in angles_deg); h = t_ply * len(angles_deg)
    Ar = Qbar(A / h, math.radians(-load_deg)) if load_deg else A / h
    return 1 / np.linalg.inv(Ar)[0, 0]


if __name__ == "__main__":
    E1, E2, G12, nu12 = ply()
    print(f"carbon/epoxy ply, 60 % fibre: E1 = {E1/1e9:.1f} GPa, E2 = {E2/1e9:.2f} GPa, G12 = {G12/1e9:.2f} GPa, nu12 = {nu12:.2f}")
    for d in (0, 5, 15, 30, 45, 90):
        print(f"  load at {d:2d} deg to the fibres: E = {Ex_offaxis(E1, E2, G12, nu12, math.radians(d))/1e9:.1f} GPa")
    # the matrix rotation agrees with the closed-form off-axis modulus
    for d in (10, 37, 60):
        Ex = 1 / np.linalg.inv(Qbar(Q(E1, E2, G12, nu12), math.radians(d)))[0, 0]
        assert abs(Ex - Ex_offaxis(E1, E2, G12, nu12, math.radians(d))) < 1e-6 * Ex
    qi = [0, 45, -45, 90, 90, -45, 45, 0]
    Eqi = [laminate_Ex(qi, (E1, E2, G12, nu12), load_deg=a) for a in (0, 22.5, 45, 70)]
    print("quasi-isotropic [0/45/-45/90]s: E = " + ", ".join(f"{e/1e9:.2f}" for e in Eqi) + " GPa at 0, 22.5, 45, 70 deg")
    assert max(Eqi) - min(Eqi) < 1e-6 * Eqi[0]
    rho = 0.6 * 1800 + 0.4 * 1200
    print(f"density {rho:.0f} kg/m^3; specific stiffness {Eqi[0]/rho/1e6:.1f} vs aluminium {70e9/2700/1e6:.1f} MJ/kg")
    assert reuss(230e9, 3.5e9, 0.6) < voigt(230e9, 3.5e9, 0.6)
```

:::exercise Glass fibre
E-glass fibres ($E_f = 72$ GPa) in polyester ($E_m = 3$ GPa) at $V_f = 0.5$. Find $E_1$ and $E_2$.
---solution---
1. $E_1 = 0.5\cdot72 + 0.5\cdot3 = 37.5$ GPa.
2. $E_2 = 1/(0.5/72 + 0.5/3) = 1/(0.006944 + 0.16667) = 5.76$ GPa.
3. The ratio is 6.5, smaller than for carbon (16), because glass fibres are less stiff relative to the matrix.
:::
