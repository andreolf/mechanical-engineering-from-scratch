Run a lathe faster and parts come off sooner, but the tool wears out much faster. A carbide insert might last an hour at 150 m/min and two minutes at 350. Every tool change stops the machine and costs a new cutting edge. So there's a cutting speed that makes each part as cheap as possible, and it isn't the fastest one.

## Taylor's equation

In 1907 F. W. Taylor, after years of tests on steel, found that tool life $T$ (minutes until the flank wear reaches a limit) and cutting speed $V$ follow

$$
V T^n = C .
$$

$C$ is the speed that gives a one-minute life. The exponent $n$ depends mostly on the tool material: about 0.1 for high-speed steel, 0.25 for carbide, 0.4 to 0.6 for ceramics. Because $T = (C/V)^{1/n}$, doubling the speed with $n = 0.25$ cuts tool life by $2^4 = 16$.

On log-log axes $\ln V = \ln C - n\ln T$ is a straight line, so a handful of wear tests fixes both constants.

## The economic speed

Cost per part has three pieces:

- loading and unloading: $C_o t_l$;
- machining time: $C_o t_m$, with $t_m \propto 1/V$;
- tool cost: each edge costs $C_t$ plus the machine time $t_{ch}$ to change it, and $t_m/T$ edges are used per part.

$$
c = C_o t_l + C_o t_m + (C_o t_{ch} + C_t)\frac{t_m}{T} .
$$

Setting $dc/dV = 0$ gives the tool life at minimum cost,

$$
T_\text{opt} = \left(\frac1n - 1\right)\left(t_{ch} + \frac{C_t}{C_o}\right) ,
$$

and $V_\text{opt} = C/T_\text{opt}^{\,n}$. For maximum production rate, drop the $C_t$ term. That gives a shorter life and higher speed.

:::example Turning a steel shaft
Carbide with $n = 0.25$, $C = 400$ m/min. Shaft 60 mm diameter, 200 mm long, feed 0.25 mm/rev. Machine plus operator 1.5 USD/min, edge 6 USD, change 2 min, loading 1 min.

1. Five synthetic wear tests from 150 m/min (48.6 min) to 350 m/min (1.8 min), with 5 % scatter. Fit: $n = 0.258$, $C = 406$ m/min.
2. $T_\text{opt} = (1/0.25 - 1)(2 + 6/1.5) = 3\cdot6 = 18.0$ min, so $V_\text{opt} = 400/18^{0.25} = 194.2$ m/min.
3. A numerical scan of the cost curve gives the same 194.2 m/min, at 3.053 USD per part.
4. For maximum production rate: $T = 3\cdot2 = 6.0$ min at 255.6 m/min.
:::

```python file=taylor.py
"""Tool life: fit Taylor's equation V T^n = C to wear tests and find the cutting speed that minimises cost per part."""
import math
import numpy as np

N_TRUE, C_TRUE = 0.25, 400.0      # carbide on steel: exponent and speed (m/min) for a 1 minute life


def life(V, n=N_TRUE, C=C_TRUE):
    return (C / V) ** (1 / n)


def fit(V, T):
    """log V = log C - n log T."""
    slope, icpt = np.polyfit(np.log(T), np.log(V), 1)
    return -slope, math.exp(icpt)


def cost_per_part(V, n, C, Lc=180.0, D=60.0, L=200.0, f=0.25, Co=1.5, Ct=6.0, tch=2.0, tl=1.0):
    """Turning one pass: machining time from speed, tool cost shared per life.
    Co: machine and operator cost per minute, Ct: cost per cutting edge, tch: minutes to change an edge, tl: load time."""
    tm = math.pi * D * L / (1000 * V * f)          # minutes cutting (D, L in mm, V in m/min, f in mm/rev)
    T = life(V, n, C)
    return Co * tl + Co * tm + (Co * tch + Ct) * tm / T


if __name__ == "__main__":
    rng = np.random.default_rng(5)
    V = np.array([150, 200, 250, 300, 350.0])
    T = np.array([life(v) for v in V]) * np.exp(rng.normal(0, 0.05, len(V)))
    for v, t in zip(V, T):
        print(f"  {v:.0f} m/min: tool lasts {t:.1f} min")
    n, C = fit(V, T)
    print(f"fit: n = {n:.3f}, C = {C:.0f} m/min (true 0.25, 400)")
    assert abs(n - N_TRUE) < 0.03 and abs(C / C_TRUE - 1) < 0.1
    # minimum cost: T_opt = (1/n - 1)(tch + Ct/Co)
    Topt = (1 / N_TRUE - 1) * (2.0 + 6.0 / 1.5)
    Vopt = C_TRUE / Topt ** N_TRUE
    Vs = np.linspace(100, 400, 30001); cs = [cost_per_part(v, N_TRUE, C_TRUE) for v in Vs]
    Vnum = Vs[int(np.argmin(cs))]
    print(f"minimum cost: tool life {Topt:.1f} min at {Vopt:.1f} m/min (numerical {Vnum:.1f}); cost {min(cs):.3f} USD per part")
    assert abs(Vnum - Vopt) < 0.02
    Tmax = (1 / N_TRUE - 1) * 2.0
    print(f"maximum production rate: tool life {Tmax:.1f} min at {C_TRUE / Tmax ** N_TRUE:.1f} m/min")
    print(f"doubling speed from 150 to 300 m/min cuts life by {2**(1/N_TRUE):.0f}x")
```

:::exercise High-speed steel
An HSS tool has $n = 0.12$ and lasts 60 min at 30 m/min. What speed gives a 15 min life?
---solution---
1. $C = 30\cdot60^{0.12} = 30\cdot1.634 = 49.0$ m/min.
2. $V = 49.0/15^{0.12} = 49.0/1.384 = 35.4$ m/min.
3. Quartering the life only buys 18 % more speed. HSS has a small $n$, so its life is very sensitive to speed.
:::
