"Assume small angles" turns the nonlinear pendulum into simple harmonic motion with the famous period $2\pi\sqrt{L/g}$. It's the most used approximation in mechanics, and few people can say how small is small enough. This lesson answers with a number: the linear model's period is off by less than 1% for amplitudes up to about 23°.

## The pendulum equation and its linearisation

A point mass on a massless rod of length $L$ obeys, from the moment balance about the pivot,

$$
\ddot\theta + \frac{g}{L}\sin\theta = 0 .
$$

Replace $\sin\theta$ by its first Taylor term $\theta$ and you get $\ddot\theta + (g/L)\theta = 0$, with solution $\theta = \theta_0\cos(\omega_0 t)$, $\omega_0 = \sqrt{g/L}$ and

$$
T_0 = 2\pi\sqrt{\frac{L}{g}} .
$$

Lesson 01.07's remainder says the error in $\sin\theta \approx \theta$ is at most $|\theta|^3/6$. At $\theta = 0.4\ \mathrm{rad}$ ($23^\circ$) that's $0.011$, a 2.7% error in the force at the extremes. But the period depends on the force over the whole swing, so its error is smaller than the worst-case force error.

## The exact period

Energy conservation gives $\dot\theta^2 = \frac{2g}{L}(\cos\theta - \cos\theta_0)$. Integrating the time for a quarter swing and substituting $\sin(\theta/2) = k\sin\varphi$ with $k = \sin(\theta_0/2)$ gives

$$
T = 4\sqrt{\frac{L}{g}}\,K(k), \qquad K(k) = \int_0^{\pi/2} \frac{d\varphi}{\sqrt{1 - k^2\sin^2\varphi}} ,
$$

the complete elliptic integral of the first kind. $K(0) = \pi/2$ recovers $T_0$. Expanding for small amplitude,

$$
\frac{T}{T_0} = 1 + \frac{\theta_0^2}{16} + \frac{11\,\theta_0^4}{3072} + \cdots
$$

$K$ is easy to compute exactly with the arithmetic-geometric mean: $K(k) = \dfrac{\pi}{2\,\mathrm{AGM}(1, \sqrt{1 - k^2})}$, which converges quadratically, like Newton's method.

:::example A clock that runs slow
A pendulum clock with $L = 0.994\ \mathrm{m}$ has $T_0 = 2\pi\sqrt{0.994/9.81} = 2.000\ \mathrm{s}$, one tick per second. Its pendulum swings to $10^\circ$.

1. $\theta_0 = 0.1745\ \mathrm{rad}$, so $\theta_0^2/16 = 0.00190$.
2. Exact: $T/T_0 = 1.001\,907$, the series gives $1.001\,904$: agreement to 3 parts in a million.
3. The clock runs slow by $0.1907\%$, which is $0.001907 \times 86\,400 = 165\ \mathrm{s}$ per day.

Small for a swing, huge for a clock. That's why precision clocks keep the amplitude constant: a constant error can be tuned out by adjusting $L$, a varying one can't.
:::

```python file=pendulum.py
"""Exact pendulum period via the AGM versus the small-angle formula."""
import math


def agm(a, b, tol=1e-15):
    while abs(a - b) > tol * a:
        a, b = (a + b) / 2, math.sqrt(a * b)
    return a


def period_ratio(theta0):
    """T / T0 for amplitude theta0 in radians."""
    k = math.sin(theta0 / 2)
    return 1.0 / agm(1.0, math.sqrt(1 - k * k))   # (4 K(k)) / (2 pi) = (2/pi) K = 1/AGM


def simulate_period(theta0, L=1.0, g=9.81, dt=1e-4):
    """Integrate the nonlinear equation with RK4 and time a quarter swing."""
    f = lambda th, om: (om, -g / L * math.sin(th))
    th, om, t = theta0, 0.0, 0.0
    while True:
        k1 = f(th, om); k2 = f(th + dt / 2 * k1[0], om + dt / 2 * k1[1])
        k3 = f(th + dt / 2 * k2[0], om + dt / 2 * k2[1]); k4 = f(th + dt * k3[0], om + dt * k3[1])
        th_n = th + dt / 6 * (k1[0] + 2 * k2[0] + 2 * k3[0] + k4[0])
        om_n = om + dt / 6 * (k1[1] + 2 * k2[1] + 2 * k3[1] + k4[1])
        if th_n <= 0:                                  # crossed the bottom: interpolate
            return 4 * (t + dt * th / (th - th_n))
        th, om, t = th_n, om_n, t + dt


if __name__ == "__main__":
    T0 = 2 * math.pi * math.sqrt(1 / 9.81)
    for deg in (10, 30, 60):
        r, rs = period_ratio(math.radians(deg)), simulate_period(math.radians(deg)) / T0
        print(f"{deg:3d} deg: exact {r:.6f}, simulated {rs:.6f}")
        assert abs(r - rs) < 1e-6
    # find where the linear model's error reaches 1%
    lo, hi = 1.0, 60.0
    for _ in range(60):
        mid = (lo + hi) / 2
        lo, hi = (mid, hi) if period_ratio(math.radians(mid)) < 1.01 else (lo, mid)
    print(f"1% error at {lo:.2f} degrees")
    assert 22 < lo < 24                                 # the lesson's test
    assert abs((period_ratio(math.radians(10)) - 1) * 86400 - 164.8) < 0.5
```

The simulation agrees with the elliptic-integral formula to six digits, which checks both: the AGM formula and the RK4 integrator would have to be wrong in exactly the same way to agree by accident.

:::exercise A playground swing
A child swings to $45^\circ$ on a $2.5\ \mathrm{m}$ swing. What period does the small-angle formula predict, and how far off is it? Use the series $T/T_0 \approx 1 + \theta_0^2/16$ and compare with the exact ratio $1.0400$.
---solution---
1. $T_0 = 2\pi\sqrt{2.5/9.81} = 3.172\ \mathrm{s}$.
2. $\theta_0 = \pi/4 = 0.785\ \mathrm{rad}$, so $\theta_0^2/16 = 0.0386$ and the series gives $T \approx 3.172 \times 1.0386 = 3.294\ \mathrm{s}$.
3. The exact ratio $1.0400$ gives $T = 3.299\ \mathrm{s}$. The linear formula is 4% short; the one-term series closes most of the gap.
4. For a swing that's irrelevant. For a seismometer or a clock it would be a design error.
:::
