Bisection gains one binary digit per step. Newton's method doubles the number of correct digits per step once it's close, which is why nearly every nonlinear solver in engineering software, from structural FEM to circuit simulation, is built around it. The price is that it can fail, so you'll also learn when.

## Linearise and solve

Near a guess $x_n$, replace $f$ by its tangent line:

$$
f(x) \approx f(x_n) + f'(x_n)(x - x_n) .
$$

Set the line to zero and call the result the next guess:

$$
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} .
$$

For $f(x) = x^2 - 2$ this is $x_{n+1} = x_n - \dfrac{x_n^2 - 2}{2x_n} = \dfrac12\left(x_n + \dfrac{2}{x_n}\right)$: the Babylonian method from lesson 01.01.

## Quadratic convergence

Let $r$ be a simple root ($f(r) = 0$, $f'(r) \ne 0$) and $e_n = x_n - r$. Expanding $f(r) = 0$ around $x_n$ with the Lagrange remainder,

$$
0 = f(x_n) - f'(x_n)e_n + \tfrac12 f''(\xi)e_n^2 .
$$

Divide by $f'(x_n)$ and use the update formula:

$$
e_{n+1} = \frac{f''(\xi)}{2f'(x_n)}\,e_n^2 .
$$

The error is squared each step, so once $|e_n|$ is small the digits double. Far from the root, there's no such promise.

:::widget newton
Tangent steps for $x^2 - 2$. Start near the root and three steps reach machine precision; start near $x = 0$ and the first tangent throws you far away.
:::

## When Newton fails

- **Flat spots**: if $f'(x_n) \approx 0$, the step is huge and can leave the region you care about.
- **Cycles**: for some functions and starting points the iterates bounce between values forever.
- **Multiple roots**: if $f'(r) = 0$ too, convergence drops to linear.

Production solvers guard Newton with a fallback: keep a bisection bracket, and if a Newton step lands outside it, bisect instead. You'll build exactly that in the code.

:::example The cantilever frequency, again
Solve $f(x) = \cos x\cosh x + 1 = 0$ from $x_0 = 2$, with $f'(x) = -\sin x\cosh x + \cos x\sinh x$.

1. $x_1 = 1.885275$ (error $10^{-2}$)
2. $x_2 = 1.875179$ (error $8\times10^{-5}$)
3. $x_3 = 1.87510407286$ (error $4\times10^{-9}$)
4. $x_4 = 1.875104068712$ (at machine precision)

Four function and derivative evaluations, against about 40 bisection steps for the same accuracy in lesson 01.02. In the code the derivative comes from the dual numbers of lesson 01.04, so you never write $f'$ by hand.
:::

```python file=newton.py
"""Safeguarded Newton's method with derivatives from dual numbers."""
import math


class Dual:
    def __init__(self, a, b=0.0): self.a, self.b = a, b
    def __add__(self, o): o = o if isinstance(o, Dual) else Dual(o); return Dual(self.a + o.a, self.b + o.b)
    __radd__ = __add__
    def __mul__(self, o): o = o if isinstance(o, Dual) else Dual(o); return Dual(self.a * o.a, self.a * o.b + self.b * o.a)
    __rmul__ = __mul__
    def __sub__(self, o): return self + (-1) * o


def cos(x):  return Dual(math.cos(x.a), -math.sin(x.a) * x.b)
def cosh(x): return Dual(math.cosh(x.a), math.sinh(x.a) * x.b)


def newton(f, x0, lo=None, hi=None, tol=1e-14, max_iter=50):
    """Newton steps; if a bracket [lo, hi] is given, any step leaving it becomes a bisection."""
    x, hist = x0, [x0]
    for _ in range(max_iter):
        y = f(Dual(x, 1.0))
        step = y.a / y.b if y.b != 0 else float("inf")
        x_new = x - step
        if lo is not None and not (lo < x_new < hi):
            x_new = 0.5 * (lo + hi)
        if lo is not None:   # shrink the bracket using the sign at x_new
            if f(Dual(lo)).a * f(Dual(x_new)).a <= 0: hi = x_new
            else: lo = x_new
        hist.append(x_new)
        if abs(x_new - x) < tol * max(1.0, abs(x_new)):
            return x_new, hist
        x = x_new
    raise RuntimeError("no convergence")


if __name__ == "__main__":
    f = lambda x: cos(x) * cosh(x) + 1
    root, hist = newton(f, 2.0)
    r = 1.8751040687119611
    errs = [abs(h - r) for h in hist]
    print("errors:", ", ".join(f"{e:.1e}" for e in errs[:5]))
    assert abs(root - r) < 1e-14
    # digits roughly double: log10 error ratio near 2 while far from machine precision
    d = [-math.log10(e) for e in errs[:4]]
    assert 1.6 < d[2] / d[1] < 2.6 and 1.6 < d[3] / d[2] < 2.6
    # sqrt(2): Newton equals the Babylonian iteration
    rt, h2 = newton(lambda x: x * x - 2, 1.0)
    assert abs(h2[2] - 17 / 12) < 1e-15 and abs(rt - math.sqrt(2)) < 1e-15
    # a bad start: x0 = 0.05 on x^2 - 2 shoots to about 20, the safeguard keeps it in [0, 3]
    rs, hs = newton(lambda x: x * x - 2, 0.05, lo=0.0, hi=3.0)
    assert max(hs) <= 3.0 and abs(rs - math.sqrt(2)) < 1e-12
```

:::exercise Diagnose a stalled solver
Newton's method on $f(x) = (x - 1)^2$ from $x_0 = 2$ converges, but slowly. Compute the first three iterates, explain the rate, and suggest a fix.
---solution---
1. $f' = 2(x - 1)$, so $x_{n+1} = x_n - \dfrac{(x_n - 1)^2}{2(x_n - 1)} = x_n - \dfrac{x_n - 1}{2}$.
2. Iterates: $x_1 = 1.5$, $x_2 = 1.25$, $x_3 = 1.125$. The error halves each step: linear convergence.
3. Reason: $r = 1$ is a double root, $f'(r) = 0$, so the quadratic-convergence derivation (which divides by $f'(r)$) doesn't apply.
4. Fix: if you know the multiplicity $m$, use $x_{n+1} = x_n - m\,f/f'$; with $m = 2$ it lands on $1$ in one step. Or apply Newton to $f/f'$, which has a simple root.
:::
