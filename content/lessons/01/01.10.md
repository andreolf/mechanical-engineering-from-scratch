Rectangles were the definition. In practice you integrate tabulated data and simulation output with the trapezoid rule or Simpson's rule, and you want to know in advance how many points you need. Both rules come from fitting a simple polynomial through the samples, and their error terms come from the same Taylor expansions as before.

## Trapezoid rule

Join neighbouring samples with straight lines and add up the trapezoids. With $n$ slices of width $h$ and $f_i = f(a + ih)$:

$$
T_n = h\left(\tfrac12 f_0 + f_1 + f_2 + \cdots + f_{n-1} + \tfrac12 f_n\right).
$$

Integrating the Taylor expansion over one slice shows the error per slice is $-\tfrac{h^3}{12}f''$. Summing $n = (b-a)/h$ slices:

$$
\int_a^b f\,dx - T_n = -\frac{(b-a)h^2}{12} f''(\xi) .
$$

That's second order, like the midpoint rule, with twice the error and the opposite sign. So the two rules bracket the true value when $f''$ doesn't change sign.

## Simpson's rule

Fit a parabola through each pair of slices (three points) instead of a line. For an even $n$:

$$
S_n = \frac{h}{3}\left(f_0 + 4f_1 + 2f_2 + 4f_3 + \cdots + 2f_{n-2} + 4f_{n-1} + f_n\right).
$$

Its error is

$$
\int_a^b f\,dx - S_n = -\frac{(b-a)h^4}{180} f^{(4)}(\xi) .
$$

Fourth order: halve $h$ and the error drops 16 times. And because the error involves $f^{(4)}$, Simpson integrates every cubic exactly, one degree more than the parabolas it's built from. The odd terms cancel by symmetry, the same trick as in the central difference.

:::example Air compression with four slices
Same integral as lesson 01.09: $W = \int_{0.5}^{1}\ 100/V\ dV$ (litres, J), exact $69.3147\ \mathrm{J}$, using five pressure samples at $V = 0.5, 0.625, 0.75, 0.875, 1.0\ \mathrm{L}$.

1. Pressures (bar): $2.000, 1.600, 1.333, 1.143, 1.000$; with $p_1V_1 = 100\ \mathrm{J}$ that's $f_i = 200, 160, 133.3, 114.3, 100\ \mathrm{J/L}$.
2. Trapezoid: $0.125 \times (100 + 160 + 133.3 + 114.3 + 50) = 69.702\ \mathrm{J}$, error $+0.388$.
3. Simpson: $\dfrac{0.125}{3}(200 + 4\times160 + 2\times133.3 + 4\times114.3 + 100) = 69.325\ \mathrm{J}$, error $+0.011$.

Same five numbers, 36 times smaller error. That's why engineering codes integrate tabulated data with Simpson whenever the spacing is even.
:::

```python file=quadrature.py
"""Composite trapezoid and Simpson rules, with convergence checks."""
import math


def trapezoid(f, a, b, n):
    h = (b - a) / n
    return h * (0.5 * f(a) + sum(f(a + i * h) for i in range(1, n)) + 0.5 * f(b))


def simpson(f, a, b, n):
    if n % 2:
        raise ValueError("Simpson's rule needs an even number of slices")
    h = (b - a) / n
    s = f(a) + f(b)
    s += 4 * sum(f(a + i * h) for i in range(1, n, 2))
    s += 2 * sum(f(a + i * h) for i in range(2, n, 2))
    return h / 3 * s


def order(rule, f, a, b, exact, ns=(4, 8, 16, 32)):
    e = [abs(rule(f, a, b, n) - exact) for n in ns]
    return sum(math.log2(e[i] / e[i + 1]) for i in range(len(e) - 1)) / (len(e) - 1)


if __name__ == "__main__":
    f = lambda V: 100.0 / V
    W = 100 * math.log(2)
    T, S = trapezoid(f, 0.5, 1.0, 4), simpson(f, 0.5, 1.0, 4)
    print(f"trapezoid {T:.4f}, Simpson {S:.4f}, exact {W:.4f}")
    assert abs(T - 69.7024) < 1e-4 and abs(S - 69.3254) < 1e-4
    assert abs(order(trapezoid, f, 0.5, 1, W) - 2) < 0.05
    assert abs(order(simpson, f, 0.5, 1, W) - 4) < 0.1
    # Simpson integrates any cubic exactly, even with one panel (the lesson's test)
    for c in [(1, 0, 0, 0), (0, 1, 0, 0), (2, -3, 5, 7), (-1, 4, 0.5, 2)]:
        cubic = lambda x, c=c: c[0] * x**3 + c[1] * x**2 + c[2] * x + c[3]
        exact = c[0] * 16 / 4 + c[1] * 8 / 3 + c[2] * 2 + c[3] * 2      # integral on [0, 2]
        assert abs(simpson(cubic, 0, 2, 2) - exact) < 1e-12
```

:::exercise Simpson on a cubic
Evaluate $\int_0^2 x^3\,dx$ with Simpson's rule using a single panel ($n = 2$, $h = 1$) and compare with the exact value.
---solution---
1. Samples: $f(0) = 0$, $f(1) = 1$, $f(2) = 8$.
2. $S_2 = \dfrac{1}{3}(0 + 4\times1 + 8) = \dfrac{12}{3} = 4$.
3. Exact: $\left[\tfrac{x^4}{4}\right]_0^2 = 4$.
4. Exact agreement, as the error term predicts: $f^{(4)} = 0$ for a cubic.
:::
