Design is choosing the best value of something: the thickness that minimises weight while staying strong enough, the speed that minimises fuel per kilometre, the cut that maximises the volume of a folded box. With one design variable, calculus gives a complete recipe: find where the derivative vanishes, then check what kind of point it is.

## Stationary points

If a differentiable function $f$ has a local maximum or minimum at an interior point $x^*$, then

$$
f'(x^*) = 0 .
$$

Points where $f' = 0$ are **stationary points**. To classify one, look at the curvature:

$$
f''(x^*) < 0 \Rightarrow \text{local maximum}, \qquad f''(x^*) > 0 \Rightarrow \text{local minimum} .
$$

If $f''(x^*) = 0$ the test is inconclusive (think of $x^3$ at $0$). And the condition is only for interior points: on a closed interval $[a, b]$ the global optimum may sit at an end, so always compare the stationary values with $f(a)$ and $f(b)$.

## The sheet-metal box

$$
V(x) = x(a - 2x)^2, \qquad 0 \le x \le \tfrac{a}{2} .
$$

Differentiate with the product and chain rules:

$$
V'(x) = (a - 2x)^2 - 4x(a - 2x) = (a - 2x)(a - 6x) .
$$

The roots are $x = a/2$ (no base, $V = 0$) and $x = a/6$. At $x = a/6$, $V''(x) = 24x - 8a = -4a < 0$, so it's a maximum, and the endpoints both give $V = 0$. The best box has

$$
x^* = \frac{a}{6}, \qquad V^* = \frac{a}{6}\left(\frac{2a}{3}\right)^2 = \frac{2a^3}{27} .
$$

:::example A box from a 600 mm sheet
A workshop folds open trays from $600 \times 600\ \mathrm{mm}$ steel sheet.

1. Optimal cut: $x^* = 600/6 = 100\ \mathrm{mm}$.
2. Base: $600 - 200 = 400\ \mathrm{mm}$ square, height $100\ \mathrm{mm}$.
3. Volume: $100 \times 400^2 = 1.6\times10^7\ \mathrm{mm^3} = 16\ \mathrm{L}$, which matches $2a^3/27 = 2 \times 600^3/27 = 1.6\times10^7$.
4. Sensitivity: a $90\ \mathrm{mm}$ cut gives $90 \times 420^2 = 15.88\ \mathrm{L}$, only 0.8% less. Near an optimum $V' = 0$, so small errors in $x$ cost very little. That flatness is why "optimal" designs tolerate manufacturing scatter.
:::

```python file=box.py
"""Maximise the volume of an open box folded from sheet: calculus versus a numerical search."""
import math


def volume(x, a, b=None):
    b = a if b is None else b
    return x * (a - 2 * x) * (b - 2 * x)


def golden_max(f, lo, hi, tol=1e-10):
    """Golden-section search for the maximum of a unimodal function on [lo, hi]."""
    g = (math.sqrt(5) - 1) / 2
    c, d = hi - g * (hi - lo), lo + g * (hi - lo)
    while hi - lo > tol:
        if f(c) > f(d):
            hi, d = d, c
            c = hi - g * (hi - lo)
        else:
            lo, c = c, d
            d = lo + g * (hi - lo)
    return 0.5 * (lo + hi)


def best_cut_rect(a, b):
    """Stationary point of x(a-2x)(b-2x): 12x^2 - 4(a+b)x + ab = 0, smaller root."""
    return ((a + b) - math.sqrt((a + b) ** 2 - 3 * a * b)) / 6


if __name__ == "__main__":
    a = 600.0
    x_num = golden_max(lambda x: volume(x, a), 0, a / 2)
    assert abs(x_num - a / 6) < 1e-6                       # the lesson's test
    assert abs(volume(a / 6, a) - 2 * a**3 / 27) < 1e-6
    print(f"cut {x_num:.4f} mm, volume {volume(x_num, a) / 1e6:.3f} L")
    assert abs(volume(90, a) / volume(100, a) - 0.99225) < 1e-5
    x_r = best_cut_rect(400, 250)
    assert abs(x_r - 50) < 1e-12 and abs(volume(x_r, 400, 250) - 2.25e6) < 1e-6
    assert abs(golden_max(lambda x: volume(x, 400, 250), 0, 125) - 50) < 1e-6
```

:::exercise A rectangular sheet
The sheet is $400 \times 250\ \mathrm{mm}$ instead. Find the cut that maximises volume and the resulting volume.
---solution---
1. $V = x(400 - 2x)(250 - 2x) = 4x^3 - 1300x^2 + 100\,000x$.
2. $V' = 12x^2 - 2600x + 100\,000 = 0$, so $x = \dfrac{2600 \pm \sqrt{2600^2 - 4\cdot12\cdot100\,000}}{24} = \dfrac{2600 \pm 1400}{24}$.
3. Roots: $x = 50$ and $x = 166.7\ \mathrm{mm}$. The second exceeds $125\ \mathrm{mm}$ (half the short side), so it's not feasible.
4. $V''(50) = 24(50) - 2600 = -1400 < 0$: a maximum.
5. Volume: $50 \times 300 \times 150 = 2.25\times10^6\ \mathrm{mm^3} = 2.25\ \mathrm{L}$.
:::
