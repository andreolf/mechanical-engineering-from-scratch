Engineers solve equations that have no formula for their roots all the time: the natural frequency of a beam, the friction factor in a pipe, the angle where a mechanism locks. Bisection is the slowest way to find such a root and also the only one that can't fail. Its guarantee comes straight from a theorem about continuous functions.

## Continuity

A function $f$ is continuous at $c$ when $\lim_{x\to c} f(x) = f(c)$: small changes in input give small changes in output. Formally, for every $\varepsilon > 0$ there is a $\delta > 0$ such that $|x - c| < \delta$ implies $|f(x) - f(c)| < \varepsilon$. Polynomials, $\sin$, $\cos$, $\exp$ and their sums, products and compositions are continuous wherever they're defined.

## The intermediate value theorem

If $f$ is continuous on $[a, b]$ and $f(a)$ and $f(b)$ have opposite signs, then there is at least one $c \in (a, b)$ with $f(c) = 0$.

A continuous graph can't get from below the axis to above it without crossing. Note what the theorem doesn't say: it promises a root, not that there's only one, and it fails for discontinuous functions like $1/x$ on $[-1, 1]$.

## Bisection

Halve the bracket, keep the half where the sign change survives, repeat:

1. Let $m = (a + b)/2$.
2. If $f(a)\,f(m) \le 0$, set $b = m$; otherwise set $a = m$.

After $n$ steps the bracket has width $(b - a)/2^n$, and the root is inside it. Taking the midpoint as the estimate, the error is at most

$$
|c - m_n| \le \frac{b - a}{2^{\,n+1}} .
$$

To guarantee a tolerance $\tau$ on a bracket of width $w$ you need $n \ge \log_2(w/\tau) - 1$ steps. The bound doesn't depend on $f$ at all, which is why bisection is the safety net inside faster solvers.

Bisection on the cantilever frequency equation. Each step halves the shaded bracket; the guarantee holds whatever the curve looks like inside.
:::

:::example The first natural frequency of a cantilever
Beam theory (Phase 08) shows that a clamped-free beam vibrates at frequencies $\omega = (\beta L)^2\sqrt{EI/(\rho A L^4)}$, where $x = \beta L$ solves

$$
\cos x \cosh x + 1 = 0 .
$$

There is no closed form. Find the first root.

1. Check the bracket: $f(1) = \cos 1\cosh 1 + 1 = 1.834 > 0$ and $f(3) = -8.967 < 0$. The function is continuous, so a root lies in $(1, 3)$.
2. Step 1: $m = 2$, $f(2) = -0.566 < 0$, so the root is in $(1, 2)$.
3. Step 2: $m = 1.5$, $f(1.5) = 1.166 > 0$, so it is in $(1.5, 2)$.
4. Continuing: tolerance $10^{-6}$ on a bracket of width 2 needs $\lceil\log_2(2/10^{-6})\rceil = 21$ halvings to make the bracket itself narrower than $10^{-6}$.
5. Result: $\beta L = 1.875104$, so $(\beta L)^2 = 3.516$, the famous constant in the cantilever's first frequency.
:::

```python file=bisection.py
"""Bisection with a guaranteed error bound, applied to the cantilever frequency equation."""
import math


def bisect(f, a, b, tol=1e-12, max_iter=200):
    fa, fb = f(a), f(b)
    if fa * fb > 0:
        raise ValueError("no sign change: the IVT gives no guarantee on this bracket")
    history = []
    for n in range(max_iter):
        m = 0.5 * (a + b)
        fm = f(m)
        history.append((a, b))
        if fa * fm <= 0:
            b, fb = m, fm
        else:
            a, fa = m, fm
        if b - a < tol:
            break
    return 0.5 * (a + b), history


if __name__ == "__main__":
    f = lambda x: math.cos(x) * math.cosh(x) + 1
    root, hist = bisect(f, 1.0, 3.0)
    print(f"beta*L = {root:.10f}, (beta*L)^2 = {root**2:.6f}, {len(hist)} steps")
    assert abs(root - 1.8751040687) < 1e-9
    # the error never exceeds the theoretical bound (b-a)/2^(n+1) for the midpoint
    for n, (a, b) in enumerate(hist):
        m = 0.5 * (a + b)
        assert abs(root - m) <= 2.0 / 2 ** (n + 1) + 1e-12
    assert math.ceil(math.log2(2 / 1e-6)) == 21
    try:
        bisect(lambda x: x * x + 1, -1, 1)
    except ValueError as e:
        print("refused:", e)
```

:::exercise How many steps?
A bisection solver starts on $[0, 10]$ and must report a root to within $10^{-9}$, using the midpoint as its answer. What's the minimum number of iterations?
---solution---
1. After $n$ iterations the midpoint error is at most $\dfrac{10}{2^{n+1}}$.
2. Require $\dfrac{10}{2^{n+1}} \le 10^{-9}$, so $2^{n+1} \ge 10^{10}$ and $n + 1 \ge \log_2 10^{10} = 33.2$.
3. So $n + 1 = 34$, $n = 33$ iterations.
4. Each iteration costs one function evaluation. Newton's method (lesson 01.05) would need about 5 near a simple root, but it can diverge; bisection can't.
:::
