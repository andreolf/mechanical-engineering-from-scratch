Mass, spring, damper: the model behind car suspensions, building isolation, measuring instruments and the needle of every analogue gauge. Its equation is linear and second order, and it has a complete closed-form solution. This lesson derives it from one guess, classifies the three ways a system can return to rest, and checks the formulas against a numerical integrator.

## The equation

Newton's second law for a mass $m$ on a spring $k$ with a viscous damper $c$:

$$
m\ddot x + c\dot x + kx = 0 .
$$

Divide by $m$ and introduce the **natural frequency** and the **damping ratio**:

$$
\omega_n = \sqrt{\frac{k}{m}}, \qquad \zeta = \frac{c}{2\sqrt{km}}, \qquad \ddot x + 2\zeta\omega_n\dot x + \omega_n^2 x = 0 .
$$

## One guess solves it

Try $x = e^{st}$. Every derivative brings down a factor $s$, so the equation becomes the **characteristic equation**

$$
s^2 + 2\zeta\omega_n s + \omega_n^2 = 0 \quad\Longrightarrow\quad s = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^2 - 1} .
$$

The sign of $\zeta^2 - 1$ decides everything:

- **Underdamped**, $\zeta < 1$: complex roots $s = -\zeta\omega_n \pm i\omega_d$ with $\omega_d = \omega_n\sqrt{1 - \zeta^2}$. Using $e^{i\omega t} = \cos\omega t + i\sin\omega t$ (lesson 01.17), for $x(0) = x_0$, $\dot x(0) = 0$:
$$
x(t) = x_0 e^{-\zeta\omega_n t}\left(\cos\omega_d t + \frac{\zeta\omega_n}{\omega_d}\sin\omega_d t\right) .
$$
- **Critically damped**, $\zeta = 1$: a double root, and $x = x_0(1 + \omega_n t)e^{-\omega_n t}$. The fastest return without overshoot.
- **Overdamped**, $\zeta > 1$: two negative real roots $s_1, s_2$, and $x = \dfrac{x_0}{s_2 - s_1}\left(s_2 e^{s_1 t} - s_1 e^{s_2 t}\right)$. No oscillation, but a slow tail.

:::widget damping
Free response from an initial displacement. Slide $\zeta$ through 1 to watch the oscillation vanish; above 1 the return gets slower again.
:::

:::example A quarter-car suspension
One wheel of a car carries $m = 300\ \mathrm{kg}$ on a spring $k = 20\ \mathrm{kN/m}$ with a damper $c = 2000\ \mathrm{N\,s/m}$.

1. $\omega_n = \sqrt{20\,000/300} = 8.165\ \mathrm{rad/s}$, or $f_n = 1.30\ \mathrm{Hz}$.
2. $\zeta = \dfrac{2000}{2\sqrt{20\,000 \times 300}} = \dfrac{2000}{4899} = 0.408$. Underdamped.
3. $\omega_d = 8.165\sqrt{1 - 0.167} = 7.454\ \mathrm{rad/s}$, so the body oscillates at $1.19\ \mathrm{Hz}$.
4. Each half-cycle the amplitude shrinks by $e^{-\zeta\pi/\sqrt{1-\zeta^2}} = 0.245$: after a bump the body overshoots by a quarter of the bump, then by 6%, then it's settled.

Car makers tune $\zeta$ between about $0.2$ and $0.4$. Lower feels floaty; critical damping ($c = 4899\ \mathrm{N\,s/m}$ here) would transmit every road bump harshly.
:::

```python file=oscillator.py
"""Closed-form damped oscillator versus a fourth-order Runge-Kutta integration."""
import math


def closed_form(t, x0, wn, z):
    if z < 1:
        wd = wn * math.sqrt(1 - z * z)
        return x0 * math.exp(-z * wn * t) * (math.cos(wd * t) + z * wn / wd * math.sin(wd * t))
    if z == 1:
        return x0 * (1 + wn * t) * math.exp(-wn * t)
    r = wn * math.sqrt(z * z - 1)
    s1, s2 = -z * wn + r, -z * wn - r
    return x0 / (s2 - s1) * (s2 * math.exp(s1 * t) - s1 * math.exp(s2 * t))


def rk4(x0, wn, z, T, dt):
    f = lambda x, v: (v, -2 * z * wn * v - wn * wn * x)
    x, v = x0, 0.0
    out = [(0.0, x)]
    for i in range(round(T / dt)):
        k1 = f(x, v)
        k2 = f(x + dt / 2 * k1[0], v + dt / 2 * k1[1])
        k3 = f(x + dt / 2 * k2[0], v + dt / 2 * k2[1])
        k4 = f(x + dt * k3[0], v + dt * k3[1])
        x += dt / 6 * (k1[0] + 2 * k2[0] + 2 * k3[0] + k4[0])
        v += dt / 6 * (k1[1] + 2 * k2[1] + 2 * k3[1] + k4[1])
        out.append(((i + 1) * dt, x))
    return out


if __name__ == "__main__":
    m, k, c = 300.0, 20_000.0, 2000.0
    wn, z = math.sqrt(k / m), c / (2 * math.sqrt(k * m))
    print(f"wn = {wn:.3f} rad/s, zeta = {z:.3f}")
    assert abs(wn - 8.16497) < 1e-4 and abs(z - 0.408248) < 1e-5
    for zeta in (0.0, z, 1.0, 2.5):
        err = max(abs(x - closed_form(t, 0.05, wn, zeta)) for t, x in rk4(0.05, wn, zeta, 3.0, 1e-3))
        print(f"zeta={zeta:.3f}: max |RK4 - closed form| = {err:.1e} m")
        assert err < 1e-6                                     # the lesson's test
    ratio = math.exp(-z * math.pi / math.sqrt(1 - z * z))
    assert abs(ratio - 0.24538) < 1e-4
```

:::exercise Design the damper
For the same car ($m = 300\ \mathrm{kg}$, $k = 20\ \mathrm{kN/m}$), what damping coefficient gives $\zeta = 0.3$? What fraction of a displacement remains after one full damped period?
---solution---
1. $c = 2\zeta\sqrt{km} = 2 \times 0.3 \times 2449.5 = 1470\ \mathrm{N\,s/m}$.
2. One full period is $T_d = 2\pi/\omega_d$; the envelope decays by $e^{-\zeta\omega_n T_d} = e^{-2\pi\zeta/\sqrt{1 - \zeta^2}}$.
3. $2\pi \times 0.3/\sqrt{0.91} = 1.976$, so the factor is $e^{-1.976} = 0.139$.
4. About 14% of the displacement remains after one period, compared with 6% at $\zeta = 0.408$: a softer, slightly floatier ride.
:::
