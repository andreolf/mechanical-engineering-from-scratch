The sum, product and chain rules let you differentiate any formula built from simple pieces. They aren't separate facts to memorise: each one falls out of the limit definition in a few lines. Once you see that, you can teach a computer to apply them automatically and get derivatives that are exact to machine precision, with no step size to choose.

## Rules from the definition

Let $f$ and $g$ be differentiable at $x$. The **product rule** follows from adding and subtracting one term:

$$
\frac{f(x+h)g(x+h) - f(x)g(x)}{h} = f(x+h)\frac{g(x+h) - g(x)}{h} + g(x)\frac{f(x+h) - f(x)}{h} \;\longrightarrow\; f g' + g f' .
$$

The **chain rule** for $f(g(x))$: write $u = g(x)$ and $\Delta u = g(x + h) - g(x)$. Then

$$
\frac{f(g(x+h)) - f(g(x))}{h} = \frac{f(u + \Delta u) - f(u)}{\Delta u}\cdot\frac{\Delta u}{h} \;\longrightarrow\; f'(g(x))\,g'(x) .
$$

(When $\Delta u = 0$ for small $h$ the step needs a little care, but the result holds.) Combined with $(x^n)' = n x^{n-1}$, $(\sin x)' = \cos x$, $(e^x)' = e^x$ and $(\ln x)' = 1/x$, these rules differentiate every formula in an engineering handbook.

## Dual numbers: the rules as arithmetic

Invent a number $\epsilon$ with $\epsilon^2 = 0$ but $\epsilon \ne 0$, and compute with pairs $a + b\epsilon$. Multiplication gives

$$
(a + b\epsilon)(c + d\epsilon) = ac + (ad + bc)\epsilon ,
$$

which is the product rule sitting in the $\epsilon$ part. For any smooth function, Taylor's theorem stops after one term because $\epsilon^2 = 0$:

$$
f(a + b\epsilon) = f(a) + f'(a)\,b\,\epsilon .
$$

So if you evaluate $f$ at $x + 1\epsilon$, the $\epsilon$ part of the result is $f'(x)$. Teach the computer how $+$, $\times$, $\sin$, $\exp$ act on pairs and every derivative comes out exact. This is **forward-mode automatic differentiation**, and it's how modern simulation and machine-learning tools compute gradients.

:::example Differentiating by hand and with duals
Find the derivative of $f(x) = x^3 \sin x$ at $x = 2$.

1. Product rule: $f'(x) = 3x^2 \sin x + x^3 \cos x$.
2. At $x = 2$: $12 \sin 2 + 8 \cos 2 = 12(0.9093) + 8(-0.4161) = 10.912 - 3.329 = 7.582$.
3. With duals: start from $x = 2 + 1\epsilon$. Then $x^3 = 8 + 12\epsilon$ and $\sin x = 0.9093 - 0.4161\epsilon$.
4. Multiply: $(8 + 12\epsilon)(0.9093 - 0.4161\epsilon) = 7.274 + (8 \times (-0.4161) + 12 \times 0.9093)\epsilon = 7.274 + 7.582\epsilon$.

The $\epsilon$ part is the derivative, produced by arithmetic alone.
:::

```python file=dual.py
"""Forward-mode automatic differentiation with dual numbers."""
import math


class Dual:
    __slots__ = ("a", "b")

    def __init__(self, a, b=0.0):
        self.a, self.b = float(a), float(b)

    @staticmethod
    def lift(x):
        return x if isinstance(x, Dual) else Dual(x)

    def __add__(self, o): o = Dual.lift(o); return Dual(self.a + o.a, self.b + o.b)
    __radd__ = __add__
    def __sub__(self, o): o = Dual.lift(o); return Dual(self.a - o.a, self.b - o.b)
    def __rsub__(self, o): return Dual.lift(o) - self
    def __neg__(self): return Dual(-self.a, -self.b)
    def __mul__(self, o): o = Dual.lift(o); return Dual(self.a * o.a, self.a * o.b + self.b * o.a)
    __rmul__ = __mul__
    def __truediv__(self, o):
        o = Dual.lift(o)
        return Dual(self.a / o.a, (self.b * o.a - self.a * o.b) / (o.a * o.a))
    def __rtruediv__(self, o): return Dual.lift(o) / self
    def __pow__(self, n):  # real exponent
        return Dual(self.a ** n, n * self.a ** (n - 1) * self.b)


def sin(x):  x = Dual.lift(x); return Dual(math.sin(x.a), math.cos(x.a) * x.b)
def cos(x):  x = Dual.lift(x); return Dual(math.cos(x.a), -math.sin(x.a) * x.b)
def exp(x):  x = Dual.lift(x); e = math.exp(x.a); return Dual(e, e * x.b)
def log(x):  x = Dual.lift(x); return Dual(math.log(x.a), x.b / x.a)
def sinh(x): x = Dual.lift(x); return Dual(math.sinh(x.a), math.cosh(x.a) * x.b)
def cosh(x): x = Dual.lift(x); return Dual(math.cosh(x.a), math.sinh(x.a) * x.b)


def derivative(f, x):
    return f(Dual(x, 1.0)).b


if __name__ == "__main__":
    for x in (0.3, 1.5, 4.0):
        d = derivative(lambda t: sin(t ** 2), x)
        assert abs(d - 2 * x * math.cos(x * x)) < 1e-14     # machine precision
    d = derivative(lambda t: t ** 3 * sin(t), 2.0)
    assert abs(d - (12 * math.sin(2) + 8 * math.cos(2))) < 1e-13
    d = derivative(lambda t: exp(t * log(t)), 2.0)         # x^x
    assert abs(d - 4 * (math.log(2) + 1)) < 1e-13
    print(f"d/dx x^3 sin x at 2 = {derivative(lambda t: t ** 3 * sin(t), 2.0):.6f}")
```

Unlike the finite differences of lesson 01.03 there is no $h$, so no truncation error and no cancellation. The cost is that every function you use must have a dual version.

:::exercise The quotient rule, from duals
Using the dual division rule in the code, $\dfrac{a + b\epsilon}{c + d\epsilon} = \dfrac{a}{c} + \dfrac{bc - ad}{c^2}\epsilon$, derive the quotient rule. Check it by multiplying back.
---solution---
1. Put $a = f(x)$, $b = f'(x)$, $c = g(x)$, $d = g'(x)$, so the numerator and denominator are $f(x + \epsilon)$ and $g(x + \epsilon)$.
2. The $\epsilon$ part of the quotient is $\dfrac{f'g - fg'}{g^2}$, which is the quotient rule.
3. Check: $\left(\dfrac{a}{c} + \dfrac{bc - ad}{c^2}\epsilon\right)(c + d\epsilon) = a + \left(\dfrac{ad}{c} + \dfrac{bc - ad}{c}\right)\epsilon = a + b\epsilon$, using $\epsilon^2 = 0$. Multiplying back recovers the numerator, so the division rule is right.
:::
