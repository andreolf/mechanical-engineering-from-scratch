A differential equation states how something changes, and asks you to recover what it is. First-order equations, where only the first derivative appears, already cover a draining tank, a charging capacitor, a cooling part and a parachutist reaching terminal speed. This lesson solves them by hand with two techniques, then numerically with the simplest method there is, and measures exactly how its error shrinks.

## Separation of variables

When the equation can be written $\dfrac{dy}{dt} = g(t)\,h(y)$, move all $y$ to one side and integrate:

$$
\int \frac{dy}{h(y)} = \int g(t)\,dt + C .
$$

## Torricelli's tank

A tank of cross-section $A$ drains through a hole of area $a$ at the bottom. Bernoulli's equation (Phase 11) gives the outflow speed $\sqrt{2gh}$, so the volume balance is

$$
A\frac{dh}{dt} = -a\sqrt{2gh} .
$$

Separate with $k = \dfrac{a}{A}\sqrt{2g}$:

$$
\int h^{-1/2}\,dh = -k\int dt \;\Longrightarrow\; 2\sqrt{h} = 2\sqrt{h_0} - kt \;\Longrightarrow\; h(t) = \left(\sqrt{h_0} - \frac{kt}{2}\right)^2 .
$$

The tank empties at $t_\text{empty} = 2\sqrt{h_0}/k$. Unlike exponential decay, it really reaches zero in finite time, because the outflow slows only like $\sqrt{h}$.

## Integrating factors

A linear equation $y' + p(t)\,y = q(t)$ becomes integrable after multiplying by $\mu = e^{\int p\,dt}$, because then the left side is $(\mu y)'$:

$$
(\mu y)' = \mu q \;\Longrightarrow\; y = \frac{1}{\mu}\left(\int \mu q\,dt + C\right) .
$$

For an RC circuit charging from a source $V_s$, $\dot V + V/\tau = V_s/\tau$ with $\mu = e^{t/\tau}$ gives $V = V_s(1 - e^{-t/\tau})$.

## Explicit Euler

When there's no closed form, step forward along the tangent:

$$
y_{n+1} = y_n + \Delta t\, f(t_n, y_n) .
$$

Each step makes a local error of order $\Delta t^2$ (the Taylor term it ignores). Over a fixed time span there are $T/\Delta t$ steps, so the global error is of order $\Delta t$: Euler is **first order**. Halve the step, halve the error.

:::

:::example Draining a water tank
A tank with $A = 1\ \mathrm{m^2}$ holds water $2\ \mathrm{m}$ deep and drains through a $20\ \mathrm{cm^2}$ hole ($a = 0.002\ \mathrm{m^2}$).

1. $k = 0.002 \times \sqrt{2 \times 9.81} = 0.002 \times 4.429 = 8.859\times10^{-3}\ \mathrm{m^{1/2}/s}$.
2. Empty time: $t = 2\sqrt{2}/k = 2.828/0.008859 = 319\ \mathrm{s}$, a bit over five minutes.
3. Half the water ($h = 1\ \mathrm{m}$) is gone when $\sqrt{h} = 1$: $t = 2(\sqrt 2 - 1)/k = 93.5\ \mathrm{s}$. The second half takes $225\ \mathrm{s}$, because the pressure head is lower.
4. Euler with $\Delta t = 10\ \mathrm{s}$ gives $h(100\ \mathrm{s}) = 0.927\ \mathrm{m}$ against the exact $0.943\ \mathrm{m}$. It drains too fast, because each step uses the outflow rate at the start of the step, when the level is highest. With $\Delta t = 5\ \mathrm{s}$ the error halves, from $0.016$ to $0.008\ \mathrm{m}$.

A real orifice discharges less than ideal (a discharge coefficient of about $0.6$ for a sharp-edged hole), which would stretch the time to about $532\ \mathrm{s}$. The model is honest about that: it's Torricelli's ideal law.
:::

```python file=tank.py
"""Torricelli tank: exact solution versus explicit Euler, and Euler's first-order convergence."""
import math

G = 9.81


def exact_h(t, h0, A, a):
    k = a / A * math.sqrt(2 * G)
    return max(0.0, math.sqrt(h0) - k * t / 2) ** 2


def euler_h(T, h0, A, a, dt):
    k = a / A * math.sqrt(2 * G)
    h, t = h0, 0.0
    n = round(T / dt)
    for _ in range(n):
        h = max(0.0, h - dt * k * math.sqrt(h))
        t += dt
    return h


if __name__ == "__main__":
    h0, A, a = 2.0, 1.0, 0.002
    k = a / A * math.sqrt(2 * G)
    assert abs(2 * math.sqrt(h0) / k - 319.275) < 1e-2
    assert abs(2 * (math.sqrt(2) - 1) / k - 93.51) < 1e-2
    e = exact_h(100, h0, A, a)
    errs = []
    for dt in (10, 5, 2.5, 1.25, 0.625):
        errs.append(abs(euler_h(100, h0, A, a, dt) - e))
        print(f"dt={dt:6.3f}  error {errs[-1]:.3e}")
    ratios = [errs[i] / errs[i + 1] for i in range(len(errs) - 1)]
    assert all(1.9 < r < 2.1 for r in ratios)            # error halves with the step: first order
    assert abs(euler_h(100, h0, A, a, 10) - 0.9269) < 1e-3 and abs(e - 0.9434) < 1e-3
```

:::exercise Charging a capacitor
A $100\ \mathrm{\mu F}$ capacitor charges through $10\ \mathrm{k\Omega}$ from a $12\ \mathrm{V}$ source. Derive $V(t)$ with an integrating factor and find when it reaches $9\ \mathrm{V}$.
---solution---
1. Kirchhoff: $V_s = RC\,\dot V + V$, so $\dot V + V/\tau = V_s/\tau$ with $\tau = RC = 10^4 \times 10^{-4} = 1\ \mathrm{s}$.
2. Multiply by $\mu = e^{t/\tau}$: $(e^{t/\tau}V)' = \dfrac{V_s}{\tau}e^{t/\tau}$, so $e^{t/\tau}V = V_s e^{t/\tau} + C$.
3. With $V(0) = 0$: $C = -V_s$ and $V = V_s(1 - e^{-t/\tau})$.
4. $9 = 12(1 - e^{-t})$ gives $e^{-t} = 0.25$, so $t = \ln 4 = 1.386\ \mathrm{s}$.
:::
