Every numerical method in this course produces a sequence of approximations and stops when they are "close enough". This lesson makes "close enough" precise with the definition of a limit, then uses it on a 4000-year-old algorithm for square roots that your computer's hardware still resembles.

## What a limit means

A sequence $a_0, a_1, a_2, \dots$ converges to $L$ when you can get it as close to $L$ as you like, and keep it there, by going far enough:

$$
\lim_{n\to\infty} a_n = L \iff \forall\, \varepsilon > 0 \;\; \exists\, N \;\; \forall\, n \ge N: \; |a_n - L| < \varepsilon .
$$

Read it as a game. Someone hands you a tolerance $\varepsilon$. You must answer with an index $N$ after which every term stays inside the band $L \pm \varepsilon$. If you can always answer, the sequence converges.

For $a_n = 1/n$ and $L = 0$: given $\varepsilon$, choose any $N > 1/\varepsilon$. Then $n \ge N$ gives $|1/n| \le 1/N < \varepsilon$.

## Monotone and bounded means convergent

You often can't guess $L$ in advance. A sufficient condition that needs no $L$: a sequence that is **monotone** (never increases, or never decreases) and **bounded** converges. This is a property of the real numbers (completeness), and it's how you prove that an iteration settles before you know where.

## The Babylonian square root

To find $\sqrt{2}$, start with any $a_0 > 0$ and repeat

$$
a_{n+1} = \frac{1}{2}\left(a_n + \frac{2}{a_n}\right).
$$

If $a_n$ is too big, $2/a_n$ is too small, and their average lands between. Two facts prove convergence:

1. For $n \ge 1$, $a_n \ge \sqrt{2}$, by the inequality of arithmetic and geometric means: $\tfrac12(a + 2/a) \ge \sqrt{a \cdot 2/a} = \sqrt 2$.
2. For $a_n \ge \sqrt 2$, $a_{n+1} - a_n = \dfrac{2 - a_n^2}{2a_n} \le 0$, so the sequence decreases.

Decreasing and bounded below, so it converges. Its limit $L$ must satisfy $L = \tfrac12(L + 2/L)$, which gives $L^2 = 2$.

:::example How fast does it get there?
Start from $a_0 = 1$ and track the error $e_n = a_n - \sqrt 2$.

| $n$ | $a_n$ | error |
|---|---|---|
| 0 | 1 | $-4.1\times10^{-1}$ |
| 1 | 1.5 | $8.6\times10^{-2}$ |
| 2 | 1.416 666 666 7 | $2.5\times10^{-3}$ |
| 3 | 1.414 215 686 3 | $2.1\times10^{-6}$ |
| 4 | 1.414 213 562 374 7 | $1.6\times10^{-12}$ |
| 5 | 1.414 213 562 373 1 | at machine precision |

The number of correct digits roughly doubles each step. Algebra shows why: $e_{n+1} = \dfrac{e_n^2}{2a_n}$, so the new error is proportional to the square of the old one. That's **quadratic convergence**, and in lesson 01.05 you'll see that this iteration is Newton's method in disguise.
:::

```python file=babylon.py
"""Babylonian square root as a sequence, with an epsilon-N check."""
import math


def babylon(S, a0, steps):
    seq = [a0]
    for _ in range(steps):
        a = seq[-1]
        seq.append(0.5 * (a + S / a))
    return seq


def first_N(seq, L, eps):
    """Smallest N such that |a_n - L| < eps for every n >= N in the list (None if never)."""
    N = None
    for n, a in enumerate(seq):
        if abs(a - L) < eps:
            N = n if N is None else N
        else:
            N = None
    return N


if __name__ == "__main__":
    r2 = math.sqrt(2)
    seq = babylon(2.0, 1.0, 8)
    for n, a in enumerate(seq[:6]):
        print(n, f"{a:.15f}", f"{abs(a - r2):.1e}")
    assert first_N(seq, r2, 1e-12) < 7                       # the lesson's test
    assert all(a >= r2 - 1e-15 for a in seq[1:])             # bounded below
    assert all(b <= a + 1e-15 for a, b in zip(seq[1:], seq[2:]))  # decreasing
    # quadratic convergence: e_{n+1} ~ e_n^2 / (2 a_n)
    e = [a - r2 for a in seq]
    assert abs(e[3] / (e[2] ** 2 / (2 * seq[2])) - 1) < 1e-6
    assert first_N(babylon(2.0, 4.0, 10), r2, 1e-12) == 6
```

:::exercise An epsilon-N proof
Show that $a_n = \dfrac{3n + 1}{n}$ converges to $3$, and find the $N$ that works for $\varepsilon = 10^{-3}$.
---solution---
1. $|a_n - 3| = \left|\dfrac{3n + 1}{n} - 3\right| = \dfrac{1}{n}$.
2. We need $1/n < \varepsilon$ for all $n \ge N$, which holds when $N > 1/\varepsilon$.
3. Since such an $N$ exists for every $\varepsilon > 0$, the limit is $3$.
4. For $\varepsilon = 10^{-3}$: $N = 1001$ works ($1/1001 < 10^{-3}$; $N = 1000$ gives exactly $10^{-3}$, which is not strictly less).
:::
