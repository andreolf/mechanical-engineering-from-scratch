An infinite sum can have a finite value: a ball that bounces forever travels a finite distance. Engineering is full of such sums, from Fourier series of vibrations to the power series inside every `sin` your computer evaluates. This lesson gives you tests that decide convergence without computing the sum, and then shows that even a convergent sum can be added up wrong in floating point, and how to fix it.

## Partial sums

A series $\sum_{k=1}^\infty a_k$ converges when its partial sums $S_n = a_1 + \cdots + a_n$ converge (lesson 01.01). The terms must tend to zero, but that's not enough: the harmonic series $\sum 1/k$ has terms tending to zero and still grows without bound, like $\ln n$.

The **geometric series** is the one you can always sum:

$$
\sum_{k=0}^{\infty} r^k = \frac{1}{1 - r} \quad (|r| < 1) .
$$

## Three tests

- **Comparison**: if $0 \le a_k \le b_k$ and $\sum b_k$ converges, so does $\sum a_k$. Compare with geometric series or with $\sum 1/k^p$, which converges exactly when $p > 1$ (the integral test with lesson 01.13's $p$-test).
- **Ratio test**: if $\left|a_{k+1}/a_k\right| \to L$, the series converges for $L < 1$ and diverges for $L > 1$. $L = 1$ says nothing.
- **Root test**: same verdicts with $L = \lim |a_k|^{1/k}$.

For the exponential series $\sum x^k/k!$ the ratio is $|x|/(k+1) \to 0$ for every $x$, so it converges everywhere, which is why the Taylor polynomials of lesson 01.07 eventually work for any $x$.

:::example A bouncing ball
A ball dropped from $h_0 = 2\ \mathrm{m}$ rebounds with coefficient of restitution $e = 0.8$: each rebound speed is $0.8$ times the impact speed, so each rebound height is $e^2 = 0.64$ times the previous one. How far does it travel in total?

1. The fall: $2\ \mathrm{m}$. Each later bounce goes up and down: $2h_0 e^2, 2h_0 e^4, \dots$
2. Total: $D = h_0 + 2h_0\sum_{k=1}^{\infty} e^{2k} = h_0 + 2h_0\dfrac{e^2}{1 - e^2}$.
3. $D = 2 + 4 \times \dfrac{0.64}{0.36} = 2 + 7.11 = 9.11\ \mathrm{m}$.
4. Time is also a geometric series, with ratio $e$: $t = t_0\left(1 + \dfrac{2e}{1 - e}\right)$ with $t_0 = \sqrt{2h_0/g} = 0.639\ \mathrm{s}$, so $t = 0.639 \times 9 = 5.75\ \mathrm{s}$.

Infinitely many bounces in under six seconds. Real balls stop sooner because $e$ drops at low speeds, but the model explains why the bouncing seems to accelerate before it stops.
:::

## Adding many numbers in floating point

Every addition rounds (lesson 00.07). Adding a small term to a large running total loses the term's low digits, and over $10^7$ terms those losses pile up to an error of order $n\varepsilon$ times the total. **Kahan summation** keeps a second variable that captures what each addition rounded away and feeds it back into the next one:

$$
y = a_k - c, \qquad t = s + y, \qquad c = (t - s) - y, \qquad s = t .
$$

Algebraically $c$ is always zero. In floating point it holds exactly the lost low-order part, and the total error becomes $O(\varepsilon)$, independent of $n$.

```python file=kahan.py
"""Naive versus Kahan compensated summation, plus two convergent series."""
import math


def naive_sum(xs):
    s = 0.0
    for x in xs:
        s += x
    return s


def kahan_sum(xs):
    s = c = 0.0
    for x in xs:
        y = x - c
        t = s + y
        c = (t - s) - y      # what the addition just rounded away
        s = t
    return s


if __name__ == "__main__":
    n = 10_000_000
    xs = [0.1] * n
    ref = math.fsum(xs)                     # correctly rounded reference
    e_naive, e_kahan = abs(naive_sum(xs) - ref), abs(kahan_sum(xs) - ref)
    print(f"sum of 1e7 x 0.1: naive error {e_naive:.2e}, Kahan error {e_kahan:.2e}")
    assert e_kahan < e_naive / 1000         # the lesson's test

    e, h0, g = 0.8, 2.0, 9.81
    D = h0 + 2 * h0 * e**2 / (1 - e**2)
    D_partial = h0 + 2 * h0 * kahan_sum(e ** (2 * k) for k in range(1, 400))
    assert abs(D - 9.1111) < 1e-4 and abs(D - D_partial) < 1e-12
    t0 = math.sqrt(2 * h0 / g)
    assert abs(t0 * (1 + 2 * e / (1 - e)) - 5.7470) < 1e-3
    basel = kahan_sum(1.0 / (k * k) for k in range(1, 100_001))
    assert abs(basel - (math.pi**2 / 6 - 1 / 100_000)) < 1e-9   # tail of 1/k^2 is about 1/n
    print(f"bouncing ball travels {D:.3f} m")
```

The naive sum of ten million copies of $0.1$ is off by $1.6\times10^{-4}$; Kahan's is correctly rounded. In a simulation that accumulates time steps or energy over millions of steps, that difference is the difference between a conserved quantity and a drifting one.

:::exercise Apply the ratio test
Decide whether $\sum_{k=1}^{\infty} \dfrac{k^2}{2^k}$ converges, then estimate its value by summing terms until they fall below $10^{-10}$.
---solution---
1. Ratio: $\dfrac{a_{k+1}}{a_k} = \dfrac{(k+1)^2}{k^2}\cdot\dfrac{1}{2} \to \dfrac12 < 1$. It converges.
2. Terms: $0.5, 1, 1.125, 1, 0.78, 0.56, \dots$: they rise first, then decay geometrically.
3. Summing to $k \approx 45$, where $k^2/2^k < 10^{-10}$, gives $6.000\,000$.
4. In fact $\sum k^2 x^k = \dfrac{x(1 + x)}{(1 - x)^3}$, which at $x = 1/2$ gives $\dfrac{0.5 \times 1.5}{0.125} = 6$ exactly.
:::
