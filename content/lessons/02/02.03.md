Gaussian elimination is the algorithm behind every direct solver: subtract multiples of rows until the matrix is upper triangular, then solve from the bottom up. It's short to write, and its two weak spots, small pivots and $n^3$ cost, explain most of what professional solvers do differently.

## Forward elimination

For column $k$, use the **pivot** $a_{kk}$ to clear every entry below it. Row $i$ becomes

$$
\text{row}_i \leftarrow \text{row}_i - \ell_{ik}\,\text{row}_k, \qquad \ell_{ik} = \frac{a_{ik}}{a_{kk}} .
$$

Apply the same operation to $\mathbf b$. After $n - 1$ columns the system is $U\mathbf x = \mathbf c$ with $U$ upper triangular.

## Back substitution

Solve the last equation first and work upwards:

$$
x_i = \frac{1}{u_{ii}}\Big(c_i - \sum_{j > i} u_{ij}\,x_j\Big) .
$$

## Pivoting

If a pivot is zero the method stops; if it's tiny the multipliers are huge and rounding errors swamp the answer. **Partial pivoting** swaps rows so the largest entry (in absolute value) in the column becomes the pivot. Consider

$$
\begin{pmatrix} 10^{-20} & 1 \\ 1 & 1 \end{pmatrix}\mathbf x = \begin{pmatrix} 1 \\ 2 \end{pmatrix}, \qquad \mathbf x \approx (1, 1) .
$$

Without a swap, $\ell = 10^{20}$, the second row becomes $(0,\, 1 - 10^{20})$, and in double precision the $1$ is lost. Back substitution gives $x_2 = 1$ and then $x_1 = 0$, completely wrong. With the swap the multiplier is $10^{-20}$ and the answer is right to machine precision.

## Cost

Clearing column $k$ touches an $(n-k)\times(n-k)$ block, so the total is about $\sum k^2 \cdot 2 \approx \tfrac23 n^3$ floating-point operations. Back substitution is only $n^2$. Doubling the number of unknowns makes a dense solve eight times slower, which is why lesson 02.14 is about exploiting zeros.

:::example Elimination by hand
Solve $\begin{pmatrix} 2 & 1 & -1 \\ -3 & -1 & 2 \\ -2 & 1 & 2 \end{pmatrix}\mathbf x = \begin{pmatrix} 8 \\ -11 \\ -3 \end{pmatrix}$ without pivoting, to see the mechanics.

1. Column 1, pivot 2: $\ell_{21} = -1.5$, $\ell_{31} = -1$. Row 2 becomes $(0,\ 0.5,\ 0.5 \mid 1)$, row 3 becomes $(0,\ 2,\ 1 \mid 5)$.
2. Column 2, pivot 0.5: $\ell_{32} = 4$. Row 3 becomes $(0,\ 0,\ -1 \mid 1)$.
3. Back substitution: $x_3 = -1$; $0.5x_2 + 0.5(-1) = 1$ gives $x_2 = 3$; $2x_1 + 3 + 1 = 8$ gives $x_1 = 2$.
4. Check row 2 of the original: $-6 - 3 - 2 = -11$. Correct.

With partial pivoting, the first step would swap in row 2 (largest entry $|-3|$). The answer is the same; the multipliers stay at most 1 in size.
:::

```python file=gauss.py
"""Gaussian elimination with partial pivoting, tested against NumPy."""
import time
import numpy as np


def solve(A, b, pivot=True):
    A = [list(map(float, r)) for r in A]
    b = list(map(float, b))
    n = len(b)
    for k in range(n - 1):
        if pivot:
            p = max(range(k, n), key=lambda i: abs(A[i][k]))
            A[k], A[p] = A[p], A[k]
            b[k], b[p] = b[p], b[k]
        if A[k][k] == 0.0:
            raise ZeroDivisionError("zero pivot")
        for i in range(k + 1, n):
            l = A[i][k] / A[k][k]
            if l == 0.0:
                continue
            for j in range(k, n):
                A[i][j] -= l * A[k][j]
            b[i] -= l * b[k]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        x[i] = (b[i] - sum(A[i][j] * x[j] for j in range(i + 1, n))) / A[i][i]
    return x


if __name__ == "__main__":
    x = solve([[2, 1, -1], [-3, -1, 2], [-2, 1, 2]], [8, -11, -3], pivot=False)
    assert np.allclose(x, [2, 3, -1], atol=1e-14)
    # tiny pivot: wrong without pivoting, right with it
    bad = solve([[1e-20, 1], [1, 1]], [1, 2], pivot=False)
    good = solve([[1e-20, 1], [1, 1]], [1, 2])
    print("no pivoting:", bad, " partial pivoting:", good)
    assert abs(bad[0]) < 1e-12 and abs(good[0] - 1) < 1e-15 and abs(good[1] - 1) < 1e-15
    # random systems match numpy, residuals at rounding level
    rng = np.random.default_rng(0)
    for n in (5, 40, 120):
        A = rng.standard_normal((n, n)); b = rng.standard_normal(n)
        t = time.perf_counter(); x = np.array(solve(A, b)); t = time.perf_counter() - t
        r = np.linalg.norm(A @ x - b) / (np.linalg.norm(A) * np.linalg.norm(x))
        assert np.allclose(x, np.linalg.solve(A, b), rtol=1e-8, atol=1e-10) and r < 1e-14
        print(f"n = {n:4d}: relative residual {r:.1e}, pure Python {t*1e3:7.1f} ms")
```

:::exercise Count the work
Estimate the floating-point operations for Gaussian elimination on a dense $10\,000 \times 10\,000$ system, and the time at $10^{11}$ operations per second (a good laptop with an optimised library). How does that compare with a $1000 \times 1000$ system?
---solution---
1. $\tfrac23 n^3 = \tfrac23 \times 10^{12} \approx 6.7\times10^{11}$ operations.
2. At $10^{11}$ per second: about 6.7 s.
3. For $n = 1000$: $6.7\times10^8$ operations, about 7 ms. Ten times the unknowns costs a thousand times the work.
4. Memory matters too: $10^8$ entries at 8 bytes is 800 MB just to store the matrix.
:::
