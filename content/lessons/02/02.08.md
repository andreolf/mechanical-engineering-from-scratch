Orthonormal bases make everything easy: coordinates are dot products, projections are sums, and nothing amplifies rounding error. The QR decomposition turns any set of independent columns into an orthonormal set $Q$ plus an upper-triangular record $R$ of how to rebuild the originals. It's the standard way to do least squares, and the first step of the QR eigenvalue algorithm.

## Gram-Schmidt

Process the columns $\mathbf a_1, \mathbf a_2, \dots$ in order. Subtract from each the parts along the directions you already have, then normalise:

$$
\mathbf v_j = \mathbf a_j - \sum_{i<j} (\mathbf q_i\cdot\mathbf a_j)\,\mathbf q_i, \qquad \mathbf q_j = \frac{\mathbf v_j}{\|\mathbf v_j\|} .
$$

The coefficients are the entries of $R$: $r_{ij} = \mathbf q_i\cdot\mathbf a_j$ and $r_{jj} = \|\mathbf v_j\|$. Then $A = QR$, with $Q^{\mathsf T}Q = I$.

## Classical versus modified

The formula above (classical Gram-Schmidt) computes every $r_{ij}$ from the original $\mathbf a_j$. If the columns are nearly dependent, the $\mathbf q$'s it produces drift away from orthogonal. **Modified Gram-Schmidt** subtracts one direction at a time from the running vector, which is the same in exact arithmetic but much better in floating point. **Householder reflections**, used by LAPACK and `np.linalg.qr`, are better still: $Q$ is orthogonal to machine precision regardless of conditioning.

| Hilbert matrix | $\kappa(A)$ | classical GS | modified GS | Householder |
|---|---|---|---|---|
| $6\times6$ | $1.5\times10^{7}$ | $3\times10^{-4}$ | $1\times10^{-9}$ | $9\times10^{-16}$ |
| $8\times8$ | $1.5\times10^{10}$ | $1.4$ | $4\times10^{-7}$ | $7\times10^{-16}$ |
| $10\times10$ | $1.6\times10^{13}$ | $3.5$ | $2\times10^{-4}$ | $1\times10^{-15}$ |

The table shows $\|Q^{\mathsf T}Q - I\|_F$, the loss of orthogonality, measured by the code below.

## Least squares with QR

Substitute $A = QR$ into the normal equations: $R^{\mathsf T}Q^{\mathsf T}QR\hat{\mathbf x} = R^{\mathsf T}Q^{\mathsf T}\mathbf b$, so

$$
R\,\hat{\mathbf x} = Q^{\mathsf T}\mathbf b ,
$$

a triangular solve. The condition number stays at $\kappa(A)$ instead of $\kappa(A)^2$.

:::example QR by hand
$A = \begin{pmatrix} 1 & 1 \\ 1 & 0 \\ 0 & 1 \end{pmatrix}$.

1. $r_{11} = \|\mathbf a_1\| = \sqrt2 = 1.4142$, $\mathbf q_1 = (1, 1, 0)/\sqrt2$.
2. $r_{12} = \mathbf q_1\cdot\mathbf a_2 = 1/\sqrt2 = 0.7071$.
3. $\mathbf v_2 = \mathbf a_2 - r_{12}\mathbf q_1 = (1, 0, 1) - (0.5, 0.5, 0) = (0.5, -0.5, 1)$.
4. $r_{22} = \|\mathbf v_2\| = \sqrt{1.5} = 1.2247$, $\mathbf q_2 = (0.4082, -0.4082, 0.8165)$.
5. Check orthogonality: $\mathbf q_1\cdot\mathbf q_2 = (0.4082 - 0.4082 + 0)/\sqrt2 = 0$. Check the rebuild: $r_{12}\mathbf q_1 + r_{22}\mathbf q_2 = (0.5, 0.5, 0) + (0.5, -0.5, 1) = \mathbf a_2$.
:::

```python file=qr.py
"""Classical and modified Gram-Schmidt versus Householder QR."""
import numpy as np


def cgs(A):
    m, n = A.shape; Q = np.zeros((m, n)); R = np.zeros((n, n))
    for j in range(n):
        R[:j, j] = Q[:, :j].T @ A[:, j]            # all coefficients from the original column
        v = A[:, j] - Q[:, :j] @ R[:j, j]
        R[j, j] = np.linalg.norm(v); Q[:, j] = v / R[j, j]
    return Q, R


def mgs(A):
    m, n = A.shape; V = A.astype(float).copy(); Q = np.zeros((m, n)); R = np.zeros((n, n))
    for j in range(n):
        R[j, j] = np.linalg.norm(V[:, j]); Q[:, j] = V[:, j] / R[j, j]
        for k in range(j + 1, n):                  # remove q_j from the remaining columns right away
            R[j, k] = Q[:, j] @ V[:, k]; V[:, k] -= R[j, k] * Q[:, j]
    return Q, R


def householder(A):
    m, n = A.shape; R = A.astype(float).copy(); Q = np.eye(m)
    for k in range(n):
        x = R[k:, k]; v = x.copy()
        v[0] += np.copysign(np.linalg.norm(x), x[0])   # sign choice avoids cancellation
        v /= np.linalg.norm(v)
        R[k:, :] -= 2 * np.outer(v, v @ R[k:, :])
        Q[:, k:] -= 2 * np.outer(Q[:, k:] @ v, v)
    return Q[:, :n], np.triu(R[:n])


hilbert = lambda n: 1.0 / (np.arange(n)[:, None] + np.arange(n)[None, :] + 1)

if __name__ == "__main__":
    A = np.array([[1, 1], [1, 0], [0, 1.0]])
    for f in (cgs, mgs, householder):
        Q, R = f(A)
        Q, R = Q * np.sign(np.diag(R)), R * np.sign(np.diag(R))[:, None]   # fix signs to compare
        assert np.allclose(Q @ R, A) and np.allclose(R, [[2 ** 0.5, 2 ** -0.5], [0, 1.5 ** 0.5]])
    print(" n   cond      CGS       MGS       Householder")
    for n in (6, 8, 10):
        H = hilbert(n)
        loss = [np.linalg.norm(f(H)[0].T @ f(H)[0] - np.eye(n)) for f in (cgs, mgs, householder)]
        print(f"{n:2d}  {np.linalg.cond(H):.1e}  " + "  ".join(f"{l:.1e}" for l in loss))
        assert loss[2] < 1e-14 < loss[1] < loss[0]
    # least squares through QR matches lstsq on a tall random problem
    rng = np.random.default_rng(6)
    B, y = rng.standard_normal((50, 4)), rng.standard_normal(50)
    Q, R = householder(B)
    assert np.allclose(np.linalg.solve(R, Q.T @ y), np.linalg.lstsq(B, y, rcond=None)[0])
```

:::exercise Orthonormalise three vectors
Apply Gram-Schmidt to $\mathbf a_1 = (1, 0, 0)$, $\mathbf a_2 = (1, 1, 0)$, $\mathbf a_3 = (1, 1, 1)$. What are $Q$ and $R$?
---solution---
1. $\mathbf q_1 = (1, 0, 0)$, $r_{11} = 1$.
2. $r_{12} = \mathbf q_1\cdot\mathbf a_2 = 1$; $\mathbf v_2 = (0, 1, 0)$, so $r_{22} = 1$ and $\mathbf q_2 = (0, 1, 0)$.
3. $r_{13} = 1$, $r_{23} = 1$; $\mathbf v_3 = (0, 0, 1)$, $r_{33} = 1$.
4. $Q = I$ and $R = \begin{pmatrix} 1 & 1 & 1 \\ 0 & 1 & 1 \\ 0 & 0 & 1 \end{pmatrix}$, which is $A$ itself: $A$ was already upper triangular.
:::
