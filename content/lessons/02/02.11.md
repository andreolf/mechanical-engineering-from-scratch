Deform an elastic structure and you store energy in it. If every possible deformation stores positive energy, the structure is stable and its stiffness matrix is **positive definite**. That one property makes systems uniquely solvable, makes Cholesky factorisation work at half the cost of LU, and is what the conjugate gradient method in lesson 02.15 relies on.

## Quadratic forms and energy

For a linear spring system with stiffness matrix $K$ and nodal displacements $\mathbf u$, the stored strain energy is

$$
U = \tfrac12\,\mathbf u^{\mathsf T}K\,\mathbf u .
$$

A symmetric matrix is **positive definite** (PD) if $\mathbf u^{\mathsf T}K\mathbf u > 0$ for every $\mathbf u \ne \mathbf 0$, and **positive semi-definite** if it's only $\ge 0$. A free-floating structure is semi-definite: rigid-body motions cost zero energy.

## Four equivalent tests

For a symmetric matrix, these all mean the same thing:

1. $\mathbf u^{\mathsf T}K\mathbf u > 0$ for all $\mathbf u \ne \mathbf 0$.
2. All eigenvalues are positive (write $\mathbf u$ in the eigenvector basis: the energy is $\sum\lambda_i c_i^2$).
3. All pivots of elimination are positive (no row swaps needed).
4. $K = LL^{\mathsf T}$ with $L$ lower triangular and a positive diagonal: the **Cholesky factorisation** exists.

Test 4 is the practical one: try to factor, and if a square root of a negative number appears, the matrix isn't PD.

## Cholesky

Matching entries of $K = LL^{\mathsf T}$ column by column gives

$$
\ell_{jj} = \sqrt{k_{jj} - \sum_{m<j}\ell_{jm}^2}, \qquad \ell_{ij} = \frac{1}{\ell_{jj}}\Big(k_{ij} - \sum_{m<j}\ell_{im}\ell_{jm}\Big) \quad (i > j).
$$

It costs $\tfrac13 n^3$ operations, half of LU, stores only one triangle, and needs no pivoting for PD matrices. Most FEM codes solve $K\mathbf u = \mathbf f$ this way (in sparse form).

## Minimum energy

For PD $K$, the solution of $K\mathbf u = \mathbf f$ is the unique minimiser of the total potential energy

$$
\Pi(\mathbf u) = \tfrac12\,\mathbf u^{\mathsf T}K\mathbf u - \mathbf f^{\mathsf T}\mathbf u ,
$$

because the gradient of $\Pi$ is $K\mathbf u - \mathbf f$. Setting it to zero is equilibrium. This link between linear algebra and energy is the foundation of the finite element method in Phase 16.

:::example Energy in a two-spring chain
Springs $k = 1000$ N/mm from a wall to node 1 and from node 1 to node 2: $K = 1000\begin{pmatrix} 2 & -1 \\ -1 & 1 \end{pmatrix}$ N/mm.

1. Displacement $\mathbf u = (1, 2)$ mm: $K\mathbf u = 1000\,(2 - 2,\ -1 + 2) = (0, 1000)$ N, so $\mathbf u^{\mathsf T}K\mathbf u = 2000$ N mm and $U = 1000$ N mm $= 1$ J.
2. Check with the springs directly: spring 1 stretches 1 mm, spring 2 stretches $2 - 1 = 1$ mm, so $U = \tfrac12\cdot1000\cdot(1^2 + 1^2) = 1000$ N mm.
3. Cholesky of $\begin{pmatrix} 2 & -1 \\ -1 & 1 \end{pmatrix}$: $\ell_{11} = \sqrt2 = 1.4142$, $\ell_{21} = -1/\sqrt2 = -0.7071$, $\ell_{22} = \sqrt{1 - 0.5} = 0.7071$. All positive, so it's PD.
4. Remove the wall spring: $\begin{pmatrix} 1 & -1 \\ -1 & 1 \end{pmatrix}$ gives $\ell_{11} = 1$, $\ell_{21} = -1$, $\ell_{22} = \sqrt{1 - 1} = 0$. Cholesky breaks down: semi-definite, a free motion.
:::

```python file=cholesky.py
"""Cholesky factorisation, a positive-definiteness test, and the energy principle."""
import math
import numpy as np


class NotPositiveDefinite(ValueError):
    pass


def cholesky(K):
    K = np.array(K, dtype=float); n = len(K); L = np.zeros_like(K)
    for j in range(n):
        d = K[j, j] - L[j, :j] @ L[j, :j]
        if d <= 1e-14 * abs(K[j, j]):
            raise NotPositiveDefinite(f"pivot {j} is {d:.3g}")
        L[j, j] = math.sqrt(d)
        L[j + 1:, j] = (K[j + 1:, j] - L[j + 1:, :j] @ L[j, :j]) / L[j, j]
    return L


def solve_spd(K, f):
    L = cholesky(K)
    y = np.linalg.solve(L, f)        # triangular solves (np.linalg.solve is fine for clarity here)
    return np.linalg.solve(L.T, y)


def is_pd(K):
    try:
        cholesky(K); return True
    except NotPositiveDefinite:
        return False


if __name__ == "__main__":
    K = 1000 * np.array([[2, -1], [-1, 1.0]])
    u = np.array([1.0, 2.0])
    U = 0.5 * u @ K @ u
    assert abs(U - 1000) < 1e-12
    L = cholesky(K / 1000)
    assert np.allclose(L, [[2 ** 0.5, 0], [-(0.5 ** 0.5), 0.5 ** 0.5]]) and np.allclose(L @ L.T, K / 1000)
    assert not is_pd([[1, -1], [-1, 1]]) and not is_pd([[1, 2], [2, 1]])
    # spring chain of n springs fixed at one end: PD; energy minimum = solution
    n = 50
    Kc = 2 * np.eye(n) - np.eye(n, k=1) - np.eye(n, k=-1); Kc[-1, -1] = 1
    f = np.zeros(n); f[-1] = 1.0                      # unit pull at the free end
    u = solve_spd(Kc, f)
    assert np.allclose(u, np.arange(1, n + 1))        # each spring stretches by 1
    Pi = lambda v: 0.5 * v @ Kc @ v - f @ v
    rng = np.random.default_rng(9)
    assert all(Pi(u + 1e-3 * rng.standard_normal(n)) > Pi(u) for _ in range(200))
    # random PD matrices: eigenvalues positive, Cholesky matches numpy
    for _ in range(20):
        B = rng.standard_normal((8, 8)); S = B @ B.T + 0.1 * np.eye(8)
        assert is_pd(S) and np.all(np.linalg.eigvalsh(S) > 0) and np.allclose(cholesky(S), np.linalg.cholesky(S))
    print(f"strain energy {U:.0f} N mm; 50-spring chain solved by Cholesky; energy is minimal at the solution")
```

:::exercise Is it positive definite?
Decide whether $A = \begin{pmatrix} 4 & 2 & 0 \\ 2 & 3 & 1 \\ 0 & 1 & 2 \end{pmatrix}$ is PD by computing its Cholesky factor.
---solution---
1. $\ell_{11} = 2$, $\ell_{21} = 2/2 = 1$, $\ell_{31} = 0$.
2. $\ell_{22} = \sqrt{3 - 1} = \sqrt2 = 1.414$, $\ell_{32} = (1 - 0)/\sqrt2 = 0.707$.
3. $\ell_{33} = \sqrt{2 - 0 - 0.5} = \sqrt{1.5} = 1.225$.
4. All diagonal entries are real and positive, so $A$ is PD. Check: $\det A = (2\cdot\sqrt2\cdot\sqrt{1.5})^2 = 12$, and directly $4(6 - 1) - 2(4 - 0) = 12$.
:::
