A structure is analysed for many load cases: self-weight, wind from four directions, a crane at six positions. The stiffness matrix stays the same; only the right-hand side changes. LU decomposition stores the result of elimination once, so each new load case costs $n^2$ operations instead of $n^3$.

## Elimination is a factorisation

The multipliers $\ell_{ik}$ from Gaussian elimination aren't thrown away. Put them below the diagonal of a unit lower-triangular matrix $L$, keep the eliminated matrix as $U$, and

$$
A = LU .
$$

With row swaps from pivoting, recorded in a permutation matrix $P$, the general form is $PA = LU$.

## Solving with the factors

$A\mathbf x = \mathbf b$ becomes $L(U\mathbf x) = \mathbf b$. Solve two triangular systems:

1. Forward substitution: $L\mathbf y = P\mathbf b$, top to bottom.
2. Back substitution: $U\mathbf x = \mathbf y$, bottom to top.

Each costs about $n^2$ operations. Factor once at $\tfrac23 n^3$, then solve as many right-hand sides as you like.

:::note Never form the inverse
$A^{-1}\mathbf b$ is fine on paper. In code, computing $A^{-1}$ costs about three times as much as $LU$, uses more memory for sparse matrices, and is less accurate. Keep the factors and solve.
:::

## Determinant for free

$\det L = 1$ and $\det U$ is the product of the pivots, so $\det A = \pm \prod u_{ii}$, with the sign set by the number of row swaps. Lesson 02.05 uses this.

:::example Factor once, solve twice
Take the matrix from lesson 02.03, $A = \begin{pmatrix} 2 & 1 & -1 \\ -3 & -1 & 2 \\ -2 & 1 & 2 \end{pmatrix}$. The multipliers were $\ell_{21} = -1.5$, $\ell_{31} = -1$, $\ell_{32} = 4$, so

$$
L = \begin{pmatrix} 1 & 0 & 0 \\ -1.5 & 1 & 0 \\ -1 & 4 & 1 \end{pmatrix}, \quad U = \begin{pmatrix} 2 & 1 & -1 \\ 0 & 0.5 & 0.5 \\ 0 & 0 & -1 \end{pmatrix} .
$$

New load case $\mathbf b = (1, 0, 0)$:

1. Forward: $y_1 = 1$; $y_2 = 0 + 1.5 \cdot 1 = 1.5$; $y_3 = 0 + 1 - 4 \cdot 1.5 = -5$.
2. Back: $x_3 = -5/(-1) = 5$; $0.5x_2 + 0.5 \cdot 5 = 1.5$ gives $x_2 = -2$; $2x_1 - 2 - 5 = 1$ gives $x_1 = 4$.
3. Check: $A\mathbf x = (8 - 2 - 5,\ -12 + 2 + 10,\ -8 - 2 + 10) = (1, 0, 0)$.

And $\det A = 2 \times 0.5 \times (-1) = -1$, with no swaps.
:::

```python file=lu.py
"""LU decomposition with partial pivoting: factor once, solve many load cases."""
import numpy as np


def lu_factor(A):
    A = np.array(A, dtype=float)
    n = A.shape[0]
    perm = np.arange(n)
    swaps = 0
    for k in range(n - 1):
        p = k + np.argmax(np.abs(A[k:, k]))
        if p != k:
            A[[k, p]] = A[[p, k]]; perm[[k, p]] = perm[[p, k]]; swaps += 1
        A[k + 1:, k] /= A[k, k]                                    # multipliers stored in place
        A[k + 1:, k + 1:] -= np.outer(A[k + 1:, k], A[k, k + 1:])  # update the trailing block
    return A, perm, swaps


def lu_solve(F, perm, b):
    n = len(b)
    y = np.array(b, dtype=float)[perm]
    for i in range(n):                    # forward, unit diagonal
        y[i] -= F[i, :i] @ y[:i]
    x = y.copy()
    for i in range(n - 1, -1, -1):        # back
        x[i] = (y[i] - F[i, i + 1:] @ x[i + 1:]) / F[i, i]
    return x


def det(F, swaps):
    return (-1) ** swaps * np.prod(np.diag(F))


if __name__ == "__main__":
    A = [[2, 1, -1], [-3, -1, 2], [-2, 1, 2]]
    F, perm, s = lu_factor(A)
    L = np.tril(F, -1) + np.eye(3); U = np.triu(F)
    assert np.allclose(L @ U, np.array(A, float)[perm])
    assert np.allclose(lu_solve(F, perm, [1, 0, 0]), [4, -2, 5])
    assert np.allclose(lu_solve(F, perm, [8, -11, -3]), [2, 3, -1])
    assert abs(det(F, s) - (-1)) < 1e-12
    # many load cases on a bigger matrix: all match numpy
    rng = np.random.default_rng(2)
    n = 200
    K = rng.standard_normal((n, n)) + n * np.eye(n)
    F, perm, s = lu_factor(K)
    B = rng.standard_normal((n, 25))
    X = np.column_stack([lu_solve(F, perm, B[:, j]) for j in range(25)])
    assert np.allclose(K @ X, B, atol=1e-10)
    assert np.isclose(det(F, s), np.linalg.det(K), rtol=1e-9)
    print(f"factored once, solved 25 load cases; work ratio ~ {(2/3*n**3 + 25*2*n**2)/(25*2/3*n**3):.3f} of re-eliminating each time")
```

:::exercise When does LU pay off?
For $n = 2000$, compare the operation count of solving 50 load cases by (a) repeating Gaussian elimination each time and (b) one LU factorisation plus 50 pairs of triangular solves.
---solution---
1. (a) $50 \times \tfrac23 n^3 = 50 \times 5.33\times10^9 = 2.67\times10^{11}$.
2. (b) $\tfrac23 n^3 + 50 \times 2n^2 = 5.33\times10^9 + 4\times10^8 = 5.73\times10^9$.
3. LU is about 46 times cheaper. With one load case the two are the same; the gain grows with every extra right-hand side.
:::
