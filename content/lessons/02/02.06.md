Rank answers a practical question: how many independent equations do you actually have? A truss with a redundant bar, a sensor array with two sensors measuring the same thing, a free-floating part with rigid-body motions: each shows up as a rank deficiency. This lesson gives you the four ideas you need (span, independence, rank, null space) and the code to compute them reliably.

## Span, independence, basis

The **span** of vectors $\mathbf v_1, \dots, \mathbf v_k$ is every combination $c_1\mathbf v_1 + \dots + c_k\mathbf v_k$. The vectors are **independent** if the only combination giving $\mathbf 0$ is all $c_i = 0$. An independent spanning set is a **basis**, and every basis of a space has the same number of vectors: its **dimension**.

## The column space and the null space

For an $m\times n$ matrix $A$:

- The **column space** $C(A)$ is the span of the columns: every $A\mathbf x$. Its dimension is the **rank** $r$.
- The **null space** $N(A)$ is every $\mathbf x$ with $A\mathbf x = \mathbf 0$.

They're tied by the **rank-nullity theorem**:

$$
\operatorname{rank} A + \dim N(A) = n \quad (\text{the number of columns}).
$$

So each independent way the system can move freely costs one rank.

## Computing rank in floating point

In exact arithmetic, rank is the number of nonzero pivots. In floating point, a "zero" pivot comes out as $10^{-17}$, so you need a tolerance. The robust tool is the singular value decomposition (lesson 02.12): rank is the number of singular values above $\varepsilon\,\sigma_{\max}\,\max(m,n)$. The code below implements reduced row echelon form with a tolerance and compares it with the SVD answer.

:::example Count the free motions
The free three-mass chain from lesson 02.05 has

$$
K = \begin{pmatrix} 1 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 1 \end{pmatrix}.
$$

1. Row reduce: add row 1 to row 2 to get $(0, 1, -1)$; add the new row 2 to row 3 to get $(0, 0, 0)$.
2. Two nonzero pivots, so $\operatorname{rank} K = 2$.
3. Rank-nullity: $\dim N(K) = 3 - 2 = 1$.
4. The null space: from row 2, $x_2 = x_3$; from row 1, $x_1 = x_2$. So $N(K)$ is spanned by $(1, 1, 1)$, the rigid shift.
5. Fix one node (delete its row and column) and the rank of the remaining $2\times2$ matrix is 2: the system is solvable.
:::

```python file=rank.py
"""Rank and null space by row reduction with a tolerance, checked against the SVD."""
import math
import numpy as np


def rref(A, tol=None):
    R = np.array(A, dtype=float); m, n = R.shape
    tol = tol if tol is not None else max(m, n) * np.finfo(float).eps * max(1.0, np.abs(R).max())
    pivots, row = [], 0
    for col in range(n):
        if row == m:
            break
        p = row + np.argmax(np.abs(R[row:, col]))
        if abs(R[p, col]) <= tol:
            R[row:, col] = 0.0
            continue
        R[[row, p]] = R[[p, row]]
        R[row] /= R[row, col]
        for i in range(m):
            if i != row:
                R[i] -= R[i, col] * R[row]
        pivots.append(col); row += 1
    return R, pivots


def null_space(A):
    R, piv = rref(A); n = R.shape[1]
    free = [j for j in range(n) if j not in piv]
    basis = []
    for f in free:
        v = np.zeros(n); v[f] = 1.0
        for i, p in enumerate(piv):
            v[p] = -R[i, f]
        basis.append(v)
    return np.array(basis).T if basis else np.zeros((n, 0))


def rank_svd(A):
    s = np.linalg.svd(np.array(A, float), compute_uv=False)
    return int(np.sum(s > s[0] * max(np.shape(A)) * np.finfo(float).eps))


def truss_stiffness(nodes, bars, EA=1.0):
    K = np.zeros((2 * len(nodes), 2 * len(nodes)))
    for i, j in bars:
        d = np.subtract(nodes[j], nodes[i]); L = math.hypot(*d); c, s = d / L
        k = EA / L * np.outer([-c, -s, c, s], [-c, -s, c, s])
        idx = [2 * i, 2 * i + 1, 2 * j, 2 * j + 1]
        K[np.ix_(idx, idx)] += k
    return K


if __name__ == "__main__":
    K = [[1, -1, 0], [-1, 2, -1], [0, -1, 1]]
    R, piv = rref(K)
    N = null_space(K)
    assert len(piv) == 2 and rank_svd(K) == 2 and N.shape == (3, 1)
    assert np.allclose(N[:, 0] / N[0, 0], [1, 1, 1])
    # a free triangle truss: rank 3, null space = 2 translations + 1 rotation
    tri = truss_stiffness([(0, 0), (2, 0), (1, 1.6)], [(0, 1), (1, 2), (2, 0)])
    Nt = null_space(tri)
    print("triangle truss: rank", len(rref(tri)[1]), "svd rank", rank_svd(tri), "null dim", Nt.shape[1])
    assert len(rref(tri)[1]) == 3 == rank_svd(tri) and Nt.shape[1] == 3
    assert np.allclose(tri @ Nt, 0, atol=1e-12)
    rot = np.array([c for x, y in [(0, 0), (2, 0), (1, 1.6)] for c in (-y, x)])  # small rotation: u = -y, v = x
    assert np.allclose(tri @ rot, 0, atol=1e-12)
    # rank-nullity on random low-rank matrices
    rng = np.random.default_rng(5)
    for r in range(1, 6):
        A = rng.standard_normal((7, r)) @ rng.standard_normal((r, 6))
        assert rank_svd(A) == r and len(rref(A)[1]) == r and null_space(A).shape[1] == 6 - r
    print("rank-nullity holds for all tests")
```

:::exercise Supports for a triangle
The free triangle truss has three rigid-body motions. You pin node 1 (fixing $u_1$ and $v_1$). What's the rank of the remaining $4\times4$ stiffness matrix, and is it enough? Where would you put one more support, and in which direction?
---solution---
1. Pinning removes the two translations but not the rotation about node 1, so the remaining $4\times4$ matrix has rank 3 and one null vector.
2. Not enough: the triangle can still spin about the pin.
3. Add a roller at node 2 that stops motion perpendicular to the line from node 1 to node 2: for nodes $(0,0)$ and $(2,0)$, fix $v_2$. Now the matrix that's left is $3\times3$ with rank 3.
4. A roller at node 2 fixing $u_2$ would fail, because rotating about node 1 moves node 2 vertically, not horizontally.
:::
