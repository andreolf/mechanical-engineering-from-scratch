Most vectors change direction when a matrix acts on them. A few special ones only stretch: those are eigenvectors, and the stretch factors are eigenvalues. In mechanics they are the natural frequencies and mode shapes of a structure, the principal stresses in a material, and the growth rates that decide whether a system is stable.

## The definition

$$
A\mathbf v = \lambda\mathbf v, \qquad \mathbf v \ne \mathbf 0 .
$$

Rewrite it as $(A - \lambda I)\mathbf v = \mathbf 0$. A nonzero solution exists only when $A - \lambda I$ is singular:

$$
\det(A - \lambda I) = 0 .
$$

For an $n\times n$ matrix this **characteristic polynomial** has degree $n$, so there are $n$ eigenvalues counted with multiplicity, possibly complex. For $2\times2$: $\lambda^2 - (\operatorname{tr}A)\lambda + \det A = 0$. Two handy checks: the eigenvalues sum to the trace and multiply to the determinant.

Cyan lines are eigenvector directions: vectors on them only stretch. Set a₁₂ = −a₂₁ (for example 0 and 1, then −1 and 1) to get a rotation-like matrix with complex eigenvalues and no real eigenvector.
:::

## Why mechanics cares: vibration modes

Free vibration of masses on springs obeys $M\ddot{\mathbf x} + K\mathbf x = \mathbf 0$. Try $\mathbf x = \mathbf v\cos\omega t$:

$$
K\mathbf v = \omega^2 M\mathbf v .
$$

That's an eigenvalue problem: $\omega^2$ are eigenvalues of $M^{-1}K$, and each eigenvector $\mathbf v$ is a mode shape, the pattern in which every mass moves in step at one frequency.

## Computing them: power iteration

Polynomial roots are a terrible way to find eigenvalues numerically. Iterative methods work on the matrix directly. The simplest is **power iteration**: repeat $\mathbf x \leftarrow A\mathbf x / \|A\mathbf x\|$. Any component along the dominant eigenvector grows fastest, so $\mathbf x$ turns towards it, at a rate set by $|\lambda_2/\lambda_1|$. Applying it to $A^{-1}$ (solving instead of multiplying) finds the smallest eigenvalue: **inverse iteration**. In vibration, the smallest is the one you care about most, the fundamental frequency. Production codes use the QR algorithm or Lanczos, which build on the same idea.

:::example Two masses, two modes
Two 2 kg masses on a line, joined wall to mass 1 to mass 2 by springs of $k = 800$ N/m.

1. $M = 2I$, $K = \begin{pmatrix} 1600 & -800 \\ -800 & 800 \end{pmatrix}$, so $M^{-1}K = \begin{pmatrix} 800 & -400 \\ -400 & 400 \end{pmatrix}$.
2. Trace 1200, determinant $320\,000 - 160\,000 = 160\,000$. Solve $\lambda^2 - 1200\lambda + 160\,000 = 0$: $\lambda = 600 \mp 447.2$, so $\omega_1^2 = 152.8$ and $\omega_2^2 = 1047.2$ s$^{-2}$.
3. Frequencies: $\omega_1 = 12.36$ rad/s ($f_1 = 1.97$ Hz) and $\omega_2 = 32.36$ rad/s ($f_2 = 5.15$ Hz).
4. Mode 1: from row 1, $(800 - 152.8)v_1 = 400 v_2$, so $\mathbf v = (1, 1.618)$. Both masses move the same way, the outer one more.
5. Mode 2: $\mathbf v = (1, -0.618)$. The masses move against each other.

The golden ratio isn't a coincidence: the eigenvalues are $\tfrac{k}{m}\cdot\tfrac{3 \mp \sqrt5}{2}$.
:::

```python file=eigen.py
"""Power iteration and inverse iteration, checked on a two-mass system and random matrices."""
import math
import numpy as np


def power_iteration(A, iters=5000, tol=1e-13, seed=0):
    x = np.random.default_rng(seed).standard_normal(len(A))
    lam = 0.0
    for _ in range(iters):
        y = A @ x
        x_new = y / np.linalg.norm(y)
        lam_new = x_new @ A @ x_new                 # Rayleigh quotient
        # stop on the residual, not on lambda: lambda converges twice as fast as the vector
        if np.linalg.norm(A @ x_new - lam_new * x_new) < tol * abs(lam_new):
            return lam_new, x_new
        x, lam = x_new, lam_new
    return lam, x


def inverse_iteration(A, shift=0.0, iters=5000, tol=1e-13):
    n = len(A); x = np.ones(n) / math.sqrt(n); lam = None
    B = A - shift * np.eye(n)
    for _ in range(iters):
        y = np.linalg.solve(B, x)
        x = y / np.linalg.norm(y)
        lam_new = x @ A @ x
        if np.linalg.norm(A @ x - lam_new * x) < tol * np.abs(A).max():
            break
        lam = lam_new
    return lam_new, x


if __name__ == "__main__":
    k, m = 800.0, 2.0
    A = np.array([[2 * k, -k], [-k, k]]) / m
    lmax, vmax = power_iteration(A)
    lmin, vmin = inverse_iteration(A)
    print(f"omega_1 = {math.sqrt(lmin):.4f} rad/s, omega_2 = {math.sqrt(lmax):.4f} rad/s")
    phi = (1 + 5 ** 0.5) / 2
    assert abs(lmin - k / m * (3 - 5 ** 0.5) / 2) < 1e-9 and abs(lmax - k / m * (3 + 5 ** 0.5) / 2) < 1e-9
    assert abs(vmin[1] / vmin[0] - phi) < 1e-8 and abs(vmax[1] / vmax[0] + 1 / phi) < 1e-8
    assert abs(lmin + lmax - np.trace(A)) < 1e-9 and abs(lmin * lmax - np.linalg.det(A)) < 1e-6
    # symmetric random matrices: extreme eigenvalues match numpy
    rng = np.random.default_rng(7)
    B = rng.standard_normal((30, 30)); S = B @ B.T + np.eye(30)
    w = np.linalg.eigvalsh(S)
    assert abs(power_iteration(S, iters=20000)[0] - w[-1]) < 1e-8 * w[-1]
    assert abs(inverse_iteration(S)[0] - w[0]) < 1e-8 * w[-1]
    # a shift picks out an interior eigenvalue
    target = w[12] + 0.01
    assert abs(inverse_iteration(S, shift=target)[0] - w[12]) < 1e-8 * w[-1]
    print("power, inverse and shifted inverse iteration agree with numpy")
```

:::exercise Eigenvalues of a shear
Find the eigenvalues and eigenvectors of $A = \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix}$, a horizontal shear. How many independent eigenvectors are there?
---solution---
1. $\det(A - \lambda I) = (1 - \lambda)^2 = 0$, so $\lambda = 1$ twice.
2. $(A - I)\mathbf v = \begin{pmatrix} 0 & 2 \\ 0 & 0 \end{pmatrix}\mathbf v = \mathbf 0$ gives $v_2 = 0$: only $\mathbf v = (1, 0)$.
3. One independent eigenvector for a double eigenvalue. The matrix is **defective**: it can't be diagonalised. Symmetric matrices never do this (lesson 02.10).
:::
