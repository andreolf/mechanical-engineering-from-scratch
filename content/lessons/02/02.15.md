For the biggest problems (3D meshes with tens of millions of unknowns) even sparse elimination runs out of memory. Iterative solvers never factor the matrix. They start from a guess and improve it using only matrix-vector products, which cost as much as the number of nonzeros. How fast they converge depends on the matrix, and that's what this lesson is about.

## Splitting methods

Write $A = D + L + U$ (diagonal, strictly lower, strictly upper).

- **Jacobi**: solve each equation for its own unknown using the old values of the others, $\mathbf x^{k+1} = D^{-1}(\mathbf b - (L + U)\mathbf x^k)$.
- **Gauss-Seidel**: the same, but use each new value as soon as it's computed.
- **SOR** (successive over-relaxation): take the Gauss-Seidel step and overshoot it by a factor $\omega \in (1, 2)$.

The error obeys $\mathbf e^{k+1} = G\,\mathbf e^k$ for an iteration matrix $G$, so each step multiplies the error by roughly the **spectral radius** $\rho(G)$, its largest eigenvalue in absolute value. To shrink the error by a factor $10^{-8}$ you need about $\ln10^{-8}/\ln\rho$ iterations.

For the 1D Poisson matrix (tridiagonal $-1, 2, -1$) with $n$ unknowns, everything is known in closed form: $\rho_J = \cos\frac{\pi}{n+1}$, $\rho_{GS} = \rho_J^2$, and the best SOR factor $\omega^* = 2/(1 + \sin\frac{\pi}{n+1})$ gives $\rho = \omega^* - 1$.

## Conjugate gradients

For symmetric positive definite matrices (lesson 02.11) there's a far better method. Solving $A\mathbf x = \mathbf b$ is minimising $\tfrac12\mathbf x^{\mathsf T}A\mathbf x - \mathbf b^{\mathsf T}\mathbf x$. Steepest descent zigzags; **conjugate gradients** (CG) chooses search directions that are $A$-orthogonal, so each step's progress is never undone. In exact arithmetic it finishes in at most $n$ steps, and in practice the error falls like

$$
\Big(\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\Big)^k ,
$$

which depends on $\sqrt\kappa$ instead of $\kappa$. With a good **preconditioner** (an approximate inverse that's cheap to apply, such as incomplete Cholesky or multigrid) $\kappa$ shrinks and CG becomes the workhorse of large-scale FEM.

:::example How many iterations for n = 40?
The 1D Poisson matrix with $n = 40$ has $\kappa = 681$. Target: error reduced by $10^{-8}$, so $\ln10^{-8} = -18.42$.

1. Jacobi: $\rho = \cos(\pi/41) = 0.99707$, so $-18.42/\ln0.99707 = 6270$ iterations (the code measures 6238).
2. Gauss-Seidel: $\rho = 0.99413$, half as many: 3130.
3. SOR with $\omega^* = 2/(1 + \sin(\pi/41)) = 1.858$: $\rho = 0.858$, so $-18.42/\ln0.858 = 120$ iterations. The code measures 152, because SOR's error falls unevenly at first.
4. CG: at most 40 steps in exact arithmetic; the bound with $\sqrt{681} = 26.1$ gives a factor $0.926$ per step, about 240 steps as a worst case, but the finite-termination property kicks in first. The code needs only 20: a uniform load is symmetric, so it excites just half of the 40 eigenvectors, and CG finishes once it has handled those.

Each Jacobi or CG iteration costs about $5n$ operations here, so CG's 40 steps cost less than a single dense solve, and the gap grows with $n$.
:::

```python file=iterative.py
"""Jacobi, Gauss-Seidel, SOR and conjugate gradients on the 1D Poisson problem."""
import math
import numpy as np


def poisson1d(n):
    return 2 * np.eye(n) - np.eye(n, k=1) - np.eye(n, k=-1)


def sor(A, b, omega=1.0, tol=1e-8, max_iter=100000):
    """omega = 1 is Gauss-Seidel."""
    x = np.zeros_like(b); r0 = np.linalg.norm(b)
    for k in range(1, max_iter + 1):
        for i in range(len(b)):
            gs = (b[i] - A[i, :i] @ x[:i] - A[i, i + 1:] @ x[i + 1:]) / A[i, i]
            x[i] += omega * (gs - x[i])
        if np.linalg.norm(b - A @ x) < tol * r0:
            return x, k
    return x, max_iter


def jacobi(A, b, tol=1e-8, max_iter=100000):
    x = np.zeros_like(b); d = np.diag(A); R = A - np.diag(d); r0 = np.linalg.norm(b)
    for k in range(1, max_iter + 1):
        x = (b - R @ x) / d
        if np.linalg.norm(b - A @ x) < tol * r0:
            return x, k
    return x, max_iter


def cg(A, b, tol=1e-8):
    x = np.zeros_like(b); r = b.copy(); p = r.copy(); rr = r @ r; r0 = math.sqrt(rr)
    for k in range(1, 10 * len(b)):
        Ap = A @ p; alpha = rr / (p @ Ap)
        x += alpha * p; r -= alpha * Ap
        rr_new = r @ r
        if math.sqrt(rr_new) < tol * r0:
            return x, k
        p = r + (rr_new / rr) * p; rr = rr_new
    return x, k


if __name__ == "__main__":
    n = 40
    A = poisson1d(n); b = np.ones(n) / (n + 1) ** 2
    exact = np.linalg.solve(A, b)
    w_opt = 2 / (1 + math.sin(math.pi / (n + 1)))
    results = {"Jacobi": jacobi(A, b), "Gauss-Seidel": sor(A, b), f"SOR (w = {w_opt:.3f})": sor(A, b, w_opt), "CG": cg(A, b)}
    for name, (x, k) in results.items():
        print(f"{name:20s} {k:6d} iterations, error {np.linalg.norm(x - exact)/np.linalg.norm(exact):.1e}")
        assert np.linalg.norm(x - exact) < 1e-6 * np.linalg.norm(exact)
    kj, kg, ks, kc = (results[k][1] for k in results)
    # theory: residual iterations track the spectral-radius estimates within a factor of about 1.5
    rho = math.cos(math.pi / (n + 1))
    assert 0.6 < kj / (math.log(1e-8) / math.log(rho)) < 1.5 and 1.7 < kj / kg < 2.3
    assert ks < 200 and kc <= n
```

:::exercise Pick the solver
For the 1D Poisson matrix with $n = 1000$, estimate the Jacobi iterations needed for a $10^{-6}$ reduction, and compare with CG's worst-case bound using $\kappa \approx 4(n+1)^2/\pi^2$.
---solution---
1. $\rho_J = \cos(\pi/1001) \approx 1 - \tfrac12(\pi/1001)^2 = 1 - 4.93\times10^{-6}$.
2. Jacobi iterations: $\ln10^{-6}/\ln\rho \approx 13.8/4.93\times10^{-6} \approx 2.8\times10^6$.
3. $\kappa \approx 4\cdot1001^2/\pi^2 = 4.06\times10^5$, $\sqrt\kappa = 637$. CG's factor per step is about $1 - 2/\sqrt\kappa$, so it needs about $13.8\cdot637/2 \approx 4400$ steps, and it can't exceed 1000 in exact arithmetic.
4. CG is three orders of magnitude faster. For a tridiagonal matrix, Thomas (lesson 02.14) beats both; iterative methods shine in 3D, where direct solvers fill in.
:::
