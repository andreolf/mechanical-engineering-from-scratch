You measure a spring at six extensions and get six forces. Hooke's law has two unknowns (stiffness and an offset), so six equations can't all hold exactly: the data is noisy. Least squares picks the line that makes the total squared error smallest, and the reason it works is pure geometry: the best fit is an orthogonal projection.

## Overdetermined systems

With more equations than unknowns, $A\mathbf x = \mathbf b$ usually has no solution because $\mathbf b$ isn't in the column space of $A$. Instead, minimise the length of the residual $\mathbf r = \mathbf b - A\mathbf x$:

$$
\min_{\mathbf x} \|\mathbf b - A\mathbf x\|_2^2 .
$$

## The projection picture

$A\mathbf x$ ranges over the column space. The closest point to $\mathbf b$ in that space is its orthogonal projection, so at the optimum the residual is perpendicular to every column:

$$
A^{\mathsf T}(\mathbf b - A\hat{\mathbf x}) = \mathbf 0 \quad\Longrightarrow\quad A^{\mathsf T}A\,\hat{\mathbf x} = A^{\mathsf T}\mathbf b .
$$

These are the **normal equations**. If the columns of $A$ are independent, $A^{\mathsf T}A$ is invertible and the fit is unique.

## Don't solve the normal equations blindly

$A^{\mathsf T}A$ squares the condition number: if $\kappa(A) = 10^6$, then $\kappa(A^{\mathsf T}A) = 10^{12}$ and you've lost twelve of your sixteen digits. For small, well-scaled fits like the one below the normal equations are fine. For anything else, use QR (lesson 02.08) or the SVD, which is what `np.linalg.lstsq` does.

:::widget lsq
Twelve noisy measurements of a 2.4 N/mm spring. Degree 1 recovers the stiffness. Push the degree up and the curve chases the noise: the residual shrinks, but the model gets worse.
:::

:::example Fitting a spring test
Extensions $x = 0, 1, 2, 3, 4, 5$ mm, forces $F = 0.1, 2.6, 4.7, 7.4, 9.6, 12.1$ N. Model $F = kx + F_0$.

1. $A$ has columns $x$ and $\mathbf 1$. Then $A^{\mathsf T}A = \begin{pmatrix} \sum x^2 & \sum x \\ \sum x & 6 \end{pmatrix} = \begin{pmatrix} 55 & 15 \\ 15 & 6 \end{pmatrix}$ and $A^{\mathsf T}\mathbf F = \begin{pmatrix} \sum xF \\ \sum F \end{pmatrix} = \begin{pmatrix} 133.1 \\ 36.5 \end{pmatrix}$.
2. Determinant $55\cdot6 - 15^2 = 105$.
3. $k = (6\cdot133.1 - 15\cdot36.5)/105 = 251.1/105 = 2.391$ N/mm.
4. $F_0 = (55\cdot36.5 - 15\cdot133.1)/105 = 11/105 = 0.105$ N.
5. Residual norm $\|\mathbf r\| = 0.259$ N, and $A^{\mathsf T}\mathbf r = \mathbf 0$ to rounding: the residual is orthogonal to both columns.

Forcing the line through the origin ($F_0 = 0$) gives $k = \sum xF / \sum x^2 = 133.1/55 = 2.420$ N/mm. Whether to include the offset is a modelling decision: a real load cell usually has one.
:::

```python file=least_squares.py
"""Least-squares fits by normal equations and by QR, with an orthogonality check."""
import numpy as np


def fit_normal(A, b):
    return np.linalg.solve(A.T @ A, A.T @ b)


def fit_qr(A, b):
    Q, R = np.linalg.qr(A)          # reduced QR: A = QR, Q has orthonormal columns
    return np.linalg.solve(R, Q.T @ b)


if __name__ == "__main__":
    x = np.array([0, 1, 2, 3, 4, 5.0])
    F = np.array([0.1, 2.6, 4.7, 7.4, 9.6, 12.1])
    A = np.column_stack([x, np.ones_like(x)])
    k, F0 = fit_normal(A, F)
    r = F - A @ np.array([k, F0])
    print(f"k = {k:.4f} N/mm, F0 = {F0:.4f} N, |r| = {np.linalg.norm(r):.4f} N")
    assert abs(k - 251.1 / 105) < 1e-12 and abs(F0 - 11 / 105) < 1e-12
    assert np.allclose(A.T @ r, 0, atol=1e-12)                       # residual is orthogonal to the columns
    assert np.allclose(fit_qr(A, F), [k, F0]) and np.allclose(np.linalg.lstsq(A, F, rcond=None)[0], [k, F0])
    # an ill-conditioned fit: degree-11 polynomial in raw x on [10, 11]
    t = np.linspace(10, 11, 40)
    V = np.vander(t, 12)
    y = np.cos(t)
    c_qr, c_ne = fit_qr(V, y), np.linalg.lstsq(V.T @ V, V.T @ y, rcond=None)[0]
    e_qr, e_ne = np.linalg.norm(V @ c_qr - y), np.linalg.norm(V @ c_ne - y)
    print(f"cond(V) = {np.linalg.cond(V):.1e}; residual with QR {e_qr:.1e}, with normal equations {e_ne:.1e}")
    assert e_qr < 1e-6 and e_ne > 100 * e_qr
```

:::exercise Average as least squares
You measure one length four times: 12.02, 11.98, 12.05, 11.99 mm. Write this as an overdetermined system $A\mathbf x = \mathbf b$ for the single unknown $L$, solve the normal equations, and say what you've found.
---solution---
1. $A = (1, 1, 1, 1)^{\mathsf T}$, $\mathbf b = (12.02, 11.98, 12.05, 11.99)^{\mathsf T}$.
2. $A^{\mathsf T}A = 4$ and $A^{\mathsf T}\mathbf b = 48.04$, so $\hat L = 12.01$ mm.
3. That's the arithmetic mean. Least squares with one constant unknown always gives the average, and the residuals $(0.01, -0.03, 0.04, -0.02)$ sum to zero: orthogonal to $(1,1,1,1)$.
:::
