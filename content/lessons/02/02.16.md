This lesson puts Phase 02 together. You'll build the direct stiffness method for pin-jointed trusses: transform each bar's stiffness into global coordinates (lesson 02.13), assemble a sparse symmetric matrix (02.14), apply supports to remove the rigid-body null space (02.06), and solve a positive definite system (02.11). It's the same pipeline as a full finite-element code, in about 40 lines.

## One bar

A bar with axial stiffness $EA/L$ from node $i$ to node $j$, at angle $\theta$, with $c = \cos\theta$, $s = \sin\theta$. Its stretch is the difference of the end displacements projected on the bar axis: $\delta = c(u_j - u_i) + s(v_j - v_i)$. Writing the energy $\tfrac12\frac{EA}{L}\delta^2$ as a quadratic form in $(u_i, v_i, u_j, v_j)$ gives

$$
k_e = \frac{EA}{L}\begin{pmatrix} c^2 & cs & -c^2 & -cs \\ cs & s^2 & -cs & -s^2 \\ -c^2 & -cs & c^2 & cs \\ -cs & -s^2 & cs & s^2 \end{pmatrix} = \frac{EA}{L}\,\mathbf g\mathbf g^{\mathsf T}, \quad \mathbf g = (-c, -s, c, s) .
$$

Rank 1: a single bar only resists stretching.

## Assemble, constrain, solve

1. **Assemble**: add each $k_e$ into the rows and columns of the global $K$ belonging to its two nodes.
2. **Constrain**: delete the rows and columns of supported degrees of freedom. Without this, $K$ is singular (three rigid-body motions in 2D).
3. **Solve** $K_{ff}\mathbf u_f = \mathbf f_f$ for the free displacements.
4. **Recover**: bar force $N = \frac{EA}{L}\,\mathbf g\cdot\mathbf u_e$ (positive in tension); reactions $\mathbf r = K\mathbf u - \mathbf f$ at the supports.

:::example Solve the two-bar truss
Nodes $1 = (0, 0)$ and $2 = (4, 0)$ are pinned; node $3 = (2, 1.5)$ carries $P = 10$ kN downward. Each bar has $EA = 200$ GPa $\times$ 500 mm$^2 = 10^8$ N, $L = 2.5$ m, so $EA/L = 4\times10^7$ N/m.

1. Bar A (node 1 to 3): $c = 0.8$, $s = 0.6$. Bar B (node 2 to 3): $c = -0.8$, $s = 0.6$.
2. Only node 3 is free. Its $2\times2$ block sums both bars: $K_{33} = 4\times10^7\begin{pmatrix} 2(0.64) & 0 \\ 0 & 2(0.36) \end{pmatrix} = \begin{pmatrix} 5.12 & 0 \\ 0 & 2.88 \end{pmatrix}\times10^7$ N/m. The $cs$ terms cancel by symmetry.
3. Solve: $u_3 = 0$, $v_3 = -10^4/2.88\times10^7 = -3.47\times10^{-4}$ m $= -0.347$ mm.
4. Bar A force: $N = 4\times10^7\,(0.8\cdot0 + 0.6\cdot(-3.47\times10^{-4})) = -8333$ N. Compression, and bar B is the same.
5. Hand check by statics at node 3: $2N\sin\theta = -P$, so $N = -10/(2\cdot0.6) = -8.33$ kN. Reactions: 5 kN up at each support, and $\pm6.67$ kN horizontally, pushing the supports apart.
6. Stress: $8333/500 = 16.7$ MPa. The bars are short and stocky, so buckling (Phase 15) isn't the limit here.
:::

```python file=truss.py
"""Direct stiffness method for 2D pin-jointed trusses."""
import math
import numpy as np


def solve_truss(nodes, bars, EA, supports, loads):
    """nodes: [(x, y)], bars: [(i, j)], EA: float or list, supports: {node: (fix_x, fix_y)}, loads: {node: (Fx, Fy)}."""
    n = len(nodes); K = np.zeros((2 * n, 2 * n)); f = np.zeros(2 * n)
    EA = [EA] * len(bars) if np.isscalar(EA) else EA
    geo = []
    for (i, j), ea in zip(bars, EA):
        dx, dy = np.subtract(nodes[j], nodes[i]); L = math.hypot(dx, dy); c, s = dx / L, dy / L
        g = np.array([-c, -s, c, s]); dofs = [2 * i, 2 * i + 1, 2 * j, 2 * j + 1]
        K[np.ix_(dofs, dofs)] += ea / L * np.outer(g, g)
        geo.append((dofs, g, ea / L))
    for node, (fx, fy) in loads.items():
        f[2 * node] += fx; f[2 * node + 1] += fy
    fixed = [2 * k + d for k, fix in supports.items() for d in (0, 1) if fix[d]]
    free = [d for d in range(2 * n) if d not in fixed]
    u = np.zeros(2 * n)
    Kff = K[np.ix_(free, free)]
    L = np.linalg.cholesky(Kff)                      # fails loudly if the truss is a mechanism
    u[free] = np.linalg.solve(L.T, np.linalg.solve(L, f[free]))
    N = np.array([k * g @ u[d] for d, g, k in geo])
    R = K @ u - f
    return u, N, R


if __name__ == "__main__":
    nodes = [(0, 0), (4, 0), (2, 1.5)]
    u, N, R = solve_truss(nodes, [(0, 2), (1, 2)], 1e8, {0: (1, 1), 1: (1, 1)}, {2: (0, -1e4)})
    print(f"apex deflection {u[5]*1e3:.4f} mm, bar forces {np.round(N, 1)} N, reactions {np.round(R[:4], 1)} N")
    assert abs(u[4]) < 1e-15 and abs(u[5] + 1e4 / 2.88e7) < 1e-15
    assert np.allclose(N, -1e4 / 1.2) and np.allclose(R[:4], [1e4 / 1.2 * 0.8, 5e3, -1e4 / 1.2 * 0.8, 5e3])  # reactions on the truss: inward, upward
    assert abs(R[1] + R[3] - 1e4) < 1e-9 and abs(R[0] + R[2]) < 1e-9          # global equilibrium
    # a Warren truss: 4 bays, 10 kN at every bottom joint; compare midspan chord force with statics
    bay, h, nb = 2.0, 1.5, 4
    bot = [(bay * i, 0.0) for i in range(nb + 1)]; top = [(bay * (i + 0.5), h) for i in range(nb)]
    nodes = bot + top; T = lambda i: nb + 1 + i
    bars = [(i, i + 1) for i in range(nb)] + [(T(i), T(i + 1)) for i in range(nb - 1)] \
         + [(i, T(i)) for i in range(nb)] + [(i + 1, T(i)) for i in range(nb)]
    loads = {i: (0, -1e4) for i in range(1, nb)}
    u, N, R = solve_truss(nodes, bars, 1e8, {0: (1, 1), nb: (0, 1)}, loads)
    # method of sections at midspan: the top chord over the middle (between top nodes 1 and 2) carries M/h
    M_mid = 1.5e4 * 4.0 - 1e4 * 2.0                    # reaction 15 kN times 4 m minus the load at 2 m
    i_top = nb + 1                                      # bar index of the top chord T(1)-T(2)
    print(f"Warren truss: midspan top chord {N[i_top]/1e3:.2f} kN, statics {-M_mid/h/1e3:.2f} kN")
    assert abs(N[i_top] + M_mid / h) < 1e-6 and abs(R[1] + R[2 * nb + 1] - 3e4) < 1e-6
    try:
        solve_truss([(0, 0), (1, 0)], [(0, 1)], 1e8, {0: (1, 1)}, {1: (0, -1)}); raise AssertionError
    except np.linalg.LinAlgError:
        print("a single bar with a free end is correctly rejected as a mechanism")
```

:::exercise Make it a mechanism
In the two-bar truss, replace the pin at node 2 by a roller that only stops vertical motion. What happens to the stiffness matrix of the free degrees of freedom, and why does the structure fail even though there are three support reactions?
---solution---
1. Free degrees of freedom are now $u_2$, $u_3$, $v_3$, a $3\times3$ matrix.
2. Supports give three reactions ($x_1$, $y_1$, $y_2$), the minimum for a rigid body in 2D, and there are two bars. Counting: $m + r = 2 + 3 = 5 < 2j = 6$, so there are fewer unknowns than equilibrium equations.
3. The motion that costs nothing: node 2 slides right while node 3 drops, keeping both bar lengths fixed (to first order). That's a null vector of $K_{ff}$, which is singular, and Cholesky fails.
4. Physically the two bars splay apart like a pair of scissors. A third bar between nodes 1 and 2 (a tie) fixes it: $m + r = 6 = 2j$.
:::
