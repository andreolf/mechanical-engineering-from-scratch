Every matrix, square or not, symmetric or not, maps the unit sphere to an ellipsoid. The singular value decomposition names the axes of that ellipsoid. It gives you the rank that survives rounding, the condition number, the best low-rank approximation of a data table, and a stable way to solve any least-squares problem.

## The decomposition

Any real $m\times n$ matrix factors as

$$
A = U\Sigma V^{\mathsf T},
$$

with $U$ ($m\times m$) and $V$ ($n\times n$) orthogonal and $\Sigma$ diagonal with **singular values** $\sigma_1 \ge \sigma_2 \ge \dots \ge 0$. Read it right to left: rotate (by $V^{\mathsf T}$), stretch along the axes (by $\Sigma$), rotate again (by $U$). So $A\mathbf v_i = \sigma_i\mathbf u_i$: the columns of $V$ go to the ellipse axes, scaled by the singular values.

The link to lesson 02.10: $A^{\mathsf T}A = V\Sigma^2V^{\mathsf T}$, so $\sigma_i^2$ are the eigenvalues of the symmetric PD matrix $A^{\mathsf T}A$.

:::widget matrix2d
The white ellipse is the image of the unit circle. Its semi-axes are the singular values. Make the columns nearly parallel and the ellipse flattens: the small singular value heads to zero and the condition number σ₁/σ₂ explodes.
:::

## What it gives you

- **Rank**: the number of singular values above a tolerance. Robust, unlike pivots.
- **Condition number**: $\kappa_2(A) = \sigma_1/\sigma_n$.
- **Low-rank approximation**: keep the top $k$ terms, $A_k = \sum_{i\le k}\sigma_i\mathbf u_i\mathbf v_i^{\mathsf T}$. By the Eckart-Young theorem this is the best rank-$k$ matrix, with error $\|A - A_k\|_2 = \sigma_{k+1}$.
- **Pseudo-inverse and least squares**: $A^+ = V\Sigma^+U^{\mathsf T}$, inverting only the nonzero singular values. $A^+\mathbf b$ is the least-squares solution with the smallest norm, even when $A$ is rank deficient.

:::note Don't compute it from A^T A
Forming $A^{\mathsf T}A$ squares the singular values, so anything below $\sqrt{\varepsilon}\,\sigma_1 \approx 10^{-8}\sigma_1$ disappears into rounding. Library SVDs (Golub-Kahan) work on $A$ directly. The code shows the difference.
:::

:::example SVD of a 2 × 2 by hand
$A = \begin{pmatrix} 3 & 0 \\ 4 & 5 \end{pmatrix}$.

1. $A^{\mathsf T}A = \begin{pmatrix} 25 & 20 \\ 20 & 25 \end{pmatrix}$, eigenvalues $45$ and $5$ with eigenvectors $(1, 1)/\sqrt2$ and $(1, -1)/\sqrt2$.
2. $\sigma_1 = \sqrt{45} = 6.708$, $\sigma_2 = \sqrt5 = 2.236$.
3. $\mathbf u_1 = A\mathbf v_1/\sigma_1 = (3, 9)/(\sqrt2\cdot6.708) = (0.316, 0.949)$.
4. Checks: $\sigma_1\sigma_2 = 15 = |\det A|$; $\kappa_2 = 6.708/2.236 = 3$.

**Low rank in practice.** A $100\times100$ grid of surface temperatures (a hot spot on a gradient) has singular values $3395, 509, 52, 9.7, 9.3, \dots$ once 0.5 K sensor noise is added. The first three carry the physics; the rest is noise. Keeping rank 3 stores 603 numbers instead of 10 000, and cuts the RMS error against the true field from 0.50 K to 0.12 K: truncation also denoises.
:::

```python file=svd.py
"""SVD: geometry checks, low-rank denoising, and why not to go through A^T A."""
import numpy as np


def svd_via_ata(A):
    w, V = np.linalg.eigh(A.T @ A)
    order = np.argsort(w)[::-1]
    return np.sqrt(np.clip(w[order], 0, None)), V[:, order]


def truncate(A, k):
    U, s, Vt = np.linalg.svd(A, full_matrices=False)
    return (U[:, :k] * s[:k]) @ Vt[:k]


if __name__ == "__main__":
    A = np.array([[3, 0], [4, 5.0]])
    s = np.linalg.svd(A, compute_uv=False)
    assert np.allclose(s, [45 ** 0.5, 5 ** 0.5]) and abs(s[0] / s[1] - 3) < 1e-12
    # the unit circle maps to an ellipse whose longest radius is sigma_1
    t = np.linspace(0, 2 * np.pi, 20001)
    r = np.linalg.norm(A @ np.vstack([np.cos(t), np.sin(t)]), axis=0)
    assert abs(r.max() - s[0]) < 1e-6 and abs(r.min() - s[1]) < 1e-6
    # low-rank temperature field with noise
    x = np.linspace(0, 1, 100); X, Y = np.meshgrid(x, x)
    T = 20 + 60 * np.exp(-((X - 0.3) ** 2 + (Y - 0.6) ** 2) / 0.05) + 10 * X * Y
    Tn = T + np.random.default_rng(0).normal(0, 0.5, T.shape)
    rms = lambda E: np.sqrt(np.mean(E ** 2))
    sv = np.linalg.svd(Tn, compute_uv=False)
    print("leading singular values:", np.round(sv[:5], 1))
    print(f"RMS error: noisy {rms(Tn - T):.3f} K, rank-3 {rms(truncate(Tn, 3) - T):.3f} K")
    assert np.linalg.matrix_rank(T) == 3 and rms(truncate(Tn, 3) - T) < 0.3 * rms(Tn - T)
    # Eckart-Young: 2-norm error of the rank-k truncation equals sigma_{k+1}
    rng = np.random.default_rng(1)
    B = rng.standard_normal((30, 20)); sb = np.linalg.svd(B, compute_uv=False)
    for k in (1, 5, 10):
        assert abs(np.linalg.norm(B - truncate(B, k), 2) - sb[k]) < 1e-10
    # small singular values are lost through A^T A
    U, _ = np.linalg.qr(rng.standard_normal((6, 6))); V, _ = np.linalg.qr(rng.standard_normal((6, 6)))
    true = np.array([1, 1e-2, 1e-4, 1e-6, 1e-9, 1e-12])
    C = U @ np.diag(true) @ V.T
    s_lib, s_ata = np.linalg.svd(C, compute_uv=False), svd_via_ata(C)[0]
    print("relative error of smallest sigma: library", f"{abs(s_lib[-1]-1e-12)/1e-12:.1e},", "via A^T A", f"{abs(s_ata[-1]-1e-12)/1e-12:.1e}")
    assert abs(s_lib[-1] - 1e-12) < 1e-4 * 1e-12 and abs(s_ata[-1] - 1e-12) > 1e-12   # library: 6 digits; A^T A: none
```

:::exercise Rank and pseudo-inverse
$A = \begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$. Find its singular values, its rank, and the minimum-norm least-squares solution of $A\mathbf x = (2, 0)$.
---solution---
1. $A^{\mathsf T}A = \begin{pmatrix} 2 & 2 \\ 2 & 2 \end{pmatrix}$, eigenvalues 4 and 0, so $\sigma = 2, 0$ and the rank is 1.
2. $\mathbf v_1 = (1, 1)/\sqrt2$, $\mathbf u_1 = A\mathbf v_1/2 = (1, 1)/\sqrt2$.
3. $A^+ = \mathbf v_1\sigma_1^{-1}\mathbf u_1^{\mathsf T} = \tfrac14\begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$.
4. $\mathbf x = A^+(2, 0) = (0.5, 0.5)$. Then $A\mathbf x = (1, 1)$: the best you can do, since every $A\mathbf x$ has equal components, and $(0.5, 0.5)$ is the shortest $\mathbf x$ that achieves it.
:::
