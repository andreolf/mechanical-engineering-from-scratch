The same force has different components in the ground frame, the frame of a rotating arm, and the frame aligned with a weld. Engineering is full of frame changes: robot kinematics, rotating stress tensors, transforming element stiffness matrices in a truss. Rotation matrices do all of it, and they have a structure (orthogonal, determinant one) that you can test in code.

## Rotations in the plane

Rotating a vector anticlockwise by $\theta$:

$$
R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} .
$$

Its columns are the rotated unit vectors. Two facts make rotations special:

- $R^{\mathsf T}R = I$, so $R^{-1} = R^{\mathsf T}$ and lengths and angles are preserved.
- $\det R = 1$. (An orthogonal matrix with $\det = -1$ is a reflection.)

## Active versus passive

Rotating the **vector** by $\theta$ (active) and rotating the **axes** by $\theta$ (passive) are inverses. If $\mathbf v$ has components $\mathbf v$ in frame $A$, then in frame $B$ (rotated by $\theta$ relative to $A$) its components are $\mathbf v' = R(\theta)^{\mathsf T}\mathbf v$. Mixing these up is the classic sign error; always write down which one you mean.

## Rotations in 3D don't commute

Rotations about $x$, $y$ and $z$ are $3\times3$ matrices with the planar block in the right place. Multiplying them in different orders gives different results: turn a book 90° about $z$ then 90° about $x$, and compare with the opposite order. That's why a set of three angles (Euler angles, roll-pitch-yaw) always comes with a stated order.

## Homogeneous transforms

A rigid-body motion is a rotation plus a translation, $\mathbf p' = R\mathbf p + \mathbf t$. Append a 1 to each point and it becomes a single matrix product:

$$
\begin{pmatrix} \mathbf p' \\ 1 \end{pmatrix} = \begin{pmatrix} R & \mathbf t \\ \mathbf 0^{\mathsf T} & 1 \end{pmatrix}\begin{pmatrix} \mathbf p \\ 1 \end{pmatrix} .
$$

Chain them to walk from the base of a robot to its tool: $T_{0\to2} = T_{0\to1}T_{1\to2}$.

## Tensors transform twice

A stress tensor relates two vectors (a plane's normal and the traction on it), so it picks up a rotation on each side:

$$
\boldsymbol\sigma' = R^{\mathsf T}\boldsymbol\sigma R .
$$

Choose $R$ from the eigenvectors and $\boldsymbol\sigma'$ is diagonal: the principal stresses of lesson 02.10.

2. Elbow to tip: rotate by $45^\circ$ and translate 0.3 m. Total rotation $75^\circ$.
3. Tip: $x = 0.4\cos30^\circ + 0.3\cos75^\circ = 0.3464 + 0.0776 = 0.4241$ m, $y = 0.4\sin30^\circ + 0.3\sin75^\circ = 0.2000 + 0.2898 = 0.4898$ m.
4. Check: the distance from the base is $\sqrt{0.4241^2 + 0.4898^2} = 0.648$ m, and the law of cosines gives $\sqrt{0.4^2 + 0.3^2 + 2\cdot0.4\cdot0.3\cos45^\circ} = 0.648$ m.
:::

```python file=transforms.py
"""Rotation matrices, homogeneous transforms and tensor rotation."""
import math
import numpy as np


def rot2(t):
    c, s = math.cos(t), math.sin(t)
    return np.array([[c, -s], [s, c]])


def rot3(axis, t):
    c, s = math.cos(t), math.sin(t)
    i, j = {"x": (1, 2), "y": (2, 0), "z": (0, 1)}[axis]
    R = np.eye(3); R[i, i] = R[j, j] = c; R[i, j] = -s; R[j, i] = s
    return R


def homog(R, t):
    n = len(t); T = np.eye(n + 1); T[:n, :n] = R; T[:n, n] = t
    return T


def arm_tip(L1, L2, t1, t2):
    T1 = homog(rot2(t1), rot2(t1) @ [L1, 0])
    T2 = homog(rot2(t2), rot2(t2) @ [L2, 0])
    return (T1 @ T2 @ [0, 0, 1])[:2]


if __name__ == "__main__":
    tip = arm_tip(0.4, 0.3, math.radians(30), math.radians(45))
    print("tip:", np.round(tip, 4))
    assert np.allclose(tip, [0.4 * math.cos(math.pi / 6) + 0.3 * math.cos(math.radians(75)),
                             0.4 * math.sin(math.pi / 6) + 0.3 * math.sin(math.radians(75))], atol=1e-15)
    rng = np.random.default_rng(10)
    for _ in range(100):
        R = rot3("x", rng.uniform(-3, 3)) @ rot3("y", rng.uniform(-3, 3)) @ rot3("z", rng.uniform(-3, 3))
        assert np.allclose(R.T @ R, np.eye(3), atol=1e-14) and abs(np.linalg.det(R) - 1) < 1e-14
        v = rng.standard_normal(3)
        assert abs(np.linalg.norm(R @ v) - np.linalg.norm(v)) < 1e-13
    # order matters in 3D
    A = rot3("z", math.pi / 2) @ rot3("x", math.pi / 2)
    B = rot3("x", math.pi / 2) @ rot3("z", math.pi / 2)
    assert not np.allclose(A, B)
    print("Rz Rx e_y =", np.round(A @ [0, 1, 0], 12), " Rx Rz e_y =", np.round(B @ [0, 1, 0], 12))
    # rotating the axes by the principal angle diagonalises the stress tensor
    S = np.array([[80, 30], [30, 20.0]])
    R = rot2(math.radians(22.5))
    Sp = R.T @ S @ R
    assert abs(Sp[0, 1]) < 1e-12 and np.allclose(np.diag(Sp), [50 + 30 * 2 ** 0.5, 50 - 30 * 2 ** 0.5])
    assert abs(np.trace(Sp) - np.trace(S)) < 1e-12        # invariants survive any rotation
    print("rotated stress tensor:\n", np.round(Sp, 6))
```

:::exercise Components in a tilted frame
A force $\mathbf F = (100, 0)$ N acts horizontally on a ramp inclined at $30^\circ$. Find its components along and perpendicular to the ramp, using a passive rotation.
---solution---
1. The ramp frame is the ground frame rotated by $30^\circ$, so $\mathbf F' = R(30^\circ)^{\mathsf T}\mathbf F$.
2. $R^{\mathsf T} = \begin{pmatrix} \cos30^\circ & \sin30^\circ \\ -\sin30^\circ & \cos30^\circ \end{pmatrix}$, so $\mathbf F' = (100\cos30^\circ, -100\sin30^\circ) = (86.6, -50.0)$ N.
3. Along the ramp: 86.6 N up the slope. Perpendicular: 50 N into the ramp surface (negative normal direction).
4. Check: $86.6^2 + 50^2 = 100^2$. The length is unchanged.
:::
