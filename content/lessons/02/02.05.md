The determinant is one number that says whether a square system has a unique solution. Geometrically it's the factor by which the matrix scales areas (in 2D) or volumes (in 3D). In a structure, a zero determinant of the stiffness matrix means something can move without resistance: a mechanism.

## Area scaling

The $2\times2$ matrix $A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$ maps the unit square to the parallelogram spanned by its columns $(a, c)$ and $(b, d)$. That parallelogram's signed area is

$$
\det A = ad - bc ,
$$

the $z$ component of the cross product of the columns from lesson 02.01. A negative value means the map flips orientation, like a mirror.

:::widget matrix2d
The lime shape is the image of the unit square, so its area is |det A|. Slide the entries until the columns line up: the square collapses to a line and det A = 0.
:::

## Rules that matter

- $\det(AB) = \det A \,\det B$: scaling factors multiply.
- $\det A^{\mathsf T} = \det A$.
- Swapping two rows flips the sign; adding a multiple of one row to another changes nothing.
- $\det(cA) = c^n \det A$ for an $n\times n$ matrix.
- $\det A \ne 0$ exactly when $A$ is invertible, and then $\det A^{-1} = 1/\det A$.

## How to compute it

Cofactor expansion is the textbook formula, but it costs about $n!$ operations: for $n = 20$ that's $2.4\times10^{18}$. Use elimination instead. Row operations of the "add a multiple" kind don't change the determinant, so after elimination

$$
\det A = (-1)^{s} \prod_i u_{ii},
$$

where $s$ counts the row swaps. That's $\tfrac23 n^3$ operations, the same as LU.

:::note Small determinant doesn't mean nearly singular
$\det(10^{-3} I_{10}) = 10^{-30}$, but that matrix is perfectly conditioned. Scale changes the determinant without changing how hard the system is. Use the condition number (lesson 02.12) to judge near-singularity.
:::

:::example A spring chain with and without its anchor
Three masses in a row, joined by springs of stiffness $k$, with the first one also tied to a wall. The stiffness matrix is

$$
K = k\begin{pmatrix} 2 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 1 \end{pmatrix} .
$$

1. Eliminate: pivots $2$, then $2 - \tfrac12 = 1.5$, then $1 - \tfrac{1}{1.5} = \tfrac13$.
2. $\det K = k^3 \cdot 2 \cdot 1.5 \cdot \tfrac13 = k^3$. Nonzero, so every load gives a unique displacement.
3. Now cut the wall spring. The first diagonal entry drops to 1: pivots $1$, $1$, $0$. The determinant is zero.
4. Physical reading: with no anchor, the vector $(1, 1, 1)$, all masses shifted equally, stretches no spring. $K(1,1,1)^{\mathsf T} = 0$, a rigid-body motion. Any solver will fail on that matrix, as it should.
:::

```python file=determinant.py
"""Determinants by elimination versus cofactor expansion."""
import itertools
import math
import time
import numpy as np


def det_lu(A):
    A = np.array(A, dtype=float); n = len(A); sign = 1.0
    for k in range(n):
        p = k + np.argmax(np.abs(A[k:, k]))
        if A[p, k] == 0.0:
            return 0.0
        if p != k:
            A[[k, p]] = A[[p, k]]; sign = -sign
        A[k + 1:, k:] -= np.outer(A[k + 1:, k] / A[k, k], A[k, k:])
    return sign * np.prod(np.diag(A))


def det_cofactor(A):
    n = len(A)
    if n == 1:
        return A[0][0]
    return sum((-1) ** j * A[0][j] * det_cofactor([row[:j] + row[j + 1:] for row in A[1:]]) for j in range(n))


if __name__ == "__main__":
    K = [[2, -1, 0], [-1, 2, -1], [0, -1, 1]]
    assert abs(det_lu(K) - 1) < 1e-14 and det_cofactor(K) == 1
    free = [[1, -1, 0], [-1, 2, -1], [0, -1, 1]]
    assert abs(det_lu(free)) < 1e-14 and np.allclose(np.array(free) @ [1, 1, 1], 0)
    rng = np.random.default_rng(4)
    A, B = rng.standard_normal((6, 6)), rng.standard_normal((6, 6))
    assert np.isclose(det_lu(A @ B), det_lu(A) * det_lu(B))
    assert np.isclose(det_lu(3 * A), 3 ** 6 * det_lu(A))
    assert np.isclose(det_lu(A), det_cofactor(A.tolist())) and np.isclose(det_lu(A), np.linalg.det(A))
    # swapping two rows flips the sign
    S = A.copy(); S[[0, 3]] = S[[3, 0]]
    assert np.isclose(det_lu(S), -det_lu(A))
    for n in (6, 7, 8):
        M = rng.standard_normal((n, n)).tolist()
        t = time.perf_counter(); det_cofactor(M); tc = time.perf_counter() - t
        t = time.perf_counter(); det_lu(M); tl = time.perf_counter() - t
        print(f"n = {n}: cofactor {tc*1e3:8.1f} ms, elimination {tl*1e3:6.2f} ms")
```

:::exercise Is the bracket a mechanism?
Two springs, $k_1 = 400$ N/mm and $k_2 = 600$ N/mm, connect a wall to node 1 and node 1 to node 2. Write the $2\times2$ stiffness matrix for the node displacements, compute its determinant, then repeat with $k_1 = 0$.
---solution---
1. $K = \begin{pmatrix} k_1 + k_2 & -k_2 \\ -k_2 & k_2 \end{pmatrix} = \begin{pmatrix} 1000 & -600 \\ -600 & 600 \end{pmatrix}$ N/mm.
2. $\det K = 1000 \cdot 600 - 600^2 = 240\,000$ (N/mm)$^2$, which equals $k_1 k_2$. Invertible.
3. With $k_1 = 0$: $\det = 600\cdot600 - 600^2 = 0$. Nothing holds the pair to the wall, so $(1, 1)$ is a free motion.
:::
