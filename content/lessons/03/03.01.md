Real quantities depend on more than one thing. Gas pressure depends on temperature and volume; the stress in a beam depends on position along it and across it; the temperature of a plate depends on $x$, $y$ and time. This lesson sets up the language: level sets to see such functions, partial derivatives to measure them, and the total differential to estimate how errors and changes combine.

## Seeing a function of two variables

$f(x, y)$ is a surface over the plane. Two views help:

- **Level sets** (contours): the curves $f(x, y) = c$. A weather map's isobars, a topographic map's height lines, isotherms on a heated plate.
- **Slices**: hold one variable fixed and plot $f$ against the other. A slice is an ordinary one-variable function.

:::widget gradient
Contours of the bowl $f = \tfrac12(x^2 + \kappa y^2)$: brighter bands are higher values. Increase the elongation and the contours stretch into thin ellipses. (Lesson 03.02 explains the path and the arrows.)
:::

## Partial derivatives

The partial derivative with respect to $x$ is the slope of the slice in the $x$ direction, with $y$ held fixed:

$$
\frac{\partial f}{\partial x}(x, y) = \lim_{h\to0}\frac{f(x + h, y) - f(x, y)}{h} .
$$

Compute it by treating every other variable as a constant. Numerically, use the central difference from lesson 01.03 in one variable at a time.

## The total differential

If both inputs change a little, the changes add up to first order:

$$
df = \frac{\partial f}{\partial x}\,dx + \frac{\partial f}{\partial y}\,dy .
$$

This is the tangent-plane approximation, the 2D version of the tangent line. Two uses dominate engineering:

1. **Sensitivity**: which input matters most? Compare $|\partial f/\partial x_i|\,\Delta x_i$ term by term.
2. **Error propagation**: for independent random errors $\sigma_i$, $\sigma_f \approx \sqrt{\sum_i(\partial f/\partial x_i)^2\sigma_i^2}$.

:::note Order of differentiation
For smooth functions, $\partial^2 f/\partial x\,\partial y = \partial^2 f/\partial y\,\partial x$ (Schwarz's theorem). The code checks it numerically.
:::

:::example Pressure in a heated tank
1 kg of air ($R = 287$ J/(kg K)) at $T = 300$ K in $V = 0.5$ m³. Ideal gas: $p = mRT/V = 172.2$ kPa.

1. $\partial p/\partial T = mR/V = 574$ Pa/K.
2. $\partial p/\partial V = -mRT/V^2 = -344\,400$ Pa/m³.
3. The tank warms by 2 K and bulges by 0.01 m³: $dp = 574\cdot2 - 344\,400\cdot0.01 = 1148 - 3444 = -2296$ Pa.
4. Exact: $p(302, 0.51) - p(300, 0.5) = 169\,949 - 172\,200 = -2251$ Pa. The linear estimate is 2% off because $dV/V = 2\%$ isn't tiny.
5. Error propagation: with $\sigma_T = 0.5$ K and $\sigma_V = 0.002$ m³, $\sigma_p = \sqrt{(574\cdot0.5)^2 + (344\,400\cdot0.002)^2}$, which is $\sqrt{287^2 + 689^2} = 746$ Pa. The volume measurement dominates, so that's the one to improve.
:::

```python file=partials.py
"""Partial derivatives by central differences, the total differential and error propagation."""
import math


def partial(f, x, i, h=None):
    """Central difference in variable i at point x (a list)."""
    h = h or 1e-6 * max(1.0, abs(x[i]))
    xp, xm = list(x), list(x)
    xp[i] += h; xm[i] -= h
    return (f(xp) - f(xm)) / (2 * h)


def grad(f, x):
    return [partial(f, x, i) for i in range(len(x))]


def propagate(f, x, sigmas):
    g = grad(f, x)
    return math.sqrt(sum((gi * si) ** 2 for gi, si in zip(g, sigmas)))


if __name__ == "__main__":
    m, R = 1.0, 287.0
    p = lambda v: m * R * v[0] / v[1]           # v = [T, V]
    x0 = [300.0, 0.5]
    dpdT, dpdV = grad(p, x0)
    print(f"dp/dT = {dpdT:.3f} Pa/K, dp/dV = {dpdV:.1f} Pa/m^3")
    assert abs(dpdT - 574) < 1e-5 and abs(dpdV + 344400) < 1e-2
    dp_lin = dpdT * 2 + dpdV * 0.01
    dp_exact = p([302, 0.51]) - p(x0)
    print(f"linear estimate {dp_lin:.0f} Pa, exact {dp_exact:.0f} Pa")
    assert abs(dp_lin + 2296) < 0.1 and abs(dp_exact + 2251) < 1
    # the estimate improves quadratically as the change shrinks
    errs = []
    for s in (1.0, 0.1, 0.01):
        lin = dpdT * 2 * s + dpdV * 0.01 * s
        errs.append(abs(p([300 + 2 * s, 0.5 + 0.01 * s]) - p(x0) - lin))
    assert 80 < errs[0] / errs[1] < 120 and 80 < errs[1] / errs[2] < 120
    sigma_p = propagate(p, x0, [0.5, 0.002])
    print(f"sigma_p = {sigma_p:.0f} Pa")
    assert abs(sigma_p - math.hypot(287, 688.8)) < 0.5
    # mixed partials commute for a smooth function
    f = lambda v: math.sin(v[0] * v[1]) + v[0] ** 3 * v[1]
    fx = lambda v: partial(f, v, 0, 1e-4)
    fy = lambda v: partial(f, v, 1, 1e-4)
    a, b = partial(fx, [0.7, 1.3], 1, 1e-4), partial(fy, [0.7, 1.3], 0, 1e-4)
    assert abs(a - b) < 1e-5
```

:::exercise Which measurement matters?
The bending stress in a rectangular beam is $\sigma = 6M/(bh^2)$. With $M = 2$ kN m, $b = 40$ mm, $h = 100$ mm, each measured with 1% error, which dimension dominates the uncertainty in $\sigma$?
---solution---
1. $\sigma = 6\cdot2\times10^6/(40\cdot100^2) = 30$ MPa.
2. Relative sensitivities: $\frac{\partial\sigma}{\partial M}\frac{M}{\sigma} = 1$, $\frac{\partial\sigma}{\partial b}\frac{b}{\sigma} = -1$, $\frac{\partial\sigma}{\partial h}\frac{h}{\sigma} = -2$.
3. 1% errors become 1%, 1% and 2% in $\sigma$; combined $\sqrt{1 + 1 + 4} = 2.4\%$, about 0.73 MPa.
4. The depth $h$ dominates because it appears squared. Measure it more carefully first.
:::
