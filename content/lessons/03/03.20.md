If a structure is linear, you only need to know its response to a single point load. Any other load is a sum of point loads, so the response is a sum (an integral) of point-load responses. The point-load response is the **Green's function**. Engineers know it as the influence line, and it's the idea behind the boundary element method and much of signal processing.

## The idea

For a linear operator $\mathcal L$ (for a beam, $\mathcal L u = EI\,u''''$) with boundary conditions, the Green's function $G(x, \xi)$ solves

$$
\mathcal L\,G(x, \xi) = \delta(x - \xi),
$$

the response at $x$ to a unit point load at $\xi$. Then for a distributed load $q$:

$$
u(x) = \int G(x, \xi)\,q(\xi)\,d\xi .
$$

It's superposition taken to the limit. In time, the same idea is the impulse response $h(t)$, and $y = \int h(t - \tau)\,f(\tau)\,d\tau$ is a convolution.

## The simply supported beam

For a beam of length $L$ and a unit load at $\xi$, with $x \le \xi$ and $b = L - \xi$:

$$
G(x, \xi) = \frac{b\,x}{6EIL}\big(L^2 - b^2 - x^2\big),
$$

and by symmetry (swap the roles) for $x > \xi$. Integrate it against a uniform load $w$ and you recover the textbook midspan deflection $5wL^4/(384EI)$.

## Maxwell's reciprocal theorem

$G(x, \xi) = G(\xi, x)$: the deflection at A due to a load at B equals the deflection at B due to the same load at A. It follows from the symmetry of the stiffness operator, the continuous version of $K = K^{\mathsf T}$ from Phase 02. It's also a practical trick: to find how a load anywhere affects one point, put a single load at that point and measure the deflected shape.

:::example A steel beam under two load cases
An IPE 200 section ($I = 1943\times10^4$ mm⁴, $E = 200$ GPa, so $EI = 3.886\times10^6$ N m²) spans $L = 4$ m, simply supported.

1. Point load $P = 10$ kN at midspan: $\delta = PL^3/(48EI) = 10^4\cdot64/(48\cdot3.886\times10^6) = 3.43$ mm. This is $P\,G(L/2, L/2)$.
2. Uniform load $w = 5$ kN/m: $\delta = \int_0^L G(L/2, \xi)\,w\,d\xi = 5wL^4/(384EI) = 4.29$ mm. The code does the integral numerically and matches.
3. Influence line: move the 10 kN load to $\xi = 1$ m and read the midspan deflection off $G(2, 1)$: 2.36 mm. Reciprocity says a load at midspan deflects the point $x = 1$ m by the same 2.36 mm.
4. Both load cases together: $3.43 + 4.29 = 7.72$ mm. Linearity lets you add them; a span/deflection ratio of $4000/7.72 = 518$ passes a typical $L/300$ serviceability limit.
:::

```python file=greens.py
"""Green's function of a simply supported beam: superposition, reciprocity and textbook checks."""
import numpy as np


def G(x, xi, L, EI):
    """Deflection at x from a unit downward load at xi (positive downward)."""
    x, xi = np.broadcast_arrays(np.asarray(x, float), np.asarray(xi, float))
    lo, hi = np.minimum(x, xi), np.maximum(x, xi)
    b = L - hi
    return b * lo * (L ** 2 - b ** 2 - lo ** 2) / (6 * EI * L)


def deflection(x, q, L, EI, n=20001):
    xi = np.linspace(0, L, n)
    return np.trapezoid(G(x, xi, L, EI) * q(xi), xi)


if __name__ == "__main__":
    L, EI = 4.0, 200e9 * 1943e-8
    P, w = 1e4, 5e3
    d_point = P * G(L / 2, L / 2, L, EI)
    d_udl = deflection(L / 2, lambda s: w * np.ones_like(s), L, EI)
    print(f"point load {d_point*1e3:.3f} mm, uniform load {d_udl*1e3:.3f} mm, both {1e3*(d_point+d_udl):.2f} mm")
    assert abs(d_point - P * L ** 3 / (48 * EI)) < 1e-15
    assert abs(d_udl - 5 * w * L ** 4 / (384 * EI)) < 1e-9
    # reciprocity: G(x, xi) = G(xi, x)
    rng = np.random.default_rng(15)
    a, b = rng.uniform(0, L, 100), rng.uniform(0, L, 100)
    assert np.allclose(G(a, b, L, EI), G(b, a, L, EI), rtol=0, atol=1e-18)
    print(f"influence: 10 kN at 1 m gives {P * G(2, 1, L, EI) * 1e3:.3f} mm at midspan")
    # a point load as the limit of a narrow uniform patch
    for width in (0.4, 0.04):
        patch = lambda s, wd=width: np.where(np.abs(s - L / 2) < wd / 2, P / wd, 0.0)
        print(f"patch of width {width} m: {deflection(L / 2, patch, L, EI, 400001) * 1e3:.4f} mm")
    assert abs(deflection(L / 2, lambda s: np.where(np.abs(s - 2) < 0.02, P / 0.04, 0.0), L, EI, 400001) - d_point) < 1e-3 * d_point
    # a triangular load rising from 0 to w: by symmetry its midspan deflection is half the uniform one
    q_tri = lambda s: w * s / L
    d_tri = deflection(L / 2, q_tri, L, EI)
    assert abs(d_tri - 0.5 * d_udl) < 1e-12          # mirror it and add: the two triangles make a uniform load
```

:::exercise Where should the jack go?
On the same beam, a hydraulic jack pushes up with force $F$ at $x = 1$ m to cancel the midspan deflection from the 5 kN/m uniform load. Using the influence value from the example, how big must $F$ be?
---solution---
1. Midspan deflection from the uniform load: 4.29 mm down.
2. A unit upward force at $x = 1$ m lifts midspan by $G(2, 1) = 2.36\times10^{-7}$ m/N (from 2.36 mm per 10 kN).
3. $F = 4.29\times10^{-3}/2.36\times10^{-7} = 18.2$ kN.
4. Reciprocity check: that's the same as asking how much a load at midspan would deflect the jack point. Placing the jack at midspan instead would need only $4.29/3.43 \times 10 = 12.5$ kN, because the beam is most flexible there.
:::
