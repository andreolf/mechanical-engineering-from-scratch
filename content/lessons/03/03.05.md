Mass, centroid, second moment of area, total heat in a body: all are integrals over a region in 2D or 3D. You compute them as iterated one-dimensional integrals, slicing the region into strips. The second moment of area $I$ is the headline example in mechanics, because it sets how stiff a beam is in bending.

## Iterated integrals

Over a rectangle, integrate in one variable with the other fixed, then integrate the result:

$$
\iint_R f\,dA = \int_a^b\!\Big(\int_c^d f(x, y)\,dy\Big)dx .
$$

For a non-rectangular region, the inner limits depend on the outer variable: for the region between $y = g_1(x)$ and $y = g_2(x)$, the inner integral runs from $g_1(x)$ to $g_2(x)$. Fubini's theorem says the order doesn't matter for well-behaved $f$, so pick whichever makes the limits easiest.

## Quantities you'll compute

| Quantity | Integral |
|---|---|
| Area | $A = \iint dA$ |
| Centroid | $\bar y = \frac1A\iint y\,dA$ |
| Second moment about the $x$ axis | $I_x = \iint y^2\,dA$ |
| Mass of a body | $m = \iiint\rho\,dV$ |

For a rectangle of width $b$ and height $h$ about its centroid, $I = \int_{-h/2}^{h/2} b\,y^2\,dy = bh^3/12$. The cube on $h$ is why beams are deep rather than wide.

## The parallel axis theorem

The second moment about an axis a distance $d$ from the centroid is $I = I_c + Ad^2$. Build composite sections (T, I, channel) from rectangles with it.

## Numerical integration in 2D

The midpoint rule extends directly: split the region into cells, evaluate at each centre, sum value × area. Its error is $O(h^2)$ as in 1D. For high dimensions, grids become hopeless ($n^d$ points) and **Monte Carlo** (average $f$ at random points) wins: its error falls like $1/\sqrt N$ regardless of dimension.

:::example Bending stiffness of a T-beam
Flange $100\times20$ mm on top of a web $20\times80$ mm, base at $y = 0$.

1. Areas: flange $2000$ mm² with centroid at $y = 90$; web $1600$ mm² at $y = 40$.
2. Centroid: $\bar y = (2000\cdot90 + 1600\cdot40)/3600 = 67.78$ mm.
3. Flange: $I_c = 100\cdot20^3/12 = 66\,667$, distance $d = 22.22$, $Ad^2 = 987\,654$. Total $1\,054\,321$ mm⁴.
4. Web: $I_c = 20\cdot80^3/12 = 853\,333$, $d = 27.78$, $Ad^2 = 1\,234\,568$. Total $2\,087\,901$ mm⁴.
5. $I = 3.142\times10^6$ mm⁴. The code gets the same number by brute-force double integration over the shape.

A solid $40\times100$ mm rectangle (more material, 4000 mm²) has $I = 40\cdot100^3/12 = 3.333\times10^6$ mm⁴. The T uses 10% less material for 6% less stiffness, and its flange can carry a slab.
:::

```python file=double_integrals.py
"""Double integrals by the midpoint rule and Monte Carlo: centroid and second moment of a T-section."""
import math
import numpy as np


def in_T(x, y):
    flange = (y >= 80) & (y <= 100) & (np.abs(x) <= 50)
    web = (y >= 0) & (y < 80) & (np.abs(x) <= 10)
    return flange | web


def midpoint_2d(f, region, x0, x1, y0, y1, n):
    hx, hy = (x1 - x0) / n, (y1 - y0) / n
    X, Y = np.meshgrid(x0 + hx * (np.arange(n) + 0.5), y0 + hy * (np.arange(n) + 0.5))
    return np.sum(f(X, Y) * region(X, Y)) * hx * hy


if __name__ == "__main__":
    one = lambda x, y: np.ones_like(x)
    n = 2000
    A = midpoint_2d(one, in_T, -50, 50, 0, 100, n)
    ybar = midpoint_2d(lambda x, y: y, in_T, -50, 50, 0, 100, n) / A
    I = midpoint_2d(lambda x, y: (y - ybar) ** 2, in_T, -50, 50, 0, 100, n)
    print(f"A = {A:.1f} mm^2, ybar = {ybar:.3f} mm, I = {I:.4e} mm^4")
    assert abs(A - 3600) < 1e-6 and abs(ybar - 244000 / 3600) < 1e-6
    I_exact = 100 * 20 ** 3 / 12 + 2000 * (90 - ybar) ** 2 + 20 * 80 ** 3 / 12 + 1600 * (40 - ybar) ** 2
    assert abs(I - I_exact) / I_exact < 1e-6 and abs(I_exact - 3142222.2) < 0.1
    # rectangle about its centroid: b h^3 / 12, and midpoint error falls like h^2 for a smooth integrand
    f = lambda x, y: np.exp(-x * y)
    exact = sum((-1) ** k / (math.factorial(k) * (k + 1) ** 2) for k in range(40))   # integral over the unit square
    errs = [abs(midpoint_2d(f, lambda x, y: True, 0, 1, 0, 1, m) - exact) for m in (20, 40, 80)]
    print("midpoint errors:", [f"{e:.1e}" for e in errs])
    assert 3.6 < errs[0] / errs[1] < 4.4 and 3.6 < errs[1] / errs[2] < 4.4
    # Monte Carlo on the T: error ~ 1 / sqrt(N)
    rng = np.random.default_rng(11)
    for N in (10 ** 4, 10 ** 6):
        x, y = rng.uniform(-50, 50, N), rng.uniform(0, 100, N)
        print(f"Monte Carlo area with N = {N:>7}: {1e4 * np.mean(in_T(x, y)):.1f} mm^2")
    assert abs(1e4 * np.mean(in_T(x, y)) - 3600) < 30
```

:::exercise Wide or deep?
A plank is $200\times50$ mm. Compare its second moment of area laid flat (bending about the axis parallel to the 200 mm side) and on edge. By what factor is the on-edge orientation stiffer?
---solution---
1. Flat: $b = 200$, $h = 50$: $I = 200\cdot50^3/12 = 2.083\times10^6$ mm⁴.
2. On edge: $b = 50$, $h = 200$: $I = 50\cdot200^3/12 = 3.333\times10^7$ mm⁴.
3. Ratio $(200/50)^2 = 16$. Same material, sixteen times stiffer, because the depth is cubed and the width only enters linearly.
:::
