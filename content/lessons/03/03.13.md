Partial differential equations describe fields that change in space and time: temperature, displacement, pressure, velocity. Second-order linear PDEs come in three families, and the family decides everything: what boundary and initial data you need, how information travels, and which numerical method will work. The test is a discriminant, just like for conic sections.

## The three types

For $A\,u_{xx} + B\,u_{xy} + C\,u_{yy} + (\text{lower-order terms}) = 0$, compute $B^2 - 4AC$:

| $B^2 - 4AC$ | Type | Prototype | Behaviour |
|---|---|---|---|
| $< 0$ | elliptic | Laplace $u_{xx} + u_{yy} = 0$ | equilibrium; every point feels every boundary point |
| $= 0$ | parabolic | heat $u_t = \alpha u_{xx}$ | diffusion; smooths out, infinite propagation speed, one direction in time |
| $> 0$ | hyperbolic | wave $u_{tt} = c^2u_{xx}$ | waves; information travels at finite speed along characteristics |

For the heat equation, take $y = t$: $A = \alpha$, $B = C = 0$, so $B^2 - 4AC = 0$. For the wave equation, $A = c^2$, $C = -1$: $B^2 - 4AC = 4c^2 > 0$.

## What each type needs

- **Elliptic**: boundary conditions all around a closed region, no initial data. Steady heat conduction, static elasticity, potential flow.
- **Parabolic**: an initial condition plus boundary conditions. Transient heat, diffusion of a pollutant, consolidation of soil.
- **Hyperbolic**: initial displacement and velocity plus boundary conditions. Vibrating strings and beams, acoustics, supersonic flow.

## Characteristics

For hyperbolic equations there are curves along which information travels. For $u_{tt} = c^2u_{xx}$ they're the lines $x \pm ct = \text{const}$: a disturbance at one point affects only the region between those lines, its **domain of influence**. Numerical methods must respect this: a time step that lets information jump further than one grid cell per step is unstable (the CFL condition, lesson 04.15).

## Type can change: compressible flow

Small disturbances in steady 2D compressible flow satisfy $(1 - M^2)\,\phi_{xx} + \phi_{yy} = 0$, where $M$ is the Mach number. Then $B^2 - 4AC = -4(1 - M^2)$:

- $M < 1$: elliptic. A subsonic body is felt upstream; air starts moving aside before the nose arrives.
- $M > 1$: hyperbolic. Disturbances stay inside a Mach cone of half-angle $\mu = \arcsin(1/M)$, and nothing upstream knows the body is coming.

:::example Classify and interpret
1. $3u_{xx} + 2u_{xy} + u_{yy} = 0$: $B^2 - 4AC = 4 - 12 = -8$. Elliptic.
2. $u_{xx} - 4u_{xy} + 4u_{yy} = 0$: $16 - 16 = 0$. Parabolic.
3. A flat plate in an airflow at $M = 2$: $1 - M^2 = -3$, so $B^2 - 4AC = 12 > 0$, hyperbolic. Mach angle $\mu = \arcsin(1/2) = 30^\circ$.
4. The same plate at $M = 0.5$: $B^2 - 4AC = -3$, elliptic. The flow field is smooth everywhere and extends upstream.
5. Characteristics for case 3: slopes $dy/dx = \pm1/\sqrt{M^2 - 1} = \pm0.577$, lines at $\pm30^\circ$. The Mach waves.
:::

```python file=classify_pde.py
"""Classify second-order PDEs and compute characteristic directions."""
import math
import numpy as np


def classify(A, B, C, tol=1e-12):
    d = B * B - 4 * A * C
    return "hyperbolic" if d > tol else "elliptic" if d < -tol else "parabolic"


def characteristic_slopes(A, B, C):
    """Roots of A (dy/dx)^2 - B (dy/dx) + C = 0, real only for hyperbolic or parabolic equations."""
    d = B * B - 4 * A * C
    if d < 0:
        return ()
    return tuple(sorted(((B - math.sqrt(d)) / (2 * A), (B + math.sqrt(d)) / (2 * A))))


if __name__ == "__main__":
    assert classify(3, 2, 1) == "elliptic" and classify(1, -4, 4) == "parabolic"
    assert classify(1, 0, 1) == "elliptic"                 # Laplace
    assert classify(1.2e-5, 0, 0) == "parabolic"           # heat, with y = t
    assert classify(343.0 ** 2, 0, -1) == "hyperbolic"     # wave, with y = t
    for M in (0.5, 0.99, 1.5, 2.0, 3.0):
        kind = classify(1 - M * M, 0, 1)
        line = f"M = {M}: {kind}"
        if M > 1:
            s = characteristic_slopes(1 - M * M, 0, 1)
            mu = math.degrees(math.atan(abs(s[1])))
            assert abs(mu - math.degrees(math.asin(1 / M))) < 1e-9
            line += f", Mach angle {mu:.2f} deg"
        print(line)
    # wave equation: characteristics x +- c t, so dt/dx = +-1/c
    s = characteristic_slopes(1.0, 0.0, -1 / 343.0 ** 2)
    assert np.allclose(np.abs(s), 1 / 343.0)
    # numerical check: a wave pulse moves exactly along its characteristic
    c = 2.0; f = lambda z: np.exp(-50 * z ** 2)
    x = np.linspace(-1, 5, 6001)
    for t in (0.5, 1.0, 1.5):
        u = 0.5 * (f(x - c * t) + f(x + c * t))
        right = x[x > 0][np.argmax(u[x > 0])]
        assert abs(right - c * t) < 2e-3
```

:::exercise The Tricomi equation
The Tricomi equation $y\,u_{xx} + u_{yy} = 0$ models transonic flow. Where in the plane is it elliptic, parabolic and hyperbolic?
---solution---
1. $A = y$, $B = 0$, $C = 1$, so $B^2 - 4AC = -4y$.
2. $y > 0$: negative discriminant, elliptic (subsonic region).
3. $y = 0$: parabolic (the sonic line).
4. $y < 0$: hyperbolic (supersonic region).
5. A single equation can change type across the domain, which is why transonic flow is hard to compute: the solver has to switch between equilibrium-like and wave-like behaviour.
:::
