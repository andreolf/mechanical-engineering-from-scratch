Push a crate across a floor along a winding path and the work you do depends on the path. Lift it against gravity and only the height difference matters. Line integrals make that distinction precise. They add up a field along a curve, and the question "does the path matter?" leads to potential energy and conservative forces.

## Work as a line integral

A force field $\mathbf F(\mathbf r)$ acting on a particle moving along a curve $C$ does work

$$
W = \int_C\mathbf F\cdot d\mathbf r = \int_a^b\mathbf F(\mathbf r(t))\cdot\mathbf r'(t)\,dt,
$$

where $\mathbf r(t)$, $a \le t \le b$, traces the curve. Only the force component along the motion counts, as in lesson 02.01.

## Conservative fields

If $\mathbf F = \nabla\phi$ for some scalar $\phi$, the integral telescopes:

$$
\int_C\nabla\phi\cdot d\mathbf r = \phi(\mathbf r_{\text{end}}) - \phi(\mathbf r_{\text{start}}) .
$$

The work is path independent, and around any closed loop it's zero. In physics the potential energy is $V = -\phi$, so $\mathbf F = -\nabla V$. Gravity and ideal springs are conservative; friction and drag are not.

## Testing for conservative

In 2D, $\mathbf F = (P, Q)$ on a region without holes is conservative exactly when

$$
\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y} .
$$

(Mixed partials of $\phi$ commute.) In 3D the condition is $\nabla\times\mathbf F = \mathbf 0$, the subject of lesson 03.09. To find $\phi$, integrate $P$ with respect to $x$, then fix the "constant" (a function of $y$) by matching $Q$.

:::example Path matters, or not
Move from $(1, 0)$ to $(0, 1)$ (metres) along two paths: the straight line, and the quarter circle of radius 1.

**Field 1:** $\mathbf F = (2xy, x^2)$ N. Test: $\partial Q/\partial x = 2x = \partial P/\partial y$, conservative with $\phi = x^2y$.

1. Work $= \phi(0, 1) - \phi(1, 0) = 0 - 0 = 0$ J on either path.

**Field 2:** $\mathbf F = (-y, x)$ N, a swirl. Test: $\partial Q/\partial x = 1 \ne -1 = \partial P/\partial y$, not conservative.

2. Straight line $\mathbf r = (1 - t, t)$: $\mathbf F\cdot\mathbf r' = (-t)(-1) + (1 - t)(1) = 1$, so $W = 1$ J.
3. Quarter circle $\mathbf r = (\cos t, \sin t)$, $0 \le t \le \pi/2$: $\mathbf F\cdot\mathbf r' = \sin^2t + \cos^2t = 1$, so $W = \pi/2 = 1.571$ J.

Different paths, different work. Around the full unit circle, Field 2 does $2\pi$ J: a machine that extracts energy each lap, which is why real forces of this shape (a stirring paddle, wind in a vortex) need a power source.
:::

```python file=line_integrals.py
"""Line integrals along parametrised paths; testing whether a force field is conservative."""
import math
import numpy as np


def line_integral(F, r, dr, a, b, n=20000):
    """Gauss-Legendre-free version: composite Simpson on t."""
    t = np.linspace(a, b, n + 1)
    vals = np.array([np.dot(F(*r(ti)), dr(ti)) for ti in t])
    h = (b - a) / n
    return h / 3 * (vals[0] + vals[-1] + 4 * vals[1:-1:2].sum() + 2 * vals[2:-1:2].sum())


def is_conservative_2d(P, Q, pts, h=1e-5):
    return all(abs((Q(x + h, y) - Q(x - h, y)) / (2 * h) - (P(x, y + h) - P(x, y - h)) / (2 * h)) < 1e-6 for x, y in pts)


if __name__ == "__main__":
    line = (lambda t: (1 - t, t), lambda t: (-1.0, 1.0), 0, 1)
    arc = (lambda t: (math.cos(t), math.sin(t)), lambda t: (-math.sin(t), math.cos(t)), 0, math.pi / 2)
    F1 = lambda x, y: (2 * x * y, x * x)
    F2 = lambda x, y: (-y, x)
    W = {(f, p): line_integral(F, *path) for f, F in (("F1", F1), ("F2", F2)) for p, path in (("line", line), ("arc", arc))}
    for k, v in W.items():
        print(f"{k[0]} along the {k[1]:4s}: {v:.6f} J")
    assert abs(W["F1", "line"]) < 1e-10 and abs(W["F1", "arc"]) < 1e-10
    assert abs(W["F2", "line"] - 1) < 1e-10 and abs(W["F2", "arc"] - math.pi / 2) < 1e-10
    rng = np.random.default_rng(12); pts = rng.uniform(-2, 2, (50, 2))
    assert is_conservative_2d(lambda x, y: 2 * x * y, lambda x, y: x * x, pts)
    assert not is_conservative_2d(lambda x, y: -y, lambda x, y: x, pts)
    # gravity on a helical path: work depends only on the height drop
    m, g = 2.0, 9.81
    helix = (lambda t: (math.cos(t), math.sin(t), -0.1 * t), lambda t: (-math.sin(t), math.cos(t), -0.1), 0, 10 * math.pi)
    Wg = line_integral(lambda x, y, z: (0, 0, -m * g), *helix)
    assert abs(Wg - m * g * math.pi) < 1e-9
    print(f"gravity on a helix dropping {math.pi:.3f} m: {Wg:.4f} J = m g h")
```

:::exercise Find the potential
Show that $\mathbf F = (y\cos x + 2x,\ \sin x)$ is conservative, find $\phi$, and compute the work from $(0, 0)$ to $(\pi/2, 3)$.
---solution---
1. $\partial Q/\partial x = \cos x$ and $\partial P/\partial y = \cos x$: equal, so conservative.
2. $\phi = \int(y\cos x + 2x)\,dx = y\sin x + x^2 + g(y)$. Then $\partial\phi/\partial y = \sin x + g'(y) = Q = \sin x$, so $g$ is a constant.
3. $\phi = y\sin x + x^2$. Work $= \phi(\pi/2, 3) - \phi(0, 0) = 3 + \pi^2/4 = 5.467$.
:::
