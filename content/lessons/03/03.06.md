Shafts, pipes, pressure vessels and bearings are round. Describing them in $x$ and $y$ makes every integral messy; in polar or cylindrical coordinates the limits become constants. The one thing to remember when you switch is the **Jacobian**, the factor that says how big a small coordinate box really is.

## Polar coordinates

$x = r\cos\theta$, $y = r\sin\theta$. A small box $dr \times d\theta$ is a curved patch of width $dr$ and arc length $r\,d\theta$, so

$$
dA = r\,dr\,d\theta .
$$

The extra $r$ is the Jacobian $|\partial(x, y)/\partial(r, \theta)| = r$. Forget it and you'll get the area of a disc as $2\pi R$ instead of $\pi R^2$.

## Cylindrical and spherical

| System | Coordinates | Volume element |
|---|---|---|
| Cylindrical | $x = r\cos\theta$, $y = r\sin\theta$, $z$ | $dV = r\,dr\,d\theta\,dz$ |
| Spherical | $x = \rho\sin\phi\cos\theta$, $y = \rho\sin\phi\sin\theta$, $z = \rho\cos\phi$ | $dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta$ |

Here $\phi$ is measured from the $z$ axis. Check: $\int_0^{2\pi}\!\int_0^\pi\!\int_0^R \rho^2\sin\phi\,d\rho\,d\phi\,d\theta = \tfrac43\pi R^3$.

## The polar second moment

Torsion of a shaft depends on $J = \iint r^2\,dA$. For a hollow circular section with outer diameter $D$ and inner $d$:

$$
J = \int_0^{2\pi}\!\int_{d/2}^{D/2} r^2\cdot r\,dr\,d\theta = \frac{\pi}{32}(D^4 - d^4),
$$

and the maximum shear stress under torque $T$ is $\tau_{\max} = T(D/2)/J$.

:::example Hollow versus solid shaft
A drive shaft carries $T = 500$ N m. Option A is hollow, $D = 50$ mm, $d = 40$ mm. Option B is solid with the same cross-section area, so the same mass.

1. A: area $\tfrac\pi4(50^2 - 40^2) = 706.9$ mm²; $J = \tfrac{\pi}{32}(50^4 - 40^4) = 362\,265$ mm⁴.
2. A: $\tau_{\max} = 500\,000\cdot25/362\,265 = 34.5$ MPa.
3. B: same area means $d_s = \sqrt{4\cdot706.9/\pi} = 30.0$ mm, so $J = \tfrac{\pi}{32}30^4 = 79\,522$ mm⁴.
4. B: $\tau_{\max} = 500\,000\cdot15/79\,522 = 94.3$ MPa.

Same steel, same weight, and the hollow shaft runs at 37% of the stress. Material near the centre carries little torque because the stress there is small; moving it outwards, where $r^2$ is large, pays off. That's why bicycle frames and drive shafts are tubes.
:::

```python file=polar.py
"""Integrals in polar and spherical coordinates, checked against closed forms."""
import math
import numpy as np


def polar_integral(f, r0, r1, n_r=400, n_t=400):
    """Midpoint rule over an annulus with the Jacobian r."""
    hr, ht = (r1 - r0) / n_r, 2 * math.pi / n_t
    r = r0 + hr * (np.arange(n_r) + 0.5)
    t = ht * (np.arange(n_t) + 0.5)
    R, T = np.meshgrid(r, t)
    return np.sum(f(R, T) * R) * hr * ht


def J_hollow(D, d):
    return math.pi / 32 * (D ** 4 - d ** 4)


if __name__ == "__main__":
    J = polar_integral(lambda r, t: r ** 2, 20, 25)
    print(f"J numeric {J:.1f} mm^4, formula {J_hollow(50, 40):.1f} mm^4")
    assert abs(J - J_hollow(50, 40)) / J < 1e-5
    tau_A = 500e3 * 25 / J_hollow(50, 40)
    tau_B = 500e3 * 15 / J_hollow(30, 0)
    print(f"hollow {tau_A:.1f} MPa, solid {tau_B:.1f} MPa")
    assert abs(tau_A - 34.505) < 1e-3 and abs(tau_B - 94.314) < 1e-3
    # forgetting the Jacobian gives the wrong area of a disc
    with_j = polar_integral(lambda r, t: np.ones_like(r), 0, 1)
    without = np.sum(np.ones((400, 400))) * (1 / 400) * (2 * math.pi / 400)
    assert abs(with_j - math.pi) < 1e-9 and abs(without - 2 * math.pi) < 1e-9
    # sphere volume in spherical coordinates
    n = 200; hp = math.pi / n; hr = 1 / n
    rho = hr * (np.arange(n) + 0.5); phi = hp * (np.arange(n) + 0.5)
    P, Rh = np.meshgrid(phi, rho)
    V = 2 * math.pi * np.sum(Rh ** 2 * np.sin(P)) * hr * hp
    assert abs(V - 4 / 3 * math.pi) < 1e-3
    # the Gaussian integral via polar coordinates: (integral e^{-x^2})^2 = pi
    G = polar_integral(lambda r, t: np.exp(-r ** 2), 0, 8, 8000, 4)
    assert abs(G - math.pi) < 1e-6
    print("disc, sphere and Gaussian integrals all check out")
```

:::exercise Mass of a dome
A hemispherical concrete dome has inner radius 10 m and outer radius 10.3 m, with density 2400 kg/m³. Find its mass using spherical coordinates.
---solution---
1. $V = \int_0^{2\pi}\!\int_0^{\pi/2}\!\int_{10}^{10.3}\rho^2\sin\phi\,d\rho\,d\phi\,d\theta = 2\pi\cdot1\cdot\frac{10.3^3 - 10^3}{3}$.
2. $10.3^3 = 1092.727$, so $V = 2\pi\cdot92.727/3 = 194.2$ m³.
3. Mass $= 2400\cdot194.2 = 466\,000$ kg, about 466 t.
4. Check with a thin-shell estimate: area $2\pi(10.15)^2 = 647.3$ m² times thickness 0.3 m is 194.2 m³.
:::
