A PDE alone has infinitely many solutions. The boundary conditions pick the one that matches your physical problem, and getting them wrong is the most common modelling error in simulation. There are three kinds, each with a physical meaning and a standard way to put it into a finite-difference or finite-element model.

## The three types

| Name | Prescribes | Heat transfer meaning | Mechanics meaning |
|---|---|---|---|
| Dirichlet | the value $u$ | fixed temperature (wall clamped to a cold block) | fixed displacement (support) |
| Neumann | the normal derivative $\partial u/\partial n$ | fixed heat flux; zero for insulation or symmetry | applied traction (load) |
| Robin | a combination $a\,u + b\,\partial u/\partial n$ | convection: $-k\,\partial T/\partial n = h(T - T_\infty)$ | elastic support (spring foundation) |

Two practical rules:

- A pure-Neumann problem (only fluxes given) determines the solution only up to a constant, like an unsupported structure (lesson 02.06). At least one Dirichlet or Robin condition pins it down.
- **Symmetry planes** are Neumann conditions with zero flux. Model half or a quarter of a symmetric part and save the computation.

## The Biot number

For convection at a solid's surface, compare the internal conduction resistance $L/k$ with the external convection resistance $1/h$:

$$
Bi = \frac{hL}{k} .
$$

If $Bi \ll 1$, the solid is nearly isothermal and the surface sits close to the interior temperature; if $Bi \gg 1$, the surface is pulled almost to $T_\infty$ and the Robin condition behaves like Dirichlet.

## Boundary conditions in finite differences

- **Dirichlet**: just set the boundary node's value.
- **Neumann and Robin**: add a **ghost node** outside the boundary and use a central difference for the derivative. That keeps second-order accuracy; a one-sided difference drops to first order.

:::example Heat loss through a wall in winter
A 0.2 m brick wall ($k = 1.4$ W/(m K)) has its inner face held at 20 °C (Dirichlet) and its outer face exposed to wind at $-5$ °C with $h = 25$ W/(m² K) (Robin).

1. Resistances in series per square metre: conduction $L/k = 0.1429$ m² K/W, convection $1/h = 0.04$ m² K/W.
2. Heat flux $q = 25/(0.1429 + 0.04) = 136.7$ W/m².
3. Outer surface temperature: $T_s = -5 + q/h = -5 + 5.47 = 0.47$ °C. Just above freezing.
4. $Bi = hL/k = 3.57$: neither limit. Treating the outer face as Dirichlet at $-5$ °C would overestimate the loss to $25/0.1429 = 175$ W/m², 28% too high.
5. The code solves the same problem with finite differences and a ghost node; with 11 nodes it matches the exact flux to machine precision, because the exact solution is linear.
:::

```python file=boundary_conditions.py
"""1D steady conduction with Dirichlet, Neumann and Robin conditions via ghost nodes."""
import numpy as np


def wall(n, L, k, T_in, h, T_inf, q_gen=0.0):
    """Solve k T'' + q_gen = 0 on [0, L]; T(0) = T_in, -k T'(L) = h (T(L) - T_inf)."""
    dx = L / (n - 1)
    A = np.zeros((n, n)); b = np.full(n, -q_gen * dx * dx / k)
    A[0, 0] = 1.0; b[0] = T_in                                   # Dirichlet
    for i in range(1, n - 1):
        A[i, i - 1], A[i, i], A[i, i + 1] = 1.0, -2.0, 1.0
    # ghost node T_{n} from the Robin condition: -k (T_n - T_{n-2}) / (2 dx) = h (T_{n-1} - T_inf)
    # substitute into the stencil at the last node
    A[-1, -2] = 2.0; A[-1, -1] = -2.0 - 2 * dx * h / k; b[-1] += -2 * dx * h / k * T_inf
    return np.linspace(0, L, n), np.linalg.solve(A, b)


if __name__ == "__main__":
    L, k, h = 0.2, 1.4, 25.0
    x, T = wall(11, L, k, 20.0, h, -5.0)
    q = h * (T[-1] + 5.0)
    print(f"outer surface {T[-1]:.4f} C, heat flux {q:.3f} W/m^2, Biot {h*L/k:.2f}")
    assert abs(q - 25 / (L / k + 1 / h)) < 1e-9 and abs(T[-1] - 0.46875) < 1e-9
    # Dirichlet limit: very large h pulls the surface to T_inf
    _, Td = wall(11, L, k, 20.0, 1e9, -5.0)
    assert abs(Td[-1] + 5) < 1e-5
    # Neumann limit: h = 0 is an insulated face, so the wall sits at 20 C
    _, Tn = wall(11, L, k, 20.0, 0.0, -5.0)
    assert np.allclose(Tn, 20.0)
    # with internal heat generation the profile is a parabola; ghost nodes keep second order
    qg = 5e3
    def exact(x):   # T = T_in + C1 x - qg x^2 / (2k), C1 from the Robin condition
        C1 = (h * (-5.0 - 20.0) + qg * L + h * qg * L * L / (2 * k)) / (k + h * L)
        return 20.0 + C1 * x - qg * x * x / (2 * k)
    errs = [np.max(np.abs(wall(n, L, k, 20.0, h, -5.0, qg)[1] - exact(np.linspace(0, L, n)))) for n in (11, 21, 41)]
    print("errors with heat generation:", [f"{e:.2e}" for e in errs])
    assert all(e < 1e-8 for e in errs)    # the stencil is exact for quadratics
```

:::exercise Insulate the wall
You add 60 mm of insulation ($k = 0.035$ W/(m K)) on the outside of the brick wall. What's the new heat flux and the new outer surface temperature?
---solution---
1. Insulation resistance $0.06/0.035 = 1.714$ m² K/W.
2. Total resistance $0.1429 + 1.714 + 0.04 = 1.897$ m² K/W, so $q = 25/1.897 = 13.2$ W/m², about a tenth of before.
3. Outer surface: $T_s = -5 + 13.2/25 = -4.47$ °C, almost the air temperature. With insulation, the Biot number of the whole wall is large and the outer face behaves almost like a Dirichlet boundary.
:::
