Wait long enough and a heated plate stops changing: every point settles at the temperature its surroundings dictate. That steady state obeys Laplace's equation, the most common elliptic PDE in engineering. It also governs potential flow (lesson 03.10), electrostatics, and seepage through soil. You'll solve it two ways: with a series, and with the five-point stencil and an iterative solver from Phase 02.

## From heat to Laplace

Set $\partial T/\partial t = 0$ in the 2D heat equation:

$$
\nabla^2T = \frac{\partial^2T}{\partial x^2} + \frac{\partial^2T}{\partial y^2} = 0 .
$$

With an internal heat source $\dot q$ (W/m³) it becomes Poisson's equation $\nabla^2T = -\dot q/k$.

## Two properties worth knowing

- **Mean value property**: the value at any point equals the average over any circle around it. So the solution has no bumps or dips inside.
- **Maximum principle**: the maximum and minimum occur on the boundary. A plate with edges between 0 and 100 °C is between 0 and 100 °C everywhere inside. Useful as a sanity check on any numerical solution.

## Series solution on a square

Unit square, top edge at $T_0$, other edges at 0. Separation of variables (as in 03.14, but with $\sinh$ in $y$):

$$
T(x, y) = \sum_{n\ \text{odd}}\frac{4T_0}{n\pi\sinh n\pi}\sin(n\pi x)\sinh(n\pi y) .
$$

:::widget plate
A 1 m square plate with the bottom edge held at 0 °C. Set the other three edges and watch the field rebuild itself. The centre is always the average of the four edge temperatures, a consequence of superposition and symmetry.
:::

## The five-point stencil

On a grid with spacing $h$, replace each second derivative by a central difference:

$$
\frac{T_{i+1,j} + T_{i-1,j} + T_{i,j+1} + T_{i,j-1} - 4T_{i,j}}{h^2} = 0 .
$$

Each interior value is the average of its four neighbours: the discrete mean value property. Writing this for every node gives a sparse SPD system (lesson 02.14) with five nonzeros per row. Gauss-Seidel solves it by sweeping "replace each value by the average of its neighbours" until nothing changes; SOR or CG (02.15) do it much faster. The error is $O(h^2)$.

:::example The centre of a hot-topped plate
A square plate with its top edge at 100 °C and the other three at 0 °C.

1. **Superposition trick**: rotate the problem four times so each edge takes a turn at 100 °C. Adding the four solutions gives a plate with all edges at 100 °C, whose solution is 100 °C everywhere. By symmetry each of the four contributes equally at the centre, so the centre is exactly $100/4 = 25$ °C.
2. The series confirms it: $T(0.5, 0.5) = 25.00$ °C. Also $T(0.5, 0.75) = 54.1$ °C and $T(0.5, 0.25) = 9.5$ °C.
3. A $41\times41$ grid with SOR gives the centre to within 0.01 °C of 25 (the code checks it).
4. Halving $h$ cuts the error at $(0.5, 0.75)$ by about 4: second-order accuracy.
:::

```python file=laplace.py
"""Steady heat in a square plate: five-point stencil with SOR, checked against the series solution."""
import math
import numpy as np


def sinh_ratio(a, b):
    """sinh(a) / sinh(b) for 0 <= a <= b without overflow."""
    return math.exp(a - b) * (1 - math.exp(-2 * a)) / (1 - math.exp(-2 * b))


def series(x, y, T0=100.0, terms=301):
    return sum(4 * T0 / (n * math.pi) * math.sin(n * math.pi * x) * sinh_ratio(n * math.pi * y, n * math.pi)
               for n in range(1, terms, 2))


def solve_plate(n, T_top=100.0, tol=1e-10):
    T = np.zeros((n, n)); T[-1, :] = T_top        # row index = y; top row is y = 1
    T[-1, 0] = T[-1, -1] = T_top / 2              # corners: average of the two edges
    w = 2 / (1 + math.sin(math.pi / (n - 1)))     # optimal SOR factor for the square
    for sweep in range(20000):
        change = 0.0
        for j in range(1, n - 1):
            for i in range(1, n - 1):
                new = 0.25 * (T[j, i + 1] + T[j, i - 1] + T[j + 1, i] + T[j - 1, i])
                d = w * (new - T[j, i]); T[j, i] += d; change = max(change, abs(d))
        if change < tol:
            return T, sweep + 1
    return T, sweep + 1


if __name__ == "__main__":
    assert abs(series(0.5, 0.5) - 25) < 1e-9
    print(f"series: centre {series(0.5, 0.5):.4f}, (0.5, 0.75) {series(0.5, 0.75):.3f}, (0.5, 0.25) {series(0.5, 0.25):.3f}")
    errs = []
    for n in (21, 41):
        T, sweeps = solve_plate(n)
        c, q = T[(n - 1) // 2, (n - 1) // 2], T[3 * (n - 1) // 4, (n - 1) // 2]
        errs.append(abs(q - series(0.5, 0.75)))
        print(f"{n}x{n} grid: centre {c:.4f} C after {sweeps} SOR sweeps, error at (0.5, 0.75) {errs[-1]:.4f}")
        assert abs(c - 25) < 0.02
        assert T.max() <= 100 + 1e-12 and T.min() >= -1e-12          # maximum principle
    assert 3.0 < errs[0] / errs[1] < 5.0                              # second order
```

:::exercise Heat through the edges
In the hot-topped plate (unit square, top at 100 °C, other edges at 0 °C, conductivity $k$), which edges carry most of the heat out, and how much heat per unit thickness leaves through the bottom? Differentiate the series term by term at $y = 0$ and integrate over $x$.
---solution---
1. All the heat enters through the top and leaves through the other three edges. The side edges meet the hot edge at the top corners, where the temperature jumps from 100 °C to 0 °C, so the gradients there are unbounded and the sides carry by far the most heat.
2. At $y = 0$: $\partial T/\partial y = \sum \frac{4T_0}{n\pi}\,\frac{n\pi}{\sinh n\pi}\sin n\pi x$. Integrating $\sin n\pi x$ over $[0,1]$ gives $2/(n\pi)$, so the bottom flux is $k\sum_{n\,\text{odd}} \frac{8T_0}{n\pi\sinh n\pi} \approx 22.06\,k$ W per metre of thickness. The first term alone gives 22.05.
3. The total through the sides is infinite in this idealised model: the corner jump is not physical. A real plate has a thin transition zone at each corner, which makes the total finite but still dominated by the sides.
:::
