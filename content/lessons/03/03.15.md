Pluck a guitar string and two things happen at once: a shape travels along the string at a fixed speed, and the string rings at a set of definite pitches. Both views come from the same equation. The wave equation governs strings, axial vibrations of rods, sound in pipes, and (in more dimensions) acoustics and seismic waves.

## Derivation

A string under tension $T$ with mass per length $\mu$. For a small piece $dx$ with small slope, the vertical tension components differ by $T\,\partial^2u/\partial x^2\,dx$. Newton's second law:

$$
\mu\,dx\,\frac{\partial^2u}{\partial t^2} = T\frac{\partial^2u}{\partial x^2}dx \quad\Longrightarrow\quad \frac{\partial^2u}{\partial t^2} = c^2\frac{\partial^2u}{\partial x^2}, \qquad c = \sqrt{T/\mu} .
$$

The same equation holds for longitudinal waves in a rod with $c = \sqrt{E/\rho}$ (about 5100 m/s in steel) and sound in air with $c = \sqrt{\gamma RT}$ (343 m/s at 20 °C).

## Travelling waves: d'Alembert

Any function of $x - ct$ or of $x + ct$ solves the equation. With initial shape $f(x)$ and zero initial velocity,

$$
u(x, t) = \tfrac12\big[f(x - ct) + f(x + ct)\big] :
$$

the initial shape splits into two halves that run apart at speed $c$. At a fixed end the wave reflects upside down.

## Standing waves: modes

With fixed ends at $x = 0$ and $x = L$, separation of variables gives modes $\sin\frac{n\pi x}{L}\cos\omega_nt$ with

$$
f_n = \frac{n}{2L}\sqrt{\frac{T}{\mu}}, \qquad n = 1, 2, 3, \dots
$$

Whole-number multiples of the fundamental: a harmonic series, which is why strings sound musical. A string plucked at a fraction $a$ of its length has mode amplitudes proportional to $\sin(n\pi a)/n^2$. Modes with a node at the pluck point are missing.

:::

:::example Tuning a guitar string
A string of length $L = 0.65$ m and $\mu = 0.4$ g/m is tensioned to $T = 70$ N.

1. Wave speed $c = \sqrt{70/4\times10^{-4}} = 418.3$ m/s.
2. Fundamental $f_1 = c/(2L) = 418.3/1.3 = 321.8$ Hz.
3. The target is E4 at 329.6 Hz. Since $f \propto \sqrt T$, the tension needs to rise by $(329.6/321.8)^2 = 1.049$, to 73.4 N.
4. Plucked at $a = 1/4$: relative harmonic amplitudes $\sin(n\pi/4)/n^2$ normalised to the first are 1, 0.35, 0.11, 0, 0.04, 0.04. The 4th harmonic is missing; pluck near the bridge (small $a$) for a brighter sound with more high harmonics.
5. A pulse takes $L/c = 1.55$ ms to run the length of the string. One period of the fundamental is $2L/c = 3.11$ ms: out to the far end and back.
:::

```python file=wave.py
"""Wave equation on a string: d'Alembert's solution against the mode series, and energy conservation."""
import math
import numpy as np


def pluck(x, L, a):
    """Triangle with peak 1 at x = a L."""
    return np.where(x < a * L, x / (a * L), (L - x) / (L - a * L))


def odd_periodic(f, L):
    """Extend f (defined on [0, L], zero at the ends) oddly with period 2L, as fixed ends require."""
    def g(x):
        y = np.mod(x, 2 * L)
        return np.where(y <= L, f(y), -f(2 * L - y))
    return g


def dalembert(x, t, c, L, a):
    g = odd_periodic(lambda s: pluck(s, L, a), L)
    return 0.5 * (g(x - c * t) + g(x + c * t))


def modes(x, t, c, L, a, N=4000):
    u = np.zeros_like(x)
    for n in range(1, N + 1):
        bn = 2 * math.sin(n * math.pi * a) / (n * math.pi) ** 2 / (a * (1 - a))
        u += bn * np.sin(n * math.pi * x / L) * math.cos(n * math.pi * c * t / L)
    return u


if __name__ == "__main__":
    L, mu, T = 0.65, 4e-4, 70.0
    c = math.sqrt(T / mu); f1 = c / (2 * L)
    print(f"c = {c:.1f} m/s, f1 = {f1:.1f} Hz, tension for 329.6 Hz: {T * (329.6 / f1) ** 2:.1f} N")
    assert abs(f1 - 321.79) < 0.01
    x = np.linspace(0, L, 1301)
    for t in (0.0, 0.3e-3, 1.1e-3, 2.7e-3):
        assert np.max(np.abs(dalembert(x, t, c, L, 0.25) - modes(x, t, c, L, 0.25))) < 2e-3
    # after one full period 2L/c the string is back where it started
    assert np.max(np.abs(dalembert(x, 2 * L / c, c, L, 0.25) - pluck(x, L, 0.25))) < 1e-9
    # half a period later the shape is flipped
    assert np.max(np.abs(dalembert(x, L / c, c, L, 0.25) + pluck(L - x, L, 0.25))) < 1e-9
    # harmonic content: the 4th harmonic vanishes for a pluck at L/4
    amps = [abs(math.sin(n * math.pi / 4)) / n ** 2 for n in range(1, 7)]
    print("relative harmonics:", [round(v / amps[0], 3) for v in amps])
    assert amps[3] < 1e-15
    # energy (kinetic + strain) stays constant as the shape travels and reflects
    xf = np.linspace(0, L, 20001); dt = 1e-8
    def energy(t):
        u_t = (dalembert(xf, t + dt, c, L, 0.25) - dalembert(xf, t - dt, c, L, 0.25)) / (2 * dt)
        u_x = np.gradient(dalembert(xf, t, c, L, 0.25), xf)
        return np.trapezoid(0.5 * mu * u_t ** 2 + 0.5 * T * u_x ** 2, xf)
    E = [energy(t) for t in (0.0, 0.37e-3, 1.21e-3, 2.5e-3)]
    print("energy (J per unit amplitude^2):", [round(float(e), 3) for e in E])
    assert max(E) - min(E) < 0.01 * E[0]
```

:::exercise A steel rod rings
A 1 m steel rod, free at both ends, rings in longitudinal vibration. With $E = 210$ GPa and $\rho = 7850$ kg/m³, what's the wave speed and the fundamental frequency? (For free-free ends, $f_n = nc/(2L)$ as well.)
---solution---
1. $c = \sqrt{E/\rho} = \sqrt{210\times10^9/7850} = 5172$ m/s.
2. $f_1 = c/(2L) = 2586$ Hz.
3. That's the high "ting" of a struck bar. Halving the length doubles the pitch, so a tuning fork maker adjusts frequency by grinding length.
:::
