Near a point, a smooth function of several variables looks like a constant plus a tilted plane plus a curved bowl, saddle or dome. The tilt is the gradient; the curvature is the **Hessian**, the matrix of second derivatives. Its eigenvalues tell you whether a stationary point is a minimum, maximum or saddle, which is exactly the stability test for equilibria in mechanics.

## The second-order expansion

$$
f(\mathbf x + \mathbf h) \approx f(\mathbf x) + \nabla f(\mathbf x)\cdot\mathbf h + \tfrac12\,\mathbf h^{\mathsf T}H(\mathbf x)\,\mathbf h, \qquad H_{ij} = \frac{\partial^2 f}{\partial x_i\,\partial x_j} .
$$

$H$ is symmetric for smooth $f$ (lesson 03.01), so the spectral theorem (02.10) applies: in the eigenvector directions, the quadratic term is a sum of independent parabolas $\tfrac12\lambda_i c_i^2$.

## Classifying stationary points

At a stationary point $\nabla f = \mathbf 0$, and the Hessian decides:

| Eigenvalues of $H$ | Shape | Type |
|---|---|---|
| all positive | bowl | local minimum |
| all negative | dome | local maximum |
| mixed signs | saddle | neither |
| some zero | flat direction | the test is inconclusive |

In mechanics, an equilibrium is stable when the potential energy has a minimum there: $H$ positive definite (lesson 02.11). A ball on a saddle-shaped surface is in equilibrium but unstable.

## Newton's method in several variables

Minimise the quadratic model instead of $f$: set its gradient to zero, $\nabla f + H\mathbf h = \mathbf 0$, and solve for the step

$$
H\,\mathbf h = -\nabla f .
$$

Near a minimum with positive definite $H$, this converges quadratically, like the 1D Newton method in lesson 01.05, and it doesn't care how elongated the bowl is. The cost is forming and solving with $H$ each step.

:::example Find and classify
$f(x, y) = x^3 - 3x + y^2$.

1. $\nabla f = (3x^2 - 3,\ 2y) = \mathbf 0$ at $(1, 0)$ and $(-1, 0)$.
2. $H = \begin{pmatrix} 6x & 0 \\ 0 & 2 \end{pmatrix}$.
3. At $(1, 0)$: eigenvalues 6 and 2, both positive, so a minimum with $f = -2$.
4. At $(-1, 0)$: eigenvalues $-6$ and 2, a saddle with $f = 2$. It's a maximum along $x$ and a minimum along $y$.
5. Quadratic model at the minimum: $f \approx -2 + 3(x - 1)^2 + y^2$. At $(1.1, 0.1)$ it gives $-1.960$; the exact value is $1.331 - 3.3 + 0.01 = -1.959$.
:::

```python file=hessian.py
"""Numerical Hessian, classification of stationary points and Newton's method for minimisation."""
import numpy as np


def num_grad(f, x, h=1e-5):
    x = np.asarray(x, float)
    return np.array([(f(x + h * e) - f(x - h * e)) / (2 * h) for e in np.eye(len(x))])


def num_hessian(f, x, h=1e-4):
    x = np.asarray(x, float); n = len(x); H = np.zeros((n, n))
    for i in range(n):
        for j in range(n):
            ei, ej = h * np.eye(n)[i], h * np.eye(n)[j]
            H[i, j] = (f(x + ei + ej) - f(x + ei - ej) - f(x - ei + ej) + f(x - ei - ej)) / (4 * h * h)
    return 0.5 * (H + H.T)


def classify(H, tol=1e-6):
    w = np.linalg.eigvalsh(H)
    if np.all(w > tol): return "minimum"
    if np.all(w < -tol): return "maximum"
    if np.any(w > tol) and np.any(w < -tol): return "saddle"
    return "inconclusive"


def newton_min(f, x0, tol=1e-10, max_iter=50):
    x = np.asarray(x0, float); hist = [x.copy()]
    for _ in range(max_iter):
        g = num_grad(f, x)
        if np.linalg.norm(g) < tol:
            break
        x = x + np.linalg.solve(num_hessian(f, x), -g)
        hist.append(x.copy())
    return x, hist


if __name__ == "__main__":
    f = lambda p: p[0] ** 3 - 3 * p[0] + p[1] ** 2
    assert classify(num_hessian(f, [1, 0])) == "minimum" and classify(num_hessian(f, [-1, 0])) == "saddle"
    assert np.allclose(num_hessian(f, [1, 0]), [[6, 0], [0, 2]], atol=1e-5)
    q = lambda p: -2 + 3 * (p[0] - 1) ** 2 + p[1] ** 2
    print(f"at (1.1, 0.1): exact {f([1.1, 0.1]):.4f}, quadratic model {q([1.1, 0.1]):.4f}")
    assert abs(f([1.1, 0.1]) - q([1.1, 0.1])) < 2e-3
    # Rosenbrock's banana valley: Newton reaches the minimum (1, 1) in a handful of steps
    rosen = lambda p: (1 - p[0]) ** 2 + 100 * (p[1] - p[0] ** 2) ** 2
    x, hist = newton_min(rosen, [-1.2, 1.0])
    print(f"Rosenbrock: Newton reached {np.round(x, 8)} in {len(hist) - 1} steps")
    assert np.allclose(x, [1, 1], atol=1e-6) and len(hist) - 1 < 15
    assert classify(num_hessian(rosen, [1, 1])) == "minimum"
    # a monkey saddle has a zero Hessian at the origin: inconclusive
    assert classify(num_hessian(lambda p: p[0] ** 3 - 3 * p[0] * p[1] ** 2, [0, 0])) == "inconclusive"
```

:::exercise Stability of a spring-loaded hinge
A bar of length $L$ hinged at its base is held upright by a torsional spring $k_t$ and loaded by a vertical force $P$ at its tip. The potential energy is $V(\theta) = \tfrac12k_t\theta^2 + PL\cos\theta$. When is the upright position $\theta = 0$ stable?
---solution---
1. $V'(\theta) = k_t\theta - PL\sin\theta$, which is zero at $\theta = 0$: an equilibrium for every load.
2. $V''(0) = k_t - PL$.
3. Stable (a minimum) when $k_t - PL > 0$, so $P < k_t/L$. The critical load $P_{cr} = k_t/L$ is a buckling load, the 1D version of the Euler column in Phase 06.
4. Above it, $V''(0) < 0$: the upright position becomes a maximum and the bar tips over to a bent equilibrium.
:::
