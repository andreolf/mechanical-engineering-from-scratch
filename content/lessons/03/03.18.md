The Laplace transform turns linear differential equations with constant coefficients into algebra. Derivatives become multiplications by $s$, initial conditions come along automatically, and the ratio of output to input becomes a **transfer function** whose poles tell you at a glance whether a system is stable, how fast it responds and how much it overshoots. It's the language of control engineering (Phase 18).

## Definition and the key rule

$$
F(s) = \mathcal L\{f(t)\} = \int_0^\infty f(t)\,e^{-st}\,dt .
$$

Integrating by parts gives the rule that does all the work:

$$
\mathcal L\{f'(t)\} = sF(s) - f(0), \qquad \mathcal L\{f''(t)\} = s^2F(s) - sf(0) - f'(0) .
$$

## A small table

| $f(t)$ | $F(s)$ |
|---|---|
| $1$ (unit step) | $1/s$ |
| $e^{-at}$ | $1/(s + a)$ |
| $\sin\omega t$ | $\omega/(s^2 + \omega^2)$ |
| $e^{-at}\cos\omega t$ | $(s + a)/((s + a)^2 + \omega^2)$ |
| $\delta(t)$ (impulse) | $1$ |

## Solving an ODE

For $m\ddot x + c\dot x + kx = F(t)$ starting at rest, transform term by term:

$$
(ms^2 + cs + k)X(s) = F(s) \quad\Longrightarrow\quad G(s) = \frac{X(s)}{F(s)} = \frac{1}{ms^2 + cs + k} .
$$

To get $x(t)$ back, split $X(s)$ into partial fractions and read each term off the table.

## Poles tell the story

The roots of the denominator, the **poles**, are $s = -\zeta\omega_n \pm i\omega_n\sqrt{1 - \zeta^2}$ with $\omega_n = \sqrt{k/m}$ and $\zeta = c/(2\sqrt{km})$. The real part sets the decay rate, the imaginary part the oscillation frequency. All poles in the left half-plane means stable.

Two shortcuts:

- **Final value theorem**: $\lim_{t\to\infty}x(t) = \lim_{s\to0}sX(s)$, if the system is stable.
- **Step overshoot** for a second-order system: $M_p = e^{-\zeta\pi/\sqrt{1 - \zeta^2}}$, peaking at $t_p = \pi/\omega_d$.

:::widget step2
A 1 kg mass under a 10 N step, solved with the Laplace transform. Increase $c$ and the complex poles slide towards the real axis; the overshoot shrinks and vanishes at critical damping, $c = 2\sqrt{km}$.
:::

:::example Step response of a suspension model
$m = 1$ kg, $c = 4$ N s/m, $k = 20$ N/m, hit by a 10 N step force.

1. $X(s) = \dfrac{10}{s(s^2 + 4s + 20)}$.
2. Poles: $s = 0$ and $s = -2 \pm 4i$. So $\omega_n = \sqrt{20} = 4.472$ rad/s, $\zeta = 4/(2\sqrt{20}) = 0.447$, $\omega_d = 4$ rad/s.
3. Final value: $\lim_{s\to0}sX(s) = 10/20 = 0.5$ m, the static deflection $F/k$.
4. Partial fractions: $X(s) = \frac{0.5}{s} - \frac{0.5(s + 2) + 0.25\cdot4}{(s + 2)^2 + 16}$, so $x(t) = 0.5\big[1 - e^{-2t}(\cos4t + 0.5\sin4t)\big]$.
5. Overshoot $e^{-0.447\pi/0.894} = e^{-\pi/2} = 20.8\%$ at $t_p = \pi/4 = 0.785$ s: the peak is $0.604$ m.
:::

```python file=laplace_transform.py
"""Step response by partial fractions (from the poles) checked against direct ODE integration."""
import math
import numpy as np


def step_response_2nd(m, c, k, F, t):
    """Closed form for an underdamped system starting at rest."""
    wn = math.sqrt(k / m); z = c / (2 * math.sqrt(k * m)); wd = wn * math.sqrt(1 - z * z); s = z * wn
    return F / k * (1 - np.exp(-s * t) * (np.cos(wd * t) + s / wd * np.sin(wd * t)))


def residues(num, den):
    """Partial fractions for distinct poles: X(s) = sum r_i / (s - p_i)."""
    p = np.roots(den); dden = np.polyder(den)
    return p, np.polyval(num, p) / np.polyval(dden, p)


def rk4(f, y0, t):
    y = np.array(y0, float); out = [y.copy()]
    for a, b in zip(t[:-1], t[1:]):
        h = b - a; k1 = f(a, y); k2 = f(a + h / 2, y + h / 2 * k1); k3 = f(a + h / 2, y + h / 2 * k2); k4 = f(b, y + h * k3)
        y = y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4); out.append(y.copy())
    return np.array(out)


if __name__ == "__main__":
    m, c, k, F = 1.0, 4.0, 20.0, 10.0
    t = np.linspace(0, 4, 4001)
    p, r = residues([F], np.polymul([1, 0], [m, c, k]))
    x_pf = np.real(sum(ri * np.exp(pi * t) for pi, ri in zip(p, r)))
    x_cf = step_response_2nd(m, c, k, F, t)
    x_ode = rk4(lambda _, y: np.array([y[1], (F - c * y[1] - k * y[0]) / m]), [0, 0], t)[:, 0]
    print("poles:", np.round(p, 6))
    assert np.max(np.abs(x_pf - x_cf)) < 1e-12 and np.max(np.abs(x_ode - x_cf)) < 1e-10
    i = np.argmax(x_cf)
    print(f"peak {x_cf[i]:.4f} m at t = {t[i]:.3f} s, final value {x_cf[-1]:.4f} m")
    assert abs(t[i] - math.pi / 4) < 1e-3 and abs(x_cf[i] / 0.5 - 1 - math.exp(-math.pi / 2)) < 1e-6
    # final value theorem: lim s->0 of s X(s) = F / k
    s = 1e-9
    assert abs(s * F / (s * (m * s * s + c * s + k)) - F / k) < 1e-9
```

:::exercise Pick the damper
For the same $m = 1$ kg and $k = 20$ N/m, what damping $c$ limits the step overshoot to 5%?
---solution---
1. $M_p = e^{-\zeta\pi/\sqrt{1 - \zeta^2}} = 0.05$ gives $\zeta\pi/\sqrt{1 - \zeta^2} = \ln20 = 2.996$.
2. Square and solve: $\zeta^2(\pi^2 + 2.996^2) = 2.996^2$, so $\zeta = 2.996/\sqrt{9.870 + 8.974} = 0.690$.
3. $c = 2\zeta\sqrt{km} = 2\cdot0.690\cdot4.472 = 6.17$ N s/m.
:::
