Here is an embarrassing fact about Bezier curves and B-splines: they cannot draw a circle. A polynomial curve can only approximate one. For a CAD system that must model bearing seats, bolt holes and gear blanks to the micrometre, that is not good enough. The fix is to give every control point a **weight**, which turns the polynomials into ratios of polynomials: **NURBS**, non-uniform rational B-splines.

## Rational curves

$$
C(u) = \frac{\sum_i N_{i,p}(u)\,w_i\,P_i}{\sum_i N_{i,p}(u)\,w_i} .
$$

With all weights equal, this is an ordinary B-spline. Raising $w_i$ pulls the curve towards $P_i$. The neat implementation trick: write each control point in homogeneous coordinates $(w_iP_i, w_i)$, as in 14.02, run plain de Boor in one dimension higher, and divide by the last coordinate at the end.

## A circle, exactly

A rational quadratic Bezier with control points $P_0$, $P_1$, $P_2$ and weights $1, w, 1$ is always a conic section: an ellipse if $w < 1$, a parabola if $w = 1$, a hyperbola if $w > 1$. For a quarter circle, put $P_1$ at the corner of the square and choose

$$
w = \cos 45° = \frac{\sqrt 2}{2} .
$$

Four such quarters, joined with double knots, make a full circle from 9 control points with knots $(0, 0, 0, \tfrac14, \tfrac14, \tfrac12, \tfrac12, \tfrac34, \tfrac34, 1, 1, 1)$. Every point is exactly on the circle, though the parameter does not advance uniformly in angle. This is how STEP files, Onshape, SolidWorks and FreeCAD's OpenCascade kernel store circles, cylinders and spheres.

:::widget nurbsweight
A rational quadratic arc. Find the weight that makes it a perfect quarter circle.
:::

:::example A 62 mm flange
A full NURBS circle of radius 31 mm with 9 control points, weights $(1, \tfrac{\sqrt2}{2}, 1, \dots)$ and the double-knot vector above.

1. At 10001 parameter values, the largest radius error is $1.1\times10^{-14}$ mm: rounding only.
2. At $u = 0.125$, the middle of the first quarter, the point sits at exactly 45°. At $u = 0.0625$ it is at 21.5982°, not 22.5°: the speed varies, the shape does not.
3. The same quarter with $w = 1$ (a plain quadratic Bezier) bulges out to a radius of 32.8805 mm, an error of 1.8805 mm.
4. The shoulder point at $t = \tfrac12$ lies at radius 29.2271 mm for $w = 0.5$, 31.0000 for $w = \sqrt2/2$, 32.8805 for $w = 1$ and 36.5339 for $w = 2$.
:::

```python file=nurbs.py
"""NURBS: a full circle as a degree-2 rational B-spline, checked to be exactly round, against a plain polynomial approximation that is not."""
import math
import numpy as np


def find_span(U, p, u):
    n = len(U) - p - 2
    if u >= U[n + 1]: return n
    k = p
    while not (U[k] <= u < U[k + 1]): k += 1
    return k


def nurbs_point(P, W, U, p, u):
    """De Boor in homogeneous coordinates (w x, w y, w), then divide by w."""
    Pw = [np.array([P[i][0] * W[i], P[i][1] * W[i], W[i]], float) for i in range(len(P))]
    k = find_span(U, p, u)
    d = [Pw[j + k - p].copy() for j in range(p + 1)]
    for r in range(1, p + 1):
        for j in range(p, r - 1, -1):
            i = j + k - p
            a = (u - U[i]) / (U[i + p - r + 1] - U[i])
            d[j] = (1 - a) * d[j - 1] + a * d[j]
    return d[p][:2] / d[p][2]


def rational_quadratic(P0, P1, P2, w, t):
    b = np.array([(1 - t) ** 2, 2 * t * (1 - t) * w, t * t])
    return (b[0] * np.array(P0) + b[1] * np.array(P1) + b[2] * np.array(P2)) / b.sum()


if __name__ == "__main__":
    R = 31.0   # a 62 mm flange, radius in mm
    s = math.sqrt(2) / 2
    P = [(R, 0), (R, R), (0, R), (-R, R), (-R, 0), (-R, -R), (0, -R), (R, -R), (R, 0)]
    W = [1, s, 1, s, 1, s, 1, s, 1]
    U = [0, 0, 0, 0.25, 0.25, 0.5, 0.5, 0.75, 0.75, 1, 1, 1]
    us = np.linspace(0, 1, 10001)
    pts = np.array([nurbs_point(P, W, U, 2, u) for u in us])
    r = np.hypot(pts[:, 0], pts[:, 1])
    print(f"NURBS circle, R = {R} mm: radius error over 10001 points max {np.abs(r - R).max():.1e} mm")
    assert np.abs(r - R).max() < 1e-12
    # the parametrisation is not uniform in angle: speed varies, but the shape is exact
    ang = np.unwrap(np.arctan2(pts[:, 1], pts[:, 0]))
    print(f"angle at u = 0.125, the middle of the first quarter: {math.degrees(ang[1250]):.4f} deg (45 by symmetry)")
    assert abs(math.degrees(ang[1250]) - 45) < 1e-9
    q = math.degrees(ang[625])
    print(f"angle at u = 0.0625: {q:.4f} deg, not 22.5: the speed is non-uniform")
    # the same quarter with weight 1 (a plain quadratic Bezier) is a parabola, not a circle
    tq = np.linspace(0, 1, 2001)
    rq = [np.hypot(*rational_quadratic((R, 0), (R, R), (0, R), 1.0, t)) for t in tq]
    print(f"polynomial (w = 1) quarter arc: radius ranges {min(rq):.4f} to {max(rq):.4f} mm, bulging out by up to {max(rq) - R:.4f} mm")
    assert max(rq) - R > 1.5
    # conic family: w < 1 ellipse, w = 1 parabola, w > 1 hyperbola; the curve's shoulder point at t = 1/2 is the clean test
    for w in (0.5, s, 1.0, 2.0):
        m = rational_quadratic((R, 0), (R, R), (0, R), w, 0.5)
        print(f"  w = {w:.4f}: shoulder point at radius {np.hypot(*m):.4f} mm")
    assert abs(np.hypot(*rational_quadratic((R, 0), (R, R), (0, R), s, 0.5)) - R) < 1e-12
```

:::exercise The shoulder point
For the quarter arc $P_0 = (R, 0)$, $P_1 = (R, R)$, $P_2 = (0, R)$ with weights $(1, w, 1)$, show that the point at $t = \tfrac12$ is at distance $R$ from the origin only when $w = \sqrt2/2$.
---solution---
1. At $t = \tfrac12$ the blending weights are $\tfrac14, \tfrac{w}{2}, \tfrac14$, summing to $\tfrac{1+w}{2}$.
2. The point is $\big(\tfrac R4 + \tfrac{wR}{2},\ \tfrac{wR}{2} + \tfrac R4\big)\big/\tfrac{1+w}{2} = \tfrac{R(1+2w)}{2(1+w)}(1, 1)$.
3. Its distance is $\sqrt2\,R\,\tfrac{1+2w}{2(1+w)}$. Setting this to $R$: $\sqrt2(1 + 2w) = 2(1 + w)$, so $w(2\sqrt2 - 2) = 2 - \sqrt2$, giving $w = \tfrac{2-\sqrt2}{2(\sqrt2-1)} = \tfrac{\sqrt2}{2}$.
:::
