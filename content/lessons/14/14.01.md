A technical drawing is a contract. The machinist in Denpasar or Winterthur who makes your part has never seen your 3D model; they work from views and dimensions. Before learning CAD software, it pays to understand what a drawing view actually is: a **projection**, and a projection is a linear map.

## Orthographic projection

Imagine looking at a part from infinitely far away, so all sight lines are parallel. Each point $(x, y, z)$ lands on the drawing at a position that is a linear function of its coordinates. For the three principal views, the map simply drops one coordinate:

$$
\text{front: } \begin{pmatrix}u\\v\end{pmatrix} = \begin{pmatrix}1&0&0\\0&0&1\end{pmatrix}\begin{pmatrix}x\\y\\z\end{pmatrix}, \quad
\text{top: } \begin{pmatrix}1&0&0\\0&1&0\end{pmatrix}, \quad
\text{side: } \begin{pmatrix}0&1&0\\0&0&1\end{pmatrix} .
$$

Embedded back in 3D, each is a projection matrix $P = M^{\mathsf T}M$ with $P^2 = P$: projecting twice changes nothing. Every edge parallel to the viewing direction collapses to a point, and edges at different depths can land on top of each other. That is why one view is never enough, and why drawings show hidden edges as dashed lines.

## Arranging the views

The views are laid out so that they share dimensions: the front and top views share widths, the front and side views share heights. Europe (ISO, including Switzerland) uses **first-angle** projection: the top view goes *below* the front view and the left-side view goes on the *right*. North America uses **third-angle**, the mirror arrangement. A small truncated-cone symbol in the title block says which one a drawing uses.

## Isometric views

A pictorial view rotates the part before projecting. Turn it 45° about the vertical, tilt it by $\arctan(1/\sqrt 2) = 35.264°$, then drop the depth axis. All three axes are then foreshortened equally, by $\sqrt{2/3} = 0.8165$, which is what "isometric" (equal measure) means.

:::example Views of a stepped block
A block 60 mm long ($x$), 40 mm deep ($y$) and 30 mm high ($z$), with a 25 × 15 mm step cut from the top right along its full depth. Its wireframe has 12 vertices and 18 edges.

1. Projecting all 18 edges with the front matrix gives 6 distinct segments: the L-shaped outline. The 6 depth edges collapse to points and the back profile lands exactly on the front one.
2. The top view gives 7 segments: the 60 × 40 rectangle plus a line at $x = 35$ where the step's vertical face is seen edge-on.
3. The side view gives 7 segments: the 40 × 30 rectangle plus a line at $z = 15$, the edge of the step.
4. Each set matches the hand-drawn view exactly, once collinear segments are split at shared vertices.
5. The isometric matrix foreshortens all three axes by 0.816497 $= \sqrt{2/3}$.
:::

```python file=ortho.py
"""Orthographic projection as linear maps: project a 3D wireframe of a stepped block to front, top and side views and compare with the hand-drawn views."""
import numpy as np

# a stepped block: 60 long (x), 40 deep (y), 30 high (z), with the top-right 25 x 15 step cut away along the full depth
P = np.array([[0, 0, 0], [60, 0, 0], [60, 0, 15], [35, 0, 15], [35, 0, 30], [0, 0, 30]], dtype=float)
V = np.vstack([P, P + [0, 40, 0]])                        # front profile (y = 0) and back profile (y = 40)
E = [(i, (i + 1) % 6) for i in range(6)] + [(i + 6, (i + 1) % 6 + 6) for i in range(6)] + [(i, i + 6) for i in range(6)]

# the three principal views are linear maps R^3 -> R^2 (drop one coordinate)
FRONT = np.array([[1, 0, 0], [0, 0, 1]])                 # look along +y: see x across, z up
TOP = np.array([[1, 0, 0], [0, 1, 0]])                   # look down -z: see x across, y up
SIDE = np.array([[0, 1, 0], [0, 0, 1]])                  # look along -x (from the right): see y across, z up


def project(M, verts, edges):
    """Project every edge and return the set of distinct 2D segments (zero-length ones dropped; overlapping ones merged by endpoints)."""
    q = verts @ M.T
    segs = set()
    for a, b in edges:
        pa, pb = tuple(np.round(q[a], 9)), tuple(np.round(q[b], 9))
        if pa != pb:
            segs.add(tuple(sorted((pa, pb))))
    return segs


def split_collinear(segs):
    """Break segments at every vertex lying on them, so views compare as sets of minimal segments."""
    pts = {p for s in segs for p in s}
    out = set()
    for a, b in segs:
        a_, b_ = np.array(a), np.array(b); d = b_ - a_; L2 = d @ d
        on = sorted({p for p in pts if abs(d[0] * (p[1] - a_[1]) - d[1] * (p[0] - a_[0])) < 1e-9 and -1e-9 <= (np.array(p) - a_) @ d <= L2 + 1e-9},
                    key=lambda p: (np.array(p) - a_) @ d)
        out |= {tuple(sorted((on[i], on[i + 1]))) for i in range(len(on) - 1)}
    return out


def seg(x1, y1, x2, y2):
    return tuple(sorted(((float(x1), float(y1)), (float(x2), float(y2)))))


if __name__ == "__main__":
    # hand-drawn views (as you would sketch them on grid paper)
    hand_front = {seg(0, 0, 60, 0), seg(60, 0, 60, 15), seg(60, 15, 35, 15), seg(35, 15, 35, 30), seg(35, 30, 0, 30), seg(0, 30, 0, 0)}
    hand_top = {seg(0, 0, 35, 0), seg(35, 0, 60, 0), seg(60, 0, 60, 40), seg(60, 40, 35, 40), seg(35, 40, 0, 40), seg(0, 40, 0, 0), seg(35, 0, 35, 40)}
    hand_side = {seg(0, 0, 40, 0), seg(40, 0, 40, 15), seg(40, 15, 40, 30), seg(40, 30, 0, 30), seg(0, 30, 0, 15), seg(0, 15, 0, 0), seg(0, 15, 40, 15)}
    for name, M, hand in (("front", FRONT, hand_front), ("top", TOP, hand_top), ("side", SIDE, hand_side)):
        got = split_collinear(project(M, V, E))
        print(f"{name}: {len(got)} segments, matches the hand drawing: {got == split_collinear(hand)}")
        assert got == split_collinear(hand)
    # projection matrices are idempotent when embedded in 3D: P = M^T M satisfies P @ P = P
    for M in (FRONT, TOP, SIDE):
        Pm = M.T @ M
        assert np.allclose(Pm @ Pm, Pm)
    # isometric view: rotate 45 deg about z, then atan(1/sqrt 2) = 35.264 deg about x, then drop the depth axis
    a, b = np.radians(45), np.arctan(1 / np.sqrt(2))
    Rz = np.array([[np.cos(a), -np.sin(a), 0], [np.sin(a), np.cos(a), 0], [0, 0, 1]])
    Rx = np.array([[1, 0, 0], [0, np.cos(b), -np.sin(b)], [0, np.sin(b), np.cos(b)]])
    ISO = np.array([[1, 0, 0], [0, 0, 1]]) @ Rx @ Rz
    k = np.linalg.norm(ISO, axis=0)
    print(f"isometric foreshortening of x, y, z axes: {k.round(6)} (sqrt(2/3) = {np.sqrt(2/3):.6f}); tilt {np.degrees(b):.3f} deg")
    assert np.allclose(k, np.sqrt(2 / 3))
```

:::exercise A block with a slot
A block 80 × 50 × 20 mm has a slot 20 mm wide and 10 mm deep cut through its full depth ($y$), centred along the top. How many lines does each principal view show (visible and hidden)?
---solution---
1. Front view (looking along $y$): the slot appears as a notch, so the outline has 8 segments, all visible.
2. Top view: the 80 × 50 rectangle plus two lines at $x = 30$ and $x = 50$, where the slot walls are seen edge-on. Splitting the two long edges at the walls gives 3 pieces each, so 6 + 2 + 2 = 10 minimal segments, all visible.
3. Side view (looking along $x$): the 50 × 20 rectangle plus a hidden (dashed) line at $z = 10$, the slot floor, behind the solid end: 5 lines, one of them dashed.
:::
