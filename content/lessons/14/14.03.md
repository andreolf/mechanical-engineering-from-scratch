Draw a smooth curve in any CAD program, a fairing, a fillet, a car body line, and the software stores it not as thousands of points but as a handful of **control points** and a rule for blending them. The two rules at the heart of every CAD system are the Bezier curve (invented at Renault and Citroën in the 1960s) and its flexible descendant, the B-spline.

## Bezier curves

Given control points $P_0, \dots, P_n$, a Bezier curve blends them with the **Bernstein polynomials**:

$$
B(t) = \sum_{i=0}^{n} \binom{n}{i} t^i (1-t)^{n-i}\, P_i, \qquad 0 \le t \le 1 .
$$

The weights are non-negative and sum to 1, so the curve stays inside the convex hull of its control points. It passes through $P_0$ and $P_n$, and its end tangents point along the first and last legs: $B'(0) = n(P_1 - P_0)$.

The stable way to evaluate it is **de Casteljau's algorithm**: interpolate every leg of the control polygon at fraction $t$, repeat on the shorter polygon, and stop when one point is left. It uses only linear interpolation, so it never suffers the cancellation that raw polynomials can.

## B-splines

A single Bezier curve has two problems: its degree grows with the number of control points, and moving any point changes the whole curve. A **B-spline** of degree $p$ fixes both by stitching polynomial pieces together at **knots** $u_0 \le u_1 \le \dots$:

$$
C(u) = \sum_i N_{i,p}(u)\,P_i, \qquad
N_{i,p}(u) = \frac{u - u_i}{u_{i+p} - u_i}N_{i,p-1}(u) + \frac{u_{i+p+1} - u}{u_{i+p+1} - u_{i+1}}N_{i+1,p-1}(u) .
$$

This is the **Cox-de Boor recursion**, starting from $N_{i,0} = 1$ on $[u_i, u_{i+1})$. Each basis function is non-zero only on $p+1$ knot spans, so moving one control point changes the curve only locally. Repeating the end knots $p+1$ times ("clamping") makes the curve start and end at the first and last control points. **De Boor's algorithm** is the B-spline version of de Casteljau.

:::example A velomobile nose fairing
A cubic Bezier from the nose tip (0, 0) to the shoulder (600, 250) mm, with inner control points (0, 160) and (300, 250).

1. De Casteljau and the Bernstein sum agree to $2.3\times10^{-13}$ mm at 101 values of $t$. The curve starts at (0, 0) and ends at (600, 250).
2. A difference quotient at $t = 0$ gives the end tangent (0.001, 480), matching $3(P_1 - P_0) = (0, 480)$: the nose leaves the tip straight up, so it is smoothly rounded.
3. The midpoint $B(0.5)$ is (187.5, 185.0) mm.
4. A clamped cubic B-spline with 7 control points and knots (0, 0, 0, 0, 1, 2, 3, 4, 4, 4, 4): de Boor and the basis-function sum agree to $2.3\times10^{-13}$; the basis functions sum to 1 within $2.2\times10^{-16}$; and the curve starts and ends on the end control points.
5. Moving control point 1 changes the curve only for $u$ between 0.02 and 1.98, inside the support (0, 2) of $N_{1,3}$.
:::

```python file=curves.py
"""Bezier curves by de Casteljau and by Bernstein polynomials, and B-splines by de Boor's algorithm and the Cox-de Boor basis."""
import math
import numpy as np


def de_casteljau(P, t):
    Q = np.array(P, float)
    while len(Q) > 1:
        Q = (1 - t) * Q[:-1] + t * Q[1:]
    return Q[0]


def bernstein(P, t):
    n = len(P) - 1
    return sum(math.comb(n, i) * t ** i * (1 - t) ** (n - i) * np.asarray(P[i], float) for i in range(n + 1))


def find_span(U, p, u):
    n = len(U) - p - 2
    if u >= U[n + 1]: return n
    k = p
    while not (U[k] <= u < U[k + 1]): k += 1
    return k


def de_boor(P, U, p, u):
    k = find_span(U, p, u)
    d = [np.asarray(P[j + k - p], float) for j in range(p + 1)]
    for r in range(1, p + 1):
        for j in range(p, r - 1, -1):
            i = j + k - p
            a = (u - U[i]) / (U[i + p - r + 1] - U[i])
            d[j] = (1 - a) * d[j - 1] + a * d[j]
    return d[p]


def basis(U, p, i, u):
    """Cox-de Boor recursion for N_{i,p}(u). The last knot span is closed so that u = U[-1] works."""
    if p == 0:
        last = u == U[-1] and U[i + 1] == U[-1] and U[i] < U[i + 1]
        return 1.0 if (U[i] <= u < U[i + 1]) or last else 0.0
    a = 0.0 if U[i + p] == U[i] else (u - U[i]) / (U[i + p] - U[i]) * basis(U, p - 1, i, u)
    b = 0.0 if U[i + p + 1] == U[i + 1] else (U[i + p + 1] - u) / (U[i + p + 1] - U[i + 1]) * basis(U, p - 1, i + 1, u)
    return a + b


if __name__ == "__main__":
    # a velomobile nose fairing, a cubic Bezier from the tip (0, 0) to the shoulder (600, 250) mm
    P = [(0, 0), (0, 160), (300, 250), (600, 250)]
    ts = np.linspace(0, 1, 101)
    gap = max(np.abs(de_casteljau(P, t) - bernstein(P, t)).max() for t in ts)
    print(f"de Casteljau vs Bernstein: max difference {gap:.1e} mm; ends {de_casteljau(P, 0)} and {de_casteljau(P, 1)}")
    assert gap < 1e-9 and np.allclose(de_casteljau(P, 0), P[0]) and np.allclose(de_casteljau(P, 1), P[-1])
    # end tangent: B'(0) = n (P1 - P0)
    h = 1e-6
    d0 = (de_casteljau(P, h) - de_casteljau(P, 0)) / h
    print(f"end tangent from a difference quotient {d0.round(3)}, formula 3(P1 - P0) = {3*(np.array(P[1])-P[0])}")
    assert np.allclose(d0, 3 * (np.array(P[1]) - P[0]), atol=1e-2)
    mid = de_casteljau(P, 0.5)
    print(f"midpoint of the fairing at t = 0.5: {mid}")
    # a clamped cubic B-spline through 7 control points
    Q = [(0, 0), (100, 150), (250, 220), (400, 120), (500, 260), (650, 300), (800, 200)]
    p = 3
    U = [0, 0, 0, 0, 1, 2, 3, 4, 4, 4, 4]
    us = np.linspace(0, 4, 201)
    err = max(np.abs(de_boor(Q, U, p, u) - sum(basis(U, p, i, u) * np.array(Q[i], float) for i in range(len(Q)))).max() for u in us)
    pou = max(abs(sum(basis(U, p, i, u) for i in range(len(Q))) - 1) for u in us)
    print(f"de Boor vs basis sum: max difference {err:.1e}; partition of unity error {pou:.1e}")
    assert err < 1e-9 and pou < 1e-12
    assert np.allclose(de_boor(Q, U, p, 0), Q[0]) and np.allclose(de_boor(Q, U, p, 4), Q[-1])
    # local control: N_1,3 is non-zero only on (U[1], U[5]) = (0, 2), so moving control point 1 cannot touch the rest
    Q2 = list(Q); Q2[1] = (100, 50)
    changed = [u for u in us if np.abs(de_boor(Q, U, p, u) - de_boor(Q2, U, p, u)).max() > 1e-12]
    print(f"moving control point 1 changes the curve only for u in [{min(changed):.2f}, {max(changed):.2f}] (support of N_1,3 is (0, 2))")
    assert max(changed) < 2.0
```

:::exercise By hand
Evaluate the quadratic Bezier with $P_0 = (0, 0)$, $P_1 = (2, 4)$, $P_2 = (4, 0)$ at $t = 0.25$, both with de Casteljau and with Bernstein polynomials.
---solution---
1. De Casteljau: first level $(0.5, 1)$ and $(2.5, 3)$; second level $0.75(0.5, 1) + 0.25(2.5, 3) = (1.0, 1.5)$.
2. Bernstein: weights $(0.75^2, 2\cdot0.25\cdot0.75, 0.25^2) = (0.5625, 0.375, 0.0625)$, so $B = 0.375(2, 4) + 0.0625(4, 0) = (1.0, 1.5)$.
:::
