# Mechanical Engineering from Scratch

A free, open-source mechanical engineering curriculum: **20 phases, 356 lessons**, following an ETH-Zurich-style BSc spine plus practice. Every lesson runs the same loop:

1. **Derive** the math by hand
2. **Code** it from scratch (Python/NumPy, sometimes JS)
3. **Test** it against an analytic result, conservation law or benchmark
4. **Keep the artifact**, then meet the open-source pro tool it maps to (FreeCAD, CalculiX, FEniCSx, OpenFOAM…)

The homepage has a live 3D cantilever hero and three "Break the machine" labs (truss bridge, gyroscope, venturi), plus links to two live labs: [The coconut that never escapes](https://andreolf.github.io/coconut-lab/) and [Subak rice terraces](https://andreolf.github.io/subak-lab/).

> Live site: https://andreolf.github.io/mechanical-engineering-from-scratch/

> Status: v2. **164 full lessons are written: Phase 00 (00.01–00.12), Phase 01 (01.01–01.18), Phase 02 (02.01–02.16), Phase 03 (03.01–03.20), Phase 04 (04.01–04.20), Phase 05 (05.01–05.20), Phase 06 (06.01–06.22), Phase 07 (07.01–07.20) and Phase 08 (08.01–08.16).** Each one has its own page with an explanation, KaTeX math, figures or an interactive widget, a worked example with real numbers, from-scratch Python (shown and downloadable), exercises with hidden step-by-step solutions, and a graded quiz. The other 192 lessons (Phases 09–19) show their outline and are marked "Full lesson coming soon". The AI-tutor install command on the site is a **coming-soon placeholder** (no skill package is published yet).

### Progress and certificates

- Progress, XP and streaks live in your browser's `localStorage` only. There are no accounts, no backend and no data collection.
- Each phase has a 12-question test drawn from its lesson quizzes plus dedicated test questions (`content/tests/NN.json`). A score of 80% or more unlocks the phase certificate. Passing every phase unlocks the course certificate.
- Certificates are generated in the browser as PNG or PDF. Each carries a verification code (SHA-256 of scope, name, date and phases), which anyone can check on the site's verify page.
- **This is a free certificate of completion. It is not accredited and is not affiliated with or endorsed by ETH Zurich.**

## Layout

```
curriculum/            one markdown file per phase + curriculum.json (single source of truth)
scripts/phases/*.py    lesson source data (edit these)
scripts/build_curriculum.py   regenerates curriculum/*.md, curriculum.json, site/public/curriculum.json
scripts/validate_curriculum.py checks every lesson has every field
site/                  Vite + vanilla JS + three.js (bundled from npm, no CDN at runtime)
  src/physics.js       pure physics models (beam, truss DSM, gyroscope RK4, Bernoulli pipe)
  unit/                node:test checks of the physics against closed-form results
  src/learn/           lesson app (router, quiz, progress store, certificates, widgets)
  scripts/build-lessons.mjs  markdown + KaTeX -> public/lessons/*.json, code -> public/code/
  tests/               Playwright e2e (desktop, mobile 390, iPhone 13/14 WebKit, Pixel 7, 360px Android, landscape)
content/lessons/NN/    full lesson markdown (one file per lesson)
scripts/check_lessons.py   runs every lesson's Python and recomputes every numeric quiz answer
screenshots/           generated by the e2e run
```

## Run locally

```bash
cd site
npm install
npm run dev            # http://localhost:5183
npm run build && npm run preview   # production build on http://localhost:4183
npm run test:unit      # physics checks
npx playwright install chromium webkit    # first time only
npm run test:e2e       # e2e + screenshots into ../screenshots
```

After editing the outline: `python3 scripts/build_curriculum.py && python3 scripts/validate_curriculum.py`.
After editing a full lesson: `python3 scripts/check_lessons.py` (runs the code and checks the quiz numbers).

## Honesty notes

- All simulations are simplified educational models and are labelled as such on the page (Euler-Bernoulli beam; pin-jointed linear truss with yield and Euler buckling; rigid frictionless symmetric top; 1D Bernoulli with an assumed Darcy friction factor). Do not use them to design real structures.
- ETH course names refer to the public D-MAVT Bachelor programme (2022 regulations) where marked; other mappings are generic descriptions. Not affiliated with or endorsed by ETH Zurich.
- Material values (e.g. bamboo) are typical orders of magnitude and vary widely.
